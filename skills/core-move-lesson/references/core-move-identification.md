# Core Move Identification

Use this reference to turn a homework problem into the lesson spine.

## Output Fields

When analyzing a problem, identify:

- `core_move`: one sentence starting with a concrete action verb.
- `recognition_cue`: what tells the student this move applies.
- `target_output`: what the problem asks for: value, formula, unit, graph choice, truth value, classification, proof step, etc.
- `given_structure`: the equations, objects, diagrams, tables, options, or constraints supplied.
- `prerequisite_floor`: only the facts the student must already know to begin the lesson.
- `failure_modes`: mistakes that should become distractors or later sections.
- `variant_axes`: small changes that preserve the same skill.

## Rules

- Start the core move with an action verb: determine, compute, convert, identify, choose, match, rewrite, compare, infer, solve, estimate, interpret, or prove.
- Name the exact reasoning, recognition, interpretation, conversion, computation, or application being practiced.
- Keep it operational and teachable.
- Tie the move to the problem's mathematical object and answer form.
- Do not use broad verbs like understand or learn.
- Do not include section planning, prerequisites, or assessment details inside the `core_move` sentence.
- Do not merely restate the problem title.

## Good Shape

```text
Determine the units of an unknown coefficient by matching the units of each term in a sum to the left-hand quantity and dividing out the units contributed by powers of time.
```

## Bad Shapes

- Understand angular acceleration.
- Learn dimensional analysis.
- Use formulas involving alpha, omega, and theta.

These are too broad. They do not say what the student must actually do.
