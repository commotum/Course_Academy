# Step Progression

Use this reference to plan the lesson's sections.

## Section Types

- `tutorial`: the first section. It gives the minimum direct instruction needed to recognize and begin the move.
- `example`: every later section. It models and practices one local extension of the same move.

## Typical Progression

1. Introduction to the core move.
2. Simplest canonical example.
3. Same move with one added wrinkle.
4. Common trap or nearby confusion.
5. Variant that changes representation, direction, or condition.
6. Final mixed check if needed.

Most single-problem lessons should have 3-6 sections. Add more only when the same move has meaningful variants the student must recognize.

## Section Planning Checklist

For each section decide:

- `section_title`
- `step_type`
- `learning_goal`
- `worked_example_prompt`
- `solution_step_plan`
- `practice_question_model`
- `distractor_plan`
- `variant_axis`

## Progression Rules

- The first section should make the target move, cue, and expected performance explicit.
- Later sections should deepen the same lesson, not hide a different lesson under the same title.
- Each section should support a worked example and closely matched quiz block.
- Use section order to increase complexity one wrinkle at a time.
- A section may prepare for a later homework problem, but it must still belong to the current core move.
