# Math Academy Lesson Principles

Use these rules to keep the lesson narrow, active, and cumulative.

## Stable Principles

- Every lesson needs a clear instructional spine: one procedure, governing formula, representation, invariant, or test.
- Open by naming the object, rule, cue, or representation that later sections reuse.
- State the condition under which the rule is valid.
- Establish the pattern with a canonical first use before widening the task.
- Keep practice attached to the section it reinforces.
- Reuse notation, wording, and representation style unless the representation change is the point.
- Let the lesson widen through controlled uses of the same machinery.

## Instruction-Action Loop

Each example section should follow this loop:

1. Name the local move.
2. Show it once with a worked example.
3. Ask the student to do a mirrored or near-mirrored version in a quiz block.
4. Provide concise feedback or explanation.
5. Move to one controlled extension.

## Avoid

- Covering a topic family instead of one teachable move.
- Long explanations before the student does anything.
- Practice that changes skill family.
- Multiple new wrinkles in one section.
- Edge cases before the base pattern is stable.
- Distractors that are random rather than tied to real mistakes.
- A summary that names the topic but gives no usable procedure.
