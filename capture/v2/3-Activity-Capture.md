# 3. Activity Capture

## 3.1. Questions

1. Before answering, save the question's Math Academy ID when shown, activity and position, problem, calculator instructions, HTML, screenshot, and images.
2. Record each answer field's type, position, choices, and displayed order.
3. Launch one math-solving sub-agent for the activity's first question and save its session ID. For each later question in that activity, continue that same saved conversation so it retains earlier questions, reasoning, examples, and feedback. Send the new question, answer fields, current choices and their order, screenshot, and images, plus any newly captured examples, worked solutions, and grades. Save its proposed answer for each field, reasoning, and confidence separately. Start a new session for the next activity.
4. Enter the response and verify the field values and selected choices before submission. Record actual submissions, skips, retries, and timing.
5. When feedback appears, save Math Academy's grade, revealed correct answers, worked solution, HTML, and images. Capture any newly revealed answer fields and repeat the answering steps as needed.
6. After the activity is complete, expand the question on its history page and match it to the saved capture. Record difficulty and topic, knowledge-point, and example references; save the final results, expanded worked solution, HTML, screenshot, and images.
7. Keep Math Academy's correct answers as provided. Record any disagreement from the sub-agent for later review.
