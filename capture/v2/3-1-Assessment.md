# 3.1. Assessment

1. Start or resume the assessment. Read its instructions, question count, and time limit.
2. Save each question, its answer fields, choices, images, and original HTML.
3. Answer every question within the time limit. If uncertain, use the best available answer and continue.
4. Submit the assessment and confirm that Math Academy has completed it.
5. Open its activity history page and expand every question. Save grades, revealed correct answers, worked solutions, difficulty, topic/knowledge-point references, and original HTML. Match these to the questions captured during the assessment.
6. Save the completed capture and continue to Post-Activity Processing.
