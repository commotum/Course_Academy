# 3.2. Assessment

1. Start or resume the assessment. Read its instructions, question count, and time limit.
2. Use the shared [Questions](3-1-Questions.md) process to capture and answer every question within the time limit. If uncertain, use the best available answer and continue.
3. Submit the whole assessment and confirm that Math Academy has completed it.
4. Open its activity history page and expand every question. Use the shared question process to save the results and connect them to the questions captured during the assessment.
5. Save the completed capture and continue to Post-Activity Processing.
