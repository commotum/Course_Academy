## Repairs after author probes

The first audit found reliable incidental cues in inherited/initially authored banks: the evaluated-slope operation bank always made the answer the median, some source scalar banks made it an extreme, and unequal TeX spacing made the correct derivative longest. These banks are retained only for explicit original-source replay (`--replay-source`); normal generation rejects historical profiles. This supersedes the proposed normal-profile selection above.

Normal radios now use one declared extension, `scale_bank`. First choose the eligible correct coefficient role (rank 0 through 4) in a consecutive five-integer ladder. Then sample the compatible function and point. If the inner leading coefficient is a and chosen role is j, the bank is the five complete derivative/slope expressions multiplied by q/a for q=a-j,...,a-j+4; q=a is correct. Derive and render all five through the same symbolic simplifier. This is a full parameterized bank, not pooled source distractors. The wrong values are rational scale errors of the complete response. No new learner operation is introduced: the learner still computes the derivative (and evaluates/adds the cubic derivative where requested). Having the same radical exponent in several options is a valid simplification of the choice task; it offers no fixed position/rank or constant response. Linear coefficient recognition is the actual inner-derivative step, not an incidental cue. The chosen rank is not part of semantic identity; mathematical tuples still determine semantic counts.

Normal sampling bounds: signed linear a of magnitude 2..8, nonzero derivative-only shifts -12..12, points -4..4, roots 1..9; quadratic derivative a of magnitude 2..8 and nonzero b -12..12; sqrt quadratic slopes use a finite exact pool with a -5..5 (nonzero), b -12..12 (nonzero), t -4..4 (nonzero), radicand at most 144 and square; reciprocal quadratic slopes retain the starter's finite pool a=1..6, signed b magnitude 1..24, signed t magnitude 1..4, root 2..12. Both signs of the reciprocal slope are supported by reflection. The hard quadratic-radio shape uses a=1..6, b=0, t signed magnitude 1..4, root 1..12, deriving c. This preserves its observed x²-plus-constant shape without requiring the sign of c to be fixed. The sum family uses signed k magnitude 1..4. Source replay permits original values outside sampling bounds, including sum a=1 and linear blank a=3. A controlled fixed-curve zero-slope counterfactual uses -x²+10x at t=2,5,8 to retain exact square roots while varying positive/zero/negative slopes; these explicit test values extend the normal point bound solely for that same-method test.
