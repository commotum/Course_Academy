# Instructional account

The learner applies the cosine sum/difference identity once to a supplied special-angle split, recalls the signed values, multiplies two simple radical products, and combines over denominator four. Imported q-65556/q-141360 and q-332487/q-332488 support supplied splits in easy; q-332492/q-332497/q-274484 support supplied splits and signed special-angle values in moderate. There is no imported hard anchor. Hard retains the supplied split and one forward identity, with quadrant/sign decisions and exact entry; it is an authored overlapping calibration, not a reverse-identity synthesis task. Unit choice alone is not claimed to determine difficulty. Generated ordinary cases exclude familiar target angles that would permit direct unit-circle recall. Complete radio profiles remain for source-supported easy/moderate shapes; exact entry is retained. Published generated cases are evidence of the old implementation, not imported calibration, and are not replayed as source practice.

This account was written before runtime edits. Source capture remains read-only in the audit directory. No database or registration changes are part of this package repair.
