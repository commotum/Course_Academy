## Learner operation and contract

Inspect each term's radical, reciprocal, sign, and coefficient. Distinguish its exponent p from the new exponent p+1; infer the negative exponent for reciprocals. Compute a/(p+1) for each original coefficient a, carrying its sign through division (including sign changes from a negative divisor), and combine the three primitives with C. Choose one complete antiderivative from five math radio options (key `selection`). Equality is up to an additive constant on an interval in the real domain. No logarithms, substitution, products, definite integrals, or extra unknowns are introduced.

Three terms are fixed to preserve the evidenced workload. All exponents exclude -1 because that case requires logarithms, outside this lesson. Odd roots and nonzero x preserve the two hard sources' real domains on either side of zero; explicit domain text states x != 0. The same C applies separately on each interval. The positive integer exponent is 1..7; the reciprocal exponent is -m with m=2..6. The fractional term is either -(d+1)/d or r/d, with d in {3,5,7}, 1<=r<d and gcd(r,d)=1. This is a conservative same-power-rule extension from the hard sources and the seventh-root source, not an observed exhaustive catalog. Coefficients independently range over signed integers with absolute value 1..6, including source values. Roots stay odd to avoid new even-root branch work. All six term orders are eligible; radical/reciprocal notation remains visible, rather than giving away the power rewrite. All choices use the same term order and formatting. Final answers use radicals/reciprocals, as in the sources.

## Answer-bearing assignments and generation order

First choose fractional-power profile and term order. Sample five distinct binary term-assignment rows with two or three of each bit in each column, then select the true row uniformly. Each column represents two competing term values for its role. Relative to the selected true row, convert the four others into an error-assignment matrix (four distractors by three term roles). This treats every candidate as eligible for the true role before values exist, so the correct answer is not structurally distinguished by the most common coefficients or greatest pairwise agreement. Select one error-recipe slot per role before numerical values. A column uses that recipe wherever its bit differs from the true row; the other two available recipes remain unused for that instance. A zero means that term agrees with the correct primitive; nonzero entries select one of three distinct incorrect term values. For each role, a seeded priority order chooses from omit division a, multiply by the new exponent a*(p+1), reverse sign -a/(p+1), divide by the original exponent a/p, divide by the next exponent a/(p+2), divide twice a/(p+1)^2, double the correct coefficient, or halve it. The same pool also includes retaining the original exponent p with the correct primitive coefficient, decrementing the original exponent to p-1 with that coefficient, and (for fractional powers only) negating the new exponent. These exponent mistakes occur in the supplied hard banks. Restrict the last error to fractional terms to keep exponents of different roles distinct and avoid accidental term cancellation. Undefined, correct, and duplicate values are skipped. The original divisor, multiplication, scaling and sign errors are grounded in the observed banks; next-divisor and repeated-division recipes are conservative authored arithmetic-error extensions. Combining these across roles is also an authored bank extension. The wider recipe pool prevents a universal smallest/largest-coefficient cue that a bank of only omitted divisions would create. Then sample compatible exponents and coefficients. Compute every prompt, key, option, solution stage, and metadata entry from this one instance. Reject sampled binary banks with a singleton term class in any column; rows are distinct by construction and all five candidates remain eligible as the true role. Explicit test designs separately reject a wholly correct distractor, duplicate rows, or a term that is wrong in every distractor. The latter ensures no single term alone uniquely identifies the correct option. The coefficient candidates are checked for distinctness after exponents are known; exponent -2 has divisor -1 and makes several naive error formulas coincide, so distinct alternatives are selected rather than rejecting that valid source case. No mathematical instance is rejected. No rejection by correct position, sign, profile, or particular target.

The hard source banks contain fixed conspicuous errors and are replayed exactly, not pooled or silently relabeled as the new profile. Normal practice uses only the declared distributed-term-errors extension: four distractors, three fixed term roles, no added learner operation. Both coefficient and exponent errors occur in normal sampling; no option-independent exponent structure gives the new powers away in every bank. Coefficient signs and magnitudes vary independently, so a fixed sign pattern is not a reliable answer cue. Correct position is shuffled. This finite error pool is not a claim of exhaustive assessment of power-rule mistakes.

Decision coverage obligations: both fractional cases; each odd degree; every eligible numerator; both coefficient signs in every role; all integer/reciprocal exponents; every term order; each correct position; and every error recipe in every role. Count distinct coefficient/exponent instances, not IDs or permutations. Controlled tests change each coefficient and exponent with the other data and bank assignments fixed, require the appropriate answer and solution changes, and use the native grader to reject the old keyed value and accept the new one. An irrelevant presentation reorder must preserve the primitive as a mathematical function. Within each fractional profile, probe fixed option positions, sign patterns, smallest/largest magnitudes, copied first coefficient, common/rare per-term coefficients, and majority-agreement scoring. Also report conditional probes for every term order and root degree within each fractional profile; these small strata have limited statistical power. These probes must not become perfect answer-producing strategies. Compare coverage before and after shared delivery filtering; inspect the five-record runner-style batch as well.

Live learner history and selection policy are unavailable without database access. Read-only inspection of question_selection.rs shows configured selection draws a band then uniformly within that band, after freshness filtering; no claim is made about a particular learner. With hard-only generated records, positive hard weight preserves the available profile support; zero hard weight or exhausted freshness can exclude the whole family. An unconfigured policy chooses the first candidate, so that mode cannot establish varied delivery. Shared check_delivery.py handles the captured inventory and stable identities; source replay is evidence-only and is not sent through publication.

## Implementation audit finding

The first assignment sampler made the correct row unusually central: a most-agreement strategy succeeded on 53% and 64% of negative/positive fractional audit records. Before handoff, this was replaced by the answer-neutral binary-bank construction above, and all affected math, grading, coverage and delivery checks were rerun. This is a repair to the specification as well as the sampler, without imposing answer-position quotas.
