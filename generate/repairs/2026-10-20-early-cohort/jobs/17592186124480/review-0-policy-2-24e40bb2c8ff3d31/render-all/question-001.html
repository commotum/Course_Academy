Review topic

What are the pivot columns of the matrix P, given by

P=[245−4000−400−4−4]?

Select all that apply.

Answer: Column 1: [200]
Answer: Column 2: [400]
Answer: Column 3: [50−4]
Answer: Column 4: [−4−4−4]
CorrectPreview only
Solution:

Answer: Column 1: [200] · correct value:

true

Answer: Column 2: [400] · correct value:

false

Answer: Column 3: [50−4] · correct value:

true

Answer: Column 4: [−4−4−4] · correct value:

true

First, we need to convert P to row echelon form:

P=[245−4000−400−4−4]R2↔R3∼[245−400−4−4000−4]

Looking at the row echelon form, we see that P has 3 pivots. In particular, the pivot columns are the 1st, 3rd, and 4th columns.
