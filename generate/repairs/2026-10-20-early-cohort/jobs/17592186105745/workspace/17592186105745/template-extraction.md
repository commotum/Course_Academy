# Extraction and bounded parameterization

The exact per-source description is in source-cases.json: supplied matrix, coefficient/RHS values, source Markdown, every original field/choice, correct designation and ordered worked solution. Every supported bank replays all five options and four distractors at its original parameters (source-replay.json). q-42156 and q-73524 are explicitly excluded in capabilities.json.

Backbone: a consistent rank-one augmented matrix with two unknowns. The basic variable x and free variable y are fixed because switching their roles would change the specific solved fragment and source solution stages. Eligible row/cell identities are not free target slots: these templates explicitly normalize the first pivot and eliminate the second row, or start in that echelon form. Matrix dimension, coefficient columns, row multipliers, prompt verbs, requested object, five-choice radio contract, field key selection and instructional sentences remain fixed within each observed profile.

The variable slot is a signed nonzero integer scale t of the source RHS. The finite normal domain is {-4,-3,-2,-1,1,2,3,4}; source replay uses t=1. This is a conservative same-method generalization beyond observed literal constants. Each augmented matrix has its third column multiplied by t, including every solution stage and every matrix distractor. Row-operation coefficients stay fixed. A general-solution vector (c+d*y,y) becomes (t*c+d*y,y); an isolated-point distractor (u,v) becomes (t*u,t*v). Source solution equations scale the RHS; solved x expressions scale their constant term; vector and angle forms update together. Zero rows remain zero. Sign changes and non-unit magnitudes are exercised for every profile.

The choice recipe for each source expression is recorded literally and structurally in choice-recipes.json. It is a homogeneous scaling of the observed mathematical object, with no psychological mistake inferred. Fixed coefficient patterns are a narrower sampling policy, not a claim that they are essential to the full KP. No new operations, forms or solution stages are introduced. Each sampled question has one concrete worked solution, independent of response.

Correctness follows independently from rendered data: rank of A and [A|b] is one, every reduction stage has the same exact RREF, every displayed x equation yields the same affine function, and the supplied vector solves both equations for every real y. A point alone is not a general solution. Complete generated banks have one correct option and five distinct mathematical answer objects. The automorphism induced by multiplying the RHS by nonzero t preserves linear elimination and correctness/noncorrectness of each mapped option; validators additionally check every bounded instance.

Fidelity: original prompt, solution and all five answer strings replay exactly at t=1. Correct designation and complete bank correspondence are compared independently of grading. Generated TeX spacing/order may normalize at other t, while all prose and ordered solution stages remain from the source. Source provenance uses source IDs only in metadata; new questions have no Math Academy content IDs.

Deduplication: normalize the supplied nonzero row to [1,b,c], and include the requested role (solve REF, reduce then solve, or reduce to REF). Exclude seed, choice order, UUID, source bank and dependent-row scale from fingerprints. Exclude all original and canonical tasks before adding inventory. The finite domain can exhaust; shortages remain explicit rather than padded with identical mathematical tasks.

Validation covers all 96 bounded cases across 12 profiles and all five options through course_academy_engine::learning::grade_field. review.json places original replay and scales -2 and 3 together for every profile. There are no variable target-position slots; slot-coverage.json documents this deliberate restriction. No plots or asset publication are required.
