Review topic

Consider the following sets:

N,Z,Q,R,C

To which of these sets does the number −18 belong?

Choose an answer
CorrectPreview only
Solution:

Answer · correct value:

Z,Q,R, and C only

Recall the following:

  • N represents the set of natural numbers.

  • Z represents the set of integers.

  • Q represents the set of rational numbers.

  • R represents the set of real numbers.

  • C represents the set of complex numbers

With that in mind, we note the following:

  • The number −18 is negative, so it does not belong to N, and we can write

−18∉N.

  • However, −18 is an integer, so it does belong to Z, and we can write

−18∈Z.

  • Every integer is a rational, real, and complex number. Consequently, −18 belongs to Q,R, and C, and we can write

−18∈Q,−18∈R,−18∈C.

Therefore, the correct answer is "Z,Q,R, and C only."
