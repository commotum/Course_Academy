To which of the following sets does the number 58 belong?

Select all that apply.

Answer: Integers (Z)
Answer: Real numbers (R)
Answer: Complex numbers (C)
Answer: Rational numbers (Q)
Answer: Natural numbers (N)
CorrectPreview only
Solution:

Answer: Integers (Z) · correct value:

false

Answer: Real numbers (R) · correct value:

true

Answer: Complex numbers (C) · correct value:

true

Answer: Rational numbers (Q) · correct value:

false

Answer: Natural numbers (N) · correct value:

false

Recall the following:

  • N represents the set of natural numbers.

  • Z represents the set of integers.

  • Q represents the set of rational numbers.

  • R represents the set of real numbers.

  • C represents the set of complex numbers.

With that in mind, we note the following:

  • The number 58 is not an integer, so it does not belong to Z nor to N. We can write

58∉N58∉Z

  • Also, 58 is irrational because 58 is positive and not a perfect square. It cannot be written as the ratio of two integers, so it does not belong to Q either:

58∉Q

  • Every irrational number is both a real number and a complex number. Consequently, 58 belongs to both R and C, and we can write

58∈R58∈C

Therefore, the correct answer is R,C only.
