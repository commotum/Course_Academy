# Template extraction

Read classification.md with source-cases.json and choice-recipes.json. The latter files retain every original source value, full ordered bank and exact option mapping.

The task supplies two linear equations in x and y with dependent coefficient rows, requests Gaussian elimination to row echelon form and the general solution, and accepts one of five complete values. Easy omits first-row normalization; moderate includes it. Dependent and inconsistent outcomes have separate solution sequences. The ordered steps and instructional wording are preserved from each source with explicitly parameterized mathematics.

The implemented bounded slot is nonzero integer RHS scale t in {-4,-3,-2,-1,1,2,3,4}; original replay is t=1. Coefficient rows, number/order of equations, basic x/free y roles, prompt instruction, field layout and profile bank remain fixed. Multiply both supplied RHSs and all corresponding augmented last-column values by t. Normalize the first pivot when required, then eliminate the second x. This is a conservative same-method generalization: rank consistency remains fixed, but intercepts and elimination arithmetic change. No new operations, targets or difficulty labels are introduced. Target roles are fixed because moving the basic variable changes the taught elimination/solution sequence; no changed-target slot is declared.

For scalar equations in the reduced system and solution, scale their constant terms; preserve y slopes. For vector banks, transport the first coordinate c+d*y to t*c+d*y. The second coordinate is fixed (normally y; one distractor has literal 6). For text choices, preserve No solution. Each bank remains complete and source-owned. All four nontext options are mapped independently, including swapped/altered constants and coefficients; transport is documented as an observed expression pattern without asserting an inferred learner mistake. No choice pool or mixed profiles. Replay at t=1 reproduces every original mathematical object and correct designation.

Ordered solution stages: build augmented matrix; normalize first row if needed; eliminate x in second row; write corresponding system; for inconsistency read 0=d with d nonzero and conclude no solution; for dependence remove 0=0, identify basic/free variables, solve x in terms of y, then render system and vector family. Every scalar RHS, contradiction and vector intercept derives from the same t. The generator corrects the two evidenced initial-matrix typos, with raw originals retained separately.

Distinctness uses both supplied equations normalized by their x coefficients, sorted independently of row order. It ignores UUID, seed, profile, worked-solution prose and choice order. Only altered mathematical tasks count; equivalent row scalings do not. Stable UUIDs include the task and full authored bank; replenishment deduplicates tasks across profiles and all old questions, even when old questions are no longer fresh.

All 128 profile/scale combinations are independently parsed and checked, including every rendered system, exact elementary row operation, reduced scalar equation, final family or contradiction and full choice bank. Native grade_field exercises correct and incorrect submissions for all options. Source replay, slot coverage and side-by-side original/-2/3 variants are retained separately in source-replay.json, slot-coverage.json and review.json. Hard remains unsupported and the finite domain can be exhausted; see capabilities.json.
