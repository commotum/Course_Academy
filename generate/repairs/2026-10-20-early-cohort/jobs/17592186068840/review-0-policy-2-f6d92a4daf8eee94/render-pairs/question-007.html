Find the general solution to dTdt=−0.03(T−35) for T≠35.

T=35+K⋅ , where K is an arbitrary nonzero constant. Write the factor as a single exponential with leading coefficient 1.

CorrectPreview only
Solution:

Answer 1 · correct value:

e−3t100

To find the general solution, we separate variables and integrate both sides with respect to t, as follows:

dTdt=−0.03(T−35)1T−35⋅dTdt=−0.03∫1T−35⋅dTdtdt=∫−0.03dt∫dTT−35=−0.03∫dtln|T−35|=−0.03t+C

This is a perfectly valid general solution. However, if we want to write T=T(t) explicitly, then we can solve for T. This gives

ln|T−35|=−0.03t+C|T−35|=e−0.03t+C|T−35|=Ke−0.03t

where K=eC is an arbitrary positive constant.

We can drop the absolute value bars by allowing K to be both positive and negative. Therefore, the most general solution is

T=35+Ke−0.03t.

Here K is arbitrary and nonzero.
