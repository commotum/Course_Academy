The row echelon form matrix M is given below. What are the pivot columns of M?

M=[258003000]

Select all that apply.

Answer: Column 1: [200]
Answer: Column 2: [500]
Answer: Column 3: [830]
CorrectPreview only
Solution:

Answer: Column 1: [200] · correct value:

true

Answer: Column 2: [500] · correct value:

false

Answer: Column 3: [830] · correct value:

true

Remember that the pivots of a matrix in row echelon form are the first non-zero entries in each row of the matrix.

We can see that M has 2 pivots in the 1st and 3rd columns:

M=[258003000]
