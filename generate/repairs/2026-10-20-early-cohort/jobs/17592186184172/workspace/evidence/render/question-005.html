Which of the following statements are true, given that A is a 3×3 matrix and Null(A)={[x14x1−5x1]|x1∈R}?

I. rank(A)=2

II. A is not invertible

III. det(A)≠0

Solution:

Answer · correct value:

I and II only

Since A is a 3×3 matrix, the invertible matrix theorem states the following:

A is invertible

⇔{Col(A)=R3dim(Col(A))=3=rank(A)Null(A)={0}dim(Null(A))=0=nullity(A)

Also, according to the rank-nullity theorem, if A is a matrix with n columns, then

rank(A)+nullity(A)=n.

The supplied null space has the independent spanning vectors

[14−5]

Thus nullity(A)=1.

By the rank-nullity theorem,

rank(A)+nullity(A)=n.

rank(A)+1=3,rank(A)=3−1=2.

Hence rank(A)=2 and nullity(A)=1. Since rank is less than the number of columns, A is not invertible and det(A)=0. Also, Col(A) has dimension 2. The number of pivot columns is 2, and the number of non-pivot columns is 1.

  • Statement I is true. rank(A)=2.

  • Statement II is true. The rank is less than the number of columns.

  • Statement III is false. A is not invertible, so det(A)=0.

Therefore, the correct answer is I and II only.
