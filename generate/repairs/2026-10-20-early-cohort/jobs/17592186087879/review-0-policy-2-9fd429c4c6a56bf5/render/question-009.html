Consider the following initial value problem.

dydx+(1x)y=sin⁡(x)x,x>0,y(π2)=−5

Answer 1 · correct value:

Answer 2 · correct value:

−cos⁡(x)−5π2x

This equation is in the standard form

dydx+P(x)y=Q(x),

with P(x)=1x and Q(x)=sin⁡(x)x.

We compute an integrating factor using the definition:

I(x)=e∫P(x)dx=e∫1xdx=eln⁡(x)=x

Multiplying both sides of the equation in standard form by I(x)=x yields

x⋅(dydx+1xy)=x⋅sin⁡(x)xxdydx+1y=sin⁡(x)ddx(yx)=sin⁡(x).

Now, we integrate with respect to x:

∫ddx(yx)dx=∫sin⁡(x)dxyx=−cos⁡(x)+Cy=C−cos⁡(x)x

This is the general solution. To find the value of C corresponding to the specific solution, we apply the initial condition y(π2)=−5 as follows:

y(π2)=(−cos⁡((π2)))+C((π2))−5=0+Cπ2C=−5π2

Therefore, the solution to the initial value problem is

y=−cos⁡(x)−5π2x.
