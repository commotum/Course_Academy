Consider the matrix

D=[3003800−10].

Which of the following statements are true?

Select all that apply.

Answer: D is upper triangular.
Answer: D is lower triangular.
Answer: DT is upper triangular.
Answer: None of the above
CorrectPreview only
Solution:

Answer: D is upper triangular. · correct value:

false

Answer: D is lower triangular. · correct value:

true

Answer: DT is upper triangular. · correct value:

true

Answer: None of the above · correct value:

false

  • D is upper triangular: false. The entry in row 2, column 1 is 3≠0, below the main diagonal.

D=[3003800−10]

  • D is lower triangular: true. All entries above the main diagonal are zero.

D=[3003800−10]

  • DT is upper triangular: true. All entries below the main diagonal are zero.
