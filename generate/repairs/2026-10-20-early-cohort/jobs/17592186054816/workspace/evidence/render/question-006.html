To which of the following sets does the number 121 belong?

Select all that apply.

Answer: Q−
Answer: N (natural numbers)
Answer: None of the above
Answer: Z (integers)
Answer: Z−
CorrectPreview only
Solution:

Answer: Q− · correct value:

false

Answer: N (natural numbers) · correct value:

true

Answer: None of the above · correct value:

false

Answer: Z (integers) · correct value:

true

Answer: Z− · correct value:

false

First, we note that 121=11 is a natural number, so it belongs to N.

Since every natural number is also an integer number, 121 also belongs to Z.

On the other hand, the sets Z− and Q− only contain negative numbers. Therefore, 121 does not belong to either of these sets.

Therefore, the correct answer is “N (natural numbers)”; “Z (integers)” only.
