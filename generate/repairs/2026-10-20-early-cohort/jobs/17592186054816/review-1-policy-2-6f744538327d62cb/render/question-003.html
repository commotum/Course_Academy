To which of the following sets does the number −π belong?

Select all that apply. If none of the sets apply, select "None of the above".

Answer: R
Answer: Z−
Answer: R−
Answer: C
Answer: None of the above

The number −π is a negative irrational number. It is not a rational number.

  • The set R contains all real numbers. Therefore, −π belongs to R.

  • The set Z− contains the negative integers. Therefore, −π does not belong to Z−.

  • The set R− contains the negative real numbers. Therefore, −π belongs to R−.

  • The set C contains all complex numbers. Therefore, −π belongs to C.

Therefore, select R, R−, C only.
