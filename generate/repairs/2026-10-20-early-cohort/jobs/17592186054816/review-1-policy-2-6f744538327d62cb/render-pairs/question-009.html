Review topic

To which of the following sets does the number 0.25 belong?

I. Z

II. Q+

III. Q−

IV. R

Choose an answer
CorrectPreview only
Solution:

Answer · correct value:

II and IV only

The terminating decimal 0.25=14 is a positive rational number that is not an integer.

  • The set Z contains all integers. Therefore, 0.25 does not belong to Z.

  • The set Q+ contains the positive rational numbers. Therefore, 0.25 belongs to Q+.

  • The set Q− contains the negative rational numbers. Therefore, 0.25 does not belong to Q−.

  • The set R contains all real numbers. Therefore, 0.25 belongs to R.

Therefore, select "II and IV only".
