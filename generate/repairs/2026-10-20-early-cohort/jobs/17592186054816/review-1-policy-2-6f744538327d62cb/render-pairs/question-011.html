Review topic

To which of the following sets do all the natural numbers belong?

I. Z+

II. Z−

III. Q+

IV. Q−

Choose an answer
CorrectPreview only
Solution:

Answer · correct value:

I and III only

We must check whether each set contains all the natural numbers.

  • The set Z+ contains the positive integers. By the number-set hierarchy and the sign restrictions, every member of the given class belongs to Z+.

  • The set Z− contains the negative integers. For instance, 1 is in the given class but not in Z−. Therefore, this set does not contain all the natural numbers.

  • The set Q+ contains the positive rational numbers. By the number-set hierarchy and the sign restrictions, every member of the given class belongs to Q+.

  • The set Q− contains the negative rational numbers. For instance, 1 is in the given class but not in Q−. Therefore, this set does not contain all the natural numbers.

Therefore, select "I and III only".
