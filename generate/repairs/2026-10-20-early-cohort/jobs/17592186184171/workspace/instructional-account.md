# Instructional account and repair design

The learner applies rank(A)+nullity(A)=n, where n is the number of columns. Canonical example 10cc01a6-af19-5340-9743-ade4d5e252dc identifies rank from three column-basis vectors, then subtracts 3 from 5. Tutorial 0728c510-110b-5bde-93ea-9050a87a6ecc states the same theorem and identifies n as the number of vector components for a described null space. Prerequisites concern bases of column and null spaces; row reduction is not added to these questions.

Easy stages: inspect m by n, count the k listed column-basis vectors, infer rank=k, calculate n-k, select the integer. Moderate stages: count n components, expand the homogeneous vector in its two or three real parameters, identify the number of independent coefficient vectors, calculate rank=n-k, select the integer. Both retain one five-choice radio field and a concrete worked solution stating the theorem, identifying dimensions, substituting and subtracting. Full column rank is required so parameter counting is justified. No diagrams occur in the assessed source; prerequisite images describe other exercises and are not output assets.

Observed easy cases use m=3..6, n=5..10, k=2..5 (seven questions). Observed moderate cases use n=4 or 5, k=2 or 3, indices [1,2], [2,3], or [1,2,3] (eight questions). In particular 5e7c8be1-d271-506d-bfc9-fbf1881a88d8, 7663d433-7983-5195-82f9-f8b3b6b0d6aa and 1b45e803-c138-5bcf-9207-424394814f56 require five components. The older bundled basis-2516 snapshot contained only eleven cases; it is retained as historical evidence, but the supplied basis-5443 source with fifteen cases governs this repair. No mathematical source errors were found. Set delimiter sizing and algebraic term ordering may be normalized without changing values or solution stages.

Answer-bearing assignments are the integer n-k and the numeric option that represents it. Easy n and k vary; m is contextual and may vary independently when feasible. Moderate n, k, coefficient supports and coefficients vary; relabeling independent parameters is irrelevant to rank. The requested invariant stays nullity for column-basis prompts and rank for null-space prompts because reversing supplied/requested roles changes the exercise. Positive k and n-k retain the source nontrivial spaces. Moderate n stays in {4,5} and k in {2,3}, preserving the demonstrated expansion workload. Dependent parameters are excluded because deciding dependence would add a new learner task. Coefficients remain integers -3..3, the established conservative extension. Easy limits m=2..7,n=4..12 retain short basis lists and one subtraction; feasible k is 1..min(m,n-1). Hard has no source workload and is unsupported; easy and moderate are supported.

The former answer-relative offsets forced a fixed numeric answer position. In normal generation the easy bank is now a translated observed *shape*, independent of a designated correct position: consecutive offsets [0,1,2,3,4], gapped offsets [0,2,3,4,5], or dimension-bank offsets [0,1,2,3,5] at scale 1 or 2 (scale 2 reproduces the observed [0,2,4,6,10]). The primitive integer scale retains this bank shape when the feasible nullity interval is too short to contain two even-spaced candidates. These are explicitly authored extensions of complete observed banks, not inferred learner mistakes. Choose m,n and a bank shape/translation with at least two feasible nullities, then assign the qualifying value among those candidates and derive k=n-value. Thus the same complete bank and same matrix dimensions can require different choices as the basis cardinality changes. No new feedback or error interpretations are invented. For explicit parameters choose a compatible translation with the same two-answer support; all mathematical parameter instances remain representable. Source-ID replay uses the exact original complete bank. It does not define a separate learner-visible layout and every source bank shape is also exercised in normal sampling with varying correct positions.

Moderate retains the two observed complete banks 0..4 and 1..5. Both contain all supported ranks 1,2,3 and neither fixes the answer. Sample n and k before coefficients; both two-parameter index sets are eligible at both component counts. Fixed five-option count preserves the source response contract. Sorted numeric choices preserve the existing UI contract; numeric order must not identify correctness. Choosing a basis count or counting independent coefficient vectors is the intended reasoning, not a shortcut.
