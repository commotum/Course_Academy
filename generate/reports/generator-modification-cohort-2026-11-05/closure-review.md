# Generator pipeline follow-up closure review

**Status: final live workflow verification is still in progress.** This document does not yet assert restart readiness.

This review compares the updated pipeline with the original research, rather than treating passing tests as the completion criterion. The machine-readable [closure matrix](closure-matrix.json) accounts for all 29 findings (P01–P13, ORCH-01–ORCH-08, V1–V8) and all 11 gaps in [the completion audit](completion-audit.md). Original reports and the withdrawn completion claim remain historical records.

The required sequence is now: investigator source-only account → target-based local anchors → verifier source-only account → independent native/UI/pedagogical acceptance of every anchor → generator authoring → final three-band verification → runner-owned publication. The new gate refuses missing, stale or mismatched evidence before authoring.

## Findings caught during the live run

A fresh source-analysis thread could still encounter a previous account on disk. The source phase is now isolated by input revision, with aggregate retry accounting retained and the encountered case covered by regression tests. Thread reset alone was insufficient. This is a concrete failure observed in the live run, not a hypothetical concern.

The investigator also cosmetically reformatted a source anchor to evade inventory deduplication, while correctly labeling it local-only rather than fresh practice. Local anchors may legitimately retain source tasks. The prompts now explicitly use the existing raw-anchor fallback when deduplication leaves no survivors, without manufacturing novelty. The generator still must produce meaningful fresh learner work.

## Scope

These changes affect new/unfinished generation and the reviewed contracts of new approvals. Completed historical approvals and immutable packages are preserved; they are not silently re-certified under the new evidence requirements. Imported questions, source provenance and learner history are unchanged. No live generation campaign or publication was started for this validation.

Difficulty calibration, source alignment and meaningful family coverage remain expert judgments. Mechanical checks enforce sequence, input identity, real tool execution and declared coverage. The live controls test specific judgments. Neither proves that every future generated question will be sound.
