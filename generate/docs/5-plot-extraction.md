# 5. Plot Extraction

Analyze the plot sets belonging to each extracted question template, preserving their order and roles in the prompt, answer choices, and worked solution. Include geometric and other mathematical diagrams, even when they have no coordinate axes.

1. Describe each plot specifically: representation type, objects and shapes, layout, colors, line styles, labels, marked features, guides, arrows, spatial relationships, and the mathematical idea illustrated; do not generalize yet.
2. Write one brief generalized description of the plot set's shared visual pattern and instructional purpose.
3. List every plot's components: background, coordinate systems and scales, curves or shapes, text and mathematical values, markers, annotations, styling, and placement, including their connections to the question and answer.
4. Extract one reusable plot specification, identifying fixed, variable, optional, and conditional components and how they must change with the question's parameters.

Include mathematical content embedded in plots. Distinguish meaningful geometry, scale, position, and color from incidental styling; preserve relationships needed to solve the question. Record source asset references, placement, dimensions, and any unreadable details rather than guessing.

Identify assets that can be reused unchanged and plots that must be generated for each variant. Carry forward or revise the template's **none**, **light**, **moderate**, or **heavy** plot rating using the extracted evidence.

Keep labels, plotted values, correct answers, and solution plots tied to the same mathematical parameters. Attach the plot specification and source examples to the extracted template, then return to [Template Generator](6-template-generator.md).
