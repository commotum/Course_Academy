The public API provides `generate`, `generate_easy`, `generate_moderate`, and `generate_hard`. Normal output uses finite authored visual catalogs, complete observed statement-subset banks, explicit I–IV labels and a single correct radio designation. It assesses local source/sink behavior and everywhere-zero solenoidal status. It never asks for divergence computation, units conversion, circulation, flux integrals or a new prerequisite.

The captured basis-1356 sources, including every field, answer and full solution, are in `source.json`. Explicit `raw-q-*` profiles reproduce original records through parameterized prompt/solution/graph/subset recipes. They are `evidence_only: true` and `eligible: false`, preserving duplicate fields without correct refs and unnumbered statement bullets. Original difficulty and missing attribute presence are preserved; no missing designation is fabricated. `source-cases.json` documents the public calls. A coordinate exchange is a genuinely changed graph/prose component; field aliases and magnitude changes do not inflate task counts.

All observed levels exist. Normal questions extend their visual contexts rather than replacing fidelity evidence. Catalog sizes are easy 10, moderate 16, hard 24 distinct reduced visual objects; each level contains the three semantic divergence sign classes. Field letters, positive magnitude, option order and bank aliases are excluded from mathematical fingerprints. See the classification and extraction for workload claims and limitations of unlabelled source raster scales.

It then parses the actual I–IV statements and complete response subset, checks all five choices and the worked solution, and invokes the real native `learning::grade_field` for correct and incorrect owned UUID submissions. Source fidelity, raw missing-ref limitations and supported-field fixture repairs have separate counts. Fresh concurrent rendering uses unique temporary inputs and atomic writes.
