# Template extraction

## 1. Specific source descriptions

`template-components.json` is the lossless component ledger: original prompt, complete owned field/bank, original key presence and solution text for every MA question. It also lists each original parameter set and independent mathematical interpretation. q13461 uses x*sin(x²); q13464 x*csc²(x²); q13474 4x²*sec²(x³). q3038 uses sec²(1/x)/x², a negative reciprocal differential. q13533 and q13537 use A*x*cos(2x²) and A*x*sin(2x²), with transformed limits [0,pi] and [0,2pi], both giving zero. q350202 is 8x*sec(4x²)*tan(4x²) on [0,sqrt(pi/12)], giving 1; q350203 is 12x*cos(6x²) on [sqrt(pi/12),sqrt(pi/6)], giving -1. Original five-answer banks contain 30 radio values; two blanks add two values. Seven supplied solutions and seven supplied keys are present; one original is unrated and lacks both key and solution.

## 2. Generalized pattern and instructional purpose

Recognize a nonlinear inner argument u=k*x^n or u=k/x, differentiate it, extract a constant ratio between its derivative and the supplied outside factor, integrate a basic trig function, then back-substitute or evaluate transformed bounds. Required output is an entire primitive with +C or an exact definite scalar. Fixed function/power roles and source family stages stay fixed. A normal missing-level easy task uses the exact derivative of k*x²; moderate requires a nonunit ratio; hard adds a reciprocal negative differential or definite-limit transformation.

## 3. Complete component and bank mapping

Each source radio bank is a separate `observed_raw` profile identified by its template. Every source option is parsed independently; the reusable evidence recipe substitutes the new inner argument and multiplies the complete nonconstant expression by the ratio r/r_original. This is amplitude/argument transport of a historical pattern, not a recovered misconception model. All scalar options, including nonzero constants next to a zero correct answer, are transported. The original correct ref is preserved where present; q13461's missing ref remains absent. Raw/evidence profiles explicitly carry evidence_only=true and eligible_for_learning=false. All original bank values are byte-exact at original parameters. Arbitrary C is preserved independently of the scale.

Normal `authored_method` selects its complete family/bank first. Indefinite bank: r*H(u), -r*H(u), A*H(u), r*H(u)/(abs(n)*k), r*J(u), where H is the correct primitive and J is the named alternative function (sin→sin; cos→cos; sec²→sec; csc²→-csc; sec*tan→tan). These correspond to missed sign, omitted derivative adjustment, applied adjustment twice, and wrong primitive function. A whole instance is rejected if any pair describes the same primitive family. No first-valid replacement is used.

Definite radios use [r*(H(b)-H(a)), reversed endpoints, A*(H(b)-H(a)), r*(H(b)-H(a))/(n*k), r*(h(b)-h(a))]. The last differentiates the primitive instead of using it. The two opaque zero-answer source banks cannot use this bank without equivalent zeros, so their normal endpoints are conservatively authored as [pi/6,pi/2] (cosine) and [0,pi] (sine); raw original endpoints/banks remain public evidence. Blank families preserve their entire scalar-answer contract and no distractors.

## 4. Reusable masks, slots, constraints and stages

Normal A and k are independent positive integer slots: A=1..12 and k=1..6 for source families. Raw evidence transport exposes only A=1..12 with the original k fixed; every public raw parameter tuple is also exhaustively checked. Source powers/families stay fixed. Moderate excludes A=n*k; explicit calls enforce the same bounds. Easy has k=1..12, A=2k, and sin/cos selection, exactly one derivative-factor recognition and no scale correction. Its complete method bank is the same evaluated family bank. Definite x endpoints are sqrt(u_endpoint/k), with original or documented authored transformed endpoints, preserving familiar exact angles and finite integrals. Reciprocal questions exclude x=0 and all trig poles on their connected domain. All definite transformed intervals avoid poles.

The backbone preserves actual source prose and rows: initial u definition; derivative/differential relation; limit table where present; split integrand into trig factor and outside differential factor; substitute the differential; extract coefficient; basic primitive; back substitution. Source blanks omit a redundant extraction row and retain that omission. Definite questions retain unevaluated endpoint trig components, individually evaluated endpoint components, and the source's final difference/product simplification rows. q13533 alone collapses its evaluated endpoint difference into one delta row as originally observed; q13537 keeps two arithmetic rows. q3038's redundant nested aligned wrapper is preserved raw and harmlessly supported in normal output.

Complete math cells are variable slots; fixed source sentences and row separators form the immutable mask. A component formatter retains its source lexeme when that component is unchanged, while every component follows the same mathematical recipe at original and changed inputs. There is no whole-question source-return branch or answer lookup table. The validator compares whole original text and independently evaluates every actual displayed mathematical cell, derivative relation and endpoint table. A mutation that replaces a substituted differential row by an equivalent extracted integral must fail its structural check.

Content identity hashes actual level, prompt, solution and complete unordered displayed bank; seed/order changes cannot affect identity. Mathematical fingerprints omit the bank/profile and retain integrand, bounds and answer contract. Equivalent primitives are compared modulo arbitrary constants; finite batch deduplication uses mathematical fingerprints. Evidence-only raw bank profiles never serve default learning questions.

Source-format anomalies are presentation-only normal repairs: q13461's missing integral separator and absent teaching content/key; literal backslash-u2061 sequences in several original bank strings become the actual invisible function-application separator before normal formatting. Decoded bytes were checked: these strings have a single backslash followed by literal u2061, not doubled TeX commands. Source strings and wrapper remain untouched. Native original 'Do not round the answer.' wording is retained only in faithful evidence; normal exact-answer wording is 'Give an exact answer.'
