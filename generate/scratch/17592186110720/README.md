# Solving For an Unknown Parameter

All three levels generate local JSON or Markdown. Run:

```
.venv/bin/python generate/scratch/17592186110720.py --difficulty all --count 2 --seed 42 --format markdown
.venv/bin/python generate/scratch/17592186110720/validate.py
```

API: generate(level, seed=0, template=None, field_type=None, parameters=None,
profile=None), plus generate_easy/generate_moderate/generate_hard. Templates are
scale_radio, shift_radio, affine_blank, fraction_affine_blank. Exact parameter
objects contain a,b,c and optional var. Public source replay cases and full
profiles are in source-cases.json; no literal source-return branch exists.
Normal easy banks are authored mathematical-error operations. Hard is an authored
extension anchored to the captured linked lesson route, prerequisite topic343,
and canonical affine coefficient. It retains one unknown in ax=bx and excludes
the following two-parameter KP. All profiles reject complete ambiguous banks.

Validation compares five exact prompts and complete fixed solutions, 21 choices,
16 wrong choices and all five correct designations. It reads printed mathematics
independently, checks explicit reduced workload guards and identities, enumerates
meaningful finite variants, and calls the shared real native grader through
memory-only fixtures. validation.json reports current results and hashes;
review.md/review.json show originals/replays and changed-parameter variants.

No plots or source repairs are required. Source scalar distractor intentions
remain underdetermined in explicit observed profiles. Hard labels are authored;
normal samplers and explicit calls share the documented bounds.

The existing reference directory contains historical evidence from a previous
run; it is not current-basis validation or part of the current generator workflow.
