# Plot extraction and specification

1. **Specific originals.** All 15 actual transparent rasters were inspected at their original 360×304-ish resolution, composited on white solely for inspection. They show a blue axis-aligned ellipse, black Cartesian axes with signed numerical ticks, and grey horizontal/vertical center guides. Five rated moderate plots and the unrated q-78679 omit direction and A. Nine hard plots mark the rightmost endpoint with a black dot and A(h+a,k), and place a blue arrow on the upper-right arc pointing upward-left: counterclockwise. Full original paths/hashes, every fitted origin, signed axis scale, blue extent, and bounded pixel error are in raster-geometry.json. The plots' independent axis transforms were read from axes/ticks, not fitted from expected ellipse aspect ratio.

2. **Shared pattern.** The graph conveys center and positive horizontal/vertical semiaxes. Hard adds the starting point and direction. These are the complete geometric features assessed by this KP; no arbitrary ellipse rotation or partial arc occurs.

3. **Components.** Curve (h+a cosθ,k+b sinθ), center guides across both complete diameters, equal Cartesian scales, black axes through (0,0), legible signed ticks, x/y labels; optional rightmost A dot/coordinate label and CCW arrow from θ=.65 to .80. Each changed question's plotted data is its own exact parameter dictionary. Source options are expressions, not images.

4. **Reusable specification.** render.py uses Matplotlib Agg and an equal aspect ratio. Bounds contain zero and all four extrema with margin .35 max(a,b)+1. Tick increment is 1 for short spans and 2 otherwise. Blue stroke, grey dashed guides and black axes are retained. A is placed outside the rightmost point; its actual rendered bbox is measured against the point and every signed tick-label bbox, with ≥11 pixel horizontal point clearance and ≥4 pixel tick clearance. Alternate offsets are tried without masking/covering the axes. PNG and JSON sidecar are mandatory cache entries, the key includes renderer source hash, and sidecar includes actual Python/Matplotlib versions, bounds, parameter values, equal scale, label clearances and image hash. Unique per-call input files and atomic writes support concurrent identical/different instances. Source assets are reused only at matching full original geometry, after independent raster extraction, not as proof of geometry by themselves.

All changed source masks/banks share the graph specification and are independently checked for their own printed mathematical content. See review.json and review.md for originals and a changed-parameter example for every source profile, plus two normal samples per level. Read-only cached Python 3.10 dependencies are used when primary Python 3.13 lacks Matplotlib; no installation or shared environment edit occurs.
