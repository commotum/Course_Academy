# Gradient vector fields generator

Run from the repository root:

```
.venv/bin/python generate/scratch/17592186179714/validate.py
.venv/bin/python generate/scratch/17592186179714.py --difficulty all --count 3 --seed 17
.venv/bin/python generate/scratch/17592186179714/replenish.py
```

Supports easy and moderate through eight complete source-backed banks.
Hard remains unsupported; see `capabilities.json`. Classification, extraction,
source replay, independent displayed mathematics and real application grading
are retained in this package. Replenishment acquires the application api.lock,
rechecks current inventory, uses additive ensured EDB forms, saves exact requests
before commit, verifies at db_after and preserves the original source bank.
