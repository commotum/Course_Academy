```sh

.venv/bin/python generate/scratch/17592186087688.py --difficulty all --count 2 --seed 19 --format markdown

```

Interface: `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` and individually documented `generate_easy`, `generate_moderate`, `generate_hard`. Parameter keys: `slope` exact rational spelling, `known_intercept`, `unknown_y_coefficient`, `unknown_constant`, `known_scale` (integers). Explicit parameters must meet the same documented level guards as sampling. `batch` enumerates meaningful tasks without counting intercept or scale aliases.

All captured practices are unrated and lack bank, correct reference and worked solution. Public `raw-q-214098` / `raw-q-214099` reconstruct source prompts with attribute-presence parity, normalized enum strings and content-derived UUIDs. They are evidence-only and ineligible for learning. The supported `completed-*` profiles add independently inferred answer fragments and authored solutions/levels. Default `authored-blank` retains the observed blank shape and two information masks. No observed choice bank exists; absent banks cannot be counted as recovered opaque distractor recipes. Source bank/solution/designation fidelity denominators are zero and reported as such.

Easy: one standard equation isolation with integer known slope. Moderate: two conversions, integer known slope. Hard: two primitive standard equations with reduced noninteger known slope and noncancelling rational answer. Scope rationale is in `classification.md`, all four extraction stages in `template-extraction.md`. `source-cases.json` calls the public raw API; `source-replays.json` retains those results. `review.md` / `review.json` show every observed family/profile plus three defaults at each level. `validation.json` is current QA evidence; `engine-input.json` / `engine-report.json` are native real-application grading evidence. Raw incomplete records cannot be graded; completed source records are checked separately.
