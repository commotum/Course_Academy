# Four-stage extraction

## 1. Specific source description

Each source is described in classification.md and recipes.json: complete prompt mask, original three-component parameters, vector names from the fixed formal rows, exact choice strings, original field type, key, level presence, and ordered numeric-stage recipes. source.json retains original database identities and all raw attributes. Easy sources include zeros, negative coordinates, sqrt(8) written unreduced, paired roots, perfect-square norms and nonsquare norms. Moderate sources combine the two differently normalized projections by addition or subtraction. All observed dot products are integer except easy q-18374 and q-126502; all calculations are exact.

## 2. Shared mathematical pattern

From displayed a,b, compute D=sum(a_i b_i), A²=sum(a_i²), B²=sum(b_i²), P=D/sqrt(B²), Q=D/sqrt(A²). Requested result is P, P+Q or P-Q. Preserve the first formal formula and component expansion; substitute three products and three squared coordinates; retain separately evaluated products where observed; reduce the norm and combine the two scalars in the original stage sequence. The second projection reuses D rather than recomputing three products, exactly as observed.

## 4. Reusable masks and domain

`recipes.json` separates fixed prose/formal math and variable whole-vector/whole-row slots. `source_build` evaluates component, product, norm, dot, reduced-projection, factored-combination, common-denominator and collected-result renderers. Source sqrt(8) is retained through a root-component formatting rule; signs remain grouped and evaluated terms retain their order. Parameterized source profiles have exact nonzero real components with integer squares, abs coordinates<=30; operations/field shapes are fixed, ratio banks require R!=0, and an observed lcm stage additionally requires integer norms.

Normal bounds: easy abs coordinates<=8, integer component squares and norm squares<=144; single uses integer coordinates while single_radical requires an irrational component. Moderate abs coordinates<=12, integer norms <=15, integer dot product, unequal norms, and familiar integer/root coordinates. Hard abs coordinates<=4, integer component squares, no zero component, squared norms<=40, irrational dot product and two nonsquare norms with irrational ratio. Explicit parameters obey these identical guards. Whole-bank collisions reject the instance even when a blank field is selected, so response layout does not quietly change the mathematical sampler.

The mathematical fingerprint removes positive common scaling of either vector, names, profiles and option order; it retains directions/signs and requested operation. Full display identity hashes actual prompt, solution, difficulty, and complete bank. The finite samplers provide much larger valid families than the 60 validation draws. domain-audit.json enumerates conservative exact slices with 196 easy, 11,520 moderate and 110 hard meaningful tasks; it does not pretend these lower bounds exhaust the wider domains.
