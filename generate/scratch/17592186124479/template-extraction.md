# Template extraction and sampling contract

General pattern: determine the number of pivot columns of the supplied rectangular matrix; perform the source's ordered row additions to obtain echelon form, count its pivots, and select that count from its original complete five-value bank.

The JSON companion gives each source's exact matrix, all intermediate states, complete field bank, numeric recipes, row operations, source IDs and parameter values. Source records preserve the original prose and field identities. There are 16 source-specific templates and four count-bank profiles. Every original option is a fixed integer count recipe (including the correct one); no misconception interpretation is inferred. Each source keeps its entire bank. The incomplete unrated q-35459 is explicitly excluded.

Backbone: source matrix dimensions and letter; structural zero pattern at every stage; target/source rows and order of operations; one or two elimination stages; final echelon rank; request to count all pivot columns; five integer radio choices in the source bank; one concrete worked solution. The supplied matrix is not augmented, and no system solution or identification of particular columns is requested. These constraints preserve the observed method and workload. Zero entries establish which leading entries require elimination and which columns can contain pivots, so they are method constraints rather than visual coincidences.

Variable slots: each nonzero entry of the final echelon form, and each row-addition coefficient. Normal sampling mixes independent nonzero integer echelon entries from -9 through 9 with integer row-addition coefficients from -3 through 3, and constrained source-scaled proposals. For the latter choose independent nonzero row and column scales from {-2,-1,1,2}; multiply final entry (i,j) by row_scale[i]*column_scale[j] and each operation coefficient c by row_scale[target]/row_scale[source]. These algebraically dependent proposals preserve cancellation identities while exercising multiplier variation. All resulting entries must stay within the shared integer bound of 40 and every coefficient must satisfy the shared rational bound. The original final entries remain replayable; no sampling policy changes the method or invents operations. Source replay additionally permits all original integer entries and original rational coefficients. Explicit parameters accept integer entries of absolute value at most 40 and nonzero signed ratios n/d with |n|<=5, 1<=d<=5. These are conservative same-method bounds, not claims that all such combinations are admissible. Reject instances unless every reconstructed state preserves the source zero pattern, contains only integers of absolute value <=40, and the original operation sequence yields echelon form. Reject bank collisions or a correct count absent from the bank. Fail after a bounded 3000 proposals; never substitute duplicate fallback questions.

Calculate the supplied matrix by reversing the sampled row operations from the sampled echelon matrix. Compute the answer independently from the resulting supplied matrix; use the same concrete states for the rendered solution. Validators independently read the rendered prompt and solution and compute rank with Fraction Gaussian elimination. Each final nonzero slot and coefficient must exhibit variation across the validation sample; structural zeros and fixed row roles must remain fixed. There is no variable target position: the requested object is the count of all pivot columns. A held-data changed-entry case verifies propagation through the prompt, all stages and answer key without inventing a new target.

Seed is reproducibility metadata, never identity. Question identities use a fingerprint of the actual matrix task (primitive rows suppress mere row rescaling) and its complete numeric bank. Inventory deduplication uses the matrix fingerprint across banks, excludes all current questions and canonical examples, and ignores seed, label and choice order. Fields own answer UUIDs. No Math Academy content ID is assigned to generated records.

Rendering preserves the prompt layout and the concrete source sequence: introduce echelon conversion, show the matrix with each exact row addition, then count pivots. Negative/fractional multiples are written uniformly as addition of a signed multiple. Source replay compares every matrix, intermediate state, coefficient, complete bank and correct designation. Original prose is presented alongside variants in reference/side-by-side.md; fidelity is recorded separately from independent correctness and native grading. Source label errors are corrected only in generated rendering.
