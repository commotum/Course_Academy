# Matrix assets

No practice template needs a plot. Matrices are ordinary mathematical notation, rendered directly from the sampled matrix using LaTeX. The canonical example's original SVGs are MathJax matrix renderings with semantic MathML, not mathematical graphs. The first is the 4×4 matrix `[[-1,1,0,1],[0,0,7,8],[0,-4,2,4],[0,0,8,4]]`. The requested first, third and fourth rows have leading entries -1, -4 and 8; their sum is 3. The second repeats the matrix and marks those leading entries for explanation. Their order and references remain unchanged in EDB. `canonical-assets.json` records both original hashes and the decoded matrix for deduplication.

Plot rating: none. No new raster or vector assets are created or published. Source artwork is not modified.
