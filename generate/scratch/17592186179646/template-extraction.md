# Template extraction and sampling contract

The source-specific record is source.json; the component/option ledger is source-replay.json. Exact source parameters are extracted from the rendered field and side length. Observed easy (coefficient, axis, length) tuples are (2,j,4), (3,i,2), (-2,i,6), (-3,j,4). Moderate tuples are (1,4), (-1,4), (2,8), (4,6), (-4,2), (-1/2,8). The incomplete radial source has (-2,6). Positive integer, negative integer and decimal coefficients are retained. All squares are centered at O with edges parallel to axes.

Uniform backbone: supply F=c i or F=c j and side length L; request the total outward flux. Define the closed-curve integral, decompose into four sides, identify the two parallel sides with zero contribution, reduce to the other pair, cancel their equal and opposite flow, conclude zero. Direction is an eligible role slot: horizontal changes the zero pair to C2/C4; vertical changes it to C1/C3. The signed coefficient changes inflow/outflow grammar. The same selected instance supplies every field reference and diagram. The source's literal step wording is retained by parameterizing its signed/directional branches.

Radial backbone: supply F=c x i+c y j; request total outward flux with the existing symmetry hint. Define flux, decompose into four sides, identify right side C1 with normal i, take the dot product c x, parameterize r(t)=(L/2)i+t j over [-L/2,L/2], evaluate c(L/2)L, multiply that result by four. C1 stays fixed because it establishes the x component of the chosen parameterization; changing that target is outside this template. Normal orientation and axis-aligned topology stay fixed because the symmetry argument requires them. The source's operative wording and ordered equations are parameterized in MODERATE. Coefficient signs, half-lengths, factors, bounds and final values share one instance.

All fields preserve key selection and radio type, five delimiter-free math answers, and a field-owned canonical choice. No new operations, field layouts, targets or feedback are added. The exact answer is computed first with SymPy: zero or 2*c*L**2. A separate validator integrates each outward-normal side without using the generator formula.

Easy profiles q-126881, q-127194 and q-127193 use {0, -L, L, -abs(c)*L, abs(c)*L}; q-127190 uses {0,-L,L,-2L,2L}. These reproduce all original values. The latter profile's mistake interpretation is unresolved; its literal doubled-length pattern is retained. A complete bank is chosen before evaluating recipes. |c|>=2 prevents duplicates.

Every radial profile preserves the **entire observed ratio vector**, multiplying each original value v by (2*c*L**2)/(2*c0*L0**2). This is an explicitly documented conservative homogeneous value-pattern extension, not a claim to know the original distractor author's intent. The ledger gives every rational multiplier separately. There are no unmapped values or unresolved mathematical comparisons; all eleven banks replay completely. Source ratios are not mixed, no choice is silently dropped, and there is no learner-facing error interpretation.

Proposed finite sampling bounds extend, rather than redefine, the observations: L in {2,4,6,8,10,12}; c in {-4,-3,-2,-1,-1/2,1/2,1,2,3,4}, excluding |c|<2 for easy banks. The square's role is fixed. Whole-domain validation covers every allowed coefficient, length, direction and bank profile. Signed values and fractional coefficients keep the source method; fractions introduced into distractors are exact LaTeX fractions. Supported bands remain easy and moderate.

Distinctness ignores seed, UUID, order and bank. Uniform direction/sign aliases share a fingerprint (|c|,L); radial fingerprints use (c,L). Thus the bounded package has 18 uniform and 60 radial parameter tasks before source/history exclusions. These are package limits, not claims about the mathematical universe. New banks cannot collide under one question UUID: identities include the complete normalized bank, but inventory deduplication ignores bank differences. Replenishment excludes all existing tasks, including canonical and incomplete sources, before adding content.

Source replay is separate from correctness and grading. The validator matches all 55 source answer values, 40 known distractors, ten present keys, eleven prompts and ten present solutions exactly. The incomplete source's inferred key/solution are identified rather than counted as observed fidelity. Review originals beside changed signed coefficients and lengths in review.md; the fixed-value changed-axis case checks stale side references separately. Dependencies and generator hash are frozen in validation.json.
