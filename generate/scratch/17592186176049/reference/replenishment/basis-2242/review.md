Which of the following statements are true regarding the function $y=\tan x?$ Assume that $n$ is an integer.

Select all that apply.

- **I.** The zeros of the function are exactly $x=2n\pi.$
- **II.** The vertical asymptotes are exactly $x=\frac{\pi}{2}+2n\pi.$
- **III.** The range of the function is $(-\infty,\infty).$

Let's plot the graph of $y=\tan x.$

![](images/e6/e65a2728d8bdad40af736ced1ec8303bf10fb4d11fc66b33784663512093a26b.png)

Let's go through each statement.

- Statement I is false. The zeros occur at $x=0,\pm\pi,\pm2\pi,\ldots,$ which can be written as $x=n\pi.$

- Statement II is false. The function has an asymptote at $x=\frac{\pi}{2}$ and the period is $\pi.$ Therefore, the asymptotes occur at $x=\frac{\pi}{2}+n\pi.$

- Statement III is true. The function takes values on all the real numbers, hence the range is $(-\infty,\infty).$

So, the correct answer is "III only".
