# Fractional affine integration generator

Run `.venv/bin/python generate/scratch/17592186064205.py --difficulty moderate --count 5 --seed 1930`. Supported bands are moderate and hard. Easy has a bounded exception in capabilities.json. `validate.py` checks source replay, rendered mathematics, solution stages, deterministic boundaries and actual learner grading; `replenish.py` uses the application integration, acquires api.lock, rechecks current inventory/basis, previews native specs, saves exact guarded requests, and verifies additive content at the committed basis.

Original source/canonical questions and learner history are immutable. Distinctness normalizes affine slope, shift and reduced rational exponent independently of variable names, seed and choice order. Only shift changes are sampled. Documented source corrections apply to generated solutions only. All exact requests and receipts are retained under reference/replenishment.
