Suppose that $S$ is a subset of ${R}^{2}.$ A vector field on ${R}^{2}$ is a function $F$ that maps every point $(x,y)$ in $S$ to a vector $F(x,y)\in {R}^{2}.$

With that in mind, let's examine each function.

- The function $B(x,y,z)$ is *not* a vector field on ${R}^{2}.$ It assigns points in ${R}^{3}$ (not ${R}^{2}$) to vectors in ${R}^{2}.$

- The function $A(x,y)$ is a vector field on ${R}^{2}.$ It maps every point in the set $S,$ given by

$$
S=\{(x,y)\in {R}^{2}\,|\,x+y>1,\,x\ne -1\}
$$

to a vector in ${R}^{2}.$

- The function $C(x,y)$ is *not* a vector field on ${R}^{2}.$ It assigns points in ${R}^{2}$ to vectors in ${R}^{3}$ (not ${R}^{2}$).

Therefore, the correct answer is "II only."
