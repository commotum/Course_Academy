Other bounded shifts are integers -4..4. Every source anchor can replay through generate with its original profile, with no branch returning a captured question payload. Whole-bank eligibility rejects permutations whose true subset is absent from that source bank.

Profiles named by source ID are public raw evidence; `<source>-normal` profiles use normal name/set-glyph repairs and allow eligible list permutations. Raw profiles require original list order but accept changed bounded h, retaining the same source prose recipe. All source attributes are present here, and presence parity is checked independently for each replay. UUID identities are generated, field-owned, and not copied from source. Choice values and correct designations match separately.

Authored moderate kinds: log, square root, reciprocal. Authored hard kinds: reciprocal+square root, log+square root, log+reciprocal. All use only observed elementary components. Their nonempty domains are certified by y=0, x=|h|+2. The assessed question does not ask learners to construct those domains. Both use a complete five-choice bank containing all singleton outcomes, I+II, I+III; two selected answers are always incorrect because exactly one listed function qualifies. Input `kind` is optional with a documented fixed default (log at moderate, reciprocal+sqrt at hard), and wrong kinds reject rather than change silently.

Identity hashes version, difficulty, actual displayed prompt, fixed worked solution and sorted complete bank. Seed/choice order/profile aliases cannot create identity differences. The categorical task fingerprint uses ordered input/output dimensions and restriction categories; shifts and coefficients are incidental for the recognition criterion, excluded from semantic task counts. A source-shaped mathematical recipe can change presentation without adding a new recognition skill.
