# 6. Template generator and verification

`../17592186064250-draft.py` is isolated from the registered numeric artifact. It reads the private `source.json` snapshot and private frozen `math_format.py`; it never imports or writes the numeric script or numeric directory. The full registered path set and file SHA256 baseline was captured before any import in `registered-baseline.json` and is compared by validation, including preexisting caches.

Public API: `generate(difficulty, seed, profile=…, parameters={…})` and `batch(difficulty, count, seed)`. Difficulties are easy/moderate/hard, with all supported for batch/CLI. `seed` and `count` must be built-in integers (bool rejected); count must be positive. Original named-role parameters are available from source_parameters(profile) and can be replayed explicitly. All source bank profiles are eligible for normal sampling. A complete profile is chosen before independent numerator/slope, scale/slope or numerator/radicand sampling, then the whole instance is rejected on collision or duplicate mathematical task. Field-owned answer UUIDs include the bank profile and complete value; identity never treats an option-order shuffle as variety.

Run `.venv/bin/python generate/scratch/17592186064250-draft/validate.py`. Frozen private `parser.py` reads rendered prompt integrands and each solution's substitution, du/dx, differential equality, individual formal integral inputs and all intermediate primitives. Every formal integral equality is checked as its x-derivative after the displayed u substitution. Both real components are retained. Each bank has exactly one correct derivative and no equivalent wrong/wrong antiderivatives; arbitrary additive constants disappear from derivative checks. This establishes calculus separately from radio grading.

`source-cases.json` contains MA originals only. `review-cases.json` contains bounded generated variants and authored easy cases. The private frozen native `check-engine` invokes `course_academy_engine::learning::grade_field` separately on each file and every radio answer identity. There are no blank fields, so blank-equivalence engine tests do not apply. No engine, database registration or EDB write is performed. Source prose and ordered operative roles are replayed while canonical math presentation differences are explicit. Prompt integrands and every operative equality are parsed independently; complete banks match one-to-one with correct designations.

All bounded Cartesian role combinations (and all reduced authored easy rational pairs) and every eligible profile are checked, with rejected instances recorded. Each independent role is also changed with the others held fixed. Actual normal sampling over250 seeds per source level exercises every profile. Mutation tests target stale u, du/dx, a changed individual inverse-function input, a lost absolute value, a wrong intermediate scale, and a wrong key. API and CLI invalid integer/count inputs are rejected; JSON and Markdown seeded output are deterministic. `review.md` places each source beside its independent-role boundary variant, and easy slope3 beside slope2/3. The source ledger retains raw wording; no source error is concealed by normalization.

Use `--difficulty all --seed 2718 --count 2 --format json` (or markdown). This produces count questions per requested level. `capability.json` records finite distinct integrands, not an unbounded bank claim. `validation.json`, source/review engine reports and `source-replay.json` report separate evidence. Recursive file SHA256 values are frozen in `freeze.json`, excluding only the freeze manifest itself.
