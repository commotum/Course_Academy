## 2. Shared pattern and instructional purpose

The learner is given the objects to multiply; they do not compute an inverse from a formula. For a candidate pair, multiply in both orders to establish identity, or exhibit a product entry differing from its identity position to refute it. Use that result to evaluate a redundant inverse equality/inequality. Select the true statements with the original field contract.

## 4. Reusable masks and variable slots

The entire source prompt and existing solution are masked at complete matrix boundaries. `@@M0@@` etc identify supplied matrix roles. Each `@@Pj@@` is an actual product result matrix from the corresponding displayed ordered operands, either complete identity or a one-cell witness mask. Witness position is an explicit0–3 slot whose evaluated product entry must differ from the identity entry there. All four positions occur in generated practice at every level. Labels and assertion locations remain the original mask's aliases; they are not counted as variety.

The twelve numerical entries of the three matrices may vary subject to complete truth-role profile, rational bounds and level workload. The third inverse relation and the second-pair adjacency remain fixed by each source family because they determine which earlier calculation supports each claim. Default sampling chooses a family and then a complete candidate construction before coefficients: flip one entry of a valid candidate, omit a common inverse scale, or transpose a nonsymmetric candidate. These constructions generate supplied objects; they are not presented as learner methods or recovered historical error intentions. Reject the whole instance if it violates profile, workload or any witness condition. Explicit parameters obey the identical guards. Internally using exact inverse arithmetic to generate a valid supplied object does not add that method to the learner solution.

At every replay, normal generation computes matrices/products from rational inputs, renders all objects with shared `matrix_tex(..., augmented=False)` and normalizes prose before IDs. Exact source formatting of negative fractions is retained. Identity includes normalized prompt, full solution, complete field banks, correct predicates, version and difficulty; seed and option order are excluded. Mathematical fingerprint retains rational matrices and assessed relation roles, excluding profile, witness, alias and bank presentation. Equivalent rational spellings, including scaled numerator/denominator, deduplicate. Multiplying a supplied matrix itself by a nonunit scalar generally changes this verification task and is not a mathematical equivalence.
