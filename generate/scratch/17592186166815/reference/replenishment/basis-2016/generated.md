Which of the following systems is a first-order initial value problem?

Select all that apply.

- **I.** $(5+x^2)\left(\dfrac{dy}{dx}-1y\right)+x{y}^{′}={e}^{x},\,y(2)=-3$
- **II.** $(3+x^2)\left(\dfrac{dy}{dx}-2y\right)+x{y}^{′}={e}^{x},\,y(3)=4$
- **III.** $(5+x^2)\left(\dfrac{d^2y}{dx^2}-3y\right)+x{y}^{′}={e}^{x},\,y(3)=5,\,{y}^{′}(3)=6$



Worked solution:

A first-order initial value problem (or IVP) is a first-order ordinary differential equation together with an initial condition that specifies a value of the unknown function at a point in its domain. A first-order initial value problem typically takes the form

$$
{y}^{′}=f(x,y),\,y({x}_{0})={y}_{0},
$$

where ${x}_{0}$ and ${y}_{0}$ are constants.

With that in mind, let's check each option.

- System I is a first-order initial value problem. It consists of a first-order differential equation $(5+x^2)\left(\dfrac{dy}{dx}-1y\right)+x{y}^{′}={e}^{x}$ together with the initial condition $y(2)=-3.$

- System II is a first-order initial value problem. It consists of a first-order differential equation $(3+x^2)\left(\dfrac{dy}{dx}-2y\right)+x{y}^{′}={e}^{x}$ together with the initial condition $y(3)=4.$

- System III is not a first-order initial value problem. It consists of a *second*-order differential equation $(5+x^2)\left(\dfrac{d^2y}{dx^2}-3y\right)+x{y}^{′}={e}^{x}$ together with *two* initial conditions $y(3)=5,\,{y}^{′}(3)=6.$ This is a second-order initial value problem.

Therefore, the correct answer is "I and II only."
