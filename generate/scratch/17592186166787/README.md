# Hyperbolic quotient substitution generator

Run `.venv/bin/python generate/scratch/17592186166787/validate.py` to exhaustively check 22 bounded mathematical tasks and the complete source banks, then `replenish.py` for the scoped inventory job. JSON/Markdown CLI: `python3 generate/scratch/17592186166787.py --difficulty easy --count 5 --seed 1916 --format json`. The API exposes generate(level, seed, template, parameters), candidates(level) and batch(level,count,seed). Easy/moderate are authored workload assignments; hard remains unsupported and unfilled. Each supported band has 11 distinct tasks including its original source task.

Both captured sources lack keys, solutions and difficulty labels. Raw sources and learner history are preserved. Complete source-bank replay, mathematical validation, native application grading, explicit capabilities and review are retained here. The generator performs no database writes. replenish.py uses existing EDB integration, configured application/ca-engine attribution, native validation specs, the application api.lock and exact basis guards. It retains exact requests, previews, receipts and verified readback in reference/replenishment and registers the existing or stable generator identity using the installed UUID/script attributes and KP reference. Only this KP's additive generated content and generator registration may be changed.
