# Plot extraction and generation

All 18 unique source assets were inspected in sources-0.png and sources-1.png. Their exact equations, placement and source hashes are recorded in extraction-data.json. Choices show one red straight line on a white Cartesian grid, black x/y axes with arrowheads and labeled integer coordinates. Some source views shift their range to show the intercept; grid squares preserve equal geometric scaling. No equation labels or marked points appear in the choices. Solution plots mark the two computed points in blue; canonical e-984 uses red marks, and is retained unchanged.

Each supported question has five answer plots in observed bank order and one final solution plot. The plot function takes exact slope, intercept and optional exact point pairs from the same instance; it never samples. It uses Matplotlib, equal data scaling, a gray unit grid, labeled even ticks, red line, x/y axes and blue solution markers. Choice y bounds -6.5..9.5 include the largest possible intercept 8; x bounds -4.5..9.5. Solution x bounds expand to include x2=4d up to 16 and its point. Labels, arrowheads and markers stay inside the rendered 540-by-540 PNG. No direct SVG or raster image model is used.

At unchanged source parameters and roles, reuse the original images byte-for-byte. Variants may reuse an unchanged source graph for an identical affine object. New assets are hashed from PNG bytes, staged locally, and published only for admitted questions through ImageLibrary.put_bytes; the learner values are relative images/xx/sha256.png paths. Stored bytes are checked before submission and again at exact-basis readback.

Every bounded graph bank has five distinct affine objects and one target. Exact plotted point membership and all rendered solution arithmetic are checked independently. Source replay remains separate from mathematical correctness and actual radio grading. Source/variant review and committed-asset sheets verify readability, intercept visibility, scales, labels and absence of clipping. Heavy plot rating remains appropriate because answering depends on graph recognition.
