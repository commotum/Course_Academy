# Known-magnitude unit vectors

Run `.venv/bin/python generate/scratch/17592186096813/validate.py` from the repository root. It replays both source banks, independently parses printed prompts/options/equality stages, exhaustively checks finite authored domains, checks explicit bounds/identities/shuffling, writes reviews and validation, and calls the real memory-only native grader.

Preview: `.venv/bin/python generate/scratch/17592186096813.py --difficulty all --seed 17 --count 2 --format markdown` (or `json`). API: `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` plus `generate_easy`, `generate_moderate`, `generate_hard`. Templates: `named`, `directed`. Normal complete banks: `normalization`, `direction_errors`. Evidence profiles: `raw_named`, `raw_directed` (easy only). Explicit parameters: easy `m`; moderate `p,q`; hard `k,d`; optional complete `label`.

All E/M/H ratings and practice worked solutions are authored. Both captured sources are unrated/unkeyed/solutionless, with five original choices apiece. `source.json` and `source-cases.json` retain raw evidence; raw API records preserve those omissions and cannot be used as keyed learning records. Independent mathematics finds the unique eligible displayed answer; this is not original-key fidelity. Scalar-source 2m/4m masks have unresolved error intent and stay evidence-only. Normal arrows use standard TeX; raw arrow notation stays unchanged. Parallelism is audited in both directions. No database writes, component vectors, diagrams or vector sums are implemented.

Native grading also checks both original complete banks in explicitly identified memory-only fixtures with mathematically inferred keys. Those fixture keys never modify source evidence or raw replay and never count as original-key matches. `engine-input.json` labels this distinction. Normal learning records contain authored keys and solutions. All 58 raw magnitude/template variants and 644 authored magnitude/template/bank variants are independently checked; meaningful mathematical task counts remain 29/72/60, excluding labels and banks.
