## 2. Generalized pattern

Solve the printed consistent NxM system by reducing its augmented matrix to RREF, identify pivot/free variables, express basic variables in the single free variable, and select the complete general-solution vector. The solution never depends on the selected error. Observed families vary the row-operation sequence and scalar/vector presentation; one fixed prose/mathematical sequence is retained for each source profile.

## 3. Components and recipe coverage

A source profile contains its original complete augmented matrix, source system syntax, every innermost mathematical component of its fixed solution, field layout, and entire five-choice bank. Matrices, equation rows, vector components, and the one q32517 explicit numeric equation in prose are replaced only as complete components. No global substring substitutions touch coefficients, labels, or prose.

Let X_new = c X_old + d, where c is nonzero. Each augmented matrix [A | b] becomes [A | cb + Ad]. Each vector component f_i(t) becomes c f_i((t−d_t)/c)+d_i, preserving its original free parameter’s name and entire domain. Every existing elementary row operation commutes with this transformation; its coefficients remain unchanged. Consequently every matrix and equation stage is derived from the changed parameters, and each whole observed incorrect vector remains incorrect. This is an invertible mathematical transport of the entire bank, not an inferred explanation for individual distractors and not a scalar polynomial fit. At c=1,d=0 every original full mathematical value is recovered. All 55 options are mapped above with their own UUID. Distractor intent remains underdetermined for observed banks; these replay profiles are explicitly requested, never silently promoted to normal defaults.

Normal defaults choose the complete authored `authored_operations` profile before sampling. The five options are: the correct vector, reverse the first basic variable’s free-term sign, reverse its constant sign, omit the second basic variable’s free contribution, exchange the first two basic coordinates. Compute them from the actual RREF and reject the WHOLE instance on equivalence, a second valid answer, or collisions. No first-valid recipe pool or unrelated perturbation is used. None of these author-side error labels is learner-facing feedback.

## 4. Reusable template and bounds

Observed input parameters are `scale` c with |c|≤5, denominator≤2, c≠0, and n `offsets` with |d_i|≤10, denominator≤2. The normal observed-profile sampler uses c in ±1,±2,±3 and offsets in −5..5. Coefficients and elementary-operation workload are unchanged. Arithmetic and source value transport are exact SymPy rationals.

Authored parameter slots are `free_coefficients`, `constants`, and complete integer `mix` vectors. The RREF is [I | free_coefficients | constants], giving one free variable. All free coefficients are nonzero: easy magnitude≤5, moderate≤4, hard≤3. Easy/moderate denominators≤2, hard≤3; constant magnitude≤6 and denominator≤2. Mixing factors are nonzero integers of magnitude≤2, with lengths 2,4,6 for easy/moderate/hard. Every input matrix entry has magnitude≤48. Explicit inputs obey the same bounds and fail rather than being silently replaced. Samplers use nonzero integer free coefficients/constants; boundary fractional inputs are supported under these exact rational bounds. Rejected collision cases are resampled only when parameters were sampled automatically.

Easy uses two row additions; moderate six operations (row-one scaling, row-two elimination/scaling, two eliminations of the dependent row, backward elimination); hard nine operations (three scales and six eliminations). Thus all peers at a given level have a fixed same-method workload.
