# Path plots

Sources place one image before the integral. Each has black x/y axes, numerical endpoint/intercept labels, a blue line/circular/elliptical arc labeled C, and blue traversal arrows. All text endpoints, arc sectors and directions agree with the source diagrams in the inspected contact sheet. Moderate line paths and hard semicircle/ellipse paths are retained exactly. Source aspect ratio is incidental to the line-integral calculation; endpoint geometry, arc selection and arrows are meaningful.

Only the scalar integrand changes. Reuse the existing content-addressed PNGs without alteration. No curve, endpoint, axis, numerical label, arrow, styling or placement is sampled. Thus the new-plot rating is none for every supported template. plot-assets.json records exact paths, SHA-256 bytes, and source placement. No new asset publication or plot renderer is needed.
