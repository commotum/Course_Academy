# Template extraction

The supplied object is a scalar field f(x,y), an oriented path C, and one requested coordinate differential dx or dy. The response is one exact scalar integral, selected from a field-owned five-choice bank under key selection. Every source is described and mapped in source-components.json or excluded-sources.json, including all choices, source fields, full prompt, and full worked solution. No distractor interpretation is asserted without evidence.

The fixed backbone is: state the coordinate line-integral formula; rewrite ellipse semiaxes when present; parameterize the supplied path with its traversal bounds; compute the requested coordinate derivative; substitute the field; evaluate the integral. Hard templates retain the observed u=cos(t) or u=cos²(t) substitution stage and its complete endpoint calculation. Moderate polynomial, square-root and trig stages remain distinct. Repeated instructional sentences and all source equation stages are preserved. Documented differential-label errors and captured TeX artifacts are corrected in new records only.

The sole variable slot is the positive constant c multiplying the entire original integrand. Observed c=1 replays sources for evidence; sampling is the explicitly narrower domain c in {2,3,4,5,6,7,8,9}. Positive nonzero scaling preserves the real domain, smoothness along the path, all integration/substitution stages, and source difficulty. Correct answers are computed first using exact SymPy integration. Each original bank profile is scaled as a whole: every source option v becomes c·v, with the same correct designation. These are conservative exact observed-value recipes; no inferred feedback is added. Zero/negative scales and changes of path, orientation, differential, powers, or integrand structure are outside this version.

The path is deliberately fixed in this bounded package: changing it would affect endpoint values, branch behavior, diagram and in some cases integration method. Diagram labels and target coordinate remain fixed and validated; there is no declared variable target slot. A changed-c case with the entire path held fixed checks all prompt, field-substitution, solution and bank dependencies. The finite sampling domain is exhaustively validated per template. Seeds select content from that domain; they do not create additional content.

Complete source-bank replay, normalized prompt/solution fidelity, exact mathematical correctness, and actual grader results are reported separately. All printed scalar rows and integral evaluations are independently parsed from rendered TeX and checked against the displayed field and path. review.md shows every supported source next to c=2 and c=9 variants.
