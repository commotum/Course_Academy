# Template extraction

## 1. Individual observations

Every observed prompt asks for area using an unprovided change of variables. Linear families present two pairs of oblique parallel lines with small integer coefficients, varied signs and constants. Their solutions have five steps: choose the transformation by rearrangement; substitute all four boundaries and display a rectangle; compute the forward derivative matrix and signed determinant distribution; reciprocate; integrate the absolute reciprocal over the rectangle, evaluate widths, and collect. The nonlinear hard families instead form x²y and xy, or xy and x/y², then integrate 1/u or1/(3v). Source order and notation are preserved. q-160373 has only its first-power hyperbola/line prompt and bank, so its normal five-stage solution is explicitly authored from this route rather than recovered prose.

## 2. Generalized backbone

Recognize the two invariant expressions shared by paired boundaries, select them as u and v, map to four constant bounds, compute both Jacobians and calculate area. Keep the radio scalar response, five options, shared solution prose, all four boundary substitutions, determinant stages, area absolute value, factorizations and endpoint row. One worked solution is independent of the selected learner error.

These expression masks genuinely parameterize complete displayed banks but cannot recover unknown historical mistake intent. They never become normal defaults. Exact originals are replayed through generate(..., profile="source_<source-id>") with original omission parity. Raw evidence may carry a collision/incorrect teaching row on changed inputs and is ineligible for learning.

Normal profile `method` is selected as one whole profile before parameter sampling:

- Linear |J|≠1: [A,wh,w/|J|,h/|J|,wh|J|] (omit Jacobian, omit one side, use forward determinant).
- Linear J=1: [A,w,h,1/A,1/w] (omit one side, invert collected area/one side).
- First-power product/ratio: [A,2A,wR/(2d),w/(2c),w ln(d)/2] (omit factor2, substitute endpoint into Jacobian, omit log, omit lower log).
- Square product: [A,−A,dL,L/h,wh] (signed area, omit lower v bound, invert width, omit Jacobian).
- Product square ratio: [A,−A,3A,R/3,w ln(d)/3] (signed area, omit3, omit u width, omit lower log).

All ten option pairs, including wrong/wrong pairs, are compared for full scalar mathematical equality. Whole instances with collisions are rejected; no option replacement pool is used. No learner-facing error diagnosis is added.

## 4. Reusable masks and slots

The script holds each primitive coefficient/exponent family fixed; those constants define source reasoning workload. Four complete boundary constants are slots, not global digit replacements. Moderate integers lie in [−4,6] with each width<=5; easy/hard integers in [1,8] with each width<=5, keeping first-quadrant injectivity and familiar log ratios. Explicit parameters obey the identical guards. Random samplers use interior bounds with widths1..4. Each level independently repeats the same number of recognition, Jacobian and integration steps.

All parameter-dependent math blocks are masked as complete equations, boundary chains, rectangle and endpoint/integration components. Source coefficient matrices remain fixed because their independent-variable dependence does not change when bounds change. Simultaneous masking prevents a changed first interval from matching the original second interval. Preserve unnormalized source set braces in evidence; normal output escapes the visible set braces without changing inequalities. q-160654's erroneous upper boundary substitution is retained in raw replay and repaired in normal output. Source bank spellings use their original ln/operatorname conventions. IDs depend on version, actual displayed prompt, fixed solution and complete bank; option order and seed are excluded. Mathematical fingerprints exclude profiles/banks and include recognized objects and meaningful bounds.
