Slots: retain an observed shape/rank pair (3–5 columns and rows; rank 2–4), vary the strictly increasing leading-column tuple, nonzero signed leading values and trailing integer values in [-9,9]. Zero rows remain last. A bijection of original column roles maps every original option subset to a new subset; the displayed matrix is then constructed with increasing mapped pivot positions. These are same-method generalizations. They do not assume a particular source column location essential. Source replay uses original entries and identity mapping. Pivots increase strictly down the nonzero rows. All options remain distinct under the bijection.
