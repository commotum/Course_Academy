# Non-pivot columns from supplied echelon matrices

Each question presents an integer matrix already in row echelon form. The learner identifies each first nonzero row entry, finds the pivot columns, and selects their column-set complement. Version 1.1.0 exposes this subset directly as one Boolean checkbox per matrix column. All columns are displayed in order, including the columns the learner should leave unchecked.

The 16 historical profiles retain their observed shape/rank pairs: 3–5 columns and rows, rank 2–4, and one or two non-pivot columns. Strictly increasing leading-column positions vary across every eligible placement; nonzero leading values and trailing integer values lie in [-9,9]. Zero rows remain last. A mapping of original column roles determines the new pivot tuple; the generator then constructs a new echelon matrix. It does not claim that arbitrary column permutations preserve echelon form. The method and supported easy difficulty are unchanged.

Original matrices are replayed with their original wording plus “Select all that apply.” Their former combination-radio choices are recorded as column subsets in `checkbox-update-2026-10-16/source-replay.json`. The source key is compared with the exact matrix complement and with the checkbox key. All former choices, empty/full selections, and every other subset can be expressed by the new fields. There is no None checkbox. New question, field, and answer identities depend on the served checkbox content, not the old choice bank or seed.

`source.json` and historical extraction artifacts preserve the original capture, including duplicate fields and typos. Replay deliberately repairs the endings of q-73618 (“columns”) and q-73621 (“column”), with exact substitutions recorded in the current replay evidence. All other solution text is preserved on replay. Generated variants retain the same definition, pivot list, and complement conclusion.

Independent validation reads the printed matrix, proves echelon form, verifies exact rational RREF pivots and the complement, checks each Boolean field and owned key, and verifies the printed solution. Every historical profile is exercised over all column-role mappings; ordinary seeded sampling covers every eligible pivot set. Current native grading checks both owned Boolean answers per column. The family remains finite at 40 structural tasks; coefficient-only variation does not replenish inventory. Moderate/hard and zero/full correct non-pivot sets are outside the existing generator scope.
