# Pivot-column template

source-components.json records every source matrix, dimensions, ordered pivot set, source answer identity, complete choice value, correct designation, and parameterized recipe. source-fidelity.json records exact prompt/solution replay and 52/52 distractors across 13/13 complete banks. The incorrect subsets have no evidenced psychological explanation; their interpretation remains unresolved. The generator retains their observed subset expressions under a column bijection instead of inventing error stories or pooling recipes.

Fixed backbone: a matrix already in row echelon form; one request for its pivot columns; a five-choice radio field named selection; the reminder defining pivots, followed by the number and ordered columns of the leading entries, followed by the matrix. No elimination or arithmetic is added. The source's matrix name and sentence structure are retained. No feedback is added to the source presentation.

Slots: select one complete source bank profile before constructing the question; retain that profile's observed row count, column count, rank and number of zero rows. Choose any increasing subset of columns of the same rank. Define a bijection mapping the old pivots in order to those targets and the old nonpivots in order to their complement. Apply that same bijection to every source choice. This changes the assessed column relations, including leading zero columns and internal gaps, without changing the method. Rebuild an REF matrix with those pivots: entries before each leading position are zero, the leading entry is a nonzero integer in [-9,9], trailing entries are integers in [-9,9], and zero rows stay at the bottom. The exact source matrix is accepted for replay.

These are conservative same-method generalizations. Source numeric values and nonleading zero patterns are fully preserved in replay, but are incidental to finding the leading entries. Default sampling varies target columns and numeric entries. Supplied parameters replay exactly; seed alone does not establish a question's identity. A changed target updates the matrix, solution column references and all five subsets together. Source conjunction/punctuation is exact at original parameters; nonidentity choice-index substitutions use sorted conventional ordinals.

Question UUIDs derive from complete authored content excluding seed. Field UUIDs belong to the question; answer UUIDs belong to the field. A separate stricter mathematical fingerprint consists of dimensions and ordered pivot columns. Inventory generation rejects every fingerprint already present, including shown questions and the canonical task, even if coefficients, label or bank differ. There are 40 structural tasks across the seven observed dimension/rank shapes. The finite limit applies to this conservative package, and shortages remain explicit at exhaustion.

Validation reads rendered matrices independently, obtains pivots by exact SymPy RREF, verifies the first-nonzero rule and bottom zero rows, checks the worked-solution matrix and column statement, validates all subsets and the unique key, and exercises the actual learner grader for all five options. Every eligible target subset for every bank profile is exercised. A fixed-values changed-column probe compares pivots (1,3) with (2,3); changing the solution to a stale instance is rejected. review.md provides original/variant comparisons; review.json retains the structured records. No plots or asset publication are required.
