Source replay uses `profile="raw:q-..."` and original parameters through the normal generate API. It constructs factor/prose slots and the complete bank; the raw profile reuses the original PNG only when the entire source polynomial matches. Changed parameters call the same renderer as normal generation. This does not return a literal question payload or an answer lookup table. Normal profiles omit the raw prefix and always render complete labeled plots. Mathematical fingerprints use sorted roots, local behavior categories and leading sign. They exclude exact positive amplitude, even-exponent aliases, seeds, shuffle and bank profile. Presentation identity includes actual displayed prompt, fixed solution, complete bank, version and difficulty.
