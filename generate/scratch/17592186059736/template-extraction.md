# Four extraction stages

1. Specific observations: `inventory.json` records all 27 source coordinate pairs, scalar/basis/tuple number forms, field ownership/order and arithmetic-stage sequences. `source.json` retains every complete original prompt, answer bank, correct reference and solution. The source bank count is 17 radio banks plus 11 three-field blank layouts. There are exactly two missing original field keys: q-1408's only field and q-1405's legacy field. They are inferred for runnable fixtures and never counted as matched original designations.

2. General pattern: expand the formal 3×3 determinant in the basis row, take the signed i,j,k minors, evaluate the same six products and three differences, and report the requested vector or supplied scalar fragments. All observed response layouts retain their source-specific stages. No magnitude, unknown coordinate, triangle, altitude, trigonometry or further vector operation is introduced.

3. Components and full banks: `recipes.json` maps each original field to every original displayed value and its correct index, with flags for whether that index was captured or inferred. For radio profile `observed:q-id`, let the original input coordinate pair be A,B and independent allowed scales be α,β. Inputs are αA and βB; every complete original bank vector W is the explicitly parameterized expression αβW. All original wrong values are thereby preserved one-to-one at α=β=1, with exact full-vector covariance at changed parameters. These opaque expressions recover bank values and answer shapes; they make **no claim to recover the author's mistake operations**. Numerical values do not identify the original error intention. This finite covariance extension is explicit replay evidence, never the normal default bank. Allowed scales are 1/2, 1, 2. The two factors vary independently; every combination is checked from the displayed input vectors and full banks. Scalar blanks apply αβ to the required source fragment, preserving all supplied signs and angle-tuple/basis layouts.

The default authored bank is selected in full before sampling: correct A×B; B×A; omit the outer negative sign on the j minor; use addition in all three minors; cyclically move the three correct components. All five complete vectors must be pairwise inequivalent, including noncorrect/correct collisions. Failure rejects the entire instance; options are never replaced using a first-valid pool. Banks are identical operations throughout a level, with no learner-facing invented diagnosis.

4. Reusable masks: source prompt masks contain two complete-vector slots. Basis i/j/k labels and source variable names never undergo free prose substitution. The formal matrix and minor rows have explicit row-owner scalar nodes (α versus β). Twelve-leaf product rows preserve original operand order, including commuted products. Evaluated-products and result rows use αβ scalar nodes. Full scalar atoms include fractions and radicals; the radicand is not replaced as a separate coordinate. Fixed wording, math grouping, row counts, optional rows, punctuation and tuple/basis fragments remain source-specific. Positive scales preserve source signs and zeros. This is a parameterized recipe, not a branch returning a source question or a correct-answer table. Exact SymPy math computes and independently verifies the correct components. At α=β=1 source masks reconstruct original teaching stages; changed-parameter rows are independently parsed from actual printed strings.
