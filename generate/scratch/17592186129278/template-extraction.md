## 2. Shared assessed method

Substitute x=r cos(theta), y=r sin(theta), z=z; establish disk angle/radius and z bounds; include the Jacobian r; integrate in the source order dz, dr, dtheta. Keep the sources' common change-of-variables opening, coordinate formulas, projection discussion, vertical-bound bullet points, cylindrical domain, and the "Therefore, using the change of variables formula" transition. ## 3. Components and operative chains

- radial_tilt: sqrt(x²+y²) -> r; integrand r²; z-height h-b r sin(theta); distribute; radial primitive includes r³ and r⁴ sin(theta); full-circle sine integrates to zero. Original unrated source independently gives64π, but has no supplied designation or solution.
- cross_z: 2z with z=-x and z=h+x, half disk. Raw source is an oriented iterated integral; actual stated enclosed-solid geometry is anomalous (see below). No normal family is generated.
- half_xradial: x sqrt(x²+y²) -> r³ cos(theta), parallel y-planes cancel to constant height; retain height factor, radial fourth power, and sin(theta) endpoints(-1,1).
- reciprocal: z/sqrt(x²+y²) -> z after r cancellation; square the radical upper bound during z integration; reduce cos²-sin² to cos(2theta); radial primitive has separate r and r³ cos(2theta) components; full-circle angular primitive has separate theta and sin(2theta) components. Both endpoint components are independently checked.
- cone: radial-square integrand -> r³; z cap minus cone produces h r³-b r⁴; radial primitive has two powers; retain endpoint difference and constant angular primitive.
- half_xz: 2xz ->2z r² cos(theta); factor r² cos(theta) outside [z²]; substitute BOTH squared height endpoints; expand both squares and cancel; cos²(theta) survives; integrate radial powers, then use cos²(theta)=(1+cos(2theta))/2; preserve identity and distributed rows before angular primitive.
- half_constant: constant c -> c r; expand tilted height, integrate r and r² cos(theta), evaluate both primitive components, then theta and sin(theta) endpoints on0..π.
- quarter_x: cx -> c r² cos(theta); z height gives product cos(theta)sin(theta) and a cosine term; rewrite product with sin(2theta)/2 BEFORE radial integration; retain separate r⁴ and r³ primitives and angular cosine/sine endpoints.
- half_linear: c(x-y) -> c r²(cos(theta)-sin(theta)); parallel x-planes cancel; retain factored height and signed angular sum, radial cubic, then sine and cosine endpoint components.
- power_tilt: x²+y² -> r³; z-height expansion gives h r³-b r⁴ cos(theta); retain separate r⁴ and r⁵ cos(theta) primitives; cosine disappears only at final full-circle angular evaluation.

Normal solutions use standard TeX normalization (cos/sin, braces, explicit multiplication), canonical additive term order and computed integer/rational coefficients.
