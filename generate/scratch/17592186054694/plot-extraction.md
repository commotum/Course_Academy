# Plot specification

All source choices are Cartesian line diagrams with labeled x/y axes, integer grid, red line, blue marked points at x=0,1,2,3. Source scales differ between banks; geometry was inspected in source-graphs.png. The 15 observed (m,b) values and marked-point evidence are retained in source-choice-mapping.json. Choice order is preserved in replay. The canonical and two complete practice solutions contain a points-only graph followed by the correct connected line graph. Plots are heavy because they are the answers and part of each solution.

Generated choices use Matplotlib with equal x/y unit scales, labeled axes through the origin, gray unit grid, red line, and four blue points. All five choices for one question share square bounds [-L,L] on both axes, L=max(6, 1+max absolute y over every bank's four points); no correct-answer-only scale hint. Numbered ticks every 2 units for L<=12 and every 4 beyond that keep labels readable, with unit minor grid. Font size 7 at 480x480 PNG; blue markers size 4; red line width 1.8. Source raster style is not claimed identical. Curves clip at the frame; all table points remain strictly inside it. The solution first shows only its four correct points and then reuses the correct choice plot.

Rendering accepts the exact computed slope, intercept and shared bounds; it never samples parameters. Each deterministic PNG has a sidecar recording parameters, table points, limits and SHA-256. All committed assets are published by the existing content-addressed ImageLibrary, and their stored bytes are checked. Visual review covers original and generated complete banks, both slope signs and largest bounded intercepts; source raster replay and new mathematical geometry are assessed separately.
