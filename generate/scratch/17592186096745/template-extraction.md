# Template extraction

The source-analysis.json record describes every original question, field and full bank before generalization. source-replay.json maps all 25 supported source choices, including every distractor, to its exact generated value and recipe. Profiles are never pooled or partially selected.

Each supported template supplies three equations in x,y,z with a fixed coefficient matrix and a dependent third equation. The learner selects the complete reduced augmented matrix. Its solution stages are the original augmented matrix, each annotated Gauss-Jordan row operation, row echelon form with two pivots, and elimination above those pivots. Keep the original prose, answer shape, notation, field key, choice count and exact operation sequence. Coefficients, pivot positions and the complete requested matrix are fixed to preserve this conservative workload; they are not claimed to be intrinsically fixed by the KP.

Variable slot k is a nonzero integer in {-5,-4,-3,-2,-1,1,2,3,4,5}. Observed parameters are k=1. The explicit same-method generalization replaces every equation RHS b_i by k*b_i and every last-column value in every intermediate, final and choice matrix by k times that value. Text choices stay unchanged. E[A|k b]=[EA|k Eb] for every elementary row-operation matrix E, so the original annotations and operation sequence remain exact. Nonzero k preserves rank, consistency, option distinctness and correct designation; each of those properties is also checked independently. Scaling b changes the affine solution set. Fixed coefficient choices are a narrower policy than the KP's possible full range.

Distractor recipe for each source option: retain its complete first three columns and multiply its entire last column by k; for the text option retain “No solution.” These are observed matrix-expression patterns with a covariant extension. Their psychological interpretation is unresolved. No misconception feedback is invented. The mapping includes altered constants and compound errors exactly as complete source matrices; no recipe is replaced by a plausible alternative.

Sampling chooses a complete profile first and then k. It rejects unsupported levels/profiles/scales, has 50 validated distinct augmented row spaces, and never creates additional questions by shuffling banks or seeds. Every instance has field-owned answer UUIDs. Deduplication uses the exact augmented RREF, so equivalent equation systems, source identities and option changes do not increase inventory. The k=1 replay is fidelity evidence, not automatically fresh inventory.

Source replay matches prompt, worked solution and all five options verbatim for each supported profile (5/5 complete banks, 25/25 choices, 20/20 distractors). The other nine practice sources are excluded from generator support, including eight vector-response sources and the malformed duplicate-field source. The generator makes no full-KP fidelity claim. Review.md places exact replays beside negative and positive changed-RHS instances for every supported profile. No target-position slot is declared; the target is the complete RREF matrix.
