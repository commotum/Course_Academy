# Stage 6: local draft generator

Run `.venv/bin/python generate/scratch/17592186064203-draft.py --difficulty all --count 1 --seed 29` for a flat JSON array of three records, one per level. `--count` applies per level; each count must fit every requested level. `--format markdown` emits full prompts, choices and complete solutions. `--output PATH` optionally saves the local result.

Public functions: `generate(level, seed=0, template=None, parameters=None, profile=None)`, `generate_easy`, `generate_moderate`, `generate_hard`, `batch(level,count=5,seed=0)`, `capacity(level)`, `source_record(source_id,raw=False)`, and `markdown(record)`. Learning levels are exactly easy/moderate/hard; template/profile identifiers are the keys in templates.json and must match grade and each other when both supplied. Parameters are exactly a dict with b as builtin int1..80. Seeds are any builtin int (negative included); bool, strings and nonintegral values are rejected. Batch counts are builtin integers0..capacity, including empty batches; overflow raises ValueError. Finite candidates are shuffled reproducibly and deduplicated by actual expanded integrand. Automatic sampling excludes independent-inventory aliases.

source_record is explicitly a reference API. It returns the original complete Pull or a typography-normalized copy. Incomplete sources retain missing grade/key/solution and never enter the served learning generator. It does not establish served fidelity; generate source-profile replays, full-bank comparisons and independently read solution rows do that.

All generated content is normalized with shared math_format helpers before deterministic content UUIDs, then checked by checked_math_content. IDs belong to question and field. Seed is metadata only when the selected parameters/profile are fixed. Native grader uses the frozen existing runs/current/check-engine executable; no rebuilding or engine changes. Radio grading checks field-owned IDs, so the equivalent-display probe exercises a separate algebraically expanded bank with the same answer ownership; it is not a claim that radios accept typed algebra. Ordinary wrong probes are the four owned distractors; malformed/foreign submissions are not used to inflate rejection counts.

Validate with `.venv/bin/python generate/scratch/17592186064203-draft/validate.py`. It exhaustively reads printed math for all480 unique permitted learning tasks, verifies each field, every choice derivative, each substitution/differential and ordered integral/derivative equality; checks original source anchors and changed-b variants; rejects corruption of math rows, prompt, substitution and key; tests API limits, repeatability, native grading, full-capacity dedup and the flat all-level CLI. Source fidelity, independent inventory fidelity, mathematical correctness and native grading have separate report fields. registered-baseline.json is rechecked at completion. See validation.json, engine-input/report.json, source-cases.json, independent-cases.json and side-by-side review.md.
