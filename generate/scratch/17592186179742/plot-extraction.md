# Plot extraction and generation

All source figures were inspected in `reference/source-plots.png`. Source PNG paths, byte hashes, dimensions, placement roles and ordered references are in `source-assets.json`. Full source solution figures remain directly linked in `reference/review.md`.

The source plot pattern is a two-dimensional quiver field in gray, black coordinate axes labeled x/y, a blue path with named endpoints A and B, and solution versions emphasizing the direction of travel. Numerical ticks are absent. The diagrams carry the entire supplied mathematical relation, so the rating is heavy even when assets can be reused for exact replay. Arc shape, endpoints, field directions, perpendicularity/tangency and forward/reverse roles are meaningful; exact pixel layout and arrow density are incidental.

Source-specific path descriptions: q-125380 vertical segment in a rightward field; q-150018 horizontal segment in an upward field; q-125381 upper semicircle in clockwise field; q-125499 three-quarter circle in counterclockwise field; q-125507 left semiellipse against a circulating field; q-125497 lower semiellipse with a circulating field; q-125500 upper-left quarter circle in outward radial field; q-125504 upper-right quarter circle in inward radial field; q-125501 lower semicircle in inward radial field; q-125502 right semiellipse in normal field; q-125688 rising curved path against the field; q-125687 upward-opening curved path against the field; q-150013 downward-opening curved path assisting the field. Canonical e-9542 shows a general curve with perpendicular field.

`render` uses Matplotlib only. It draws the specified analytic field on a 13x13 mesh, using one common vector scaling (never independent arrow normalization), a dense parameterized path, endpoint markers, and labels offset from the endpoints. It fixes equal physical coordinate scale, supplies bounds from both axes with margins, and produces prompt/forward/reverse PNGs. Prompt figures omit traversal arrows as in the sources; the prompt explicitly defines A to B. Orange motion arrows in solutions follow the same parameterization, reversed only in the reverse role. No random state is used by rendering. File identities retain full plot parameters even when mathematical inventory deduplication collapses equivalent tasks.

Every generated source reference is rewritten to the existing content-addressed image library at publication and its exact bytes rechecked. Source assets are immutable and reused only for source replay. Rendered examples spanning both geometries, alignment signs, profiles, arc sweeps and both traversal directions are visually reviewed before freezing.
