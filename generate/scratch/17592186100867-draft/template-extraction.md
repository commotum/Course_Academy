## 4. Reusable masks and constraints

The backbone is fixed to a numeric3×3 matrix, a numeric3×1 column, all three ordered row dot products, source field keys/types/counts, complete five-choice radio banks or three scalar blank fields, shared prose and original operative solution layouts. The numeric tokens inside each source matrix/product/evaluation stage are component masks; every token is derived from the new operands. Negative numeric multiplicands receive explicit grouping where needed, while source grouping is preserved at anchors. Complete named components are substituted without replacing single letters across unrelated TeX.

Numeric domains and equal-level workloads are specified in classification.md and enforced for explicit inputs as well as samplers. Observed profiles have a separate integer ceiling128 to exercise scaling covariance; normal arithmetic never exceeds magnitude8 in the operands. A whole bank is selected before parameter sampling and resampled only as a whole. Blank fields preserve exact scalar answer fragments and placeholders. Raw profiles preserve source attribute presence. Normal completion supplies missing solutions/keys only with explicit authored provenance outside learner content.

Eligible matrix/vector names are six uppercase and five lowercase letters. Every numeric cell and vector coordinate varies; all output roles remain assessed. Validation records per-slot signed values, name sets and template coverage, plus a name change with operands held constant and a matrix-row permutation with the column held constant. Mathematical fingerprints exclude names and banks but retain ordered operands and the assessed three-row method. Presentation identity includes version, normalized prompt, full solution, actual difficulty/omissions and complete canonical banks; choice order and seed do not affect it. Fields and answers are owned by that content identity.

No plots need generating. The canonical raster matrices are copied and hashed only as reference evidence; practice is code-native TeX. Source errors are the two missing key/solution/difficulty records, recorded without silent repair in observed replay. There are no unmatched source choices or known mathematical source errors.
