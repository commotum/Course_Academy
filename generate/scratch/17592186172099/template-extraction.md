# Extracted templates and declared variation

The original complete prompts, solution stages, fields, choices and correct values are retained in reference/initial/source.json. classification.md describes each source separately; bank-mapping.json maps every supported source option by its original answer UUID, exact original notation, mathematical expression, source field, complete profile, recipe and correctness designation. The two excluded profiles are retained verbatim in source.json and identified in validation.json.

Shared instruction: apply the flux form of Green's theorem to a supplied planar vector field across the closed boundary of a specified region. The requested object is the total outward flux, a scalar, using the supplied five-option radio selection field. Each distinct vector structure and integration workload in classification.md remains its own template and profile.

Fixed backbone and stages: quote the theorem and smoothness hypothesis; show D and C; identify P and Q; compute P_x and Q_y; express D with type I or type II bounds; set up the flux/divergence double integral; integrate the inner variable and evaluate its bounds; simplify; integrate the outer variable, evaluate bounds, and state the exact scalar flux. The generator retains this sequence and the source's shared instructional sentences. Algebraic factoring is allowed in intermediate lines; it does not add a reasoning stage. No learner-dependent solutions or new feedback are added.

Declared numerical slot `scale`: a positive integer k, with source value 1. Multiply both entire components of the supplied field by k and evaluate/expand the result. The divergence, both antiderivatives, worked numeric values, and all five mathematical options must change consistently. Default seeded sampling uses 2 through 50; explicit replay permits every positive integer. A single scale is a deliberately narrow same-method generalization. Independent coefficient sampling would require new distractor recipes, which these sparse banks do not establish.

For every original option v in a complete source bank, retain the observed expression pattern as the explicit recipe k*v. This is a covariance extension, not a claim to have identified the learner's cognitive error. Flux is linear in the field, so the correct option remains correct, distinct original options remain distinct under k>0, and every wrong option remains wrong. bank-mapping.json records all exact recipes, including fractions and the exponential constants. Profiles are never mixed or truncated, and interpretation of distractors remains unresolved. Scaling the original complete bank is the only supported bank generalization.

Fixed slots and reasons: the question asks flux rather than circulation; P and Q keep the source's expression operators, powers, variable roles, signs and smooth spectator terms. Each region stays fixed, including vertices, curve identities, interval and orientation. This package exposes no location or target slot: changing the bounds while keeping k*v bank recipes would break correctness; changing them would require independently justified distractor transformations. No sparse-source inference that a region is inherently unvarying is made; this is an explicit limitation of the present bank policy. Radio count, key, mathematical values and exact scalar answer contract are fixed.

Supported source replay sets k=1 and compares the complete bank as exact mathematical values, ignoring order, with a one-to-one mapping of all five options and the correct designation. Rendered notation uses LaTeX angle brackets and normalized fraction escapes rather than malformed doubled source escapes. Actual differentiation and integration, source and generated final values, and solution layout are separate checks. Supported sources have nine matched complete banks, 45/45 options, and 36/36 distractors; exclusions are reported separately.

Distinctness fingerprints collapse questions with equal divergence on the same region, ignoring seed, identity, spectators, bank order and notation of the vector. All generated questions also undergo source/canonical/current pool matching. Changing k changes the actual differentiated field and flux; seed, identity and option order never do. No new question is counted merely because it has a new UUID or bank.

Validation exercises k=1,2,7,50 for every supported profile, positive-integer boundary rejection, deterministic parameter replay independent of seed, and 100 seeded choices per difficulty. Fixed geometry and response roles are checked for every variant. Key, primitive, region-bound and final-value mutations must fail. Because there is no target slot, a changed-target demonstration is inapplicable. review.json places original and k=1/k=7 variants side by side for all nine supported profiles.

Supported notation correction: doubled TeX command escapes in captured scalar choices are interpreted as single command escapes for exact source-bank comparison, and generated values render with standard TeX. This is a recorded presentation correction, not a source edit. Unchanged malformed source banks do not contribute to validated inventory.
