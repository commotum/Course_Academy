# Surface-integrand generator

Run `.venv/bin/python generate/scratch/17592186172130/validate.py` for source fidelity, independently parsed displayed stage checks, finite-domain variety, mutation checks and real engine selection grading. Preview: `.venv/bin/python generate/scratch/17592186172130.py --difficulty all --seed 4 --count 2 --format markdown`.

API exposes generate_easy/moderate/hard and generate(level,seed,template,field_type,parameters,profile). Supported field selectors are radio or :answer-field.type/radio. Normal defaults sample every observed family using complete authored method banks. Explicit observed profiles replay all captured field banks and missing refs, preserve raw teaching errors and are marked evidence-only. Read classification.md for five anomalous sources and the one ungradable raw legacy fixture.

The inventory publisher is `replenish.py`. It reuses the application EDB integration and contributor, takes `api.lock`, refreshes inventory and source evidence, saves exact requests, and verifies additive commits at their receipt basis. `--prepare-only` validates and saves questions without publishing them. The generator itself does not write to EDB. No engine changes or asset rendering are needed. basis1356 source.json and topic/lesson wrappers retain capture provenance. Hard is an authored same-method extension, not an observed label. validation.json records actual dependency versions and mathematical/native counts.

The live-source refresh is retained under `reference/replenishment/basis-*/source-refresh.json`. Publication requests and verified receipts are retained in the same reference directory.
