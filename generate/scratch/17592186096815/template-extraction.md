## 2. Generalized pattern

Identify the perpendicular relationship from the given directions. Compute |a+b|=sqrt(A²+B²), then normalize by multiplying a+b by its reciprocal. No coordinate conversion, diagram reading, angle evaluation, or vector subtraction is assessed. The full response criterion is unit AND parallel; both ±1/|a+b| would qualify if offered. Exactly one option qualifies in each complete source bank.

## 3. Components and complete profiles

`bank-mapping.json` maps every one of10 original choices to its exact text, independently parsed scalar, source field, and evidence recipe. All ten replay exactly at source parameters. The numeric wrong options underdetermine their original authoring operations. They are not described as recovered errors.

The complete cardinal evidence bank scales each original denominator by new_norm/5; the complete compass evidence bank scales each denominator by new_norm/sqrt569. Those are explicitly authored similarity recipes for preserving opaque evidence expressions under parameter changes. They are parameterized, not literal answer lookup branches, but are never eligible learning banks. Both raw and inferred versions carry `evidence_only:true`, `eligible_for_learning:false`.

Normal authored bank: reciprocals of sqrt(A²+B²), A+B, A²+B², A, B times(a+b). These represent correct normalization, adding magnitudes, omitting the square root, and normalizing by just one summand's magnitude. The bank is selected whole; unequal positive magnitudes and collision/response-criterion checks reject the whole instance if any member fails. No random unrelated perturbation or pooled first-valid selection is used. No diagnosis appears in learner choices.

## 4. Reusable masks and conditions

Complete slots hold positive integer magnitudes and full direction phrases. Cardinal prompt slots preserve `has magnitude`; compass slots preserve magnitude-bar notation. Calculator wording is fixed. Evidence solution/rating/designation omissions are fixed structural components. `observed_*_raw` replays every absent attribute through the public generate API. `observed_*_inferred` adds only the mathematically supported correct lookup reference; it leaves the rating and solution absent and labels inference separately.

Normal generated solutions are authored using the canonical common wording and full formal normalization, formal Pythagorean relation, substituted squares, individually evaluated squares, sum, magnitude-root, and normalization stages. Canonical malformed LaTeX and its diagram are retained only in raw source evidence; no verbatim practice solution fidelity is claimed because neither practice solution exists. There is one fixed solution independent of selected error.

Native testing uses the inferred evidence fixtures and authored eligible banks; raw missing-key records are deliberately unsupported by the grader harness. Source widget field type, key, count, fragments, and calculator instruction are preserved.
