# Parallel-line standard-form generator

`python3 generate/scratch/17592186175912.py --difficulty easy --count 5 --seed 1913 --format json` supports easy and moderate. Each level has 17 bounded lines; original-task exclusion leaves 16 per level before learner consumption. Hard is unsupported and unfilled.

`validate.py` checks both exact source prompt/field replays, all 34 mathematical variants, deterministic identities, boundaries and 374 native grading checks. New prompts explicitly normalize the two blank sides. Source answers, solutions and ratings are absent; these additions are authored. The original database records are preserved.

`replenish.py` rechecks native inventory under application api.lock, recovers exact pending requests, prepares additive transactions, previews with deployed native validation, retains complete intents and verifies scoped datoms/readback at the receipt basis. Evidence lives under reference/replenishment. Future calls exclude every existing line and report finite exhaustion rather than duplicate tasks.
