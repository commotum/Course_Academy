# Plot extraction and generation

1. Every original raster was opened in the native source image set; source-plots.png displays canonical plus all practice prompt/solution rasters. All show a blue unit circle centred at axis intersection, black axes with positive arrowheads, faint square grid at integer increments, labels −1 and 1 on both axes, black origin-to-P radius ending in a black point, first-quadrant yellow theta wedge measured counterclockwise from positive x, theta label outside wedge. Prompt label is P; solution label is P(cosθ,sinθ). There are no further marked branches or answer plots.

2. The diagram supplies QI sign and coordinate-to-central-angle relationship. This makes its plot rating heavy under docs3, despite simple construction. It is mathematically parameter-dependent; an unchanged source image cannot illustrate a moved P.

3. Circle is x²+y²=1, axes −2..2; meaningful ±1 ticks and labels retained. Radius endpoint is (known,missing) for x-given or (missing,known) for y-given. Angle is atan2(y,x). Solution labels identify coordinates symbolically, not a separately resampled value. Exact source anchors retain their native image paths byte-for-byte. Native raster sizes/hashes and expected QI endpoints are retained in raster-geometry.json. These raster checks establish approximate source placement within a five-pixel stroke allowance, not exact coordinate recovery from the pixels. Normal plot coordinates are derived exactly from the given ratio before numerical rendering.

4. Matplotlib programmatically creates changed prompts and solution figures from exact instance values, then converts to floats for drawing only. Equal scaling, fixed unit circle, positive directions, per-instance radius, P, wedge, theta and semantic labels are required. Label offsets keep them clear of point/line; domain 0.14≤known≤0.97 avoids degenerate slopes. Circle/axes/grid/colors are fixed. Per-role per-instance PNG+JSON sidecars record renderer version, exact point and PNG hash. Unique temporary files and atomic renames avoid mixed-instance concurrency. A per-process lock protects Matplotlib’s shared mathtext parser during concurrent thread calls. No SVG or image-generation model is used. Generated montage was visually inspected for both axes, all levels, and steep/shallow angle positions.
