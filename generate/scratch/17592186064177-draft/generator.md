# Implementation and reproduction

`../17592186064177-draft.py` is an unregistered local candidate. Its registered numeric predecessor and entire associated tree are immutable. `numeric-baseline.json` records the full original file pathset and SHA-256 map before any imports; validation compares both the pathset and every hash. No module from that tree is imported.

The draft uses seeded Python randomness and exact SymPy arithmetic. Public `generate(difficulty, seed=0, template=None, parameters=None, bank_profile=None)` returns the existing question/answer-field/answer representation plus separate metadata. All values are delimiter-free bare TeX; prose is normalized before stable IDs are calculated. `batch` rejects bool/float seed/count values and duplicate task IDs, returns count per difficulty for `all`, and allows zero count. The CLI accepts `--difficulty easy|moderate|hard|all --count N --seed N --format json|markdown` plus optional `--output`.

Run `.venv/bin/python generate/scratch/17592186064177-draft/validate.py` from the repository root. Validation checks lossless raw source replay, exact mathematical one-to-one option coverage, complete-bank designation, all bounded source base values, authored profiles at boundaries and interior values, actual rendered formal integral operands and coefficients, every solution equality and primitive, C ownership, both real domain intervals, task/content identity, strict inputs, deterministic replay, corruption controls and unchanged registered artifacts. It uses private frozen copies `private_reader.py` and `math_format.py` and never imports the registered generator or its cache. Shared engine, formatter, registration, database and run QA files remain unchanged.

Native grading uses the existing frozen `generate/runs/current/check-engine` interface through `course_academy_engine::learning::grade_field`. Full fixture input is retained in `engine-input.json`. Fixtures run separately so a mathematically valid grading gap can be recorded without hiding other checks. Blank fixtures submit the stored primitive, a genuinely uncollected equivalent primitive and an expression with a wrong derivative. Native gaps are qualified failures in `engine-report.json` and `validation.json`, not relabeled successes or removed variants. Raw exact sources and authored normal completions have separate evidence files.

`freeze.json` recursively hashes the entire draft tree, including private dependencies, evidence and existing caches, plus the script; only `freeze.json` itself is excluded. Its engine hash identifies the actual native grader. Regenerate the freeze after any changes or imports that alter included files.
