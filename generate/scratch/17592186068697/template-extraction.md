## 4. Reusable template

Easy slots are a horizontal graph translation h in integers [-4,4], applied to every entire asked coordinate, function input, one-sided approach, marker and asymptote. Shape and labelled ordinates stay fixed because their algebraic formulas are not supplied. At h=0 raw observed replay uses the exact original raster; changed h uses calibrated red-stroke trace via Matplotlib. Normal output preserves original worked prose/sequence. A fixed solution is independent of answer selection. Observed source profiles retain original five-subset banks; fieldless normal q-48063 uses explicitly authored five-subset completion.

Authored numerical slots: moderate target ±1/2 or ±3/2, bounded integer labelled ordinates; hole requires equal limits with no value, displaced requires distinct value, jump requires unequal limits and assigned value. Hard target noninteger quarter, |a|<=2, second b=a±1; at least one side infinite, finite ordinates and assigned value integer [-4,4], and second neighborhood either ordinary or an open hole. No progression within a level. Whole semantic subset profile is selected from topology before numerical sampling; the independently computed correct designation must agree with that planned profile or the whole instance fails. All pairwise subset equivalence is rejected, including wrong/wrong pairs.

Observed banks are fully defensible categorical recipes: each option denotes precisely its named truth subset. Default easy samples every source family; authored levels select all eligible topologies. Coordinate/grid variants affect the task’s reading demand but do not create additional conceptual criteria. Finite semantic catalog and finite graph-read coordinate counts are reported separately in validation. No claim of unlimited variety.

Decoded-byte audit shows practice prompt strings have no adjacent slash bytes; worked aligned rows contain exactly their intentional TeX row separator pair. There is no inferred doubled-command repair. Canonical nonstandard `\lim_\limits` spelling is preserved in frozen source evidence, not promoted as an escape anomaly.
