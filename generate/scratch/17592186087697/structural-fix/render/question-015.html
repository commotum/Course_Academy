Which of the following are identity matrices?

M=[100010]
N=[1001]
P=[1001]

Select all that apply.

Answer: M
Answer: N
Answer: P
CorrectPreview only
Solution:

Answer: M · correct value:

false

Answer: N · correct value:

true

Answer: P · correct value:

true

  • M is not an identity matrix. It is not a square matrix: it has 2 rows and 3 columns.

  • N is an identity matrix. It is square, every main diagonal entry is one, and every off-diagonal entry is zero.

  • P is an identity matrix. It is square, every main diagonal entry is one, and every off-diagonal entry is zero.

Therefore, only N and P are identity matrices.
