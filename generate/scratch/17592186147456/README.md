# Bernoulli recognition package

Generator: `generate/scratch/17592186147456.py`.
Supported levels: easy, moderate. Hard remains unsupported within the observed
source backbones. No source questions or learner history are altered.

Preview: `.venv/bin/python generate/scratch/17592186147456.py --difficulty easy --seed 11 --output /tmp/bernoulli.json`.
Validate: `.venv/bin/python generate/scratch/17592186147456/validate.py`.
Read-only LaTeX validation requires SymPy 1.14.0 and antlr4-python3-runtime 4.11.1;
the latter is installed at `/tmp/ca-bernoulli-validation`, outside the repository.
The generator itself requires only the repository's existing SymPy dependency.

`replenish.py` rechecks the inventory before generation and again under the
application lock, prepares additive ensured EDN, previews with the deployed
native predicates, saves exact requests, and verifies exact-basis readback.
Saved unknown requests are recovered before any new plan. Receipt checks admit
only additions to new content entities and this KP's pool/generator refs.

The five source-backed component sets and every complete Boolean bank replay
are retained alongside rendered-equation, slot-boundary, native checkbox
grading, deterministic identity, and side-by-side evidence. The bounded scalar
domain is intentionally conservative, with remaining shortages recorded whenever
distinct fresh variants cannot be produced. The configured application source
is `:application/ca-engine`, resolved and verified at preparation basis.
