## 2. Shared visual purpose

Show the complete closed region, traversal arrows and meaningful intercept/extremum scales. Plots support orientation and segment bookkeeping, while the printed parametric equations carry exact geometry. Moderate rating because every instance needs a plot but construction is one/two known plane segments.

## 3. Components

White background, black arrowed x/y axes through origin; nonzero feature ticks, no zero label; orange curve C orC1; pink C2; black traversal arrows following increasing parameter; labels C,C1,C2,D; pale-blue enclosed area. ## 4. Parameterized renderer

Matplotlib samples each exact segment at601 monotonically increasing parameter values. Filled boundary concatenates the same segments. Closing endpoints must meet symbolically. Curve arrows use fractions .18,.42,.68,.87 for one segment, .12,.88 on a polynomial curve and .27,.74 on its closing segment; moving the curve arrows away from the cusp keeps black arrowheads clear of the axes under thin aspect ratios. Bounds derive from coordinate extrema, with padding; tick labels round the exact integer extrema rather than truncate floating-point samples. Equal axis scale prevents distorted geometry. Canvas width/height adapt to the true aspect ratio, while C/C1/C2/D labels occupy a reserved figure-space column with thin grey leaders to actual curve/region anchors. Axis titles use fixed screen offsets above their arrow tips; signed feature tick labels face outward, clear of closing segments. Actual text pixel boxes are checked pairwise and against every tick/axis title, with clipping assertions; sidecars record those boxes, anchor pixels, canvas dimensions and x/y pixels per coordinate unit. The four parent-found collisions and a1b8/a8b1 across every family are in plot-regressions.json and plot-review.md. Ellipse a1/b8 and a8/b1 are renderer stress tests outside the authored easy bank domain; supported easy extremes2/8 and8/2 remain separately tested. Reproduce the mathematical geometry/traversal, not incidental source typography. Earlier cached assets are preserved; v8 paths provide an independent updated cache namespace. Leader lines are shortest pixel-space polylines routed around measured text rectangles with3px clearance, so neither callout text nor axis/tick text can be crossed. Sidecars retain each leader path and every text rectangle for independent segment-intersection validation. Fresh writes use private unique temporaryPNG/JSON files, atomic final replacements and a renderer lock around Matplotlib thread-unsafe state. Cache hits require bothPNG and itsJSON sidecar. NoSVG or image models. All plot files are local draft artifacts; original-image refs preserved only in anchor raw evidence.
