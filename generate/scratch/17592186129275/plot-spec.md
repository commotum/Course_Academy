# Plot extraction and specification

1. Specific originals: all24 figures (21 practice solution assets and3 canonical assets) were inspected at their native360×304 dimensions in `original-contact.png`; transparent backgrounds were composited on white. Each has black Cartesian axes with arrowheads, blue disk/semidisk boundary, pale-blue fill, region label D and radius/center coordinate marks. The second image adds a pink origin-to-boundary radial arrow, with 0≤r≤trigonometric boundary. The third adds a gold angular arc/arrow and angular bounds. Disks lie above, right, lower right, upper right half, lower left half, upper left half, or below as dictated by each source. The source expdiff angular figure uses −π/2≤θ≤0, while the later region/answer uses the equivalent3π/2≤θ≤2π; this periodic notation difference is preserved in source replay.
2. Shared pattern: a disk tangent at the origin is converted to a radial trig limit and a half- or quarter-turn angular interval. No option plot exists.
3. Components: axes and arrowheads, exact center/radius, circle arc, straight cut boundary for halves, ticks at a and2a on the center axis, D interior label; radial arrow at an interior eligible angle; angular arc from actual lower to upper angle. Parameter variations change every numeric label and coordinate consistently.
4. Reusable specification: Matplotlib Agg, equal aspect, 4.8×4.1in,130dpi, white background, source blue/pink/gold colors. Bounds derive from the actual trig radial curve plus0.65a padding. Paths hash complete geometry and renderer version. Each PNG has a sidecar containing the exact render input and runtime versions. Unique temporary input/output files and atomic final writes prevent concurrent mixes. Cache hits require both PNG and sidecar. Reuse original PNGs only at the exact original radius/orientation; other questions recreate all three images. No direct SVG is generated.

The canonical region SVG `14df7999…svg` was inspected/decoded by its MathJax `data-mml-node` structure and glyph data: **D={(x,y):x²+(y+2)²≤4}**. The integral SVG `00986541…svg` contains a double integral with subscript D and `msup(e,msqrt(x²+y²))`: **∬D exp(√(x²+y²)) dA**. Thus the canonical example is a full disk of radius2 centered at(0,−2), with radial upper bound−4sinθ and π≤θ≤2π. These two standalone formula assets do not contribute to plot ratings.

The renderer uses an already-cached Python3.10/Matplotlib3.10.9 dependency fallback, read-only; no installation or shared environment writes. Dependency configuration is in `render.py`. Full source asset paths and dimensions are recorded in `assets.json` and the contact sheet labels. Generated images and exact inputs are under `plots/`; a changed-geometry contact sheet is reviewed before freezing.
