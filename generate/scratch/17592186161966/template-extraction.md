# Column-zero template

For a nonsingular pivot entry A[r,p], use k[c] = -A[r,c]/A[r,p] in C[c] := C[c] + k[c] C[p] for each of the three c != p. Provide A and its resulting B and one of those operations; ask for the other two as one five-choice radio response. The common pivot column is unchanged. Compute the correct pair before selecting the complete source profile, then reject equivalent, duplicate or ambiguous banks. Source-specific sign changes, coefficient swaps, unit-coefficient replacements, and explicit affine offsets are the exact recipes in `recipes`; affine offsets retain the observed numerical pattern without asserting an unverified misconception.

Fixed: matrix shape, operation type, three steps in ascending nonpivot column order, one given/two missing contract, five choices, all four intermediate matrices and concluding pair. Variable: all entries of A, row r (0..3), pivot p (0..3), given column (any c != p), signs and integer operation coefficients. B, each stage, target columns, answer pair, bank values and prose references are derived from these same parameters. Changing the given position changes the requested pair, preserving roles and workload. No extra operations, fields or solution stages are introduced.

Observed parameters, complete original strings, original choice indices, recipe expressions and exact values are in source-components.json. Replay compares entire column assignments, not just bare coefficients. Original notation is normalized only for comparison; generated notation consistently uses C indices and integer matrices. The unrated q-91208 bank is replayed as evidence, excluded from normal generation. q-42563's duplicate fields are preserved in evidence, while generated questions use its complete valid field. q-91210's initial-matrix typo is corrected with the calculation in classification.md.

Sampling is a conservative bounded same-method generalization: nonpivot operation coefficients in +/-1..5; pivot +/-1 or +/-2; other entries -9..9; target-row entries equal -k[c] times pivot, hence bounded by 10 in magnitude. Exactly one eligible zeroed row is required. All 48 row/pivot/given-role combinations, all ten complete supported profiles, 600 normal samples, original replay and ten changed-given tests with A held constant were checked. A stale worked-solution mutation must fail. Dependency version, seed, complete parameters, profile and semantic fingerprint accompany each instance. Seeds and choice ordering do not define distinctness; the rendered A/B and supplied operation do.

Solution wording preserves the source's ordered stages: identify the pivot and desired zeros; introduce elementary operations; show initial A and each of the three resulting matrices; identify B; conclude with the missing pair. Generated layouts use labeled arrows instead of the source's alignment columns; this presentation difference is explicitly reviewed in review.md. No plot generation or publishing is applicable.
