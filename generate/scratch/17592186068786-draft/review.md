# Local review

See review.json for each complete original full Pull, its served anchor and a genuine b=12 variant. Every source prompt, complete bank, correct designation and worked solution replays exactly. Normal generation uses the same source masks at changed parameters; raw evidence is never used as a shortcut for served rendering.

The displayed-math validator reads all original-variable and u-variable formal integrands, u/du, differential scaling, every ordered primitive row and final expression, and every choice derivative. Pairwise derivative-family equality modulo C detects collisions between incorrect choices as well as correct/wrong ambiguity. Required unsimplified factorization/coefficient rows are checked structurally in addition to algebraic equality. Mutation regressions alter an intermediate coefficient, delete an algebraically equivalent source stage, change a formal u operand and inject a control character.

Native grading uses only the frozen check-engine binary. Radio choices are selected by identity. Canonical mathematical text, an equivalent primitive text and an ordinary wrong text are separately unresolved by the actual radio contract; foreign identities and malformed submissions have their distinct native reasons in native-grading.json. No mathematical-text acceptance claim is made for radio fields.

Private pinned formatter and parser are loaded by exact file paths, with no mutable shared helper imports. All bounded instances are checked; count overflow raises rather than returning duplicates. Batch novelty is the rendered formal mathematical task and supplied-information role, not option order. Seeds/counts/option seeds require built-in int, typed b excludes booleans, and metadata replay reproduces exact output independently of option shuffle.

Registered numeric script and the complete original evidence directory path/hash set, including preexisting __pycache__, are preserved in baseline-preservation.json. No database writes, registration, shared QA/queue/engine edits or commits are performed. Root independent review is required before any further lifecycle action.
