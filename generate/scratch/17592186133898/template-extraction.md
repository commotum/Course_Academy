# Scalar curl template extraction

Each complete source template retains its own supplied P and Q structures, evaluation point if present, radio selection field and five mathematical choices. The backbone is Q_x − P_y, followed by substitution only for moderate point-evaluation templates. Its instructional purpose is to hold the other coordinate constant, differentiate the correct components, subtract in the correct order, and evaluate when requested.

`source-components.json` describes every complete source specifically: exact P, Q, target point, real-domain restriction, all source answer identities, complete mathematical expressions and explicit parameter recipes. `source-fidelity.json` records every original option match, full bank, correct designation and separate prompt/solution fidelity. `source.json` retains all 16 originals, including excluded incomplete examples.

The only sampled slot is a common positive integer c on the complete vector field: c=1 is the observed parameter for exact replay; c∈{2,…,9} is a conservative same-method generalization. Multiplication by a constant preserves the derivative method, domain and point, while changing each assessed partial and curl. This narrow policy introduces no new functions, products between components, operators, answer shapes or reasoning stages. Other coefficients, functions and evaluation coordinates are fixed to preserve the specific local method and source difficulty; variation beyond uniform scaling is not claimed by this version. This gives 48 easy and 56 moderate distinct candidate tasks before subtracting current/previously served content.

Correct answers are computed first from exact symbolic partials. Every source option has the explicit recipe c times its complete source expression, including altered constants and compound expressions. Profiles are selected as complete five-option banks before rendering. No recipes are pooled. The underlying error interpretation is unresolved for arbitrary distractors; the observed expression pattern is retained instead. Nonzero c preserves all bank distinctions and correct designations. New answer values normalize captured doubled backslashes and literal function-application markers; originals remain intact. Mathematical source replay matches 52/52 distractors and 13/13 complete banks.

Prompt RHS, every formal derivative input and every subsequent worked-solution RHS derive from the same c. The source's explanatory prose and ordered calculation stages are preserved. Constants wrap complete expressions, not independently selected terms. No feedback is added. Radio field key `selection` and source choice count are retained; each new answer UUID is owned by its field. A seed changes candidate selection, never the identity of an already authored mathematical task.

Variable-slot validation covers every c at every supported template. Review pairs use c=2 and c=9 with source point and all other mathematical data held fixed; the independent reader checks prompt components, formal derivative inputs, every solution row and the exact full bank, catching stale references. `review.md` and `review.json` retain these comparisons. All 104 candidates pass actual radio grading for every correct and incorrect option. Context-dependent blanks and incomplete unrated questions are evidence-only exclusions, with no generated replacement or mutation.
