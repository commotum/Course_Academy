# General linear identity parameter generator

Local generator only; no EDB writes, registration or engine edits. Captured source provenance is math basis 1356. Easy and moderate preserve observed mathematical workloads; hard is a documented authored extension of the same independent coefficient/constant matching skill.

```sh
.venv/bin/python generate/scratch/17592186110721/validate.py
.venv/bin/python generate/scratch/17592186110721.py --difficulty all --seed 12 --count 2 --format markdown
```

Python API: `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` and `generate_easy`, `generate_moderate`, `generate_hard`. Parameters are a six-entry exact list or a dict with `a,b,c,d,e,f`. See `source-cases.json` for seven public explicit raw source replays. `raw:<source-id>` profiles preserve original missing attributes and are ineligible for normal practice. Normal radio banks are authored method-operation banks; `method-components` is available only for hard. Set `field_type='blank', profile='blank'` for native blank grading, or `field_type='radio', profile='method-sum'` for radio overrides.

Validation independently reads the displayed equation and solution, audits all source prompt/solution strings and banks, tests level bounds and collisions, verifies deterministic identities, and invokes the actual memory-only learning grader. Results and native binary hash are in `validation.json`; originals and labeled variants are in `review.md` and `review.json`. Two missing source correct designations/solutions and the absence of observed hard labels remain explicit limitations.

Historical replenishment code and prior previews are retained under `reference/prior-attempt-root-files/`; they are outside this basis1356 generator and its QA. This rebuild stops after step7.
