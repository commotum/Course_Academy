## 4. Reusable masks, bounds and scope

`observed_parts` extracts the source heading, whole RHS component slots, common definition/introduction and complete per-function explanation blocks, then fills coefficient, name and order slots and recomputes every subset label. It does not return a literal source payload; changed coefficients/names/order go through the same public generate API. Sources preserve Unicode function application and their original math spelling in raw replay. Normal source generation preserves that same wording/sequence except the three supported scalar-prose corrections and seven outer-set-brace presentation normalizations documented in classification.md.

The authored bank is the correct categorical mask c plus c XOR 1, c XOR 2, c XOR 4 and c XOR 7: misclassifying only I, only II, only III, or all three. These four complete wrong subsets are always distinct and never correct. There is one shared worked solution independent of the chosen error; no distractor-specific explanation is invented.

Easy authored catalog: each candidate is one of (3,3), (2,2), (1,3); 27 ordered signatures. Observed families and their six orders expand the union to 51 meaningful easy signatures. Moderate: every function declares x,y,z; outputs are scalar, pairs or triples, with at least one pair output, giving 19 signatures. This prevents the all-triple instance from collapsing into the authored easy family. Hard: every output is a triple depending on only one variable, so the declared input signature—not the number of used variables—must be read; at least one input triple and at least one nontriple are required, giving 18 signatures. These are explicit missing-level design claims. Source examples already introduce the ingredients; the lesson route and prerequisite vector/multivariable-function concepts support them, without a new method or internal progression. The catalogs represent unordered same-workload alternatives within each level.

The two-dimensional sibling and domain-finding sibling establish boundaries, not additional generation branches.

Semantic fingerprints are ordered dimension pairs.
