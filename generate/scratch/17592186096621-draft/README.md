# Private quotient-functions draft

Run from the repository root with `.venv/bin/python -B`.

```sh
.venv/bin/python -B generate/scratch/17592186096621-draft.py --difficulty all --count 3 --seed 19
.venv/bin/python -B generate/scratch/17592186096621-draft/validate.py
.venv/bin/python -B generate/scratch/17592186096621-draft/sample_validation.py
.venv/bin/python -B generate/scratch/17592186096621-draft/evidence.py inventory
.venv/bin/python -B generate/scratch/17592186096621-draft/evidence.py probes
.venv/bin/python -B generate/scratch/17592186096621-draft/evidence.py native
```

`generate(level, seed, template, parameters, bank_profile)` serves repaired source-shaped rows. `replay_raw(source_id)` is a separate public evidence-only path that preserves exact attribute presence and omissions. Both field and question IDs use the complete rendered prompt, source-shaped solution, field shape, complete unordered bank and key. Mathematical task dedup instead uses the actual original quotient plus its original domain and target, independent of seed, bank, and option order.

The frozen parser/formatter and family chains load explicitly by this private path. No registered-generator import, live capture-module import, database read/write, registration, engine change, or git mutation occurs. `registered-baseline.json` captured every full path and SHA in the numeric registered script and entire evidence/cache tree before any generator import. `freeze.json` verifies the final private pair and the untouched baseline.

Review `review.md` and `review.json`: each of 15 MA families has its original/repaired anchor and two changed scales; hard has three authored variants. `validation.json`, `source-fidelity.json`, mutation/domain reports, and `native-report.json` separate mathematical validation, fidelity, and actual grader behavior. The native report retains legitimate unsupported-equivalence gaps and separately labels owned answer IDs, foreign numeric IDs, and malformed selections. Neither a grader limitation nor a poor distractor is used to prune valid source parameters.
