# Template generator (doc 6)

The draft loads only private copies of the formatting implementation and immutable template JSON. Exact SymPy rationals derive authored primitives and all dependent rows. Source banks are parameterized complete-expression masks; original and genuinely changed affine factors go through the same public `generate` API. The sampler uses finite, typed, bounded domains. Built-in integer seeds/counts/tuple components are required; booleans and implicit numeric coercion are rejected. Independent SHA-derived option RNG keeps the selected correct field-owned ID stable.

Replay uses `generate(level, seed, template=case.template, profile=case.profile, parameters=case.parameters)`; the `generation` metadata explicitly records all replay inputs, domain, version, provenance and role. `generate_easy`, `generate_moderate`, `generate_hard` and `batch` expose the same contracts. CLI `--difficulty all --count 3` returns a flat nine-record array.

`validate.py` reads the actual displayed integral, u definition, du/dx, dx, every integration row and every derivative-check operand, and all five choices. It computes exact values independently using a private fail-closed expression parser. For authored rows it additionally checks ordered unevaluated formal operands and chain-rule factors. For observed rows it compares the entire normalized source solution and full changed-parameter masks, preserving source-specific row order. A copied, SHA-checked native engine binary grades every selected field-owned choice and reports canonical/equivalent math-text submissions as malformed transport under the radio contract (separate from valid-math unresolved limits). There is no blank-field contract here. Source bank fidelity and mathematical correctness have separate counts.

`q-12499-raw` is an explicitly marked ambiguous evidence profile; its absent correct designation and solution are authored for the review fixture. It reproduces all five source mathematical values one-to-one, while `q-12499` is the separate narrow normal repair. Raw evidence must never be treated as a normal unambiguous bank.
