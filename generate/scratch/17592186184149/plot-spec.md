# Plot extraction and renderer

1. **Individual descriptions.** Every one of the 46 referenced PNGs was read individually at original resolution: 18 canonical images (two graphs, sixteen math glyphs), and fourteen prompt/solution graph pairs. Transparent images were composited on white for inspection without changing geometry. `assets.json`, `inspection/{index}.png`, and `source-plot-inspection.json` identify each by source, role and original dimensions. Each graph's own black origin, grey pole positions, blue zero and monotonic branch samples are read from its actual pixels, with independent origin/scale calibration. Source ordinate scales are unlabelled; no quantitative y-tick claim is made.

2. **Common pattern.** The prompt contains a solid blue single increasing tangent or decreasing cotangent branch, black x/y axes with arrowheads, grey dashed vertical asymptotes, exact π-fraction labels for poles and the zero. Solutions add a dashed blue unstretched-in-phase baseline at the given horizontal coefficient B and labels identifying the two functions. The original comparison has precisely the same sign and displacement as its prompt. Canonical mathematical glyphs read y=tan(2x+C), -π/2<C<π/2, factor x+C/2, displacement π/8, and C=-π/4.

3. **Components.** For tangent, the selected branch has zero z=-C/B and poles z±π/(2B). For cotangent, the selected branch has zero z=π/(2B)-C/B and the same pole formula. Baseline zero z0 is respectively 0 or π/(2B). Domain endpoints are excluded. Tangent increases, cotangent decreases. Both original source graph branches have blue tails toward the poles. The arrows belong to the black axes, not invented endpoints. Curve drawing cannot connect across excluded poles.

4. **Reusable specification.** render.py uses exact rational inputs converted to floating point solely for rendering; no resampling. Bounds include the selected branch, the origin, and the baseline branch when shown. Curve samples terminate at |y|=3.4, inside axes limits ±3.7; no paths cross poles. The two pole guides are grey dashed; zero and pole ticks carry exact coordinate labels. Comparison overlays the baseline as a dashed blue branch, while the shifted curve remains solid. Easy prompts also show the baseline, moderate/hard prompts show only the shifted graph. Equations are exterior top labels; coordinate calibrations occupy an exterior bottom strip. Close coordinate labels stagger vertically; expanded actual label bounding boxes reject collisions, and actual label-to-curve clearance exceeds 10 px. No white masks hide curve features. This strip differs incidentally from the source's under-axis labels, preserving the exact assessed coordinates and visibility.

New plots are needed whenever meaningful geometry changes. Exact source plots are reused only for faithful parameter replay; changed observed parameters use the same renderer as normal output. Each plot has its own atomic PNG/JSON sidecar. Pixel QA reads actual blue pixels around four independently evaluated curve points and grey pixels at both asymptotes. Renderer Python/Matplotlib versions and read-only cached dependency paths are recorded. Fresh concurrent identical/different parameter calls exercise unique inputs and atomic output behavior. No image models or SVG assets are used.
