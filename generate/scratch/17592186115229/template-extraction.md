# Matrix-power extraction

The assessed method is repeated row-by-column multiplication of a square integer matrix. The input matrix, requested power, output cell roles, field keys, matrix letter, and ordered multiplication stages define each profile. Exact originals, matrix entries, choice values, field IDs, designated correct values and solutions are in source-components.json; source.json/source.edn preserve all original facts.

Supported profiles are the nine complete blank sources. A 2x2 square uses one multiplication and four row-major blanks. A cube first computes M² then M²M. A fourth power first computes M² then M²M². A 3x3 square computes one product and asks for five cells; all supplied cells must be computed from the same instance. q-279444, q-279446 and q-279448 preserve their observed target masks as separate selectable profiles. Masks select output entries, not new operations. No distractors or feedback are added to blanks. Canonical answers are delimiter-free integer strings, with one field-owned answer per blank.

Source prompt wording, HTML/Markdown layouts, notation, and every solution sentence remain literal templates. Only complete matrix expressions and the supplied partial-result cells change. The matrix letter and power remain fixed inside a source profile because each source selects a corresponding solution sequence. Moderate cube/fourth-power profiles are not merged. Radio banks are captured individually and excluded from this generator; their observed cellwise deltas reproduce the original numerical options but are not asserted as inferred error recipes.

All input nonzero entries are numerical slots. Normal sampling uses nonzero integers -4 through 5, preserves observed zero cells as a conservative sparsity policy, bounds result entries to magnitude 1000, and excludes zero-square and idempotent results. q-279430 retains trace zero to preserve its observed scalar-square shortcut. Other nonzero entries vary independently. Signed source values and every original matrix are retained for exact replay. These are narrower sampling policies, not claims that the original zeros or literal letters are essential to the method. Explicit replay parameters use integer entries -5 through 5. No continuous domain, branching, division, or singular-matrix restriction is involved in positive integer matrix powers.

Every answer, supplied result entry, and matrix in each solution is derived from one matrix and its requested power. Validation independently reads displayed row/column entries and recomputes products with Python integer dot products, checks all displayed intermediate matrices, field positions and supplied cells, then tests actual learner grading. Profile coverage includes all numerical slots and all three observed target masks. Original-to-variant side-by-side review is in review.md. Source replay must exactly match complete supported banks and correct values, prompts, and solutions.

No plot extraction/generation is needed: there are no assets. Hard is unsupported in version 1: sources supply no hard backbone. Deferring radio generation is a bounded response-format capability exception, not a claim that radio questions are mathematically impossible. Source questions and learner history are not repaired or replaced.
