# Plot evidence and renderer

reference/assets.json maps all 13 original images (12 practice plus canonical) to their exact source references, local copies and question IDs. Original MA images use gray square unit grids, black axes/positive arrowheads and italic A/B/C labels beside red points; non-MA images use equivalent point-only grids with ordinary labels and integer ticks. Original source image dimensions and hashes are recorded separately. No prompt contains a drawn target line; no answer or worked-solution plot is required. The plot is central to every task, rating heavy.

Read coordinates: canonical A(0,5),B(2,1),C(3,0); q-22405 A(2,7),B(4,5),C(7,2); q-44504 A(-6,5),B(1,5),C(6,5); q-71829 A(-1,-2),B(0,1),C(1,6); q-102142 A(0,5),B(1,2),C(2,-4). The eight non-MA coordinate sets are explicitly retained in classification.json and were checked against source-contact.png. All source points and keys agree.

Normal variants use Matplotlib on a 5-inch square canvas at 120 dpi, equal axis units, gray integer grid, zero-crossing black axes with positive arrowheads, red markers at zorder 5 (including on axes), and readable A/B/C labels with white backing. Points, labels, bounds and grid derive from the exact same parameter instance; no independent plot sampling. x coordinates are ordered in normal sampling. Bounds include every point and the origin with margins. Integer ticks, upper axis-label placement and plot proportions are visual modernizations of the sources with the same instructional purpose. Exact original replays reuse exact original assets.

Every new plot has a reproducible parameter/render-revision hash filename and a rendering sidecar recording bounds, marker coordinates, label pixel boxes and renderer versions. Label boxes must fit the canvas. Independent PNG readback infers the axes and gray-grid unit spacing from pixels and reads all three red-marker centers, comparing them to the coordinates read from actual worked prose; it does not trust the sidecar. A stale-plot negative control keeps the final key/solution correct and must fail that pixel check. Source/normal screenshots are checked for readable labels, clipping, equal scales and no drawn answer line.
