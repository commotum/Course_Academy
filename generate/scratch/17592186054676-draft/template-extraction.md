# Template extraction and slots

At original parameters, all 12 records replay their exact original prompt, worked solution, answer fields, complete banks, keys and IDs. Source-cases.json contains only these original wrappers. The formatter normalizes enum/reference representation without inventing omitted attributes. The 62 observed choice values, including 16 complete field banks, are mapped in choice-ledger.json. Full raw evidence remains source.json.

The E/M backbone is: read three distinct labeled integer grid points; supply y=mx+b; test A, B and C by substituting both coordinates; compare the resulting equality; state each membership; select the exact subset in one five-choice radio field. Fixed method: substitution into the supplied line; three points; three equation rows per point; shared explanatory sentences; final subset. Variable numeric slots: easy m in {1,2,3,4}, moderate m in {-2,-3,-4,-5}, b in -4..6, three distinct x coordinates in -4..4, nonmember integer vertical deviations of magnitude 1/2, all displayed y coordinates in -10..10. Explicit source replay retains all source values. Independent numeric slots do not depend on a hardcoded target label.

Variable role slots: the easy source has two member roles and one nonmember role; moderate has one member and two nonmember roles. Choose one complete source-bank role permutation before sampling numbers. Map every source option as a complete label-subset object through that same bijection. The three member-subset possibilities AB/AC/BC (easy) or A/B/C (moderate) are eligible and have the same arithmetic method/workload. Labels stay in left-to-right x order in normal plots; changing the member role changes actual y coordinates rather than cosmetically relabeling an unchanged question. Each reference in summary, substitution operand, result, truth marker, per-point conclusion, bank/key and final subset derives from those roles. Retaining original AC/C merely because examples repeat it would be unjustified.

Source whole-bank profile E is {AC,A,B,C,BC}; M is {AC,C,AB,B,A}. Selecting a profile plus bijection selects all five options before coefficients. An option recipe is a selected subset of original roles, not a guessed numeric error. Each profile is reproduced completely, and the full subset objects must be distinct with exactly one mathematically correct option. The validator exercises all six permutations independently. A template ID chooses source wording, never a pooled distractor list. The eight captured non-MA rows remain independent source inventory and have their own explicit original replay cases.

Authored missing-hard extension: use a nonintegral rational slope with reduced denominator 2 or 3 and numerator from -5..5 excluding zero, integer intercept -4..6 and integer grid coordinates. Keep the moderate source's same three substitution/equality stages and complete radio subset-bank roles. Integer x values for the member point are constrained so its y coordinate is integral; nonmembers remain integral grid points. Fraction arithmetic is the sole added workload. This is a disclosed conservative same-method extension, not observed hard fidelity and not a claim of calibrated Math Academy difficulty. No systems, finding slopes, fitting a line, solving for unknown coordinates, graph construction or new reasoning branch is introduced.

Canonical dedup uses the actual linear equation and unordered supplied coordinate set plus point-membership task, ignoring labels, bank profile, template, IDs, seed and plot path. Normal sampling accepts all valid tasks in that declared domain; no filtering against prior source math is built into the sampler. Batch accepts an explicit optional set of already-seen task hashes. Content UUIDs additionally include the complete bank to prevent different bank objects sharing an identity. Original records retain original IDs. Strict built-in int seed/count guards reject booleans, strings, fractional inputs and invalid or excessive counts; bounded resampling raises on exhaustion. 10000 is a conservative per-level request cap, not an exact capacity theorem.
