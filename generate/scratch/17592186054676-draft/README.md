# Point-line draft review bundle

Run `.venv/bin/python -B generate/scratch/17592186054676-draft.py --difficulty all --count 1 --seed 2275 --format json` for a list of three E/M/H records; `--format markdown` displays prompt, full bank and solution. `generate(level, seed, template, parameters, bank_profile)` permits an exact source replay using its original parameters and `LEVEL-source-bank:ABC`; `replay_raw(source_id)` retains all original source records including difficulty omissions and checkbox fields. Normal E/M/H use radio fields. Hard is an explicitly authored rational-slope extension with source-shaped substitution stages.

`validate.py` independently reads actual printed equations, coordinate summaries, substitution operands, evaluated equalities, truth marks, every per-point/final conclusion and complete mathematical subset banks; it reads normal plot coordinates directly from PNG pixels. It exercises all role profiles, holds numeric line/x slots fixed while changing member positions, and runs ten corruption probes with otherwise-correct final keys where possible. Native grading runs the frozen actual check-engine binary on every original and reviewed choice. Equivalent numeric encodings of each selected choice ID are also accepted. Unsupported literal-label submissions are retained as explicit unresolved contract probes; algebraic free-entry equivalence is inapplicable to these selection-only fields.

`browser_qa.py` renders all source and review records, including all choices and all solution stages, through a frozen copy of the actual player's Markdown, DOMPurify and MathJax pipeline. Full rendered math trees, layout checks and representative full-record screenshots are retained. It needs a local browser/localhost socket. No external page is accessed.

source.json is the exact basis-2275 wrapper. source-cases.json contains original-ID wrappers only; independent-inventory.json contains only the eight captured non-MA records with lineage and string relationship descriptions. Authored variants live in review-cases.json. classification.json preserves all source components; extraction/scope documents explain slots, profiles, source differences and authored H limits.

Registered numeric.py and its entire 143-file tree are immutable. Their initial full-path byte hashes were captured before generator imports in reference/registered-baseline.json; validation checks both the complete path set and every byte hash. No numeric module is imported. The draft imports only its frozen formatter, source wrapper and installed dependencies. The actual engine binary/source and UI pipeline are frozen privately; no shared engine, registry, queue, database or source changes occur. freeze.py records the whole owned tree and generator, excluding only the hash manifest itself.
