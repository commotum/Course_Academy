Run from repository root:

```sh
.venv/bin/python generate/scratch/17592186129267/validate.py
.venv/bin/python generate/scratch/17592186129267.py --difficulty all --seed 100 --count 2 --format json
```

Public API: `generate(level,seed=0,template=None,field_type=None,parameters=None,profile=None)`, plus easy/moderate/hard wrappers. Only radio fields. Profiles `observed:q-id` replay complete captured fields/omissions and are evidence-only; `source:q-id` uses complete observed mathematical banks with corrected normal presentation, rejecting scalar-equivalent options; `authored:method` uses a complete bank of Jacobian/radial-bound operations. All observed mathematical families serve normal defaults through their complete source banks; collisions at changed parameters reject the whole instance. Explicit invalid inputs raise rather than resampling.

Eight observed templates; authored hard combines observed operations within the origin-centered-cylinder rewriting KP. No shifted cylinders, evaluation requests, database registration or writes. `validation.json` separates exact strings and field-presence fidelity from source mathematical errors and native choice grading. Parent QA is independent. Complete definite-integral comparisons use exact symbolic inner stages and 30-digit quadrature when a radical radial integral remains; eligibility rejects near-equal/nonreal values conservatively. Mathematical fingerprints exclude bank/profile aliases; presentation identities include difficulty, actual prompt, solution and complete bank. Raw replay retains malformed source bytes and is ineligible.
