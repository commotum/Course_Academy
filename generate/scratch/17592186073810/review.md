Find the shortest distance between the point $(5,-1)$ and the line $y=2.$

- $4$
- $5$
- $1$
- $3$
- $2$

Let's sketch the given situation.

![](images/f9/f907ee8b0bb92792cc69905678210af71088af6731e5a586eaeed0bfc7856b9c.png)

Since the line $y=2$ is a horizontal line, the shortest distance between this line and the point $(5,-1)$ is given by the absolute value of the difference between $y$-coordinate of the point and $2.$ 

So, the shortest distance is

$$
d=|-1-2|=3.
$$
