## Backbone and slots

Supply a nonsingular two-variable linear system. Form its augmented matrix; normalize the first pivot when required; eliminate the first entry in row 2; normalize the second pivot when required. Echelon-only templates stop here. Back-substitution templates then state the reduced system, substitute the second variable into the first equation and give the ordered solution pair. Easy back-substitution has separate operative sequences: q-10522 starts with a unit first pivot and normalizes the second; q-73544 normalizes the first and ends elimination with a unit second pivot. These are separate templates. The fractional-input moderate template retains its fractional coefficient arithmetic and extra subtraction stage. Do not interchange these response contracts.

One radio field named selection has five complete responses, using math for matrices alone and text with inline math for matrices plus x,y. No new feedback or extra fields. Matrices are standalone mathematical notation, so plots and asset publication are unnecessary. Source images in the canonical example are not used in generated practice.

Variable slots h,k are integer offsets -3 through 3. For each original row (a,b,c), use (a,b,c+a*h+b*k). For each original answer matrix, apply the same formula using that option’s own coefficients; for its explicit x,y pair add h,k. Each source bank is transported as a complete bank, never pooled. This is a conservative same-method affine generalization: right-hand sides and solution values change while every row-operation coefficient, pivot and arithmetic stage is retained. Source parameters h=k=0 are replayable. Each incorrect option’s exact source matrix and pair are part of its recipe; apparent mistakes are not replaced with invented recipes.

The sampler intentionally retains the source coefficient matrices. This is a bounded policy, not a claim that coefficients must be fixed. It avoids extrapolating coefficient-dependent arithmetic difficulty or sparsely observed distractor logic. Unknown and pivot roles stay ordered because the standard forward-elimination method assesses those roles; column and option shuffles do not create variants.

Every intermediate solution matrix changes by the same affine map. Problem equations, reduced-system equations, back-substitution statements, result pairs and all five options are tied to one h,k instance. Constraints: original determinant nonzero, both pivots unchanged/nonzero, five distinct complete objects and exactly one valid full response. Zero, positive and negative solutions and offsets are included. No singular-system, inconsistent-system, three-variable, new-operation or hard-level extension is claimed.

Novelty uses the exact solution vector, conservatively treating all systems with the same solution as the same task even if their coefficients differ. Identity includes the rendered prompt and complete authored bank, never seed. The finite domain has 49 variants per profile before cross-profile and existing-content deduplication. Exhaustion must be reported as finite-limit.
