# Parametric derivative generator

Run from repository root:

```sh
.venv/bin/python generate/scratch/17592186083240/validate.py
.venv/bin/python generate/scratch/17592186083240/validate-plots.py
.venv/bin/python generate/scratch/17592186083240.py --difficulty all --seed 31 --count 2 --format json
```

18 frozen practice sources replay through public observed profiles with parameter r=s=1; source-cases.json specifies every anchor. Original profiles are evidence-only. Normal easy/moderate output samples all source-shaped curve families with supplied-t evaluation where present; radios use complete method-derived banks. Hard adds two supported prerequisite-rule combinations. No database writes.

validation.json separates original fidelity, printed mathematics and real learning::grade_field checks. review.md/review.json include every original bank and two generated records per exposed family, including both hard families. classification.md and template-extraction.md document historical-bank interpretation limits, duplicate legacy field, native exact-answer wording limitations and the restricted-parabola plot repair.
