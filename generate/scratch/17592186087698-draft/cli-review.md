Which of the following are row vectors?
$E = \begin{bmatrix}2 & -2 & -2 & 2\end{bmatrix}, F = \begin{bmatrix}2 & 2\end{bmatrix}, G = \begin{bmatrix}2 \\ 1 \\ 0 \\ -3 \\ -3 \\ -3\end{bmatrix}$

selection: $G$ only, $E$ and $F$ only, $E$ only, $F$ only, $E$ and $G$ only

- $E$ is a row vector since it has only one row.

- $F$ is a row vector since it has only one row.

- $G$ is *not* a row vector. It has only one column (and $6$ rows), so it's a column vector.

Therefore, only $E$ and $F$ are row vectors.

Which of the following best describes the following matrix $Q?$

$$
Q=\begin{bmatrix}1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1\end{bmatrix}
$$

selection: A square matrix, A zero matrix, An identity matrix, A row vector, A column vector

The matrix is square, all the entries that do not lie on the main diagonal are zeros, and the diagonal entries are all ones. 

Hence it is an identity matrix.
