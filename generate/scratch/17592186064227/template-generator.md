# 6. Template generator

The numeric script exposes `generate(difficulty, seed, template, parameters, bank_profile)` and `batch(difficulty, count, seed)`, with easy/moderate/hard and all-level CLI previews. `--difficulty all --count 1` returns a JSON list containing three records. Every record has the existing question/field/answer representation, field-owned answer identities, bare mathematical choice values, deterministic IDs, full parameters, source IDs, basis/lineage, dependency version and domain information. All math normalization uses the privately frozen formatter. `sys.dont_write_bytecode=True` is set before private imports.

The complete source profile is selected first. Both independent slots are sampled directly: a in 1..6 and k in ±1..±6. Original a=k=1 stays eligible in ordinary sampling and direct replay. The exact invertible rule k*f(a*x) and answer rule (k/a)*D(a*x) propagate coefficients and function arguments through all dependent expressions. There are 72 parameter pairs per source profile, or 1,440 profile instances; this is a bounded conservative inventory, not a count of distinct mathematical tasks. mathematical-inventory.json enumerates actual normal outputs and reports the canonical integrand/bounds/domain-hole counts by level. Source exponent/operator shapes and argument-space intervals stay fixed. The normal sampler has no within-level progression. A separate mathematical_task_fingerprint uses only the canonical actual integrand, bounds and original domain-hole contract. It excludes profile, seed, bank, option order and field shape. Content IDs still distinguish field and bank contracts. Batch-only deduplication rejects duplicate mathematical task fingerprints inside that call and never globally excludes source originals.

`validate.py` reads actual rendered prompts, all inline trigonometric identities, all original and changed formal integral operands, full substitution arguments, derivative/differential coefficients, endpoint tables, primitive operands, constants and subsequent reciprocal/log/endpoint rewrites. It proves identities by exact symbolic trigonometric reduction. For logarithm derivatives, it applies d(log|f|)=f'/f on each open domain component; it does not force logarithm or square-root identities. Correctness tests respect original poles even if the displayed source later cancels a factor. Radio banks are checked for exactly one correct derivative/value and pairwise distinct primitive families, so constant differences are not mistaken for distractors. Blank fields preserve their exact answer shape and collected equivalents.

Source fidelity checks compare all source prompt/solution prose after presentation normalization, field keys/types, full source banks and the correct designation. `choice-ledger.json` maps each original answer ID one-to-one to its full parameterized recipe; `source-replay.json` reports matched complete banks and distractors separately. Source-cases contains MA exact raw original replays only, with eleven malformed bare trig-name captures marked ineligible. Review-cases contains 80 changed authored instances and eleven separately supported original notation repairs. Normal serving repairs only those operator names; exact source replay is explicitly requested by raw_source=True and is ineligible when malformed. The native runner checks each original and one changed instance per source using normal radio selection IDs and actual blank canonical/equivalent/incorrect entries. Native expected mathematics and observed outcomes remain separate in native-input.json, native-grading.json and native-gaps.json. No engine, database or registration change is used to conceal a grading gap.

`source-and-changed.md` shows every original beside a=2,k=3, preserving all ordered stages. `rendered-stage-checks.json`, `boundary-checks.json`, `mutation-checks.json` and `validation.json` record the completed checks. `freeze.py` hashes the complete script/tree, including this documentation, source evidence, private helpers, native binary and validation, excluding only freeze-manifest.json itself.
