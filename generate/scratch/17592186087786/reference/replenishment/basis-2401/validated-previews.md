$$
x=3\cos\theta,\quad y=3\sin\theta,\quad 0\leq\theta<2\pi.
$$

To find the Cartesian equation of the circle, we need to eliminate the parameter $\theta.$ We can do this using the Pythagorean identity:

$$\cos^2\theta+\sin^2\theta=1.$$

By squaring the $x$-equation, we get

$$\begin{aligned}x&=3\cos\theta\\x^2&=(3\cos\theta)^2\\&=9\cos^2\theta.\end{aligned}$$

By squaring the $y$-equation, we get

$$\begin{aligned}y&=3\sin\theta\\y^2&=(3\sin\theta)^2\\&=9\sin^2\theta.\end{aligned}$$

Adding the two equations and using the identity, we get

$$\begin{aligned}x^2+y^2&=9\cos^2\theta+9\sin^2\theta\\&=9(\cos^2\theta+\sin^2\theta)\\&=9(1)\\&=9.\end{aligned}$$

Therefore the Cartesian equation is $x^{2}+y^{2}=9.$
