# Cosecant derivative generator

Run with the project runtime:

```
.venv/bin/python generate/scratch/17592186115190/validate.py
.venv/bin/python generate/scratch/17592186115190.py --difficulty all --seed 77 --count 2 --format markdown
```

Eight source families at immutable math basis2275 are parameterized at easy,
moderate and hard. `generate`, the three difficulty entrypoints and finite
`batch` support explicit templates/profiles. Parameters and sampler bounds are
identical; invalid, bool, unknown-profile and incompatible-level requests fail.
Raw public source replay uses `profile="evidence"`, explicitly ineligible and
preserving missing attributes and original mathematical/presentation errors.
Normal defaults serve every eligible family and provide authored completions
of the missing q1889 key/solution/easy label and q104316 blank. Normal q313723
repairs a wrong sign in the first formal derivative operand. The hard authored
familiar-angle bank extends the original differentiate/evaluate method without
adding a chain rule. `classification.md` and `template-extraction.md` delimit
these claims and map every option in every complete source bank.

The private formatter/parser are loaded by explicit file paths, with no live
question-capture dependency. Validation reads actual prompts, derivative
arguments, formal operands, every intermediate row and every option; checks
all bounded normal instances, invalid explicit requests, mutation rejection,
source bank/presence/prose fidelity, deterministic identities and finite task
deduplication. Source evidence counts, mathematical checks and actual native
grading results are reported separately. Native measurement uses a private
byte-frozen copy of the current check-engine and preserves every unexpected
outcome; no engine change or valid-output exclusion is performed. Its binary
and provenance remain private evidence; no DB writes or registration occur.

No plots or raster generation are needed. The q1889 authoritative widget and its
native screenshot were inspected; every option agrees with the EDB capture up
to ordering and typography, but neither supplies a visible key or worked
solution. `review.md` includes all originals and two changed variants for every
normal family/profile. `review.json` is the machine-readable generated review.
`bounded-records.json` holds complete finite-domain validation data.
