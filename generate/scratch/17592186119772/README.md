# Identifying a Triangular Matrix

Local generator and evidence for KP17592186119772, math basis1356. Easy and moderate preserve all eight original practice banks. Hard has two explicitly authored five-4×4 subset radio profiles within the same triangular-recognition scope. All output uses native TeX arrays; no plots or renderer needed.

```sh
.venv/bin/python generate/scratch/17592186119772.py --difficulty all --seed 42 --count 2
.venv/bin/python generate/scratch/17592186119772.py --difficulty moderate --profile raw:q-42090 --format json
.venv/bin/python generate/scratch/17592186119772/validate.py
```

`generate_easy`, `generate_moderate`, `generate_hard` and `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` accept fixed full matrix parameters. Valid templates are single_matrix, three_matrix_subset and five_matrix_subset. Profile q-N retains its entire observed bank; raw:q-N publicly replays raw key/layout evidence; hard_two and hard_three are authored banks. Original source parameters are in source-cases.json.

Normal q-42090 removes its first duplicate field according to the authoritative MA widget. Raw q-42090 retains the legacy absent correct ref and is evidence-only, so that record cannot be passed unchanged to the grader. All normal banks are tested through the application's actual grader. Full raw bank/solution fidelity is checked separately from grading.

validation.json reports actual finite structural task counts, original-bank matches, authored profile coverage, bounds, displayed mathematics, stale-witness regressions, native grading and runtime versions. review.md / review.json contain all raw originals and two generated examples per observed or authored complete profile. No database, engine, registration, shared file or environment edits are performed.
