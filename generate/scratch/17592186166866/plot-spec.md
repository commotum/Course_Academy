# Plot extraction and specification

1. Specific sources: ten blue ellipse outlines on transparent backgrounds with black axes pointing right/up. Origin plots label positive and negative x/y endpoints. Translated plots show an orange center with signed coordinate label and dashed positive-direction semiaxis guides labeled a,b. Original rasters are 360×304. No tangent line or tangent-direction arrow appears. Source full-resolution files are under `/media/jake/SSD/EDB/math/images/`; `source-montage.png` composites them on white for visual review.
2. Shared pattern: equally scaled Cartesian axes, axis-aligned ellipse centered at h,k with horizontal and vertical semiaxes a,b; graph reading carries the entire equation-reconstruction demand. All plots are heavy prompt assets. Choices and solutions have no diagrams.
3. Components: ellipse extrema h±a and k±b, origin, positive axis arrows, signed center, semiaxis annotations, dashed guides and labels. `source-geometry.json` records each raw source pixel extent, longest black axis pixel origin, independent x calibration from the inspected labels/guide a, and y-height/center verification using that SAME unit transform. Stroke/antialias tolerance is bounded in pixels (3px extent, 2px center). Every source's signed labels and arrow directions were visually inspected; this is independent geometry evidence rather than path/hash-only fidelity.
4. Reusable renderer: Matplotlib, equal aspect, integer tick spacing 1, x/y bounds from curve extrema plus 1 and origin, 801-angle outline; translated guide/center annotations from the same exact parameter object. Fractional vertices and arbitrary plot scale changes are not supported. Source original geometry uses its captured path for exact replay; changed parameters always render. Renderer writes unique temporary inputs, PNGs and sidecars, then atomically replaces final cache entries. Both PNG and sidecar are required for a hit. Concurrent identical/different fresh calls are verified in a private isolated QA directory. Active caches are never pruned.

Cached Python 3.10/Matplotlib dependencies are reused read-only, following the approved 78582 approach; exact dependency paths/versions are recorded in each plot sidecar. No install, shared environment edit, direct SVG or image model is used. Rendered variants retain clear integer grid increments and unchanged response demand.
