# Plot extraction and specification

1. Every original was viewed at its full 339 × 281 resolution, including canonical e-5814. Copies are under originals/. Each is a white Cartesian sketch, thin black axes through actual zero, arrowheads at positive axis ends, a red polynomial curve, short root ticks and black integer x-root labels. Root zero is unlabelled where it meets the vertical axis. There are no y ticks, quantitative y scale, labelled y-intercepts, filled markers, finite included/excluded endpoints or answer-option images. q-38668: simple -1,0,1, negative odd leading sign. q-38671: -3 simple,-1 even,2 simple, both ends up. q-38763: -2 simple,-1 even,2 simple, both ends up. q-38765: -1 even,1/2/3 simple, left down/right up. q-112595: -3 simple,0 even,2 even, left up/right down. q-112596: -2 simple,0 odd multiple,3 simple, left down/right up. q-38774: -2 even,-1 simple,2 even, left down/right up. q-80348: -1 simple,0 and2 odd multiple, left down/right up. q-80350: -1 simple,2 odd multiple,5 simple, left down/right up. q-80352: -2 and1 odd multiple,0 simple, left up/right down. Canonical: -2 simple,-1 even,2 odd multiple, both ends up.

2. The shared visual pattern carries root location, crossing/touching/tangency and leading sign/end behavior. An unscaled sketch cannot identify vertical amplitude or distinguish multiplicity 3 from 5 merely by its category. Banks must admit exactly one compatible choice, with distinct complete graphical signatures across all normal options.

3. Components: zero axes, positive arrows, integer x ticks at every nonzero root, red curve, relative root spacing and local topology. No exact numerical y geometry is inferable from source pixels. In generated plots each actual ordinate nevertheless comes from the displayed key polynomial. Matplotlib 3.11.2 renders PNG only; no SVG or image model. Renderer sidecars record exact roots/coefficient, bounds, transforms and interior/critical point pixels. A positive vertical scale changes actual ordinates and presentation but is not meaningful assessed variety.

4. A complete instance's root/multiplicity/coefficient data drives both plot and answers. Bounds include actual zero and all roots; derivative critical points set vertical limits with padding so all source-shaped lobes remain visible. A dense 10001-point path includes roots and extrema exactly. Every axis spine is at data zero, and labels have a fixed screen offset. Positive arrows remain; curves leave the viewport as unbounded polynomial graphs, with no endpoint markers. Generated variants were visually inspected at full resolution for easy, moderate and hard, including shifted root zero. Raster validation checks actual red pixels near independently calculated displayed-polynomial points; exact checks establish root orders, crossing signs and end behavior separately.

Horizontal translations h in [-3,3], stretch s in {1,2} for easy/moderate and {1} for hard preserve each source's geometry/behavior workload. Labels update from actual mapped roots. Roots up to 13 remain readable with adaptive horizontal bounds. No source-specific image reuse branch exists; source anchors are recreated by the same renderer.
