# Normal-intercept draft

Run `.venv/bin/python generate/scratch/17592186092385-draft.py --difficulty all --count 5 --seed 0` for five questions per band, or select easy, moderate or hard. JSON is the default; `--format markdown` prints review questions, solutions and fields. `--field-type blank` selects two coordinate blanks. Python APIs are generate_easy, generate_moderate, generate_hard, generate, batch, catalog and explicit source_replay. Parameters are scale, point and axis; explicit invalid inputs fail closed. Seeded defaults choose a valid complete instance deterministically. Batch count must be an exact nonnegative Python int and seed an exact Python int; bool and float inputs are rejected. Count zero returns an empty list. Requests at capacity return exactly that many distinct eligible mathematical tasks; requests above capacity raise ValueError and never return a partial successful batch.

Raw captured evidence uses source_replay(source_id, 'observed_raw'), and is evidence-only. Missing contracts stay excluded from every normal API. observed_served supports fixed normalized source replay and the documented q-342222 answer-record repair; those review records are also evidence-only. Normal authored and source_bank APIs are the only learning-eligible profiles. Authored radio banks derive all five whole-line intercepts from one actual curve instance: correct normal, tangent slope, positive reciprocal, omitted abscissa shift, and omitted ordinate. Entire degenerate banks fail closed through every explicit normal API; there is no offset fallback. Blank catalogs retain all valid underlying tasks. No database operations, registrations, commits or shared QA edits occur.

Validation: `.venv/bin/python generate/scratch/17592186092385-draft/validate.py`. The independent private_readback.py parses the actual printed prompt, branches and full points. It binds the derivative variable and supplied abscissa explicitly, validates all derivative operands and every displayed intermediate/equation, and checks whole banks against the actual normal and requested axis. Mutation controls bypass identity hashes, so they test readback. Every authored radio bank is also read back against its five independently derived whole-line error recipes; a mutation replacing a distractor with correct+1 must fail despite keeping one mathematically correct option. CLI --difficulty all is exercised in both field shapes and JSON/Markdown. Every valid bounded radio/blank catalog and observed bank variant is exercised through the shared actual learning::grade_field checker, including canonical and exact equivalent blank entries, ordinary 0 and 1, and correct+1. Any unresolved check is fatal and remains visible. The shared checker hash is 71d435e31aa0cdea66d992aa4d4bd1043cdd871aaffc7a3af9f54e9b0f846dea. The private parser is frozen and hashed; it does not import registered code or another generator's validator.

Evidence lives in classification, extraction, source-cases, source-fidelity, independent-inventory, capacity, engine-input, engine-validation, validation and review files. source-cases.json contains ten MA-original cases only. independent-inventory.json preserves the three non-MA full pull records under its basis, lineage and questions wrapper. registered-baseline.json verifies the complete original pathset and hashes. frozen-manifest.json freezes the new draft and evidence. Status is working, with root independent QA required; this is not approval for DB preparation. Hard has zero original practice evidence and uses the canonical method conservatively. Moderate/easy arithmetic ranges are author policies. Non-MA inventory is never counted as MA-original fidelity.
