# Local generator and validation

Entry point: ../17592186064207-draft.py. Standard CLI supports --difficulty easy/moderate/hard/all, --count, --seed, --format json/markdown. Python seed/count reject bool and float values. Explicit parameters are [n,a,b] and receive the same strict integer/domain/full-bank checks as sampled parameters. Source evidence is exposed by source_case with exact raw records and eligibility reasons; it never enters the serving sampler.

source-cases.json contains Math Academy originals only. independent-inventory.json is the exact four-record non-MA inventory. raw-replay.json retains source records and canonical evidence, including missing fields and keys. review-cases.json contains authored/normal generated practice, with origin provenance. Source fidelity reports complete mathematical-value matches at the SAME K, preserving designation and omissions. The q113533 family ambiguity is independently proved by the explicit positive-K reciprocal mapping.

validate.py independently parses the rendered prompt, substitution operand and differential, every displayed formal integral (including the u Jacobian), each primitive, the prose C mapping, expanded/factored/combined constant stages, all answer choices, and pole domain. Every primitive stage must equal the final result after the explicit C=(n/a)ln K mapping; derivative equality alone is insufficient. A private copied parser and math formatter are frozen with the draft. Five mutation tests target the prose constant, expanded constant, differential, formal operand, and intermediate primitive.

Native radio checks use only generate/runs/current/check-engine, SHA 71d435e31aa0cdea66d992aa4d4bd1043cdd871aaffc7a3af9f54e9b0f846dea. Every generated choice is submitted through course_academy_engine::learning::grade_field; malformed/foreign selections are explicitly unresolved. No blank source field exists, so no blank contract or tautological identity test is invented. Native grading cannot assess mathematical source ambiguity, which is handled separately by symbolic source audit.

numeric-baseline.json captures the full historical numeric file/tree pathset, including directories and cached files, before any numeric import. The numeric script is never imported; validation compares every path and file SHA. All authored files belong only to this draft entry point and matching directory. No database writes, engine writes, registration, or root queue edits occur.
