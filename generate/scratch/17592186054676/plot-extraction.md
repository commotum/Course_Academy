Each prompt contains one square Cartesian grid, equal x/y unit spacing, thin light gray grid lines, dark coordinate axes with positive arrowheads and x/y labels, numeric ticks, three red point markers and nearby italic letter labels. No line is drawn: discovering membership requires reading coordinates and substituting. The plot is central to every task, so the rating is heavy. There are no answer-choice or solution plots.

Variant renderer: Matplotlib, 4.5-inch square canvas, 120 dpi, equal aspect; integer ticks; light gray grid, axes crossing at zero with arrows, x/y labels, red markers with A/B/C annotations offset 6 points vertically and away from the vertical axis horizontally. Bounds derive from all three coordinates plus margins and include both axes. No independent sampling occurs during rendering; exact integer instance data controls markers, limits and labels. Styling/tick-label density is a disclosed visual modernization, separate from exact mathematical fidelity. Original assets are reused only for original coordinates. Plot filenames are deterministic parameter hashes; publication uses image-byte SHA-256 and verifies the resulting stored bytes.
