# Constructing Line Integrals With Respect to X

Bounded easy radio generator with four complete unambiguous source-bank profiles.
The function coefficient varies; path geometry, parametrization hints, response
shape and worked-solution stages stay source-shaped. Three ambiguous banks are
replayed as ineligible evidence, and one incomplete record is retained unchanged.
Moderate and hard remain explicit unsupported reserves for this package.

Run `.venv/bin/python generate/scratch/17592186133891/validate.py` to check complete
rated source-bank fidelity, all 32 tasks, rendered mathematics and solution rows,
seed-independent identity, mutation regressions and actual native radio grading.
Run `.venv/bin/python generate/scratch/17592186133891.py --difficulty easy --count 5
--seed 42 --format json` for reproducible previews. Generation itself never writes
to EDB. `replenish.py` rechecks inventory under application api.lock and retains
exact additive requests, previews, receipts and readback evidence.
