# Word Problems generator

Generator: `../17592186138429.py`. Scope: read the horizontal coordinate of a unique intersection of two supplied contextual linear graphs; no learner algebraic solving. Two unrated sources replay with exact prompt/PNG and full five-choice banks. Missing original correct refs, solutions and labels receive explicitly authored repairs. Original distractor intent remains unknown; expression replay profiles never serve as defaults.

Normal authored bands: easy directly numbered integer-hour ticks; moderate odd days between numbered two-day ticks; hard ten-meter minor ticks between numbered twenty-meter ticks. All preserve source units and five-choice radio layout, including truck `h` suffix. The original car's hard replay placement is fidelity-only: its unchanged graph uses numbered ten-meter ticks. Two generated examples per band and variants of both source banks are in `review.md` and `review.json`.

From repository root:

```sh
.venv/bin/python generate/scratch/17592186138429/validate.py
.venv/bin/python generate/scratch/17592186138429.py --difficulty all --seed 21 --count 2 --format json
.venv/bin/python generate/scratch/17592186138429.py --difficulty hard --template cars --profile observed_car_ratios
```

Validation compares every source option, exact prompt and captured PNG; independently solves plotted line data from linked plot sidecars, checks printed solution values and units, verifies output identity/whole-bank domain/explicit guards and native grading of every option. Renderer uses cached Python 3.10 Matplotlib dependencies read-only and unique atomic files; no installs, source edits, database writes or registration. `validation.json` stores freeze hashes and honest original-fidelity denominators. Parent independent QA is required before completion of the larger run.

Inventory refresh, math basis 2019 onward: `extensions.py` adds both newly
captured easy templates: airplane radio and conserved water-transfer numeric
blank. `source-current.json` preserves all four source questions; the originals
remain unchanged in EDB. `validate-current.py` checks the two additional complete
source banks and normalized solutions, generated math/graphs, and actual blank
equivalence grading. `current-validation.json` freezes the refreshed package.
`capabilities.json` distinguishes observed easy labels from the explicitly
authored moderate/hard graph-scale reading bands. `generator-identity.json`
records the stable registration UUID and repository-relative script.

`replenish.py` rechecks native inventory, excludes exact context/line tasks
already in the practice/canonical bank, validates and publishes SHA-256 PNGs,
and prepares a native-spec preview. `--commit` requires the recorded plot review,
acquires the application's api.lock, rechecks the current basis and inventory,
submits the exact retained source-attributed request with a basis guard, and
verifies only additive scoped datoms and full content readback at db-after.
The exact request, receipt, validation and final inventory stay in
`reference/replenishment/basis-*/`; unknown outcomes recover the same request.
