```sh
.venv/bin/python -B generate/scratch/17592186100877/validate.py
.venv/bin/python -B generate/scratch/17592186100877.py --difficulty all --seed 20 --count 2 --format markdown
```

Basis2275 frozen source fidelity and source keys are counted separately from
mathematical correctness, native grading, and authored missing-data completions.
See validation.json, raw-source-replay.json, review.md and engine reports.

whole bank because sparse scalar data does not establish distractor intent.

observed bank and all levels. No plots, database writes, registration, engine
edits or shared-file changes are part of this pair.
