- **III.** $x\in (0,1]$

- false
- true **(correct)**

- false **(correct)**
- true

**Worked solution**

A function is invertible on a particular interval if and only if it is one-to-one on that interval.

The vertex occurs at $x=\frac{1}{2}$. On either side of this vertex, the function is strictly monotone. Including the vertex as an endpoint does not create a repeated output. An interval containing points on both sides is not one-to-one: inputs equally far from the vertex have the same output.

- Interval I, $[-1,0)$, lies on one side of the vertex, since $0\le \frac{1}{2}$. It is therefore invertible.

- Interval II, $[- \frac{1}{2},\frac{1}{2})$, lies on one side of the vertex, since $\frac{1}{2}\le \frac{1}{2}$. It is therefore invertible.

- Interval III, $(0,1]$, contains the distinct inputs $\frac{1}{4}$ and $\frac{3}{4}$, both with output $\frac{1}{16}$. It is therefore not invertible.

Therefore, the correct answer is "I and II only".
