## 2. Generalize the shared pattern

A supplied elementary formula and three specified nondegenerate real intervals ask for the complete subset of restrictions on which the function is one-to-one. For a line of nonzero slope, every restriction works. For a quadratic/absolute-value fold with vertex h, an interval works exactly when it stays entirely at or to one side of h; inclusion of h as an endpoint is allowed. A crossing interval fails by equal outputs at h−d and h+d.

## 3. Component and recipe mapping

Each source template owns its complete five-selector bank. Selector operations are literal finite subsets of the displayed interval positions, not numerical fits or inferred pedagogical diagnoses. Punctuation variants such as “I, II and III” and “I, II, and III” are the same mathematical answer and cannot coexist in an eligible bank. Wrong selectors remain independently incorrect after the full bank is chosen and every displayed interval is evaluated.

Prompt components are the full function expression, three complete interval components, and fixed source prose/Markdown. Solution components include the full transformed function, intermediate translated base expression, translation magnitudes and direction, line slope/intercept, complete interval references, ordered images, horizontal-line-test sentences, subset-containment reasoning where present, and a fixed concluding subset. The implementation masks complete components before inserting them, so nested expressions or incidental prose numerals are not accidentally replaced.

Source images and exact formula spelling are recovered at original parameters using the same rendering recipe. Parameterized variation changes the function/interval components and relevant translation prose; it does not branch to return a literal source payload. Exact original parameter rendering preserves the source spelling and spacing. Plot data comes from the same formula/domain parameters.

## 4. Reusable template and constraints

Observed easy parameters: nonzero integral slope of magnitude 1–4, source slope sign/layout retained, positive integral intercept 1–6, and common interval translation −4…4. Source decimal/radical endpoints remain exact under translation. Every interval stays nondegenerate.

Observed moderate parameters: source reflection coefficient ±1; h,k integers of magnitude at most 6, with zero/nonzero status and translation direction preserved so the same construction stages remain applicable. Intervals translate with h, preserving their original branch/vertex/crossing structure. The fieldless source has explicit raw and repaired profiles.

Authored moderate parameters: integer h,k of magnitude at most 6. A complete catalog is chosen first: one left/right half-infinite single-branch interval, one of six finite branch/vertex endpoint types, and a crossing interval, in any order (72). Authored hard parameters: reduced h of denominator 2–4, |h|≤4, integer |k|≤4; two distinct finite branch/vertex endpoint types and a crossing interval, in any order (90). Whole authored banks contain the exact valid pair, omission of either true member, and substitution of the crossing interval for either true member: three distinct pairs and two singleton omissions. This avoids a unique-length correct-answer shortcut. The easy constant catalog uses the empty selector, three singleton errors, and all three.

No normal instance includes ambiguous banks, invalid intervals, missing choices, or equivalent subset answers. No first-valid distractor pool or arbitrary perturbation exists. Public fixed parameters must satisfy exactly the same workload/domain guards as sampled parameters.

## Mathematical assumptions and response criterion

The displayed formulas are continuous real functions on their natural domain R. Strict monotonicity on each branch is sufficient; the source does not assert that nonstrict monotonicity or arbitrary nonmonotonicity is equivalent to failure. A discontinuous injective function can be nonmonotone, and nothing here generalizes the folded-function rule to such descriptions. All requested objects are the three supplied intervals, not largest/maximal domains, unions, disconnected sets, or inverse ranges. Including the vertex as an endpoint does not introduce two distinct preimages; crossing it does. No codomain surjectivity demand is supplied; invertibility is understood onto the restricted image, as in the lesson.
