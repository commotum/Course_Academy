# Plot extraction and rendering

1. Original plots are source-specific schematic Cartesian illustrations. Lines have positive/negative slope, intercept annotations, x/y arrowed axes and a horizontal dashed test line. Folded functions have a labelled vertex/shift, upward/downward quadratic or V shape, solid assessed branches, dotted excluded branches, open/filled endpoint circles, dashed test lines, and interval captions. Composite images order the interval panels according to the fixed solution: q-66778 displays III before II. There are 26 practice files, plus three canonical files inspected at original resolution. The transparent q-66679 paired panel was also composited on white before inspection.
2. The shared purpose is illustrating the horizontal line test for the supplied formula and specified restriction; plots supply no additional assessed information.
3. `plot-extraction.json` records every original file/hash/dimensions, blue-pixel extents, formula, vertex, interval-panel order, endpoints and endpoint inclusion. The original rasters were individually read against the full prose and all domains. Source coordinate axes are schematic and independently scaled; no equal-aspect or unlabelled numeric tick recovery is claimed. Tick/vertex labels in the originals agree with the formulas; open/closed circles agree with the listed restrictions. q-66687 draws interval II and explains interval III by set containment in prose.
4. Changed-parameter source variations render via Matplotlib from the same exact formula/domain data. Bounds contain the vertex, all finite interval endpoints, and zero, with margins. Solid restricted branches, dotted excluded branches, endpoint circles, interval captions, axis arrows and horizontal witnesses are preserved. Generated coordinate ticks/grid are a labelled presentation extension; source images are reused only at their exact complete original geometry. All original assets remain unchanged in faithful replay.

The private renderer uses cached Python 3.10.13 wheels read-only; nothing is installed. Each plot PNG has a JSON sidecar with actual Python/Matplotlib versions, dependency paths, formula geometry, assessed interval, plot bounds and measured title/x/y-label clearance (≥5 display pixels). Input and atomic output temporary filenames are unique, including concurrent calls. Cache hits require both PNG and sidecar. There is no SVG, image model, or shared renderer mutation.

The independent validator recovers formulas and intervals from displayed prose, then checks every sidecar curve at three points, every panel's endpoints/closure, and label-clearance measurements. Source fidelity additionally checks exact image references and full solution strings. Authored defaults justify injectivity algebraically and need no plots; original source-shaped defaults continue to show their full plotted solution layouts.
