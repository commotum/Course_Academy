# Source-preserving closest-point templates

The per-question descriptions, exact equation/point values, plots, fields, original solution text and every complete choice bank are recorded in extraction.json. Each source owns its profile; no pooled distractor selection or mixed banks are used.

Given a nonzero finite-slope line Ax+By=C and point P=(u,v), find the perpendicular foot by the original sequence: standard-form rewrite when present, negative reciprocal slope, point-slope expansion, intersection system, elimination for x, substitution for y, conclusion as a coordinate pair. Easy uses supplied slope-intercept form; moderate includes the observed standard-form rewrite. Domains are real x,y; A,B are both nonzero for all observed sources. Exact integer and rational values, signed coordinates, zero coordinates, unsimplified coefficients such as 5y-10x=5, and tuple answer shape are retained.

Fixed: source direction, coefficient scaling, original target x, field key/type, five-choice bank membership and source-specific instructional sequence. Variable: vertical translation t in integer [-4,4]. Transform line to Ax+By=C+Bt, target to (u,v+t), and every source tuple (r_i,z_i) to (r_i,z_i+t). Thus all source numerical offsets are recorded exactly; no inferred error mechanism replaces an observed value. The complete mathematical value is reproduced at t=0. Translation is an explicit narrower policy and geometric recipe; it changes actual equation, target and answers, not just identity or order. All eight profiles are exercised at every t, including zero, both signs and boundaries. Choices remain pairwise distinct, and distance minimization proves exactly one is correct.

Compute exact m=-A/B, intercept b=(C+Bt)/B, perpendicular n=-1/m, d=v+t-nu, then X=(d-b)/(m-n), Y=mX+b. Plots use this same instance. Source wording and solution are exact at replay. Variants retain shared source instructional sentences and operation sequence, using normalized parentheses and a consistent elimination layout; this layout difference is explicitly a fidelity limit. No misconception feedback is added. Original source records stay unchanged.

Question UUID derives from normalized line and target point, independent of seed, profile choice order and rendered notation. Fields and answers have deterministic field-owned identities. Exact source tasks and canonical tasks are excluded during preparation. Banks alone are not counted as new tasks.
