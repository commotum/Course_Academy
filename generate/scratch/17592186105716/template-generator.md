# Generator and verification

The numeric script is a new local draft because basis2275 has generator_entity=null and no numeric script/evidence directory existed before this task. No registered artifacts were changed. registration-reconciliation.json records the empty original pathset.

`generate(level,seed,template,parameters,profile,field_type)` exposes all E/M/H profiles and permits only the declared finite parameter catalogs. Profiles select complete five-option banks. IDs bind normalized content, then field-owned option values. Seed controls selection and option order; a seed change with fixed mathematical parameters does not manufacture a new question ID. CLI `--difficulty all --format json` produces a flat list of exactly three records for count 1. `generate_batch` groups canonical expanded integrands across eligible profiles, samples distinct task groups without replacement, then samples an eligible profile/parameter representative within each group. Count is per level for all-level CLI calls. Exhaustion above semantic capacity fails before producing any output. Single and batch APIs reject boolean, fractional and string seeds.

Public output uses a private frozen copy of the shared math-content formatter. SymPy calculates exact answer values. Every original and finite public instance is independently read back from the actual rendered prompt, options and formal integral solution rows by independent_math.py and scalar_reader.py. No hidden generation calculations or metadata establish correctness. All formal integrals have their displayed operands integrated before differentiation, and every expression side of every ordered row must differentiate to the printed given integrand. Original normalized solution bytes and prompt bytes must additionally match; complete source banks are compared by full mathematical values with C fixed. Distinct learner options are checked modulo C by derivatives. The private native engine exercises all five owned IDs for each instance, and foreign/malformed ownership diagnostics are separate cases. Native radio ID selection alone does not establish calculus correctness.
