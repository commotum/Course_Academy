## Curriculum and authored levels

Following `activity/first-step` and `step/next`, the lesson route is Introduction → Identifying a Zero Matrix → Identifying a Square Matrix → Diagonal, Identity, and Other Matrices tutorial → this KP → Identifying Other Matrices. The tutorial defines diagonal matrices by square shape and offdiagonal zeros, explicitly permits zero on the diagonal, defines identity by diagonal ones, and displays a 1×1 identity. The adjacent KP owns row/column vector recognition, which is not introduced here. No triangularity, multiplication, determinants, rank or arithmetic operations are assessed.

Every normal level keeps exactly three supplied matrices, the original three-checkbox contract or separate original radio contract, and the same requested predicate. Shapes are 1..5 in each direction: 1×1 comes from the tutorial, 5×5 from unrated q-7829, and rectangular roles from originals. Easy inspects 3..36 displayed entries, covering all rated source workloads; moderate inspects 37..45, hard 46..60. These disjoint workload bands require more shape/entry bookkeeping while preserving the same finite classification method. Some total sizes in a band are unattainable for a particular three-square family; such inputs are never fabricated. Entries are integers -3..7 as in the originals, with no extra numeric arithmetic.

Moderate and hard are conservative authored grade estimates. There is no observed moderate/hard label, no empirical MA grade calibration, and no claim that a larger matrix introduces a new skill. Easy source replay retains observed easy labels and the unrated omission. Raw replay is constrained separately from normal authored bands.

A zero square matrix is diagonal; an identity matrix is diagonal; a rectangular zero matrix is not diagonal under this curriculum's square definition. 1×1 `[0]`, `[1]`, and `[2]` are all diagonal; only `[1]` is identity. Normal diagonal slots may be identity, and their identity notice changes accordingly. Raw nonidentity diagonal source slots keep the source notice valid. Selection asks whether each matrix belongs to the requested class; it does not ask for a most-specific category.
