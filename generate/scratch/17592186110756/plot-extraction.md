# Plot specification

Inspected all twelve source prompt/solution figures (source-plots.png). Axes are
black with arrowheads, grid grey, circle blue, radius black, central angle yellow.
P is on the first-quadrant arc; solution adds (cos theta,sin theta). There are no
choice plots. Each generated prompt and solution uses the same known coordinate,
exact complementary square root and atan2(y,x). Coordinates satisfy x^2+y^2=1.
The rational/radical source typography has no mathematical role in geometry.

Matplotlib renders exact derived positions at 4.3 inches and 140 DPI, square
aspect and [-1.35,1.35] bounds. Long solution annotation is placed above the
figure to avoid clipping. Axes, bounds, colors, unit radius, topology and QI stay
fixed; P, OP and theta vary together. Assets are deterministic SHA-256 PNGs;
accepted content is published through the existing ImageLibrary content store.
