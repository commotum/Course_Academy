Determine the largest domain on which the function $f(x)$ (shown above) is invertible.

Choices:
$x\in [-3,1)$
$x\in [-3,1]\cup (3,5]$
$x\in [-3,5]$
$x\in [0,5]$
$x\in [1,5]$

Worked solution:
First, notice that the domain of our function is $x\in [-3,5].$ 

A function is invertible on a particular interval if and only if it's a one-to-one function on that interval. To determine the intervals on which the function is invertible, we use the horizontal line test.

- The function $f(x)$ does not pass the horizontal line test on the interval $x\in (1,3).$ In this case, the horizontal line $y=1$ intersects the graph at more than one point.

![](images/eb/eb544795c61be7dd87568e6def10fc907c3554b603c3b344f88ac2a8ff847f8d.png)

- Among the given options, the largest domain on which the function $f(x)$ is invertible is $x\in [-3,1]\cup (3,5].$ On this domain, any horizontal line will intersect the curve at most once, no matter where we draw the line.

![](images/40/4059a1ad684023640358af6ee38f0967957336578eb93b3299c9c842e7ce108f.png)

 

Therefore, the correct answer is $x\in [-3,1]\cup (3,5].$
