## 2. Shared pattern

Restrict the shown function's domain to each requested interval/set. Count distinct input points at each horizontal height. One-to-one on every requested point is invertibility. A disconnected requested set also requires disjoint output ranges across its components. A largest interval/domain question adds the explicit response criterion; an injective proper subset is not automatically the requested answer.

## 3. Component and complete-bank mapping

`source-bank-map.json` lists every original field/value/type/correct designation, every interval's open/closed membership, complete profile, and exact shared prose. Text answers encode subsets of I/II/III; they arise from dropping or adding restrictions from the true subset. Mathematical answers are whole domain restrictions, including unions: recipes alter plateau inclusion, retain/drop a branch, extend across a constant segment, or truncate the valid restriction. The entire bank, not its first eligible options, is fixed before parameters.

Underlying author distractor intent is not recoverable from membership alone. We claim complete displayed set/label recovery and operation masks, not source authoring code. Source profile coordinate translations transform every complete interval component in prompt, solution and choices together. They do not replace short symbols across prose. The original raster slots are used at x_shift=0; nonzero source shifts use explicitly qualitative landmark graphs. Those surrogate curves cannot establish original analytic-ink fidelity and are never normal defaults.

## 4. Reusable masks and calculations

Fixed: horizontal-line-test opening, per-source grammar, complete bank membership, prose/solution ordering, answer shape and field layout. Variable: full interval endpoint components; coordinate shift in evidence profiles; normal graph spans, orientation, endpoint inclusion and interval assignment. Conditional: evidence raster versus explicitly qualitative changed-coordinate plot; subset answer versus largest listed domain/interval. Source prose and diagram witness stages are retained exactly at original parameters.

Normal generation derives branch ranges and exact domain intersections before selecting the correct subset. A complete five-choice subset profile is chosen from the computed true subset; all profiles derive from omissions/additions of the same requested restrictions. Maximal banks derive from adding constant pieces, omitting endpoints or truncating nonconstant pieces. It validates the complete bank against the actual requested response, rejecting any ambiguity. No unrelated perturbation or first-valid distractor pool is used.
