# Orientation-region question generator

`../17592186129283.py` provides deterministic JSON/Markdown generation at easy, moderate and hard levels. Classification, template and plot extraction, original raw banks, source defect evidence and finite region bounds are retained in this package. Version 2 uses the application's canonical math formatter; it preserves the existing exact mathematical and instructional templates.

Run `.venv/bin/python generate/scratch/17592186129283/validate_inventory.py` to replay source banks and independently check displayed transformations, partials, determinant stages, inequalities and strict plotted regions. `check-engine` was compiled from the existing application grader harness against the current engine library. `replenish.py` reads current inventory, excludes shown/reserved or duplicate region tasks, publishes content-addressed images through the existing ImageLibrary, and prepares additive content and generator registration. It holds the application's api.lock through the basis recheck, guarded request, submission and exact receipt-basis readback. Complete requests, receipts and verification remain under `reference/replenishment/`.

Default easy capacity is 24 distinct sign regions. Replenishment samples at most 300 candidates per level; any remaining shortage stays explicit. Changing seed, identities, ordering, arithmetic coefficients with the same region, or a bank profile does not add distinct inventory. Source content and learner history are preserved.
