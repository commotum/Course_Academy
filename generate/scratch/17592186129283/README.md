Run from repository root:

```sh
.venv/bin/python generate/scratch/17592186129283/validate.py
.venv/bin/python generate/scratch/17592186129283/validate_concurrent.py
.venv/bin/python generate/scratch/17592186129283.py --difficulty all --seed 9 --count 2 --format json
.venv/bin/python generate/scratch/17592186129283.py --difficulty moderate --template q-160601 --profile observed --seed 2
```

API: generate(level,seed=0,template=None,field_type=None,parameters=None,profile=None), generate_easy/moderate/hard. Source parameters are h,k; authored parameters add a,b,orientation. Original replay uses h=k=0 and original profile. Field type radio only. Explicit invalid inputs reject whole instances. Review files compare every original family and two generated variants per template, with authored levels labeled. validation.json separates original bank/field repairs, displayed math checks and native grader results. Cached parser and Matplotlib dependencies are used read-only. No database writes.
