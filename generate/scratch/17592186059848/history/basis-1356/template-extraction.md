## 4. Reusable Markdown/value template

Fixed prompt: “Which of the following statements are true regarding the matrix $NAME$ given below?” Three ordered statements use the observed bullet/roman layout followed by NAME=[matrix] in display math. Fixed solution opening and cofactor explanation follow the captured sentences. Variable components: all nine exact entries, three determinant claims at applicable positions, matrix name, evaluated minors/products/determinant, truth conclusion. Source formatting style retains optional ne0, trailing explanation spaces, and blank line before Since. Malformed bold is repaired. No distractor-specific feedback is added.

Full solution stages: determinant matrix → first-row minor expansion → evaluated pair-products in minor parentheses → evaluated minors → evaluated signed terms → determinant. Compact stages preserve the same first three stages, combine unit-coefficient pair products with evaluated nonunit-coefficient minors, then determinant. Parentheses, explicit multiplication, product order, and zero terms are canonically rendered; the same stage count and every complete equality are replay-checked, not asserted byte-identical.

Constraints: nine real finite exact algebraic constants, exactly three claims matching statement kinds, one capital name, distinct determinant claims, and a complete five-choice bank with one unique correct truth subset. Explicit invalid input fails; sampled invalid input rejects the whole instance. No floats, symbols, nonreal radicals, infinity, duplicate semantic options, or missing choices. Identity covers learner prompt/solution and the complete displayed bank; seed and shuffling are excluded. Mathematical fingerprint excludes matrix name and bank.

Sampling bounds (authored policies): easy/moderate base entries −5..8 (covering all observed integer entries), hard base entries −4..4 to control exact arithmetic, singular third row u*r1+v*r2 for (u,v) in {(1,1),(2,−1),(−1,2),(1,−2)}, or independent nonsingular rows. Easy keeps integers. Moderate applies one fraction column 1/d, d∈{2,3,5,7}, one radical column sqrt(q), q∈{2,3,5,7}, or both in different columns. These observed number types can coexist as in q-128490/q-128484. Source matrices with mixed kinds within a column remain supported by explicit replay; column scaling is a documented narrower sampling policy, not a claim that all observed structures arose from it. Hard requires all nine entries nonzero and applies sqrt(q)/d, 1/e, sqrt(q)/f to three columns (d∈{2,3,4,5}, e∈{2,3,5}, f∈{2,3,4}). This repeats a supported radical family and keeps exact products within source fraction/radical arithmetic. Both determinant-zero/nonzero states are sampled; numeric claims choose exact det or independent small integers −10..10, 0, ±1. Default easy/moderate banks are selected from the profiles actually observed for that template. Hard and explicitly requested cross-template banks reuse an entire observed categorical bank and label it authored-reuse/profile_extension; no option is mixed into another bank.

Generalization limits: observed categorical bank fragments are exact. Original distractor-making intent is not recoverable and is not claimed. The source mathematics has no detected errors. The duplicate field, missing legacy correct ref, and malformed bold are documented in classification and counted separately in validation. Hard is authored because no source difficulty label supports it. The density policy is a scoped design claim, anchored to named moderate originals and the lesson definition.
