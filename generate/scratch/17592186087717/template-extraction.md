# Template extraction

## 1. Specific source descriptions

`source-bank-extraction.json` records all 18 originals individually: exact printed x(t), y(t), ordered sampling times, every cell/slot, requested a/b/c combination, original field key/type/shape, every option and designation, complete raw prose and ordered mathematical components. `source.json` retains the complete basis-1356 wrapper. `widget-evidence.json` retains the original q-6827 widget metadata/layout/bank. Raw evidence is never overwritten by repairs.

The sources include affine, quadratic and cubic polynomials; simple rational quotients; a shifted square root; and sine/cosine/tangent at familiar exact angles. All answers require substitution at three specified times. Radio responses combine those values with the printed coefficients ±1; blank responses give each coordinate directly. Times are ordered but may skip values (q-6827); grids and every provided cell are preserved.

## 2. Generalized descriptions

Observed templates ask for three coordinate values from two explicitly printed parametric equations. Eight observed templates use one five-choice scalar answer; eight use three math blanks. Two fieldless sources retain a linear-combination request and receive one authored scalar blank. The instructional purpose is reading the correct row and time, substituting with correct sign/order, and carrying out exact arithmetic.

## 3. Component and bank mapping

The JSON inventory maps each choice to its field, exact value, correct designation (null where absent), and complete bank profile. Each source radio has one distinct whole `observed-scalar-replay` bank identified by its template. The explicit replay operation is k×source scalar for every bank member while both printed coordinate functions and the requested linear combination are scaled by k. This is a parameterized evidence recipe, not a recovered theory of the original wrong answers.

Before preserving those banks, the extraction enumerates actual supported mistakes: reverse the full combination sign; reverse or omit each a/b/c term; use the opposite coordinate at the same printed time; negate the input; or use every other printed sampling time for each slot. `supported_operation_matches` records every exact match per option, including ambiguous multiple matches and empty residual lists. A unique numerical coincidence does not establish author intent. Complete banks include opaque residual scalars, so no partial inferred bank is promoted to normal default output. All 32 original distractors and all eight whole banks reproduce numerically under the explicit replay profile.

The authored default five-choice bank is chosen as a whole: correct combination, its negative, and reversal of each individual a/b/c sign. All values derive from the assessed substitutions. Any zero/collision rejects the entire sampled instance; no replacement pool or unrelated perturbation is used. Normal independent coefficients are sampled again as one instance. Explicit invalid parameters raise an error.

## 4. Reusable templates and constraints

Source rendering stores complete x/y expression spans within the one formula token. Scaling replaces those slots only; prose and adjacent function components are protected. Each source table is regenerated by axis and time; unit coefficients omit redundant multiplication. Every equality stage's numeric RHS is scaled, preserving the original number/order of substitution and simplification stages, including omitted redundant rows. Shared solution prose is retained, with no learner-facing distractor feedback. The original completed tables retain every cell. Unit-scale source replay normalizes math whitespace and mathematically equivalent LaTeX scalar notation; prose/sequence comparisons cover the entire solution.

k∈{-3,-2,-1,1,2,3}; source replay uses k=1. This bounded scale route is for observed fidelity/evidence. Normal generators also vary independently authored affine/quadratic/cubic coefficients, rather than claiming scalar rescaling alone establishes variety. The easy affine family has six nonzero integer slope choices per coordinate and seven shifts, with both blank and radio layouts. Moderate/hard bounds and fixed workloads are in classification.md. Explicit parameters obey the same absolute-value bounds as samplers.

Content identity includes version, complete displayed prompt, fixed solution, owned complete bank and canonical mathematics. Seed and choice order do not affect it. A separate mathematical fingerprint uses canonical coordinate expressions, actual times, assessed cell locations and the combination expressed by coordinate/time symbols; equivalent coefficient spelling and different answer banks do not create new mathematical tasks.

Minimal supported source corrections (raw preserved): q-69923 `b=2(-2)-4` → `b=2(-2)=-4`; q-326242 solution x(2) → x(3); q-326250 y(0) → y(5); q-326255 y(1) → y(4); q-6832 b/c substitution prose y=sin → x=sin; q-6825 final c substitution labeled a → c. Eleven complete solutions are unchanged except whitespace, six are minimally repaired, and q-6827's missing solution is authored. Correctness of every actual displayed stage and coordinate label is checked independently.
