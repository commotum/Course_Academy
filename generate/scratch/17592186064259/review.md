# Review

The seven `*-review.md` files show each original prompt, complete bank and available
worked solution alongside a completed replay and two variants. The review keeps
moderate difficulty, supplied polynomial and slope, branch request, field layout,
and derivative/equation/root-selection stages consistent. The normalized TeX and
explicit radio placeholder are intentional presentation changes; exact source
whitespace and wording fidelity are not claimed.

Quadratic variants change coefficients, tangent slope and exact roots; cubic
variants change the two eligible tangent locations or the repeated location and
coherent coefficients. The positive request remains positive, the pair request
remains a complete pair in one radio option, and blanks retain numeric fragments.
All profiles replay their original complete mathematical bank, with no extra or
missing distractors. q-48692 and q-48816 have inferred keys in authored completions;
the source missing keys and unrated status remain unchanged. q-343737's final
slope is corrected in authored local output; its original solution is unchanged.

No plot assets need visual inspection. The application native grading report
checks every radio option and equivalent/correct/incorrect numeric blank inputs.
Independent validation reads the actual printed curve, slope, derivative rows,
slope-equation rows, branch selection and banks, rather than trusting metadata.
Seed-independent replay, vertical-translation deduplication, profile coverage,
signed coefficient domains and unsupported-level guards are checked separately.

The commit review is saved under `reference/replenishment/basis-*/review.md` with
only currently needed, unshown, unreserved, mathematically distinct instances.
