# Plot extraction and reuse

All ten source plots were visually inspected together and checked against the
source coordinates and orientation. They show black coordinate axes, labelled
endpoints, blue straight/curved path pieces and arrowheads for traversal. There
are no field coefficients or integral values in these assets. The moderate
plots show two connected straight pieces; the hard plots include respectively
y=x^2, y=4-x^2, y=-x^3 and y=-sqrt(x), with their source endpoints.

The exact source references and byte hashes are recorded in components.json.
They remain in the prompt in their original position. Whole-field scaling
changes no plotted object, coordinate, label or arrow, so all assets are reused
unchanged: new-plot rating **none**. There are no answer or solution plots.
No new rendering is necessary for this bounded parameter domain. Preparation
checks the existing content-addressed filenames and SHA-256 bytes again.
