# Plot extraction and generation

All 13 distinct source asset byte sets were inspected in source-plots-review.png. Prompt plots show a blue unit circle centered on an orthogonal black x/y axis, grid and ±1 labels, first-quadrant radius OP, P marker, and a gold theta sector measured from the positive x-axis. q-64974/q-65073 are steep; q-124789/q-124791 are near diagonal; q-124796 is nearly vertical; q-64730/q-65072 are lower diagonal; q-65075 is steep. Five solution plots add P(cos theta,sin theta) at the same point. q-124796/q-64730 have no solution plot; canonical e-3485 reuses q-65072's prompt plot. Individual references and placement order remain in source-components.json.

The first quadrant is mathematically essential to positive root selection. Grid color and incidental padding are styling; radius orientation changes with the supplied coordinate. Fixed topology: one unit circle, orthogonal axes, one radius, one point, one first-quadrant central angle. Variable: x/y of P, radius direction, sector end angle and associated label position. Solution plot additionally labels the coordinate/angle relation. No plot carries numeric answer choices.

render_plots uses Matplotlib, 4.1-inch square figures at 120 dpi, equal aspect, bounds ±1.95, ±1 grid labels, 721 circle samples, black arrows and radius, blue circle, gold Wedge. The point, segment and angle derive from exact sqrt(n)/d and sqrt(d²−n)/d, converted to floats only for plotting. Original parameters reuse unchanged source assets for exact replay. Changed parameters receive prompt and solution figures together, in the original order. The helper is deterministic and resamples nothing. No SVG renderer.

variant-plots-review.png and individual selected commit assets are visually checked for labels, clipping, overlaps, quadrant, scale and angle alignment. Database preparation hashes PNG bytes with SHA-256, publishes through ImageLibrary, rewrites Markdown to images/<prefix>/<hash>.png and verifies stored bytes. Exact publication evidence is in reference/replenishment.
