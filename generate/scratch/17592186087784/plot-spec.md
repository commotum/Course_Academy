# Four-stage plot extraction and renderer specification

1. **Observed plots.** All 31 assets in `plot-inventory.json` were visually inspected via `source-contact-0.png` through `source-contact-3.png`; the original MA q-79205 graphic was inspected independently. Prompt graphics have white/transparent background, black x/y axes with arrowheads, blue solid assessed arc, blue filled endpoint dots, and numerical cardinal axis ticks. Worked graphics add the full circle in dashed blue, four cardinal θ labels, noncardinal endpoint labels, and a counterclockwise tangent arrow. Translated-circle graphics retain Cartesian axes and dashed horizontal/vertical guides through the center. q-79165, q-79168, q-321947 additionally show a dashed ray to the noncardinal endpoint and an orange familiar-angle cue relative to the vertical axis. There are zero plotted answer choices.

2. **Generalized purpose.** The prompt gives the arc geometry without revealing its θ domain. The solution adds the parameter angles and traversal direction, making the restricted angular interval visible.

3. **Components.** r,h,k control the numerical circle, endpoint coordinates, guides, ticks, and bounds. Exact rational a,b control the solid assessed arc and closed markers. The four cardinal θ values and any noncardinal endpoint control solution labels. Orange cue = difference from the next cardinal ray; it is displayed only for a noncardinal endpoint and never exposes the entire assessed interval. The complementary context is dashed; it cannot be confused with the solid assessed segment.

4. **Reusable specification.** `render_plots(parameters)` sends the exact normalized instance, with no further sampling, to `renderer.py`. That script uses Matplotlib only, with 250 solid-arc samples, 300 full-circle context samples, equal aspect, white background, and bounds including axes origin plus circle extrema and radius-scaled padding. Radius/center and exact angles are converted to numerical coordinates only here. Prompt and solution assets have stable names under a parameter/plot-version hash; `spec.json` records all inputs, bounds, orientation, speed, endpoint convention, Matplotlib/Python versions and read-only cached dependency paths. The main Python 3.13 environment lacks Matplotlib; the renderer uses existing cached Python 3.10 wheels without installation or changes to shared environments. No direct SVG or image model is used.

Prompt and solution share the same geometric curve. The solution arrow is derived from increasing θ on the assessed interval. [π,2π] shows θ=2π at the rightmost endpoint; [0,3π/2] shows θ=0. The mathematically identical 0/2π location is represented once to avoid overlapped text. The cue and exact markers survive source replay and authored angular/center changes. Source and generated review sheets support checking bounds, circle shape, direction, endpoint closure and readability.
