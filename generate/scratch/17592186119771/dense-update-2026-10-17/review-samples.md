## easy lower

How can we best describe the following matrix?

$$
A = \begin{bmatrix}-9 & 0 \\ -1 & -2\end{bmatrix}
$$

Choose the most specific listed description: identity before diagonal, and diagonal before upper or lower triangular. Choose Other only if none of these descriptions applies.

- [x] Lower triangular matrix
- [ ] Diagonal matrix
- [ ] Upper triangular matrix
- [ ] Other
- [ ] Identity matrix

Notice that $A$ is a matrix for which all entries above the diagonal are $0$'s:

$$
A = \begin{bmatrix}-9 & 0 \\ -1 & -2\end{bmatrix}
$$

Therefore, it is a lower triangular matrix.

It is not an upper triangular matrix or a diagonal matrix since there is a non-zero element below the diagonal: ${a}_{21}=-1\ne 0.$
