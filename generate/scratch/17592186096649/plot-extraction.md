# Plot extraction and reusable specification

1. Original specific plots:12 practice PNGs with transparent background. Prompt arrows are black, single choices orange, and paired choices blue/orange. Source drawings have no axes, ticks or grids. Bold/italic math labels lie near the arrow midpoints. Each source uses a common physical pixel scale across its prompt and options, although individual image extents differ. For q-11324 the base length is about99 pixels; q-12140 about198 pixels. Captured pair labels remain3a/−a even in the wrong-length/direction options. Exact path values and original dimensions are preserved. White-background copies live in originals/ for full-resolution review; source files themselves remain unchanged.

2. Shared pattern: straight arrows with explicit directed tips and nearby vector labels. Required mathematical content is orientation and relative length, including reversals. Position/translation, margin and typography are incidental. This is heavy plotting because prompt and all five options carry the assessed data.

3. Components: nonzero exact scalar multiples of a=L(cosθ,sinθ); arrow tails chosen for clear translated placement; tips tail+vector; correct full bank selected before rendering; requested labels on all options; consistent black/blue/orange colors. No coordinate-reading demand is introduced. Every original bank's arrow tails and tips, with actual raster stroke/head checks, are recorded in source-raster-checks.json. Canonical prompt and both solution diagrams were inspected separately.

4. Matplotlib specification:600 × 600 white PNG, equal x/y physical scaling, all axes/ticks disabled, fixed shared bounds calculated from the prompt and complete bank. A shared viewport prevents autoscaling from turning unequal magnitudes into equal-looking arrows. Pair vectors are translated into two separated parallel lanes; labels use measured text extents and a perpendicular clearance derived from their actual rendered sizes. No white masks are used. Actual text box/arrow distances exceed3 pixels, every text box lies inside bounds, and label boxes cannot overlap. Sidecars retain renderer/Python versions, real text boxes, transformed arrow tails/tips, bounds and raster data. PNG+JSON both required for cache hit.

The renderer uses the cached Python3.10/Matplotlib dependencies read-only; it installs nothing. Unique private temporary JSON files and atomic PNG/sidecar writes support concurrent calls. Original rasters may be reused only when complete extracted geometry and labels match the source. Changed-parameter prompt and complete choice banks are freshly rendered, never source path replay alone. Exact symbols use SymPy; numeric conversion happens only for raster coordinates. Validation independently reads actual prompt expressions and actual displayed plot geometry/labels, checks complete response eligibility, and tests raster strokes as well as cached sidecars. No SVG or image-generation model is used.
