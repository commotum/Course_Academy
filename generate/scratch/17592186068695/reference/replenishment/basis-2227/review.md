Select all that apply.

- **I.** $x=- \frac{9}{2}$
- **II.** $x=-3$
- **III.** $x=- \frac{3}{2}$

- true
- false

- true
- false

- true

Worked solution:

Let's consider each point separately.

- The function $f(x)$ is not continuous at $x=- \frac{9}{2}.$ Because there is a jump at $x=- \frac{9}{2},$ it is impossible to draw the function in the neighborhood of $x=- \frac{9}{2}$ without taking our pencil off of the paper.

- The function $f(x)$ is continuous at $x=-3.$ The graph can be drawn in the neighborhood of $x=-3$ without taking our pencil off of the paper.

- The function $f(x)$ is not continuous at $x=- \frac{3}{2}.$ Since there is a break at $x=- \frac{3}{2},$ it is impossible to draw the function in the neighborhood of $x=- \frac{3}{2}$ without taking our pencil off of the paper.

Hence, the correct answer is: "II only".
