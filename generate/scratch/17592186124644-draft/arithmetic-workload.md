# Coupled arithmetic workload policy (v2)

Root independently verified the v1 mathematics and source fidelity but rejected its arithmetic scope. Small coefficient guards had admitted 11664−2e²/3, 8748−e/2 and 3069/16, far above the source examples 3−e and7. V2 rejects those explicit calls and limits the actual point-evaluation work. The immutable source wrapper and source bank profiles are unchanged.

Candidate coordinates/exponents are listed in domains.json. They are catalogs, not a Cartesian eligibility promise. The same public generation path checks every candidate's evaluated factors and products, then the entire completed bank. A failure rejects the complete tuple. Explicit inputs cannot bypass the policy; random generation resamples within the selected family. Positive coefficients remain integers 1..4, but most families couple them to powers, point values or contribution coefficients.

Every normal option, including both wrong/wrong pairs, is independently evaluated. Rational coefficient numerator/denominator caps per family are in WORKLOAD_HEIGHTS and domains.json. For pure rational answers these apply to the complete reduced scalar, so a modest-looking difference cannot conceal a large collected fraction. For π/e/log expressions they apply to each reduced rational coefficient; the factor-specific bounds above prevent large transcendental inputs or hidden powers. Numeric Euler-e products remain explicit, and familiar logarithm arguments are never compressed into enormous integers.

The independent auditor reads the actual printed function and ordered point, factors each summand into held/active parts, differentiates it, and checks all factors/contributions/options from those expressions. It does not trust generation parameter or arithmetic metadata. enumerate-domain.py exercises every finite explicit tuple, including every endpoint and every rejected boundary combination. finite-domain-counts.json records accepted and rejected counts, observed metric maxima, whole-function tasks and conservative restricted-function tasks. The latter collapses, for example, changes to a held exponent that evaluate to the identical coefficient at coordinate1. Variable letters and option/profile aliases never inflate either count.
