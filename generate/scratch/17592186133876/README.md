# 2D divergence generator

Run from repository root:

```
.venv/bin/python generate/scratch/17592186133876/validate.py
.venv/bin/python generate/scratch/17592186133876.py --difficulty all --seed 19 --count 2 --format markdown
```

Public Python entrypoints: generate_easy, generate_moderate, generate_hard and generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None).

Normal profiles are authored operation banks over observed function families and two missing-hard extensions. Raw profiles (`raw:q-...`) are public parameterized evidence replay, with a nonzero integer whole-field scale c of magnitude at most 4. Original raw cases use c=1, retain key omissions and complete original solution sequences, and are marked ineligible for learner generation. Unknown scalar error intent is not claimed recovered. No source bank lookup is used to choose the correct answer; raw designation is captured evidence and mathematics is checked separately from it.

Review.md contains all 14 originals, 28 scaled raw evidence variants, and 32 authored standalone variants (two per template, including each of all three levels). Review.json contains the 60 generated records. Source-cases.json replays all originals through the public API.

Source errors and supported repairs are itemized in template-extraction.md. A real logarithm at a negative argument remains evidence-only; inherited fields are supplied in normal output; unrated missing designation/solution remain absent in raw output. Normal records use only bounded exact arithmetic, complete owned answer banks, and deterministic UUID identities. No database writes.
