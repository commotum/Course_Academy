# Spatial arc length generator

Run `.venv/bin/python generate/scratch/17592186119860/validate.py` from the repository root. CLI: `.venv/bin/python generate/scratch/17592186119860.py --difficulty all --seed 42 --count 2 --format json`.

Scope: exact arc-length evaluation for ten three-coordinate curve families. Seven observed easy templates, one observed moderate, one observed hard; the unrated logarithmic source receives an authored moderate level. All five-choice banks and all available worked-stage sequences are replayed. Observed scalar-bank intent is underdetermined, so those explicit evidence-only profiles are separate from authored defaults. No database writes, registration, engine changes or commits.

source.json retains basis/lineage and original questions. source-cases.json lists normal-generator replay inputs. template-extraction.md and bank-mapping.json account for every original choice and identify source repairs. review.md/review.json include every original plus two changed-interval examples per family (one replay-profile variant and one authored default). validation.json separates bank fidelity, designation availability, presentation repairs, independent displayed-stage mathematics, enumerated interval variety and native grading. The frozen generator SHA is in validation.json.
