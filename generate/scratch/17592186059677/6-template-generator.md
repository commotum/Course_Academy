# Generator and validation

`../17592186059677.py` is the local generator. `math_format.py` is a private frozen copy of the repository formatter, loaded by exact local path; eligible authored records are normalized before IDs and checked at the public boundary. `observed_raw` deliberately returns immutable original records without normalization, including whitespace, source identifiers, enum Pull shapes and omitted attributes. Both raw API metadata and the source review call these evidence-only. `faithful.py` separately supplies five eligible source templates, preserving original full banks, prose and all ordered rows; these are not raw-copy substitutes.

The public APIs enforce one finite coefficient/target domain, fixed field types, whole-bank uniqueness, and fixed derivative order. The default seeded sampler chooses only valid complete instances. The CLI enumerates that same inventory without replacement; a count above mathematical capacity fails before printing any data. The inventory schema includes database/basis/lineage and `questions[{record, role, relationship_to_source_templates}]`. Each record labels whether it instantiates a faithful source template or a separately authored extension; raw MA evidence never enters this inventory.

`validate.py` independently reads actual printed mathematical inputs, complete formal operators and orders, all intermediate rows, evaluation names/points, and full banks through the private `readback.py`. It verifies both radical and power representations on x>0, domains, field-owned keys, exact source record equality, source absence parity, complete source banks, deterministic replay, every bounded instance, and explicit API failures. Changed-target cases hold other parameters constant and check every target reference; deliberately stale target prose and doubled formal derivative operators must fail.

Every eligible instance is submitted to the native frozen `course_academy_engine::learning::grade_field` through `generate/runs/current/check-engine`, SHA256 `71d435e31aa0cdea66d992aa4d4bd1043cdd871aaffc7a3af9f54e9b0f846dea`. All five owned radio identities are checked; blanks check canonical and equivalent entries and check 0 and 1 against the actual result, and reject correct+1. Malformed math, empty answers and foreign/malformed choices are recorded separately as diagnostics, with no hidden owned-choice or blank grading gap. Raw incomplete records are not submitted as learner-ready fields.

Run `.venv/bin/python generate/scratch/17592186059677/validate.py`. `validation.json` records capacities, source fidelity, printed-math coverage, native outcomes and CLI checks. `review.md` presents each original alongside authored boundary and changed-target examples. `freeze-manifest.json` hashes the generator, validator, private helpers, evidence and reports. No database write, registration, shared QA change or commit is performed by this worker. Completion remains subject to root QA.
