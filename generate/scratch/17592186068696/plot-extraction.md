# Plot extraction / renderer specification

1. **Specific plots:** each of 36 native-resolution PNGs is individually recorded in `plot-spec.json`: exact source path/hash/dimensions; fitted black-axis origin; independently read unit tick calibration; every open/filled marker; each asymptote; all red branch samples; crop bounds. Native-resolution inspection sheets preserve all originals, including every distractor and solution highlight. There are 43 open/filled point markers. All red branches are solid; no source red curve arrowheads exist. Positive axes have black arrowheads. Cropped tails do not imply included/excluded finite endpoints. Continuous corners are distinct from breaks.
2. **General pattern:** coordinate-plane function graphs with red branches, hollow circles for excluded points, filled dots for assigned values, and optional grey/blue asymptote guides or highlighted blue markers. Correctness follows branch connectivity and marker roles, not slope smoothness.
3. **Components:** source red branches are numerically traced per connected component after removing each independently transcribed marker region. Curves are x-column ordered raster-derived polylines; unlabeled y values preserve pixel geometry only. The canonical plot has a different origin/scale and labelled y scale; it anchors scope, not new assessment formulas. Marker types, x coordinates and asymptotes are not inferred from a source answer key. The marker center is refined against actual raster ring/filled pixels. The validation transcript is separately fixed and checks each against original colored pixels. The unshown one-sided asymptote at x=0 in q48088 is recorded despite having no separate dashed guide (it lies on the y axis).
4. **Reusable specification:** transform each branch and marker x coordinate by the instance's positive affine map. Keep each graph's own fitted bounds/scale and vertical silhouette. Matplotlib renders every changed plotted bank member separately, with readable tick labels, open/filled markers and axis arrows. The moderate/hard authored curves place exact graphical holes/jumps and asymptotic tails; vertical reflection is optional. Moderate half-unit ticks use adaptive figure width to keep signed coordinate labels legible. Hard keeps unit ticks so midpoints must be read. One connected hard corner is never included in the key.

Exact anchor replay reuses unchanged source images; changed parameters always invoke Matplotlib. No image model, direct SVG, invented exact source formula, or database registration is used. `extract-plots.py` is the reproducible local extraction utility. Its source transcription table is visual evidence, while branch tracing is image measurement. Every final PNG has a sidecar with the exact displayed geometry, tick transform, renderer/runtime versions, and image hash. Generated raster checks inspect actual hollow/filled marker pixels under the recorded axes transform, independently of graph metadata's break list. Graphical solution/key readbacks derive discontinuities from the actual plotted endpoint/asymptote components and parse displayed coordinate values separately.

Source curves have raster precision and unlabelled vertical values; their mathematical topology and labelled x coordinates are asserted, their original analytic formulas are not. Marker removal can leave small stroke-width gaps around the ring, an explicit trace limitation. This does not move the hollow/filled endpoint or add a new labelled break. Cache assets remain retained during parent review. Unique temporary files plus a renderer lock make fresh concurrent same/different-parameter calls deterministic; atomic PNG/sidecar writes are checked for mixing and hashes.
