# Plot extraction and construction

All source prompt and solution assets are retained by reference in `reference/initial/source.json`, shown in the inspected `reference/initial/source-contact.png`. The source prompt figures use coordinate axes, the relevant circle arc, straight cutting line, pale blue fill, a D label, equations, ticks and intersection guides. The solution figures add orange angular rays, angle labels and polar radial-bound labels. Figures show either a complete circular cap or a single quadrant's half-cap; that region distinction is essential. Circle and line coordinates, signs, radius, shading, orientation and angle limits carry mathematics. Typeface, exact blue shade and incidental whitespace do not.

`render_plots` uses Matplotlib only. Exact instance bounds define the polygon between lower and upper radial curves over the declared angle interval, so the source's topology and selected region are preserved. The prompt figure labels the actual Cartesian circle and cutting-line equations. The solution figure adds the actual bounding rays and angle interval. Detailed radial equations are in the adjacent worked solution. Both plots use equal aspect, labeled coordinate axes, blue shading, D, automatic padded bounds and readable titles. Black/white-background inconsistencies in the captured assets are normalized to white. There are no resampled plot parameters and no direct SVG renderer.

Scale varies center, radius, offset, polygon and equations together. Angular limits and region orientation are fixed per template. Source scale 1 and changed scales 2/3 are reviewed side by side; boundary scale 12 is mathematically checked. Asset names hash generator version, template and scale. Content hashes are computed separately at publication. New questions reference the existing content-addressed database image store only after stored-byte verification. Unchanged source records and source assets are never rewritten.
