New scalar denominator d produces basis coordinates divisible by d so all endpoints remain exact grid intersections, and ratio reading has a substantive lattice scale. Most normal figures use nonparallel oblique bases `(2d,d)` and `(-d,2d)`; authored hard uses `(d1,0)` and `(0,d2)` to keep two fractional ratios legible. Hard reverses the component traversal. Arrow origins/endpoints, scalar labels and path corner are all from one question instance. Sidecars capture plotted coordinates, labels, unit grid and renderer/dependency provenance. Adaptive vertex labels move outward from triangle centroid away from incident arrowheads; white backing preserves visibility. Version 2 fixes the initial target-label collision observed by parent QA. Old artifacts remain retained.

Unchanged source plots reuse exact captured factors/names/path geometry; changed cases use regenerated coherent grids rather than claim pixel-exact source styling. Ratings remain heavy. No direct SVG, external image model, or independent plot resampling. Fresh concurrent rendering uses unique input and temporary output paths followed by atomic PNG/JSON writes. Both PNG and sidecar are required for a cache hit.
