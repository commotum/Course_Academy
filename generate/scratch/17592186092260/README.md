# Linear exponent exponential generator

Run `.venv/bin/python generate/scratch/17592186092260/validate.py` from the repository root. Preview `.venv/bin/python generate/scratch/17592186092260.py --difficulty all --count 2 --format json`.

API: generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None), generate_easy/moderate/hard. Source-case templates use their q IDs; hard uses shifted_tangent. Public raw:q-ID profiles retain absent fields, difficulty, worked solutions and refs; they are evidence-only. The completed profile is an alias for normal authored-method output: it supplies supported fields, independently derived answers, and authored complete method banks. It never promotes a raw historical opaque bank to learner eligibility. All normal radios have five choices; blanks are expression/scalar fragments. Tangent equations use radio fields.

Frozen provenance is math basis 1356. source.json is unchanged capture evidence; source-cases.json drives raw replay, masks.json contains extracted parameterized components. Review labels originals and generated variants separately. No database reads/writes, registration, engine changes or plots occur.

Historical opaque banks are retained as evidence and replaced by explicitly authored method banks in normal output. Hard is an authored design claim using only linear exponents and source-grounded tangent arithmetic.
