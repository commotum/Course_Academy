# Surface-integral Stokes generator (step 7 draft)

Run `.venv/bin/python generate/scratch/17592186133928/validate.py` from the repository root. Preview with `.venv/bin/python generate/scratch/17592186133928.py --difficulty all --seed 17 --count 2 --format markdown` (or `json`).

The API is `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` and the three individual difficulty entrypoints. All normal fields are five-option radio. Normal parameters are nonzero signed integers a,b,d,c, absolute value ≤3; bilinear source b,d ≤2, exponential source d=b, authored easy d=1. Explicit bad inputs fail, never resample. Family and complete bank are selected before sampled parameters; collisions reject the whole instance.

`profile="raw"` uses the 11 source family names, field-scale parameter c (nonzero integer |c|≤4), full extracted masks and entire original banks. Unit scale normalizes ordinary factors to reproduce source wording/rows exactly. Every scale changes the actual full field and every field-dependent value/stage. These opaque historical banks and malformed original records are evidence-only and ineligible; no distractor intent is claimed. They are not defaults. Normal profile `method` uses source-shaped boundary/field families plus authored easy, independently computed math and method-derived wrong operations. Normal solutions use shared source sentences with authored vector notation and expanded stage layout.

`source-errors.md` documents raw errors, missing keys, and minimal mathematical repairs. `source-cases.json` replays all originals through the public API. `source-masks.json` records component masks, not answer tables or branches returning original payloads. `review.md`/`review.json` show every original and two generated examples per observed family, plus two authored easy examples. Native raw malformed fixtures are not claimed as passed. No plots occur. No database operation, registration, shared-file modification, engine modification or commit is performed.
