## Stage 2 — Shared pattern

Select the graph of the supplied unscaled exponential growth function y=b^x+c.
Translate y=b^x by |c| units up/down. Correct graph remains increasing, approaches
y=c as x→−∞, and passes through (0,1+c). The fixed solution has: first unshifted
graph; translation sentence; intercept change; asymptote change; overlay graph.
The same solution is provided regardless of selected error.

## Stage 3 — Components and complete banks

The table maps every option to its field, source profile, image and labelled
mathematical features. Historical intent is unresolved wherever a distractor
has an unexplained amplitude/constant. The public evidence profile parameterizes
each labelled source pair (A,C) as amplitude A and asymptote c+(C−c_source),
with the original exponent orientation. At original parameters it reuses exactly
the observed raster; at changed parameters it renders that explicitly declared
feature continuation. It does not claim recovery of the historical error recipe
or horizontal base. Explicit feature continuations require 1<b≤9, |c|≤4, c≠0 and reduced denominators at most 4, limiting numeric and label workload. These entire observed profiles are evidence-only and never
selected by default. A raw legacy source's correct plot is independently inferred
from asymptote/intercept/orientation (q-25154 option 4; q-25292 option 4); its raw
record still has no correct reference and cannot be natively graded.

Two authored complete profiles supply default generation. `authored_transformations`
uses (A,C,D)=(1,c,+1), (1,−c,+1), (1,c,−1), (1,0,+1), (b,c,+1): correct translation,
reversed shift, negative exponent, omitted shift, base mistaken for prefactor.
`authored_offsets` uses (1,c,+1), (1,−c,+1), (1,c+1,+1), (1,c−1,+1), (1,0,+1):
correct, reversed shift, moved intercept used as shift, baseline unit subtracted
from supplied shift, omitted shift. These are authored operations, not recovered
source intentions. Every required member is constructed together; collisions
reject the whole instance. The offsets profile excludes c=±1/2,±1 because of
whole-bank collisions. No first-valid option substitution is used.

## Stage 4 — Reusable masks, constraints and scope

One supplied-equation/selection mask with legacy spacing, decimal or fractional
format controls source replay. Complete mathematical components are formatted;
short expressions are never blindly replaced in prose. b and c determine both
graphs, intercept 1+c, shift sign/amount, and asymptote c. Raw source replay
preserves missing difficulty/correct/solution keys and exact original Markdown.
Question/field/answer UUIDs are owned deterministic review identities; enums are
plain schema enum strings. Content identity includes version, actual displayed
prompt, solution, complete plotted bank, difficulty and raw presence. The
mathematical fingerprint excludes bank, aliases, seed, option order, and base
magnitude because all options share the same base and recognition here does not
assess recovering it. It includes shift, labelled versus grid response cues and
relevant grid increment. Thus numerical base variation is never counted as new
assessed-task variety.

Easy defaults have integer bases 2…9 and signed nonzero quarter shifts −4…4,
anchored to the observed 3.5 and −0.75. Moderate has reduced rational bases p/q>1
with p≤9, q∈{2,3,4}, and signed nonzero half shifts −4…4, anchored to observed
3/2, 5/3, and 3/2 or integer shifts. Observed moderate demand is fractional-number
recognition at the same translation stage, not additional algebra. Hard is an
explicit authored missing-level design: those rational bases and nonintegral
third/quarter shifts −3…3, with no coordinate/asymptote-value labels; read the
fractional level from subdivided numbered axes. Shift remains supplied, so this
never enters sibling shift-recovery. Signed values are retained at every level.
The hard nonintegral denominator guard is enforced on explicit inputs as well
as sampling. All are dimensionless mathematical curves with x∈R; physical
context restrictions do not apply. Bounds cap arithmetic and plot workload.
Actual finite assessed-task counts and eligible full-bank counts are enumerated
in validation.json; base magnitude and alternate bank aliases do not inflate them.
