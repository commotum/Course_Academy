## 2. Shared instructional pattern

Hard sources retain an additional term, sometimes requiring the single fraction to be written as a sum. Every complete worked solution is fixed independently of a learner choice.

These are fully specified authored operations; there is no learner-facing diagnosis. Every profile is checked at every allowed scalar and both mirrors.
