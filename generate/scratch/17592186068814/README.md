# Graphing a stretched negative reciprocal function

Run from the repository root:

```sh
.venv/bin/python generate/scratch/17592186068814/validate.py
.venv/bin/python generate/scratch/17592186068814.py --difficulty all --seed 41 --count 2 --format markdown
```

Public generate/generate_easy/generate_moderate/generate_hard accept explicit n,d, template and profile. Defaults select complete eligible banks before parameters. `raw_q-...` profiles replay every original bank and parameterize changed inputs. Raw q-97958/q-97963 preserve absent difficulty, solution and correct designation; raw q-99068 retains an opaque doubled-factor distractor. All three are evidence-only. The two missing-designation normal completions are independently derived and native-graded. Hard is an authored same-method extension with larger reduced rational denominators and nonunit marked x coordinates, not an observed source level.

Source bank fidelity, independently read mathematics/plots, and real radio grading are separate checks. validation.json reports exact denominators. review.md/review.json show all originals and two generated variants per profile, plus completed normal anchor records. Work stops after step7; no database/register/shared edits.
