## 2. Generalized pattern

Write the plane curve as f(x,y)=c; compute both partials with the other coordinate held constant; evaluate the gradient at the supplied point; use that vector as the normal line direction. The answer is a complete line relation. A nonzero gradient and an on-curve point are required. Hard sources require a cross-product equation when a direction component is zero. They are observed hard labels, not an invented algebraic progression.
