# Unregistered draft: Adding Non-Square Matrices

This private draft preserves the registered numeric generator and all its evidence. It uses the immutable basis2275 wrapper and all seven MA originals. Seven source masks, six complete historical radio banks, and the six-blank table replay publicly. Raw missing attributes stay absent. Historical banks/completions are explicitly evidence-only; normal defaults cover every source-shaped family with separately authored complete omission/sign banks.

Easy, moderate and hard generators retain six entrywise additions and original solution stages. Missing moderate/hard boundaries are conservative, uncertain authored sign/magnitude workload claims. Details and opaque historical bank limits are in `template-extraction.md`.

Run from repository root:

```sh
.venv/bin/python generate/scratch/17592186054650-draft/validate.py
.venv/bin/python generate/scratch/17592186054650-draft.py --difficulty all --seed 7 --count 2 --format markdown
```

API: `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` and `generate_easy`, `generate_moderate`, `generate_hard`. Source cases supply explicit parameters and `source:<MA-id>`; `source-completed:<MA-id>` is separate inferred completion, never raw fidelity. Normal profiles are `method-omission` and `method-sign`; `method`/`authored-method` alias omission. Source output omits solution/rating/correct attributes where the original did; Markdown CLI handles missing attributes. Every record has actual Python/SymPy metadata and distinct content/mathematical fingerprints.

Validation checks source bytes/presence, full displayed math/stages/banks, every default family/profile, arithmetic boundaries, substantive slots, identity/aliases, mutation failures, and native `learning::grade_field` through memory-only fixtures. It verifies baseline hashes twice. No DB writes, registration, engine edits, shared edits, plots or child agents. Parent QA remains required.
