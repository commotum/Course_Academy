# Four-stage extraction

1. Each original: `source.json` preserves all literal fields; `source-cases.json` gives exact radii and layouts; `option-map.json` maps every displayed choice. Easy radii are (4,2), (8,6), (3,1), (6,3), (6,2), (4,3). Moderate radii are (7/2,2), (8,9/2), (11/2,3/2), (17/2,7/2), (3,3/2), (15/2,5/2). Blue origin-centered wide curves have four labeled intercepts, no grid and no other assessed geometry. Easy numerator/denominator values are integer squares. Moderate radii use decimal intercept labels, with fractional or decimal solution prose as captured. Radio answers are whole equations; blanks are only x²/a²+y²/b² with =1 supplied in the prompt.

2. Shared pattern: read the positive horizontal and vertical intercept radii a,b; insert them into x²/a²+y²/b²=1; square and simplify. Every question assesses this same operation. Shared prose states the origin-centered formula, identifies both radius lengths, and introduces the resulting equation. Source solutions use three rows for integers, four rows for rational blanks, and six rows for each decimal radio. The x-decimal variant squares the integer y radius one stage earlier; the y-decimal variant leaves the integer x radius unsquared through the fractional-conversion row. These distinctions are preserved structurally.

3. Components and complete banks: the following pairs are coefficients of x²,y², each equation having RHS 1. Correct pair C=(1/a²,1/b²). Bank order below is evidence recipe order; display order is shuffled after identities are assigned.

Opaque bank patterns are genuinely parameterized algebraic recipes and can be publicly generated under changed radii, but their numerical replay does not identify the original misconception. They are explicit evidence profiles, excluded from normal defaults. The reciprocal source profile is also retained only explicitly; its constant denominator pattern is not promoted into defaults. There is no answer lookup table and no branch returning a literal source question. Replay constructs prompt, full bank and solution through the normal generator using the original profile. Exact source assets can be reused only for their matching radii/source profile. The source x-compound option retains unreduced 9/(12b) syntax to reproduce 9/24.

4. Reusable masks: prompt is one plot followed by the original question sentence, with the original blank placeholder when required. `solution(a,b,style)` shares all prose and builds distinct unevaluated substitution/square/conversion/reduction masks. Fixed formula is symbolic; radii and numerator/denominator components vary; decimal intermediate rows are conditional on template, not random errors. All bank choices are built together from a profile selected before parameters. The whole instance is rejected for duplicate full equation values, invalid/nonfinite coefficients, or missing unique correct answer. Defaults never replace an invalid option with a pooled substitute. See the source-cases API for exact replay and the finite domain enumeration for changed inputs. Mathematical fingerprints contain only the two assessed radii, excluding profile/layout aliases. Content identities incorporate actual prompt, full fixed solution, field shape and complete bank; changing shuffle order does not change IDs.
