# Wide ellipse generator

Run `.venv/bin/python generate/scratch/17592186087839/validate.py` from repository root. Preview: `.venv/bin/python generate/scratch/17592186087839.py --difficulty all --seed 17 --count 2 --format json`.

API: generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None), plus generate_easy/moderate/hard. Radii parameters are exact strings a,b. Public source replay uses profile="source:q-7603" (or any of the 12 IDs in source-cases.json) with its captured parameters and difficulty. Source profiles use the same parameterized builders; changing parameters produces new math and plots. CLI accepts difficulty/seed/count/format/template/profile. Source evidence profiles are explicit; normal radios use the authored method bank. Worked solutions are fixed per instance and independent of selected option.

Scope: origin-centered wide ellipse equations, read labeled intercepts and square radii. Five observed field/solution templates, five observed radio profiles, six blank originals; authored hard adds two quarter-radius layouts. validation.json separates exact original fidelity, independent displayed mathematics, finite sampler bounds, raster geometry, and native grade_field results. review.md includes every original and two generated examples for every supported template and each observed profile. No database transactions, registration, engine edits or commits. See classification.md and template-extraction.md for difficulty limits and honest opaque-bank findings. frozen-manifest.json hashes private review artifacts and the generator after verification.
