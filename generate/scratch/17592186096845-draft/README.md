# Chain and product rules: unregistered draft

The numeric registered generator and all 65 existing evidence files are preserved by registered-baseline.json. This draft reads the frozen math basis2275 wrapper and keeps one independently authored inventory record separate from all 18 MA sources.

The normal generator serves easy, moderate and hard. Seven observed easy/moderate families parameterize complete prompt, choice-bank and worked-solution component masks. Hard is an authored rating/completion of the existing unrated polynomial product q-11599. Its original five-choice bank is preserved, and the missing key and worked solution are explicitly authored using the same KP product/chain stages and polynomial factoring. No extra radio placeholder is appended.

Every MA source has an observed_raw case. Raw output is evidence-only and preserves prompt/solution/bank bytes, omitted keys/solutions/difficulty/fields and the exact captured record. Ten incomplete/contextual or finite slope-bank records are explicitly excluded from normal serving. The two acceleration prompts do not supply their velocity, so their missing multipart context is never presented to learners.

Template extraction includes full component prototype masks for every supported prompt, all ordered operative solution stages and every option in each complete bank. Whole banks are selected before parameters; collisions reject the entire instance. Variable slots change mathematical inputs, chain factors or polynomial coefficients. Arbitrary symbolic base a, variable labels and option order do not count toward novelty.

Independent validation parses the actual displayed prompt, both product factors, individual prime inputs and results, both evaluated product summands, every displayed simplification, complete banks and keys, and reinserts the blank fragment into the exponential printed outside it. Per-slot bounds and single-slot changes are checked. Native grade_field checks use only in-memory fixtures, the unchanged root binary SHA71d435e31aa0cdea66d992aa4d4bd1043cdd871aaffc7a3af9f54e9b0f846dea, canonical/equivalent blank submissions and ordinary wrong zero/nonzero/correct-plus-one submissions, and all field-owned radio IDs.

Run `.venv/bin/python generate/scratch/17592186096845-draft/validate.py` and preview `.venv/bin/python generate/scratch/17592186096845-draft.py --difficulty all --count 1 --seed 83 --format json`.

No database, engine, registration, shared QA or git mutation is performed. Fidelity, correctness, grading and explicit source exclusions are reported separately in validation.json.
