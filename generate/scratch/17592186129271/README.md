# Direct three-dimensional Jacobian generator

Run from the repository root:

```sh
.venv/bin/python generate/scratch/17592186129271/validate.py
.venv/bin/python generate/scratch/17592186129271.py --difficulty all --seed 17 --count 2 --format markdown
```

The public API has `generate_easy`, `generate_moderate`, `generate_hard`, and `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)`. Only the observed radio layout is supported. `source-cases.json` supplies every original's exact parameter/profile call. The source snapshot is a required read-only local template dependency; mathematical values, derivatives, minors, stages and banks are computed, never looked up from its answer records.
