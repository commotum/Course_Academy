# Vertical asymptote generator

Run from the repository root:

```sh
.venv/bin/python generate/scratch/17592186087842/validate.py
.venv/bin/python generate/scratch/17592186087842.py --difficulty all --seed 12 --count 2 --format json
```

Public API: `generate(level, seed=0, template=None, field_type=None, parameters=None, profile=None)` and `generate_easy`, `generate_moderate`, `generate_hard`. Default families use authored complete method banks or ascending scalar blanks. Source replay uses any `source-cases.json` entry’s level/template/parameters/bank_profile; every original record is retained there. Source profile selection is explicit. All source radio profiles are `evidence_only=true`, `eligible_for_learning=false`; their positive root dilation is an honest mathematical transformation with unresolved original error intent.

Easy factors real denominators; moderate also factors a quadratic numerator; hard combines exactly two proper fractions with four distinct arithmetic stages. No common-factor cancellation, complex-root discrimination, graphing, or database writing. Bounds and invalid explicit inputs are enforced. Changing option order preserves identity. Mathematical fingerprints remove overall rational-function scalars and exclude banks/layouts/function labels.

`validation.json` separates exact prompts, presentation repair, all available solution sequences, original banks, supplied keys, missing-source authored additions, independently parsed mathematics, and native engine grading. `review.md` shows all originals, replays, changed observed variants, and at least two authored examples per family and level. `engine.json` records actual `learning::grade_field` outcomes.


## Public raw evidence replay

Every `observed_<id>_raw` profile is available through the same `generate` API, selected using `source-cases.json`’s `raw_bank_profile`. It performs the same positive dilation of mathematical components and all choices while preserving attribute absence: missing original difficulty, worked solution, field layout and correct references remain absent. Raw q-39790 remains fieldless. All raw profiles are evidence-only and ineligible for learning; completed `observed_<id>` profiles separately carry supported authored repairs. `raw-source-replays.json` contains all ten original raw public replays and ten changed variants. Validation checks the absent attributes, exact available strings/full banks, changed actual function names/poles and deterministic identities. Raw records with absent assessment attributes are not passed to the native grader as if complete learner records.
