# Four-stage extraction

## 1. Specific source descriptions

`source.json` retains all decoded prompt, solution, bank, enum, ID and attribute-presence evidence. `source-cases.json` maps every source individually. Source scalar/formal masks are in CONFIG. All field components are polynomials, some independent of their associated coordinate. Their derivatives must therefore use held-coordinate convention, including zero terms. Source easy integrals supply all six rectangular planes. Moderate supplies four planes plus two inner-variable surfaces. Sources use outward orientation throughout. No units, numerical integration or flux evaluation is assessed.

The source solution route is: theorem statement; formal ordered partials; individually substituted derivative terms (including zeros); collected divergence; theorem's triple integral; region inequalities for moderate; repeated integral in the supplied order. Easy omits redundant region description and uses a two-row triple/repeated equality. No solution depends on which wrong option is selected. Original raw replay preserves all strings at multiplicative identity parameters, including absent worked solution.

## 2. Generalized mathematical pattern

For F=(P,Q,R), use P_x+Q_y+R_z as the integrand. Easy asks only for this fragment. Moderate/hard asks for a full repeated integral over the displayed simple region, with correct differential order and lower/upper surfaces. Never evaluate it in learner content. Family orientations and independent component scales provide unordered same-method variants.

Raw parameter s multiplies all components and every entire option integrand. This is a genuine scalar-field recipe, not literal question replay: source blocks are masks, their expressions scale together, and changed-scale fixtures are checked. Normal component scales a,b,c are independent integers 1..4; h is a surface offset 0..3. Easy box bounds u,v in 1..2 are incidental to the missing-integrand task and excluded from its mathematical fingerprint. Moderate outer bounds retain family rectangles except the explicitly authored positive-domain repair for odd-symmetry families; u,v have no effect there and consequently no effect on identity. Hard u,v control the actual assessed region.

## 3. Complete source-bank component map

Exact values and answer IDs are recorded in source.json, with public original-profile replay. Below each ordered expression is a parameterized shape. They are shape recovery, not claims about original author intention. Raw profile s multiplies every integrand. Each moderate tuple is (integrand,inner lower,inner upper), with outer bounds/differentials as in classification.

## 4. Reusable masks and constraints

Normal source-shaped prompts retain the theorem wording, field layout, number of choices and assessed response. Source theorem/derivative/region/repeated-integral routes are retained with standard TeX spacing, grouped signed contributions, visible escaped set braces and a uniform explicit missing-box token. Complete mathematical components, not short substrings, are constructed. Source raw masks preserve exact decoded bytes at s=1. At changed s their mathematical blocks follow the same route using scaled components and divergence.

Authored easy complete bank: divergence; omit first nonzero diagonal contribution; omit second; leave first component undifferentiated; sum the three components. Authored moderate/hard complete bank: correct setup; omit first nonzero derivative contribution (or differentiate all three components with respect to inner coordinate when only one diagonal term is nonzero); reverse inner bounds; flatten the variable inner boundary by setting outer coordinates to zero; wrong derivative plus reversed bounds. If wrong derivative coincides with correct divergence, sum components is the documented eligible alternative family operation. Five choices are computed together and the whole instance rejected for any collision. No unrelated scalar offsets are used.

Surface gap extrema are checked on the entire rectangle, including stationary points. All coefficients defining hard workload are positive/nonzero. Explicit inputs have the same bounded domains as random sampling. Scalar integration is used only in private QA to rule out complete-integral answer ambiguity; setup eligibility is checked separately. Normal learner solutions stop at setup.

Anomalies: legacy lacks rating/correct ref/solution and uses damaged plaintext `A A A A A` missing content; raw retains it, normal supplies box presentation and authored solution. Three raw moderate solutions use unescaped literal set braces; raw evidence is ineligible, normal escapes visible braces. typeIIIbowl correct setup and rectangular 2xy choice both evaluate to zero on symmetric x bounds. It is mathematically correct to identify the intended setup, but scalar equality makes the historical bank unsuitable for ordinary practice. Raw replay remains public evidence, with equality and setup-eligibility reported separately. Normal chooses a positive x interval and rejects any complete-value collisions. Missing designation never counts as matched.

Identity separates mathematical task and displayed content. Task fingerprints omit incidental easy box bounds, component parts killed by held differentiation, unused parameters and bank/profile aliases. Full content identity includes actual prompt, solution, complete displayed bank, difficulty and correct-attribute presence; seed and option ordering have no effect. Question/field/answer UUIDs are deterministic and field-owned.
