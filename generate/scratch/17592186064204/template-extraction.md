# Negative integer powers of affine functions

Every individual source, prompt mask, worked-solution mask, exact bank value, source answer ID and parameter tuple is in contract.json. Each source is its own template/profile to retain the entire observed bank and ordered solution. The pattern is to integrate n/(a*x+b)^m for integer m>1 by u=a*x+b, dx=du/a, obtaining n/[a(1-m)]*(a*x+b)^(1-m)+C on each interval avoiding x=-b/a. a is nonzero. The source fixed coefficients and powers stay fixed; b varies over signed nonzero integers of magnitude 1 through 12. This includes every observed intercept; zero intercepts and other slopes/coefficient/power combinations are outside this version.

Fixed parts: prompt wording/layout, selection field, five choices, n/a Jacobian, powers, instructional sentences and every intermediate u-expression. Variable parts: every occurrence of the affine input, its domain pole and all dependent choice denominators. There are no optional components. Every complete source choice is mapped to c*(a*x+b)^(-k)+C in choice-recipes.json, with exact rational c and positive integer k. Those are observed value recipes, with no inferred misconception labels. All five choices are selected as one source bank; profiles are never pooled. Each choice must differentiate differently and exactly one must equal the prompt integrand.
