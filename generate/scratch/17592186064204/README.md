# Negative integer affine powers

`.venv/bin/python generate/scratch/17592186064204.py --difficulty moderate --count 5 --seed 1920 --format json` (run from repository root, using `.venv/bin/python`) produces seeded previews. `validate.py` checks all 96 bounded instances: exact full source banks, prompt and solution fidelity, independent calculus readback and real learner radio grading. The bound preserves each source's slope, numerator, exponent and difficulty, varying only signed nonzero intercepts of magnitude 1 through 12. Finite pools contain 60 easy and 36 moderate normalized integrands. Hard is unsupported in this version; see capabilities.json.

`replenish.py` uses the existing EDB integration, configured application contributor, native inventory and application api.lock. It recovers saved requests first, rechecks basis and inventory under the lock and holds the lock through guarded submission and exact-basis readback. Registration uses a stable generator UUID and repository-relative script. It excludes all current practice/canonical mathematical content; seed, IDs and option order cannot create novelty. Requests, preview, receipt, preparation and verification are retained under reference/replenishment. Source records and learner history remain unchanged. The job outcome is written only after verification and a final inventory recheck.
