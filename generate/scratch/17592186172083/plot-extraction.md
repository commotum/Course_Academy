# Plot extraction and specification

1. Specific plots: ten original montages contain all 50 unique source option images. All are square Cartesian grids with arrowed axes labelled x,y, sparse numeric axis labels, orange point markers and blue vectors. Each has exactly three tails; zero horizontal/vertical components appear as axis-parallel arrows. Bounds vary to accommodate tips and tails, notably the larger source exponential and shared-linear cases. The source correct option appears again in the worked solution. No plot has an endpoint label from which the one small q-122745/d443 arrow can be recovered exactly.

2. General pattern: show the same three associated points and a complete candidate vector at each one. Correctness depends on anchoring, direction, zero sets and relative component scale. The actual scalar field and exact points determine correct arrows. Every wrong plotted option has its own complete geometry.

3. Components: white background; Cartesian axes; blue arrows to scale; marked tails; square unit aspect; source integer major grid; authored half/quarter minor grid, major labels still 1. All five generated options share the same symmetric bounds and grid from their union of tails and tips, with one major unit padding. No option gains a different scale. Bounds, exact vectors, exact points, renderer version and dependency versions are stored in image sidecars. The q-122745 precision limit is specific to an unlabelled wrong source vector and does not affect correct geometry.

4. Reusable spec: Matplotlib annotate arrows with mutation_scale 11, blue tail dots, equal coordinate aspect, grid, visible x/y axes, 5 inch square and 120 dpi. Source styling is normalized; instructional geometry is preserved. Assets are keyed by exact data, grid and rendering version. Cache hits require both PNG and sidecar. Each renderer invocation uses its own TemporaryDirectory/input.json; final PNG and sidecar writes are atomic. Fresh identical and different parameter calls are tested concurrently. Unchanged original source geometry reuses the complete original raster only at exact original field/point parameters, preserving the ambiguous unlabelled original exactly. Changed parameters always render through the corresponding geometric operations. Source raster copies and dependencies are hashed in the freeze manifest. No SVG or image model is used.

Independent raster audit is reproducible in source-pixel-check.py and source-pixel-check.json: 50 unique plots / 150 tail-fitted arrow-end proximity checks. Every image uses its own orange tail centers and corresponding coordinates to fit its own grid origin/unit scale; the coordinate residual must be under two pixels. A five-pixel blue endpoint proximity tolerance permits raster arrowhead variation; an endpoint hidden by another orange tail marker permits seven pixels. This proximity check supplements full-resolution visual reading and explicit symbolic bank maps; it does not prove exact fractional coordinates or recover original distractor intent.
