The graph of y=f(x) is plotted above. Given that f(x) is defined on the interval x∈[−10,2], which points represent the global minimum of f(x)?

Select all that apply.

Answer: Point A
Answer: Point B
Answer: Point C
Answer: Point D
CorrectPreview only
Solution:

Answer: Point A · correct value:

true

Answer: Point B · correct value:

false

Answer: Point C · correct value:

false

Answer: Point D · correct value:

false

The global extrema of a function are the lowest or highest points of the function's graph over its entire domain.

The lowest point is the global minimum, whereas the highest point is the global maximum.

According to the graph, the lowest point is A, and so this point represents the global minimum of f(x).

Note: The point C is not a global minimum, it's a local minimum.
