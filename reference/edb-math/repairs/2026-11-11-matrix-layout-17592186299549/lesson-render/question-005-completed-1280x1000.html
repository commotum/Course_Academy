We require a 2×2 matrix T such that

T⋅[xy]=[(−6)⋅x+4⋅y5⋅x+(−3)⋅y].

Notice that

[−645−3]⋅[xy]=[−6x+4y5x−3y].

Therefore, the matrix which represents the linear transformation T is

[−645−3].
