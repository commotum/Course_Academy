A linear transformation T represents a dilation. Given that v=[−105] and T(v)=[−42], what is the standard matrix T of T?

T=
Solution:

Answer 1 · correct value:

25

Answer 2 · correct value:

Answer 4 · correct value:

25

We can write T(v) as follows:

T(v)=[−42]=25⋅[−105]=25v

So we have T(v)=25v, and so the linear transformation T is a dilation with scale factor k=25.

The matrix that represents a dilation of scale factor k is given by

[k00k].

Therefore, the standard matrix of T is

T=[250025].
