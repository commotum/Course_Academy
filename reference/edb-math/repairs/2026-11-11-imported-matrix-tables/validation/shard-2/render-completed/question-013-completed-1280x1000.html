Solution:

Answer 1 · correct value:

sinh(4t)+3cosh(4t)

Answer 2 · correct value:

e4scosh(4(t−s))

Given the system x′(t)=Ax(t)+g(t), where A is a constant square matrix, the solution of the initial value problem can be written as the sum of the homogeneous part and a particular solution:

x(t)=eA(t−t0)x(t0)⏟homogeneous part+∫t0teA(t−s)g(s)ds⏟particular solution,

where x(t0) is the initial condition vector.

Let's evaluate each part separately:

  • First, we find the homogeneous part. We are given that eAt=[cosh(4t)sinh(4t)sinh(4t)cosh(4t)]. So,

eAtx(0)=[cosh(4t)sinh(4t)sinh(4t)cosh(4t)][13]=[cosh(4t)+3sinh(4t)sinh(4t)+3cosh(4t)].

  • Next, we find the particular solution. Notice that

eA(t−s)=[cosh(4(t−s))sinh(4(t−s))sinh(4(t−s))cosh(4(t−s))].

So, we have

eA(t−s)g(s)=[cosh(4(t−s))sinh(4(t−s))sinh(4(t−s))cosh(4(t−s))][0e4s]=[e4ssinh(4(t−s))e4scosh(4(t−s))].

Therefore, we get

x(t)=[cosh(4t)+3sinh(4t)sinh(4t)+3cosh(4t)]+∫0t[e4ssinh(4(t−s))e4scosh(4(t−s))]ds.
