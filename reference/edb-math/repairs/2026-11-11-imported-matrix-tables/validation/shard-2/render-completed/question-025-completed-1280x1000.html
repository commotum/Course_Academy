Given that w=[2−56], find a unit vector that is parallel to w.

u=
265
CorrectPreview only
Solution:

Answer 1 · correct value:

−565

Answer 2 · correct value:

665

Remember that to find a unit vector that is parallel to a given vector, we need to divide the given vector by its length:

u=w|w|

Using the formula for the magnitude of a vector, we get

|w|=wx2+wy2+wz2=22+(−5)2+62=4+25+36=65.

Finally, we divide w by its length and get the following unit vector:

u=w|w|=165w=165⋅[2−56]=[265−565665]
