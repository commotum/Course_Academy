Review topic

Construct the matrix T of the linear transformation T that acts on a vector in R2 as follows (in the order given):

  • It rotates the vector by π radians counterclockwise about the origin, then

  • stretches the result by a scale factor of 2 parallel to the y-axis, and finally

  • shears the result with a shear factor of 4 parallel to the y-axis.

T=
0
CorrectPreview only
Solution:

Answer 1 · correct value:

−1

Answer 2 · correct value:

−4

Answer 3 · correct value:

−2

Let P be the matrix that represents the rotation, Q be the matrix that represents the stretching, and R be the matrix that represents the shearing. These are given by the following elementary transformation matrices:

P=[−100−1],Q=[1002],R=[1041]

Hence, the combined transformation can be represented by the matrix RQP:

T=RQP=[1041][1002][−100−1]=[1041][−100−2]=[−10−4−2]
