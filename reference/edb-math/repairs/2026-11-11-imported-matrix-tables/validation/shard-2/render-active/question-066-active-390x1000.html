Consider the functions y:R2→R2 and f:R2→R3, defined by

y(x)=[x1x2x1−x2],f(y)=[y1y2y22y1+y2].

What is ddxf(y(x)) evaluated at x0=[−11]?

ddxf(y(x))|x0=
−4
2−2
Solution:

Answer 1 · correct value:

−3

Answer 2 · correct value:

3

Answer 3 · correct value:

4

Using the chain rule, we have

ddxf(y(x))=dfdy⋅dydx.

Let's consider each of the factors in turn.

  • The function f acts on a vector y∈R2 and outputs a vector f(y)∈R3. Thus, the total derivative of f with respect to y is a 3×2 matrix

dfdy=[∂f1∂y1∂f1∂y2∂f2∂y1∂f2∂y2∂f3∂y1∂f3∂y2]=[∂∂y1(y1y2)∂∂y2(y1y2)∂∂y1(y22)∂∂y2(y22)∂∂y1(y1+y2)∂∂y2(y1+y2)]=[y2y102y211].

Evaluating at y0=y(x0)=[−1⋅1−1−1]=[−1−2], we get

dfdy|y0=[−2−10−411].

  • The function y acts on a vector x∈R2 and outputs a vector y(x)∈R2. Thus, the total derivative of y with respect to x is a 2×2 matrix

dydx=[∂y1∂x1∂y1∂x2∂y2∂x1∂y2∂x2]=[∂∂x1(x1x2)∂∂x2(x1x2)∂∂x1(x1−x2)∂∂x2(x1−x2)]=[x2x11−1].

Evaluating at x0=[−11], we get

dydx|x0=[1−11−1].

Therefore, we have

ddxf(y(x))|x0=dfdy|y0⋅dydx|x0=[−2−10−411]⋅[1−11−1]=[−33−442−2].
