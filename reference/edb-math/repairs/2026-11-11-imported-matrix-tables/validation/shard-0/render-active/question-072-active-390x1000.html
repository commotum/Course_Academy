Compute the gradient of the function f:R2→R defined by

f(x)=xT[45−4−5]x

with respect to x at x=[01]T.

∇xf=
Solution:

Answer 1 · correct value:

Answer 2 · correct value:

−10

Defining the matrix A as

A=[45−4−5],

we have f(x)=xTAx.

Since A is not symmetric, we use the more general formula for the gradient of a quadratic function:

∇xf(x)=(AT+A)x

First, we compute

AT=[4−45−5],

which gives

AT+A=[4−45−5]+[45−4−5]=[811−10].

Now, compute the gradient at x=[01]:

∇xf(x)=(AT+A)x=[811−10][01]=[0+10−10]=[1−10]
