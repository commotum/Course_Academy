Given the function f(x;w)=w1x1−w2x2−w3x3, compute ∇wf with the input x=[5,4,6]T.

∇wf= 
Solution:

Answer 1 · correct value:

5

Answer 2 · correct value:

−4

Answer 3 · correct value:

−6

To compute ∇wf, we take partial derivatives with respect to each component of w.

∂f∂w1=∂∂w1(w1x1−w2x2−w3x3)=x1∂f∂w2=∂∂w2(w1x1−w2x2−w3x3)=−x2∂f∂w3=∂∂w3(w1x1−w2x2−w3x3)=−x3

Therefore, with x=[5,4,6]T, we obtain the following:

∇wf=[x1−x2−x3]=[5−4−6]
