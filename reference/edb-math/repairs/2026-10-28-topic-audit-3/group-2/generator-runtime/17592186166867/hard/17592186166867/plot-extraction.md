# Plot extraction and specification

1. Each original raster was individually inspected in source-montage.png and independently calibrated in source-geometry.json. q-127372 labels (1,2), q-127374 (-2,2), q-127510 (3,6), q-127515 (-1,2), q-127520 (-8,4), q-312780 (5,7), q-342215 (-3,-1), q-342218 (-6,6), q-342354 (8,-8), q-342355 (6,-2). Canonical e-9579 labels (3,-2). All have a blue two-branch horizontal parabola, black arrow axes, origin vertex and orange marked point. There are no tick labels, grids, focus marks, tangent lines or direction-of-traversal demands. Asset dimensions are 360×304; axes placement and geometric scale differ independently across assets.
2. The shared visual pattern supplies vertex O and an on-curve coordinate. Reading these determines c=b²/a; the requested derivative is c/(2y), for y≠0. Both signs of b are interchangeable point labels for the same locus.
3. Calibration identifies black axis pixels, orange marker centroid and all blue stroke pixels. Each image's independent coordinate transform comes from its own origin and labeled marker. Fit predicts x=y²/c and measures normal pixel residuals under that transform, including stroke/antialias allowance (95th percentile <4px). It does not assume common bounds or scale and never uses another raster's fit. This geometry confirms the source's actual signed coordinate labels. No exact historical raster renderer is claimed.
4. New plots use Matplotlib and exact instance integers; c is computed from them, not resampled. Draw both branches y∈[-1.65|b|,1.65|b|], set horizontal extent 2.6|a| on the opening side and 0.6|a| on the other side, black axes with arrowheads, O, x/y labels, orange coordinate marker and blue curve. Unequal screen scale is allowed (as in originals); semantic axes and geometry share one transform. Plot PNG and JSON sidecar are atomically replaced via unique temporary files. Caller render inputs are unique and removed only by their own caller; no cache pruning. Cache hits require both PNG and sidecar. Exact-source geometry can reuse its original asset; changed geometry always renders.

The primary Python 3.13 environment lacks Matplotlib. The private render_plot.py reuses the cached Python3.10 and cached dependency wheels read-only, following KP78582's approach. Sidecars record versions, bounds, marked point and curve sample coordinates. It performs no installation or network operation.

In authored easy, the supplied Cartesian equation determines the derivative directly; the same graph remains a consistent visual of the assessed parabola, and its marker is incidental to the easy operation. Moderate/hard still need its marked coordinate to reconstruct the equation. Sidecars now retain actual Python/Matplotlib/NumPy versions, loaded module paths and cached dependency paths. Older sidecars lacking this provenance are refreshed atomically through the same renderer; assets are never pruned.
