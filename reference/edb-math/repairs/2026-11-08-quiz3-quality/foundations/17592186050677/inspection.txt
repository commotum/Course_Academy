- $yy'' - y'+ 9 = 0$
SOLUTION: A second-order linear differential equation has the form

$$
a(x)y'' + b(x)y' + c(x) y = f(x).
$$

Let's look at each equation in turn.

- The equation 

$$
y'' + (y-1)y'+x = 2
$$

is **NOT** linear because it contains the nonlinear term $(y-1)y'.$

- The equation 

$$

$$

is a second-order linear ODE with $a(x) = 1, b(x) = 1, c(x) = 0,$ and $f(x) = x\cos{x}.$

- The equation 

$$
yy'' - y'+ 9 = 0
$$

is **NOT** linear because it contains the nonlinear term $yy''.$

Therefore, the correct answer is "II only."

QUESTION 17592186151960 e-6565
Determine which of the following second-order ODEs are homogeneous, and which are inhomogeneous.

- $\, (2-\sin(x)) y'' + x y' + y = 0$

- $\,y'' + 6y' + 9y = 3e^x$

- $\,y'' + x^3 y - 8 = 0$
SOLUTION: Suppose we have a second-order linear ODE given in the form

$$
a(x)y'' + b(x)y' + c(x) y = f(x).
$$

The equation is homogeneous if $f(x) = 0$ for all $x.$ If it is not homogeneous, then it is inhomogeneous.

With that in mind, let's examine each option.

- The equation

$$
(2-\sin(x)) y'' + x y' + y = 0
$$

is homogeneous since, for the right-hand side, we have $f(x) = 0$ for all $x.$

- The equation

$$
y'' + 6y' + 9y = 3e^x
$$

is inhomogeneous since, for the right-hand side, we have $f(x) = 3e^x,$ which is different from zero.

- Writing the equation

$$
y'' + x^3 y - 8 = 0
$$

in the form $ay'' + by' + cy = f,$ we have

$$
y'' + x^3 y = 8.
$$

This equation is inhomogeneous since, for the right-hand side, we have $f(x) = 8,$ which is different from zero.

SOLUTION: If a second-order differential equation for the function $y(x)$ is given with two conditions specified at the *same* location in the domain of $y,$ then this is an **initial value problem.**

With this in mind, let's go through each equation in turn.

- System I is not an initial value problem. It contains an equation only. No conditions are specified.

- System II is not an initial value problem because it consists of a differential equation together with two conditions in *different* locations, $x=0$ and $x=4.$ So this is a **boundary value problem**, not an initial value problem.

- System III is an initial value problem. The differential equation is together with two conditions at the same location in the domain of $y(x)$ (i.e., at $x=1$).

Therefore, the correct answer is "III only".
