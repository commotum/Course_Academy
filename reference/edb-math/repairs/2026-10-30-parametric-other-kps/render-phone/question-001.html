Consider the curve with parametric equations

x=cos⁡(πt4),y=tan⁡(πt3).

Consider the following table of values. Angles are in radians.

t −4 −3 −2 −1 0
x −1 −22 0 b a
y −3 0 c −3 0

Find the exact value of a−b−c.

CorrectPreview only
Solution:

Answer: result · correct value:

−3−22+1

The a entry is in the x-row under t=0. Substitute into x=cos⁡(πt4):

a=cos⁡(π(0)4)=cos⁡(0)=1

The b entry is in the x-row under t=−1. Substitute into x=cos⁡(πt4):

b=cos⁡(π(−1)4)=cos⁡(−π4)=22

The c entry is in the y-row under t=−2. Substitute into y=tan⁡(πt3):

c=tan⁡(π(−2)3)=tan⁡(−2π3)=3

Substitute the three entries with the signs in the requested expression:

a−b−c=(1)−(22)−(3)=−3−22+1

The completed table is

t −4 −3 −2 −1 0
x −1 −22 0 22 1
y −3 0 3 −3 0
