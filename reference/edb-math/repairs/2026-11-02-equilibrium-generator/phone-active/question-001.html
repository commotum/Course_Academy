Consider the differential equation

dydt=y2ln⁡(y)−e2.

Which of the following are equilibrium solutions? Select all that apply.

Answer: y=e
Answer: y=2
Answer: y=1
Solution:

Answer: y=e · correct value:

true

Answer: y=2 · correct value:

false

Answer: y=1 · correct value:

false

An equilibrium is a constant function y(t)=c. Set dy/dt=0 and test the resulting equation.

First keep the original domain: y>0.

Test whether f(c)=0, where

f(c)=c2ln⁡(c)−e2.

  • For c=e: Use ln⁡(e)=1.

f(e)=−e2+e2ln⁡(e)=0

This is zero, so it is an equilibrium solution.

  • For c=2:

f(2)=−e2+4ln⁡(2)

This is nonzero, so it is not an equilibrium solution.

  • For c=1: Use ln⁡(1)=0.

f(1)=−e2+1ln⁡(1)=−e2

This is nonzero, so it is not an equilibrium solution.

Select y=e.
