# Generator follow-up audit

At the checkbox audit basis **3704**, 55 generators were registered on the 427 knowledge points with candidate presentation repairs. Read-only probes of their registered source produced **248 records** and confirmed **46 generators still emit checkbox keys containing only remote labels**. The other nine produced radio or blank fields in the sampled calls. This is a bounded sample audit, not a claim that every unsampled template is correct.

The updated radio2checkbox skill does not change these generators. Database repairs do not change their scripts or source snapshots. No generator was edited, published, or disabled in this audit. Networking and writes outside this evidence directory were blocked during probes.

The initial database census included **220 questions without Math Academy IDs** across 31 knowledge points. All were reviewed: **201 mapped repairs, seven image-panel repairs, one column repair, and 11 already-complete layouts**. Retained generation records match 199 of those question UUIDs; the remaining 21 are classified by their current database content without asserting an unproven generator origin. See [descendant-coverage.json](descendant-coverage.json) for every ID and source record.

The static source inventory found 103 matching snapshot files, of which 66 retain bare checkbox keys. Some are immutable historical evidence; this inventory is a follow-up queue, not a request to overwrite historical receipts.
