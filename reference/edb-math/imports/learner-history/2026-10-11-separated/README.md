Apply the files in the order recorded in `manifest.json`, passing each declared source once on its EDB request. The source is transaction metadata, not an additional schema attribute. The manifest records file checksums and stable retry keys. A changed destination requires a fresh review and preview before submission.

Seven verbatim entered-answer records with their original answer UUIDs and membership in the corresponding current blank fields; all 44 saved submissions; the original saved course choice.
