Write in your own words what it means for a set of vectors to be linearly dependent. Is there a geometric way that you think about linear dependence?

A set is linearly dependent when at least one vector can be built as a linear combination of the others. That vector is redundant: removing it does not change the span. Equivalently, there are coefficients, not all zero, for which

c1v→1+⋯+ckv→k=0→.

Geometrically, two nonzero vectors are dependent when they are parallel. Three vectors in R3 are dependent when they all lie in a plane through the origin, possibly in a smaller line or just at the origin. Any set containing the zero vector is dependent.

Answer: answer · reference answer:

A set is linearly dependent when at least one vector can be built as a linear combination of the others. That vector is redundant: removing it does not change the span. Equivalently, there are coefficients, not all zero, for which

c1v→1+⋯+ckv→k=0→.

Geometrically, two nonzero vectors are dependent when they are parallel. Three vectors in R3 are dependent when they all lie in a plane through the origin, possibly in a smaller line or just at the origin. Any set containing the zero vector is dependent.

Dependence does not require two vectors to coincide or be parallel. For example, (1,0), (0,1), and (1,1) are dependent because (1,0)+(0,1)−(1,1)=(0,0); none of the three pairs is parallel. The phrase not all zero is essential: every set has the all-zero-coefficient combination. If cj≠0 in a zero combination, then v→j=−∑i≠j(ci/cj)v→i, which expresses that vector using the others. Conversely, such an expression rearranges to a zero combination with a nonzero coefficient.
