Earlier in the course, we studied homogeneous systems of linear equations. What did we call the solution to a homogeneous system when it was unique?

Answer:

CorrectPreview only
Solution:

Answer: answer · correct value:

trivial solution

The trivial solution sets every unknown equal to zero. A homogeneous system has the form Ax=0, and A0=0, so this solution always exists. If the solution is unique, it must be this zero solution. The name applies to the zero solution even when other solutions also exist.
