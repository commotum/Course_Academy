Consider the vector field F(x,y)=−2x1+x2+y2i−2y1+x2+y2j. Which of the following statements are true?

  1. F is conservative
  2. ∫CF⋅dr=0 for any piecewise smooth path C∈R2
  3. ∮CF⋅dr=0 for any closed path C∈R2
a
I, II, and III
b
 I and II only
c
II only
d
I only
e
I and III only
Submit
Correct
EXPLANATION

If F is a conservative vector field on R2, then the circulation Γ=0 for any closed path C∈R2, that is Γ=∮CF⋅dr=0.

We notice that F=Pi+Qj is a vector field with domain D=R2. Computing the partial derivatives, we have ∂P∂y=∂Q∂x=4xy(1+x2+y2)2.

With that in mind, let's consider each statement in turn:

  • Statement I is true. The vector field F is conservative since the partial derivatives are equal and continuous everywhere on R2.

  • Statement II is false, while statement III is true. The result Γ=0 applies to closed curves only.

Therefore, the correct answer is "I and III only."

EXPLANATION

The circulation Γ measures the total work done by a force F in moving a particle along a closed curve C. It is given by the formula Γ=∮CF⋅dr=∫abF(r(t))⋅r′(t)dt.

Along the curve C, we have x=2cos⁡t,y=sin⁡t.

So,

F(r(t))=−yi+xj=−sin⁡ti+2cos⁡tj.

Computing r′(t), we get

r′(t)=ddt(2cos⁡t)i+ddt(sin⁡t)j=−2sin⁡ti+cos⁡tj.

Therefore,

F(r(t))⋅r′(t)=(−sin⁡ti+2cos⁡tj)⋅(−2sin⁡ti+cos⁡tj)=−sin⁡t⋅(−2sin⁡t)+2cos⁡t⋅cos⁡t=2sin2⁡t+2cos2⁡t=2.

Finally, we evaluate the integral as follows:

Γ=∮CF⋅dr=∫02πF(r(t))⋅r′(t)dt=∫02π2dt=2t|02π=2(2π)−0=4π
