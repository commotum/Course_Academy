Calculate the integral ∫(log3⁡x)2dx.

a
x((log3⁡x)2+2log3⁡(x)ln⁡3−2ln2⁡3)+C
b
2x((log3⁡x)2−log3⁡(x)ln⁡3−1ln2⁡3)+C
c
x((log3⁡x)2−3log3⁡(x)ln⁡3+3ln2⁡3)+C
d
x((log3⁡x)2−2log3⁡(x)ln⁡3+2ln2⁡3)+C
e
2x(3(log3⁡x)2+log3⁡(x)ln⁡3+2ln2⁡3)+C
Submit
Correct
EXPLANATION

We need to use integration by parts.

In this case, we define u=(log3⁡x)2⟹dudx=2log3⁡xxln⁡3dvdx=1⟹v=∫dvdxdx=∫dx=x.

Using the formula of integration by parts, we get ∫(log3⁡x)2dx=∫udvdxdx=uv−∫vdudxdx=(log3⁡x)2(x)−∫(x)(2log3⁡xxln⁡3)dx=x(log3⁡x)2−2ln⁡3∫log3⁡(x)dx.

We use integration by parts once again to evaluate ∫log3⁡(x)dx. We take u=log3⁡(x)⟹dudx=1xln⁡3dvdx=1⟹v=∫dvdxdx=∫dx=x.

In this case, the formula for integration by parts gives ∫log3⁡(x)dx=∫udvdxdx=uv−∫vdudxdx=(log3⁡(x))(x)−∫(x)(1xln⁡3)dx=xlog3⁡(x)−1ln⁡3∫dx=xlog3⁡(x)−xln⁡3+D, where D is an integral constant.

So we have ∫(log3⁡x)2dx=x(log3⁡x)2−2ln⁡3(xlog3⁡(x)−xln⁡3+D)=x(log3⁡x)2−2xlog3⁡(x)ln⁡3+2xln2⁡3−2Dln⁡3=x((log3⁡x)2−2log3⁡(x)ln⁡3+2ln2⁡3)+C, where C=−2Dln⁡3.
