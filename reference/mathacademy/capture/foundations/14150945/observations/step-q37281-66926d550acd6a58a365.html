EXPLANATION

First, let's find the differential:

df(x,y)=(∂f∂x)dx+(∂f∂y)dy=13x2/3dx+12ydy.

At the point (8,144), the differential is

df(x,y)=13⋅82/3dx+12144dy=112dx+124dy.

So, if we move to the point (8+Δx,144+Δy), then we can approximate the change in f as

Δf≈112Δx+124Δy

Note that 103+150=f(10,150),

so we want to move to the point (10,150).

Moving from (8,144) to (10,150), we have

Δx=10−8=2,Δy=150−144=6.

So, we have

Δf≈112(2)+124(6)≈16+14≈512≈0.417.

This means that the value of f increases by about 0.417. Consequently, we have

f(10,150)≈f(8,144)+0.417103+150≈83+144+0.417≈2+12+0.417≈14.417.
