First, let's find the differential:

df(x,y)=(∂f∂x)dx+(∂f∂y)dy=yexydx+xexydy.

At the point (0,2), the differential is

df(x,y)=2⋅e0⋅2dx+0⋅e0⋅2dy=2dx+0dy.

So, if we move to the point (0+Δx,2+Δy), then we can approximate the change in f as

Δf≈2Δx+0Δy.

Note that e(0.3)(2.15)=f(0.3,2.15),

so we want to move to the point (0.3,2.15).

Moving from (0,2) to (0.3,2.15), we have

Δx=0.3−0=0.3,Δy=2.15−2=0.15.

So, we have

Δf≈2⋅(0.3)+0⋅(0.15)≈0.6.

This means that the value of f increases by about 0.6. Consequently, we have

f(0.3,2.15)≈f(0,2)+0.6e(0.3)(2.15)≈e(0)(2)+0.6≈1+0.6≈1.6.
