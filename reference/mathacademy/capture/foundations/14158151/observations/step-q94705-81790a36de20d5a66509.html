Find the 90th percentile of the random variable X if the probability distribution function of X is given by f(x)={12x3,x≥1,0,otherwise.

Correct
EXPLANATION

The 100pth percentile of a random variable X is the number xp such that

P(X≤xp)=p.

In our case, we want to find the 90th percentile, which corresponds to the decimal p=0.9. We have

P(X≤x0.9)=∫1x0.912x3dx=∫1x0.912x−3/2dx=−x−1/2|1x0.9=1−1x0.9.

Therefore, the 90th percentile is given by

1−1x0.9=0.91x0.9=0.1x0.9=10x0.9=100.
