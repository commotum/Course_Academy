The 100pth percentile of a random variable X is the number xp such that

P(X≤xp)=p.

In our case, we want to find the 25th percentile, which corresponds to the decimal p=0.25. We have

P(X≤x0.25)=∫2x0.25(x2−1)dx=(x24−x)|2x0.25=x0.2524−x0.25−((2)24−2)=x0.2524−x0.25+1.

Therefore, the 25th percentile is given by

x0.2524−x0.25+1=0.25x0.252−4x0.25+3=0(x0.25−3)(x0.25−1)=0x0.25=1,3.

Note that we take the root x0.25=3 because 2<x0.25<4.
