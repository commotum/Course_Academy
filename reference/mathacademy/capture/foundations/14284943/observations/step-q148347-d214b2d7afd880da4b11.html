EXPLANATION

Recall that if X and Y are random variables and a and b are constants, then

Var[aX+bY]=a2Var[X]+b2Var[Y]+2abCov[X,Y].

Also, the variance of a random variable X is determined by the formula

Var[X]=E[X2]−E[X]2,

and the covariance of two random variables X and Y is given by the formula

Cov[X,Y]=E[XY]−E[X]⋅E[Y].

First, let's find the marginal mass functions for X and Y. These are given by the row and column totals, respectively.

f Y=0 Y=1 fX
X=0 0.1 0.2 0.3
X=1 0.2 0.5 0.7
fY 0.3 0.7 1

Now, we can find Var[X]. If X is defined on a sample space SX, then

E[X]=∑x∈SXx⋅fX(x)=0⋅0.3+1⋅0.7=0.7

and

E[X2]=∑x∈SXx2⋅fX(x)=02⋅0.7+12⋅0.7=0.7.

Therefore,

Var[X]=E[X2]−E[X]2=0.7−0.72=0.21.

Similarly, if Y is defined on a sample space SY, then

E[Y]=∑y∈Syy⋅fY(y)=0⋅0.3+1⋅0.7=0.7

and

E[Y2]=∑y∈Syy2⋅fY(y)=02⋅0.3+12⋅0.7=0.7.

Therefore,

Var[Y]=E[Y2]−E[Y]2=0.7−0.72=0.21.

Now, let's find Cov[X,Y]. We find E[XY] using the rule of the lazy statistician:

E[XY]=∑(x,y)∈Sxy⋅f(x,y)=0⋅0⋅f(0,0)+0⋅1⋅f(0,1)+1⋅0⋅f(1,0)+1⋅1⋅f(1,1)=0+0+0+1⋅0.5=0.5.

Then, using the covariance formula, we have

Cov[XY]=E[XY]−E[X]⋅E[Y]=0.5−0.7⋅0.7=0.01.

Therefore,

Var[4X+2Y]=42⋅0.21+22⋅0.21+2⋅4⋅2⋅0.01=3.36+0.84+0.16=4.36.
