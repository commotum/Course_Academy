EXPLANATION

If F is a vector field and C is a piecewise-smooth, simple, closed curve, then the flux of F across C is given by ∮CF⋅nds, where n denotes the outward-pointing unit normal vector to C.

In our case, we need to find an expression for the flux across only the part C4 of the closed curve C. Since this side is perpendicular to the y-axis and we require an outward-pointing unit normal vector, we must have n=−j.

Therefore,

∫C4F⋅nds=∫C4(xyi−x2yj)⋅(−j)ds=∫C4x2yds

Therefore, the missing expression is x2y.
