Which of the diagrams shown above represent subspaces of R2?

a
I and II only
b
III only
c
I only
d
II and III only
e
II only
Submit
Correct
EXPLANATION

Let's analyze each diagram in turn.

  • Diagram I is a line that passes through the origin. Therefore, it is a subspace of R2.

  • Diagram II represents a line that does not pass through the origin. But every subspace must contain the origin, so the line in Diagram II is not a subspace of R2.

  • Diagram III does not represent a subspace. There are vectors a=[a1a2] in the subset for which a1>0 and a2>0. But then (−1)⋅a=[−a1−a2] lies outside the subset.

So, the correct answer is "I only".
