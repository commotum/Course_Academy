Which of the diagrams shown above represent subspaces of R2 or R3?

a
 III only
b
 II and III only
c
 II only
d
None

 I and II only

Correct
EXPLANATION

Let's analyze each diagram in turn.

  • Diagram I does not represent a subspace. The origin 0=[000] clearly lies outside the subset.

  • Diagram II represents the origin 0=[00], which is considered a special (trivial) subspace of R2.

  • Diagram III represents a line that does not pass through the origin. But every subspace must contain the origin, so the line in Diagram III is not a subspace of R3.

So, the correct answer is "II only."
