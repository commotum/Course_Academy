Which of the diagrams shown above represent subspaces of R2?

a
I only
b
II only
c
III only
d
None

I and II only

Correct
EXPLANATION

Let's analyze each diagram in turn.

  • Diagram I does not represent a subspace. The vector a=[−11] lies inside the given subset. But (−1)⋅a=[1−1] lies outside the subset.

  • Diagram II represents the whole plane R2 without the origin. But every subspace must contain the origin, so Diagram II is not a subspace of R2.

  • Diagram III does not represent a subspace. In this case we also have that the vector a=[−11] lies inside the given subset. But (−1)⋅a=[1−1] lies outside the subset.

So, the correct answer is "None".
