Recall that a subset of a vector space is a subspace if it's closed under addition and scalar multiplication.

With that in mind, let's examine each statement in turn.

  • Statement I is false. For example, if A1=[1000] and A2=[0001], then A1 and A2 each contain a row consisting only of zeros, so they are not invertible. However,
    A1+A2=[1001] is invertible. So, S is not closed under addition.

  • Statement II is true. Indeed, if A is a 2×2 matrix that is not invertible then det(A)=0 and therefore for all α∈R det(αA)=α2⋅det(A)=α2⋅0=0. Therefore, S is closed under scalar multiplication.

  • Statement III is false, while statement IV is true. S is a not subspace because it's not closed under addition.

Therefore, the correct answer is "II and IV only."
