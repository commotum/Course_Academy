EXPLANATION

Recall that since A=UΣVT is a singular value decomposition of a 2×2 matrix A, the matrix U must be a 2×2 orthogonal matrix. This means that

  • the first column must be orthogonal to the second column, and

  • the norm of the second column must be equal to 1.

Among the given options, only the vector [117417] has both properties.
