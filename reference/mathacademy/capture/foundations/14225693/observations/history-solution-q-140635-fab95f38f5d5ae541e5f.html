Recall that if A=UΣVT is a singular value decomposition of an m×n matrix A, then

  • Σ is a m×n matrix with nonnegative elements on the main diagonal and zeroes outside the main diagonal,

  • U is an orthogonal m×m matrix,

  • V is an orthogonal n×n matrix.

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, since A is a 4×2 matrix, U in the singular value decomposition UΣVT must be a 4×4 orthogonal matrix.

  • Statement II is false. Since A is a 4×2 matrix, Σ must be a 4×2 matrix.

  • Statement III is false. The matrix V in the singular value decomposition UΣVT must be an orthogonal matrix, not a diagonal matrix.

Therefore, the correct answer is "I only."
