Recall that the set of functions {f1(x),f2(x),…,fn(x)}, which are defined on some interval I, is linearly dependent if there exist real scalars k1,k2,…,kn not all zero such that the linear combination k1⋅f1+k2⋅f2+…+kn⋅fn is identically zero, i.e, k1⋅f1(x)+k2⋅f2(x)+…+kn⋅fn(x)=0 for all x∈I. Otherwise, if k1=k2=⋯=kn=0 is the only solution, the set is linearly independent.

Now, for all x∈R, we have that 3⋅sin⁡x+0⋅ex+(−1)⋅3sin⁡x=0.

Therefore, since not all the scalar coefficients in the linear combination are zero, the given set of functions is linearly dependent.
