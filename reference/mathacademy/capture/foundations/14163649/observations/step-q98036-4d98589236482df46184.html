Which of the regions shown above are simply connected?

a
 I and II only
b
 II and III only
c
 I only
d
 I and III only
e
 II and IV only
Submit
Correct
EXPLANATION

A connected region D is simply connected if every simple closed curve in D can be contracted to a point.

A connected plane region D is simply connected if every simple closed curve in D encloses only points in D. In other words, the region does not contain any holes. Plane regions containing holes are not simply connected, since some simple closed curves cannot be contracted to a point:

With that in mind, let's examine each of the regions:

  • Region I is simply connected. This is a connected region that does not contain holes.

  • Region II is not simply connected. Instead, this is a connected region that contains two holes.

  • Region III is simply connected. This is a connected region that does not contain holes.

  • Region IV is not simply connected. Instead, this is a region that consists of two pieces (it's not connected).

Therefore, the correct answer is "I and III only."
