Which of the following vector fields are conservative on R2?

  1. F=2xeyi−x2eyj
  2. G=arctan⁡yi−xy2+1j
  3. H=(8x−3y)i+(4y−3x+1)j
a
III only
b
I and III only
c
II only
d
I, II and III
e
I and II only
Submit
Correct
EXPLANATION

Let F(x,y)=P(x,y)i+Q(x,y)j be a vector field with domain D=R2, where P and Q have continuous first-order partial derivatives everywhere on D. Then, we have the following theorem:

F is conservative if and only if ∂P∂y=∂Q∂x everywhere on D.

Note that for each of our functions, D=R2. With this in mind, let's check each of the vector fields.

  • For the vector field F, we have P=2xey and Q=−x2ey. Computing the partial derivatives, we get ∂P∂y=−2xey,∂Q∂x=−2xey. Since the partial derivatives are continuous and equal everywhere on R2, we conclude that F is conservative on R2.

  • For the vector field G, we have P=arctan⁡y and Q=−xy2+1. Computing the partial derivatives, we get ∂P∂y=1y2+1,∂Q∂x=−1y2+1. Since the partial derivatives are not equal, we conclude that G is not conservative on R2.

  • For the vector field H, we have P=8x−3y and Q=4y−3x+1. Computing the partial derivatives, we get ∂P∂y=−3,∂Q∂x=−3. Since the partial derivatives are continuous and equal everywhere on R2, we conclude that H is conservative on R2.

Therefore, the correct answer is "I and III only."
