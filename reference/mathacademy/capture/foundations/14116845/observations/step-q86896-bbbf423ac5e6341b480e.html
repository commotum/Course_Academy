Which of the following vector fields are conservative on R2?

  1. F=(ex+y−2)i+(ex+y−7)j
  2. G=(y3−6x)i+(3xy2)j
  3. H=2xyx2+1i+ln⁡(x2+1)j

EXPLANATION

Let F(x,y)=P(x,y)i+Q(x,y)j be a vector field with domain D=R2, where P and Q have continuous first-order partial derivatives everywhere on D. Then, we have the following theorem:

F is conservative if and only if ∂P∂y=∂Q∂x everywhere on D.

Note that for each of our functions, D=R2. With this in mind, let's check each of the vector fields.

  • For the vector field F, we have P=ex+y−2 and Q=ex+y−7. Computing the partial derivatives, we get ∂P∂y=ex+y,∂Q∂x=ex+y. Since the partial derivatives are continuous and equal everywhere on R2, we conclude that F is conservative on R2.

  • For the vector field G, we have P=y3−6x and Q=3xy2. Computing the partial derivatives, we get ∂P∂y=3y2,∂Q∂x=3y2. Since the partial derivatives are continuous and equal everywhere on R2, we conclude that G is conservative on R2.

  • For the vector field H, we have P=2xyx2+1 and Q=ln⁡(x2+1). Computing the partial derivatives, we get ∂P∂y=2xx2+1,∂Q∂x=2xx2+1. Since the partial derivatives are continuous and equal everywhere on R2, we conclude that H is conservative on R2.

Therefore, the correct answer is "I, II, and III".
