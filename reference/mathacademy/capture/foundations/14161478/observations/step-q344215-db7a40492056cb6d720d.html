A hospital administrator observed that the growth of the number of occupied beds in a hospital is directly proportional to the difference between the hospital’s maximum bed capacity and the current number of occupied beds. Let H(t) be the number of occupied beds, measured in beds, and let t≥0 be the time in years. If the maximum number of beds the hospital can support is 75 beds, which differential equation could be used to model the number of occupied beds in the hospital? Assume that k>0 is a constant of proportionality.

a
dHdt=k(75−H)
b
dHdt=−k(75−H)
c
dHdt=kH2(75−H)
d
dHdt=kH(75−H)
e
dHdt=−k(75+H)
Submit
Incorrect
EXPLANATION

The rate at which the number of occupied beds H(t) in the hospital changes is proportional to the difference between the maximum number of beds the hospital can support and the current number of occupied beds. Therefore, we have the differential equation

dHdt=k(a−H),

where a is the maximum number of beds the hospital can support, and k>0 is a constant of proportionality.

In our case, a=75 beds, and we have

dHdt=k(75−H).
