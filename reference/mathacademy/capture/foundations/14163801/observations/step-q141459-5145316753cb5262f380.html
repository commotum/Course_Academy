EXPLANATION

Since T is a linear transformation from R3 into R3, the invertible matrix theorem states the following:

T is a bijection (an invertible transformation) ⟺{Im(T)=R3rank(T)=3Ker(T)={0}nullity(T)=0

With that in mind, let's examine each statement in turn.

  • Statement I is true. Since v∈Ker(T) and v≠0, we must have that Ker(T)≠{0}.

  • Statement II is false. According to the invertible matrix theorem, since Ker(T)≠{0}, the transformation T is not a bijection and the matrix T is not invertible.

  • Statement III is false. Since T is not invertible, the invertible matrix theorem implies that Im(T)≠R3.

Therefore, the correct answer is "I only."
