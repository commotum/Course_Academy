Which of the following sets is a subspace of R2?

  1. A={⟨x,y⟩∈R2:y=0}
  2. B={⟨x,y⟩∈R2:y=3x}
  3. C={⟨x,y⟩∈R2:y=2}
a
I only
b
II only
c
I and II only
d
I and III only
e
II and III only
Submit
Incorrect
EXPLANATION

Let's analyze each of the subsets.

  • The set A is a subspace. It represents a line, and a line is a subspace if and only if it passes through the origin. Here, the components of the zero vector 0=⟨0,0⟩ satisfy the equation y=0 since 0=0. So, 0 lies in A.

  • The set B is a subspace. It represents a line, and a line is a subspace if and only if it passes through the origin. Here, the components of the zero vector 0=⟨0,0⟩ satisfy the equation y=3x since 0=3⋅0. So, 0 lies in B.

  • The set C is not a subspace because it does not contain the zero vector. Indeed, 0=⟨0,0⟩ does not satisfy the condition y=2 since 0≠2.

So, the correct answer is "I and II only."
