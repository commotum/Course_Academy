Which of the following random variables follow a geometric distribution?

  1. The number of questions answered correctly on a quiz before the first incorrect answer
  2. The cost of an item randomly selected from a store
  3. The number of products checked before finding a defective product
a
I and III only

III only

II and III only

Incorrect
EXPLANATION

A geometric distribution is used to model the number of binomial experiments needed before the first success.

With that in mind, let's consider each of the given random variables.

  • Random variable I follows a geometric distribution. Answering a question correctly (or incorrectly) is a binomial experiment, and the number of questions answered before the first incorrect answer can be interpreted as the number of binomial experiments needed before the first success.

  • Random variable II does not follow a geometric distribution. The cost of an item randomly selected from a store is not a binomial experiment.

  • Random variable III follows a geometric distribution. Checking a product is a binomial experiment, and the number of products checked before the first defective product is found can be interpreted as the number of binomial experiments needed before the first success.

Therefore, the correct answer is "I and III only."
