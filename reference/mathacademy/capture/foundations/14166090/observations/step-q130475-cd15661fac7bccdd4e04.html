Which of the following random variables follow a geometric distribution?

  1. The number of apples checked in a basket until the first rotten apple is found
  2. The number of vegetarian dishes ordered in a restaurant during a day
  3. The number of dishes ordered at a restaurant until the first vegetarian dish is ordered

EXPLANATION

A geometric distribution is used to model the number of binomial experiments needed before the first success.

With that in mind, let's consider each of the given random variables.

  • Random variable I follows a geometric distribution. Checking an apple is a binomial experiment, and the number of apples checked before the first rotten apple is found can be interpreted as the number of binomial experiments needed before the first success.

  • Random variable II does not follow a geometric distribution. Ordering a vegetarian dish is a binomial experiment, but the number of vegetarian dishes ordered in a day cannot be interpreted as the number of binomial experiments needed before the first success.

  • Random variable III follows a geometric distribution. Ordering a vegetarian dish is a binomial experiment, and the number of dishes ordered before the first vegetarian dish is ordered can be interpreted as the number of binomial experiments needed before the first success.

Therefore, the correct answer is "I and III only."
