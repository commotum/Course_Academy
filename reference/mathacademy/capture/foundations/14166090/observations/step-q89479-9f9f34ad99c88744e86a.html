Which of the following random variables follow a geometric distribution?

  1. The number of victories by a chess player in 10 matches
  2. The number of arrows fired by an archer before hitting the bullseye
  3. The number of students that pass a calculus exam among a group of 30 students
a
II only
b
I and III only
c
I and II only
d
I only
e
III only
Submit
Correct
EXPLANATION

A geometric distribution is used to model the number of binomial experiments needed before the first success.

With that in mind, let's consider each of the given random variables.

  • Random variable I does not follow a geometric distribution. Winning a chess game is a binomial experiment, but the number of times the player wins cannot be interpreted as the number of binomial experiments needed before the first success.

  • Random variable II follows a geometric distribution. Firing an arrow is a binomial experiment, and the number of arrows fired before the first arrow hits the bullseye can be interpreted as the number of binomial experiments needed before the first success.

  • Random variable III does not follow a geometric distribution. Passing a calculus exam is a binomial experiment, but the number of students passing the exam cannot be interpreted as the number of binomial experiments needed before the first success.

Therefore, the correct answer is "II only."
