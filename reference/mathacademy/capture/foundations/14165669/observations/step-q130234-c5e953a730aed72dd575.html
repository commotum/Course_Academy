Given X∼Geom(57), compute P(X≥3) rounded to 4 decimal places.

0.0816

EXPLANATION

If X∼Geom(p), then X has the following probability mass function:

f(x)={(1−p)x−1p,x=1,2,3,…0,otherwise

Here, X∼Geom(57), so the distribution of X in this case is

f(x)={(27)x−1(57),x=1,2,3…0,otherwise.

There are infinitely many values of X such that X≥3. However, we can simplify the computation by using the complement instead:

P(X≥3)=1−P(X<3)

Computing the complement, we get

P(X<3)=P(X∈{1,2})=P(X=1)+P(X=2)=f(1)+f(2)=(27)0(57)+(27)1(57)≈0.9184.

Therefore,

P(X≥3)=1−P(X<3)≈1−0.9184=0.0816.
