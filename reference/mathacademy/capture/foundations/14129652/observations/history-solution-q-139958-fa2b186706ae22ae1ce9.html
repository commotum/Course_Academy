First, notice that a matrix of rank 4 must have at least 4 columns and at least 4 rows. So, we disregard the following matrices:

  • A since it has only 2 rows.

  • B since it has only 3 rows.

  • D since it has only 3 columns.

Also, the matrix must have 4 pivot columns. As we can see, the matrix C has exactly 4 pivot columns, while the matrix E has only 3 pivot columns. So, rank(C)=4 and rank(E)=3.

Therefore, the correct answer is the matrix C.
