First, notice that a matrix of rank 4 must have at least 4 columns and at least 4 rows. So, we disregard the following matrices:

  • B since it has only 3 rows.

  • D since it has only 3 columns (and only 3 rows).

  • E since it has only 3 coumns.

Also, the matrix must have 4 pivot columns. As we can see, the matrix C has exactly 4 pivot columns, while the matrix A has only 2 pivot columns. So, rank(C)=4 and rank(A)=2.

Therefore, the correct answer is the matrix C.
