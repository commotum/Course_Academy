First, notice that a matrix of rank 3 must have at least 3 columns and at least 3 rows. So, we disregard the following matrices:

  • A since it has only 2 rows.

  • B since it has only 2 rows (and only 2 columns).

  • E since it has only 2 columns.

Also, the matrix must have 3 pivot columns. As we can see, the matrix C has exactly 3 pivot columns, while the matrix D has only 2 pivot columns. So, rank(C)=3 and rank(D)=2.

Therefore, the correct answer is the matrix C.
