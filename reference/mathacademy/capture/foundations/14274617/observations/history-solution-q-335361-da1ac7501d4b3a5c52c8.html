Euler's method approximates the solution of an initial value problem containing a system of ODEs by applying the update rule component-wise to each equation.

Since we want to find the value of y, z and w at x=1, we will use a step size of

Δx=1−0=1.

First, we place the initial condition data in a table.

x y y′ Δy z z′ Δz w w′ Δw
0 0 1 1

Next, we compute y′, z′, and w′ according to the given rules:

y′=1+2x−y+z=1+2⋅0−0+1=2z′=−2+x+2y=−2+0+2⋅0=−2w′=x+y−z+2w=0+0−1+2⋅1=1

So, we add these to our table.

x y y′ Δy z z′ Δz w w′ Δw
0 0 2 1 −2 1 1

Next, we compute Δy, Δz, and Δw using Euler's method:

Δy=y′⋅Δx=2⋅1=2Δz=z′⋅Δx=(−2)⋅1=−2Δw=w′⋅Δx=1⋅1=1

We add these to our table.

x y y′ Δy z z′ Δz w w′ Δw
0 0 2 2 1 −2 −2 1 1 1

To get the new values of x, y, z, and w in the next row, we add Δx to x, Δy to y, Δz to z, and Δw to w, as follows:

xnew=x+Δx=0+1=1ynew=y+Δy=0+2=2znew=z+Δz=1+(−2)=−1wnew=w+Δw=1+1=2

Adding these values to our table in a new row gives the following:

x y y′ Δy z z′ Δz w w′ Δw
0 0 2 2 1 −2 −2 1 1 1
1 2 −1 2

Therefore, we conclude that y(1)≈2, z(1)≈−1, and w(1)≈2.
