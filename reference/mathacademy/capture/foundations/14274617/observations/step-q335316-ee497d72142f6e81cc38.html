EXPLANATION

Euler's method approximates the solution of an initial value problem containing a system of ODEs by applying the update rule component-wise to each equation.

First, because the initial conditions are y(0)=−1, z(0)=1, and w(0)=0, we place y=−1, z=1, and w=0 in the table.

x y y′ Δy z z′ Δz w w′ Δw
0 −1 1 0

Next, we compute y′,z′, and w′ according to the given rules:

y′=2x+3y−w=2⋅0+3⋅(−1)−0=−3z′=1−y+2z=1−(−1)+2⋅1=4w′=z−x=1−0=1

So, we add these to our table.

x y y′ Δy z z′ Δz w w′ Δw
0 −1 −3 1 4 0 1

Finally, we compute Δy, Δz, and Δw using Euler's method:

Δy=y′⋅Δx=(−3)⋅13=−1Δz=z′⋅Δx=4⋅13=43Δw=w′⋅Δx=1⋅13=13

We add these to our table.

x y y′ Δy z z′ Δz w w′ Δw
0 −1 −3 −1 1 4 43 0 1 13

To get the new values of x, y, z, and w in the next row, we add Δx to x, Δy to y, Δz to z, and Δw to w, as follows:

xnew=x+Δx=0+13=13ynew=y+Δy=−1+(−1)=−2znew=z+Δz=1+43=73wnew=w+Δw=0+13=13

Adding these values to our table in a new row gives the following:

x y y′ Δy z z′ Δz w w′ Δw
0 −1 −3 −1 1 4 43 0 1 13

Therefore, we conclude that y(13)≈−2, z(13)≈73, and w(13)≈13.
