Consider the vector space M2(R) of all 2×2 matrices over R and its subset C={[a00−a]|a∈R}.

Which of the following statements are true?

  1. C is closed under matrix addition
  2. C is closed under scalar multiplication
  3. C is a subspace of M2(R)
  4. C is not a subspace of M2(R)
a
IV only
b
I and IV only
c
II and IV only
d
II only
e
I, II, and III only
Submit
Incorrect
EXPLANATION

Recall that a subset of a vector space is a subspace if it's closed under addition and scalar multiplication.

With that in mind, let's examine each statement in turn.

  • Statement I is true. If A1=[a100−a1] and A2=[a200−a2] are two matrices from C, then A1+A2=[a100−a1]+[a200−a2]=[a1+a200−(a1+a2)], which is a matrix from C. So, C is closed under addition.

  • Statement II is true. If A=[a00−a] is an element of C and k∈R, then kA=k[a00−a]=[ka00−ka], which is a matrix from C. So, C is closed under scalar multiplication.

  • Statement III is true, while statement IV is false. C is a subspace because it's closed under addition and scalar multiplication.

Therefore, the correct answer is "I, II, and III only."
