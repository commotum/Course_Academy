We find the constants A and B using the initial conditions.

  • Substituting y(0)=4 into the general solution gives A=4.

  • To apply the condition y′(0)=8, we first differentiate y to get y′=Aex+Bex+Bxex. Substituting y′(0)=8 into the above gives A+B=8. Using the fact that A=4 gives B=4.

Therefore, the solution to the initial value problem is y=4ex+4xex.
