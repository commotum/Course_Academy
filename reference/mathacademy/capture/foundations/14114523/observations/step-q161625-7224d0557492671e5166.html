Consider the set A, defined by A={(x,y)∈R2:y≥2−x}.

Which of the following statements are true?

  1. A contains none of its boundary points.
  2. A contains some (not all) of its boundary points.
  3. intA≠A
a
III only
b
I and II only
c
II only
d
I and III only
e
None of the statements are true

Correct
EXPLANATION

The boundary of a set A, denoted ∂A, is the set that contains all the boundary points of A.

In this case, the set A and its boundary ∂A are shown below.

The interior of a set A, denoted intA, is the set containing all the interior points of A. It contains every point in A except the boundary points: intA=A−∂A

Notice that, in this case, the set A contains all of its boundary points.

With that in mind, let's examine each statement:

  • Statements I and II are false. As we have seen, A contains all its boundary points.

  • Statement III is true. Since A contains all of its boundary points, we must have A−∂A⊊A. Therefore intA≠A.

Therefore, the correct answer is "III only."
