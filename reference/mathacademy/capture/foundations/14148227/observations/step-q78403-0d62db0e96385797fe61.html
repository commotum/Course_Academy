Given the curve r(t)=⟨2et,3et,6et⟩, t≥0, for which the arc length s from r(0) to r(t) is given by s=7(et−1), find the corresponding unit tangent T(s), parametrized by s.

a
⟨15,35,35⟩

⟨17,27,37⟩

⟨25,35,65⟩

⟨27,37,67⟩

⟨214,314,27⟩

Correct
EXPLANATION

First, since s=7(et−1), we have that s7=et−1et=s7+1t=ln⁡(s+77).

Therefore, the vector function R(s) that parametrizes r(t) by its arc length is given by

R(s)=r(ln⁡(s+77))=⟨2eln⁡(s+77),3eln⁡(s+77),6eln⁡(s+77)⟩=⟨2⋅s+77,3⋅s+77,6⋅s+77⟩=⟨2s+147,3s+217,6s+427⟩.

Now, since the curve is parametrized by its arc length s, the unit tangent can be found as T(s)=ddsR(s).

So, we obtain

T(s)=ddsR(s)=⟨dds(2s+147),dds(3s+217),dds(6s+427)⟩=⟨27,37,67⟩.
