Find f(x,y) such that ∇f=F, where F(x,y)=2xsin⁡yi+(x2cos⁡y+3y2)j.

a
f(x,y)=x2cos⁡y+3y+C
b
f(x,y)=x2sin⁡y+y3+C
c
f(x,y)=x2cos⁡y+2y+C
d
f(x,y)=xsin⁡y+y3+C
e
f(x,y)=xsin⁡y+y2+C
Submit
Incorrect
EXPLANATION

The gradient of the function f(x,y) is defined as ∇f(x,y)=∂f∂xi+∂f∂yj.

Since ∇f(x,y)=F(x,y), the function f(x,y) must satisfy the following system: ∂f∂x=2xsin⁡y,∂f∂y=x2cos⁡y+3y2

First, we integrate ∂f∂x with respect to x. Note that the solution should contain an arbitrary function of y: f(x,y)=∫∂f∂xdx=∫2xsin⁡ydx=x2sin⁡y+g(y)

Now, differentiating the above expression with respect to y, we obtain ∂f∂y=x2cos⁡y+g′(y).

Taking ∂f∂y=x2cos⁡y+3y2 into account, we obtain x2cos⁡y+g′(y)=x2cos⁡y+3y2g′(y)=3y2g(y)=y3+C, where C is a constant.

Finally, substituting g(y)=y3+C into our expression for f(x,y), we get f(x,y)=x2sin⁡y+y3+C.
