At which point on the curve xy2=3−2y is the tangent vector to the curve perpendicular to the vector i?

a
(0,32)
b
(1,1)
c
(5,−1)
d
(−14,2)
e
(−13,3)
Submit
Incorrect
EXPLANATION

First, we bring all variables to one side: xy2=3−2yxy2+2y=3

If we set f(x,y)=xy2+2y, our curve can be viewed as the level curve f(x,y)=3.

A tangent vector to the level curve can be computed as follows: t(x,y)=fy(x,y)i−fx(x,y)j

So, we calculate t(x,y): t(x,y)=fy(x,y)i−fx(x,y)j=∂∂y(xy2+2y)i−∂∂x(xy2+2y)j=(2xy+2)i−y2j

Since our tangent vector needs to be perpendicular to i, we must have t⋅i=0.

t(x,y)⋅i=0((2xy+2)i−y2j)⋅i=02xy+2=0xy+1=0y=−1x

Substituting y=−1x into the equation of our curve gives xy2=3−2yx(−1x)2=3−2(−1x)1x=3+2x1x=−3x=−13.

Finally, for x=−13, we get y=3, and the corresponding point is (−13,3).
