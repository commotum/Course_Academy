EXPLANATION

For two random variables X and Y, the covariance matrix Σ is given by

Σ=[Var[X]Cov[X,Y]Cov[Y,X]Var[Y]].

Recall that the variance of a random variable X is determined by the formula

Var[X]=E[X2]−E[X]2.

We compute E[X2] using the rule of the lazy statistician:

E[X2]=∫04∫02x2⋅f(x,y)dxdy=∫04∫02x2(116xy)dxdy=116∫04y∫02x3dxdy=116∫04y⋅[14x4]02dy=14∫04ydy=14⋅[12y2]04=14⋅8=2.

Therefore,

Var[X]=E[X2]−E[X]2=2−(43)2=29.

Similarly, we compute E[Y2] using the rule of the lazy statistician:

E[Y2]=∫04∫02y2⋅f(x,y)dxdy=∫04∫02y2(116xy)dxdy=116∫04y3∫02xdxdy=116∫04y3[12x2]02dy=18∫04y3dy=18⋅[14y4]04=18⋅64=8.

Therefore,

Var[Y]=E[Y2]−E[Y]2=8−(83)2=89.

Now, we find the covariance of X and Y. The joint support of X and Y is given by the rectangle

S=[0,2]×[0,4].

Moreover, we can write

f(x,y)=g(x)⋅h(y),

where g(x)=x2 and h(y)=y8.

Hence, X and Y are independent, and consequently Cov[X,Y]=0.

Therefore, the covariance matrix is given by

Σ=[Var[X]Cov[X,Y]Cov[Y,X]Var[Y]]=[290089].
