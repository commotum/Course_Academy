f(x,y)={x+y,0≤x≤1,0≤y≤1,0,otherwise.

Given that E[X]=E[Y]=712, and E[X2]=512, find the covariance matrix for X and Y.

EXPLANATION

For two random variables X and Y, the covariance matrix Σ is given by

Σ=[Var[X]Cov[X,Y]Cov[Y,X]Var[Y]].

Recall that the variance of a random variable X is determined by the formula

Var[X]=E[X2]−E[X]2,

and the covariance of two random variables X and Y is given by the formula

Cov[X,Y]=E[XY]−E[X]⋅E[Y].

First, we find Var[X]. Using the given results, we have

Var[X]=E[X2]−E[X]2=512−(712)2=11144.

Similarly, we compute E[Y2] using the rule of the lazy statistician:

E[Y2]=∫01∫01y2⋅f(x,y)dxdy=∫01∫01y2(x+y)dxdy=∫01∫01(xy2+y3)dxdy=∫01[12x2y2+xy3]x=0x=1dy=∫01(12y2+y3)dy=[16y3+14y4]01=16+14=512.

Therefore,

Var[Y]=E[Y2]−E[Y]2=512−(712)2=11144.

Finally, let's find Cov[X,Y]. By the rule of the lazy statistician, we find E[XY]:

E[XY]=∫01∫01xy⋅f(x,y)dxdy=∫01∫01xy(x+y)dxdy=∫01∫01(x2y+xy2)dxdy=∫01[13x3y+12x2y2]01dy=∫01(13y+12y2)dy=[16y2+16y3]01=16+16=13.

Then, using the covariance formula, we have

Cov[X,Y]=E[XY]−E[X]⋅E[Y]=13−(712)⋅(712)=−1144.

Therefore, the covariance matrix is given by

Σ=[Var[X]Cov[X,Y]Cov[Y,X]Var[Y]]=[11144−1144−114411144]=1144[11−1−111].
