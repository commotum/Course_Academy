  2. f(x)=F(x) for all x∈R
  3. f(x+5π2)=f(x) for all x∈R

Correct
EXPLANATION

Since f is the π-periodic extension of F, we have

  • f(x+π)=f(x) for all x∈R, and

  • f(x)=F(x) for all x∈[0,π).

With that in mind, let's examine our statements in turn.

  • Statement I is true. This is exactly the definition of π-periodicity: f(x+π)=f(x) for all x∈R.

  • Statement II is true. Notice that F itself is π-periodic, because for any x∈R, we have F(x+π)=sin⁡(2(x+π))=sin⁡(2x+2π)=sin⁡(2x)=F(x). Since F already satisfies the periodicity rule, the π-periodic extension agrees with F everywhere, so f(x)=F(x) for all x∈R.

  • Statement III is false. Since f is π-periodic, shifting by 2π does not change the value of f, so f(x+5π2)=f((x+π2)+2π)=f(x+π2). But f(x+π2) does not always equal f(x). For example, take x=π3. Then, f(π3+π2)=f(5π6)=F(5π6)=sin⁡(5π6)=12, while f(π3)=F(π3)=sin⁡(π3)=32. Hence, f(x+5π2)≠f(x) for x=π4.

Therefore, the correct answer is "I and II only".
