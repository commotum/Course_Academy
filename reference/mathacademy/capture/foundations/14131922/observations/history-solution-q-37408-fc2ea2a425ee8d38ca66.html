First, since the given matrix is triangular, its eigenvalues are the entries on the main diagonal. Hence, λ1=λ2=λ4=−1 (triple root), λ3=3 (simple root).

Let's now consider the eigenspaces corresponding to each eigenvector:

  • First, we consider λ=3. Since V3 correspond to a simple root, we obtain dim(V3)=1.

  • Next, we consider λ=−1, which is a repeated root of the characteristic equation. To find the dimension of V−1, we row-reduce the matrix (A−1I)x=0: A−λI=[−11000−1100030000−1]+1[1000010000100001]=[0100001000400000]R3:=R3+(−4)R2=[0100001000000000] In the row echelon form matrix above, there are two pivot columns (the 2nd and the 3rd). This implies that we will have only 4−2=2 linearly independent eigenvectors corresponding to the eigenvalue λ=−1.

Therefore, dim(V−1)=2.
