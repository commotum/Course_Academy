Which of the following is a stream function for the vector field F(x,y)=2xyi+(y2−x2)j?

a
ψ(x,y)=x2−4y
b
ψ(x,y)=y2+xy
c
F has no stream function
d
ψ(x,y)=y2+2xy
e
ψ(x,y)=y2+x
Submit
Correct
EXPLANATION

A vector field F=Pi+Qj with a simply connected domain D⊆R2 has a stream function ψ(x,y) if and only if ∂P∂x+∂Q∂y=0.

Note that F(x,y)=2xyi+(y2−x2)j is a vector field with simply connected domain D=R2, where P(x,y)=2xy and Q(x,y)=y2−x2. Computing the partial derivatives, we have

∂P∂x=2y,∂Q∂y=2y.

Hence, F has a no stream function, since

∂P∂x+∂Q∂y=2y+2y=4y≠0.
