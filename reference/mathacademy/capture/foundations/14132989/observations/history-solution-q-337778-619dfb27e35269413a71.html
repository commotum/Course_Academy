An nth-order differential operator L is linear if it is of the following form:

L(y)=fn(x)dnydxn+fn−1(x)dn−1ydxn−1+⋯+f1(x)dydx+f0(x)y where each fi is a function of x only.

With that in mind, let's check each operator.

  • Operator D1 is linear. It is a first-order linear differential operator of the form D1(y)=f1(x)dydx+f0(x)y with f1(x)=1x+1 and f0(x)=sin⁡(x).

  • Operator D2 is linear. It is a second-order linear differential operator of the form D2(y)=f2(x)d2ydx2+f1(x)dydx+f0(x)y with f2(x)=x,f1(x)=−ln⁡(x), and f0(x)=−2.

  • Operator D3 is linear. It is a third-order linear differential operator of the form D3(y)=f3(x)d3ydx3+f2(x)d2ydx2+f1(x)dydx+f0(x)y with f3(x)=2,f2(x)=ex,f1(x)=0, and f0(x)=−11+x2.

Therefore, the correct answer is "I, II, and III."
