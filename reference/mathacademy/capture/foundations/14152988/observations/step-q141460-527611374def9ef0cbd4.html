Which of the following statements are true given that T:R7→R7 is a linear transformation whose standard matrix is T, and T(x)=v has no solution for some vector v?

  1. T is not invertible
  2. nullity(T)=0
  3. rank(T)≠7
a
I only
b
II and III only
c
II only
d
I and III only
e
III only

Correct
EXPLANATION

Since T is a linear transformation from R7 into R7, the invertible matrix theorem states the following:

T is a bijection (an invertible transformation) ⟺{Im(T)=R7rank(T)=7Ker(T)={0}nullity(T)=0

With that in mind, let's examine each statement in turn.

  • Statement I is true. Since T(x)=v has no solution, we have that v∉Im(T), hence Im(T)≠R7. According to the invertible matrix theorem, since Im(T)≠R7, the transformation T and the matrix T are not invertible.

  • Statement II is false. Since T is not invertible, the invertible matrix theorem implies that nullity(T)≠0.

  • Statement III is true. Since T is not invertible, the invertible matrix theorem implies that rank(T)≠7.

Therefore, the correct answer is "I and III only."
