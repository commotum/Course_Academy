A box is selected at random, and one marble is chosen from the selected box, also at random. If the selected marble is black, what is the probability that it came from the first box?

EXPLANATION

Let F be the event that the first box is selected, and let B be the event that a randomly selected marble is black. Then, we require P(F|B), which we can compute using Bayes' theorem.

P(F|B)=P(B|F)P(F)P(B)=P(B|F)P(F)P(B|F)P(F)+P(B|F′)P(F′)

Note that F′ is the event that the second box is selected.

From the problem statement, we have the following:

  • Since the first box contains two black and four blue marbles, and the second box contains one black and five blue marbles, we have P(B|F)=26=13,P(B|F′)=16.

  • Since the box is selected at random, we have P(F)=P(F′)=12.

Therefore, using Bayes' theorem, we have

P(F|B)=P(B|F)P(F)P(B|F)P(F)+P(B|F′)P(F′)=(13⋅12)(13⋅12+16⋅12)=(16)(16+112)=23.
