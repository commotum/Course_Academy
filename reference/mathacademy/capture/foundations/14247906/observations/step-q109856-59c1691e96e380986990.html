Which of the following subspaces must be orthogonal to Null(A+B) for all compatible matrices A and B?

  1. Null(AT+BT)
  2. Col(AT+BT)
  3. Col(A+B)
a
I and II only
b
I only
c
II only
d
II and III only
e
III only
Submit
Incorrect
EXPLANATION

Recall that Null(A+B) contains all vectors that, when pre-multiplied by A+B, result in the zero-vector 0.

When pre-multiplying a vector by A+B, we actually multiply each row of A+B by that vector. So, Null(A+B) must be orthogonal to the row space of A+B, which is Col((A+B)T)=Col(AT+BT).

Therefore, the correct answer is "II only."
