An inhibited decay initial value problem has the form

dydt=−k(y−a),y(0)=y0

where k>0 is a constant of proportionality, and y>a for all t>0.

From the given options, the only inhibited decay problem is dydt=−30(y−200),y(0)=210. In this case, k=30,a=200, and y0=210. Notice that y0>a, which is required for inhibited decay.

The other options do not represent inhibited decay. In particular, the initial value problem dydt=−30(y−200),y(0)=100,

does not represent inhibited decay model because y0=100<a=200.
