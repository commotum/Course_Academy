With that in mind, let's examine each of the given functions.

  • Functions I and III equal xsin⁡(x+y) on D and equal 0 outside D.

  • We cannot use function II. The function is not identically zero for all points in R∖D. For example, (x,y)=(1,2)∈R∖D, but the function is nonzero at this point.
