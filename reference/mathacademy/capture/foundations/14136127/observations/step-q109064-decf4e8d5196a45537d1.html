EXPLANATION

Recall that for any random variable X and constant a, we have

Var[aX]=a2⋅Var[X].

In our case, a=7. Therefore,

Var[7X]=72⋅Var[X]=49⋅Var[X].

We can compute the variance of X using the following formula:

Var[X]=E[X2]−E[X]2

Additionally, we're given that E[X]=3.

We start by computing E[X2]. Summing up the products of each value of X2 and its associated probability, we get

E[X2]=12⋅f(1)+22⋅f(2)+42⋅f(4)=1⋅17+4⋅27+16⋅47=737.

Therefore,

Var[X]=E[X2]−E[X]2=737−32=107.

Finally,

Var[7X]=49⋅Var[X]=49⋅107=70.
