Consider the standard matrices of three linear transformations shown below. Which of the transformations map R2 onto a line?

T1=[2369],T2=[0000],T3=[2963]

a
T2 only
b
T1 only
c
T3 only
d
T1 and T2 only
e
T2 and T3 only
Submit
Correct
EXPLANATION

Given a linear transformation over R2 with the standard matrix T, we have the following:

  • T maps R2 onto R2 if and only if rank(T)=2, i.e., T is nonsingular.

  • T maps R2 onto a line if and only if rank(T)=1.

  • T maps R2 onto (0,0) if and only if rank(T)=0, i.e., T is the zero matrix.

With that in mind, let's examine our matrices.

  • T1 maps R2 onto a line. Notice that the columns of T1 are linearly dependent but it's not the zero matrix. So, rank(T1)=1.

  • T2 maps R2 onto (0,0) since T2 is the zero matrix, i.e. rank(T2)=0.

  • T3 maps R2 onto R2. Indeed, T3 is a nonsingular matrix, i.e. rank(T3)=2.

Therefore, the correct answer is "T1 only."
