The second shifting theorem states that if a≥0, then L{u(t−a)f(t−a)}=e−asF(s), where F(s)=L{f(t)}.

In our case, we wish to find the transform of u(t−3)sin(5(t−3)).

By comparing this expression to the form in the theorem, we can identify the following:

  • The shift is a=3.

  • The shifted function is f(t−3)=sin(5(t−3)).

From the shifted function, we can deduce the original unshifted function f(t) by simply replacing (t−3) with t: f(t)=sin⁡(5t).

Now, we calculate the Laplace transform F(s) of the unshifted function: F(s)=L{sin⁡(5t)}=5s2+25.

Finally, we apply the shifting theorem formula L{u(t−a)f(t−a)}=e−asF(s) by multiplying F(s) by the exponential delay factor e−3s:

L{u(t−3)sin(5(t−3))}=e−3s⋅F(s)=e−3s⋅5s2+25.
