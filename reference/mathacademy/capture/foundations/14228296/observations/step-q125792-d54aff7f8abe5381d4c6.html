Consider the vector field F(x,y)=⟨1,x⟩ and the points A(1,0) and B(e,1) in the xy-plane.

Which of the following statements are true?

  1. ∫C1F⋅dr=2(e−1), where C1 is the path along the curve y=ln⁡x, traversed from A to B.
  2. ∫C2F⋅dr=2(e−1), where C2 is the path along the segment line AB―, traversed from A to B.
  3. ∫CF⋅dr is independent of path.
  4. F is conservative.

Correct
EXPLANATION

Let C be a piecewise-smooth curve given by the vector-valued function r(t) for t∈[a,b]. Let f be a differentiable function of two or three variables such that ∇f is continuous on C. The fundamental theorem for line integrals states that

∫C∇f⋅dr=f(r(b))−f(r(a)).

This theorem implies that the line integral of a conservative vector field depends only on the value of f at the initial and terminal points A and B, and is independent of the path between them.

With that in mind, we consider each statement in turn.

  • Statement I is true. Parameterizing the curve, we have r1(t)=⟨t,ln⁡t⟩,t∈[1,e]. Therefore, ∫C1F⋅dr=∫abF(r(t))⋅r′(t)dt=∫1e⟨1,t⟩⋅⟨1,1t⟩dt=∫1e1+1dt=∫1e2dt=2t|1e=2(e−1).

  • Statement II is false. Parameterizing the line segment, we have r2(t)=⟨t(e−1)+1,t⟩,t∈[0,1]. Therefore, ∫C2F⋅dr=∫abF(r(t))⋅r′(t)dt=∫01⟨1,t(e−1)+1⟩⋅⟨e−1,1⟩dt=∫01e−1+t(e−1)+1dt=∫01t(e−1)+edt=[t2(e−1)2+et]01=e−12+e=3e−12.

  • Statement III is false. Since C1 and C2 have the same initial and terminal points, yet ∫C1F⋅dr≠∫C2F⋅dr, we conclude that ∫CF⋅dr is path-dependent.

  • Statement IV is false. If a vector field is conservative then it is path-independent. Since F is path-dependent, it is not conservative.
