At which points on the curve 2xy+3y2=x2+4 is the tangent vector to the curve perpendicular to the vector j?

a
(−1,0) only
b
(0,1) only
c
(1,1) and (−1,−1)
d
(1,−1) only
e
(0,1) and (−1,0)
Submit
Correct
EXPLANATION

First, we bring all variables to one side: 2xy+3y2=x2+42xy+3y2−x2=4

If we set f(x,y)=2xy+3y2−x2, our curve can be viewed as the level curve f(x,y)=4.

A tangent vector to the level curve can be computed as follows: t(x,y)=fy(x,y)i−fx(x,y)j

So, we calculate t(x,y):

t(x,y)=fy(x,y)i−fx(x,y)j=∂∂y(2xy+3y2−x2)i−∂∂x(2xy+3y2−x2)j=(2x+6y)i−(2y−2x)j

Since our tangent vector needs to be perpendicular to j, we must have t⋅j=0.

t(x,y)⋅j=0((2x+6y)i−(2y−2x)j)⋅j=02y−2x=0y=x

Substituting y=x into the equation of our curve gives:

2xy+3y2=x2+42x(x)+3(x)2=x2+42x2+3x2=x2+44x2=4x2=1x=±1

Finally:

  • If x=1, we get y=1 and the corresponding point is (1,1).

  • If x=−1, we get y=−1 and the corresponding point is (−1,−1).
