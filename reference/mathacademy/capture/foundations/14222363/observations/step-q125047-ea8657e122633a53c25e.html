Which of the following is equivalent to ∫CF⋅dr, where F(x,y)=ln⁡(x+y)i+xyj and C is the line segment traversed from the point A(1,1) to the point B(4,3)?

Hint: Use the parametrization r(t)=(1+3t)i+(1+2t)j.

a
∫015ln⁡(5t)+66tdt
b
∫01ln⁡(2+5t)+1+5t+6t2dt
c
∫015ln⁡(2+5t)+61+5t+6t2dt
d
∫013ln⁡(2+5t)+21+5t+6t2dt
e
∫012ln⁡(5t)+36tdt
Submit
Incorrect
EXPLANATION

We will use the formula ∫CF⋅dr=∫abF(r(t))⋅r′(t)dt.

First, we need to parameterize the line segment. The position vectors of the endpoints of our line segment are a=i+j and b=4i+3j. So, the parametrization of the line segment is given by

r(t)=a+t(b−a)=(i+j)+t[(4i+3j)−(i+j)]=(i+j)+t(3i+2j)=(1+3t)i+(1+2t)j,

where t varies from t=0 (at the point A) to t=1 (at the point B). Thus, along the curve C, we have x=1+3t,y=1+2t.

As a result,

F(r(t))=ln⁡(x+y)i+xyj=ln⁡(1+3t+1+2t)i+(1+3t)(1+2t)j=ln⁡(2+5t)i+1+5t+6t2j.

Computing r′(t), we get

r′(t)=dxdti+dydtj=ddt(1+3t)i+ddt(1+2t)j=3i+2j.

Therefore, F(r(t))⋅r′(t)=(ln⁡(2+5t)i+1+5t+6t2j)⋅(3i+2j)=ln⁡(2+5t)⋅3+1+5t+6t2⋅2=3ln⁡(2+5t)+21+5t+6t2.

Finally, we can write the integral as

∫CF⋅dr=∫01F(r(t))⋅r′(t)dt=∫013ln⁡(2+5t)+21+5t+6t2dt.
