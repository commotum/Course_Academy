Since B and C are bases, the following properties must hold:

  • B and C are maximally linearly independent sets in R2 and R3, respectively, and

  • B spans R2, while C spans R3.

With that in mind, let's examine our statements.

  • Statement I is false. Since B={b1,b2} is a basis of R2, any vector of R2, including the given vector x, can be written as a linear combination of b1 and b2. This means that {b1,b2,x} is linearly dependent and therefore, cannot be a basis.

  • Statement II is false. The set {b1,b2} is not a basis of R3 because the set contains vectors from another vector space.

  • Statement III is true. The set {c3,c2,c1} is a basis of R3 because, by reordering the vectors, we obtain the basis C.

Therefore, the correct answer is "III only".
