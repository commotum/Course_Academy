Consider the vector space R2[t] of all polynomials in the variable t over R with degrees at most 2.

Which of the following statements are true?

  1. {t,t2} is a linearly independent set in R2[t]
  2. t2+1 can be expressed as a linear combination of {t,t2}
  3. {t,t2} is a basis of R2[t]
a
III only
b
I and II only
c
II only
d
I and III only
e
I only

Correct
EXPLANATION

Let's examine each of the statements in turn.

  • Statement I is true. Indeed, the equation x1⋅t+x2⋅t2=0, is true if and only if x1=x2=0. So, the set is linearly independent.

  • Statement II is false. Notice that all linear combinations of {t,t2} result in polynomials without the constant term.

  • Statement III is false. Indeed, the polynomial t2+1 can't be written as a linear combination of the set {t,t2}.

Therefore, the correct answer is "I only."
