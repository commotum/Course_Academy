Let B={b1,b2,b3} and C={c1,c2} be bases of R3 and R2, respectively.

Which of the following statements are true?

  1. {c1,c2,x} is a basis of R2
  2. {b1,b2} is a basis of R3
  3. {b1,b2,c1} is a basis of R3

II only
b

II and III only

Correct
EXPLANATION

Since B and C are bases, the following properties must hold:

  • B and C are maximally linearly independent sets in R2 and R3, respectively, and

  • B spans R2, while C spans R3.

With that in mind, let's examine our statements.

  • Statement I is false. Since C={c1,c2} is a basis of R2, any vector of R2, including the given vector x, can be written as a linear combination of c1 and c2. This means that {c1,c2,x} is linearly dependent and therefore, cannot be a basis.

  • Statement II is false. The set {b1,b2} is not a basis of R3 because the vector b3 is in R3 but it is not a linear combination of b1 and b2 as the set {b1,b2,b3} is linearly independent. This means that the set does not span R3 and therefore, cannot be a basis.

  • Statement III is false. The set {b1,b2,c1} is not a basis of R3 because the set contains vectors from another vector space.

Therefore, the correct answer is "None of the statements are true".
