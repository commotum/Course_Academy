EXPLANATION

For a continuous random variable X and a function r(x), the rule of the lazy statistician states that

E[r(x)]=∫−∞∞r(x)f(x) dx,

where f(x) is the probability density function of X.

In this problem, the break point X is chosen uniformly from [0,2], so the probability density function is

f(x)=12,0≤x<2.

When the stick is broken at point X, it is divided into two pieces: one of length X and the other of length 2−X. The shorter of the two pieces, Y, is therefore given by

Y=min(X,2−X).

Therefore, we define

r(x)=min(x,2−x).

To evaluate the integral, we express r(x) as an explicit piecewise function. Observe that,

  • if 0≤x<1, then x<2−x, so the shorter piece has length x,

  • if 1≤x≤2, then x≥2−x, so the shorter piece has length 2−x.

Therefore,

r(x)={x,0≤x<1,2−x,1≤x≤2.

Therefore, the expected length of the shorter piece is 12.
