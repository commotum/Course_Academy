Which of the following represents the shaded region above as a type II region in two-dimensional space?

a
D={(x,y):0≤y≤x2,0≤x≤1}
b
D={(x,y):0≤y≤1,y≤x≤y}
c
D={(x,y):0≤y≤1,0≤x≤1}
d
D={(x,y):0≤y≤1,0≤x≤y}
e
D={(x,y):0≤y≤1,0≤x≤y}
Submit
Incorrect
EXPLANATION

A type II region can be written as

D={(x,y):a≤y≤b,g(y)≤x≤f(y)},

where f and g are continuous functions.

To express the given region as a type II region, we first rewrite all of the given curves as functions of y:

y=x2⟹x=y

The function x=y is already written as a function of y.

Notice that the region lies between the horizontal lines y=0 and y=1. So, we have 0≤y≤1.

We draw a horizontal arrow through the region to determine the left function g(y) and the right function f(y). A horizontal line should intersect the region in a single interval only for it to be a type II region.

The horizontal line enters the region through the lower function x=y and leaves through the upper function x=y. So, we have y≤x≤y.

Therefore, we obtain D={(x,y):0≤y≤1,y≤x≤y}.
