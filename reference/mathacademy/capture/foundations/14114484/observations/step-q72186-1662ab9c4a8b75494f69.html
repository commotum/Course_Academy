  2. It is a type II region

Correct
EXPLANATION

First, let's sketch our region.

We have the following:

  • Any vertical line through the region intersects it on a single interval. Furthermore, we can represent our region as D={(x,y):−2≤x≤2,2−|x|≤y≤4−x2}. So, this is a type I region.

  • The horizontal line y=1 intersects the region in two separate intervals, as shown below. So, this can't be a type II region.

Therefore, only statement I is true.
