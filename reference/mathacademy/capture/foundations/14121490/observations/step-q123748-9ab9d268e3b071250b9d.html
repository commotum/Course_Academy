a
K(x,y,z)=−i+j
b
None of the listed
c
H(x,y,z)=−2i
d

Correct
EXPLANATION

We notice the following:

  • Each vector in our vector field is parallel to the x-axis. So, the j and k components of our vector field are zero everywhere. Therefore, we can rule out the following option: K(x,y,z)=−i+j

  • Moreover, each vector in our vector field is pointing in the negative x-direction, so the i component of our vector field is negative. Therefore, we can rule out the following option: F(x,y,z)=i

  • Finally, we note that each vector in our vector field has the same length, so the i component of our vector field is constant. Therefore, we can rule out the following option: G(x,y,z)=−yi

Therefore, we conclude that the diagram corresponds to the vector field H(x,y,z)=−2i.
