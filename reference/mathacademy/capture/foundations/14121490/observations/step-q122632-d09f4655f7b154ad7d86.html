Which of the following could be the function that generates the vector field above?

a
K(x,y)=−i−2j
b
F(x,y)=i+j
c
G(x,y)=5j
d
H(x,y)=xj
e
None of the listed
Submit
Incorrect
EXPLANATION

We notice the following:

  • The horizontal component (i.e., the i component) is zero for every vector in our vector field. Therefore, we can rule out the following options: F(x,y)=i+j,K(x,y)=−i−2j

  • As we move away from the origin in the horizontal direction, our vectors' vertical components (i.e., the j components) get longer. Therefore, we can rule out the following option: G(x,y)=5j

Therefore, we conclude that the diagram corresponds to the vector field H(x,y)=xj.
