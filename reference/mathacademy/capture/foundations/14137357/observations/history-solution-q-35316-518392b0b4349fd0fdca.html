The dimension of the null space of a matrix is the number of non-pivot columns in the matrix.

Also, all of the given matrices are in row echelon form.

With that in mind, let's consider each of the statements.

  • The matrix A has 3 pivot columns and no non-pivot column. So, dim(Null(A))=0.

  • The matrix B has 1 pivot column and 1 non-pivot column (namely, the 2nd column). So, dim(Null(B))=1.

  • The matrix C has 3 pivot columns and 1 non-pivot column (namely, the 4th column). So, dim(Null(C))=1.

Therefore, dim(Null(A))+dim(Null(B))+dim(Null(C))=0+1+1=2.
