If F is a vector field and C is a piecewise-smooth, simple, closed curve, then the flux of F across C is given by ∮CF⋅nds, where n denotes the outward-pointing unit normal vector to C.

To understand the flux intuitively, we imagine that F represents a stream of flowing water. The flux of F across C represents the net flow of water escaping the region bounded by C:

  • If more water flows out through C than in through C (i.e., there is a net flow out through C), the flux is positive.

  • If more water flows in through C than out through C (i.e., there is a net flow in through C), the flux is negative.

  • If the net flow through C is zero then the flux equals zero.

For an arbitrary closed curve, the outward-pointing unit normal vector tells us which direction is "out."
