Given that the differential equation y″−7y′−8y=0

has the general solution

y=Ae−x+Be8x,

solve the initial value problem

y″−7y′−8y=0,y(0)=0,  y′(0)=−18.

y=2e−x−2e8x

Correct
EXPLANATION

We find the constants A and B using the initial conditions.

  • Substituting y(0)=0 into the general solution gives A+B=0.

  • To apply the condition y′(0)=−18, we first differentiate y to get y′=−Ae−x+8Be8x. Then, we substitute y′(0)=−18 into the above to get −A+8B=−18.

Putting the two equations from above together, we have the following system:

{A+B=08B−A=−18

Solving this system gives A=2,B=−2.

Therefore, the solution to the initial value problem is y=2e−x−2e8x.
