EXPLANATION

We have a repeated root λ=−3, so we have the following general solution:

y=Ae−3x+Bxe−3x

We find the constants A and B using the initial conditions.

  • Substituting y(0)=−2 into the general solution gives A=−2.

  • To apply the condition y′(0)=2, we first differentiate y to get y′=−3Ae−3x+Be−3x−3Bxe−3x. Then, we substitute y′(0)=2 into the above to get −3A+B=2. Using the fact that A=−2 gives B=−4.

Therefore, the solution to the initial value problem is y=−2e−3x−4xe−3x.
