Given that the differential equation

y″+7y=0

has the general solution

y=Asin⁡(7x)+Bcos⁡(7x),

solve the following initial value problem:

y″+7y=0,y(0)=−1,y′(0)=0.

a
y=−sin⁡(7x)−cos⁡(7x)
b
y=sin⁡(7x)−cos⁡(7x)
c
y=−cos⁡(7x)
d
y=2sin⁡(7x)−cos⁡(7x)
e
y=−3sin⁡(7x)−cos⁡(7x)
Submit
Correct
EXPLANATION

We find the constants A and B using the initial conditions.

  • Substituting y(0)=−1 into the general solution gives B=−1.

  • To apply the condition y′(0)=0, we first differentiate y to get y′=A7cos⁡(7x)−B7sin⁡(7x). Substituting y′(0)=0 into the above gives 0=A7⟹A=0.

Therefore, the solution to the initial value problem is

y=−cos⁡(7x).
