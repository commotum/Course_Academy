Given that the differential equation y″+4y′+13y=0

has the general solution y=e−2x(Pcos⁡3x+Qsin⁡3x),

solve the initial value problem y″+4y′+13y=0,y(0)=1,y′(0)=−1.

a
y=e−2x(cos⁡3x−sin⁡3x)
b
y=e−2x(cos⁡3x+sin⁡3x)
c
y=e−2x(cos⁡3x+2sin⁡3x)
d
y=e−2x(cos⁡3x−3sin⁡3x)
e
y=e−2x(cos⁡3x+13sin⁡3x)
Submit
Incorrect
EXPLANATION

We find the constants P and Q using the initial conditions.

  • Substituting y(0)=1 into the general solution gives P=1.

  • To apply the condition y′(0)=−1, we first differentiate y to get y′=−2e−2x(Pcos⁡3x+Qsin⁡3x)+e−2x(−3Psin⁡3x+3Qcos⁡3x). Then, we substitute y′(0)=−1 into the above to get −2P+3Q=−1. Using the fact that P=1 gives Q=13.

Therefore, the solution to the initial value problem is y=e−2x(cos⁡3x+13sin⁡3x).
