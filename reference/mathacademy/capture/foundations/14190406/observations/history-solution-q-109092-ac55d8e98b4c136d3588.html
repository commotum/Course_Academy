Recall that for any random variable X and constants a and b, we have

Var[aX+b]=a2⋅Var[X].

In our case, a=3 and b=−5. Therefore,

Var[3X−5]=32⋅Var[X]=3⋅Var[X].

We can compute the variance of X using the following formula:

Var[X]=E[X2]−E[X]2

Additionally, we're given that E[X]=2.

We start by computing E[X2]. Summing up the products of each value of X2 and its associated probability, we get

E[X2]=02⋅f(0)+22⋅f(2)+42⋅f(4)=4⋅13+16⋅13=203.

Therefore,

Var[X]=E[X2]−E[X]2=203−22=83.

Finally,

Var[3X−5]=3⋅Var[X]=3⋅83=8.
