EXPLANATION

We can compute the variance of a discrete random variable X using the following formula:

Var[X]=E[X2]−E[X]2

First, we compute E[X]. Summing up the products of each value of X and its associated probability, we get

E[X]=(−2)⋅f(−2)+(−1)⋅f(−1)+0⋅f(0)+1⋅f(1)+2⋅f(2)=(−2)(18)+(−1)(14)+0(38)+1(116)+2(316)=−116.

Next, we compute E[X2]. Summing up the products of each value of X2 and its associated probability, we get

E[X2]=(−2)2⋅f(−2)+(−1)2⋅f(−1)+02⋅f(0)+12⋅f(1)+22⋅f(2)=4(18)+1(14)+0(38)+1(116)+4(316)=2516.

Therefore,

Var[X]=E[X2]−E[X]2=2516−(−116)2=2516−1256=400256−1256=399256.
