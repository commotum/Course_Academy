EXPLANATION

The standard deviation of a random variable X is defined as

SD[X]=Var[X],

where the variance can be computed using the following formula:

Var[X]=E[X2]−E[X]2

First, we need to compute E[X]. Summing up the products of each value of X and its associated probability, we get

E[X]=0⋅f(0)+1⋅f(1)+2⋅f(2)+3⋅f(3)=0(14)+1(38)+2(14)+3(18)=54.

Next, we compute E[X2]. Summing up the products of each value of X2 and its associated probability, we get

E[X2]=02⋅f(0)+12⋅f(1)+22⋅f(2)+32⋅f(3)=0(14)+1(38)+4(14)+9(18)=52.

So, the variance is given by

Var[X]=E[X2]−E[X]2=52−(54)2=52−2516=1516.

Finally,

SD[X]=Var[X]=1516=154.
