EXPLANATION

Suppose the sequence an is defined for n≥1. To determine whether an is increasing or decreasing, we can use the following test:

  • If a sequence an is increasing, then for all n≥1, we have an+1≥an⟹an+1−an≥0.

  • If a sequence an is decreasing, then for all n≥1, we have an+1≤an⟹an+1−an≤0.

  • If neither of these conditions holds, the sequence is neither increasing nor decreasing.

With that in mind, let's analyze each statement.

  • Statement I is false. Computing the difference an+1−an, we get an+1−an=(n+1)2−5−(n2−5)=(n+1)2−5−n2+5=n2+2n+1−n2=2n+1 which is positive for n≥1.

    To see this concretely, set bn=2n+1. Computing the first few terms of bn we get 3,5,7,9,….

  • Statement II is true, whereas statement III is false. Since an+1−an≥0 for all n≥1, we can conclude that an is an increasing sequence.

Therefore, the correct answer is "II only."
