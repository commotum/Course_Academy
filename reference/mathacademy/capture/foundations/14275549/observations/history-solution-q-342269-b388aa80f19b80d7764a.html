To solve the initial value problem, we need to compute the inverse Laplace transform of Y(s).

To find the inverse transform, we first ignore the exponential term e−πs (which corresponds to a time shift) and focus on the rational function part: F(s)=1(s2+1)(s+1)

We'll solve this in three steps.

Step 1. Partial fraction decomposition

Since the denominator contains a linear factor (s+1) and an irreducible quadratic factor (s2+1), the decomposition takes the form 1(s2+1)(s+1)=As+1+Bs+Cs2+1. To find the constants, we clear the denominators: 1=A(s2+1)+(Bs+C)(s+1) Now, we find the constants A,B, and C.

  • Setting s=−1, we have 1=A((−1)2+1)+0⟹2A=1⟹A=12.
  • Comparing the coefficients of s2, we have 0=A+B⟹B=−A=−12.
  • Comparing the constant terms, we have 1=A+C⟹C=1−12=12.

Thus, we can rewrite F(s) as F(s)=12(1s+1+−s+1s2+1)=12(1s+1−ss2+1+1s2+1).

Step 2. Finding the Inverse of the base function

We find the inverse transform f(t)=L−1{F(s)} using standard transforms: f(t)=12(L−1{1s+1}−L−1{ss2+1}+L−1{1s2+1})=12(e−t−cos⁡t+sin⁡t)

Step 3. Applying the time-shifting property

Finally, we address the e−πs term in Y(s). By the second shifting theorem, we have e−as⋅F(s)=L{u(t−a)⋅f(t−a)}.

Taking the inverse Laplace transform gives L−1{e−asF(s)}=u(t−a)⋅f(t−a). In our case, a=π. Therefore, we shift f(t) by replacing every instance of t with (t−π):

y(t)=u(t−π)f(t−π)=u(t−π)⋅12[e−(t−π)−cos⁡(t−π)+sin⁡(t−π)]

Using the trigonometric identities cos⁡(t−π)=−cos⁡t and sin⁡(t−π)=−sin⁡t, we simplify the expression inside the brackets: y(t)=12u(t−π)[e−(t−π)−(−cos⁡t)+(−sin⁡t)]=12u(t−π)(e−(t−π)+cos⁡t−sin⁡t)

Comparing this to the form given in the problem statement y(t)=12u(t−π)⋅g(t), we identify g(t) as g(t)=e−(t−π)+cos⁡t−sin⁡t.
