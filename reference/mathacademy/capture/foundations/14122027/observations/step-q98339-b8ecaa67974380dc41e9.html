Which of the curves above is simple, closed, and negatively oriented?

a
II and IV only
b
I and III only
c
I, II, and III only
d
II, III, and IV only
e
III and IV only
Submit
Correct
EXPLANATION

A simple closed curve is positively oriented if, when traveling along it, one always has the curve interior to the left and the curve exterior to the right. Otherwise, the curve is negatively oriented.

A curve is positively oriented if it is traversed counterclockwise and is negatively oriented if it is traversed clockwise.

With that in mind, let's examine each of the curves:

  • Curve I is neither simple nor closed.

  • Curve II is a simple and closed curve but it is not negatively oriented. The arrows indicate that the curve is traversed counterclockwise, so it is positively oriented.

  • Curve III is simple, closed, negatively oriented. The arrows indicate that the curve is traversed clockwise.

  • Curve IV is simple, closed, negatively oriented. The arrows indicate that the curve is traversed clockwise.

Therefore, the correct answer is "III and IV only."
