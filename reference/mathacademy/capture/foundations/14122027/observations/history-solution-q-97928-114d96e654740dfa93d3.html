A simple closed curve is positively oriented if, when traveling along it, one always has the curve interior to the left and the curve exterior to the right. Otherwise, the curve is negatively oriented.

A curve is positively oriented if it is traversed counterclockwise and is negatively oriented if it is traversed clockwise.

With that in mind, let's examine each of the curves:

  • Curve I is negatively oriented. The arrows indicate that the curve is traversed clockwise.

  • Curve II is not negatively oriented. The arrows indicate that the curve is traversed counterclockwise, so it is positively oriented.

  • Curve III is not negatively oriented. The arrows indicate that the curve is traversed counterclockwise, so it is positively oriented.

  • Curve IV is negatively oriented. The arrows indicate that the curve is traversed clockwise.

Therefore, the correct answer is "I and IV only."
