Let T:R3→R3 be a linear transformation whose standard matrix is T. Which of the following statements are true?

  1. If Im(T)={[x,y,z]T:x=0} then nullity(T)=1
  2. If Ker(T)={[x,y,z]T:y−2z=0,x+z=0} then rank(T)=2
  3. If v1, v2, and v3 are the columns of T and v3=v1−v2, then Ker(T)≠{0}
a
III only
b
II only
c
I, II, and III
d
I and II only
e
I and III only
Submit
Incorrect
EXPLANATION

Since T is a linear transformation from R3 into R3, the invertible matrix theorem states the following:

T is a bijection (an invertible transformation) ⟺{Im(T)=R3rank(T)=3Ker(T)={0}nullity(T)=0

Also, according to the rank-nullity theorem, rank(T)+nullity(T)=3.

With that in mind, let's examine each statement in turn.

  • Statement I is true. Any vector from Im(T) can be written as [xyz]=[0yz]=y[010]⏟v1+z[001]⏟v2. This means that Im(T)=Span{v1,v2}. Therefore, rank(T)=2. Finally, according the rank-nullity theorem, we obtain nullity(T)=3−rank(T)=3−2=1.

  • Statement II is true. Solving y−2z=0 for y, we get y=2z. Solving x+z=0 for x, we get x=−z. Therefore, any vector from Im(T) can be written as [xyz]=[−z2zz]=z[−121]⏟v1. This means that Ker(T)=Span{v1}. Therefore, nullity(T)=1. Finally, according the rank-nullity theorem, we obtain rank(T)=3−nullity(T)=3−1=2.

  • Statement III is true. If the columns of T are such that v3=v1−v2, then the set of vectors {v1,v2,v3} is linearly dependent and therefore Im(T)=Col(T)≠R3. Now, according to the matrix invertible theorem, we obtain that Ker(T)≠{0}.

Therefore, the correct answer is "I, II, and III."
