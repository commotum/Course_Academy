Given that A=QR is a QR factorization of a m×n matrix A with linearly independent columns, which of the following statements are true?

  1. Q is an n×m matrix
  2. Col(A) is spanned by the columns of Q
  3. R is a m×m matrix
a
I only
b
II and III only
c
II only
d
I and II only
e
III only
Submit
Correct
EXPLANATION

Recall that if A=QR is a QR factorization of an m×n matrix A, then

Am×n=Qm×n×Rn×n,

where

  • Q is an m×n matrix whose columns form an orthonormal basis of Col(A)

  • R is an n×n upper triangular matrix

With that in mind, let's examine our statements.

  • Statement I is false. Q should be an m×n matrix.

  • Statement II is true. Indeed, since the columns of Q form an orthonormal basis of Col(A), they span Col(A).

  • Statement III is false. R must be an n×n matrix.

Therefore, the correct answer is "II only."
