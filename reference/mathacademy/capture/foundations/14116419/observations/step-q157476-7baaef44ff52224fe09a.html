EXPLANATION

Recall the following two facts about subspaces:

  • A set of vectors in a vector space is a subspace if it is closed under vector addition and scalar multiplication.

  • If a non-empty set is closed under scalar multiplication, then this set must contain the zero-vector (because 0⋅v=0 for any vector v). So, if a set does not contain the zero vector, then this set is not closed under scalar multiplication.

Notice that Π contains vectors of the form

[xyz]=[3+2y−2zyz],y,z∈R.

With that in mind, let's examine our statements.

  • Statement I is false. The line does not pass through the origin since x−2y+2z=3(0)−2(0)+2(0)=30=3×

  • Statement II is false. Let's consider a=[300]∈Π and b=[101]∈Π. Then a+b=[300]+[101]=[3+10+00+1]=[401], However, [401] does not belong to Π since x−2y+2z=3(4)−2(0)+2(1)=36=3×

  • Statement III is false. Since 0∉Π, this set is not closed under scalar multiplication.

  • Statement IV is false. Since statements II and III are false, L is not a subspace of R3.

Therefore, the correct answer is "None of the statements are true."
