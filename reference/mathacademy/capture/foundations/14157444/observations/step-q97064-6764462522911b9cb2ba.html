Let [T]B and [T]C be the matrices of a linear transformation T relative to the bases B and C, respectively. If PC→B is the change-of-coordinates matrix from basis C to basis B, which of the following statements are true?

  1. [T]C=PC→B−1⋅[T]B⋅PC→B
  2. [T]B=PB→C⋅[T]C⋅PB→C−1
  3. [T]B=PC→B⋅[T]C⋅PC→B−1
a
I only
b
III only
c
II only
d
I and II only
e
I and III only

Incorrect
EXPLANATION

The connection between the matrices of our linear transformation T relative to the bases B and C is given by the following diagram:

Here, moving along an arrow means pre-multiplying by the corresponding matrix. Algebraically, we can write this as

[T]C=PC→B−1⋅[T]B⋅PC→B,

where PC→B is the change-of-coordinates matrix from C to B.

Solving this equation for [T]B, we obtain the alternative formulation

[T]B=PC→B⋅[T]C⋅PC→B−1.

Therefore, the correct answer is "I and III only."
