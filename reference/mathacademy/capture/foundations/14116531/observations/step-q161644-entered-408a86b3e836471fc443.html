Which of the following sets are neither open nor closed?

  1. {(x,y)∈R2: 2x+y<6,0<x<3}
  2. {(x,y)∈R2: 1≤x<3,2<y≤4}
  3. {(x,y)∈R2: 2x2+3y2<6}
a
I only
b
I and II only
c
I and III only
d
II only
e
II and III only
Submit
Correct
EXPLANATION

Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Let's examine our sets in turn.

  • The first set is open since it doesn't contain any point of its boundary (all the corresponding inequalities are strict).

  • The second set is neither open nor closed. It contains some of its boundary points, for example, the point (1,4). On the other hand, it does not contain some other boundary points, for example, the point (3,2).

  • The third set is open since it doesn't contain any point of its boundary (the corresponding inequality is strict).

Therefore, the correct answer is "II only."
