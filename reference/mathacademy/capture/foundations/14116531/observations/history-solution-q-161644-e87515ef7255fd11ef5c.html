Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Let's examine our sets in turn.

  • The first set is closed since it contains all of its boundary points (all the corresponding inequalities are not strict).

  • The second set is open since it doesn't contain any of its boundary points (all the corresponding inequalities are strict).

  • The third set is closed since it contains all of its boundary points (all the corresponding inequalities are not strict).
