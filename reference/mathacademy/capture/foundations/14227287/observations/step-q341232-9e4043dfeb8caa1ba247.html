Let F(x)=sin⁡(2x) for x∈R. Suppose f(x) is the π2-periodic extension of F(x) from x∈[0,π2) to x∈R. Which of the following statements are true?

  1. f(x+π2)=f(x) for all x∈R
  2. f(x)=F(x) for all x∈R
  3. f(x+π2)=f(x−π2) for all x∈R
a
I, II, and III
b
I only
c
I and III only
d
II only
e
III only

Correct
EXPLANATION

Since f is the π/2-periodic extension of F, we have

  • f(x+π2)=f(x) for all x∈R, and

  • f(x)=F(x) for all x∈[0,π2).

With that in mind, we examine each statement in turn.

  • Statement I is true. This is exactly the definition of π2-periodicity: f(x+π2)=f(x) for all x∈R.

  • Statement II is false. For example, take x=3π4. Using the periodicity of f(x): f(3π4)=f(π4+π2)=f(π4)=F(π4)=sin⁡(2⋅π4)=1, while F(3π4)=sin⁡(2⋅3π4)=sin⁡(3π2)=−1. Hence, f(x)≠F(x) for x=3π4.

  • Statement III is true. Since f is π2-periodic, any shift by a multiple of its period returns the same value: f(x+π2)=f(x)andf(x−π2)=f((x−π2)+π2)=f(x). Since both sides equal f(x), the statement is true for all x∈R.

Therefore, the correct answer is "I and III only".
