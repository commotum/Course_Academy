Consider the scalar field f(x,y)=y2arctan⁡x. Which of the following statements are true?

  1. ∇f is conservative
  2. ∫C∇f⋅dr=0 for any piecewise smooth path C∈R2
  3. ∮C∇f⋅dr=0 for any closed path C∈R2
a
II only
b
I and III only
c
I only
d
III only
e
II and III only
Submit
Correct
EXPLANATION

If F is a conservative vector field on R2, then the circulation Γ=0 for any closed path C∈R2, that is Γ=∮CF⋅dr=0.

With that in mind, let's consider each statement in turn:

  • Statement I is true. The vector field ∇f is conservative by definition.

  • Statement II is false, while statement III is true. The result Γ=0 applies to closed curves only.

Therefore, the correct answer is "I and III only."
