Find y(t) given that the Laplace transform of the initial value problem y″−4y=4,y(0)=1,y′(0)=4

is given by

s2Y(s)−s−4−4Y(s)=4s.

The solution is y(t)=
2e2t−1

Correct
EXPLANATION

Using the transformed equation, we can solve for Y(s) as follows:

s2Y(s)−s−4−4Y(s)=4s(s2−4)Y(s)=4s+s+4(s2−4)Y(s)=s2+4s+4s(s−2)(s+2)Y(s)=(s+2)2sY(s)=s+2s(s−2)Y(s)=2s−2−1s

which is valid for s>2.

Now, taking the inverse Laplace transform, we get L−1(Y(s))=L−1{2s−2−1s}y(t)=2L−1{1s−2}−L−1{1s}y(t)=2e2t−1.
