Which of the following relations are reflexive?

  • xRy if and only if x≡2y(mod7), defined on Z

  • xSy if and only if x≡y(mod9), defined on Z

  • xTy if and only if y≡x+2(mod6), defined on Z

a
R and S only
b
T only
c
S only
d
S and T only
e
R and T only
Submit
Incorrect
EXPLANATION

A binary relation R, defined on a set A, is

  • reflexive if (x,x)∈R for all x∈A,

  • irreflexive if (x,x)∉R for all x∈A.

If some pairs of the form (x,x) belong to a relation and others do not, then the relation is neither reflexive nor irreflexive.

With that in mind, let's examine our relations.

  • Relation R is neither reflexive nor irreflexive. Notice that

    • (1,1)∉R since 1≢2(1)(mod7), while

    • (7,7)∈R since 7≡2(7)(mod7).

  • Relation S is reflexive. Indeed, (x,x)∈S for all x∈Z. Notice that x≡x(mod9) for any x∈Z.
  • Relation T is irreflexive. Indeed, (x,x)∉T for all x∈Z. Notice that x≢x+2(mod6) for any x∈Z.

Therefore, the correct answer is "S only."
