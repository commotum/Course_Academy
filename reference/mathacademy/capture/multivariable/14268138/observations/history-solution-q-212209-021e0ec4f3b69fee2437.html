A binary relation R, defined on a set A, is

  • reflexive if (x,x)∈R for all x∈A,

  • irreflexive if (x,x)∉R for all x∈A.

If some pairs of the form (x,x) belong to a relation and others do not, then the relation is neither reflexive nor irreflexive.

With that in mind, let's examine our relations.

  • Relation R is reflexive. Indeed, (x,x)∈R for all x∈Q. Notice that x−x=0≥−1 for any x∈Q.

  • Relation S is neither reflexive nor irreflexive. Notice that

    • (1,1)∉S since 1⋅1=1≰0, while

    • (0,0)∈S since 0⋅0=0≤0.

  • Relation T is irreflexive. Indeed, (x,x)∉T for all x∈R. Notice that x≯x for any x∈R.

Therefore, the correct answer is "T only."
