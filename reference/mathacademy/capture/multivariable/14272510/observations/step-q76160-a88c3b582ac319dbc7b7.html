Which of the following statements are true?

  2. R is symmetric
  3. R is transitive
  4. R is an equivalence relation

EXPLANATION

Given a relation R on a set A:

  • R is reflexive if and only if for all x∈A, xRx.

  • R is symmetric if and only if for all x,y∈A, if xRy, then yRx.

  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

Let's consider each of the properties in turn.

  • The relation R is not reflexive because (1,1)∉R.

  • The relation R is not symmetric because (1,2)∈R but (2,1)∉R.

  • The relation R is transitive because for all x,y,z∈{1,2,3}, if (x,y)∈R and (y,z)∈R, then (x,z)∈R. Recall that it's sufficient to check only the cases when both pairs have different components:

    • (1,2)∈R and (2,3)∈R, and also (1,3)∈R ✓

  • The relation is not an equivalence relation since it's neither reflexive nor symmetric.

Therefore, the correct answer is "III only".
