Which of the following are equivalence relations on P(N)?

  1. |A|=|B|
  2. A⊆B
  3. A⊂B
a
I only
b
I and II only
c
II and III only
d
II only
e
None
Submit
Correct
EXPLANATION

Given a relation R on a set A:

  • R is reflexive if and only if for all x∈A, xRx.

  • R is symmetric if and only if for all x,y∈A, if xRy, then yRx.

  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

With this in mind, let's consider each of the given relations.

  • The relation "=" for the cardinalities of sets is an equivalence relation since it's reflexive, symmetric, and transitive.

  • The relation "⊆" is not an equivalence relation. For example, it is not symmetric since {1}⊆{1,2} but {1,2}⊈{1}.

  • The relation "⊂" is not an equivalence relation. For example, it is not reflexive since N⊄N.

Therefore, the correct answer is "I only."
