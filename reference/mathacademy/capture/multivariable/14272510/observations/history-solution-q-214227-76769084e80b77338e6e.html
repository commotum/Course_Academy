Given a relation R on a set A:

  • R is reflexive if and only if for all x∈A, xRx.

  • R is symmetric if and only if for all x,y∈A, if xRy, then yRx.

  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

Let's consider each of the properties in turn.

  • It's true that the relation is reflexive. For all x∈Z, x≡x(mod 5).

  • It's true that the relation is symmetric. For all x,y∈Z, if x≡y(mod 5), then y≡x(mod 5).

  • It's true that the relation is transitive. For all x,y,z∈Z, if x≡y(mod 5) and y≡z(mod 5), then x≡z(mod 5).

  • It's true that this is an equivalence relation since it's reflexive, symmetric, and transitive.
