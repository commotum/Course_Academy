The function F(t)=f(t)⋅g(t) is differentiable over the common domain where both f(t) and g(t) are differentiable. A vector function is differentiable if and only if each component is differentiable.

Let's now find the intervals where each of the functions f(t) and g(t) are differentiable.

For the function f(t):

  • The first component ln⁡(2−t) is differentiable on (−∞,2).

  • The second and third components, cos⁡t and t3, are differentiable for all values of t.

So, the intersection of the domains of all three components of f(t) is (−∞,2).

For the function g(t):

  • The first and third components, t2−4 and sin⁡t, are differentiable for all values of t.

  • The second component t+5 is differentiable on (−5,∞), as its derivative is not defined at t=−5 and the function is not defined for t<−5.

Hence, the intersection of the domains of all three components of g(t) is (−5,∞).

Finally, the common domain of differentiability for f(t) and g(t) is (−∞,2)∩(−5,∞)=(−5,2).
