Find the contrapositive of the following statement:

If it is not raining, then you can go to the beach.

a
If it is raining, then you can't go to the beach.
b
If you can go to the beach, then it is not raining.
c
If it is raining, then you can go to the beach.
d
If you can't go to the beach, then it is raining.
e
If it is not raining, then you can't go to the beach.
Submit
Incorrect
EXPLANATION

In our conditional statement:

  • The antecedent is A: It is not raining.

  • The consequent is B: You can go to the beach.

The contrapositive of a conditional statement A⇒B is given by

¬B⇒¬A.

First, we write down the negations of A and B:

  • ¬A: It is raining.

  • ¬B: You can't go to the beach.

Therefore, the contrapositive is the following:

If you can't go to the beach, then it is raining.
