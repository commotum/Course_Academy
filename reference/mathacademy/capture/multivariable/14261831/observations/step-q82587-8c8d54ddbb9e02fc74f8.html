Find the inverse of the following statement:

If it's a sunny day, then you do not use an umbrella.

a
If it's a sunny day, then you do not use an umbrella.
b
If you use an umbrella, then it's a sunny day.
c
If it's a sunny day, then you use an umbrella.
d
If you use an umbrella, then it's not a sunny day.
e
If it's not a sunny day, then you use an umbrella.
Submit
Correct
EXPLANATION

In our conditional statement:

  • The antecedent is A: It's a sunny day.

  • The consequent is B: You do not use an umbrella.

The inverse of a conditional statement A⇒B is given by

¬A⇒¬B.

First, we write down the negations of A and B:

  • ¬A: It's not a sunny day.

  • ¬B: You use an umbrella.

Therefore, the inverse is the following:

If it's not a sunny day, then you use an umbrella.
