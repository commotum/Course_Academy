If F and G are vector fields and k is a constant, then we have the following linearity properties for divergence:

  • ∇⋅(kF)=k∇⋅F

  • ∇⋅(F+G)=∇⋅F+∇⋅G.

In our case, we have

∇⋅(−3F)=−3∇⋅F.

First, we need to calculate ∇⋅F. In doing so, we get ∇⋅F=∂∂x(2xcos⁡x)+∂∂y(2xysin⁡x)−∂∂z(4z)=2cos⁡x−2xsin⁡x+2xsin⁡x−4=2cos⁡x−4=2(cos⁡x−2)

Applying the linearity properties, we get

∇⋅(−3F)=−3∇⋅F=−3⋅2(cos⁡x−2)=6(2−cos⁡x).
