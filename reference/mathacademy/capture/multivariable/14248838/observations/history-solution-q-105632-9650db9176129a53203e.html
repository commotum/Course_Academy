If F and G are vector fields and k is a constant, then we have the following linearity properties for divergence:

  • ∇⋅(kF)=k∇⋅F

  • ∇⋅(F+G)=∇⋅F+∇⋅G.

In our case, we have

∇⋅(F−G)=∇⋅F+∇⋅(−G)=∇⋅F−∇⋅G.

First, we need to calculate ∇⋅F. In doing so, we get ∇⋅F=∂∂x(ln⁡(xy2))+∂∂y(−1y)=y2xy2+1y2=1x+1y2.

Applying the linearity properties, we get

∇⋅(F−G)=∇⋅F−∇⋅G=1x+1y2−1x=1y2.
