If F=Pi+Qj is a vector field with simply connected domain D⊆R2, then the following are equivalent:

  • F is a source-free vector field.

  • ∇⋅F=∂P∂x+∂Q∂y=0.

  • The flux ∮CF⋅nds along any closed curve C⊂D is zero.

  • Flux is path-independent. That is, given any two curves C1,C2⊂D with the same start and endpoints, we have that ∫C1F⋅nds=∫C2F⋅nds.

  • There exists a stream function ψ(x,y) for F.

Note that F(x,y)=xi−yj is a vector field with the simply connected domain D=R2, where P(x,y)=x and Q(x,y)=−y. Computing the partial derivatives, we have

∂P∂x=1,∂Q∂y=−1.

With that in mind, let's consider each statement.

  • Statement I is true. Indeed, we have that ∂P∂x+∂Q∂y=1+(−1)=0.

  • Statement II is true. This follows from statement I.

  • Statement III is false. Since F is source-free, the result ∫CF⋅nds=0 is guaranteed for closed curves only.

Therefore, the correct answer is "I and II only."
