EXPLANATION

A binary relation R defined on a set A is transitive if, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R. In other words, if the pairs (x,y) and (y,z) belong to a transitive relation, then the pair (x,z) should also be in the relation.

It's sufficient to check all the "linked" pairs of the form (x,y) with x≠y and (y,z) with y≠z:

  • Consider the pair (2,1) whose second component is 1. It can't be linked with any pair from R since none of them have a first component of 1.

  • Consider the pair (2,3) whose second component is 3. It can be linked with the following pairs from R whose first component is 3:

    • Linking (2,3) with (3,1) requires that (2,1)∈R, and this pair is in R. ✓

    • Linking (2,3) with (3,2) requires that (2,2)∈R. However, this pair is not in R. ×

We can stop checking since we have found a chain of pairs that do not satisfy the transitivity condition. Therefore, we can conclude the following:

Since (2,3)∈R and (3,2)∈R, but (2,2)∉R, the relation is not transitive.
