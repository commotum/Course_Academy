A binary relation R defined on a set A is transitive if, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R. In other words, if the pairs (x,y) and (y,z) belong to a transitive relation, then the pair (x,z) should also be in the relation.

It's sufficient to check all the "linked" pairs of the form (x,y) with x≠y and (y,z) with y≠z:

  • Consider the pair (1,2) whose second component is 2. It can be linked with the following pairs from R whose first component is 2:

    • Linking (1,2) with (2,3) requires that (1,3)∈R, and this pair is in R. ✓

    • Linking (1,2) with (2,4) requires that (1,4)∈R, and this pair is in R. ✓

  • Consider the pair (1,3) whose second component is 3. It can be linked with the following pair from R whose first component is 3:

    • Linking (1,3) with (3,4) requires that (1,4)∈R, and this pair is in R. ✓

  • Consider the pair (1,4) whose second component is 4. It can't be linked with any pair from R since none of them have a first component of 4.

  • Consider the pair (2,3) whose second component is 3. It can be linked with the following pair from R whose first component is 3:

    • Linking (2,3) with (3,4) requires that (2,4)∈R, and this pair is in R. ✓

  • Consider the pairs (2,4) and (3,4) whose second component is 4. They can't be linked with any pair from R since none of them have a first component of 4.

So, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R.

Therefore, the relation is transitive.
