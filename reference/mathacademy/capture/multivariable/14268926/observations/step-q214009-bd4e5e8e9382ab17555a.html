Which of the following relations are transitive?

  • xRy if and only if x+y<0, defined on R

  • xSy if and only if x+y=2, defined on R

  • xTy if and only if x≡y+1(mod3), defined on Z

a
T only
b
R only
c
R and T only
d
None
e
S and T only
Submit
Incorrect
EXPLANATION

A binary relation R defined on a set A is transitive if, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R. In other words, if the pairs (x,y) and (y,z) belong to a transitive relation, then the pair (x,z) should also be in the relation.

It's sufficient to check all the "linked" pairs of the form (x,y) with x≠y and (y,z) with y≠z.

With that in mind, let's examine our relations.

  • Relation R is not transitive. Notice that

    • (−4,−6)∈R since −4+(−6)=−10<0, and

    • (−6,5)∈R since −6+5=−1<0, but

    • (−4,5)∉R since −4+5=1≮0.

  • Relation S is not transitive. Notice that

    • (−2,4)∈S since −2+4=2, and

    • (4,−2)∈S since 4+(−2)=2, but

    • (−2,−2)∉S since −2+(−2)=−4≠2.

  • Relation T is not transitive. Notice that

    • (0,2)∈T since 0≡2+1(mod3), and

    • (2,4)∈T since 2≡4+1(mod3), but

    • (0,4)∉T since 0≢4+1(mod3).

Therefore, the correct answer is "None."
