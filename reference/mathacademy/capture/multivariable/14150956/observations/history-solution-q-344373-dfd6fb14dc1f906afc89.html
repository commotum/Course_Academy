Let's apply the candidates test step by step.

Step 1: We find the critical points. Taking the derivative of f(x)=−x+4, we get

f′(x)=−1.

We can see that f′(x)<0 for all real values of x. So there is no solution for f′(x)=0.

So, the only critical points are the endpoints x=1,5 (since the derivative is not defined at the endpoints).

Step 2: We evaluate f(x) at the critical points.

f(1)=−(1)+4=3f(5)=−(5)+4=−1

Step 3: We compare all of the values found in step 2.

  • The greatest value is f(1)=3, so the global maximum is 3.

  • The smallest value is f(5)=−1, so the global minimum is −1.
