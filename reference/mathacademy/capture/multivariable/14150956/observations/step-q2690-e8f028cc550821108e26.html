For the function f(x)=x3+6x2+9x+3, on the closed interval −4≤x≤−2, which of the following statements are true?

  1. The global maximum value is 3
  2. The global minimum value is 1
  3. The global minimum value is −1
a
I only
b
III only
c
I and III only
d
II only
e
I and II only

Correct
EXPLANATION

Let's apply the candidates test step by step.

Step 1: We find the critical points. Taking the derivative of f(x)=x3+6x2+9x+3, we get f′(x)=3x2+12x+9=3(x2+4x+3)=3(x+1)(x+3), and solving f′(x)=0, we get 3(x+1)(x+3)=0⟹x=−3,−1.

Since x=−1 does not belong to the interval [−4,−2], the critical points are x=−3 and the endpoints x=−4,−2 (since the derivative is not defined at the endpoints).

Step 2: We evaluate f(x) at the critical points. f(−4)=(−4)3+6(−4)2+9(−4)+3=−1f(−3)=(−3)3+6(−3)2+9(−3)+3=3f(−2)=(−2)3+6(−2)2+9(−2)+3=1

Step 3: We compare all of the values found in step 2.

  • The greatest value is f(−3)=3, so the global maximum is 3.

  • The least value is f(−4)=−1, so the global minimum is −1.

Therefore, the correct answer is "I and III only."
