EXPLANATION

Let's apply the candidates test step by step.

Step 1: We find the critical points. Taking the derivative of f(x)=xx+5, we get

f′(x)=5(x+5)2.

We can see that f′(x)>0 for all real values of x. So there is no solution for f′(x)=0.

So, the only critical points are the endpoints x=0,4 (since the derivative is not defined at the endpoints).

Step 2: We evaluate f(x) at the critical points.

f(0)=0(0+5)=0f(4)=4(4+5)=49

Step 3: We compare all of the values found in step 2.

  • The greatest value is f(4)=49, so the global maximum is 49.

  • The smallest value is f(0)=0, so the global minimum is 0.
