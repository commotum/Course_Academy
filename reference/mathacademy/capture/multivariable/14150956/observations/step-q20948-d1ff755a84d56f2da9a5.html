EXPLANATION

Let's apply the candidates test step by step.

Step 1: We find the critical points. Taking the derivative of f(x)=1x, we get

f′(x)=−1x2.

We can see that f′(x)<0 for all real values of x. So there is no solution for f′(x)=0.

So, the only critical points are the endpoints x=12,2 (since the derivative is not defined at the endpoints).

Step 2: We evaluate f(x) at the critical points.

f(12)=1(12)=2f(2)=12.

Step 3: We compare all of the values found in step 2.

  • The greatest value is f(12)=2, so the global maximum is 2.

  • The smallest value is f(2)=12, so the global minimum is 12.
