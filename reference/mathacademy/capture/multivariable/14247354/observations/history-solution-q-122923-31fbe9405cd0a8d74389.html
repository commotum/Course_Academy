A partition P of a closed interval [a,b] is a finite sequence of real numbers taken from [a,b] such that

a=x0<x1<x2<…<xn=b.

We can express P using set notation as P={x0,x1,…,xn}.

With that in mind, let's consider each statement:

  • Statement I is a partition of [−2,6].

  • Statement II is not a partition of [−2,6] since it does not include the left endpoint a=−2.

  • Statement III is not a partition of [−2,6] since it does not include the right endpoint b=6.

Therefore, the correct answer is "I only."
