Consider the following predicates.

A(x): x≥2. B(x): −x≤−2.

Which of the following is equivalent to the biconditional predicate A(x)⇔B(x)?

  1. If x≥2 then −x≤−2, and if −x≤−2 then x≥2.
  2. x≥2 is equivalent to −x≤−2.
  3. If x≥2 then −x≤−2, or if −x≤−2 then x≥2.
a
I and III only
b
I and II only
c
II and III only
d
I only
e
II only
Submit
Correct
EXPLANATION

A biconditional expression P⇔Q≡(P⇒Q)∧(Q⇒P) can be read as shown below:

  • P if and only if Q

  • P is equivalent to Q

  • If P then Q, and if Q then P

So, A⇔B translates into the following sentences:

  • x≥2 if and only if −x≤−2.

  • x≥2 is equivalent to −x≤−2.

  • If x≥2 then −x≤−2, and if −x≤−2 then x≥2.

Therefore, the correct answer is "I and II only."
