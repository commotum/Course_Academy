First, recall the following definitions:

  • A binary relation R, defined on a set A, is symmetric if for all x,y∈A, we have (x,y)∈R⟹(y,x)∈R. In terms of a digraph, if we have an arrow x→y, then the arrow y→x must be in the digraph too.

  • A binary relation R, defined on a set A, is antisymmetric if for all x,y∈A, we have (x,y)∈Rand(y,x)∈R⟹x=y. So, only one of the arrows, either x→y or y→x, can be in the digraph of an antisymmetric relation. Note that this condition allows loops.

With that in mind, let's examine our digraphs.

  • Digraph I represents a relation that is both symmetric and antisymmetric. Notice that it has no pairs of the form (x,y) with x≠y. As a result, the propositions in both implications above are false. Hence, the implications themselves must be true.

  • Digraph II represents a symmetric relation since for every arrow x→y belonging to the graph, the corresponding inverse arrow y→x also belongs to the graph.

  • Digraph III represents an antisymmetric relation since for all possible x and y with x≠y, at most one of the arrows (either x→y or y→x, but not both) belongs to the digraph.

Therefore, the correct answer is "I only."
