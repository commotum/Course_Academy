Which of the following statements are true regarding the function f:[−1,5]→[−1,4] whose graph is shown above?

  1. The range of f is [−1,3]
  2. ∀y∈[−1,3], ∃x∈[−1,5] such that f(x)=y
  3. f is a surjection

EXPLANATION

A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. From the graph, the highest y-value is 3 and the lowest y-value is −1. The graph covers all y-values between −1 and 3, including these numbers, so the range of the function is [−1,3].

  • Statement II is true. Since the range of f is [−1,3] and [−1,3] is contained in that range, it follows that for all y contained within [−1,3], there exists some x contained within [−1,5] such that f(x)=y.

  • Statement III is false. As we can see from the range, there is no real number x such that f(x)=4. So, it's not true that for all y contained within [−1,4], there exists some x contained within [−1,5] such that f(x)=y. In conclusion, f is not a surjection of [−1,5] onto [−1,4].

Therefore, the correct answer is "I and II only."
