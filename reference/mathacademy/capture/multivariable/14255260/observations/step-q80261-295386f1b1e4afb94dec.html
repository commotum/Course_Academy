Which of the following statements are true regarding the function f:R→R which is given by f(x)=x3?

  1. The range of f is [0,∞)
  2. ∀y∈R, ∃x∈R such that f(x)=y
  3. f is onto
a
I only
b
III only
c
I and III only
d
I and II only
e
II and III only
Submit
Correct
EXPLANATION

First, we graph the function.

A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. The graph covers all y-values, so the range of the function is (−∞,∞).

  • Statement II is true. Since the range of the function is (−∞,∞), then for all y contained within R, there exists some x contained within R such that f(x)=y.

  • Statement III is true. Since statement II is true, f is a surjection of R onto R.

Therefore, the correct answer is "II and III only."
