Which of the following statements are true regarding the function f:[−3,1]→[−2,3] whose graph is shown above?

  1. The range of f is [−3,1]
  2. ∀y∈[−2,3], ∃x∈[−3,1] such that f(x)=y
  3. f is a surjection
a
II only
b
III only
c
II and III only
d
I and II only
e
I only
Submit
Correct
EXPLANATION

A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. From the graph, the highest y-value is 3 and the lowest y-value is −2. The graph covers all y-values between −2 and 3, including these numbers, so the range of the function is [−2,3].

  • Statement II is true. Since the range of f is [−2,3], it follows that for all y contained within [−2,3], there exists some x contained within [−3,1] such that f(x)=y.

  • Statement III is true. Since statement II is true, f is a surjection of [−3,1] onto [−2,3].

Therefore, the correct answer is "II and III only."
