EXPLANATION

A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. According to the diagram, we have f(4)=1 (we have an arrow from 4∈X to 1∈Y). So, there exists some x contained within X such that f(x)=1.

  • Statement II is false. Consider y=4. As we can see from the diagram, there are no elements contained within X that have an arrow to 4∈Y. So, it's not true that for all y contained within Y, there exists some x contained within X such that f(x)=y.

  • Statement III is true. Indeed, since statement II is false, f is not a surjection.

Therefore, the correct answer is "I and III only."
