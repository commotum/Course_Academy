A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. According to the diagram, we have f(4)=3 (we have an arrow from 4∈X to 3∈Y). So, there exists some x contained within X such that f(x)=3.

  • Statement II is true. As we can see from the diagram, for all y contained within Y, there exists some x contained within X such that f(x)=y.

  • Statement III is true. Since statement II is true, f is a surjection.

Therefore, the correct answer is "I, II, and III."
