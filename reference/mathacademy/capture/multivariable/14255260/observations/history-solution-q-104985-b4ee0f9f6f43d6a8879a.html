A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. As we can see from the graph, the highest y-value is 1 and the graph covers all y-values less than or equal to 1, so the range of the function is (−∞,1].

  • Statement II is true. Since the range of the function is (−∞,1], it follows that for all y contained within (−∞,1], there exists some x contained within (−∞,1] such that f(x)=y.

  • Statement III is true. Since statement II is true, f is a surjection of [0,∞) onto (−∞,1].

Therefore, the correct answer is "II and III only."
