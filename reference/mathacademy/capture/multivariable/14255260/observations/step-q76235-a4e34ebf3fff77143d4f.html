EXPLANATION

A function f:X→Y is a surjection (also known as onto) if, for every element y in Y, there is at least one element in X that maps to y.

Symbolically, we can write:

f:X→Y is a surjection if ∀y∈Y, ∃x∈X such that f(x)=y.

With this in mind, let's check each function.

  • I is not a surjection. There is no number x∈R such that f(x)=0. In fact, 2x>0 for all ∈R.

  • II is not a surjection. As a counterexample, choose 2∈Z. There is no number x∈Z such that g(x)=2. The only number x that satisfies g(x)=x3=2 is x=23∉Z.

  • III is a surjection. Given y∈Q, choose x=−y2∈Q. Then h(x)=h(−y2)=−2⋅(−y2)=y.

Therefore, the correct answer is "III only".
