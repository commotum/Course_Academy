The graph of the function z=f(x,y) is shown above. Which of the points shown are local minimum points?

a
A and B only
b
A only
c
C and D only
d
A, C, and D only
e
B only
Submit
Correct
EXPLANATION

A function f(x,y) has a local minimum point at (a,b) if f(x,y)≥f(a,b) for all points (x,y) in a neighborhood of (a,b).

In other words, we can take a neighborhood of (x,y)-values such that the point (x,y,f(x,y)) is the lowest point on the graph in the neighborhood.

Such neighborhood exists for the point B. Hence, B is a local minimum.
