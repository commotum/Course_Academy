The graph of the function z=f(x,y) is shown above. Which of the points shown are local maximum points?

a
The function does not have local maximum
b
D only
c
B only
d
A and C only
e
B and D only
Submit
Correct
EXPLANATION

A function f(x,y) has a local maximum point at (a,b) if f(x,y)≤f(a,b) for all points (x,y) in a neighborhood of (a,b).

In other words, we can take a neighborhood of (x,y)-values such that the point (x,y,f(x,y)) is the highest point on the graph in the neighborhood.

Such neighborhoods exist for the points B and D. Hence B and D are local maxima.
