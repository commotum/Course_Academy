Recall the following:

  • If an integer n is even, then there exists an integer p such that n=2p.

  • If an integer n is odd, then there exists an integer q such that n=2q+1.

In this case, we need to show the following:

n is odd⇒3n+1 is even

We start by using the fact that n is even.

Let n be an odd integer. Then, n=2a+1 for some integer a.

The idea is to substitute n=2a+1 into our expression 3n+1 and show it is even by writing it as a multiple of 2.

Substituting n=2a+1 into the expression 3n+1, we can show that 3n+1=2b, where b is an integer.

Once we've shown this, the proof is complete, and we can state our conclusion.

Therefore, since 3n+1 is a multiple of 2, we conclude that 3n+1 is even.
