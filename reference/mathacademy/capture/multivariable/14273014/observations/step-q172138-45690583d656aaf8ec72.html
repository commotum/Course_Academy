EXPLANATION

Let's denote:

  • P(x): x>3

  • Q(x): x2>9

Then, the given sentence has the following logical structure:

P(x)⇒Q(x)

This, in turn, is equivalent to

∀x∈U,P(x)⇒Q(x)

where the universal set U is usually apparent from the context. In this case, x∈R.

Therefore, using formal language, our statement reads

For all real x, if x>3, then x2>9.

Or, more formally:

∀x∈R,(x>3)⇒(x2>9)
