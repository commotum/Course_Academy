Which of the following are mathematical predicates?

  1. x<y
  2. n is a perfect square.
  3. Are n and m coprime?
a
I and III only
b
I, II, and III
c
I only
d
None
e
I and II only
Submit
Incorrect
EXPLANATION

A predicate of the variables x1,x2,…,xn is a sentence that contains the variables defined on some universal set, and has the property that when we substitute concrete values for all the variables into the predicate, the result becomes a statement that is either true or false.

With that in mind, let's examine our options.

  • Option I is a predicate of two variables. Substituting a concrete pair of values (x,y) into the sentence, we get a statement that is either true or false.

  • Option II is a predicate of one variable. Substituting a concrete value for n into the sentence, we get a statement that is either true or false.

  • Option III is not a predicate. Substituting a concrete pair of values (n,m) into the sentence, we do not get a statement that is either true or false.

Therefore, the correct answer is "I and II only."
