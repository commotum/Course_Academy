The truth set of a predicate P(x1,x2,…,xn) is the set of n-tuples in its universal set U=U1×U2×⋯×Un such that substituting these tuples for the variables makes the predicate a true statement:

T={(x1,x2,…,xn)∈U|P(x1,x2,…,xn)}

The universal set for our predicate is U={2,3}×{5,8}={(2,5),(2,8),(3,5),(3,8)}.

We need to find (a,b)∈U such that the following is true:

a+b is an odd number

The following pairs give the elements of our truth set:

  • (2,5) since 2+5=7 and 7 is an odd number,

  • (3,8) since 3+8=11 and 11 is an odd number.

Therefore, the truth set of our predicate is T={(2,5),(3,8)}.
