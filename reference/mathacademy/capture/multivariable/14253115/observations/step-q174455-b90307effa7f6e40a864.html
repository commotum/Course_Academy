P(x): x2≥−1

where the universal set is N.

EXPLANATION

The truth set of a predicate P(x) is the set of elements in its universal set U such that substituting these elements for the variable makes the predicate a true statement:

T={x∈U|P(x)}

The universal set for our predicate is U=N.

We need to find x∈U such that the following is true:

x2≥−1

We know that the square of any real number is greater than or equal to zero.

So, the inequality is true for every real number. In particular, it's true for every x∈N.

Therefore, the truth set of our predicate is T=N.
