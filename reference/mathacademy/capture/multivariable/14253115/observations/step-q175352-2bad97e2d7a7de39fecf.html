Which of the following are mathematical predicates?

  1. q plus 3.
  2. 2 is greater than x.
  3. a is a divisor of b.
a
I and II only
b
I only
c
I and III only
d
II and III only
e
II only
Submit
Correct
EXPLANATION

A predicate of the variables x1,x2,…,xn is a sentence that contains the variables defined on some universal set, and has the property that when we substitute concrete values for all the variables into the predicate, the result becomes a statement that is either true or false.

With that in mind, let's examine our options.

  • Option I is not a predicate. Substituting a concrete value for q into the sentence, we do not get a statement that is either true or false.

  • Option II is a predicate of one variable. Substituting a concrete value for x into the sentence, we get a statement that is either true or false.

  • Option III is a predicate of two variables. Substituting a concrete pair of values (a,b) into the sentence, we get a statement that is either true or false.

Therefore, the correct answer is "II and III only."
