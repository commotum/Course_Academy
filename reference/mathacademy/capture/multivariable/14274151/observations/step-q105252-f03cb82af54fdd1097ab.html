Which of the following statements are true regarding the function f:R→R which is given by f(x)=(x−1)2−2?

  1. The range of f is [−2,∞)
  2. ∀y∈[−2,∞), ∃x∈R such that f(x)=y
  3. f maps R into R
a
I, II, and III
b
I only
c
II and III only
d
I and II only
e
II only
Submit
Correct
EXPLANATION

First, we graph the function.

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. From the graph, the lowest y-value is −2, and it occurs at the point (1,−2). The graph will cover all y-values greater than y=−2, including y=−2 itself. So the range of the function is [−2,∞).

  • Statement II is true. Since the range of the function is [−2,∞), then for all y contained within [−2,∞), there exists some x contained within R such that f(x)=y.

  • Statement III is true. As we can see from the range, there is no real number x such that f(x)=−3∈R. So, f maps R into R.

Therefore, the correct answer is "I, II, and III."
