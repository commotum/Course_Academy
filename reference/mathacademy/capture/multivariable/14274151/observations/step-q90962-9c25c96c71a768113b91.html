Which of the following functions are into functions?

  1. f:[0,∞)→[0,∞) defined by f(x)=x+4
  2. g:R→[0,∞) defined by g(x)=|x−1|+1
  3. h:(0,∞)→[0,∞) defined by h(x)=x
a
I and III only
b
I, II, and III
c
III only
d
II only
e
I only
Submit
Incorrect
EXPLANATION

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • I is an into function. Let's take y=1∈R. There is no number x∈[0,∞) such that f(x)=x+4=1. In fact, f(x)=x+4≥2 for all x∈[0,∞).

  • II is an into function. Let's take 0∈[0,∞). There is no number x∈R such that g(x)=|x−1|+1=0. In fact, |x−1|+1≥1 for all x∈R.

  • III is an into function. Let's take 0∈[0,∞). There is no number x∈(0,∞) such that h(x)=x=0. In fact, x>0 for all x∈(0,∞).

Therefore, the correct answer is "I, II, and III."
