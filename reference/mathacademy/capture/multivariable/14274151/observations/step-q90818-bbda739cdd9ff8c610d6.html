EXPLANATION

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is false.there is no arrow from 3∈X to 5∈Y. So, f(3)≠5.

  • Statement II is true. According to the diagram, 7∈Y has no preimage in X because we have no arrows from X to 7∈Y. As a result, there exists some y (i.e., y=7) contained within Y such that f(x)≠y for any x in X.

  • Statement III is true. Since statement II is true, f is an into function.

Therefore, the correct answer is "II and III only."
