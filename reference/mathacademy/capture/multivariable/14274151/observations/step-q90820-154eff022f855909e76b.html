EXPLANATION

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. Indeed, there is an arrow from 1∈X to 4∈Y. So, f(1)=4.

  • Statement II is false. According to the diagram, for every element y∈Y, we have an arrow from some element x∈X to it, which means that f(x)=y.

  • Statement III is false. Since statement II is false, f is not an into function.

Therefore, the correct answer is "I only."
