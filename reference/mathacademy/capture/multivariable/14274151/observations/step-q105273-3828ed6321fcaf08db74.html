Which of the following functions are into functions?

  1. f:R→(0,∞) defined by f(x)=2x
  2. g:(0,∞)→R defined by g(x)=2−log2⁡x
  3. h:R→R defined by h(x)=(x−1)2−5
a
III only
b
I and II only
c
I only
d
II only
e
II and III only
Submit
Correct
EXPLANATION

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • I is a not an into function. Given y∈(0,∞), we can choose x=log2⁡y∈R. Then f(x)=f(log2⁡y)=2log2⁡y=y.

  • II is a not an into function. Given any y∈R, we can choose x=22−y∈R. Then g(x)=g(22−y)=2−log2⁡(22−y)=2−(2−y)=y.

  • III is an into function. Let's take −6∈R. There is no number x∈R such that h(x)=(x−1)2−5=−6. In fact, (x−1)2−5≥−5 for all x∈R.

Therefore, the correct answer is "III only."
