Which of the following functions are into functions?

  1. f:R→R defined by f(x)=3x
  2. g:R→[0,∞) defined by g(x)=x2
  3. h:R→[0,∞) defined by h(x)=2x
a
III only
b
II only
c
II and III only
d
I and III only
e
I and II only

Correct
EXPLANATION

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • I is an into function. Let's take −1∈R. There is no number x∈R such that f(x)=3x=−1. In fact, 3x>0 for all x∈R.

  • II is a not an into function. Given any y∈[0,∞), we can choose x=y∈R. Then g(x)=g(y)=(y)2=y.

  • III is an into function. Let's take 0∈[0,∞). There is no number x∈R such that h(x)=2x=0. In fact, 2x>0 for all x∈R.

Therefore, the correct answer is "I and III only."
