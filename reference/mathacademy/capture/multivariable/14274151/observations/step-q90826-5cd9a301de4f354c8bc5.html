Which of the following statements are true regarding the function f:R→R which is given by f(x)=x2+1?

  1. The range of f is (1,∞)
  2. ∀y∈[1,∞), ∃x∈R such that f(x)=y
  3. f maps R into R
a
I only
b
II and III only
c
III only
d
I and III only
e
II only
Submit
Incorrect
EXPLANATION

First, we graph the function.

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. From the graph, the lowest y-value is 1, and it occurs at the point (0,1). The graph will cover all y-values higher than y=1, including y=1 itself. So the range of the function is [1,∞).

  • Statement II is true. Since the range of the function is [1,∞), then for all y contained within [1,∞), there exists some x contained within R such that f(x)=y.

  • Statement III is true. As we can see from the range, there is no real number x such that f(x)=0∈R. So, f maps R into R.

Therefore, the correct answer is "II and III only."
