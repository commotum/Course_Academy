Given that (x,y)=(4,−1) is a solution of the Diophantine equation 3x+7y=5, which of the following gives the general solution to the equation?

Hint: Assume that t=0,±1,±2,….

a
(4−3t,−1+7t)
b
(4+7t,−1−3t)
c
(1+7t,−4−3t)
d
(−1+7t,4−3t)
e
(4+7t,1+3t)
Submit
Correct
EXPLANATION

First, recall that a linear Diophantine equation ax+by=c has a solution if and only if d|c, where d=gcd(a,b). Moreover, if (x0,y0) is a solution to the equation, then the general solution is given by (x0+bdt,y0−adt),t=0,±1,±2,…

Here, we have a=3, b=7, c=5, and

d=gcd(3,7)=1.

Since (4,−1) is a solution of 3x+7y=5, the general solution must be

(4+71t,−1−31t)=(4+7t,−1−3t),

where t=0,±1,±2,….
