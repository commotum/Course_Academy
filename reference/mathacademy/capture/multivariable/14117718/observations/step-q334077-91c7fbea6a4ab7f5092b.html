Consider the following initial value problem: y′=x2y,y(1)=1 Using the trapezoidal method with step size Δx=1, the new value ynew is obtained by solving the equation g(ynew)=0 at each step. Which of the following is the specific function g(ynew) used in the first step?

a
g(ynew)=ynew−2ynew−32
b
g(ynew)=ynew−2ynew−2
c
g(ynew)=ynew−ynew−32
d
g(ynew)=ynew−2ynew−1
e
g(ynew)=ynew−ynew−1
Submit
Correct
EXPLANATION

For an initial value problem y′=f(x,y),y(a)=c, the trapezoidal method with step size Δx is given by Δy=12(y′+ynew′)⋅Δx, with ynew′=f(xnew,ynew) evaluated at the next x and y values.

In this example, Δy is given by

Δy=12(y′+ynew′)⋅Δx=12(x2y+(xnew)2ynew)⋅1=12x2y+12(xnew)2ynew.

Substituting this into ynew=y+Δy, we have

ynew=y+Δyynew=y+12x2y+12(xnew)2ynew,

and moving all terms to the left-hand side gives the equation

ynew−12(xnew)2ynew−y−12x2y=0.

So, the general form of the function g for step size Δx=1 is

g(ynew)=ynew−12(xnew)2ynew−y−12x2y.

Now, in the first step, the new x value is

xnew=x+Δx=1+1=2. Therefore, the function used in the first step is

g(ynew)=ynew−12(2)2ynew−1−12(1)21=ynew−2ynew−32.
