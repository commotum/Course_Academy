  1. The function is an injection
  2. The function is a surjection
  3. The function is a bijection

Correct
EXPLANATION

Recall that a function f:X→Y is

  • an injection if ∀x1,x2∈X, whenever f(x1)=f(x2), we have x1=x2,

  • a surjection if ∀y∈Y, ∃x∈X such that f(x)=y,

  • a bijection if it is both a surjection and an injection.

With this in mind, let's check each statement.

  • Statement I is false. There are horizontal lines (like the one depicted below) that cross the graph of f(x) more than once. So, ∃x1,x2∈R such that x1≠x2 but f(x1)=f(x2).

  • Statement II is true. According to the graph, the range of f(x) will cover the entire interval (−∞,∞).

  • Statement III is false. Indeed, since statement I is false, f is not a bijection.

Therefore, the correct answer is "II only."
