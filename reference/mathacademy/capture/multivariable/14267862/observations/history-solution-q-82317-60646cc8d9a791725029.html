Recall that a function f:X→Y is

  • an injection if ∀x1,x2∈X, whenever f(x1)=f(x2), we have x1=x2,

  • a surjection if ∀y∈Y, ∃x∈X such that f(x)=y,

  • a bijection if it is both a surjection and an injection.

With this in mind, let's check each statement.

  • Statement I is false. For instance, f(0)=sin⁡(0)=0=sin⁡(2π)=f(2π), but 0≠2π. So, f(x) is not an injection.

  • Statement II is false. For example, there is no x∈R such that f(x)=2. So, f(x) is not a surjection.

  • Statement III is false because the function is not both an injection and a surjection.

Therefore, the correct answer is "None of the statements are true."
