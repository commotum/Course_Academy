Suppose we have the series ∑n=1∞an such that an≥0 for all n≥1, and that L is defined as

L=limn→∞ann=limn→∞(an)1/n.

Then, the root test states the following:

  • If L<1, the series converges.

  • If L>1 or L=∞, the series diverges.

  • If L=1, the root test is inconclusive.

We have the sequence an, defined as

an=nn/23nn2.

To apply the root test, we find the limit of ann as n→∞:

L=limn→∞ann=limn→∞(an)1/n=limn→∞(nn/23nn2)1/n=limn→∞n3n⋅nn=limn→∞13n⋅1nn−1/2=1⋅0=0 Note that we used the fact that

limn→∞13n=1.

Since L=0<1, the series converges by the root test.
