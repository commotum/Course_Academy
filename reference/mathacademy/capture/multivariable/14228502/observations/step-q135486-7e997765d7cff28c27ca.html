Which of the following are stochastic matrices?

U=[0.10.70.90.3],V=[0.450.350.250.65],W=[0−10100001]

a
U only
b
V only
c
U, V, and W only
d
U and W only
e
U and V only
Submit
Correct
EXPLANATION

Recall that a stochastic vector is a vector with nonnegative entries that add up to 1. A matrix is stochastic if all its columns are stochastic vectors.

With that in mind, let's examine our matrices in turn.

  • Matrix U is a stochastic matrix. Indeed, each column is a stochastic vector (the corresponding entries are nonnegative and add up to one): [0.10.70.90.3]0.1+0.9=10.7+0.3=1

  • Matrix V is not a stochastic matrix since its first column is not a stochastic vector (the corresponding entries don't add up to one): [0.450.350.250.65]

  • Matrix W not a stochastic matrix since its second column is not a stochastic vector (it contains negative entries): [0−10100001]

Therefore, the correct answer is "U only."
