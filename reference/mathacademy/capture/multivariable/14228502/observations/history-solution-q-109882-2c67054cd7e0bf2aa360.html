Recall that a stochastic vector is a vector with nonnegative entries that add up to 1. A matrix is stochastic if all its columns are stochastic vectors.

With that in mind, let's examine our matrices in turn.

  • Matrix U is not a stochastic matrix since its first column is not a stochastic vector (the corresponding entries don't add up to one): [0.200.51]

  • Matrix V is a stochastic matrix. Indeed, each column is a stochastic vector (the corresponding entries are nonnegative and add up to one): [0.450.250.550.75]0.45+0.55=10.25+0.75=1

  • Matrix W is not a stochastic matrix since its second column is not a stochastic vector (the corresponding entries don't add up to one): [0100.50.20.30.500.7]

Therefore, the correct answer is "V only."
