Explanation

First, we write

y(θ)=6(sin⁡θ)2.

Now, we see that y(θ) can be expressed as the composite function

y=6u2,u=sin⁡θ.

Differentiating, we get

dydu=12u,dudθ=cos⁡θ.

Finally, we apply the chain rule:

y′(θ)=dydu⋅dudθ=12u⋅cos⁡θ=12sin⁡θ⋅cos⁡θ=6sin⁡(2θ)
