If y=5arsinh⁡(3x), calculate dydx.

dydx=
15√9x2+1​
Submit
Correct
EXPLANATION

The formula for the derivative of the inverse hyperbolic sine function is ddx(arsinh⁡x)=1x2+1.

Using the formula above with the chain rule, we get

dydx=ddx(5arsinh⁡(3x))=5⋅ddx(arsinh⁡(3x))=5⋅1(3x)2+1⋅(3x)′=5⋅19x2+1⋅3=159x2+1.
