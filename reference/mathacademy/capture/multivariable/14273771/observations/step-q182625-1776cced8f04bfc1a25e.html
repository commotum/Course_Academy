To prove a statement using induction, we use the following framework:

  • Step 1: Base Case

  • Step 2: Inductive Hypothesis

  • Step 3: Inductive Step

  • Step 4: Conclusion

In this case, the general statement P(n) we're required to prove is the following:

∑i=0n3i=12(3n+1−1)

We start by proving the so-called base case, P(0). To do this, we substitute n=0 into both the left-hand side and right-hand side.

Base Case: We first prove that our statement is true for the base case n=0. ∑i=003i=12(30+1−1)

Proving that the base case is true is usually straightforward. We simply calculate the left-hand and right-hand sides independently and show they're equal.

Next, we write down our inductive hypothesis. We assume that P(k) is true for some n=k≥0. To do this, we simply replace n with k in our original statement P(n).

In our case, this gives the following:

Inductive Hypothesis: We assume that for some n=k≥0, we have ∑i=0k3i=12(3k+1−1).

Due to the base case, we already know that the statement is true for some value of k, namely k=0, so this assumption is valid.

Once we've shown that P(k)⇒P(k+1), the proof is complete, and we state our conclusion.
