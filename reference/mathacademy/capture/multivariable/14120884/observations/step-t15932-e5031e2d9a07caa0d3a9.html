Stability, Asymptotic Stability, and Instability
?

So far, we have learned how to find equilibrium points of a system However, just knowing where equilibrium points are is not enough: we also want to understand how nearby solutions behave when we start close to an equilibrium point.

Roughly speaking, there are three qualitatively different behaviors.

  • An equilibrium point is called stable if for any neighborhood of there exists a neighborhood such that every orbit that begins inside at some time remains inside for all

    In plain words, this means that solutions which start sufficiently close to the equilibrium remain close to it for all later times, although they need not converge to it.

  • An equilibrium point is called asymptotically stable if it is stable and there exists a neighborhood of such that every orbit that begins inside approaches as

    In plain words, this means that solutions which start sufficiently close to the equilibrium remain close to it and converge to it as

    Note that asymptotic stability is a stronger condition than stability: it adds the requirement that nearby solutions actually reach in the limit.

  • An equilibrium point is called unstable if it is not stable.

    In plain words, this means there is some neighborhood of from which trajectories can escape, even when started arbitrarily close to Note that this does not require trajectories to stay outside forever; it only requires them to leave at some moment, even if they return later.

Watch out! These descriptions are local: they describe what happens when the initial condition is sufficiently close to the equilibrium. They do not require that all trajectories in the entire plane behave the same way.
