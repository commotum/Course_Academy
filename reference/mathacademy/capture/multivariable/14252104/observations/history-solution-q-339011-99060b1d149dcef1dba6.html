First, we let

L=(1a+h−1a)h=−14.

Comparing this with the formula for the instantaneous rate of change,

f′(a)=limh→0f(a+h)−f(a)h,

we see that if we let f(x)=1x, we get

f′(a)=limh→0(1a+h−1a)h=L.

This confirms that L=f′(a).

Computing the derivative, we have

f′(x)=−1x2,f′(a)=−1a2,

and so, L=−1a2.

Finally, since L=−14, we must have
−1a2=−14a2=4a=±2.
