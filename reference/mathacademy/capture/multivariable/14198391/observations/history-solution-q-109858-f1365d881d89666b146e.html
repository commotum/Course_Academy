Recall that Col(AT+BT) is the row space of (AT+BT)T=A+B. This consists of all linear combinations of the rows of A+B.

If a vector is orthogonal to every linear combination of the rows of A+B, it must be orthogonal to each row of A+B. But notice that when pre-multiplying a vector by A+B, we actually multiply each row of A+B by that vector. So, Col(AT+BT) must be orthogonal to the null space of A+B, which is Null(A+B).

Therefore, the correct answer is "I only."
