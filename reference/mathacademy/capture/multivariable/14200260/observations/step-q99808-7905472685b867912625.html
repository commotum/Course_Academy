Consider the following set of functions: f1(t)=t2,f2(t)=t3,f3(t)=t

Given that the inner product in the vector space C[−1,1] of continuous functions over [−1,1] is defined as ⟨f(t),g(t)⟩=∫−11f(t)g(t)dt, which of the following statements are true?

  1. f1(t)⊥f2(t) with respect to the given inner product
  2. f2(t)⊥f3(t) with respect to the given inner product
  3. S={f1(t),f2(t),f3(t)} is an orthogonal set with respect to the given inner product
Hint: ⟨f1,f3⟩=0.

a
I and II only
b
None of the statements are true
c
I only
d
I, II, and III
e
II only
Submit
Incorrect
EXPLANATION

Recall that a set of vectors in an inner product space is called orthogonal if all vectors in the set are mutually orthogonal with respect to the given inner product.

With that in mind, let's examine our statements in turn.

  • Statement I is true. We have ⟨f1(t),f2(t)⟩=⟨t2,t3⟩=∫−11t2⋅t3dt=∫−11t5dt=t66|−11=166−(−1)66=0. This means that f1(t)⊥f2(t) with respect to the given inner product.

  • Statement II is false. We have ⟨f2(t),f3(t)⟩=⟨t3,t⟩=∫−11t3⋅tdt=∫−11t4dt=t55|−11=155−(−1)55=25≠0. This means that f2(t)⊥̸f3(t) with respect to the given inner product.

  • Statement III is false. Since f2(t)⊥̸f3(t), the set S is not orthogonal.

Therefore, the correct answer is "I only."
