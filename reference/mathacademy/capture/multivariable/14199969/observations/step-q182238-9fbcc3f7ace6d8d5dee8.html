Which of the following sets are finite?

  1. P({R,e})
  2. P({x∈R∣cos⁡x=0})
  3. P({(−1)n∣n∈Z})
a
 I and III only
b
 II and III only
c
 III only
d
 II only
e
 I only
Submit
Correct
EXPLANATION

The power set of a finite set is finite, while the power set of an infinite set is infinite.

With that in mind, let's examine our sets.

  • Set I is finite since the underlying set is finite. Notice that P({R,e})={∅,{R},{e},{R,e}} has cardinality 4.

  • Set II is infinite since the underlying set {x∈R∣cos⁡x=0} is infinite.

  • Set III is finite since the underlying set is finite. Notice that {(−1)n∣n∈Z}={−1,1}, and, as a result, P({(−1)n∣n∈Z})=P({−1,1})={∅,{−1},{1},{−1,1}} has cardinality 4.

Therefore, the correct answer is "I and III only."
