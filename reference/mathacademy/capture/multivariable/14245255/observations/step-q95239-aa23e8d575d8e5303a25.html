Which of the following vector spaces are finite-dimensional?

  1. R200
  2. R[t], the vector space of all polynomial functions in the variable t
  3. M200(R), the vector space of all 200×200 matrices over R
a
II and III only
b
I, II, and III
c
I and III only
d
I and II only
e
I only

Correct
EXPLANATION

Let's examine our vector spaces.

  • R[t] is not finite-dimensional. To understand why, we first note that the following set of (polynomial) functions is linearly independent: {1,t,t2,…,tn},n∈N. Indeed, we have that ∑i=0naiti=0 for all t∈R if and only if ai=0 for all i=0,1,2,…,n. Therefore, for any n∈N, there exists a linearly independent subset of R[t] of size n, which imples that R[t] cannot have finite dimension.

  • M200(R) and R200 are finite-dimensional. Indeed, dim(M200(R))=2002=40000, and dim(R200)=200 are both finite numbers.

Therefore, the correct answer is "I and III only."
