A function f:X→Y is a injection (also known as one-to-one) if every element in x in X is mapped to a distinct element in Y.

Symbolically, we can write:

f:X→Y is an injection if ∀x1,x2∈X, if f(x1)=f(x2), we have x1=x2.

  • I is not an injection. For example, g(1)=1=g(−1), but 1≠−1.

  • II is not an injection. For example, h(0)=1=h(2π), but 0≠2π.

  • III is an injection: f(x1)=f(x2)2x1=2x2log2⁡(2x1)=log2⁡(2x2)x1=x2

Therefore, the correct answer is "III only".
