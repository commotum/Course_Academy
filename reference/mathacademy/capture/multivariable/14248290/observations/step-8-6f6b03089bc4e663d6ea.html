The second partial derivative test states that if a∈R2 is a stationary point of f(x,y) with Hessian determinant H(a), we have the following:

  • If H(a)>0, then:

    • if ∂2f∂x2(a)<0, then f has a local maximum at a

    • if ∂2f∂x2(a)>0, then f has a local minimum at a

  • If H(a)<0, then f has a saddle point at a

  • If H(a)=0, then the second partial derivatives test is inconclusive.
