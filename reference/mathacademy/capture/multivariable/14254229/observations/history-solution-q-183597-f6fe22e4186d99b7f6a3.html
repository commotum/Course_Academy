First, notice that the statement

∃y∈Z,∀x∈Z,x+y=0

from option III reads as follows:

There exists a integer y such that, for every integer x, we have x+y=0.

With that in mind, let's examine our statements in turn.

  • Statement I is false since x+1=0 is not true for some integer x. Say, for x=1.

  • Statement II is true. The predicate P(y):∀x∈Z,x+y=0 is false for every value of y. For example, P(0):∀x∈Z,x=0 is false for any x≠0. In general, it's sufficient to take x≠−y for any y∈Z. Therefore, its truth set is empty.

  • Statement III is false. The sentence (∃y∈Z,∀x∈Z,x+y=0) can be written as ∃y∈Z(∀x∈Z,x+y=0⏟P(y)) which is true whenever the inner predicate P(y) has a nonempty truth set. And according to statement II, this is not the case.

Therefore, the correct answer is "II only."
