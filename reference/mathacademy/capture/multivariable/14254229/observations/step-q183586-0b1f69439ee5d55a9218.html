  1. ∀y∈R,2y∈R.
  2. The truth set of the predicate (∀y∈R,xy∈R) is R.
  3. ∀x,y∈R,xy∈R.

 I and III only

 I, II, and III

Correct
EXPLANATION

First, notice that the statement

∀x,y∈R,xy∈R

from option III reads as follows:

For all reals x and y, we have xy∈R.

With that in mind, let's examine our statements in turn.

  • Statement I is false since 2y∈R is not true for some real y. Say, for y=−1.

  • Statement II is false. For the predicate P(x):∀y∈R,xy∈R we note that P(x) is false for all values x∈R. For example, P(1):∀y∈R,y∈R is false, since we can take y=−1. Similarly, P(2):∀y∈R,2y∈R is false, since we can take y=−2. In general, it's sufficient to take y=−x for any value of x.

  • Statement III is false. The sentence (∀x,y∈R,xy∈R) can be written as ∀x∈R(∀y∈R,xy∈R⏟P(x)) which is true whenever the inner predicate P(x) is true over the universal set R. But, according to statement II, this is not the case.

Therefore, the correct answer is "None of the statements are true."
