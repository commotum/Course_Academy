Find the inverse of the following statement:

If it doesn't rain, then Robert goes for a walk.

a
If it doesn't rain, then Robert doesn't go for a walk.
b
If it doesn't rain, then Robert goes for a walk.
c
If Robert doesn't go for a walk, then it rains.
d
If it rains, then Robert doesn't go for a walk.
e
If Robert goes for a walk, then it doesn't rain.
Submit
Correct
EXPLANATION

In our conditional statement:

  • The antecedent is A: It doesn't rain.

  • The consequent is B: Robert goes for a walk.

The inverse of a conditional statement A⇒B is given by

¬A⇒¬B.

First, we write down the negations of A and B:

  • ¬A: It rains.

  • ¬B: Robert doesn't go for a walk.

Therefore, the inverse is the following:

If it rains, then Robert doesn't go for a walk.
