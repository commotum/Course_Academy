Find the converse of the following statement:

If π∈Z, then 7 is composite.

a
If π∉Z, then 7 is composite.
b
If 7 is composite, then π∈Z.
c
If 7 is composite, then π∉Z.
d
If 7 is not composite, then π∉Z.
e
If π∉Z, then 7 is not composite.
Submit
Incorrect
EXPLANATION

In our conditional statement:

  • The antecedent is A: π∈Z.

  • The consequent is B: 7 is composite.

The converse of a conditional statement A⇒B is given by

B⇒A.

Therefore, the converse is the following:

If 7 is composite, then π∈Z.
