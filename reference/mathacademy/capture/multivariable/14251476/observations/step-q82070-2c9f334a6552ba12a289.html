Which of the following statements are true?

  1. If 5 is a prime number, then 4 is a composite number.
  2. If 4 is a prime number, then 5 is a composite number.
  3. If 5 is a prime number, then 4 is a prime number.
a
I only
b
II only
c
None
d
I and II only
e
III only
Submit
Incorrect
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent "5 is a prime number" is true, and the consequent "4 is a composite number" is true. So the promise is kept, and the statement is true.

  • Statement II is true. The antecedent "4 is a prime number" is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement III is false. The antecedent "5 is a prime number" is true, and the consequent "4 is a prime number" is false. So the promise is broken, and the statement is false.

Therefore, the correct answer is "I and II only."
