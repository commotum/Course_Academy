Which of the following statements are true?

  1. If 8<10, then 2<3.
  2. If 8>10, then 2<3.
  3. If 8>10, then 2>3.
a
I only
b
I and II only
c
I and III only
d
II and III only
e
I, II, and III
Submit
Correct
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent 8<10 is true, and the consequent 2<3 is true. So the promise is kept, and the statement is true.

  • Statement II is true. The antecedent 8>10 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement III is true. Again, the antecedent 8>10 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

Therefore, the correct answer is "I, II, and III."
