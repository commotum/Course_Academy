Which of the following statements are true?

  1. If 2≤5, then 3≤1.
  2. If 5≤2, then 1≤3.
  3. If 1≤3, then 5≤2.
a
III only
b
II only
c
None
d
I only
e
I and III only
Submit
Incorrect
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is false. The antecedent 2≤5 is true, and the consequent 3≤1 is false. So the promise is broken, and the statement is false.

  • Statement II is true. The antecedent 5≤2 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement III is false. The antecedent 1≤3 is true, and the consequent 5≤2 is false. So the promise is broken, and the statement is false.

Therefore, the correct answer is "II only."
