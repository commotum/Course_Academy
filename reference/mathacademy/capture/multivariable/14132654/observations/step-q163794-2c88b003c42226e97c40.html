The graph z=f(x,y) is shown above. What are the global minimum points of the function?

a
 (−1,2,−2.5) and (1,0,−1)
b
 (−1,2,−2.5) only
c
 (−1,2,−2.5) and (−1,−2,2)
d
 (1,0,−1) and (2,−3,0)
e
 (1,0,−1) only
Submit
Incorrect
EXPLANATION

First, we recall the following definitions:

  • The global minimum of a function is the smallest value it attains on its domain. There can only be (at most) one global minimum.

  • A global minimum point is a point (x,y,z) where a function reaches a global minimum. There can be zero, one, or many global minimum points.

For our function, the minimum value reached by the function is f(x,y)=−2.5. Therefore, the global minimum is −2.5. The function reaches this value when (x,y)=(−1,2), so the global minimum point is (−1,2,−2.5).
