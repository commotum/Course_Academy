Let S be the set of all sequences. The given statement can be re-phrased as follows:

There exists s∈S such that s is geometric.

Introducing the existential quantifier, we get the following:

∃s∈S,s is geometric.

Negating this, we obtain ¬(∃s∈S,s is geometric)≡∀s∈S,¬(s is geometric)≡∀s∈S,s is not geometric

which reads

For all s∈S, s is not geometric.

or simply

Every sequence is not geometric.
