Negate the following statement:

For all t∈Q, t<1.

a
For all t∈Q, t≥1.
b
There exists t∈Q such that t<1.
c
For all t∈Q, t<1.
d
None of the listed
e
There exists t∈Q such that t≥1.
Submit
Incorrect
EXPLANATION

If we denote

P(t):t<1,

our statement can be written as

∀t∈Q,P(t).

Negating this, we obtain

¬(∀t∈Q,P(t))≡∃t∈Q,¬P(t).

Finally, ∃t∈Q,¬P(t) reads as follows:

There exists t∈Q such that t≥1.
