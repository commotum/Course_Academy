Negate the following statement:

Every universal statement is not true.

a
All universal statements are true.
b
All universal statements are not true.
c
Some universal statements are not true.
d
Some universal statements are true.
e
None of the listed.
Submit
Correct
EXPLANATION

Let U be the set of all universal statements. The given statement can be re-phrased as follows:

For all x∈U, x is not true.

Introducing the universal quantifier, we get the following:

∀x∈U,x is not true.

Negating this, we obtain ¬(∀x∈U,x is not true)≡∃x∈U,¬(x is not true)≡∃x∈U,x is true

which reads

There exists x∈U such that x is true.

or simply

Some universal statements are true.
