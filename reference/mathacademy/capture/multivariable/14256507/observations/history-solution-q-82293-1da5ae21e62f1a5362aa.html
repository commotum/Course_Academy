Recall that a function f:X→Y is

  • a surjection if ∀y∈Y, ∃x∈X such that f(x)=y,

  • an injection if ∀x1,x2∈X, whenever f(x1)=f(x2), we have x1=x2,

  • a bijection if it is both a surjection and an injection.

With that in mind, let's consider each statement in turn.

  • Statement I is false. Consider y=5. As we can see from the diagram, there are no elements contained within X that have an arrow to 5∈Y. So, it's not true that for all y contained within Y, there exists some x contained within X such that f(x)=y. As a result, f is not a surjection.

  • Statement II is true. As we can see from the diagram, there are no two distinct elements within X that map to the same element in Y. So, for all x1 and x2 contained within the domain X, if f(x1) and f(x2) are equal, then we must have x1=x2. As a result, f is an injection.

  • Statement III is false. Indeed, since statement I is false, f is not a bijection.

Therefore, the correct answer is "II only."
