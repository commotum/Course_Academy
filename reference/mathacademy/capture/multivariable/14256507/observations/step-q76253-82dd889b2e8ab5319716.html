EXPLANATION

Recall that a function f:X→Y is a bijection if it is both a surjection and an injection.

  • I is not a bijection because it is not injective. Indeed, notice that f(0)=0=f(π), but 0≠π.

  • II is not a bijection because it is not surjective. As a counterexample, choose y=π. Then there is no rational number x such that g(x)=π. Notice that the range of g consists only of rational numbers.

  • III is a bijection. First of all, it is a surjection because ∀y∈R, we can choose an x∈R such that h(x)=y: h(x)=yx3=yx=y3∈R Let's verify that: h(x)=h(y3)=y33=y Second, it is an injection: h(x1)=h(x2)x13=x23(x13)3=(x23)3x1=x2 Because h is both surjective and injective, h is bijective.

Therefore, the correct answer is "III only".
