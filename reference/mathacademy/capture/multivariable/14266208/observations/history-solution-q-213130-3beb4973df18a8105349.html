A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A2

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x≤y. For this relation, note that

  • the symbols R and ≤ are interchangeable, and

  • the symbols R and ≰ (or, equivalently R and >) are also interchangeable.

With that in mind, let's examine our statements in turn:

  • Statement I is true. Replacing R with the symbol ≤, we have 0≤2, which is true.

  • Statement II is true. Replacing R with the symbol ≤, we have 1≤1, which is true.

  • Statement III is true. Replacing R with the symbol >, we have 2>0, which is true.

Therefore, the correct answer is "I, II, and III."
