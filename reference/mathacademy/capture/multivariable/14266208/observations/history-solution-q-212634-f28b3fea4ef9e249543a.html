In this case, we have XRY if and only if X⊆Y. For this relation, note that

  • the symbols R and ⊆ are interchangeable, and

  • the symbols R and ⊈ are also interchangeable.

  • Statement I is true. Replacing R with the symbol ⊆, we have ∅⊆{1,2,3}, which is true.

  • Statement III is true. Replacing R with the symbol ⊈, we have {1,2,3}⊈{1,2}, which is true.
