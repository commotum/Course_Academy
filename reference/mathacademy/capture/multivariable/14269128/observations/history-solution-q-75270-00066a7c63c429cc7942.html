The normal line is vertical when the tangent to the curve is horizontal. Therefore, we require y′(t)=0 while x′(t)≠0.

So, we first find the derivatives of x and y: x′(t)=15e3t,y′(t)=12t

Solving y′(t)=0 gives 12t=0⟹t=0.

Now, we note that x′(0)=15e3⋅0=15≠0, which confirms that the normal to the curve is indeed vertical when t=0.
