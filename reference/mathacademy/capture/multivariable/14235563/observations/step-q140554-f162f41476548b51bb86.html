Which of the following equations define a non-empty set of points in the x1x2-plane?

  1. x12−x22=−1
  2. x12+2x2=0
  3. x12+x22=0
a
I and II only
b
I, II, and III
c
I and III only
d
II and III only
e
III only
Submit
Correct
EXPLANATION

Let's examine each of the equations in turn.

  • The equation x12−x22=−1 defines a non-empty set. It represents the hyperbola x22−x12=1.

  • The equation x12+2x2=0 defines a non-empty set. It represents a parabola that opens in the direction of the negative x2-axis in the x1x2-plane.

  • The equation x12+x22=0 defines a non-empty set. It represents a single point (0,0) in the x1x2-plane.

Therefore, the correct answer is "I, II, and III."
