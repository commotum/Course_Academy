∫03f(t)dt=∫02f(t)dt+∫23f(t)dt.

We can rearrange the above as follows:

∫23f(t)dt=∫03f(t)dt−∫02f(t)dt

Finally, using the given information, we get ∫23f(t)dt=∫03f(t)dt−(−∫20f(t)dt)=∫03f(t)dt+∫20f(t)dt=⟨9,9,−6⟩+⟨−4,−6,4⟩=⟨5,3,−2⟩.
