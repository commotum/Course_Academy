Let x, y, and z be the three numbers. We wish to maximize the function f(x,y,z)=xyz, subject to the constraint x+y+z=6.

Note that we also have the constraints x>0,y>0,z>0.

Let g(x,y,z)=x+y+z. Therefore, by the method of Lagrange multipliers, we must solve the following system: ∇f(x,y,z)=λ∇g(x,y,z),g(x,y,z)=6

We start by solving the first equation: ∇f(x,y,z)=λ∇g(x,y,z)⟨fx(x,y,z),fy(x,y,z),fz(x,y,z)⟩=λ⟨gx(x,y,z),gy(x,y,z),gz(x,y,z)⟩⟨yz,xz,xy⟩=λ⟨1,1,1⟩

From the first and second equations above, we have yz=xzyz−xz=0(y−x)z=0.

Since z>0, we can conclude that x=y.

Similarly, from the second and third equations, we get that z=y=x. So, using the constraint equation, we get x+y+z=6x+x+x=63x=6x=2.

Therefore, the maximum value of f is reached at the point (2,2,2), and the maximum value is f(2,2,2)=2(2)(2)=8. Note: It's easy to show that the obtained point is indeed the maximum (and not the minimum). To do that, we could compare the value of the function at this point with the value of the function at any other (arbitrary) point belonging to the domain. For example, f(1,2,3)=1⋅2⋅3=6<f(2,2,2).
