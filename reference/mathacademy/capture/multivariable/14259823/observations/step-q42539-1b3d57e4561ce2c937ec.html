Suppose that the following elementary row operations are applied to a 3×3 matrix A in the given order: R2:=R2−R1,R1↔R3 What is the equivalent notation in terms of matrix multiplication?

a
[001010100]⋅[1−10010001]⋅A
b
[001010100]⋅[100−110001]⋅A
c
[010100001]⋅[1−10010001]⋅A
d
[010001100]⋅[100−110001]⋅A
e
[001−110100]⋅[101010001]⋅A
Submit
Incorrect
EXPLANATION

First, let's find the elementary matrices corresponding to the two given elementary row operations.

  • The first operation is R2:=R2−R1. The corresponding elementary matrix can be found by applying this same elementary row operation to the identity matrix as follows: I=[100010001]R2:=R2−R1∼[100−110001]=E1

  • The second operation is R1↔R3. The corresponding elementary matrix can be found by applying this same elementary row operation to the identity matrix as follows: I=[100010001]R1↔R3∼[001010100]=E2

To apply the first elementary row operation to the matrix A, we multiply by E1 on the left and get E1A:

[100−110001]⋅A

Then, to apply the second elementary row operation to E1A, we multiply by E2 on the left and get E2E1A:

[001010100]⋅[100−110001]⋅A
