A numerical method yn+1=yn+Δyn is stable for a given step size Δx if, when applied to the test equation y′=−λy,y(0)=1,x≥0,λ>0, the numerical solution satisfies yn→0 as n→∞, just like the exact solution.

For stability, we require that the following condition holds:

|R(λΔx)|<1|1−λΔx|<1

Solving this gives 0<λΔx<2.

This means that Euler's method is stable when applied to the test equation for values in the region 0<λΔx<2. Of the given values:

  • For λΔx=1.2, falls within the given region,

  • For λΔx=2.4, falls outside the given region.

  • For λΔx=0.9, falls within the given region,

  • For λΔx=2.8, falls outside the given region.

Hence, Euler's method is unstable for the values λΔx=2.4, and λΔx=2.8.
