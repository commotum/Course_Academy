For which of the following values is Euler's method unstable, given that λ is the parameter of the test equation y′=−λy with y=y(x),y(0)=1,x≥0,λ>0, and step size Δx?

  1. λΔx=0.5
  2. λΔx=1.8
  3. λΔx=2.1
  4. λΔx=3
Hint: The stability function for Euler's method is given by R(λΔx)=1−λΔx.

a
I, II, III, and IV
b
III only
c
I and III only
d
III and IV only
e
IV only
Submit
Incorrect
EXPLANATION

A numerical method yn+1=yn+Δyn is stable for a given step size Δx if, when applied to the test equation y′=−λy,y(0)=1,x≥0,λ>0, the numerical solution satisfies yn→0 as n→∞, just like the exact solution.

For stability, we require that the following condition holds:

|R(λΔx)|<1|1−λΔx|<1

Solving this gives 0<λΔx<2.

This means that Euler's method is stable when applied to the test equation for values in the region 0<λΔx<2. Of the given values:

  • For λΔx=0.5, falls within the given region,

  • For λΔx=1.8, falls within the given region,

  • For λΔx=2.1, falls outside the given region.

  • For λΔx=3, falls outside the given region.

Hence, Euler's method is unstable for the values λΔx=2.1, and λΔx=3.

Therefore, the correct answer is "III and IV only".
