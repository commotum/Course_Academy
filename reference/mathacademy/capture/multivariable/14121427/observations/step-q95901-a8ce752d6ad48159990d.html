Given the singular value decomposition A=UΣVT, where A is a 3×4 matrix, which of the following statements are true?

  1. Σ is a 4×4 matrix
  2. V is an orthogonal 4×4 matrix
  3. U is a diagonal matrix
a
II only
b
I and III only
c
III only
d
I only
e
I and II only
Submit
Incorrect
EXPLANATION

Recall that if A=UΣVT is a singular value decomposition of an m×n matrix A, then

  • Σ is a m×n matrix with nonnegative elements on the main diagonal and zeroes outside the main diagonal,

  • U is an orthogonal m×m matrix,

  • V is an orthogonal n×n matrix.

With that in mind, let's examine our statements.

  • Statement I is false. Since A is a 3×4 matrix, Σ must be a 3×4 matrix.

  • Statement II is true. Indeed, since A is a 3×4 matrix,the matrix V in the singular value decomposition UΣVT must be orthogonal 4×4 matrix.

  • Statement III is false. The matrix U must be orthogonal but not necessarily diagonal.

Therefore, the correct answer is "II only."
