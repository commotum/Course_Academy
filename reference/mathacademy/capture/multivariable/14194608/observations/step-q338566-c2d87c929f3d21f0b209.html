Evaluate the following limit:
limx→∞(1+3x)2x=
e6

EXPLANATION

Notice that as x→∞,

  • the expression inside the parentheses approaches 1, while

  • the exponent approaches ∞.

So, if we attempt to evaluate the limit directly, we get

limx→∞(1+3x)2x=1∞, which is an indeterminate form.

Instead, let's recall the following special limit: limn→∞(1+1n)n=e

In the given limit, we let 3x=1n. Thus, we have 3x=1nx=3n.

Therefore, since n→∞ as x→∞, we rewrite the given limit using the algebra of limits, as follows:

limx→∞(1+3x)2x=limn→∞(1+1n)2(3n)=limn→∞[(1+1n)n]6=[limn→∞(1+1n)n]6=e6
