Consider the vector field F(x,y)=⟨ey,xey⟩ and the points A(1,0) and B(3,ln⁡3) in the xy-plane.

Which of the following statements are true?

  1. F is conservative.
  2. ∫C1F⋅dr=8, where C1 is the path along the curve y=ln⁡(x), traversed from A to B.
  3. ∫C2F⋅dr=3, where C2 is the path along the line segment AB―, traversed from A to B.

Correct
EXPLANATION

Let C be a piecewise-smooth curve given by the vector-valued function r(t) for t∈[a,b]. Let f be a differentiable function of two or three variables such that ∇f is continuous on C. The fundamental theorem for line integrals states that

∫C∇f⋅dr=f(r(b))−f(r(a)).

This theorem implies that the line integral of a conservative vector field depends only on the value of f at the initial and terminal points A and B, and is independent of the path between them.

With that in mind, we consider each statement in turn.

  • Statement I is true. Notice that F=Pi+Qj is a vector field on R2 with domain D=R2. Computing the partial derivatives, we get ∂P∂y=∂Q∂x=ey. Since the partial derivatives exist and are continuous and equal everywhere on R2, we conclude that F is conservative.

  • Statement II is true. Since F is conservative, there exists a function f such that ∇f=F. Reconstructing the function f from its gradient in the usual way, we get f=xey. Applying the fundamental theorem for line integrals, we get ∫C1F⋅dr=∫C1∇f⋅dr=f(3,ln⁡3)−f(1,0)=3⋅eln⁡3−1⋅e0=3⋅3−1=8.

  • Statement III is false. Since F is conservative and C2 has the same initial and terminal points as C2, we have ∫C2F⋅dr=∫C2F⋅dr=8.

Therefore, the correct answer is "I and II only."
