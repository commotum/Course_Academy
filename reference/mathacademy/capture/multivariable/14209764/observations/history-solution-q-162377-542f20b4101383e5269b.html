Let S be an oriented piecewise-smooth surface bounded by a simple, closed, piecewise-smooth boundary C with positive orientation. If a vector field F has continuous partial derivatives for all its components in an open region in space that contains S, then Stokes' theorem states that

∮CF⋅dr=∬ScurlF⋅dS.

Along the curve C, we have x=sin⁡(πt),y=cos⁡(πt),z=sin⁡(πt).

So,

F(r(t))=xi+yk=sin⁡(πt)i+cos⁡(πt)k.

Computing r′(t), we get

r′(t)=ddt(sin⁡(πt))i+ddt(cos⁡(πt))j+ddt(sin⁡(πt))k=πcos⁡(πt)i−πsin⁡(πt)j+πcos⁡(πt)k.

Therefore,

F(r(t))⋅r′(t)=(sin⁡(πt)i+cos⁡(πt)k)⋅(πcos⁡(πt)i−πsin⁡(πt)j+πcos⁡(πt)k)=sin⁡(πt)⋅πcos⁡(πt)−0⋅πsin⁡(πt)+cos⁡(πt)⋅πcos⁡(πt)=πsin⁡(πt)cos⁡(πt)+πcos2⁡(πt).

Finally, we evaluate the integral as follows:

∬ScurlF⋅dS=∮CF⋅dr=∫−11F(r(t))⋅r′(t)dt=∫−11(πsin⁡(πt)cos⁡(πt)+πcos2⁡(πt))dt=∫−11(πsin⁡(πt)cos⁡(πt)+π2(1+cos⁡(2πt)))dt=[sin2⁡(πt)2+πt2+sin⁡(2πt)4]−11=0+π2+0−(0−π2+0)=π
