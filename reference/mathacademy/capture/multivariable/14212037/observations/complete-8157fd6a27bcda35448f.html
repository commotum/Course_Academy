Correct
EXPLANATION

First, we need to find the critical values of the function in the region's interior. We compute the critical points by solving ∇f=0, as follows:

⟨fx(x,y),fy(x,y)⟩=⟨0,0⟩⟨1,1⟩=⟨0,0⟩

Since the above equation has no solutions, we conclude that the function does not have critical points in the region's interior.

Next, we need to find the minimum value of f(x,y) subject to the constraint g(x,y)=x2+y2=1.

Since f(x,y) is continuous and the constraint is closed and bounded, f(x,y) reaches a global maximum and a global minimum on the constraint.

Therefore, by the method of Lagrange multipliers, we must solve the following system:

∇f(x,y)=λ∇g(x,y)g(x,y)=1

We start by solving the first equation:

∇f(x,y)=λ∇g(x,y)⟨fx(x,y),fy(x,y)⟩=λ⟨gx(x,y),gy(x,y)⟩⟨1,1⟩=λ⟨2x,2y⟩

{1=2λx1=2λy⇒{x=12λy=12λ⇒x=y
