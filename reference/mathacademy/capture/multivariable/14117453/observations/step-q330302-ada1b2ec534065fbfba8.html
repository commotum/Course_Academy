Let x1(t) and x2(t) satisfy the homogeneous system x′(t)=A x(t) and xp(t) satisfy the inhomogeneous system x′(t)=A x(t)+f(t). Which of the following is always a solution of the same inhomogeneous system?

  1. x1(t)+xp(t)
  2. −3⋅x2(t)+xp(t)
  3. 7⋅x1(t)−5⋅x2(t)+xp(t)
a
I only
b
I, II and III
c
II only
d
I and III only
e
III only
Submit
Correct
EXPLANATION

Recall that if xh(t) satisfies a homogeneous linear system x′(t)=Ax(t) and xp(t) is a particular solution to an inhomogeneous linear system x′(t)=Ax(t)+f(t), then xh(t)+xp(t) is also a solution to the same inhomogeneous system.

Additonally, the linearity principle for systems of linear ordinary differential equations (ODEs) states that if x1(t), x2(t),…,xk(t) are solutions to a homogeneous linear system x′(t)=Ax(t), then any linear combination c1x1(t)+c2x2(t)+⋯+ckxk(t) with c1,c2,…,ck∈R is also a solution of the same homogeneous system.

With that in mind, let's examine the given expression.

  • Option I is a solution to the inhomogeneous system. Indeed, notice that the linear combination xh(t)=x1(t) is a solution to the homogeneous system x′(t)=Ax(t) according to the linearity principle. Thus, x1(t)⏟xh(t)+xp(t) is a solution to our inhomogeneous system x′(t)=Ax(t)+f(t).

  • Option II is a solution to the inhomogeneous system. Indeed, notice that the linear combination xh(t)=−3⋅x2(t) is a solution to the homogeneous system x′(t)=Ax(t) according to the linearity principle. Thus, −3⋅x2(t)⏟xh(t)+xp(t) is a solution to our inhomogeneous system x′(t)=Ax(t)+f(t).

  • Option III is a solution to the inhomogeneous system. Indeed, notice that the linear combination xh(t)=7⋅x1(t)−5⋅x2(t) is a solution to the homogeneous system x′(t)=Ax(t) according to the linearity principle. Thus, 7⋅x1(t)−5⋅x2(t)⏟xh(t)+xp(t) is a solution to our inhomogeneous system x′(t)=Ax(t)+f(t).

Therefore, the correct answer is "I, II and III".
