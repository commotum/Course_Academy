Suppose x1(t) and x2(t) are both solutions of the homogeneous system x′(t)=A x(t). Which of the following is always a solution of the same system?

  1. x(t)=x1(t)×x2(t)
  2. x(t)=sin⁡(t)⋅x2(t)
  3. x(t)=−3⋅x2(t)
a
None
b
III only
c
II and III only
d
II only
e
I only
Submit
Correct
EXPLANATION

The linearity principle for systems of linear ordinary differential equations (ODEs) states that if x1(t) and x2(t) are solutions to a homogeneous linear system, then for any constants c1 and c2, the linear combination c1x1(t)+c2x2(t) is also a solution of the system.

With that in mind, let's examine the given expressions.

  • Option I might be not a solution to the system since it's not a scalar multiple of any of the solutions x1(t) and x2(t).

  • Option II might be not a solution to the system since it's not a scalar multiple of any of the solutions x1(t) and x2(t). Notice that the multiplier is not a constant.

  • Option III is a solution to the system. Indeed, notice that −3⋅x2(t)
    is a linear combination of the solutions x1(t) and x2(t) with constant multiplies c1=0 and c2=−3, respectively.

Therefore, the correct answer is "I and III only".
