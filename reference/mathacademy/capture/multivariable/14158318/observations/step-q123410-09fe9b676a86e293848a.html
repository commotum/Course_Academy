Which of the following is equivalent to ∫Cds, where C is the path along the polar curve r=1−5cos⁡θ for π6≤θ≤7π6, shown above?

a
∫π/67π/618−8cos⁡θdθ
b
∫π/67π/616+10cos⁡θdθ
c
∫π/67π/626−10cos⁡θdθ
d
∫π/67π/68−18cos⁡θdθ
e
∫π/67π/610−26cos⁡θdθ
Submit
Correct
EXPLANATION

The line integral of unity with respect to arc length over C is equal to the arc length L of C, i.e., ∫Cds=L.

In polar coordinates, the arc length element ds is given by

ds=r2+(drdθ)2dθ.

So, for a polar curve defined as r=r(θ) for θ1≤θ≤θ2, we have

L=∫Cds=∫θ1θ2r2+(drdθ)2dθ.

Since r=1−5cos⁡θ, we have drdθ=5sin⁡θ.

Therefore, the expression for our line integral is

∫Cds=∫θ1θ2r2+(drdθ)2dθ=∫π/67π/6(1−5cos⁡θ)2+(5sin⁡θ)2dθ=∫π/67π/61−10cos⁡θ+25cos2⁡θ+25sin2⁡θdθ=∫π/67π/61−10cos⁡θ+25dθ=∫π/67π/626−10cos⁡θdθ.
