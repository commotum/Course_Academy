The negation of the predicate is a new predicate that we denote as follows: This predicate is true if and only if is false for a specific set of assignment variables

For example, consider the following predicate defined over the universal set

is even

Then, is a new predicate that reads as follows:

is not even

This can be simplified as:

is odd

For example:

  • is true while is false

  • is false while is true
