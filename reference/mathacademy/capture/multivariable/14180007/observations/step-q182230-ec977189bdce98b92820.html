Which of the following statements are true?

  1. P(∅)={∅}
  2. P(a)={∅,{a}}
  3. P({∅,{∅}})={∅,{∅,{∅}}}
a
II only
b
II and III only
c
I only
d
III only
e
I and II only
Submit
Correct
EXPLANATION

The power set of T, denoted P(T), is the set that contains every possible subset of T, including the empty set ∅.

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, the power set of the set ∅ is {∅}.

  • Statement II is false. Notice that a is not a set. So, the notation P(a) does not make sense.

  • Statement III is false. Notice that we are given the set {∅,{∅}}. So, its power set must be {∅,{∅},{{∅}},{∅,{∅}}}.

Therefore, the correct answer is "I only."
