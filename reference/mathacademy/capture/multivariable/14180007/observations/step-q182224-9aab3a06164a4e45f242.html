Which of the following statements are true?

  1. P(∅)={∅,{∅}}
  2. P({a,∅})={∅,{a},{a,∅}}
  3. P({∅})={∅,{∅}}
a
I and II only
b
II only
c
II and III only
d
III only
e
I only
Submit
Correct
EXPLANATION

The power set of T, denoted P(T), is the set that contains every possible subset of T, including the empty set ∅.

With that in mind, let's examine our statements.

  • Statement I is false. Notice that we are given the set ∅. So, its power set must be {∅}.

  • Statement II is false. Notice that we are given the set {a,∅}. So, its power set must be {∅,{a},{∅},{a,∅}}.

  • Statement III is true. Indeed, the power set of the set {∅} is {∅,{∅}}.

Therefore, the correct answer is "III only."
