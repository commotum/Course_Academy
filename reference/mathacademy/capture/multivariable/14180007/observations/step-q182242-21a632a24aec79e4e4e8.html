Which of the following statements are true?

  1. P(P(∅))={∅,{∅}}
  2. P(P({∅}))={∅,{∅}}
  3. P(P({0}))={∅,{∅},{{0}},{∅,{0}}}
a
 II and III only
b
 I and III only
c
 I only
d
 II only
e
 III only
Submit
Incorrect
EXPLANATION

The power set of T, denoted P(T), is the set that contains every possible subset of T, including the empty set ∅.

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, the power set of the set ∅ is {∅}. Therefore, P(P(∅))={∅,{∅}}.

  • Statement II is false. Notice that we are given the set {∅}. So, its power set must be {∅,{∅}}. Therefore, P(P({∅}))={∅,{∅},{{∅}},{∅,{∅}}}.

  • Statement III is true. Notice that we are given the set {0}. So, its power set must be {∅,{0}}. Therefore, P(P({0}))={∅,{∅},{{0}},{∅,{0}}}.

Therefore, the correct answer is "I and III only."
