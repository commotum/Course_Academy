Which of the following systems of linear ODEs are decoupled?

  1. x′(t)=[800−1]x(t)
  2. x′(t)=[07−43]x(t)
  3. x′(t)=[2005]x(t)
a
I only
b
III only
c
II and III only
d
I and III only
e
II only
Submit
Correct
EXPLANATION

A decoupled system consists of equations depending on only one variable, such as
xi′(t)=λixi(t),
where λi is a constant. This means that we can solve each equation independently.

In matrix form, a linear system x′(t)=Ax(t) is decoupled if A is a diagonal matrix.

With this in mind, let's examine our systems.

  • Systems I and III are decoupled since their corresponding matrices are diagonal.

  • System II is not decoupled because its matrix is not diagonal.

Therefore, the correct answer is "I and III only".
