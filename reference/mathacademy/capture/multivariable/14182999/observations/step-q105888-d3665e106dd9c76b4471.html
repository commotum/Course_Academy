If Y={1,2,3,…,100}, which collection of subsets of Y is a partition of Y?

a
 {∅,{1,2,3,…,100}}
b
 {{2,4,6,…,100},{1,3,5,…,99}}
c
 {{0,1,2,3,…,100}}
d
{{2,4,6,…,100},{5,15,25…,95}}
e
{{2,4,6,…,40},{1,2,3,…,99}}
Submit
Incorrect
EXPLANATION

A partition of a set Y is a collection of non-empty subsets of Y where every element of Y is contained in exactly one subset.

Of the given collections, only {{2,4,6,…,100},{1,3,5,…,99}} is a partition.

The rest of the collections are not partitions:

  • {{2,4,6,…,100},{5,15,25…,95}} is not a partition because many elements of Y (such as 1) do not appear in any subsets.

  • {{2,4,6,…,40},{1,2,3,…,99}} is not a partition because many elements (such as 2) appear in both subsets.

  • {{0,1,2,3,…,100}} is not a partition because it contains the element 0 that do not appear in Y.

  • {∅,{1,2,3,…,100}} is not a partition because the subset ∅ is empty.
