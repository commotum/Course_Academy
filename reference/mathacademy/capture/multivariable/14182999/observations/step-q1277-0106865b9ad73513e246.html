If B={−2,−1,0,1,2}, which collection of subsets of B is a partition of B?

a
{{−2,−1},{−1,0},{1,2}}
b
{{−2,−1},{−1,1},{0}}
c
{{−2,−1,0},{−2,2},{−2,1},{−1,0}}
d
{{−2,0},{−1,1},{2}}
e
{∅,{−2,−1},{0,1,2}}
Submit
Incorrect
EXPLANATION

A partition of a set B is a collection of non-empty subsets of B where every element of B is contained in exactly one subset.

Of the given collections, only {{−2,0},{−1,1},{2}} is a partition.

The rest of the collections are not partitions:

  • {{−2,−1},{−1,1},{0}} is not a partition because the element −1 appears in two subsets.

  • {{−2,−1},{−1,0},{1,2}} is not a partition because the element −1 appears in two subsets.

  • {{−2,−1,0},{−2,2},{−2,1},{−1,0}} is not a partition because the elements −2, −1 and 0 appear in multiple subsets.

  • {∅,{−2,−1},{0,1,2}} is not a partition because the subset ∅ is empty.
