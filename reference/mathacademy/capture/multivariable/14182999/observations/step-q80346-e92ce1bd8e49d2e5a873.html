Consider the set X={3,6,9,12,15,18,21,24}. Which subset must be placed into the blank in the set below so that it represents a partition of X?

{{6,12,18},{15,21},____}

a
 {6,15}
b
 {3,9,24}
c
 {3,9}
d
 {3,12,24}

Correct
EXPLANATION

A partition of a set X is a collection of non-empty subsets of X where every element of X is contained in exactly one subset.

To find the subset that goes in the blank, we must identify which elements of X are not yet contained within any of the given subsets.

Let's go through each element of X and check:

  • 3 does not belong to any of the given subsets ×

  • 6∈{6,12,18}✓

  • 9 does not belong to any of the given subsets ×

  • 12∈{6,12,18}✓

  • 15∈{15,21}✓

  • 18∈{6,12,18}✓

  • 21∈{15,21}✓

  • 24 does not belong to any of the given subsets ×

The elements 3, 9, and 24 are not yet contained within any of the given subsets. Therefore, the subset that must go in the blank is {3,9,24}.
