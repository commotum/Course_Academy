{∅,{0,3,6,…,99}}

Correct
EXPLANATION

A partition of a set A is a collection of non-empty subsets of A where every element of A is contained in exactly one subset.

Of the given collections, only {{0,6,12…,96},{3,9,15,…,99}} is a partition.

  • {∅,{0,3,6,…,99}} is not a partition because the subset ∅ is empty.
