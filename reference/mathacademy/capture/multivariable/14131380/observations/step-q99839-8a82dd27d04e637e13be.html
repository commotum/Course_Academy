Consider the following set of functions: f1(t)=sin⁡t,f2(t)=sin⁡(3t),f3(t)=sin⁡(5t)

Given that the inner product in the vector space C[0,π/2] of continuous functions over [0,π/2] is defined as ⟨f(t),g(t)⟩=∫0π/2f(t)g(t)dt, which of the following statements are true?

  1. f1(t)⊥f2(t) with respect to the given inner product
  2. f1(t)⊥f3(t) with respect to the given inner product
  3. S={f1(t),f2(t),f3(t)} is an orthogonal set with respect to the given inner product
Hint: ⟨f2,f3⟩=0.

a
II only
b
None of the statements are true
c
I and II only
d
I, II, and III
e
I only
Submit
Correct
EXPLANATION

Recall that a set of vectors in an inner product space is called orthogonal if all vectors in the set are mutually orthogonal with respect to the given inner product.

With that in mind, let's examine our statements in turn.

  • Statement I is true. We have ⟨f1(t),f2(t)⟩=⟨sin⁡t,sin⁡(3t)⟩=∫0π/2sin⁡tsin⁡(3t)dt. We can evaluate this integral using the identity sin⁡αsin⁡β=12(cos⁡(α−β)−cos⁡(α+β)) as follows: ∫0π/2sin⁡tsin⁡(3t)dt=12∫0π/2(cos⁡(t−3t)−cos⁡(t+3t))dt=12∫0π/2(cos⁡(−2t)−cos⁡(4t))dt=12(−sin⁡(−2t)2−sin⁡(4t)4)|0π/2=12(−sin⁡(−π)2−sin⁡(2π)4)−12(−sin⁡02−sin⁡04)=−12⋅0+12⋅0=0. This means that f1(t)⊥f2(t) with respect to the given inner product.

  • Statement II is true. We have ⟨f1(t),f3(t)⟩=⟨sin⁡t,sin⁡(5t)⟩=∫0π/2sin⁡tsin⁡(5t)dt. We can evaluate this integral using the identity sin⁡αsin⁡β=12(cos⁡(α−β)−cos⁡(α+β)) as follows: ∫0π/2sin⁡tsin⁡(5t)dt=12∫0π/2(cos⁡(t−5t)−cos⁡(t+5t))dt=12∫0π/2(cos⁡(−4t)−cos⁡(6t))dt=12(−sin⁡(−4t)4−sin⁡(6t)6)|0π/2=12(−sin⁡(−2π)4−sin⁡(3π)6)−12(−sin⁡04−sin⁡06)=−12⋅0+12⋅0=0. This means that f1(t)⊥f3(t) with respect to the given inner product.

  • Statement III is true. Since f1(t)⊥f2(t), f1(t)⊥f3(t), and f2(t)⊥f3(t), the set S is orthogonal.

Therefore, the correct answer is "I, II, and III."
