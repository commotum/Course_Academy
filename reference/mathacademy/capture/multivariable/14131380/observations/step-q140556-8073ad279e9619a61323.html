Consider the following set of functions: f1(t)=2(t−1),f2(t)=et,f3(t)=e(t−1)2

Given that the inner product in the vector space C[0,2] of continuous functions over [0,2] is defined as ⟨f(t),g(t)⟩=∫02f(t)g(t)dt, which of the following statements are true?

  1. f1(t)⊥f2(t) with respect to the given inner product
  2. f1(t)⊥f3(t) with respect to the given inner product
  3. S={f1(t),f2(t),f3(t)} is an orthogonal set with respect to the given inner product
a
I only
b
I, II, and III
c
II only
d
III only
e

Incorrect
EXPLANATION

Recall that a set of vectors in an inner product space is called orthogonal if all vectors in the set are mutually orthogonal with respect to the given inner product.

With that in mind, let's examine our statements in turn.

  • Statement I is false. We have ⟨f1(t),f2(t)⟩=⟨2(t−1),et⟩=∫022(t−1)(et)dt Let's use integration by parts. We denote u=2(t−1)⟹u′=2,v′=et⟹v=∫v′dt=∫etdt=et. Now, applying the integration by parts formula, we obtain ∫022(t−1)etdt=uv|02−∫02u′vdt=(2(t−1)et)|02−∫022etdt=(2e2−(−2))−2et|02=2e2+2−(2e2−2)=4≠0. This means that f1(t)⊥̸f2(t) with respect to the given inner product.

  • Statement II is true. We have ⟨f1(t),f3(t)⟩=⟨2(t−1),e(t−1)2⟩=∫022(t−1)e(t−1)2dt=e(t−1)2|02=e−e=0. This means that f1(t)⊥f3(t) with respect to the given inner product.

  • Statement III is false. Since f1(t)⊥̸f3(t), the set S is not orthogonal.

Therefore, the correct answer is "II only."
