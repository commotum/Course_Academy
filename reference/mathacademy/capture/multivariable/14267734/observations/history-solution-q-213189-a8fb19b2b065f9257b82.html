A binary relation can be visualized using a plot (or graph), where

  • the first set is plotted along the horizontal axis,

  • the second set is plotted along the vertical axis, and

  • each pair (x,y) from the relation defines a point with coordinates (x,y) on the plot.

The relation R is the set of ordered pairs (x,y)∈A×B with x+y≤3.

  • If x=−2, then the values y=3,5 satisfy x+y≤3. So, R contains the ordered pairs (−2,3) and (−2,5), and we should plot these points on the graph.

  • If x=−1, then the value y=3 satisfies x+y≤3. So, R contains the ordered pair (−1,3), and we should plot this point on the graph.

  • If x=0, then the value y=3 satisfies x+y≤3. So, R contains the ordered pair (0,3), and we should plot this point on the graph.
