The plot of the binary relation S, defined over the set X={♢,△,♡} is given above. Which of the following ordered pairs belong to the relation?

  1. (♡,♡)
  2. (△,♢)
  3. (△,♡)

Correct
EXPLANATION

A binary relation can be visualized using a plot (or graph), where

  • the first set is plotted along the horizontal axis,

  • the second set is plotted along the vertical axis, and

  • each pair (x,y) from the relation defines a point with coordinates (x,y) on the plot.

With that in mind, let's examine the given ordered pairs.

  • The pair (♡,♡) belongs to the relation. Indeed, the plot contains a point with these coordinates.

  • The pair (△,♢) belongs to the relation. Indeed, the plot contains a point with these coordinates.

  • The pair (△,♡) does not belong to the relation since the plot does not contain a point with such coordinates.

Therefore, the correct answer is "I and II only."
