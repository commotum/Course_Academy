A binary relation can be visualized using a plot (or graph), where

  • the first set is plotted along the horizontal axis,

  • the second set is plotted along the vertical axis, and

  • each pair (x,y) from the relation defines a point with coordinates (x,y) on the plot.

The relation R is the set of ordered pairs (x,y)∈A×B with x∈y.

  • If x=0, then the value y={0,2} satisfies x∈y. So, R contains the ordered pair (0,{0,2}), and we should plot this point on the graph.

  • If x=2, then the value y={0,2} satisfies x∈y. So, R contains the ordered pair (2,{0,2}), and we should plot this point on the graph.
