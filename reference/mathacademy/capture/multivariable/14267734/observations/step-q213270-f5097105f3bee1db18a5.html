EXPLANATION

The ordered pairs belonging to our relation correspond to the arrows on the mapping diagram. Each arrow starts at the first component of the pair and ends at its second component.

We're given the following sets: A={2,4,8},B={3,6,8}.

The relation R is the set of ordered pairs (x,y)∈A×B with x⧸∣y.

  • If x=2, then the value y=3 satisfies x⧸∣y. So, R contains the ordered pair (2,3), and we should add the arrow 2→3 to the mapping diagram.

  • If x=4, then the values y=3,6 satisfy x⧸∣y. So, R contains the ordered pairs (4,3) and (4,6), and we should add the arrows 4→3 and 4→6 to the mapping diagram.

  • If x=8, then the values y=3,6 satisfy x⧸∣y. So, R contains the ordered pairs (8,3) and (8,6), and we should add the arrows 8→3 and 8→6 to the mapping diagram.
