The velocity v at time t of a particle P moving in the xy-plane is given by v(t)=⟨2t−2,2t⟩,t∈(−∞,∞). Given that the particle is at the position r=⟨−4,−8⟩ when t=1, find the times when the particle is at the origin.

t=2
b
t=0
c
The particle is never at the origin

Incorrect
EXPLANATION

The particle is at the origin when its position is r=⟨0,0⟩. So first, we need to compute the position function of the particle.

To compute the position vector, we need to integrate the velocity vector:

r(t)=∫v(t)dt=∫⟨2t−2,2t⟩dt=⟨∫(2t−2)dt,∫2tdt⟩=⟨t2−2t+C1,t2+C2⟩.

Now, we can solve for the constants of integration using the fact that r(0)=⟨−4,−8⟩. Substituting t=1, we get

r(1)=⟨(1)2−2(1)+C1,(1)2+C2⟩⟨−4,−8⟩=⟨−1+C1,1+C2⟩,

so we must have C1=−3 and C2=−9. Therefore, the position of P at time t is given by

r(t)=⟨t2−2t−3,t2−9⟩.

To find the times at which the particle is at the origin, we solve the equation r(t)=0.

r(t)=0⟨t2−2t−3,t2−9⟩=⟨0,0⟩.

So we need t2−2t−3=(t−3)(t+1)=0⇒t=−1,3,t2−9=(t+3)(t−3)=0⇒t=±3.

The only solution that satisfies both equations is t=3.
