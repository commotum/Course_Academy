Let M2(R) be the set of all real 2×2 matrices. The given statement can be re-phrased as follows:

For all x∈M2(R), x is not singular.

Introducing the universal quantifier, we get the following:

∀x∈M2(R),x is not singular.

Negating this, we obtain ¬(∀x∈M2(R),x is not singular)≡∃x∈M2(R),¬(x is not singular)≡∃x∈M2(R),x is singular

which reads

There exists x∈M2(R) such that x is singular.

or simply

Some real 2×2 matrices are singular.
