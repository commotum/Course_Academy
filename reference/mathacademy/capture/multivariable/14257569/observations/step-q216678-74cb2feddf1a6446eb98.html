Negate the following statement:

Every sequence is arithmetic.

a
Some sequences are arithmetic.
b
None of the listed.
c
Every sequence is arithmetic.
d
Some sequences are not arithmetic.
e
Every sequence is not arithmetic.
Submit
Correct
EXPLANATION

Let S be the set of all sequences. The given statement can be re-phrased as follows:

For all s∈S, s is arithmetic.

Introducing the universal quantifier, we get the following:

∀s∈S,s is arithmetic.

Negating this, we obtain

¬(∀s∈S,s is arithmetic)≡∃s∈S,¬(s is arithmetic)≡∃s∈S,s is not arithmetic

which reads

There exists s∈S such that s is not arithmetic.

or simply

Some sequences are not arithmetic.
