A curve is defined by the parametric equations x=3t4,y=8t,−∞<t<∞. Determine the value of t at which the tangent to the curve is vertical.

a
t=12
b
t=−8
c
t=0
d
t=8
e
t=3
Submit
Correct
EXPLANATION

The slope m of a tangent line to a curve defined parametrically is given by

m=y′(t)x′(t).

The tangent line is vertical if x′(t)=0 while y′(t)≠0.

So, we first find the derivatives of x and y:

x′(t)=12t3,y′(t)=8.

Solving x′(t)=0 gives

12t3=0⟹t=0.

Note that y′(0)=8≠0. Therefore, we conclude that when t=0 the tangent to the curve is vertical.
