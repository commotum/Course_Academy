A curve is defined by the parametric equations x=4ln⁡t,y=2tln⁡t,0<t<∞. Let C be the point that corresponds to t=e on the curve. Find the equation of the normal to the curve at C.

a
y=−1ex+2e2+4e
b
y=1ex+2e2−4e
c
y=−4ex+2e2−4e
d
y=2ex+4e2−2e
e
y=2ex−2e2−4e
Submit
Correct
EXPLANATION

First, we find the coordinates of the point C by substituting t=e into the parametric equations: x=4ln⁡e=4,y=2eln⁡e=2e So we're looking to find the equation of the tangent line to the curve at the point (4,2e). For this, we need to find dydx, which means we first need to find the derivatives of x and y, as follows:

x′(t)=4t,y′(t)=2ln⁡t+2

So, we have

dydx=y′(t)x′(t)=2ln⁡t+2(4t)=tln⁡t+t2.

At the point where t=e, the slope of the tangent line is given by m=dydx|t=e=eln⁡e+e2=e+e2=e.

To find the slope mn of the normal line, we take the negative reciprocal of m:

mn=−1m=−1e

To calculate the equation of the normal, we use point-slope form with the point (x1,y1)=(4,2e) and the slope mn=−1e. We get

y−2e=(−1e)(x−4)y−2e=−1ex+4ey=−1ex+2e2+4e.
