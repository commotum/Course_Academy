R={(1,6),(2,2),(2,4),(2,6),(3,6)} What are the domain and range of this relation?

EXPLANATION

Given a relation R⊆A×B,

  • the domain of R is the set containing all elements from A that appear as the first component of the ordered pairs in R, and

  • the range of R is the set containing all elements from B that appear as the second component of the ordered pairs in R.

With that in mind, we examine the given relation.

  • Let's consider the first components of the pairs belonging to our relation: R={(1,6),(2,2),(2,4),(2,6),(3,6)} The set of first components is {1,2,2,2,3}={1,2,3}. Hence, the domain is {1,2,3}.

  • Let's consider the second components of the pairs belonging to our relation: R={(1,6),(2,2),(2,4),(2,6),(3,6)} The set of second components is {6,2,4,6,6}={2,4,6}. Hence, the range is {2,4,6}.
