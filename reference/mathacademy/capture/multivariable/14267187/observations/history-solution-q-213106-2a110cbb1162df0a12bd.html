Given a relation R⊆A×B,

  • the domain of R is the set containing all elements from A that appear as the first component of the ordered pairs in R, and

  • the range of R is the set containing all elements from B that appear as the second component of the ordered pairs in R.

With that in mind, we examine the given relation.

  • Let's consider the first components of the pairs belonging to our relation: R={(−2,5),(1,5),(1,7),(2,7)} The set of first components is {−2,1,1,2}={−2,1,2}. Hence, the domain is {−2,1,2}.

  • Let's consider the second components of the pairs belonging to our relation: R={(−2,5),(1,5),(1,7),(2,7)} The set of second components is {5,5,7,7}={5,7}. Hence, the range is {5,7}.
