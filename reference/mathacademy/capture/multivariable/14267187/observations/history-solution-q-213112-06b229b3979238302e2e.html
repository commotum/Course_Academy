Given a relation R⊆A×B,

  • the domain of R is the set containing all elements from A that appear as the first component of the ordered pairs in R, and

  • the range of R is the set containing all elements from B that appear as the second component of the ordered pairs in R.

With that in mind, we examine the given relation.

  • The set of first components contains all real numbers R. Hence, the domain is R.

  • Notice that 0≤sin⁡x+1≤2 for all x∈R, and it is continuous on R. So, the set of second components contains all real numbers greater than or equal to 0 and less than or equal to 2: {y∈R:0≤y≤2} Hence, the range is {y∈R:0≤y≤2}.
