If a relation R is defined over A={a1,a2,…,am} and B={b1,b2,…bn} of cardinalities m and n, respectively, the adjacency matrix of R is a m×n-matrix (table), where the element rij at the intersection of the ith row and the jth column is given by rij={1,if aiRbj,0,otherwise.

The relation R is the set of ordered pairs (x,y)∈A×B with x=y−1.

Let's consider each row in our table.

  • If x=−2, then there is no value of y∈B that satisfies x=y−1.

  • If x=−1, then the value y=0 satisfies x=y−1. So, R contains the ordered pair (−1,0), and we write 1 in the intersection of the 2nd row and the 1st column in the adjacency matrix.

  • If x=0, then the value y=1 satisfies x=y−1. So, R contains the ordered pair (0,1), and we write 1 in the intersection of the 3rd row and the 2nd column in the adjacency matrix.

All the other cells in the matrix must be filled with zeros. Therefore, we have the following adjacency matrix:
