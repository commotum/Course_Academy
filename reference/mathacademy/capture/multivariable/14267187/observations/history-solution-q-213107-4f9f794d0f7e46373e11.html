Given a relation R⊆A×B,

  • the domain of R is the set containing all elements from A that appear as the first component of the ordered pairs in R, and

  • the range of R is the set containing all elements from B that appear as the second component of the ordered pairs in R.

With that in mind, we examine the given relation.

  • Let's consider the first components of the pairs belonging to our relation: R={(−5,1,(−5,2),(0,3),(8,1),(8,5)} The set of first components is {−5,−5,0,8,8}={−5,0,8}. Hence, the domain is {−5,0,8}.
  • Let's consider the second components of the pairs belonging to our relation: R={(−5,1),(−5,2),(0,3),(8,1),(8,5)}

The set of second components is {1,2,3,1,5}={1,2,3,5}. Hence, the range is {1,2,3,5}.
