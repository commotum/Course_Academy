Recall that Null(XTYT) contains all vectors that, when pre-multiplied by XTYT, result in the zero-vector 0.

When pre-multiplying a vector by XTYT, we actually multiply each row of XTYT by that vector. So, Null(XTYT) must be orthogonal to the row space of XTYT, which is Col((XTYT)T)=Col(YX).

Therefore, the correct answer is "III only."
