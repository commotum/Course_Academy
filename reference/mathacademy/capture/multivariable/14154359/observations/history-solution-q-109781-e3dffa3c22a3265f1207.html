Recall that Col(BT) is the row space of B. This consists of all linear combinations of the rows of B.

If a vector is orthogonal to every linear combination of the rows of B, it must be orthogonal to each row of B. But notice that when pre-multiplying a vector by B, we actually multiply each row of B by that vector. So, Col(BT) must be orthogonal to the null space of B, which is Null(B).

Therefore, the correct answer is "III only."
