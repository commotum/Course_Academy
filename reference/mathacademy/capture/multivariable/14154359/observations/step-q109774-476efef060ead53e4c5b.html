Which of the following subspaces must be orthogonal to Null(AT) for every matrix A?

  1. Col(A)
  2. Null(A)
  3. Col(AT)
a
I only
b
I and III only
c
I and II only
d
II only
e
III only
Submit
Incorrect
EXPLANATION

Recall that Null(AT) is the left null space of A. This consists of vectors that, when pre-multiplied by AT, result in the zero-vector 0.

When pre-multiplying a vector by AT, we actually multiply each row of AT, that is, each column of A, by that vector. So, Null(AT) must be orthogonal to the column space of A, which is Col(A).

Therefore, the correct answer is "I only."
