EXPLANATION

Recall the following facts regarding the congruence ax≡b(modn):

  • The congruence has no solutions modulo n if and only if gcd(a,n)⧸|b.

  • The congruence has gcd(a,n) solutions modulo n if and only if gcd(a,n)|b.

With that in mind, let's examine our congruences.

  • Congruence I has four solutions modulo 20. We have a=4 and n=20, and so gcd(a,n)=gcd(4,20)=4. Since b=12 is divisible by 4, this congruence has 4 solutions.

  • Congruence II has a unique solution modulo 19. We have a=5 and n=19, and so gcd(a,n)=gcd(5,19)=1. Therefore, this congruence has a unique solution.

  • Congruence III has no solutions. We have a=6 and n=21, and so gcd(a,n)=gcd(6,21)=3. Since b=8 is not divisible by 3, this congruence has no solutions.

Therefore, the correct answer is "III only".
