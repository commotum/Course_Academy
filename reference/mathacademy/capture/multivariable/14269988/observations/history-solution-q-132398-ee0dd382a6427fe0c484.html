Recall the following facts regarding the congruence ax≡b(modn):

  • The congruence has no solutions modulo n if and only if gcd(a,n)⧸|b.

  • The congruence has gcd(a,n) solutions modulo n if and only if gcd(a,n)|b.

With that in mind, let's examine our congruences.

  • Congruence I has six solutions modulo 24. We have a=18 and n=24, and so gcd(a,n)=gcd(18,24)=6. Since b=12 is divisible by 6, this congruence has 6 solutions.

  • Congruence II has no solutions. We have a=9 and n=24, and so gcd(a,n)=gcd(9,24)=3. Since b=5 is not divisible by 3, this congruence has no solutions.

  • Congruence III has three solutions modulo 24. We have a=15 and n=24, and so gcd(a,n)=gcd(15,24)=3. Since b=18 is divisible by 3, this congruence has 3 solutions.
