EXPLANATION

Recall the following facts regarding the congruence ax≡b(modn):

  • The congruence has no solutions modulo n if and only if gcd(a,n)⧸|b.

  • The congruence has gcd(a,n) solutions modulo n if and only if gcd(a,n)|b.

With that in mind, let's examine our congruences.

  • Congruence I has two solutions modulo 36. We have a=10 and n=36, and so gcd(a,n)=gcd(10,36)=2. Since b=18 is divisible by 2, this congruence has 2 solutions.

  • Congruence II has a unique solution modulo 36. We have a=5 and n=36, and so gcd(a,n)=gcd(5,36)=1. Therefore, this congruence has a unique solution.

  • Congruence III has no solutions. We have a=4 and n=36, and so gcd(a,n)=gcd(4,36)=4. Since b=18 is not divisible by 4, this congruence has no solutions.

Therefore, the correct answer is "III only".
