Recall the following facts regarding the congruence ax≡b(modn):

  • The congruence has no solutions modulo n if and only if gcd(a,n)⧸|b.

  • The congruence has gcd(a,n) solutions modulo n if and only if gcd(a,n)|b.

With that in mind, let's examine our congruences.

  • Congruence I has three solutions modulo 21. We have a=9 and n=21, and so gcd(a,n)=gcd(9,21)=3. Since b=12 is divisible by 3, this congruence has 3 solutions.

  • Congruence II has three solutions modulo 21. We have a=6 and n=21, and so gcd(a,n)=gcd(6,21)=3. Since b=15 is divisible by 3, this congruence has 3 solutions.

  • Congruence III has no solutions. We have a=12 and n=21, and so gcd(a,n)=gcd(12,21)=3. Since b=8 is not divisible by 3, this congruence has no solutions.

Therefore, the correct answer is "I and II only".
