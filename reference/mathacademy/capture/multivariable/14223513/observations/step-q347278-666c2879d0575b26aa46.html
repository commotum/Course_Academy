A tutoring center offers private lesson packages. When the price of a package is $40, the center books all 80 available sessions. For every $4 increase in the package price, one fewer session is booked. If the cost of providing each session is $16, what price should the center charge to maximize its profit?
To maximize profit, the center should charge $
188
per session.

Correct
EXPLANATION

To solve this problem, we apply the candidates test.

Let x represent the number of unbooked sessions. Then the number of booked sessions is (80−x), and the price per session is (40+4x).

So, the total revenue is R(x)=(80−x)(40+4x).

Expanding, we get R(x)=−4x2+280x+3200.

The cost of providing each booked session is $16, so the total cost is C(x)=16(80−x)=1280−16x.

Therefore, the profit function is P(x)=R(x)−C(x)=(−4x2+280x+3200)−(1280−16x)=−4x2+296x+1920.

We are given the domain 0≤x≤80.

To find the maximum, we take the derivative: P′(x)=−8x+296.

Solving P′(x)=0, we get: x=37.

Since P″(x)=−8<0, this point is a maximum. Since P(x) is quadratic, this maximum is global.

Now, if x=37 sessions are unbooked, then the price is: 40+4(37)=188.

Therefore, to maximize profit, the center should charge $188 per session.
