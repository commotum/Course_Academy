A vector-valued function is continuous on an interval if and only if each of its components is continuous on that interval.

Let's now consider the components of f(t) one by one.

  • The function tcos⁡2t is continuous for all real numbers.

  • The function 2et−1 is continuous for all real numbers.

  • The function 5−t is continuous for t≤5.

Therefore, the vector-valued function f(t) is continuous for t≤5. So the interval of continuity is (−∞,5].
