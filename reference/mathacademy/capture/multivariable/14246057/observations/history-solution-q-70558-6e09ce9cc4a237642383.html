A vector-valued function is continuous on an interval if and only if each of its components is continuous on that interval.

Let's now consider the components of f(t) one-by-one.

  • The function t2+4tt is continuous everywhere except the excluded point t=0.

  • The function t2−1 is continuous for all real numbers.

  • The function 1t−2 is continuous everywhere except the point t=2.

Therefore, the vector-valued function f(t) is continuous everywhere except the points t=0 and t=2. So the interval of continuity is (−∞,0)∪(0,2)∪(2,∞).
