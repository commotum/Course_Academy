EXPLANATION

Using the scalar function multiple rule for limits, and the fact that both functions are continuous, we get:

limt→0[u(t)f(t)]=limt→0u(t)⋅limt→0f(t)=u(0)f(0)=3f(0)

On the other hand, we are told that limt→0[u(t)f(t)]=⟨−18,−21,6⟩.

Therefore, we obtain the following equation which we can solve for f(0):

limt→0[u(t)f(t)]=⟨−18,−21,6⟩3f(0)=⟨−18,−21,6⟩f(0)=13⟨−18,−21,6⟩f(0)=⟨−6,−7,2⟩
