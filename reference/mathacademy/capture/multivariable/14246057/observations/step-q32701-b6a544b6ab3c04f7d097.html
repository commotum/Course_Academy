Which of the following vector-valued functions are differentiable with respect to t on t∈(π,2π)? f(t)=⟨sin2⁡t,1t,sin⁡t−cos⁡t⟩g(t)=⟨tt,1−t2,tsin⁡(2t)⟩h(t)=⟨cos⁡(2t),2t,cos⁡t⟩

a
f(t) and h(t) only
b
None of the functions are differentiable on (π,2π)
c
 All the functions are differentiable on (π,2π)
d
g(t) and h(t) only
e
f(t) and g(t) only
Submit
Incorrect
EXPLANATION

All of these vector-valued functions are defined for all t∈(π,2π).

A function is differentiable on the interval (π,2π) if and only if each of its component functions is differentiable on that interval.

Let's now consider the functions one-by-one.

  • We differentiate f(t) to find f′(t): f′(t)=⟨ddt(sin2⁡t),ddt(1t),ddt(sin⁡t−cos⁡t)⟩=⟨2sin⁡tcos⁡t,−1t2,cos⁡t+sin⁡t⟩ Since each component of f′(t) is defined for all t∈(π,2π), we conclude that f(t) is differentiable on this interval.

  • Next, we differentiate g(t) to find g′(t): g′(t)=⟨ddt(tt),ddt(1−t2),ddt(tsin⁡(2t))⟩=⟨ddt(t3/2),ddt(1−t2),ddt(tsin⁡(2t))⟩=⟨32t1/2,−2t,sin⁡(2t)+2tcos⁡(2t)⟩=⟨32t,−2t,sin⁡(2t)+2tcos⁡(2t)⟩ Since each component of g′(t) is defined for all t∈(π,2π), we have that g(t) is differentiable on this interval.

  • Finally, we differentiate h(t) to find h′(t): h′(t)=⟨ddtcos⁡(2t),ddt(2t),ddt(cos⁡t)⟩=⟨−2sin⁡(2t),2,−sin⁡t⟩ Since each component of h′(t) is defined for all t∈(π,2π), we conclude that h(t) is differentiable on this interval.

Therefore, the answer is:

All the functions are differentiable on (π,2π).
