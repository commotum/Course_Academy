A vector-valued function is continuous on an interval if and only if each of its components is continuous on that interval.

Let's now consider the components of f(t) one by one.

  • The function 1t2−1 is continuous everywhere except the excluded points t=±1.

  • The function t is continuous for t≥0.

  • The function t+3 is continuous for all real numbers.

Therefore, the vector-valued function f(t) is continuous for all t≥0 except the point t=1. So the interval of continuity is [0,1)∪(1,∞).
