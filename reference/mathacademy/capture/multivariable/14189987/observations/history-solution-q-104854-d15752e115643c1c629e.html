Infinite discontinuities coincide with the vertical asymptotes of y=f(x). The only possible way that y=f(x) can have vertical asymptotes is if 1x−3 grows without bound within its respective subdomain.

We compute the vertical asymptotes of 1x−3. Setting the denominator equal to zero, we get

x−3=0⟹x=3.

Although this branch of the function is defined for x>3, we have that

limx→3+(1x−3)=∞,

and therefore we conclude that x=3 is indeed an infinite discontinuity.
