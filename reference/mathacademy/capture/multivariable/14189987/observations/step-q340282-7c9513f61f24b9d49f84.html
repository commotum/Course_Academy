EXPLANATION

Infinite discontinuities coincide with the vertical asymptotes of y=f(x). The only possible way that y=f(x) can have vertical asymptotes is if either x2−1 or 2x−1 grows without bound within its respective subdomain.

  • We first compute the asymptotes of x2−1. Since x2−1 is a polynomial, therefore it cannot grow without bound due to a vertical asymptote. So this function cannot have an infinite discontinuity.

  • Next, we compute the asymptotes of 2x−1. Setting the denominator equal to zero, we get x−1=0⟹x=1. Although this branch of the function is defined for x>1, we have that limx→1+(2x−1)=∞, and therefore we conclude that x=1 is indeed an infinite discontinuity.

Therefore, the only point where the function y=f(x) has an infinite discontinuity is x=1.
