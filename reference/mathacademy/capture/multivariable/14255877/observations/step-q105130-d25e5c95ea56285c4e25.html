Which of the following statements are true regarding the function f:R→R whose graph is shown above?

  1. f(0)=f(2)

EXPLANATION

A function f:X→Y is an injection (also known as one-to-one) if every element in X is mapped to a distinct element in Y:

f:X→Y is an injection if ∀x1,x2∈X, if f(x1)=f(x2), we have x1=x2.

With that in mind, let's consider each statement in turn.

  • Statement I is true. According to the graph, we have f(0)=0 and f(2)=0.

  • Statement II is false. Again, we have f(0)=f(2) but 0≠2. So, it's not true that for all x1 and x2 contained within the domain R, if f(x1) and f(x2) are equal, then we must have x1=x2.

  • Statement III is false. Indeed, since statement II is false, f is not an injection (also known as one-to-one).

Therefore, the correct answer is "I only."
