Which of the following statements are true regarding the function f:R→R which is given by f(x)=3−2x?

  1. f(−1)≠f(2)
  2. ∀x1,x2∈R, if f(x1)=f(x2), we have x1=x2
  3. f is an injection
a
I only
b
I, II, and III
c
III only
d
II and III only
e
I and II only
Submit
Incorrect
EXPLANATION

First, we graph the function.

A function f:X→Y is an injection (also known as one-to-one) if every element in X is mapped to a distinct element in Y:

f:X→Y is an injection if ∀x1,x2∈X, if f(x1)=f(x2), we have x1=x2.

With that in mind, let's consider each statement in turn.

  • Statement I is true. We have f(−1)=3−2(−1)=5 and f(2)=3−2⋅2=−1.

  • Statement II is true. As we can see from the graph, it passes the horizontal line test, meaning that there are no two distinct elements within R that map to the same element in R. So, for all x1 and x2 contained within the domain R, if f(x1) and f(x2) are equal, then we must have x1=x2.

  • Statement III is true. Indeed, since statement II is true, f is an injection.

Therefore, the correct answer is "I, II, and III."
