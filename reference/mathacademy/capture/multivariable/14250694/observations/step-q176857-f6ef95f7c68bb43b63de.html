Consider the following statement.

0.75 does not belong to the set of rational numbers.

What is the negation of this statement?

a
0.75 belongs to the set of rational numbers.
b
0.75 does not belong to the set of rational numbers.
c
0.75 does not belong to the set of integer numbers.
d
0.75 belongs to the set of integer numbers.
e
0.75 belongs to the set of real numbers.
Submit
Correct
EXPLANATION

Let's denote the given statement as P.

The symbol "¬" represents negation. So, our task is to negate the given sentence.

To negate our plain English sentence, we place the words "It is not true that" in front of it. This gives the following:

It is not true that 0.75 does not belong to the set of rational numbers.

In other words, 0.75 belongs to the set of rational numbers. Therefore, ¬P means the following:

0.75 belongs to the set of rational numbers.

Note that P is false, while ¬P is true.
