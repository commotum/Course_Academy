Given the relation R on Z defined by xRy⇔x∣y, which of the following statements are true?

  1. 3R16
  2. 4R7
  3. 5R20
a
I and II only
b
II only
c
II and III only
d
I and III only
e
III only
Submit
Incorrect
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A×A

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x∣y. For this relation, note that

  • the symbols R and ∣ are interchangeable, and

  • the symbols R and ∤ are also interchangeable.

With that in mind, let's examine our statements in turn:

  • Statement I is false. Replacing R with the symbol ∣, we have 3∣16, which is false.

  • Statement II is true. Replacing R with the symbol ∤, we have 4∤7, which is true.

  • Statement III is true. Replacing R with the symbol ∣, we have 5∣20, which is true.

Therefore, the correct answer is "II and III only."
