We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have XRY if and only if X⊆Y. For this relation, note that

  • the symbols R and ⊆ are interchangeable, and

  • the symbols R and ⊈ are also interchangeable.

With that in mind, let's examine our statements in turn.

  • Statement I is false. Replacing R with the symbol ⊆, we have N0⊆N, which is false.

  • Statement II is true. Replacing R with the symbol ⊆, we have N⊆R0+, which is true.

  • Statement III is false. Replacing R with the symbol ⊈, we have R0+⊈R0+, which is false.

Therefore, the correct answer is "II only."
