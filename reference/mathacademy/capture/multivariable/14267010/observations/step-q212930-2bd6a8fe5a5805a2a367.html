Consider the following set: A={∅,Q,R+}

Given the relation R on A defined by XRY⇔X⊂Y, which of the following statements are true?

  1. ∅RR+
  2. QRQ
  3. R+RQ
a
I only
b
I and III only
c
I, II, and III
d
III only
e
II only
Submit
Correct
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A2

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have XRY if and only if X⊂Y. For this relation, note that

  • the symbols R and ⊂ are interchangeable, and

  • the symbols R and ⊄ are also interchangeable.

With that in mind, let's examine our statements in turn.

  • Statement I is true. Replacing R with the symbol ⊂, we have ∅⊂R+, which is true.

  • Statement II is false. Replacing R with the symbol ⊂, we have Q⊂Q, which is false.

  • Statement III is true. Replacing R with the symbol ⊄, we have R+⊄Q, which is true.

Therefore, the correct answer is "I and III only."
