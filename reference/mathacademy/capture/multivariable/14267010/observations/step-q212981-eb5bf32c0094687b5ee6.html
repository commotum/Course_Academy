Consider the following set: A={Q+,Q−,Q}

Given the relation R on A defined by XRY⇔Y⊇X∪Y, which of the following statements are true?

  1. Q+RQ−
  2. Q−RQ
  3. QRQ+
a
I, II, and III
b
I and II only
c
II only
d
I only
e
II and III only
Submit
Incorrect
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A2

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have XRY if and only if Y⊇X∪Y.

With that in mind, let's examine our statements in turn.

  • Statement I is false. In this case, we have Q−⊇Q+∪Q−. This is equivalent to Q+∪Q−⊆Q−, which is false.

  • Statement II is true. In this case, we have Q⊇Q−∪Q. This is equivalent to Q−∪Q⊆Q, which is true.

  • Statement III is true. In this case, we have Q+⊉Q∪Q+. This is equivalent to Q∪Q+⊈Q+, which is true.

Therefore, the correct answer is "II and III only."
