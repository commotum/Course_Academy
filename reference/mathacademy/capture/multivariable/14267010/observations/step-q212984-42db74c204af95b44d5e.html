Given the relation R on Z defined by xRy⇔x≡y−1(mod7), which of the following statements are true?

  1. 0R8
  2. 3R2
  3. 1R(−5)
a
I and II only
b
II and III only
c
III only
d
II only
e
I only
Submit
Incorrect
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A×A

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x≡y−1(mod7), or equivalently, xRy if and only if 7∣(x−y+1).

With that in mind, let's examine our statements in turn:

  • Statement I is true. In this case, we have 7∣(0−8+1), which is true.

  • Statement II is false. In this case, we have 7∣(3−2+1), which is false.

  • Statement III is false. In this case, we have 7∤(1−(−5)+1), which is false.

Therefore, the correct answer is "I only."
