Let's denote:

  • P(n): n2 is odd

  • Q(n): n is odd

Then, the given sentence has the following logical structure: P(n)⇒Q(n)

This, in turn, is equivalent to ∀n∈U,P(n)⇒Q(n) where the universal set U is usually apparent from the context. In this case, n∈N.

Therefore, using formal language, our statement reads

For all natural number n, if n2 is odd, then n is odd.

Or, more formally:

∀n∈N, (n2 is odd) ⇒ (n is odd)
