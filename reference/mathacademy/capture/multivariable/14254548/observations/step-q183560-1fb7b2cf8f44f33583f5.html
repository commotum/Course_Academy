The square of a number is a non-negative number.

Express the above in formal language.

a
∃x∈R,∀y∈R0+,x2=y
b
∀x∈R,∃y∈R0+,x=y2
c
∃x∈R,∀y∈R0+,x=y2
d
∀x∈R,∀y∈R0+,x2=y
e
∀x∈R,∃y∈R0+,x2=y
Submit
Correct
EXPLANATION

Notice that our sentence can be re-phrased as

For any real number x, we have that x2 is a non-negative number.

Now, "x2 is a non-negative number" means that

There exists a non-negative number y such that x2=y.

Therefore, we get the following statement:

For any real number x, there exists a non-negative number y such that x2=y.

More formally, this reads as

∀x∈R,∃y∈R0+,x2=y.
