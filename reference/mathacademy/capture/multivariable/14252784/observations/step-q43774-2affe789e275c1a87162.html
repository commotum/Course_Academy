Consider the vector space C[0,1] of all continuous functions f:[0,1]→R and its subset D={f∈C[0,1]|f(0)=3}.

Which of the following statements are true?

  1. D is closed under function addition
  2. D is closed under scalar multiplication
  3. D is a subspace of C[0,1]
  4. D is not a subspace of C[0,1]
a
I, II, and III only
b
II and IV only
c
II only
d
I and IV only
e
IV only
Submit
Correct
EXPLANATION

Recall that a subset of a vector space is a subspace if it's closed under addition and scalar multiplication.

With that in mind, let's examine each statement in turn.

  • Statement I is false. For example, if f(x),g(x)∈D, then (f+g)(0)=f(0)+g(0)=3+3=6≠3 So, D is not closed under addition.

  • Statement II is false. For example, if f(x)∈D and k=5∈R, then (kf)(0)=(5f)(0)=5⋅3=15≠3 So, D is not closed under scalar multiplication.

  • Statement III is false, while statement IV is true. D is not a subspace because it's not closed under addition and scalar multiplication.

Therefore, the correct answer is "IV only."
