Which of the following is equivalent to ∫Cds, where C is the path along the polar curve r=sec3⁡θ for −π/2≤θ≤π/2 ?

a
∫0πsec2⁡θtan2⁡θdθ
b
∫−π/2π/2sec3⁡θ1+9tan2⁡θdθ
c
∫0πsec3⁡θ1+tan2⁡θdθ
d
∫−π/2π/2sec3⁡θ9+tan2⁡θdθ
e
2∫0πsec3⁡θ1+sec2⁡θdθ
Submit
Correct
EXPLANATION

The line integral of unity with respect to arc length over C is equal to the arc length L of C, i.e., ∫Cds=L.

In polar coordinates, the arc length element ds is given by

ds=r2+(drdθ)2dθ.

So, for a polar curve defined as r=r(θ) for θ1≤θ≤θ2, we have

L=∫Cds=∫θ1θ2r2+(drdθ)2dθ.

Since r=sec3⁡θ we have
drdθ=3sec3⁡θtan⁡θ.

Therefore, the expression for our line integral is

∫Cds=∫θ1θ2r2+(drdθ)2dθ=∫−π/2π/2(sec3⁡θ)2+(3sec3⁡θtan⁡θ)2dθ=∫−π/2−π/2sec6⁡θ+9sec6⁡θtan2⁡θdθ=∫−π/2π/2sec6⁡θ(1+9tan2⁡θ)dθ=∫−π/2π/2sec3⁡θ1+9tan2⁡θdθ.
