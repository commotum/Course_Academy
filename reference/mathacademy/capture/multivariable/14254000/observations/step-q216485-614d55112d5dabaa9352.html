Question 8
?

P(x): x≥1⇒1x≤1.

Given that the above predicate is defined over the universal set R+, which of the following statements are true?

  1. The truth set of P(x) is ∅.
  2. The truth set of P(x) is R+.
  3. ∀x∈R+,P(x).
a
II only
b
None of the statements are true
c
I only
d
III only
e
II and III only
Submit
Correct
EXPLANATION

The universal quantification of a predicate P(x), defined over the universal set U, transforms this predicate into a statement that we write as ∀x∈U,P(x). This statement is true if the predicate P(x) is true on the entire universal set U, i.e. if the truth set TP of the predicate coincides with the universal set U: TP=U

First, notice that:

  • the truth set of "x≥1" is [1,∞), and

  • the truth set of "1x≤1" is [1,∞).

Since A⇒B≡¬A∨B, the truth set of our predicate is TP=[1,∞)―∪[1,∞)=(0,1)∪[1,∞)=R+.

With that in mind, let's inspect each of the given statements.

  • Statement I is false. The truth set is not empty.

  • Statement II is true. Indeed, TP=R+.

  • Statement III is true. Since TP coincides with the universal set, the statement ∀x∈R+,P(x) is true.

Therefore, the correct answer is "II and III only."
