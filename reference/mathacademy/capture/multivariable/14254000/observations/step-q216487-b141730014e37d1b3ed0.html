I(m): 3m is prime

Given the predicate above, which of the following expresses the statement ∃m∈N,I(m)?

a
There exists a prime number m∈N such that 3m∈N.
b
For all m∈N,3m is not prime.
c
For all prime numbers m∈N,3m∈N.
d
There exists m∈N such that 3m is prime.
e
For all m∈N,3m is prime.
Submit
Correct
EXPLANATION

The existential quantifier "∃" means "there exists." So, the statement ∃m∈N,I(m) reads as follows:

There exists m∈N such that 3m is prime.

Note: This statement is true because 31=3 is a prime number.
