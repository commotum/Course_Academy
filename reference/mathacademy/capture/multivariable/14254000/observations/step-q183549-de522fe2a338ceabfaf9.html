P(z): z<1

Given that the above predicate is defined over the universal set N, which of the following statements are true?

  1. The truth set of P(z) is ∅.
  2. The truth set of P(z) is N.
  3. ∃z∈N,P(z).

Correct
EXPLANATION

The existential quantification of a predicate P(x), defined over the universal set U, transforms this predicate into a statement that we write as ∃x∈U,P(x). This statement is true if the predicate P(x) is true for a single element x∈U, i.e. if the truth set TP of the predicate is not empty: TP≠∅

First, notice that the truth set of our predicate is

TP=∅.

With that in mind, let's inspect each of the given statements.

  • Statement I is true. The truth set is empty.

  • Statement II is false. Indeed, TP≠N.

  • Statement III is false. Since TP is empty, the statement ∃z∈N,P(z) is false.

Therefore, the correct answer is "I only."
