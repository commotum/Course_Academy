P(a): a∈N and a is even

Given that the above predicate is defined over the universal set Q, which of the following statements are true?

  1. The truth set of P(a) is ∅.
  2. The truth set of P(a) is Q.
  3. ∃a∈Q,P(a).

III only

None of the statements are true.

e

Correct
EXPLANATION

The existential quantification of a predicate P(x), defined over the universal set U, transforms this predicate into a statement that we write as ∃x∈U,P(x). This statement is true if the predicate P(x) is true for a single element x∈U, i.e. if the truth set TP of the predicate is not empty: TP≠∅

First, notice that:

  • the truth set of "a∈N" is N and

  • the truth set of "a is even" is the set of all even integers.

So, the truth set of our predicate is

TP=N∩{even integers}={even naturals}.

With that in mind, let's inspect each of the given statements.

  • Statement I is false. The truth set is not empty.

  • Statement II is false. Indeed, TP≠Q.

  • Statement III is true. Since TP is not empty, the statement ∃a∈Q,P(a) is true.

Therefore, the correct answer is "III only."
