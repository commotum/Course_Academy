∀n∈Z,2n is even

Which of the following expresses the statement given above?

a
Double any real number is an even number.
b
Double every even integer is even.
c
Consider some integer whose double is even.
d
 There exists some integer whose double is even.
e
Double any integer is an even number.
Submit
Correct
EXPLANATION

The universal quantifier "∀" means "for all." So, our quantified statement reads as follows:

For all n∈Z,2n is even.

This can be further simplified as follows:

Double any integer is an even number.

Note: This statement is true.
