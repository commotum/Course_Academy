P(y): y2>9⇒y>0

Given that the above predicate is defined over the universal set R, which of the following statements are true?

  1. The truth set of P(y) is ∅.
  2. The truth set of P(y) is R.
  3. ∃y∈R,P(y).
a

b
I only
c

Incorrect
EXPLANATION

The existential quantification of a predicate P(x), defined over the universal set U, transforms this predicate into a statement that we write as ∃x∈U,P(x). This statement is true if the predicate P(x) is true for a single element x∈U, i.e. if the truth set TP of the predicate is not empty: TP≠∅

First, notice that:

  • the truth set of "y2>9" is the set (−∞,−3)∪(3,∞), and

  • the truth set of "y>0" is R+.

Since A⇒B≡¬A∨B, the truth set of our predicate is

TP=(−∞,−3)∪(3,∞)―∪R+=[−3,3]∪R+=[−3,∞).

With that in mind, let's inspect each of the given statements.

  • Statement I is false. The truth set is not empty.

  • Statement II is false. Indeed, TP≠R.

  • Statement III is true. Since TP is not empty, the statement ∃y∈Z,P(y) is true.

Therefore, the correct answer is "III only."
