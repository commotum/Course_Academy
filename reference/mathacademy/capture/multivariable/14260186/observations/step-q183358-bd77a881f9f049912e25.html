Consider the following predicates.

A(x): x∈Z∖N0. B(x): x∈Z−.

Which of the following is equivalent to the biconditional predicate A(x)⇔B(x)?

  1. x∈Z∖N0 if and only if x∈Z−.
  2. If x∈Z∖N0 then x∈Z−, or if x∈Z− then x∈Z∖N0.
  3. x∈Z∖N0 is equivalent to x∈Z−.
a
I, II, and III
b
I and III only
c
I and II only
d
II and III only
e
I only
Submit
Correct
EXPLANATION

A biconditional expression P⇔Q≡(P⇒Q)∧(Q⇒P) can be read as shown below:

  • P if and only if Q

  • P is equivalent to Q

  • If P then Q, and if Q then P

So, A⇔B translates into the following sentences:

  • x∈Z∖N0 if and only if x∈Z−.

  • x∈Z∖N0 is equivalent to x∈Z−.

  • If x∈Z∖N0 then x∈Z−, and if x∈Z− then x∈Z∖N0.

Therefore, the correct answer is "I and III only."
