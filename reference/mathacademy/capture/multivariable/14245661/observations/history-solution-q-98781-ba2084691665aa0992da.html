We can classify the equilibrium solutions of an autonomous ODE y′=f(y) by examining its phase line.

  • An equilibrium solution is a sink if the arrows directly above and below it on the phase line both point toward the equilibrium solution.

  • An equilibrium solution is a source if the arrows directly above and below it on the phase line both point away from the equilibrium solution.

  • An equilibrium solution is a node if the arrows directly above and below it on the phase line point in the same direction.
