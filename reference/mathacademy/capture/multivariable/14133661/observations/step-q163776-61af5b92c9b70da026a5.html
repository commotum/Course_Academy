Given that the eigenvalues of f″(a) are λ1=1−5 and λ2=1+5, what type of point is a?

Correct
EXPLANATION

The point a∈Rn is a critical point of the function f:Rn→R if f′(a)=0T. In such cases, we can classify a as follows:

  • if f″(a) is positive definite, then a is a local minimum

  • if f″(a) is negative definite, then a is a local maximum

  • if f″(a) is neither positive-definite nor negative-definite, then a is a saddle point

The quadratic Taylor expansion of a function f:Rn→R about x=a∈Rn given by

f(x)≈f(a)+f′(a)(x−a)+12(x−a)Tf″(a)(x−a).

Since the quadratic Taylor expansion of f has no (x−a) term, we can conclude that f′(a)=0T. Hence, a is a critical point of f.

Finally, notice that f″(a) has both negative and positive eigenvalues: λ1=1−5<0λ2=1+5>0 So, the matrix is neither positive-definite nor negative-definite. Therefore, a is a saddle point of f.
