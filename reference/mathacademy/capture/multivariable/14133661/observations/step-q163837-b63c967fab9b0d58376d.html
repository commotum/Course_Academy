EXPLANATION

First, we recall the following definitions:

  • The global minimum of a function is the smallest value it attains on its domain. There can only be (at most) one global minimum.

  • A global minimum point is a point (x,y,z) where a function reaches a global minimum. There can be zero, one, or many global minimum points.

For our function, the minimum value reached by the function is f(x,y)=−5. Therefore, the global minimum is −5. The function reaches this value at (x,y)=(0,3).
