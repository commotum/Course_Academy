Whenever and Provided That
?

Implication also can be written using "whenever" and "provided" as follows:

  • Whenever then

  • whenever

  • provided that

Let's again go through each one and convince ourselves that they're all equivalent to Again, we assume that is true in each case.

  • Whenever then Whenever is true, is guaranteed to be true.

  • whenever is guaranteed to be true whenever is true.

  • provided that is guaranteed to be true provided that is true.
