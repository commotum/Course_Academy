Which of the following is NOT a grammatical construction for the biconditional P⇔Q?

a
P implies Q
b
If P then Q, and conversely
c
P if and only if Q
d
P is equivalent to Q
e
P is necessary and sufficient for Q
Submit
Correct
EXPLANATION

Let's recall the following grammatical constructions for the biconditional P⇔Q:

  • P if and only if Q

  • P iff Q

  • P is necessary and sufficient for Q

  • P is equivalent to Q

  • If P then Q, and conversely

From the given options, the only one that is NOT a grammatical construction for P⇔Q is "P implies Q" (this is the grammatical construction of P⇒Q).
