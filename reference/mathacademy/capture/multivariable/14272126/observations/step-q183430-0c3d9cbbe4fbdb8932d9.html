EXPLANATION

Let's recall the following grammatical constructions for the implication P⇒Q:

  • If P, then Q

  • P only if Q

  • Q if P

  • P implies Q

With that in mind, let's examine the given options.

  • Option I reads ifx∈Z⏟Q(x),thenx∈N⏟P(x) which corresponds to Q(x)⇒P(x). ×

  • Option II reads x∈Z⏟Q(x)ifx∈N⏟P(x) which corresponds to P(x)⇒Q(x). ✓

  • Option III reads x∈N⏟P(x)impliesx∈Z⏟Q(x) which corresponds to P(x)⇒Q(x). ✓

  • Option IV reads x∈N⏟P(x)only ifx∈Z⏟Q(x) which corresponds to P(x)⇒Q(x). ✓

Therefore, the correct answer is "II, III and IV only."
