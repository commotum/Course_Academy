EXPLANATION

Given that the implication S⇒N is true, we have the following:

  • S is a sufficient condition for N.

  • N is a necessary condition for S.

These ideas can be summarized as follows:

Sufficient⇒Necessary.

We have the following grammatical constructions for S⇒N:

  • S is sufficient for N

  • For N, it is sufficient that S

  • N is necessary for S

  • For S, it is necessary that N

Let's now compare these against the entries in our table:

  • "B is sufficient for A" means B⇒A.

  • "For B, it is sufficient that A" means A⇒B.

  • "A is necessary for B" means B⇒A.

  • "For A, it is necessary that B" means A⇒B.
