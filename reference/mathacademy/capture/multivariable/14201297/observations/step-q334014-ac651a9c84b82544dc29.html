For which of the following step sizes is Euler's Method unstable, given that λ is the parameter of the test equation y′=−λy with y=y(x),y(0)=1,x≥0,λ>0, and step size Δx?

  1. Δx=2.2λ
  2. Δx=0.4λ
  3. Δx=2λ
  4. Δx=5λ
Hint: The stability function for Euler's method is given by R(λΔx)=1−λΔx.

a

EXPLANATION

A numerical method yn+1=yn+Δyn is stable for a given step size Δx if, when applied to the test equation y′=−λy,y(0)=1,x≥0,λ>0, the numerical solution satisfies yn→0 as n→∞, just like the exact solution.

For stability, we require that the following condition holds:

|R(λΔx)|<1|1−λΔx|<1

Solving this gives 0<λΔx<2.

This means that Euler's method is stable when applied to the test equation for values in the region 0<λΔx<2.

Now, we consider each step size in turn.

  • For Δx=2.2λ, we have λΔx=2.2≥2. Since this value falls outside the given region, Euler's method is not stable (or unstable) for this step size.

  • For Δx=0.4λ, we have λΔx=0.4. Since this value falls within the given region, 0<λΔx<20<0.4<2, Euler's method must be stable for this step size.

  • For Δx=2λ, we have λΔx=2≥2. Since this value falls outside the given region, Euler's method is not stable (or unstable) for this step size.

  • For Δx=5λ, we have λΔx=5≥2. Since this value falls outside the given region, Euler's method is not stable (or unstable) for this step size.

Therefore, the correct answer is "I, III, and IV only".
