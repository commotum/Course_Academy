A numerical method yn+1=yn+Δyn is stable for a given step size Δx if, when applied to the test equation y′=−λy,y(0)=1,x≥0,λ>0, the numerical solution satisfies yn→0 as n→∞, just like the exact solution.

When a method is applied to the test equation, the update takes the form yn+1=R(λΔx)yn, where R(λΔx) is referred to as the stability function of the method. The set of values for which the method is stable, given by |R(λΔx)|<1, is called the stability region of the method.

The stability function of the modified Euler method is R(λΔx)=1−λΔx+(λΔx)22.

  • For λΔx=1.1, we have |R(1.1)|=|1−1.1+(1.1)22|=|101200|=0.505<1.✓ Since this value falls within the stability region, the modified Euler method is stable.

  • For λΔx=1.7, we have |R(1.7)|=|1−1.7+(1.7)22|=|149200|=0.745<1.✓ Since this value falls within the stability region, the modified Euler method is stable.

  • For λΔx=2.9, we have |R(2.9)|=|1−2.9+(2.9)22|=|461200|=2.305>1.× Since this value falls outside the stability region, the modified Euler method is unstable.

Note that the stability region of the modified Euler method is 0<λΔx<2, so it is not absolutely stable.
