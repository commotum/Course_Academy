EXPLANATION

Recall the following facts regarding the congruence ax≡b(modn):

  • The congruence has no solutions modulo n if and only if gcd(a,n)⧸|b.

  • The congruence has gcd(a,n) solutions modulo n if and only if gcd(a,n)|b.

With that in mind, let's examine our congruences.

  • Congruence I has no solutions. We have a=20 and n=24, and so gcd(a,n)=gcd(20,24)=4. Since b=6 is not divisible by 4, this congruence has no solutions.

  • Congruence II has eight solutions modulo 24. We have a=16 and n=24, and so gcd(a,n)=gcd(16,24)=8. Since b=8 is divisible by 8, this congruence has 8 solutions.

  • Congruence III has four solutions modulo 24. We have a=28 and n=24, and so gcd(a,n)=gcd(28,24)=4. Since b=8 is divisible by 4, this congruence has 4 solutions.

Therefore, the correct answer is "III only".
