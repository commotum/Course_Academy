Given that A=QR is a QR factorization of an 8×4 matrix A with linearly independent columns, which of the following statements are true?

  1. Q is an 8×4 matrix
  2. R is an 8×8 matrix
  3. R is an upper triangular matrix
a
I and II only
b
III only
c
I and III only
d
II only
e
I only
Submit
Incorrect
EXPLANATION

Recall that if A=QR is a QR factorization of an m×n matrix A, then

Am×n=Qm×n×Rn×n,

where

  • Q is an m×n matrix whose columns form an orthonormal basis of Col(A)

  • R is an n×n upper triangular matrix

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, Q must be an 8×4 matrix.

  • Statement II is false. R should be a 4×4 matrix.

  • Statement III is true. Indeed R must be an upper triangular matrix.

Therefore, the correct answer is "I and III only."
