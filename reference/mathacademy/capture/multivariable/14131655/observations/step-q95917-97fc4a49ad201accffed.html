Given that A=QR is a QR factorization of a 4×2 matrix A with linearly independent columns, which of the following statements are true?

  1. Q is a 4×2 upper triangular matrix
  2. The columns of Q are unit vectors
  3. R is a 4×2 matrix
a
II and III only
b
I only
c
II only
d
I and II only
e
III only
Submit
Correct
EXPLANATION

Recall that if A=QR is a QR factorization of an m×n matrix A, then

Am×n=Qm×n×Rn×n,

where

  • Q is an m×n matrix whose columns form an orthonormal basis of Col(A)

  • R is an n×n upper triangular matrix

With that in mind, let's examine our statements.

  • Statement I is false. Q should be a 4×2 matrix, but is not necessarily upper triangular.

  • Statement II is true. Since the columns of Q form an orthonormal basis, they are unit vectors.

  • Statement III is false. R must be a 2×2 matrix.

Therefore, the correct answer is "II only."
