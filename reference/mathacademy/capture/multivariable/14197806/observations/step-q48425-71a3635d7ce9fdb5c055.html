Consider the function f(x)=x3 which is defined and continuous on the closed interval [0,8]. By filling the blank spaces in the sentence below, complete the statement of the intermediate value theorem:

If k is a number that lies between  ________  inclusively, then there exists a number c∈[0,8] such that f(c)=k.

a
0 and 8
b
0 and 2
c
0 and 16
d
0 and 1
e
0 and 4
Submit
Correct
EXPLANATION

The function f(x) is continuous on [0,8], so the intermediate value theorem guarantees that f(x)=k has a solution for each value of k between f(0) and f(8).

Since f(0)=0 and f(8)=2, we must have k∈[0,2].

Therefore, the missing part is "0 and 2".
