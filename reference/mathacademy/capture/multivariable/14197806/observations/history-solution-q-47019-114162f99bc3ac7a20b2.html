The function is discontinuous at the values of x which make the denominator equal to zero.

Setting the denominator equal to zero, we have x−1=0, which corresponds to x=1.

We conclude that the intermediate value theorem can be applied to the function f(x) only on closed intervals that do not contain the point x=1.
