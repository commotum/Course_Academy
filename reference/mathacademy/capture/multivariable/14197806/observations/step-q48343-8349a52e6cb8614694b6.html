EXPLANATION

The intermediate value theorem states the following.

Let f(x) be a function that is continuous on a closed interval [a,b]. If k is a number that lies between f(a) and f(b) inclusively, then there exists a number c∈[a,b] such that f(c)=k.

Therefore, the correct answer is "II, III".
