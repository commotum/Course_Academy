Consider the vector space C[0,1] of all continuous functions f:[0,1]→R and its subset K containing all nonconstant functions.

Which of the following statements are true?

  1. K is closed under function addition
  2. K is closed under scalar multiplication
  3. K is a subspace of C[0,1]
  4. K is not a subspace of C[0,1]
Hint: f is a constant function if f(x)=constant for all x∈[0,1].

a
II and IV only
b
I only
c
I, II, and III only
d
I and IV only
e
IV only
Submit
Correct
EXPLANATION

Recall that a subset of a vector space is a subspace if it's closed under addition and scalar multiplication.

With that in mind, let's examine each statement in turn.

  • Statement I is false. For example, the functions f(x)=x+2 and f(x)=−x−1 are in K, however (f+g)(x)=1 for all x∈[0,1] and hence f+g is a constant function. So, K is not closed under addition.

  • Statement II is false. For example, the product of the scalar zero by any function is the constant function zero. So, K is not closed under scalar multiplication.

  • Statement III is false, while statement IV is true. K is not a subspace because it's not closed under addition and scalar multiplication.

Therefore, the correct answer is "IV only."
