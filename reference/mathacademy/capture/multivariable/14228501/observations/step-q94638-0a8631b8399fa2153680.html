Consider the vector space C[0,3] of all continuous functions f:[0,3]→R and its subset N containing all functions that return a nonzero value at exactly one point in [0,3].

Which of the following statements are true?

  1. N is closed under function addition
  2. N is closed under scalar multiplication
  3. N is a subspace of C[0,3]
  4. N is not a subspace of C[0,3]
Hint: Different functions from N might give a nonzero value at different points in [0,3].

a
I only
b
IV only
c
I, II, and III only
d
I and IV only
e
II and IV only

Incorrect
EXPLANATION

Recall that a subset of a vector space is a subspace if it's closed under addition and scalar multiplication.

With that in mind, let's examine each statement in turn.

  • Statement I is false. For example, if f(a1)≠0 and g(a2)≠0, where a1,a2 are distinct points in [0,3], then f(a1)+g(a1)≠0f(a2)+g(a2)≠0. Therefore, f(x)+g(x)≠0 at two distinct points. So, N is not closed under addition.

  • Statement II is false. For example, if f(a)≠0 for some a∈[0,3], and k=0, then kf(x)=0 for any x∈[0,3]. So, N is not closed under scalar multiplication.

  • Statement III is false, while statement IV is true. N is not a subspace because it's not closed under addition and scalar multiplication.

Therefore, the correct answer is "IV only."
