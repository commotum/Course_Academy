EXPLANATION

First, we recall the following:

  • If v′(t)=0 for all t∈(a,b), then v(t) is constant on (a,b).

  • When v′(t)>0 for all t∈(a,b), then v(t) is increasing on (a,b).

  • When v′(t)<0 for all t∈(a,b), then v(t) is decreasing on (a,b).
