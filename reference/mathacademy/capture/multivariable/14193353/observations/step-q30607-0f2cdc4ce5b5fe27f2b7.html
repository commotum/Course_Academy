EXPLANATION

First, we recall the following:

  • If h′(t)=0 for all t∈(a,b), then h(t) is constant on (a,b).

  • When h′(t)>0 for all t∈(a,b), then h(t) is increasing on (a,b).

  • When h′(t)<0 for all t∈(a,b), then h(t) is decreasing on (a,b).

From the above graph, we can see that h′(t) is positive on the intervals [0,3) and (6,9]:
