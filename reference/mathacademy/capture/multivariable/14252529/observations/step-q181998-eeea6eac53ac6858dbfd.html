What are the minimum and maximum of the set C=[2,7]?
min(C)=
√2
max(C)=
7
Submit
Correct
EXPLANATION

Recall that

  • xmax is the maximum of a set S if xmax∈S and x≤xmax for all x∈S, and

  • xmin is the minimum of a set S if xmin∈S and xmin≤x for all x∈S.

Therefore, we have the following:

min(C)=min[2,7]=2max(C)=max[2,7]=7
