Complete the following reasoning about the set S=(−∞,−2):

The value −2 is not the maximum of the set S because
−3≤−2
−3≤−2
−2∉S
−2<∞
−2∈S
−1≥−2
−1∉S
.
Submit
Incorrect
EXPLANATION

Recall that xmax is the maximum of a set S if

  • xmax∈S, and

  • x≤xmax for all x∈S.

In our case, the value −2 is not the maximum of the set S because −2∉S.
