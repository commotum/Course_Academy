32.Approximating the Solution to an Initial Value Problem Using The ABM 2-Step Method?

Consider the following initial value problem: y′=2x−2y−3,y(0)=1 To approximate the solution, one step of the Runge-Kutta method has already been computed, resulting in the following estimate: y(1)≈0 Use the 2-Step Adams-Bashforth-Moulton Method with one step to approximate y(2).

Hint: The corrector equation of the two-step Adams-Bashforth-Moulton method is defined as Δy=112(5yp′+8y′−y−1′)⋅Δx where yp denotes the predictor at the current step, and y−1′ is the estimated slope at the previous point.
