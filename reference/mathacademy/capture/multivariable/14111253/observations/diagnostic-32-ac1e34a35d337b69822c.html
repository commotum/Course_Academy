EXPLANATION

For an initial value problem y′=f(x,y),y(a)=c, the 2-Step Adams-Bashforth-Moulton (ABM 2-step) Method with step size Δx is given by Predictor:Δyp=12(3y′−y−1′)⋅Δx,Corrector:Δy=112(5yp′+8y′−y−1′)⋅Δx, where

  • y′=f(x,y) is the estimated slope at the current point (x,y),

  • y−1′=f(x−1,y−1) is the estimated slope at the previous point (x−1,y−1), and

  • yp′=f(xnew,yp) is the estimated slope at the predicted new point (xnew,yp)=(x+Δx,y+Δyp).

Before we start, let's add the initial condition data and Runge-Kutta step data to a table.

x y y′ Δyp yp yp′ Δy
0 1 − − − −
1 0

Now, since we want to find the value of y at x=2, we will use a step size of Δx=2−1=1.

First, we compute the values of y′ at each point according to the given rule:

  • The slope at the previous point (x−1,y−1)=(0,1) is y−1′=2x−1−2y−1−3=2⋅0−2⋅1−3=−5.

  • The slope at the current point (x,y)=(1,0) is y′=2x−2y−3=2⋅1−2⋅0−3=−1.

We add these values to our table.

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1

Next, we compute Δyp using the predictor equation:

Δyp=12(3y′−y−1′)⋅Δx=12(3⋅(−1)−(−5))⋅1=1.

We add this to our table.

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1 1

So, the coordinates of the predicted new point are xnew=x+Δx=1+1=2,yp=y+Δyp=0+1=1.

Let's add the second value to the table.

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1 1 1

Hence, the slope at this predicted point is yp′=2xnew−2yp−3=2⋅2−2⋅1−3=−1.

We can add this to our table.

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1 1 1 −1

Finally, we compute Δy using the corrector equation:

Δy=112(5yp′+8y′−y−1′)⋅Δx=112(5⋅(−1)+8⋅(−1)−(−5))⋅1=112⋅(−8)=−23.

We add this to our table.

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1 1 1 −1 −23

The value of x in the next row is xnew=2. To get the value of y in the next row, we add Δy to y: ynew=y+Δy=0+(−23)=−23.

Adding these results to our table gives the following:

x y y′ Δyp yp yp′ Δy
0 1 −5 − − − −
1 0 −1 1 1 −1 −23
2 −23

Therefore, we conclude that y(2)≈−23.
