EXPLANATION

The streamlines of a vector field are the level curves of its stream function and are tangential to the vector field at every point.

If F represents the velocity field of a fluid flow, then they show the path traced out by a massless particle as it moves with the flow.

A vector field F=Pi+Qj with a simply connected domain D⊆R2 has a stream function ψ(x,y) if and only if ∂P∂x+∂Q∂y=0.

Note that F(x,y)=2xi−2yj is a vector field with simply connected domain D, where P(x,y)=2x and Q(x,y)=−2y. Computing the partial derivatives, we have

∂P∂x=2,∂Q∂y=−2.

Hence, F has a stream function, since

∂P∂x+∂Q∂y=2−2=0.

Next, we find a stream function. A function ψ(x,y) is a stream function of the vector field F=Pi+Qj if

P=∂ψ∂y,Q=−∂ψ∂x.

In our case, we have ∂ψ∂y=2x,∂ψ∂x=2y.

Integrating these equations, we obtain the following:

ψ(x,y)=2xy+f(x),ψ(x,y)=2xy+g(y)

where f and g are arbitrary functions. Finally, setting f=g=0, we have

ψ(x,y)=2xy.

Finally, we find the level curves of the stream function ψ(x,y)=2xy given by the equations ψ(x,y)=c.

Notice that the range of ψ(x,y) is (−∞,∞). So, we will consider level curves for any value of c. So, we have:

ψ(x,y)=c2xy=cy=cx
