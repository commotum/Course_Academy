Suppose the following data are sampled from a population.

2.25,3.16,2.65,3.06,2.94

Calculate the value of the statistic median(X1,X2,…Xn) for this particular sample.

a
 3.06
b
 2.65
c
 2.81
d
 3.16
e
2.94
Submit
Correct
EXPLANATION

Suppose X1,X2,…,Xn is a sequence of random variables representing a random sample of size n drawn from a population. A statistic is a random variable expressed as a function of Xi.

Statistics cannot involve unknown population parameters.

Note the following notation:

  • Xi denotes the random variable representing the ith observation in a random sample, and

  • xi is the value of Xi in a specific sample.

To find the median for the given sample, we arrange the data in numerical order: 2.25,2.65,2.94,3.06,3.16

Therefore, we have median(x1,…,x5)=2.94.

Therefore, the value of our statistic for this particular sample is 2.94.
