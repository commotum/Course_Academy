A function is not differentiable wherever it has a discontinuity, corner, cusp, or vertical tangent. * At x=−4 the function has a corner point, so it's not differentiable there. * At x=−2 the function has a jump discontinuity, so it's not differentiable there. Of these two points, f(x) is continuous only at x=−4. Therefore, the function f(x) is continuous but not differentiable at x=−4.
