Which of the following integers has a multiplicative inverse modulo 50?

  1. 10
  2. 33
  3. 45

Incorrect
EXPLANATION

An integer a has a multiplicative inverse modulo n if and only if a and n are coprime, i.e., gcd(a,n)=1.

With this in mind, let's examine the given options.

  • 10 does not have a multiplicative inverse modulo 50 since gcd(10,50)=10≠1.×

  • 33 has a multiplicative inverse modulo 50 since gcd(33,50)=1.✓

  • 45 does not have a multiplicative inverse modulo 50 since gcd(45,50)=5≠1.×

Therefore, the correct answer is "II only."
