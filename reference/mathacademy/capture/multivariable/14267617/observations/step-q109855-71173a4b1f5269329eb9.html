Which of the following subspaces must be orthogonal to Col(XY) for all compatible matrices X and Y?

  1. Null(YTXT)
  2. Col(YTXT)
  3. Null(XY)
a
I and II only
b
I and III only
c
II only
d
III only
e
I only
Submit
Correct
EXPLANATION

Recall that Col(XY) consists of all linear combinations of the columns of XY, that is, the rows of (XY)T=YTXT.

If a vector is orthogonal to every linear combination of the rows of YTXT, it must be orthogonal to each row of YTXT. But notice that when pre-multiplying a vector by YTXT, we actually multiply each row of YTXT by that vector. So, Col(XY) must be orthogonal to the left null space of XY, which is Null(YTXT).

Therefore, the correct answer is "I only."
