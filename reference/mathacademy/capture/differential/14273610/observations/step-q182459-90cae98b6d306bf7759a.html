Run fast, or you won’t catch the bus

Which conditional statement is logically equivalent to the disjunctive statement above?

a
Run fast, and you will catch the bus.
b
If you don't run fast, then you will catch the bus.
c
If you run fast, then you won't catch the bus.
d
If you don't run fast, then you won't catch the bus.
e
If you run fast, then you will catch the bus.
Submit
Correct
EXPLANATION

Let's denote by A and B the following statements:

  • A: Run fast.

  • B: You won’t catch the bus.

Then, our initial statement can be written as A∨B, which is logically equivalent to

¬A⇒B.

The negation of A can be written as

  • ¬A: You don't run fast.

Therefore, the given statement is logically equivalent to the following:

If you don't run fast, then you won't catch the bus.
