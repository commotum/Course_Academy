Correct
EXPLANATION

Suppose we have a geometric sequence with the first term a1 and common ratio r. Then, we have the following convergence properties:

  • if |r|<1, the sequence is convergent and converges to 0

  • if |r|>1, the sequence is divergent

Moreover, we have the following edge cases:

  • if r=1, the sequence is convergent and converges to a1

  • if r=−1, the sequence is divergent

The given sequence an=(43)n is a geometric sequence with the common ratio r=43.

Since |r|>1, the sequence diverges.
