EXPLANATION

We need a vector v=⟨t1,t2,t3⟩ that is parallel to the given plane.

From the equation r⋅⟨−3,1,−2⟩=7 of the plane, we get the normal vector n=⟨−3,1,−2⟩. So, v⊥n and we have the following:

v⋅n=0⟨t1,t2,t3⟩⋅⟨−3,1,−2⟩=0−3t1+t2−2t3=0t2=3t1+2t3

Hence, we obtain v=⟨t1,3t1+2t3,t3⟩, where t1,t3∈(−∞,∞).

We are told that the first component of v equals 0. So, we must set t1=0.

Since v is nonzero, we can pick any t3≠0. For example, setting t3=1, we get

v=⟨0,2,1⟩.

Therefore, bc=2.
