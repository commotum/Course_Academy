Using the cumulative distribution function table of the Poisson random variable X∼Po(3.6) given below, compute P(X≥5).

x 3 4 5 6 7 8 9
P(X≤x) 0.5152 0.7064 0.8441 0.9267 0.9692 0.9883 0.9960
P(X≥5)=
0.2936
Submit
Correct
EXPLANATION

The cumulative distribution function of a discrete random variable X is a function F(x) such that

F(x)=P(X≤x).

To solve the given problem, we can use the rule

P(X>a)=1−P(X≤a)=1−F(a).

Now, note that

P(X≥5)=P(X>4).

Therefore, we have

P(X≥5)=P(X>4)=1−P(X≤4)=1−F(4)=1−0.7064=0.2936.
