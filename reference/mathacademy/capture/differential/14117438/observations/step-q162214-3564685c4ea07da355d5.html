EXPLANATION

Recall that for any affine transformation T:u⟶Au+b, where A is a 2×2 matrix and u and b are 2×1 column vectors, we have one of the following three possibilities:

  • If T is non-singular, i.e., when det(A)≠0, then the image of a two-dimensional object is a two-dimensional object. In particular, the image of a polygon with n vertices is a polygon with n vertices.

  • If T is singular, i.e., when det(A)=0, we have two additional subcases:

    • If A has at least one nonzero entry, then the image of a two-dimensional object is a one-dimensional line segment.

    • If A is the zero matrix, then the image of a two-dimensional object is a point on the plane.

With that in mind, let's examine our transformation.

The given transformation can be expressed as

[xy]=[u−3v+24v−1]=[u−3v4v]+[2−1]=[1−304]⋅[uv]+[2−1].

Notice that the matrix representation of the linear transformation associated with T is A=[1−304].

Computing the determinant of A, we obtain

det(T)=|1−304|=1⋅4−0⋅(−3)=4≠0.

So, we have a non-singular matrix.

Therefore, T is invertible and the image of the triangle under the action of T is a triangle.
