Given that f(x,y,z)=arctan⁡(x+y+z) and ∂f∂x=∂f∂y=∂f∂z=11+(x+y+z)2, find the set of values (x,y,z) on which all partial derivatives of f exist.

a
{(x,y,z):x+y+z≠0}
b
{(x,y,z):x,y,z∈(−∞,∞)}
c
{(x,y,z):x+y+z≠1}
d
{(x,y,z):(x+y+z)2>1}
e

Incorrect
EXPLANATION

First, notice that f(x,y,z)=arctan⁡(x+y+z) is defined for any x, y, and z. So, the domain of f is Df={(x,y,z):x,y,z∈(−∞,∞)}.

As for the partial derivatives, we have the following.

  • The function fx=11+(x+y+z)2 is defined for any x, y, and z. So, the domain of fx is Dfx={(x,y,z):x,y,z∈(−∞,∞)}.

  • Similarly, the domains of fy and fz are Dfy=Dfz={(x,y,z):x,y,z∈(−∞,∞)}.

Therefore, we conclude that the partial derivatives of f exist on the set

Df∩Dfx∩Dfy∩Dfz=Df∩Dfx={(x,y,z):x,y,z∈(−∞,∞)}∩{(x,y,z):x,y,z∈(−∞,∞)}={(x,y,z):x,y,z∈(−∞,∞)}.
