The level curves of the function f(x,y)=4x2−y2 are given by f(x,y)=c. Which of the following statements are true?

  1. c=0 gives two lines
  2. c=1 gives a circle
  3. c=2 gives a hyperbola
a
I and II only
b
I and III only
c
III only
d
I, II and III
e
I only
Submit
Correct
EXPLANATION

Setting f(x,y)=c gives:

4x2−y2=c

Therefore:

  • If c=0 the level curves are y=±2x, which consists of two lines.

  • If c=1 the level curve is 4x2−y2=1, which is a hyperbola.

  • If c=2 the level curve is 2x2−y22=1, which is a hyperbola.

So, only statements I and III are true.
