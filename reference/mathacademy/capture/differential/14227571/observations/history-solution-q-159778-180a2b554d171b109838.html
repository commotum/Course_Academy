Recall that if X=[X1,X2]T is a bivariate normal random vector with mean vector μ and covariance matrix Σ, given by μ=[μ1μ2],Σ=[σ12σ12σ21σ22], then the random variable Y, defined as

Y=aX1+bX2

is a normally distributed random variable for all values of a and b, where

E[Y]=aμ1+bμ2,Var[Y]=a2σ12+b2σ22+2abσ12.

In our case, we have μ1=5 and μ2=1. Therefore, E[Y]=E[X1+3X2]=E[X1]+3E[X2]=μ1+3⋅μ2=5+3⋅1=8.

Also, we have σ12=1,σ22=5, and σ12=σ21=−2. Therefore, Var[Y]=Var[X1+3X2]=12⋅1+32⋅5+2⋅1⋅3⋅(−2)=1+45−12=34.

Therefore, Y∼N(8,34).

Now, we need to compute P(1≤Y≤5). First, transform Y into a standard normal random variable Z by z-scoring: P(1≤Y≤5)=P(1−834≤Z≤5−834)=P(−1.20≤Z≤−0.51)

Now, we express the required probability in terms of Φ(z): P(−1.20≤Z≤−0.51)=P(Z≤−0.51)−P(Z<−1.20)=P(Z≤−0.51)−P(Z≤−1.20)=Φ(−0.51)−Φ(−1.20)

From the table, we have the following: Φ(−1.20)=0.1151Φ(−0.51)=0.3050

Therefore, we have P(−1.20≤Z≤−0.51)=Φ(−0.51)−Φ(−1.20)=0.3050−0.1151=0.1899.

Finally, we conclude that P(1≤Y≤5)=0.1899.
