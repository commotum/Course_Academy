A predicate of the variables x1,x2,…,xn is a sentence that contains the variables defined on some universal set, and has the property that when we substitute concrete values for all the variables into the predicate, the result becomes a statement that is either true or false.

With that in mind, let's examine our options.

  • Option I is a predicate of one variable. Substituting a concrete value for y into the sentence, we get a statement that is either true or false.

  • Option II is not a predicate. Substituting a concrete pair of values (a,b) into the sentence, we do not get a statement that is either true or false.

  • Option III is a predicate of two variables. Substituting a concrete pair of values (x,y) into the sentence, we get a statement that is either true or false.

Therefore, the correct answer is "I and III only."
