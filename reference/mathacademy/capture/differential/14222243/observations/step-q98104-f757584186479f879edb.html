A rectangular box without a lid has a surface area of 48 cm2. Use the method of Lagrange multipliers to find the maximum possible volume of the box.

a
 54 cm3
b
 32 cm3
c
 36 cm3
d
 48 cm3
e
 24 cm3
Submit
Correct
EXPLANATION

Let x,y, and z be the box's length, width, and height, respectively. We wish to maximize the function f(x,y,z)=xyz, subject to the constraint 2xz+2yz+xy=48.

Note that we also have the constraints x>0,y>0,z>0.

Let g(x,y,z)=2xz+2yz+xy. Therefore, by the method of Lagrange multipliers, we must solve the following system: ∇f(x,y,z)=λ∇g(x,y,z),g(x,y,z)=48

We start by solving the first equation:

∇f(x,y,z)=λ∇g(x,y,z)⟨fx(x,y,z),fy(x,y,z),fz(x,y,z)⟩=λ⟨gx(x,y,z),gy(x,y,z),gz(x,y,z)⟩⟨yz,xz,xy⟩=λ⟨2z+y,2z+x,2x+2y⟩

Therefore, we have the following system of equations:

{yz=λ(2z+y)xz=λ(2z+x)xy=λ(2x+2y)

Multiplying the first, second, and third equations by x,y, and z respectively, we get the following:

{xyz=λx(2z+y)xyz=λy(2z+x)xyz=λz(2x+2y)

We cannot have λ=0 since this would give xyz=0, which contradicts the constraints. Therefore, from the first and second equations above, we have x(2z+y)=y(2z+x)2xz+xy=2yz+xyxz=yz

Since z≠0, we can conclude that x=y.

Similarly, from the second and third equations, we get that x=y=2z. So, using the constraint equation, we get 2xz+2yz+xy=484z2+4z2+4z2=4812z2=48z=2.

Therefore, the maximum value of f is reached at the point (4,4,2), and the maximum value is

f(4,4,2)=4⋅4⋅2=32cm3.

Note: It's easy to show that the obtained point is indeed the maximum (and not the minimum). To do that, we could compare the value of the function at this point with the value of the function at any other (arbitrary) point belonging to the domain. For example, f(2,2,5.5)=2⋅2⋅5.5=22<f(4,4,2).
