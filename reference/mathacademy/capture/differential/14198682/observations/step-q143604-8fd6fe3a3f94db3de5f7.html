EXPLANATION

Recall that the marginal distribution for X corresponds to the row totals, and the marginal distribution for Y corresponds to the column totals.

f Y=−2 Y=0 Y=2 Y=4 fX
X=−1 0.05 0.1 0.05 0.1 0.3
X=1 0.1 0.05 0.15 0.05 0.35
X=3 0.05 0.05 0.15 0.1 0.35
fY 0.2 0.2 0.35 0.25 1

Therefore, the probability mass functions for X and Y are given by the following tables:

x −1 1 3
fX(x) 0.3 0.35 0.35

y −2 0 2 4
fY(y) 0.2 0.2 0.35 0.25

Now, we can compute the expected values for X and Y:

E[X]=∑i=1nxifX(xi)=(−1)⋅0.3+1⋅0.35+3⋅0.35=−0.3+0.35+1.05=1.1

E[Y]=∑i=1nyifY(yi)=(−2)⋅0.2+0⋅0.2+2⋅0.35+4⋅0.25=−0.4+0+0.7+1=1.3.

Finally, using the properties of expectation, we obtain

E[2X+4Y]=2E[X]+4E[Y]=2(1.1)+4(1.3)=2.2+5.2=7.4.
