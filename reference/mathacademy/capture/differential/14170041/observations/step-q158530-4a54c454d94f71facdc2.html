EXPLANATION

First, notice that x12≥0. So, we have that

−2x12≥−5x12.

As a result,

Q(x)=−2x12−5x22≥−5x12−5x22=−5(x12+x22).

Now, recall that ‖x‖=1 is equivalent to x12+x22=1. So,

−5(x12+x22)=−5(1)=−5.

and, in turn, Q(x)≥−5.

So, the value of Q(x) can be no smaller than −5. But before we conclude that −5 is the minimum, we need to find a vector such that Q(x)=−5.

Notice that when x=[01]T, we get

Q(x)=−2x12−5x22=−2(0)2−5(1)2=−5.

Therefore, given that ‖x‖=1, the minimum value of Q(x) is equal to −5.
