Compute the gradient of the function f:R2→R defined by
f(x)=xT[130−1]x
with respect to x at x=[10]T.

∇xf=
2
3

Correct
EXPLANATION

Defining the matrix A as
A=[130−1], we have f(x)=xTAx.

Since A is not symmetric, we use the more general formula for the gradient of a quadratic function: ∇xf(x)=(AT+A)x

First, we compute AT=[103−1], which gives AT+A=[103−1]+[130−1]=[233−2].

Now, compute the gradient at x=[10]:

∇xf(x)=(AT+A)x=[233−2][10]=[2+03+0]=[23]
