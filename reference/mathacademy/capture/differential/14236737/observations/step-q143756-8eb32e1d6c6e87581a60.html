Suppose that X is a continuous random variable. For which of the following transformations can the change-of-variables method be applied to find the probability density function of Y?

  1. Y=ln⁡X, where X∈[1,∞)
  2. Y=cos⁡X, where X∈(−π,π)
  3. Y=X3, where X∈(−10,10)
a
II and III only
b
I only
c
II only
d
I and III only
e
I, II, and III
Submit
Incorrect
EXPLANATION

The change-of-variables method can be applied when a transformation Y=u(X) is strictly increasing or strictly decreasing (i.e., strictly monotonic) over the entire support of X.

With that in mind, let's inspect each transformation in turn.

  • Transformation I is strictly monotonic. The function u(x)=ln⁡x is strictly increasing for x∈[1,∞).

  • Transformation II is not strictly monotonic. The function u(x)=cos⁡x is strictly increasing for x∈(−π,0) and strictly decreasing for x∈(0,π).

  • Transformation III is strictly monotonic. The function u(x)=x3 is strictly increasing for x∈(−10,10).

Therefore, the correct answer is "I and III only."
