The change-of-variables method can be applied when a transformation Y=u(X) is strictly increasing or strictly decreasing (i.e., strictly monotonic) over the entire support of X.

With that in mind, let's inspect each transformation in turn.

  • Transformation I is strictly monotonic. The function u(x)=−x is strictly decreasing for x∈[0,1].

  • Transformation II is not strictly monotonic. The function u(x)=−x2 is strictly increasing for x∈(−1,0) and strictly decreasing for x∈(0,1).

  • Transformation III is strictly monotonic. The function u(x)=x4 is strictly decreasing for x∈(−∞,0).

Therefore, the correct answer is "I and III only."
