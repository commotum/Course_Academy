 −7 is integer but not negative.
b
 −7 is integer or negative.

 −7 is integer and negative.

 −7 is negative.

 −7 is integer.

EXPLANATION

First, let's rewrite the phrase "it is integer and negative" as the equivalent phrase "it is integer and it is negative." The sentence now reads

"−7 is integer, and it is integer and it is negative."

Then, using the associative law, we can move the comma:

"−7 is integer and it is integer, and it is negative."

Now, we can simplify the phrase "−7 is integer and it is integer" to just "−7 is integer." The sentence now reads

"−7 is integer, and it is negative."

Finally, we can write the sentence more concisely as

"−7 is integer and negative."
