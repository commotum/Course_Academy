a
III only
b
I only
c
II only
d
I and III only
e
II and III only
Submit
Correct
EXPLANATION

Let's examine the solids one-by-one.

  • I is a polyhedron but it has only 5 faces.

  • II is not a polyhedron (its top and bottom faces are not polygons).

  • III is a polyhedron and it has exactly 7 faces.

b
II and III only
c
II only
d
III only
e
I and II only
Submit
Correct
EXPLANATION

Let's examine the solids one-by-one.

  • I is a polyhedron and it has exactly 6 faces.

  • III is a polyhedron but it has exactly 4 faces.
