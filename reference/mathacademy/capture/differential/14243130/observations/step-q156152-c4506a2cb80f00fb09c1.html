EXPLANATION

Let δ>0. A neighborhood of a point x0∈R is the set of points whose distance from x0 is smaller than δ: {x:|x−x0|<δ}

A neighborhood of x0 is given by the open interval (x0−δ,x0+δ), shown below.

Furthermore, we have the following definitions:

  • A point x0 is an interior point of a set S if S contains some neighborhood of x0. The set of all interior points of S is called the interior of S.

  • A point x0 is a boundary point of a set S if every neighborhood of x0 contains points that are in S and points that are not in S. The set of all boundary points of S is called the boundary of S.

With that in mind, let's examine the statements in turn.

  • Statement I is false. Indeed, A is not an interior point of M since any neighborhood of A contains at least one point outside the set.
  • Statement II is true. The point B is an interior point since there exists an open neighborhood of B that is fully contained inside the set M.
  • Statement III is true. The point C is a boundary point because every open neighborhood of C contains points that belong to M and points that do not belong to M.

Therefore, the correct answer is 'II and III only.'
