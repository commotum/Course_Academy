Consider the set M=(−∞,1) and the points A, B, and C, shown above. Which of the following statements are true?

  2. B is an interior point of the set M
  3. C is a boundary point of the set M

Correct
EXPLANATION

Let δ>0. A neighborhood of a point x0∈R is the set of points whose distance from x0 is smaller than δ: {x:|x−x0|<δ}

A neighborhood of x0 is given by the open interval (x0−δ,x0+δ), shown below.

Furthermore, we have the following definitions:

  • A point x0 is an interior point of a set S if S contains some neighborhood of x0. The set of all interior points of S is called the interior of S.

  • A point x0 is a boundary point of a set S if every neighborhood of x0 contains points that are in S and points that are not in S. The set of all boundary points of S is called the boundary of S.

With that in mind, let's examine the statements in turn.

  • Statement I is true. The point A is an interior point since there exists an open neighborhood of A that is fully contained inside the set M.
  • Statement II is false. The point B is not an interior point of M since any neighborhood of B contains at least one point outside the set.
  • Statement III is false. The point C is not a boundary point since there exists any neighborhood of C that is fully contained outside the set M.

Therefore, the correct answer is 'I only.'
