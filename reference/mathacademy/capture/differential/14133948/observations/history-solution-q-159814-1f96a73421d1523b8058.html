Recall that if X1,X2,…,Xn are independent and identically distributed discrete random variables with probability mass function f(x;θ), where θ is an unknown parameter, then the likelihood function of a random sample x1,x2,…,xn is

L(θ)=P(X1=x1,X2=x2,…,Xn=xn)=∏i=1nf(xi;θ).

In our case, we are given a sample of n=15 independent Bernoulli random variables with unknown parameter θ, for which the probability mass function is

f(x;θ)=θx(1−θ)1−x,x=0,1.

We can calculate the likelihood function as follows:

L(θ)=∏i=1nf(xi;θ)=∏i=1nθxi(1−θ)1−xi=(θx1(1−θ)1−x1)⋅(θx2(1−θ)1−x2)⋯(θxn(1−θ)1−xn)=θ∑xi(1−θ)∑(1−xi)=θ∑xi(1−θ)n−∑xi=θS(1−θ)n−S

where S=∑i=1nxi.

We are told that S=∑i=1nxi=10 and n=15. Therefore,

L(θ)=θ10(1−θ)15−10=θ10(1−θ)5.
