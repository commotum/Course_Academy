First, notice that y=1−x2⟹x=±1−y.

Now, let's sketch our region.

We have the following:

  • Any vertical line through the region intersects it on a single interval. Furthermore, we can represent our region as D={(x,y):−2≤x≤2,−3≤y≤1−x2}. So, this is a type I region.

  • Any horizontal line through the region intersects it on a single interval. Furthermore, we can represent our region as D={(x,y):−3≤y≤1,−1−y≤y≤1−y}. So, this is a type II region.

Therefore, only statements I and II are true.
