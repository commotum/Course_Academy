Consider the binomial random variable X∼B(6,0.26). Rounding to 4 decimal places, fill in the missing values in the cumulative distribution function table below.
x 0 1 2 3 4 5 6
P(X≤x)
0.1642
0.5104
 0.8144 0.9569 0.9944 0.9997 1.0000
Submit
Correct
EXPLANATION

The cumulative distribution function of a discrete random variable X is a function F(x) such that F(x)=P(X≤x).

The probability mass function for the Binomial distribution B(n,p) is given by f(x)=(nx)px(1−p)n−x,x=0,1,2,…,n.

In our case, n=6 and p=0.26.

Therefore, we compute the missing elements of the table as follows:

F(0)=P(X≤0)=P(X=0)=(60)(0.26)0(1−0.26)6−0=1⋅(0.26)0⋅(0.74)6≈0.1642.

F(1)=P(X≤1)=P(X=0)+P(X=1)=(60)(0.26)0(1−0.26)6−0+(61)(0.26)1(1−0.26)6−1=1⋅(0.26)0⋅(0.74)6+6⋅(0.26)1⋅(0.74)5≈0.5104.
