The function is well-defined at all points (x,y) for which the following condition is satisfied:

  • The argument of the arccosine has values between −1 and 1, and

  • the expression in the denominator is not equal to zero.

As a result, the points in the domain must satisfy the following inequality:

{−1<1y−x<1y−x≠0

Therefore, the domain is

{(x,y)∈R2:−1≤1y−x≤1,y−x≠0}.
