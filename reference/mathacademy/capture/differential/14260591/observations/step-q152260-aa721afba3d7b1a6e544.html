EXPLANATION

First, we substitute u=ln⁡x. Differentiating, we get dudx=1x⟹du=1xdx.

Since u→∞ when x→∞, the table for the limits of integration using the rule u=ln⁡x is as follows:

x 1 ∞
u 0 ∞

So, the integral in terms of the new variable u is ∫1∞1x⋅5ln⁡xdx=∫0∞15udu=∫0∞5−udu.

Now, we proceed by setting the upper bound equal to some parameter a, integrating as usual, and then taking the limit as a→∞.

∫1∞1x⋅5ln⁡xdx=∫0∞5−udu=lima→∞∫0a5−udu=lima→∞[−5−uln⁡5]0a=−1ln⁡5⋅lima→∞[5−u]0a=−1ln⁡5⋅(lima→∞15a−1)

Next, recall the end behavior of the function y=15x, shown in the graph below:

  • limx→−∞15x=∞

  • limx→∞15x=0

Using this to evaluate our integral, we conclude that

∫1∞1x⋅5ln⁡xdx=−1ln⁡5⋅(lima→∞15a−1)=−1ln⁡5⋅(0−1)=1ln⁡5.
