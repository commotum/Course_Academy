We need to calculate E[X+Y].

Recall that if X and Y are random variables (not necessarily independent), and a and b are constants, then

E[aX+bY]=aE[X]+bE[Y].

The expected values of X and Y are calculated as follows: E[X]=0⋅0.2+1⋅0.4+2⋅0.3+3⋅0.1=1.3E[Y]=0⋅0.6+1⋅0.3+2⋅0.1=0.5

Hence, we get

E[X+Y]=E[X]+E[Y]=1.3+0.5=1.8.
