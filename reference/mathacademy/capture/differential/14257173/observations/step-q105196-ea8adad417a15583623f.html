Which of the following sets are closed?

  1. (0,5]
  2. [1,3]
  3. [−4,2]∪[6,9]
a
I and III only
b
III only
c
I and II only
d
II only
e
II and III only
Submit
Correct
EXPLANATION

Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Among the given sets, only [1,3] and [−4,2]∪[6,9] are closed because:

  • The boundary points of [1,3] are 1 and 3. Both of them lie in the set.

  • The boundary points of [−4,2]∪[6,9] are −4,2,6, and 9. All of them lie in the set.

The other set is not closed because (0,5] has a boundary point 0, which does not lie in the set.

Therefore, the correct answer is "II and III only".
