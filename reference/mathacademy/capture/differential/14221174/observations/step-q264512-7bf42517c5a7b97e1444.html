EXPLANATION

The gradient of a function f:Rm×n→R with respect to a matrix X∈Rm×n is ∇Xf(X)=[∂f∂x11∂f∂x12⋯∂f∂x1n∂f∂x21∂f∂x22⋯∂f∂x2n⋮⋮⋱⋮∂f∂xm1∂f∂xm2⋯∂f∂xmn].

In our case, writing out the function f(X) where X=[x11x12x21x22]∈R2×2, we get f(X)=−ln⁡(det(X))=−ln⁡(x11x22−x12x21).

So, the gradient is ∇Xf(X)=[∂f∂x11∂f∂x12∂f∂x21∂f∂x22]=[∂∂x11(−ln⁡(x11x22−x12x21))∂∂x12(−ln⁡(x11x22−x12x21))∂∂x21(−ln⁡(x11x22−x12x21))∂∂x22(−ln⁡(x11x22−x12x21))]=[−x22x11x22−x12x21x21x11x22−x12x21x12x11x22−x12x21−x11x11x22−x12x21].

Evaluating at X=[2112], we get ∇Xf(X)=[−24−114−114−1−24−1]=[−231313−23].
