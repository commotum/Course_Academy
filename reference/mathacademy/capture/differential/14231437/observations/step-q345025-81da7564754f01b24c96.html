EXPLANATION

The left Riemann sum for y=f(x) with a regular step size in sigma notation is

SL=∑k=0n−1f(xk)Δx,

where xk=a+kΔx with Δx=b−an.

From the diagram, we see that there are n=5 rectangles. The endpoints indicate that a=0 and b=5, so the step size is

Δx=5−05=55=1.

Therefore, using sigma notation, the left Riemann sum SL can be expressed as

SL=∑k=0n−1f(xk)Δx=∑k=0n−1f(a+kΔx)Δx=∑k=05−1f(0+k⋅1)⋅1=∑k=04f(k)=∑k=0425−k2.
