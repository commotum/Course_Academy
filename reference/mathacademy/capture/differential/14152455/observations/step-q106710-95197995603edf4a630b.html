Let C be the set of all polynomials p(x) such that p(0)<0. Which of the following statements are true?

  1. The zero-polynomial belongs to C.
  2. For any p(x),q(x)∈C, we have p(x)+q(x)=q(x)+p(x).
  3. The addition of polynomials in C is associative.
a
I and II only
b
III only
c
II and III only
d
I, II, and III
e
I and III only
Submit
Correct
EXPLANATION

Let's verify the statements one by one.

  • Statement I is false. The set C contains only polynomials that evaluate to a negative number at 0. However, the zero-polynomial is not such a polynomial, as it equals 0≮0 at 0. So, 0∉C.

  • Statement II is true. Indeed, for any polynomials p(x),q(x)∈C, we obtain that p(x)+q(x)=q(x)+p(x) since polynomial addition is commutative.

  • Statement III is true. Indeed, for any polynomials p(x),q(x),r(x)∈C, we obtain that [p(x)+q(x)]+r(x)=p(x)+[q(x)+r(x)] since polynomial addition is associative.

Therefore, the correct answer is "II and III only."
