EXPLANATION

Given a binomial random variable X∼B(n,p), if

  • np>5, and

  • n(1−p)>5,

we can approximate X as a normal random variable Y with mean μ=np and variance σ2=np(1−p), that is,

Y∼N(np,np(1−p)).

Here, we have n=70 and p=0.5. Therefore, np=70⋅0.5=35>5✓n(1−p)=70⋅(1−0.5)=35>5.✓ So, we can approximate our binomial random variable X with a normal random variable Y with mean

μ=np=(70)(0.5)=35

and variance

σ2=np(1−p)=(70)(0.5)(1−0.5)=17.5.

That is, we can approximate X by Y∼N(35,17.5).

Now, we can approximate the desired probability P(X=30). Using a continuity correction, we have

P(X=30)≈P(29.5≤Y≤30.5).

To compute this probability, we transform to a standard normal random variable by z-scoring:

P(29.5≤Y≤30.5)=P(29.5−3517.5≤Z≤30.5−3517.5)≈P(−1.31≤Z≤−1.08)=P(Z≤−1.08)−P(Z<−1.31)=P(Z≤−1.08)−P(Z≤−1.31)=Φ(−1.08)−Φ(−1.31)=0.1401−0.0951=0.045

Therefore,

P(X=30)≈0.045.

Note: Using a software package for the approximation gives a probability of 0.0469.
