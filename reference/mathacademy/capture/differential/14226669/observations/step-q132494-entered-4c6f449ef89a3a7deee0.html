EXPLANATION

Given a binomial random variable X∼B(n,p), if

  • np>5, and

  • n(1−p)>5,

we can approximate X as a normal random variable Y with mean μ=np and variance σ2=np(1−p), that is,

Y∼N(np,np(1−p)).

Here, we have n=100 and p=0.4. Therefore, np=100⋅0.4=40>5✓n(1−p)=100⋅(1−0.4)=60>5.✓ So, we can approximate our binomial random variable X with a normal random variable Y with mean

μ=np=(100)(0.4)=40

and variance

σ2=np(1−p)=(100)(0.4)(1−0.4)=24.

That is, we can approximate X by Y∼N(40,24).

Now, we can approximate the desired probability P(X=50). Using a continuity correction, we have

P(X=50)≈P(49.5≤Y≤50.5).

To compute this probability, we transform to a standard normal random variable by z-scoring:

P(49.5≤Y≤50.5)=P(49.5−4024≤Z≤50.5−4024)≈P(1.94≤Z≤2.14)=P(Z≤2.14)−P(Z<1.94)=P(Z≤2.14)−P(Z≤1.94)=Φ(2.14)−Φ(1.94)=0.9838−0.9738=0.010

Therefore,

P(X=50)≈0.010.

Note: Using a software package for the approximation gives a probability of 0.0102.
