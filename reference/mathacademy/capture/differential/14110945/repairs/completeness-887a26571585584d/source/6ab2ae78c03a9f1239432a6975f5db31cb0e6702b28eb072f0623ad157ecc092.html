EXPLANATION

In order for limx→1f(x) to be equal to 2, the left and right-sided limits must both exist and be equal to 2.

  • Approaching from the left, we have x<1, so we use the expression f(x)=x2+2x+b. We get limx→1−f(x)=limx→1−(x2+2x+b)=12+2(1)+b=1+2+b=b+3. Since the left-sided limit must be equal to 2, we have limx→1−f(x)=2b+3=2b=2−3b=−1.

  • Approaching from the right, we have x>1, so we use the expression f(x)=x2+cx+2. We get limx→1+f(x)=limx→1+(x2+cx+2)=12+c(1)+2=1+c+2=c+3. Since the right-sided limit must be equal to 2, we have limx→1+f(x)=2c+3=2c=2−3c=−1.
