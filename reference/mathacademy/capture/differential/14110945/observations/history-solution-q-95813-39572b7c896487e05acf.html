Given a binomial random variable X∼B(n,p), if

  • np>5, and

  • n(1−p)>5,

we can approximate X as a normal random variable Y with mean μ=np and variance σ2=np(1−p), that is,

Y∼N(np,np(1−p)).

Here, we have n=200 and p=0.4. Therefore, np=200⋅0.4=80>5✓n(1−p)=200⋅(1−0.4)=120>5.✓ So, we can approximate our binomial random variable X with a normal random variable Y with mean

μ=np=(200)(0.4)=80

and variance

σ2=np(1−p)=(200)(0.4)(1−0.4)=48.

That is, we can approximate X by Y∼N(80,48).

Now, we can estimate the desired probability P(X>90). Using a continuity correction, we have

P(X>90)=P(X≥91)≈P(Y>90.5).

To compute this probability, we transform to a standard normal random variable by z-scoring:

P(Y>90.5)=P(Z>90.5−8048)≈P(Z>1.52)=1−P(Z≤1.52)=1−Φ(1.52)=1−0.9357=0.0643

Therefore,

P(X>90)≈0.064. Note: Using a software package for the approximation gives a probability of 0.0648.
