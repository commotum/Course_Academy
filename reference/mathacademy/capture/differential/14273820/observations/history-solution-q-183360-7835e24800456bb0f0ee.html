According to the definition of the biconditional,

  • P⇔Q is true if P⇒Q and Q⇒P. Otherwise, it is false.

  • In other words, P⇔Q is true if P and Q have the same truth values. Otherwise, it is false.

So, when A=F and B=T, we have (A⇔¬B)=(F⇔¬T)=(F⇔F)=T.
