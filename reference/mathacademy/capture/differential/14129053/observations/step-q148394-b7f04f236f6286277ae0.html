Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number obtained when picking an integer between 0 and 10 at random.
  2. The number obtained when picking a real number between 5 and 9 at random.
  3. The number of clients arriving at a shopping mall in a day.
a
I only
b
III only
c
II only
d
I and II only
e
I and III only
Submit
Correct
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I can be modeled as a discrete uniform distribution. This is because there are a finite number of integers between 0 and 10, and since the selection is random, each integer has an equal probability of being selected.

  • Random variable II cannot be modeled as a discrete uniform distribution. This is because there are infinitely many real numbers between 5 and 9, and so the support is not finite.

  • Random variable III cannot be modeled as a discrete uniform distribution. This is because the number of clients arriving at a shopping mall can be any positive integer, and each outcome is not equally likely.

Therefore, the correct answer is "I only."
