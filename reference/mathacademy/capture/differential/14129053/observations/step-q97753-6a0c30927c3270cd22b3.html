Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number obtained when picking a card from a set of cards numbered from 1 to 12, at random.
  2. The number obtained when throwing a standard die that is biased toward landing on 1.
  3. The color obtained when a ball from a bag containing 5 balls with distinct colors is chosen randomly.
a
III only
b
I, II, and III
c
I and II only
d
II and III only
e
I and III only
Submit
Correct
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I can be modeled as a discrete uniform distribution. There are a finite number of cards, and since the selection is made at random, each card has an equal probability of being selected.

  • Random variable II cannot be modeled as a discrete uniform distribution. Since the die is not fair, each outcome is not equally likely, because there is a higher probability of getting 1.

  • Random variable III can be modeled as a discrete uniform distribution. This is because there are a finite number of distinct colors, and since the selection is made at random, each color has an equal probability of being picked.

Therefore, the correct answer is "I and III only."
