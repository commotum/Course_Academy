EXPLANATION

The supremum of a function is the supremum of the range of the function.

In this case, the range of f is A=[−2,1).

To find the supremum of a set A, we must find the set containing all upper bounds of A (i.e., the set of upper bounds) and take the minimum of this set.

So, in our case, we have that

  • any number y≥1 is an upper bound of A,

  • any number y<1 is not an upper bound of A. In other words, we can always find an element of A that is greater than y for any y<1.

Therefore, [1,∞) is the set of lower bounds of A, and supx∈Rf(x)=sup(A)=min[1,∞)=1.
