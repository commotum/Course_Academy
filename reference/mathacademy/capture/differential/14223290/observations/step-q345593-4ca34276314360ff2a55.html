A scientist measured 5 particular features, x1,x2,…,x5, for each athlete among a group of athletes. The collected data was stored in the standardized observation matrix X, where each row contains measurements for a particular athlete. The singular values of X are σ1=5,σ2=2,σ3=1,σ4=0.5,σ5=0.1. The scientist then converted the original observation matrix X into a new matrix Y using the equation Y=XV2, where V2 is the 5×2 matrix consisting of the first two principal components of the data. What percentage of the original variance is preserved in the new transformed matrix Y compared to the initial observation matrix X?

91.3%

95.8%

Incorrect
EXPLANATION

Let V be the matrix of principal components. Then, applying the change of variables

Y=XV

we can convert our observation matrix X into a new matrix Y of (linearly) transformed observations such that

  • the covariance matrix of Y is diagonal (meaning that the new features y1,y2,…,y5 are uncorrelated),

  • the features y1,y2,…,y5 are arranged in order of decreasing variance, and

  • the squares of the singular values σ12,σ22,…,σ52 represent the variances in the respective features y1,y2,…,y5.

Now, the total variance over all features is proportional to the sum of the squared singular values:

Total∝∑i=15σi2=(5)2+(2)2+(1)2+(0.5)2+(0.1)2=30.26

Since the scientist used only the first two principal components, the remaining variance is

Remaining∝∑i=12σi2=(5)2+(2)2=29.

Therefore, our required percentage can be computed as

RemainingTotal=2930.26≈0.958=95.8%.
