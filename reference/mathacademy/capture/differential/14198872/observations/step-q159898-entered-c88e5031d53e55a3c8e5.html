Suppose X1,X2,X3,X4 is an I.I.D random sample with Xi∼Po(θ) with unknown rate parameter θ. You're given the particular sample x1=4,x2=2,x3=1,x4=2. The log-likelihood function of the sample is given by l(θ)=aθ+bln⁡θ−ln⁡c.

Find the value of a+b+c.

Hint: The probability mass function for a Poisson distribution is given by f(x)=θxe−θx!,x=0,1,2,…

Correct
EXPLANATION

Recall that if X1,X2,…,Xn are independent and identically distributed discrete random variables with probability mass function f(x;θ), where θ is an unknown parameter, then the log-likelihood function of a random sample x1,x2,…,xn is

l(θ)=ln⁡L(θ)=ln⁡(∏i=1nf(xi,θ))=∑i=1nln⁡(f(xi,θ)).

In our case, we are given a sample of n=4 independent Poisson random variables with unknown parameter θ. Therefore, the probability mass function is

f(x,θ)=e−θ⋅θxx!.

We can calculate the log-likelihood function as follows: l(θ)=∑i=1nln⁡(e−θ⋅θxixi!)=∑i=1nln⁡(e−θ)+ln⁡(θxi)−ln⁡(xi!)=∑i=1n(−θ)+∑i=1nln⁡(θxi)−∑i=1nln⁡(xi!)=∑i=1n(−θ)+∑i=1nxiln⁡(θ)−∑i=1nln⁡(xi!)=−θ∑i=1n1+ln⁡θ∑i=1nxi−∑i=1nln⁡(xi!)=−nθ+ln⁡θ∑i=1nxi−ln⁡(∏i=1nxi!)

Now, using the sample data with n=4, we have ∏i=1nxi!=4!⋅2!⋅1!⋅2!=24⋅2⋅1⋅2=96,∑i=1nxi=4+2+1+2=9.

Therefore, substituting the above values into our expression for l(θ), we get

l(θ)=−4θ+9ln⁡θ−ln⁡96.

Finally,

a+b+c=−4+9+96=101.
