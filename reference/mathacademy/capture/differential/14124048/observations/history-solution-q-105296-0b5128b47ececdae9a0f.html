We say that two vectors v1 and v2 are linearly independent if the only solution to the equation x1v1+x2v2=0 is x1=x2=0. Otherwise, the vectors are linearly dependent.

A set containing only two vectors is linearly dependent if and only if the two vectors are parallel.
