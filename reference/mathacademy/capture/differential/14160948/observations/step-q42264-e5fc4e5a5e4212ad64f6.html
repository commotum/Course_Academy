Given that A,B, and C are 2×2 matrices, which of the following statements are always true?

  1. AB=BA
  2. (AB)C=A(BC)
  3. A(B−C)=(B−C)A
a
II only
b
II and III only
c
I and II only
d
I only
e
 III only
Submit
Incorrect
EXPLANATION

Let's consider the statements one by one.

  • Statement I is false. Matrix multiplication is not commutative, so AB≠BA in general.

  • Statement II is true. Matrix multiplication is associative, so (AB)C=A(BC) in general.

  • Statement III is false. Matrix multiplication is not commutative, so A(B−C)≠(B−C)A in general.

Therefore, only statement II is true.
