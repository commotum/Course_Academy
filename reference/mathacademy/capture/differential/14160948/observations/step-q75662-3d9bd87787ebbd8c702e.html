Given that A,B, and C are 7×7 matrices, which of the following statements are always true?

  1. A(B+C)=AC+AB
  2. A(BC)=(BA)C
  3. AB=BA

Correct
EXPLANATION

Let's consider the statements one by one.

  • Statement I is true. Matrix multiplication is distributive, so A(B+C)=AB+AC=AC+AB since matrix addition is commutative.

  • Statement II is false. Matrix multiplication is associative, so (AB)C=A(BC) in general. However, since matrix multiplication is not commutative, we have A(BC)=(AB)C≠(BA)C.

  • Statement III is false. Matrix multiplication is not commutative, so AB≠BA in general.

Therefore, only statement I is true.
