Let's consider the statements one by one.

  • Statement I is true. Matrix multiplication is not commutative in general, however, multiplication by the identity matrix is always commutative. In this case, we have AI4=I4A=A.

  • Statement II is true. Matrix multiplication is asociative, so (CA)B=C(AB) in general.

  • Statement III is false. Matrix multiplication is not commutative, so BC≠CB in general.

Therefore, only statements I and II are true.
