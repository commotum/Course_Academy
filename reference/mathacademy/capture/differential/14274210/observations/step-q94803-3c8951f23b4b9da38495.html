b
U does not contain the constant function f(x)=1 for every x∈R

EXPLANATION

The correct answer is as follows:

U is not a vector space (with respect to function addition and scalar multiplication of a function by a real number) because multiplication of f∈U by a scalar is not closed.

For example, if α=2 and f(x)=x+1, then f(x)∈U but αf(x)∉U. Indeed, we have that f(0)=1 and 2f(0)=2.

On the other hand:

  • Addition of functions is associative. ✓

  • Addition of functions is commutative. ✓

  • Addition and scalar multiplication of functions satisfy the distributive laws. ✓

  • The constant function f(x)=1 for every x∈R, satisfies f(0)=1. Thus, it is an element of U. ✓
