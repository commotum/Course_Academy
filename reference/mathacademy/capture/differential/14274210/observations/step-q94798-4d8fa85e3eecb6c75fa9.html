Let S be the set of all polynomials in the real variable x with coefficients in Q. Complete the following sentence:

S is not a vector space (with respect to polynomials addition and multiplication of a polynomial by a real number) because _________.

a
multiplication of functions in S by real scalars is not closed
b
 addition of polynomials is not commutative
c
addition of polynomials is not associative
d
1⋅f≠f for some f∈S
e
S does not contain the zero function

Incorrect
EXPLANATION

The correct answer is as follows:

S is not a vector space (with respect to polynomials addition and multiplication of a polynomial by a real number) because multiplication of functions in S by real scalars is not closed.

Indeed, let's consider, for example, the polynomial f(x)=x. Then f∈S, but 2f(x)=2 x∉S because 2∉Q. On the other hand:

  • Addition of polynomials is associative. ✓

  • Addition of polynomials is commutative. ✓

  • The zero function belongs to S. ✓

  • 1⋅f=f for all f∈S. ✓
