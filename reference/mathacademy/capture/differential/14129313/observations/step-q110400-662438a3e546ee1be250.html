EXPLANATION

If the random variables X and Y have joint distribution with joint probability mass function f(x,y), then we have

P(X=x)=fX(x)=∑yf(x,y)P(Y=y)=fY(y)=∑xf(x,y)

where fX(x) and fY(y) are the marginal mass functions for X and Y, respectively.

In this case, the marginal distribution for X corresponds to the row totals, and the marginal distribution for Y corresponds to the column totals. Let's add these row and column totals to our table:

f Y=1 Y=2 Y=3 fX
X=0 0.2 0.1 0.1 0.4
X=1 0.1 0.25 0.25 0.6
fY 0.3 0.35 0.35 1

The marginal mass function for Y is given in the following table:

y 1 2 3
fY(y) 0.3 0.35 0.35

Finally, using the table of values of the marginal mass function for Y, we have

P(Y≤2)=P(Y∈{1,2})=P(Y=1)+P(Y=2)=0.3+0.35=0.65.
