EXPLANATION

The set S contains all natural numbers between 5 and 50 (including 5 and 50).

Therefore, the set can be written as

S={x∈N:5≤x≤50}.

Note: This definition is not unique. For example:

  • We can write x∈Z. This gives S={x∈Z:5≤x≤50}.

  • We can write 4<x<51. This gives S={x∈N:4<x<51}, or, writing x∈Z as before, we have S={x∈Z:4<x<51}.
