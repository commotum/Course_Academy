A fair spinner has six sides labeled with the numbers −2, −1, 0, 1, 2, and 3. If the spinner is spun, what is the expected value of the outcome?
E[X]=
12​
Submit
Correct
EXPLANATION

The expected value of a discrete random variable X with probability mass function f(x) defined over a set S is given by

E[X]=∑x∈Sx⋅f(x).

Let X be the outcome of the spinner. Then the support is S={−2,−1,0,1,2,3}, and the corresponding probabilities are all 16:

f(−2)=f(−1)=f(0)=f(1)=f(2)=f(3)=16

Summing up the products of each value of X and its associated probability, we get

E[X]=−2⋅f(−2)+(−1)⋅f(−1)+0⋅f(0)+1⋅f(1)+2⋅f(2)+3⋅f(3)=−2(16)+(−1)(16)+0(16)+1(16)+2(16)+3(16)=−26−16+0+16+26+36=−2−1+0+1+2+36=36=12.
