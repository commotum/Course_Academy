Which of the following sets is a subspace of R3?

  1. A={t⋅⟨2,−4,1⟩:t∈R}
  2. B={⟨x,y,z⟩∈R3:xzy=1}
  3. C={⟨x,y,z⟩∈R3:x2+y2+z2>0}
a
I only
b
II and III only
c
II only
d
III only
e
I and III only
Submit
Correct
EXPLANATION

Let's analyze each of the subsets.

  • The set A is a subspace. It represents a line, and a line is a subspace if and only if it passes through the zero vector, 0. This can be verified by taking t=0, since 0⋅⟨2,−4,1⟩=⟨0,0,0⟩. So, 0 lies in A.

  • The set B is not a subspace because it does not contain the zero vector. Indeed, 0=⟨0,0,0⟩ does not satisfy the equation xyz=1 since 0⋅0⋅0≠1.

  • The set C is not a subspace because it does not contain the zero vector. Indeed, 0=⟨0,0,0⟩ does not satisfy the inequality x2+y2+z2>0 since 02+02+02=0.

In conclusion, the correct answer is "I only."
