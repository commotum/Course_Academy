Which of the following equalities are true given that D={(x,y):−12≤x≤12,−1≤y≤13}.

  1. ∬Dx2y4dA=∫−1/21/2∫−11/3x2y4dydx
  2. ∬Dx2y4dA=∫−1/21/2∫−11/3x2y4dxdy
  3. ∬Dx2y4dA=∫−11/3∫−1/21/2x2y4dydx
a
II only
b
I and II only
c
I only
d
III only
e
II and III only

Correct
EXPLANATION

We notice that:

  • the limits for the variable x are from −12 to 12, and

  • the limits for the variable y are from −1 to 13.

Therefore,

∬Dx2y4dA=∫−11/3[∫−1/21/2x2y4dx]dy.

Now, since the region of integration is rectangular, we can also swap the order of integration. This gives

∬Dx2y4dA=∫−1/21/2[∫−11/3x2y4dy]dx.

So, the correct answer is "I only".
