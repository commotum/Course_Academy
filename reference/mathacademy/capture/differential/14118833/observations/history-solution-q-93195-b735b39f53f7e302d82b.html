The solid is a heptagonal pyramid since it is a pyramid whose base is a heptagon.

Also, notice that:

  • The solid is not a triangular pyramid since not all its faces are triangular.

  • The solid is not a heptagonal prism since it has only one heptagonal face.

  • The solid is not a hexagonal prism because it has no hexagonal face.

  • The solid is not a cube since it has triangular faces.
