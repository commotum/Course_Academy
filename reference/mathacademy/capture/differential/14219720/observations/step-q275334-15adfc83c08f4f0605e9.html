A game randomly selects an integer n from 1 to 301, with each value equally likely. Then, a player is asked to guess an integer uniformly and randomly from 1 to n. What is the expected value of the player’s guess?

EXPLANATION

This is a two-step random process: first, an integer n is chosen uniformly from 1 to 301, and then a number is chosen uniformly from 1 to n. We are asked to find the expected value of the number selected in the second step.

  • Let Y be the first random number, an integer selected uniformly from 1 to 301.

  • Let X be the player’s guess, an integer selected uniformly from 1 to Y.

We are asked to compute E[X]. Since the distribution of X depends on Y, we apply the tower property:

E[X]=E[E[X∣Y]]

Given Y=n, the number X is chosen uniformly from 1 to n. So, we have that

E[X∣Y=n]=n+12.

Therefore, we have that

E[X]=E[1+Y2].

Now, we apply the linearity of expectation:

E[X]=12⋅E[1+Y]=12⋅(1+E[Y])

Since Y is uniformly distributed on {1,2,…,301}, we use the formula for the mean of the first n integers:

E[Y]=1+3012=151.

Substituting, we finally get

E[X]=12⋅(1+E[Y])=12⋅(1+151)=12⋅152=76.
