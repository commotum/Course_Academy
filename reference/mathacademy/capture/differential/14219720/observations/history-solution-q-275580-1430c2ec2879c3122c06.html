This is a two-step random process: first, a box is selected containing n items uniformly from 1 through 150, and then an item is chosen uniformly in one of the positions numbered 1 through n.

  • Let Y be the number of items in the box. Since this is an integer selected uniformly from 1 to 150, we have Y∼U{1,2,…,150}.

  • Let X be the position number scanned, an integer selected uniformly from 1 to Y.

We are asked to compute E[X]. Since the distribution of X depends on Y, we apply the tower property:

E[X]=E[E[X∣Y]]

Given Y=n, the number X is chosen uniformly from 1 to n. So, we have that

E[X∣Y=n]=n+12.

Therefore, we have that

E[X]=E[Y+12].

Now, we apply the linearity of expectation:

E[X]=12⋅E[Y+1]=12⋅(E[Y]+1)

Since Y is uniformly distributed on {1,2,…,150}, we use the formula for the mean of the first n integers:

E[Y]=150+12=75.5

Substituting, we finally get E[X]=12⋅(E[Y]+1)=12⋅(75.5+1)=12⋅76.5=38.25.
