This is a two-step random process: first, an integer n is chosen uniformly from 1 through 10, and then a number is chosen uniformly from 1 through n.

  • Let Y be the first random number: the number of steps in the staircase. Since an integer selected uniformly from 1 to 10, we have Y∼U{1,2,…,10}.

  • Let X be the number of steps the robot climbs, an integer selected uniformly from 1 to Y.

We are asked to compute E[X]. Since the distribution of X depends on Y, we apply the tower property: E[X]=E[E[X∣Y]]

Given Y=n, the number X is chosen uniformly from 1 to n. So, we have that E[X∣Y=n]=n+12.

Therefore, we have that E[X]=E[Y+12].

Now, we apply the linearity of expectation: E[X]=12⋅E[Y+1]=12⋅(E[Y]+1)

Since Y is uniformly distributed on {1,2,…,10}, we use the formula for the mean of the first n integers: E[Y]=10+12=5.5

Substituting, we finally get E[X]=12⋅(E[Y]+1)=12⋅(5.5+1)=12⋅6.5=3.25.
