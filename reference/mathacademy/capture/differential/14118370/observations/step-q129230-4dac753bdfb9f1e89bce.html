Which of the following augmented matrices are in row echelon form? A=[−50842003−5000−2010000−1],B=[4068003−10002],C=[0−90−6001−700010000].

a
A, B, and C
b
B only
c
B and C only
d
A and C only
e
A and B only
Submit
Correct
EXPLANATION

Remember that an augmented matrix is in row echelon form if its coefficient matrix satisfies the following conditions:

  1. All the zero rows (rows with only zeros), if any, are placed at the bottom of the matrix.
  2. Each leading entry of a row is in a column to the right of the leading entry of the row above it.
With that in mind, let's look at each matrix in turn.

  • The matrix A is not in row echelon form since a33≠0 (condition II is violated). A=[−50842003−5000−2010000−1]

  • The matrix B is in row echelon form (both conditions are satisfied). B=[4068003−10002]

  • The matrix C is in row echelon form (both conditions are satisfied). C=[0−90−6001−700010000]

Therefore, only B and C are in row echelon form.
