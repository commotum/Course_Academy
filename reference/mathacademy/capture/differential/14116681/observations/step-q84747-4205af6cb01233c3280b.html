Which of the following random variables could be modeled as a binomial distribution?

  1. The number of times "head" is obtained when a coin is tossed 10 times
  2. The number of students in a class
  3. The number of tickets sold for a concert in 3 days
a
II and III only
b
II only
c
I only
d
I and II only
e
III only
Submit
Correct
EXPLANATION

A binomial distribution models the number of successes in a sequence of n independent experiments (where each outcome is either success or failure).

With that in mind, let's consider each of the given random variables.

  • Random variable I could be modeled as a binomial distribution. The number of "heads" in 10 tosses can be interpreted as the number of successes in a sequence of 10 independent experiments.

  • Random variable II could not be modeled as a binomial distribution. The number of students in a class cannot be interpreted as "success" or "failure."

  • Random variable III could not be modeled as a binomial distribution. The number of tickets sold for a concert cannot be interpreted as "success" or "failure."

Therefore, the correct answer is "I only."
