Which of the following statements are true?

  1. If 1=1, then 2≤3.
  2. If 1>1, then 2=3.
  3. If 1≤1, then 2>3.
a
I and II only
b
I only
c
II only
d
III only
e
None
Submit
Correct
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent 1=1 is true, and the consequent 2≤3 is true. So the promise is kept, and the statement is true.

  • Statement II is true. The antecedent 1>1 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement III is false. The antecedent 1≤1 is true, and the consequent 2>3 is false. So the promise is broken, and the statement is false.

Therefore, the correct answer is "I and II only."
