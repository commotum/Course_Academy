Which of the following statements are true?

  1. If 2 is an even number, then 8 is a prime number.
  2. If 8 is an even number, then 2 is an even number.
  3. If 8 is a prime number, then 2 is an even number.
a
II only
b
None
c
I only
d
II and III only
e
III only
Submit
Incorrect
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is false. The antecedent "2 is an even number" is true, and the consequent "8 is a prime number" is false. So the promise is broken, and the statement is false.

  • Statement II is true. The antecedent "8 is an even number" is true, and the consequent "2 is an even number" is true. So the promise is kept, and the statement is true.

  • Statement III is true. The antecedent "8 is a prime number" is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

Therefore, the correct answer is "II and III only."
