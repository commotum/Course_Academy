Which of the following statements are true?

  1. If 7≤3, then 2≤5.
  2. If 4≤4, then 4≤2.
  3. If 4≤5, then 7≤6.
a
I only
b
I and III only
c
II only
d
II and III only
e
III only
Submit
Correct
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent 7≤3 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement II is false. The antecedent 4≤4 is true, and the consequent 4≤2 is false. So the promise is broken, and the statement is false.

  • Statement III is false. The antecedent 4≤5 is true, and the consequent 7≤6 is false. So the promise is broken, and the statement is false.

Therefore, the correct answer is "I only."
