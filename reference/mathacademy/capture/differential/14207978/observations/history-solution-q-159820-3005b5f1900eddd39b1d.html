Recall that if X1,X2,…,Xn are independent and identically distributed discrete random variables with probability mass function f(x;θ), where θ is an unknown parameter, then the likelihood function of a random sample x1,x2,…,xn is L(θ)=P(X1=x1,X2=x2,…,Xn=xn)=∏i=1nf(xi;θ).

In our case, we are given a sample of n=9 independent binomial random variables with unknown probability of success θ and N=7 trials, for which the probability mass function is f(x;θ)=(7x)θx(1−θ)7−x,x=0,1,2,…,7.

We can calculate the likelihood function as follows: L(θ)=∏i=1nf(xi;θ)=∏i=1n(7xi)θxi(1−θ)7−xi=((7x1)θx1(1−θ)7−x1)⋅((7x2)θx2(1−θ)7−x2)⋯((7xn)θxn(1−θ)7−xn)=Cθ∑xi(1−θ)∑(7−xi)=Cθ∑xi(1−θ)7n−∑xi=CθS(1−θ)7n−S where C=∏i=1n(7xi) is a constant and S=∑i=1nxi.

We are told that S=∑i=1nxi=13 and n=9. Therefore, L(θ)=Cθ13(1−θ)7(9)−13=Cθ13(1−θ)50.
