An employee of a car dealership collects data on the value y (in thousands of dollars) of a particular car model t years after its release to the market. The residual plot above was constructed after fitting a linear regression model on this data set. Which of the following statements are true?

  1. When t=6, the regression equation overestimates the value of y.
  2. The residuals appear randomly scattered about the horizontal axis (there are no obvious trends).
  3. This linear regression is probably a good fit for the data.
a
 II and III only
b
 III only
c
 II only
d
 I and II only
e
 I only
Submit
Correct
EXPLANATION

Let's examine the statements in turn.

  • Statement I is true. The residual equals the actual value minus the estimated value: Residual=Actual−Estimated From the plot, the residual at t=6 is negative. So, we have that Actual<Estimated, and therefore the model overestimates this data point.

  • Statement II is false. The plot shows the residuals tend to decrease as time increases. So, there is a trend, as shown below.

  • Statement III is false. Since the residuals are not randomly scattered above and below the horizontal axis, our regression line is not a good fit for the given data.

Therefore, the correct answer is "I only."
