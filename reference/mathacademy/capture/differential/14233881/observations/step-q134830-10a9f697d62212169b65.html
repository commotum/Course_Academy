An economist records data on the volume of corn exports y (in thousands of tons) from the United States to a particular country, x number of years since 2010. The residual plot above was constructed after fitting a linear regression model on this data set. Which of the following statements are true?

  1. When t=6, the regression equation underestimates the value of y.
  2. The residuals appear randomly scattered about the horizontal axis (there are no obvious trends).
  3. This linear regression is probably a good fit for the data.
a
II only
b
I and II only
c
II and III only
d
I only
e
III only
Submit
Incorrect
EXPLANATION

Let's examine the statements in turn.

  • Statement I is false. The residual equals the actual value minus the estimated value: Residual=Actual−Estimated From the plot, the residual at t=6 is negative. So, we have that Actual<Estimated, and therefore the model overestimates (not underestimates) this data point.

  • Statement II is true. The plot shows that the residuals appear randomly scattered about the horizontal axis (there are no obvious trends).

  • Statement III is true. Since the residuals are close to 0 and are randomly scattered above and below the horizontal axis, we can conclude that our regression line is probably a good fit for the given data.

Therefore, the correct answer is "II and III only."
