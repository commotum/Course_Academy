Let F be the event that a squirrel is an adult female, C be the event that a squirrel is born in captivity, and S1,S2,S3,S4 be the event that a squirrel is of species 1, 2, 3, or 4, respectively.

Let's break down the information given in the problem statement:

  • Each species has the same number of squirrels, so we have the following information: P(S1)=P(S2)=P(S3)=P(S4)=0.25

  • From the bullet points, we have the following information: P(C|S1)=0.12P(C|S2)=0.05P(C|S3)=0.06P(C|S4)=0.03 The disjoint union S1⊔S2⊔S3⊔S4 covers the entire sample space, and we have P(S1)+P(S2)+P(S3)+P(S4)=0.25+0.25+0.25+0.25=1.

  • Since 35% of the squirrels are adult females, we have P(F)=0.35.

  • Since 8% of adult females are born in captivity, we have P(C|F)=0.08.

We want to find the probability that a randomly chosen squirrel born in captivity is an adult female, which is represented as P(F|C).

Using Bayes' theorem combined with the law of total probability, we have

P(F|C)=P(C|F)P(F)P(C)=P(C|F)P(F)P(C|S1)P(S1)+P(C|S2)P(S2)+P(C|S3)P(S3)+P(C|S3)P(S3)=(0.08)(0.35)(0.12)(0.25)+(0.05)(0.25)+(0.06)(0.25)+(0.03)(0.25)=0.0280.065≈0.431,

rounded to 3 decimal places.
