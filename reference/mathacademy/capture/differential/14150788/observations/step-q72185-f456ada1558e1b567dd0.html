Which of the following statements are true regarding the finite region inside the circumference x2+y2=1?

  1. It is a type I region
  2. It is a type II region
  3. It's neither a type I nor a type II region
a
I and II only
b
I and III only
c
I only
d
II only
e
III only
Submit
Incorrect
EXPLANATION

First, notice that x2+y2=1⟹x=±1−y2x2+y2=1⟹y=±1−x2.

Now, let's sketch our region.

We have the following:

  • Any vertical line through the region intersects it on a single interval. Furthermore, we can represent our region as D={(x,y):−1≤x≤1,−1−x2≤y≤1−x2}. So, this is a type I region.

  • Any horizontal line through the region intersects it on a single interval. Furthermore, we can represent our region as D={(x,y):−1≤y≤1,−1−y2≤x≤1−y2}. So, this is a type II region.

Therefore, only statements I and II are true.
