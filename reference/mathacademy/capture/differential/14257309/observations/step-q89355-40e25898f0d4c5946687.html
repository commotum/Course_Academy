Which of the following random variables could be modeled as a binomial distribution?

  1. The number of boys in a family of 3 children
  2. The number of red cars passing through an avenue in an hour
  3. The number of pizzas sold by a pizzeria in a day
a
III only
b
I and III only
c
II and III only
d
I only
e
II only
Submit
Incorrect
EXPLANATION

A binomial distribution models the number of successes in a sequence of n independent experiments (where each outcome is either success or failure).

With that in mind, let's consider each of the given random variables.

  • Random variable I could be modeled as a binomial distribution. The number of boys can be interpreted as the number of successes in a sequence of 3 independent experiments.

  • Random variable II could not be modeled as a binomial distribution. Although being red can be interpreted as a "success," there is not a fixed number of trials in this experiment.

  • Random variable III could not be modeled as a binomial distribution. The number of pizzas sold cannot be interpreted as "success" or "failure."

Therefore, the correct answer is "I only."
