Which of the following sets are orthogonal?

  1. U={[−2−1],[32],[15−20]}
  2. V={[05],[12]}
  3. W={[61−1],[231],[0−10]}
a
None of the listed
b
V and W only
c
U only
d
All the listed
e
U and V only
Submit
Correct
EXPLANATION

Let's denote the vectors of the given sets as {u1,u2,u3}, {v1,v2}, and {w1,w2,w3}, respectively.

The sets U,V, and W are orthogonal if the following conditions on each set hold:

  • u1⋅u2=0,u1⋅u3=0,u2⋅u3=0.

  • v1⋅v2=0.

  • w1⋅w2=0,w1⋅w3=0,w2⋅w3=0.

With that in mind, let's examine our sets in turn.

  • The set U cannot be orthogonal since it contains 3 vectors from R2 (in which we can have an orthogonal set with at most 2 non-zero vectors). Therefore, U is not an orthogonal set.

  • For the set V, notice that v1⋅v2=[05]⋅[12]=0+10=10≠0× So, V is not an orthogonal set.

  • For the set W, notice that w1⋅w2=[61−1]⋅[231]=12+3−1=14≠0× So, W is not an orthogonal set.

Therefore, we conclude that the correct answer is "None of the listed".
