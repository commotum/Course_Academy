EXPLANATION

The cardinality of a finite set is the number of elements contained within it. A set is infinite if it has infinitely many elements.

We start by finding the solutions to the equation sin⁡(xπ2)=0 for x∈R: xπ2=mπx=2m,m∈Z

With that in mind, let's examine our sets:

  • The set A is infinite.Listing the elements of B for different values of m, we have A={…,−2,0,2,4,…}.

  • The set B is infinite. Since A is infinite, and A⊆B, it follows that B is infinite.

  • The set C is infinite. Since B is infinite, and B⊆C, it follows that C is infinite.

Therefore, the correct answer is "A, B, and C."
