Which of the following sets are infinite?

  1. A={n∈Z:sin⁡n=0}
  2. B={q∈Q:sin⁡q=0}
  3. C={x∈R:sin⁡x=0}
Hint: The arguments of the trigonometric functions are in radians.

a
C only
b
B only
c
None of the sets are infinite.
d
A, B, and C
e
B and C only
Submit
Correct
EXPLANATION

The cardinality of a finite set is the number of elements contained within it. A set is infinite if it has infinitely many elements.

We start by writing down the solutions to the equation sin⁡x=0 for x∈R: x=mπ,m∈Z

With that in mind, let's examine our sets:

  • The set A is finite. There is the only value m=0 such that mπ∈Z. Therefore, A={0}. Consequently, |A|=1, which is finite.

  • The set B is finite. Similar to the above, there is the only value m=0 such that mπ∈Q. Therefore, B={0}. Consequently, |B|=1, which is finite.

  • The set C is infinite. Listing the elements of C for different values of m, we have C={…,−π,0,π,2π,…}.

Therefore, the correct answer is "C only."
