Which of the following sets are infinite?

  1. A={n∈Z:|5n|≤4}
  2. B={q∈Q:|5q|≤4}
  3. C={x∈R:|5x|≤4}
a
A,B, and C only
b
A and C only
c
C only
d
B and C only
e
A and B only

Correct
EXPLANATION

The cardinality of a finite set is the number of elements contained within it. A set is infinite if it has infinitely many elements.

We start by solving the following inequality for x∈R: |5x|≤45|x|≤4|x|≤45 which gives −45≤x≤45 and can be expressed as x∈I=[−45,45].

With that in mind, let's examine our sets:

  • The set A is finite. If n∈Z, the solutions to the inequality |5n|≤4 are all the integers that lie in the interval I. Therefore, A={0}. Consequently, |A|=1, which is finite.

  • The set B is infinite. If q∈Q, the solutions to |5q|≤4 are all the rational numbers that lie in the interval I. Since any real interval of nonzero length contains infinitely many rational numbers, it follows that B is infinite.

  • The set C is infinite. Since B is infinite, and B⊂C, it follows that C is infinite.

Therefore, the correct answer is "B and C only."
