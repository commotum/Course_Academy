110(0)

1E(12)
c
1E(10)
d
1{0,4,8,12}(E)
e
110(E)
Submit
Incorrect
EXPLANATION

The indicator function 1[P] equals 1 if the predicate P is true and 0 if P is false. 1[P]={1,if P is true,0,if P is false.

Recall that the indicator function 1A(x) of a set A equals 1 if x∈A and 0 if x∉A. This can be written using Iverson bracket notation as 1A(x)=1[x∈A].

Here, the Iverson bracket expression 1[10∈E] has x=10 and A=E. Therefore, converting back to set indicator notation, we have 1[10∈E]=1E(10).
