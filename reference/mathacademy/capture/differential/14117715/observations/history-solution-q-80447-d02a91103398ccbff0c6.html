The cardinality of a finite set Y is the number of elements in Y.

Let's start by listing all the elements of Y: 1,2,{{2}},3,4,{{∅}}

Note the following:

  • Only unique elements are counted. In other words, duplicate elements are not counted separately.

  • {{2}} and {{∅}} each count as single elements of Y.
