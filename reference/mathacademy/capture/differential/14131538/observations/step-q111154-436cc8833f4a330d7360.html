We need to solve the equation Ax=0. First, we find the row echelon form of A as follows:

A=[1−2−364−8]R2:=R2+3R1∼[1−2004−8]R3:=R3−4R1∼[1−20000]

This corresponds to the following system:

{x1−2x2=00=00=0

The basic variables are the variables whose coefficients are pivots. In this case, the basic variable is x1, and we have one free variable, x2. That means we need to find x1 in terms of x2.

From the first equation we get x1=2x2, so the set of all the solutions of Ax=0 is

Null(A)={[2x2x2]:x2∈R}.
