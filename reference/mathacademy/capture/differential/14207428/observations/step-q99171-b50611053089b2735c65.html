EXPLANATION

We need to find the maximum value of f subject to the constraint g(x,y,z)=x2+y2+z2=35.

Since f(x,y,z) is continuous and the constraint is closed and bounded, f(x,y,z) reaches a global maximum and a global minimum on the constraint.

Therefore, by the method of Lagrange multipliers, we must solve the following system: ∇f(x,y,z)=λ∇g(x,y,z),g(x,y,z)=35

We start by solving the first equation: ∇f(x,y,z)=λ∇g(x,y,z)⟨fx(x,y,z),fy(x,y,z),fz(x,y,z)⟩=λ⟨gx(x,y,z),gy(x,y,z),gz(x,y,z)⟩⟨2,6,10⟩=λ⟨2x,2y,2z⟩

Notice that we cannot have λ=0 since this leads to a contradiction in the above equation. Therefore, assuming λ≠0, we have the following: {2=2λx6=2λy10=2λz⇒{x=1λy=3λz=5λ

Next, we substitute our expressions for x,y and z into the condition g(x,y,z)=35 and solve for λ, as follows: x2+y2+z2=351λ2+9λ2+25λ2=3535λ2=35λ2=1λ=±1

We can now find x,y and z. This gives x=±1y=±3z=±5.

Therefore, f has possible extreme values at the points (−1,−3,−5),(1,3,5).

We evaluate f at each of these points. These are given in the following table:

(x,y,z) (−1,−3,−5) (1,3,5)
f(x,y,z) −70 70

Therefore, the function reaches a maximum value at (1,3,5), and its maximum value is 70.
