Determining When a Discrete Uniform Distribution is Appropriate
?

To apply a discrete uniform probability model to a situation in context, there are two things we need to check for:

  • The support of our random variable should be finite, and

  • each must be equally likely.

There are some common pitfalls that we need to be aware of!

  • First, we cannot use a discrete uniform distribution to model continuous phenomena.

    For example, weight, time, and distance are all quantities that can take any real number within a given interval. Such quantities should be modeled as continuous, so a discrete uniform distribution is usually inappropriate.
