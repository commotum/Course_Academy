Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number of cars that enter a parking lot in an hour.
  2. The letter obtained when picking a letter from the alphabet at random.
  3. The amount of time, in minutes, between successive visits to a website.
a
I and II only
b
II only
c
III only
d
None of the statements are true
e
II and III only
Submit
Correct
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I cannot be modeled as a discrete uniform distribution. This is because the number of cars can be any positive integer. Moreover, each number of cars is not equally likely.

  • Random variable II can be modeled as a discrete uniform distribution. This is because there are a finite number of letters in the alphabet, and since the selection is random, each letter has an equal probability of being selected.

  • Random variable III cannot be modeled as a discrete uniform distribution. This is because the amount of time between events is a real number, so the support is not finite.

Therefore, the correct answer is "II only."
