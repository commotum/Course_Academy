Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number obtained when randomly picking an integer between 45 and 51.
  2. The age of a randomly selected person (child or adult) in an elementary school.
  3. The height of a basketball player in centimeters.
a
I only
b
II and III only
c
None
d
I and II only
e
II only
Submit
Incorrect
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I can be modeled as a discrete uniform distribution. There are a finite number of integers between 45 and 51, and since the selection is made at random, each integer has an equal probability of being selected.

  • Random variable II cannot be modeled as a discrete uniform distribution. Each outcome is not equally likely, as there are likely to be more children than adults in the school.

  • Random variable III cannot be modeled as a discrete uniform distribution. This is because the height of a basketball player is a real number, so the support is not finite. Moreover, each outcome is not equally likely.

Therefore, the correct answer is "I only."
