Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number of calls a call center receives in an hour.
  2. The number obtained when picking an integer number between −5 and 5 at random.
  3. The amount of time, in minutes, between successive calls received by a call center.
a
I only
b
I and III only
c
I and II only
d
None
e
II only
Submit
Incorrect
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I cannot be modeled as a discrete uniform distribution. This is because the number of calls can be any positive integer, so the support is not finite. Moreover, each number of calls is not equally likely.

  • Random variable II can be modeled as a discrete uniform distribution. This is because there are a finite number of integers between −5 and 5, and since the selection is made at random, each integer has an equal probability of being selected.

  • Random variable III cannot be modeled as a discrete uniform distribution. This is because the amount of time between events is a real number, so the support is not finite.

Therefore, the correct answer is "II only."
