The linear approximation of the function f at the point (a,b) is given by f(x,y)≈f(a,b)+∇f(a,b)⋅⟨x−a,y−b⟩.

So, the linear approximation of f at the point (−2,−3) is f(x,y)≈f(−2,−3)+∇f(−2,−3)⋅⟨x+2,y+3⟩.

From the definition of f, we have that f(−2,−3)=−19. Computing the partial derivatives, we get

fx=y2⇒fx(−2,−3)=(−3)2=9,fy=2xy⇒fy(−2,−3)=2(−2)(−3)=12.

Therefore, the gradient of the function at the point (−2,−3) is given by ∇f(−2,−3)=⟨9,12⟩.

Finally, the linear approximation of the function f is

f(x,y)≈f(−2,−3)+∇f(−2,−3)⋅⟨x+2,y+3⟩=−19+⟨9,12⟩⋅⟨x+2,y+3⟩=−19+9(x+2)+12(y+3)=35+9x+12y.
