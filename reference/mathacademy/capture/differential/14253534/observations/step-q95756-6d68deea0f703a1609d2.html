EXPLANATION

Given a binomial random variable X∼B(n,p), if

  • np>5, and

  • n(1−p)>5,

we can approximate X as a normal random variable Y with mean μ=np and variance σ2=np(1−p), that is,

Y∼N(np,np(1−p)).

Here, we have n=120 and p=0.44. Therefore, np=120⋅0.44=52.8>5✓n(1−p)=120⋅(1−0.44)=67.2>5.✓ So, we can approximate our binomial random variable X with a normal random variable Y with mean

μ=np=(120)(0.44)=52.8

and variance

σ2=np(1−p)=(120)(0.44)(1−0.44)=29.568.

That is, we can approximate X by Y∼N(52.8,29.568).

Now, we can estimate the desired probability P(49<X<70). Using a continuity correction, we have

P(49<X<70)=P(50≤X≤69)≈P(49.5≤Y≤69.5).

To compute this probability, we transform to a standard normal random variable by z-scoring:

P(49.5≤Y≤69.5)=P(49.5−52.829.568≤Z≤69.5−52.829.568)≈P(−0.61≤Z≤3.07)=P(Z≤3.07)−P(Z<−0.61)=P(Z≤3.07)−P(Z≤−0.61)=Φ(3.07)−Φ(−0.61)=0.9989−0.2709=0.7280

Therefore,

P(49<X<70)≈0.728. Note: Using a software package for the approximation gives a probability of 0.7270.
