The level curves of the function f(x,y)=x+yx are given by f(x,y)=c. Which of the following statements are true?

  1. c=−1 gives the x-axis, excluding the origin
  2. c=0 gives the y-axis, excluding the origin
  3. c=1 gives the line y=x, excluding the origin
a
None of the listed
b
I and II only
c
I only
d
II and III only
e
II only
Submit
Correct
EXPLANATION

Setting f(x,y)=c gives: x+yx=cx+y=cxy=(c−1)x

Therefore:

  • If c=−1, the level curve is the line y=−2x, excluding the origin. So, I is false.

  • If c=0, the level curve is the line y=−x, excluding the origin. So, II is false.

  • If c=1, the level curve is y=0, which is the x-axis (excluding the origin). So, III is false.

So, the correct answer is "None of the listed".
