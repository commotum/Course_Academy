The given parabola is written in standard form,

y=ax2+bx+c,

with a=3>0, b=−6, and c=5.

Because the leading coefficient is positive, the parabola opens upward. Consequently, there is no maximum output, and the vertex corresponds to the minimum output.

The x-coordinate of the vertex is given by

x=−b2a=−(−6)2⋅3=1.

Now, we substitute x=1 back into the function to find the y-value of the vertex: y=3x2−6x+5=3(1)2−6(1)+5=3−6+5=2

Therefore, the vertex is (1,2), and the range of the function is [2,∞).
