Consider the following predicates.

A(x): x∈Z. B(x): −x∈Z.

Which of the following is equivalent to the biconditional predicate A(x)⇔B(x)?

  1. If x∈Z then −x∈Z, and if −x∈Z then x∈Z.
  2. x∈Z is equivalent to −x∈Z.
  3. x∈Z if and only if −x∈Z.
a
I, II, and III
b
II and III only
c
I and III only
d
III only
e
I and II only
Submit
Incorrect
EXPLANATION

A biconditional expression P⇔Q≡(P⇒Q)∧(Q⇒P) can be read as shown below:

  • P if and only if Q

  • P is equivalent to Q

  • If P then Q, and if Q then P

So, A⇔B translates into the following sentences:

  • x∈Z if and only if −x∈Z.

  • x∈Z is equivalent to −x∈Z.

  • If x∈Z then −x∈Z, and if −x∈Z then x∈Z.

Therefore, the correct answer is "I, II, and III."
