EXPLANATION

Let's set u=ln⁡x. Then, we have dudx=1x⟹du=1xdx.

Using the above, we can write the integral in terms of u and evaluate:

∫6xln2⁡xdx=6∫1(ln⁡x)2⋅dxx=6∫1u2du=−6⋅u−1+C=−6u+C=−6ln⁡x+C
