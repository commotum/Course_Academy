EXPLANATION

Let's examine each statement in turn.

  • Statement I is false. For example, consider the matrix A=[0100]∈M. Then −A=[0−100] is the corresponding negative matrix such that A+(−A)=O. However, −a12=−1≠1, hence, −A∉M.

  • Statement II is true. Indeed, for the zero-matrix O and any matrix A∈M, we have A+O=A since O is the unique zero element in the set of all matrices.

  • Statement III is true. Indeed, For any matrices A,B,C∈M, we obtain that (A+B)+C=A+(B+C) since matrix addition is associative.

Therefore, the correct answer is "II and III only."
