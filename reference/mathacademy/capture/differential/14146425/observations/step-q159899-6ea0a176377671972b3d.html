Suppose X1,X2,X3 is an I.I.D random sample with Xi∼B(6,θ) with unknown probability of success θ. You're given the particular sample x1=2,x2=5,x3=6. The log-likelihood function of the sample is given by l(θ)=ln⁡a+bln⁡θ+cln⁡(1−θ).

Find the value of a+b+c.

EXPLANATION

Recall that if X1,X2,…,Xn are independent and identically distributed discrete random variables with probability mass function f(x;θ), where θ is an unknown parameter, then the log-likelihood function of a random sample x1,x2,…,xn is l(θ)=ln⁡L(θ)=ln⁡(∏i=1nf(xi,θ))=∑i=1nln⁡(f(xi,θ)).

In our case, we are given a sample of n=3 independent binomial random variables with an unknown probability of success θ and N=6 as the number of trials. Therefore, the probability mass function is f(x,θ)=(Nx)θx(1−θ)N−x,x=0,1,…,N=(6x)θx(1−θ)6−x,x=0,1,…,6.

We can calculate the log-likelihood function as follows: l(θ)=∑i=1nln⁡((6xi)θxi(1−θ)6−xi)=∑i=1nln⁡(6xi)+ln⁡(θxi)+ln⁡((1−θ)6−xi)=∑i=1nln⁡(6xi)+∑i=1nxiln⁡θ+∑i=1n(6−xi)ln⁡(1−θ)=∑i=1nln⁡(6xi)+ln⁡θ∑i=1nxi+ln⁡(1−θ)∑i=1n(6−xi)=∑i=1nln⁡(6xi)+Sln⁡θ+(6n−S)ln⁡(1−θ) where S=∑i=1nxi.

Now, note that ∑i=1nln⁡(6xi)=ln⁡(6x1)+ln⁡(6x2)+ln⁡(6x3)=ln⁡(∏i=1n(6xi)).

So, our expression for l(θ) becomes l(θ)=ln⁡(∏i=1n(6xi))+Sln⁡θ+(6n−S)ln⁡(1−θ).

Now, using the sample data with n=3, we have ∏i=1n(6xi)=(62)⋅(65)⋅(66)=15⋅6⋅1=90,

and S=2+5+6=13.

Substituting the above values into our expression for l(θ), we get l(θ)=ln⁡(90)+13ln⁡θ+(6⋅3−13)ln⁡(1−θ)=ln⁡(90)+13ln⁡θ+5ln⁡(1−θ).

Finally, a+b+c=90+13+5=108.
