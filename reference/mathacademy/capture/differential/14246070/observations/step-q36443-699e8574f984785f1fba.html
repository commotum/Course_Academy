Which of the following sets are closed?

  1. [1,2]∪[3,4]
  2. [0,1)
  3. [0,1)∪(1,2]

EXPLANATION

Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Among the given sets, only [1,2]∪[3,4] is closed. It consists of two parts, where the boundary points are 1,2,3, and 4. All of them lie in the set.

The other sets are not closed because:

  • [0,1) has a boundary point 1, which does not lie in the set.

  • [0,1)∪(1,2] has a boundary point 1, which does not lie in the set.

Therefore, the correct answer is "I only."
