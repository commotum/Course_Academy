Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Let's examine our sets in turn.

  • The first set is neither open nor closed. It contains some of its boundary points, for example, the point (6,1). On the other hand, it does not contain some other boundary points, for example, the point (8,0).

  • The second set is open since it doesn't contain any of its boundary points (the corresponding inequality is strict).

  • The third set is also open since it doesn't contain any of its boundary points (the corresponding inequality is strict).

Therefore, the correct answer is "I only."
