Which of the following statements are logically equivalent?

  1. ¬(A∨B)
  2. ¬A∧¬B
  3. ¬A∨¬B
a
I and III only
b
None of those listed
c
II and III only

I, II, and III
Submit
Incorrect
EXPLANATION

Two statements are logically equivalent if they have the same truth table. So, we construct a truth table for the three given statements:

A B ¬(A∨B) ¬A∧¬B ¬A∨¬B
T T F F F
T F F F T
F T F F T
F F T T T

We see that only the statements ¬(A∨B) and ¬A∧¬B have the same truth table, so they are logically equivalent.

Therefore, the correct answer is "I and II only".
