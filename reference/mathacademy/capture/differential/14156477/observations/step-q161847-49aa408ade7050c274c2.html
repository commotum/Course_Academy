Let f:U→R be continuously differentiable on an open set U⊆R such that f(a)=b and f′(a)≠0 for a∈U. Which of the following statements must be true?

  1. The function f is invertible on U.
  2. The inverse f−1 is continuously differentiable on U.
  3. The derivative of f−1 is given by (f−1)′(b)=1f′(a).
a
None of the statements are true
b
III only
c
I, II, and III
d
I and III only
e
II only
Submit
Correct
EXPLANATION

The inverse function theorem for single-variable functions states the following:

If f:U→R is continuously differentiable on an open set U⊆R, f(a)=b and f′(a)≠0 for a∈U, then

  • f is invertible in some neighborhood of a,

  • f−1, the inverse of f, is continuously differentiable in a neighborhood of b, and

  • the derivative of f−1 is given by (f−1)′(b)=1f′(a)=1f′(f−1(b)).

With that in mind, let's examine our statements in turn.

  • Statement I is false. According to the theorem, the function f must be invertible in some neighborhood of a, which could be smaller than U.

    For example, the function f(x)=2x4 satisfies the conditions of the inverse function theorem for U=(−2,2) and a=−1. However, f(x) is not invertible on the entire set U, only on a subset of U.

  • Statement II is false. According to the theorem, the functionf−1 must be continuously differentiable in a neighborhood of b, which could be smaller than U.

  • Statement III is true. According to the theorem, we must have (f−1)′(b)=1f′(a).

Therefore, the correct answer is "III only."
