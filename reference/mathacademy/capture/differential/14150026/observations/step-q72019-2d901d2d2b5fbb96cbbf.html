Which of the following statements are true about the function f(x,y,z)=2x+y−z?

  1. fy(1,1,1) is defined
  2. fz(0,1,2) is defined
  3. The partial derivative with respect to x is defined at (0,1,1)

EXPLANATION

First, we compute the partial derivatives of f(x,y,z):

∂f∂x=122x+y−z⋅2=12x+y−z∂f∂y=122x+y−z⋅1=122x+y−z∂f∂z=122x+y−z⋅(−1)=−122x+y−z

Now, let's examine the statements one-by-one.

  • Statement I is true. Indeed, the function f is defined at (1,1,1), where we have f(1,1,1)=2⋅1+1−1=2, and fy is also defined at (1,1,1): fy(1,1,1)=122⋅1+1−1=122.

  • Statement II is false. If we substitute (0,1,2) into f, we get f(0,1,2)=2⋅0+1−2=−1, which is undefined since the number under the radical is negative.

  • Statement III is false. If we substitute (0,1,1) into fx, we get fx(0,1,1)=12⋅0+1−1=10, which is undefined since we have division by zero.

Therefore, the correct answer is 'I only'.
