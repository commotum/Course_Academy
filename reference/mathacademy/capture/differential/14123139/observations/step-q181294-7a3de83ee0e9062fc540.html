If A={0,1,2} and B={x,y}, which of the following elements belong to (A×B)×A?

  1. (1,y,2)
  2. ((1,y),2)
  3. ((y,1),y)
a
II and III only
b
III only
c
I and II only
d
I only
e
II only
Submit
Incorrect
EXPLANATION

The Cartesian product A×B consists of all ordered pairs whose first coordinate belongs to A and whose second coordinate belongs to B.

In this case, A×B consists of every combination of {0,1,2} with {x,y}, as shown in the schematic below.

Hence, the set A×B is given by

A×B={(0,x),(0,y),(1,x),(1,y),(2,x),(2,y)}.

Note that |A×B|=|A|⋅|B|=3⋅2=6.

Now, the Cartesian product

(A×B)×A consists of every combination of A×B and A, as shown in the schematic below.

Note that |(A×B)×A|=|A×B|⋅|A|=6⋅3=18.

From the given options, we see that only ((1,y),2)∈(A×B)×A.

Therefore, the correct answer is "II only."
