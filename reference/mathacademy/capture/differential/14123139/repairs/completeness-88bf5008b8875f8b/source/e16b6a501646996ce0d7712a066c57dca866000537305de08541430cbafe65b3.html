If A={1,2,3} and B={x,y}, which of the following elements belong to (B×B)×A?

  1. (x,y,1)
  2. ((x,x),1)
  3. ((y,x),2)
a
II only
b
III only
c
I and II only
d
II and III only
e
I and III only
Submit
Correct
EXPLANATION

The Cartesian product A×B consists of all ordered pairs whose first coordinate belongs to A and whose second coordinate belongs to B.

In this case, B×B consists of every combination of {x,y} with {x,y}, as shown in the schematic below.

Hence, the set B×B is given by B×B={(x,x),(x,y),(y,x),(y,y)}.

Note that |B×B|=|B|⋅|B|=2⋅2=4.

Now, the Cartesian product (B×B)×A consists of every combination of B×B and A, as shown in the schematic below.

Note that |(B×B)×A|=|B×B|⋅|A|=4⋅3=12.

From the given options, we see that both ((x,x),1) and ((y,x),2) are in (B×B)×A.

Therefore, the correct answer is "II and III only."
