  1. A is upper triangular
  2. A is lower triangular
  3. AT is lower triangular

b

c

Incorrect
EXPLANATION

Let's analyze each statement in turn.

  • Statement I is false, since A has non-zero entries below the main diagonal: A=[00−31010001020010]

  • Statement II is false, since A has non-zero entries above the main diagonal: A=[00−31010001020010]

  • Statement III is false, since AT has non-zero entries above the main diagonal: AT=[00000110−30011020]

Therefore, the correct answer is "None".
