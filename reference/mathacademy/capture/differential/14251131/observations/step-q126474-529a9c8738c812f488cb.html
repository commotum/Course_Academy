Consider the matrix B=[−10−50225−2−4]. Which of the following statements are true?

  1. B is upper triangular
  2. B is lower triangular
  3. BT+B is upper triangular
a
II and III only
b
III only
c
II only
d
I and III only
e
I only
Submit
Correct
EXPLANATION

Let's analyze each statement in turn.

  • Statement I is false, since B has non-zero entries below the main diagonal: B=[−10−50225−2−4]

  • Statement II is false, since B has non-zero entries above the main diagonal: B=[−10−50225−2−4]

  • Statement III is true, since the result of BT+B has all the entries below the main diagonal equal to zero: BT+B=[−20004000−8]

Therefore, the correct answer is "III only".
