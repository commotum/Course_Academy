Recall that if X1,X2,…,Xn are independent and identically distributed continuous random variables with probability density function f(x;θ), where θ is an unknown parameter, then the likelihood function of a random sample x1,x2,…,xn is

L(θ)=P(X1=x1,X2=x2,…,Xn=xn)=∏i=1nf(xi;θ).

In our case, we are given a sample of n=5 independent normal random variables with unknown mean θ and variance σ2=1, for which the probability density function is

f(x;θ)=1σ2πe−12(x−θσ)2=12πe−(x−θ)2/2,x∈(−∞,∞).

We can calculate the likelihood function as follows:

L(θ)=∏i=1n(12πe−(xi−θ)2/2)=(2π)−n/2e−∑(xi−θ)2/2=(2π)−n/2e−(∑xi2−2θ∑xi+nθ2)/2=(2π)−n/2e−(C−2Sθ+nθ2)/2

where S=∑i=1nxi and C=∑i=1nxi2.

For our sample, we have that

S=∑i=1nxi=1.3+0.2+2.7+(−0.7)+0.9=4C=∑i=1nxi2=(1.3)2+(0.2)2+(2.3)2+(−0.7)2+(0.9)2=8.32

and n=5. Therefore,

L(θ)=(2π)−5/2e−(8.32−2(4)θ+5θ2)/2=1(2π)5/2e−4.16+4θ−2.5θ2.

Therefore,

g(θ)=−4.16+4θ−2.5θ2.
