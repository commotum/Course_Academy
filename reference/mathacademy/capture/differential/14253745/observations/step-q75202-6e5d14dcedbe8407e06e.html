The point P(0,2) is at the tip of r(t) for some specific value t0 of the parameter t. At this point, the vector r′(t0) is tangent to the curve, so the tangent line to the curve at P can be parametrized as

R(u)=r(t0)+ur′(t0),u∈(−∞,∞).

First, we find the value of t that corresponds to P. We know that

r(t)=⟨0,2⟩⟨1t−t,1t+t⟩=⟨0,2⟩,

and equating the components yields the following system:

{1t−t=01t+t=2

Subtracting the first equation from the second, we get 2t=2, hence t=1. This value also satisfies both equations. Therefore, P(0,2) is at the tip of the vector r(1).

We calculate r′(t): r′(t)=⟨ddt(1t−t),ddt(1t+t)⟩=⟨−1t2−1,−1t2+1⟩

Then, we evaluate r′(t) at t=1:

r′(1)=⟨−112−1,−112+1⟩=⟨−2,0⟩

Finally, the tangent line to the given curve at the point P(0,2) is
R(u)=⟨0,2⟩+u⟨−2,0⟩,u∈(−∞,∞).
