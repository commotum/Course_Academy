For a continuous random variable X with probability density function f(x) defined over a set S, the nth raw moment of X is given by E[Xn]=∫Sxn⋅f(x)dx.

We already know E[X]. So, we compute the second raw moment of X as follows: E[X2]=∫Sx2⋅f(x)dx=∫12x2⋅2x2dx=∫122dx=2x|12=2

Substituting E[X]=2ln⁡2 and E[X2]=2 into the simplified expression, we conclude that E[2X−5X2]=2E[X]−5E[X2]=2⋅2ln⁡2−5⋅2=4ln⁡2−10.
