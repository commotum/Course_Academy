The supremum of a set A is the smallest upper bound of A.

To find the supremum of this set, we must find the set containing all upper bounds of A (i.e., the set of upper bounds) and take the minimum of this set.

The elements of A are all the terms of the sequence an, given by

an=5−(23)n,n∈N={1,2,3,4,…}.

Let's draw some points of our sequence on the real line:

We see that an is increasing and converges to 5.

So, in our case, we have that

  • any number in the set x≥5 is an upper bound of A,

  • any number in the set x<5 is not an upper bound of A. In other words, we can always find a sufficiently large n so that 5−(23)n is greater than x for any x<5.

Therefore, [5,∞) is the set of upper bounds of A, and

sup(A)=min[5,∞)=5. Notice that 5 is not the maximum of A (the set A has no maximum). Therefore, we conclude that

sup(A)=5∉A.
