EXPLANATION

The supremum of a set C is the smallest upper bound of C.

To find the supremum of this set, we must find the set containing all upper bounds of C (i.e., the set of upper bounds) and take the minimum of this set.

In our case, we have the following:

  • Any number in the set x≥−1 is greater than or equal to the elements of C. Thus, the set [−1,∞) contains only upper bounds of C.

  • Any number in the set x<−1 is not an upper bound of C. In other words, we can always find an element of C that is greater than x for any x<−1.

Therefore, [−1,∞) is the set of upper bounds of C, and sup(C)=min[−1,∞)=−1.

Notice that −1 is also the maximum of C.
