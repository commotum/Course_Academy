Which of the following sequences diverge?

  2. an=2n2+nn2+1 for n≥1
  3. an=n5−n6n5+n4 for n≥1

EXPLANATION

Let's analyze each sequence in turn. We need to calculate the limit of each sequence as n approaches infinity.

  • In sequence I, the dominant term in the denominator is n, so we divide the numerator and the denominator by n and get limn→∞an=limn→∞n3n+1=limn→∞(n3n)(nn+1n)=limn→∞n2(1+1n)=limn→∞n21+0=∞. The limit does not exist, so the sequence diverges.

  • In sequence II, the dominant term in the denominator is n2, so we divide the numerator and the denominator by n2 and get limn→∞an=limn→∞2n2+nn2+1=limn→∞(2n2n2+nn2)(n2n2+1n2)=limn→∞(2+1n)(1+1n2)=2+01+0=2. The limit exists, so the sequence converges.

  • In sequence III, the dominant term in the denominator is n5, so we divide the numerator and the denominator by n5 and get limn→∞an=limn→∞n5−n6n5+n4=limn→∞(n5n5−n6n5)(n5n5+n4n5)=limn→∞(1−n)(1+1n)=limn→∞1−n1+0=−∞. The limit does not exist, so the sequence diverges.

In conclusion, sequences I and III diverge.
