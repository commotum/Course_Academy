Which of the following is the correct symbolic notation for the sentence given below?

"The function h maps the interval from 0 to 1 exclusive to the set containing the two numbers 0 and 1 only."

a
h:(0,1)→{0,1}
b
h:{0,1}→(0,1)
c
h:{0,1}→{0,1}
d
h:(0,1)→[0,1]
e
h:(0,1)→(0,1)
Submit
Correct
EXPLANATION

The sentence "The function h maps the interval from 0 to 1 exclusive to the set containing the two numbers 0 and 1 only" is equivalent to the following symbolic notation:

h:(0,1)→{0,1}

Here, the domain of h is (0,1), and the codomain of h is {0,1}.
