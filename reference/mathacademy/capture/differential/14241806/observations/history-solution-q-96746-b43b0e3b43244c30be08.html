The notation f:X→Y means that the function f maps the set X to the set Y. In this case,

  • the domain of f is X,

  • the codomain of f is Y.

With that in mind, let's examine our functions.

  • The domain of p is (−2,0), the interval from −2 to 0 (not including −2 nor 0).

  • The domain of q is (−2,0), the interval from −2 to 0 (not including −2 nor 0).

  • The domain of r is [−2,0), the interval from −2 to 0 (including −2 but not including 0).

Therefore, the correct answer is "I and II only."
