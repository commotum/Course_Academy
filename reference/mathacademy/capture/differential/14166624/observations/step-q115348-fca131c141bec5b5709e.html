The graph of the function y=f(x) passes through (0,5) and is concave down on the interval (−π,π). If f′(0)=12, estimate the value of f(2) using the tangent line approximation of f(x) at x=0 and determine whether the approximation is an underestimate or overestimate.

a
f(2)≈6, an underestimate
b
f(2)≈5, an overestimate
c
f(2)≈5, an underestimate
d
f(2)≈122, an overestimate
e
f(2)≈6, an overestimate
Submit
Incorrect
EXPLANATION

The tangent line approximation of f(x) at the point a=0 is L(x)=f(a)+f′(a)(x−a)=f(0)+f′(0)(x−0).

The function passes through the point (0,5), so we have f(0)=5. Also, we're told that f′(0)=12, so we get L(x)=5+12(x−0)=5+x2.

We can approximate f(2) by evaluating the tangent line approximation at x=2. We get f(2)≈L(2)=5+22=5+1=6.

Finally, since the function is concave down on the interval (−π,π), the linear approximation L(x) is above the graph near x=0, and therefore we have an overestimate.
