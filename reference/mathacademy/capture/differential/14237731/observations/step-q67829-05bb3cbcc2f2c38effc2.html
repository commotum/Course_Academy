Jim ran 56 of a mile in 15 of an hour. How many miles can Jim run in 1 hour?

a
4
b
336
c
5
d
413
e
416
Submit
Correct
EXPLANATION

To find the number of miles Jim can run in 1 hour, we can compute the unit rate of miles per hour. We do this by dividing the number of miles, 56, by the number of hours, 15, as follows:

56÷15

Dividing a fraction by another fraction is equivalent to multiplying the first fraction by the reciprocal of the second fraction:

56÷15=56×51=5×56×1=256

Finally, we write the resulting improper fraction as a mixed number:

256=4R1=416

Therefore, Jim can run 416 miles in 1 hour.
