Which of the following are mathematical statements?

  • P:(−2)⋅3

  • Q:5>3

  • R:7∈N

a
P and R only
b
P and Q only
c
Q and R only
d

 R only

Correct
EXPLANATION

A mathematical statement is a sentence or mathematical expression that is either true or false.

With that in mind, let's examine the given options:

  • P is not a statement because it is neither true nor false.

  • Q is a statement. This statement is true because 5 is larger than 3.

  • R is a statement. This statement is true because 7 is a natural number.

Therefore, the correct answer is "Q and R only."
