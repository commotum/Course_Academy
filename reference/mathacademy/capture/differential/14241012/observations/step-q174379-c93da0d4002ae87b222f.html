Which of the following are mathematical statements?

  • P: 0.5 is a rational number.

  • Q: 0.5 is an irrational number.

  • R: Divide 5 by 10.

a
Q only
b
P only
c
P and Q only
d
R only
e
Q and R only
Submit
Correct
EXPLANATION

A mathematical statement is a sentence or mathematical expression that is either true or false.

With that in mind, let's examine the given options:

  • P is a statement. This statement is true because 0.5=510, so it is a rational number.

  • Q is a statement. This statement is false because 0.5 is a rational number.

  • R is not a statement because it is neither true nor false. Rather, it is an instruction.

Therefore, the correct answer is "P and Q only."
