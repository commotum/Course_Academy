Which of the following are mathematical statements?

  • P:{2,3,7}∩{3,5,6}=∅

  • Q:π2−π

  • R:3 is a prime number.

a
P and R only
b
Q and R only
c
Q only
d
P only
e
P and Q only
Submit
Correct
EXPLANATION

A mathematical statement is a sentence or mathematical expression that is either true or false.

With that in mind, let's examine the given options:

  • P is a statement. This statement is false because the intersection of the given sets is the set {3}.

  • Q is not a statement because it is neither true nor false.

  • R is a statement. This statement is true since 3 is indeed a prime number.

Therefore, the correct answer is "P and R only."
