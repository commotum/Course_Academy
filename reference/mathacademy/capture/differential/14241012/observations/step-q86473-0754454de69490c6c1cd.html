Which of the following is a mathematical statement?

a
The negative numbers.
b
Subtract 2 from 5.
c
The height of a triangle.
d
The set of the natural numbers.
e
π is an irrational number.
Submit
Correct
EXPLANATION

A mathematical statement is a sentence or mathematical expression that is either true or false.

Of the given sentences, the only sentence that is either true or false is "π is an irrational number." (This sentence is true.)

All the other sentences are neither true nor false.
