Which of the following is a mathematical statement?

a
The set of the odd numbers.
b
The number π.
c
3 is a positive number.
d
Why is 2 an even number?
e
The hypotenuse of a triangle.
Submit
Incorrect
EXPLANATION

A mathematical statement is a sentence or mathematical expression that is either true or false.

Of the given sentences, the only sentence that is either true or false is "3 is a positive number." (This sentence is true.)

All the other sentences are neither true nor false.
