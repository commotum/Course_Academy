EXPLANATION

We need to find the minimum value of

f(x,y,z)=3x+2y+z

subject to the constraints

g(x,y,z)=x+2y+z=1,h(x,y,z)=4x2+2y2=1.

Since f(x,y,z) is continuous and the constraint is closed and bounded, f(x,y,z) reaches a global maximum and a global minimum on the constraint.

Therefore, by the method of Lagrange multipliers, we must solve the following system:

{∇f(x,y,z)=λ∇g(x,y,z)+μ∇h(x,y,z)g(x,y,z)=1h(x,y,z)=1

We start by expanding the first equation:

∇f(x,y,z)=λ∇g(x,y,z)+μ∇h(x,y,z)⟨fx,fy,fz⟩=λ⟨gx,gy,gz⟩+μ⟨hx,hy,hz⟩⟨3,2,1⟩=λ⟨1,2,1⟩+μ⟨8x,4y,0⟩

Therefore, we have the following system:

{3=λ+8μx2=2λ+4μy1=λ⇒{x=14μμy=0λ=1

Notice that μ can't be zero since this leads to a contradiction. So, from the second equation above, we must have y=0.

Next, we substitute y=0 into the second constraint:

4x2+2y2=14x2=1x=±12

Finally, we substitute x and y into the first constraint:

  • If x=12 and y=0, we have x+2y+z=112+2(0)+z=112+z=1z=12.

  • If x=−12 and y=0, we have x+2y+z=1−12+2(0)+z=1−12+z=1z=32.

Therefore, f has possible extreme values at the points (12,0,12),(−12,0,32).

We evaluate f at each of these points. These are given in the following table:

(x,y,z) (12,0,12) (−12,0,32)
f(x,y,z) 2 0

Therefore, the function reaches a minimum value at (−12,0,32), and its minimum value is 0.
