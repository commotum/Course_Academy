  3. L is closed under scalar multiplication
  4. L is not a subspace of R3

EXPLANATION

Recall the following two facts about subspaces:

  • A set of vectors in a vector space is a subspace if it is closed under vector addition and scalar multiplication.

  • If a non-empty set is closed under scalar multiplication, then this set must contain the zero-vector (because 0⋅v=0 for any vector v). So, if a set does not contain the zero vector, then this set is not closed under scalar multiplication.

First, note that the direction vector of the line L is d=[1−11]−[000]=[1−11]. This means that the vector equation of the line is

r=[000]+t[1−11]=[t−tt]

for t∈R, and the corresponding Cartesian equation is x=−y=z.

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, from the definition of L we have that the point (0,0,0) is in L.

  • Statement II is true. Let, for example, a=[a−aa]∈L and b=[b−bb]∈L. Then, a+b=[a−aa]+[b−bb]=[a+b−a+(−b)a+b]=[a+b−(a+b)a+b], which satisfies the conditions x=−y=z. Therefore, a+b∈L.

  • Statement III is true. Let, for example, a=[a−aa]∈L and k∈R. Then, k⋅a=k⋅[a−aa]=[kak(−a)ka]=[ka−(ka)ka], which satisfies the conditions x=−y=z. Therefore, k⋅a∈L.

  • Statement IV is false. Since statements II and III are true, L is a subspace of R3.

Therefore, the correct answer is "I, II, and III only."
