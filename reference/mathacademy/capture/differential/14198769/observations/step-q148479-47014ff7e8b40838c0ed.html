The scatter plot for a sample of paired observations is shown above. What vectors correspond to the direction of the first principal component of the data?

a
c only
b
a and c only
c
a only
d
b and c only
e
b only
Submit
Incorrect
EXPLANATION

Recall that the first principal component of the data corresponds to the direction in which the data varies the most (the direction where we have the maximum variance).

In our diagram, the direction where the variance changes the most corresponds (approximately) to the vectors b and c, as shown below.

Therefore, the correct answer is "b and c only."
