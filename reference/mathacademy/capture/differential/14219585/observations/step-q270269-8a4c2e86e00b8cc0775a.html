EXPLANATION

Using the chain rule, we have

ddxf(y(x))=dfdy⋅dydx.

Let's consider each of the factors in turn.

  • The function f acts on a vector y∈R2 and outputs a vector f(y)∈R2. Thus, the total derivative of f with respect to y is a 2×2 matrix dfdy=[∂f1∂y1∂f1∂y2∂f2∂y1∂f2∂y2]=[∂∂y1(2y1y2)∂∂y2(2y1y2)∂∂y1(y13)∂∂y2(y13)]=[2y22y13y120]. Evaluating at y0=y(x0)=[2(1)3(−1)2]=[23], we get dfdy|y0=[64120].
  • The function y acts on a vector x∈R2 and outputs a vector y(x)∈R2. Thus, the total derivative of y with respect to x is a 2×2 matrix dydx=[∂y1∂x1∂y1∂x2∂y2∂x1∂y2∂x2]=[∂∂x1(2x1)∂∂x2(2x1)∂∂x1(3x22)∂∂x2(3x22)]=[2006x2]. Evaluating at x0=[1−1], we get dydx|x0=[200−6].

Therefore, we have ddxf(y(x))|x0=dfdy|y0⋅dydx|x0=[64120]⋅[200−6]=[12−24240].
