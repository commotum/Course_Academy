EXPLANATION

Recall that the marginal distribution for X corresponds to the row totals, and the marginal distribution for Y corresponds to the column totals.

f Y=−1 Y=0 Y=1 Y=2 fX
X=1 0.1 0.05 0.05 0.1 0.3
X=2 0.15 0.05 0.1 0.15 0.45
X=3 0.05 0.05 0.05 0.1 0.25
fY 0.3 0.15 0.2 0.35 1

Therefore, the probability mass functions for X and Y are given by the following tables:

x 1 2 3
fX(x) 0.3 0.45 0.25

y −1 0 1 2
fY(y) 0.3 0.15 0.2 0.35

Now, we can compute the expected values for X and Y:

E[X]=∑i=1nxifX(xi)=1⋅0.3+2⋅0.45+3⋅0.25=0.3+0.9+0.75=1.95

E[Y]=∑i=1nyifY(yi)=(−1)⋅0.3+0⋅0.15+1⋅0.2+2⋅0.35=−0.3+0+0.2+0.7=0.6.

Finally, using the properties of expectation, we obtain

E[4X−5Y]=4E[X]−5E[Y]=4(1.95)−5(0.6)=7.8−3=4.8.
