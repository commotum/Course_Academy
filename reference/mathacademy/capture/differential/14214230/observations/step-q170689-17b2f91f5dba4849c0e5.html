The return on a risky investment can be negative (meaning that the investor loses money) or positive. Assuming that the return on a particular investment is uniformly distributed between −7.5% and 12.5%, what is the mean return of this investment?

a
2.5%
b
−2.5%
c
10%
d
6.25%
e
5%
Submit
Correct
EXPLANATION

Let X represent the return on the investment. From the problem statement, we know that X∼U[−7.5,12.5], and we wish to compute E[X].

In general, if X∼U[a,b], then X has the following expected value:

E[X]=a+b2

So, for our random variable X∼U[−7.5,12.5], we have the following expected value:

E[X]=−7.5+12.52=2.5

Therefore, the mean return on the investment is 2.5%.
