EXPLANATION

First, let's draw our region D and rectangle R:

Notice that the rectangle R contains the region D completely.

Now, if we define f(x,y) to be equal xy+y2 on D and to be equal 0 outside D, we obtain

∬D(xy+y2)dA=∬Rf(x,y)dA.

With that in mind, let's examine each of the given functions.

  • Functions I and III equal xy+y2 on D and equal 0 outside D.

  • We cannot use function II. The function is not identically zero for all points in R∖D. For example, (x,y)=(1,1)∈R∖D, but the function is nonzero at this point.

Therefore, the correct answer is "I and III only."
