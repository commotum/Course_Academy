First, we find the lowest and highest y-values in the graph.

  • The lowest y-value is 0. This occurs at the point (−1,0). However note that this point is not actually included in the graph.

  • The highest y-value is 4. This occurs at the point (3,4).

The function covers all the y-values between 0 and 4, including 4 but not including 0.

Therefore, the range is 0<y≤4, which can also be written as 0<f(x)≤4.
