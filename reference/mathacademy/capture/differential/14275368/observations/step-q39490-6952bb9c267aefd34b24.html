Which of the following sets are orthogonal?

  1. U={[121−2],[13−13],[2−121]}
  2. V={[22−2],[1−2−1],[−60−6]}
  3. W={[4−1],[−2−2]}
a
V only
b
U and V only
c
U only
d
V and W only
e
U and W only
Submit
Correct
EXPLANATION

Let's denote the vectors of the given sets as {u1,u2,u3}, {v1,v2,v3}, and {w1,w2}, respectively.

The sets U,V, and W are orthogonal if the following conditions on each set hold:

  • u1⋅u2=0,u1⋅u3=0,u2⋅u3=0.

  • v1⋅v2=0,v1⋅v3=0,v2⋅v3=0.

  • w1⋅w2=0.

With that in mind, let's examine our sets in turn.

  • For the set U, we get the following: u1⋅u2=[121−2]⋅[13−13]=1+6−1−6=0✓u1⋅u3=[121−2]⋅[2−121]=2−2+2−2=0✓u2⋅u3=[13−13]⋅[2−121]=2−3−2+3=0✓ So, the set U is orthogonal.

  • For the set V, we get the following: v1⋅v2=[22−2]⋅[1−2−1]=2−4+2=0✓v1⋅v3=[22−2]⋅[−60−6]=−12+0+12=0✓v2⋅v3=[1−2−1]⋅[−60−6]=−6+0+6=0✓ So, the set V is orthogonal.

  • For the set W, notice that w1⋅w2=[4−1]⋅[−2−2]=−8+2=−6≠0× So, W is not an orthogonal set.

Therefore, we conclude that the correct answer is "U and V only".
