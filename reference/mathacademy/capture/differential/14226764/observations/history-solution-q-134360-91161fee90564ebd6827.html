The (population) linear correlation coefficient for data sets x and y is given by the following formula:

ρ(x,y)=Cov(x,y)σx⋅σy

In addition, we have the following rule of thumb:

  • if |ρ|>0.7, the correlation is strong

  • if 0.3≤|ρ|≤0.7, the correlation is weak

  • if |ρ|<0.3, then the correlation is negligible

  • Statement II is false, while statement III is true. Since 0.3≤|ρ|≤0.7, the correlation is weak. Also, since ρ is positive, the correlation is positive.
