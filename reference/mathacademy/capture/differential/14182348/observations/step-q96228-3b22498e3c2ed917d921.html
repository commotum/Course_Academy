EXPLANATION

Recall that if A=UΣVT is a singular value decomposition of A, and σi≠0, then the ith column of U can be found as

ui=1σiAvi,

where ui and vi are the ith columns of the orthogonal matrices U and V, respectively.

From the matrix Σ, we deduce that the singular values are σ1=26 and σ2=0. Therefore, the first column of U is

u1=1σ1Av1=126[3322][1212]=126[6242]=[313213].

Since the second singular value is σ2=0, we can't use the same formula to find the second column of U. But we know that U must be orthogonal. Hence, we must find a vector

u2=[x1x2]

such that

u1⋅u2=0and‖u2‖=1.

Solving u1⋅u2=0, which is equivalent to 313x1+213x2=0, we get a nonzero solution [−23]. Normalizing this vector, we finally obtain the second column of U: u2=113[−23]=[−213313]
