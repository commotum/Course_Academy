Suppose X1,X2,…,Xn is a sequence of random variables representing a random sample of size n drawn from a population. A statistic is a random variable expressed as a function of Xi.

Statistics cannot involve unknown population parameters.

With that in mind, let's examine each expression.

  • Expression I is a statistic. It is a function of the sample X1,X2,…,X20 and the known population mean μ only. Note that a statistic doesn't need to include every sample element.

  • Expression II is not a statistic. It is a function that contains the unknown population standard deviation σ.

  • Expression III is not a statistic. It is a function that contains the unknown variance σ2.

Therefore, the correct answer is "I only."
