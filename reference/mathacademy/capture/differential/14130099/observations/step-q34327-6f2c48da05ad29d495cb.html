Which of the following sets is a subspace of R2?

  1. A={⟨x,y⟩∈R2:x2+y2≥0}
  2. B={⟨x,y⟩∈R2:x=2y}
  3. C={⟨x,y⟩∈R2:x−y=0}
a
II and III only
b
I and II only
c
I only
d
I, II, and III
e
II only
Submit
Incorrect
EXPLANATION

Let's analyze each of the subsets.

  • The set A is a subspace. It actually represents the whole space R2, since the coordinates of any vector ⟨x,y⟩ satisfy the inequality x2+y2≥0.

  • The set B is a subspace. It represents a line, and a line is a subspace if and only if it passes through the origin. Here, the components of the zero vector 0=⟨0,0⟩ satisfy the equation x=2y since 0=2⋅0. So, 0 lies in B.

  • The set C is a subspace. It also represents a line, and a line is a subspace if and only if it passes through the origin. Here, the components of the zero vector 0=⟨0,0⟩ satisfy the equation x−y=0 since 0−0=0. So, 0 lies in C.

So, the correct answer is "I, II, and III."
