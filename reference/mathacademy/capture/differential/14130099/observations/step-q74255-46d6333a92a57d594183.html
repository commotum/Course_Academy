Which of the following sets is a subspace of R3?

  1. A={⟨x,y,z⟩∈R3:x2+y2+z2<12}
  2. B={⟨x,y,z⟩∈R3:5x−y−z=0}
  3. C={⟨x,y,z⟩∈R3:5−x−z=0}
a
III only
b
I only
c
II and III only
d
II only
e
I and III only

Correct
EXPLANATION

Let's analyze each of the subsets.

  • The set A is not a subspace. Indeed, the vector u=⟨14,0,0⟩ is in A, since (14)2+02+02=14<12, but, 4u=⟨1,0,0⟩ is not in B, since 12+02+02>12. So, A is not closed under scalar multiplication.

  • The set B is a subspace. It represents a plane, and a plane is a subspace if and only if it passes through the origin. Here, the components of the zero vector 0=⟨0,0,0⟩ satisfy the equation 5x−y−z=0 since 5⋅0−0−0=0. So 0 lies in B.

  • The set C is not a subspace because it does not contain the zero vector. Indeed, 0=⟨0,0,0⟩ does not satisfy the equation 5−x−z=0 since 5−0−0≠0.

In conclusion, the correct answer is "II only."
