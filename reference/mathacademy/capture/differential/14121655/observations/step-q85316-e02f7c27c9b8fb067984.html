Which of the following random variables could be modeled using a Poisson distribution?

  1. The number of visits a web page has per minute
  2. The number of works of art created by a sculptor in a period of one year
  3. The average height of the players on a basketball team
a
I only
b
III only
c
I and III only
d
I, II, and III
e
I and II only
Submit
Correct
EXPLANATION

A Poisson distribution models the number of events that occur in an interval of time or space if events occur independently and at a constant average rate.

With that in mind, let's consider each of the given random variables.

  • Random variable I follows a Poisson distribution. The number of visits on a web page can be modeled as independent events with a constant average rate, and we wish to know how many events occur in an interval of time (a minute).

  • Random variable II follows a Poisson distribution. The number of works of art can be modeled as independent events with a constant average rate, and we wish to know how many events occur in an interval of time (a year).

  • Random variable III does not follow a Poisson distribution. There are no events that occur at a constant average rate, and there is no interval of time or space.

Therefore, the correct answer is "I and II only."
