EXPLANATION

First, we find the lowest and highest y-values in the graph.

  • The lowest y-value is 0. This occurs at the point (4,0). However, note that this point is not actually included in the graph.

  • The highest y-value is 3. This occurs at the point (−2,3). However, note that this point is not actually included in the graph.

The function covers all the y-values between 0 and 3, but not including 0 nor 3.

Therefore, the range is 0<y<3, which can also be written as 0<f(x)<3.
