EXPLANATION

First, we find the lowest and highest y-values in the graph.

  • The lowest y-value is −2. This occurs at the point (−4,−2).

  • The highest y-value is 4. This occurs at the point (4,4). However note that this point is not actually included in the graph.

The function covers all the y-values between −2 and 4, including −2 but not including 4.

Therefore, the range is −2≤y<4, which can also be written as −2≤f(x)<4.
