Using the cumulative distribution function table of the Poisson random variable X∼Po(10) given below, compute P(X=7).

x 3 4 5 6 7 8 9
P(X≤x) 0.0103 0.0293 0.0671 0.1301 0.2202 0.3328 0.4579
P(X=7)=
0.0901
Submit
Correct
EXPLANATION

The cumulative distribution function of a discrete random variable X is a function F(x) such that

F(x)=P(X≤x).

So, we have

F(7)=P(X≤7)=P(X∈{0,1,…,7})=P(X∈{0,1,…,6})+P(X=7)=P(X≤6)+P(X=7)=F(6)+P(X=7).

Therefore,

P(X=7)=F(7)−F(6)=0.2202−0.1301=0.0901.
