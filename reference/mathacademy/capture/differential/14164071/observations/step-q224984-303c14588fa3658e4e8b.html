Consider the Poisson distribution Po(6). Rounding to 4 decimal digits, fill in the missing values in the corresponding table for the cumulative distribution function below.
x 0 1 2 3 4 5 6
P(X≤x)
0.0025
0.0174
 0.0620 0.1512 0.2851 0.4457 0.6063
Submit
Correct
EXPLANATION

The cumulative distribution function of a discrete random variable X is a function F(x) such that F(x)=P(X≤x).

The probability mass function for the Poisson distribution Po(λ) is given by f(x)=λxe−λx!,x=0,1,2,3,….

In our case, λ=6.

Therefore, we compute the missing elements of the table as follows:

F(0)=P(X≤0)=P(X=0)=60e−60!=1⋅e−61≈0.0025

F(1)=P(X≤1)=P(X=0)+P(X=1)=60⋅e−60!+61⋅e−61!=1⋅e−61+6⋅e−61≈0.0174
