Using the cumulative distribution function table of the Poisson random variable X∼Po(5.5) given below, compute P(1<X<7).

x 1 2 3 4 5 6 7
P(X≤x) 0.0266 0.0884 0.2017 0.3575 0.5289 0.6860 0.8095
P(1<X<7)=
0.6594
Submit
Correct
EXPLANATION

The cumulative distribution function of a discrete random variable X is a function F(x) such that

F(x)=P(X≤x).

So, we have

F(6)=P(X<7)=P(X∈{0,1,…,6})=P(X∈{0,1})+P(X∈{2,3,4,6})=P(X≤1)+P(1<X<7)=F(1)+P(1<X<7).

Therefore,

P(1<X<7)=F(6)−F(1)=0.6860−0.0266=0.6594.
