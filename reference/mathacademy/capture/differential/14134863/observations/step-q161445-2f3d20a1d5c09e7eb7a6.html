Consider the set A, defined by A={(x,y)∈R2:y<1−x}.

Which of the following statements are true?

  1. A contains all of its boundary points.
  2. A contains none of its boundary points.
  3. intA=A
a
I only
b
I and III only
c
None of the statements are true.
d
II and III only
e
III only

Correct
EXPLANATION

The boundary of a set A, denoted ∂A, is the set that contains all the boundary points of A.

In this case, the set A and its boundary ∂A are shown below.

The interior of a set A, denoted intA, is the set containing all the interior points of A. It contains every point in A except the boundary points: intA=A−∂A

Notice that, in this case, the set A contains none of its boundary points.

With that in mind, let's examine each statement:

  • Statement I is false, while statement II is true. As we've seen, A contains none of its boundary points.

  • Statement III is true. Since A contains none of its boundary points, we must have intA=A.

Therefore, the correct answer is "II and III only."
