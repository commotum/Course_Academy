First, we find the lowest and highest y-values in the graph.

  • The lowest y-value is −4. This occurs at the point (−4,−4). However note that this point is not actually included in the graph.

  • The highest y-value is 5. This occurs at the point (4,5).

The function covers all the y-values between −4 and 5, including 5 but not including −4.

Therefore, the range is −4<y≤5, which can also be written as −4<f(x)≤5.
