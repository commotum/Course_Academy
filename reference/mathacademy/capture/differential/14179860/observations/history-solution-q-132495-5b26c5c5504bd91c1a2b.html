Given a binomial random variable X∼B(n,p), if

  • np>5, and

  • n(1−p)>5,

we can approximate X as a normal random variable Y with mean μ=np and variance σ2=np(1−p), that is,

Y∼N(np,np(1−p)).

Here, we have n=240 and p=0.45. Therefore, np=240⋅0.45=108>5✓n(1−p)=240⋅(1−0.45)=132>5.✓ So, we can approximate our binomial random variable X with a normal random variable Y with mean

μ=np=(240)(0.45)=108

and variance

σ2=np(1−p)=(240)(0.45)(1−0.45)=59.4.

That is, we can approximate X by Y∼N(108,59.4).

Now, we can estimate the desired probability P(X>100). Using a continuity correction, we have

P(X>100)=P(X≥101)≈P(Y≥100.5).

To compute this probability, we transform to a standard normal random variable by z-scoring:

P(Y≥100.5)=P(Z≥100.5−10859.4)≈P(Z≥−0.97)=1−P(Z<−0.97)=1−P(Z≤−0.97)=1−Φ(−0.97)=1−0.1660=0.834

Therefore,

P(X>100)≈0.834. Note: Using a software package for the approximation gives a probability of 0.8347.
