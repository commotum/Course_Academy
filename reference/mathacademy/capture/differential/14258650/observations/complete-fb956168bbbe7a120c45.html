The random variable X has the following probability distribution.

x 0 1 2 3 4
fX(x) 0.4 0.2 0.3 0.05 0.05

Let Y=X−4. The distribution of Y is given below.

y −4 −3 −2 c d
fY(y) a b 0.3 0.05 0.05

What is the value of a+c+d?

a
−1.4
b
−2.65
c
−2.2
d
−3.85
e
−0.6
Submit
Correct
EXPLANATION

First, let's add a Y=X−4 row to our table.

x 0 1 2 3 4
y −4 −3 −2 −1 0
fX(x) 0.4 0.2 0.3 0.05 0.05

Now, fX(x)=fY(y) for corresponding values of X and Y. Therefore, the distribution of Y is as follows:

y −4 −3 −2 −1 0
fY(y) 0.4 0.2 0.3 0.05 0.05

So, we have a=0.4,c=−1,d=0, and therefore a+c+d=−0.6.
