Given that det(A)=3, which of the following statements are true?

  1. −4det(AT)+2det(I)=3
  2. 2det(AT)=6
  3. det(AT)−det(I)=1
a
I only
b
II and III only
c
I and III only
d
None
e
II only
Submit
Incorrect
EXPLANATION

From the properties of determinants, we know that det(AT)=det(A)=3 and det(I)=1.

With that in mind, let's analyze each statement in turn.

  • Statement I is false. Indeed, −4det(AT)+2det(I)=−4⋅3+2⋅1=−10≠3.

  • Statement II is true. We have 2det(AT)=2⋅3=6.

  • Statement III is false. We have det(AT)−det(I)=3−1=2≠1.

In conclusion, the correct answer is "II only."
