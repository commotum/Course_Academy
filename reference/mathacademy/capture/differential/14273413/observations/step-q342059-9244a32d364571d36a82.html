EXPLANATION

First, note that the given interval is symmetric about the mean: P(1<X<5)=P(3−2<X<3+2)

So, we find the cumulative probability using symmetry: P(1<X<5)=0.37582P(3<X<5)=0.3758P(3<X<5)=0.1879P(X<5)−P(X<3)=0.1879P(X<5)−0.5=0.1879P(X<5)=0.6879P(X≤5)=0.6879

Then, we transform to a standard normal random variable by z-scoring:

P(X≤5)=0.6879P(Z≤5−3σ)=0.6879Φ(2σ)=0.68792σ=Φ−1(0.6879)

According to the table, we have

Φ(0.49)=0.6879⇒Φ−1(0.6879)=0.49.

Therefore, we have

2σ=0.49σ=20.49σ≈4.08

rounded to 2 decimal places.
