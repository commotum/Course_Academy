The Cartesian product A×B consists of all ordered pairs whose first coordinate belongs to A and whose second coordinate belongs to B.

A×B={(a,b):a∈A,b∈B}

In this case, the set S=Z×R contains every point in R2 whose x-coordinate is an integer number and whose y-coordinate is any real number.

S={(x,y):x∈Z,y∈R}
