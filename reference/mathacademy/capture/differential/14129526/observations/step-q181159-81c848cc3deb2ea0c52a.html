EXPLANATION

A point P(x,y) lies inside the rectangle if the following conditions are satisfied:

3<x<6,1<y<4.

Notice that we also need to

  • include the left edge (x=3), and

  • include the bottom edge (y=1).

Therefore, we change the corresponding inequality symbols to non-strict, as follows:

3≤x<6,1≤y<4.

Moreover, since every real value in these intervals is included, x∈R,y∈R, and therefore

(x,y)∈R×R=R2.

Therefore, we can write our set as follows:

{(x,y)∈R2:3≤x<6,1≤y<4}.
