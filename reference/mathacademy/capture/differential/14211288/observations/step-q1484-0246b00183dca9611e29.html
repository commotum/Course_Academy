Simplify the statement (Q⇒P)⇒R.

a
(Q∧¬P)∨R
b
(¬Q∧¬P)∨R
c
(Q∧¬P)∧R
d
(Q∨¬P)∧R
e
(¬Q∨¬P)∨R
Submit
Correct
EXPLANATION

First, note that (Q⇒P)⇒R≡(¬Q∨P)⇒R≡¬(¬Q∨P)∨R.

We can distribute the negation over the disjunction using De Morgan's law:

¬(¬Q∨P)∨R≡(¬(¬Q)∧¬P)∨R

Canceling out double negations, we reach

(¬(¬Q)∧¬P)∨R≡(Q∧¬P)∨R.

So the given statement is equivalent to (Q∧¬P)∨R.
