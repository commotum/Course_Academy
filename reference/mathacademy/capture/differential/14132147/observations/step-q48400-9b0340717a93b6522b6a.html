The graph of the function y=f(x) passes through (1,4) and is concave down on the interval (0,5). If f′(1)=−2, estimate the value of f(0.8) using the tangent line approximation of f(x) at x=1 and determine whether the approximation is an underestimate or overestimate.

a
f(0.8)≈4.2, an overestimate
b
f(0.8)≈4.2, an underestimate
c
f(0.8)≈3.8, an overestimate
d
f(0.8)≈4.4, an overestimate
e
f(0.8)≈4.4, an underestimate
Submit
Correct
EXPLANATION

The tangent line approximation of f(x) at the point a=1 is L(x)=f(a)+f′(a)(x−a)=f(1)+f′(1)(x−1).

The graph of the function passes through the point (1,4), so we have f(1)=4. Also, we're told that f′(1)=−2, so we get L(x)=4+(−2)(x−1)=4−2x+2=−2x+6.

We can approximate f(0.8) by evaluating the tangent line approximation at x=0.8. We get f(0.8)≈L(0.8)=−2(0.8)+6=−1.6+6=4.4.

Finally, since the function is concave down on the interval (0,5), the linear approximation L(x) is above the graph near x=1, and therefore we have an overestimate.
