f Y=−1 Y=0 Y=1 Y=3

If F(x,y) is the joint CDF of X and Y, find F(0,32).

0.3

0.45

EXPLANATION

If X and Y are discrete random variables with the joint probability mass function f(x,y), then the corresponding joint CDF is given by

F(x,y)=P(X≤x,Y≤y)=∑xi≤x∑yi≤yf(xi,yi).

By definition, we have

F(0,32)=P(X≤0,Y≤32).

We start by highlighting all cells in the table that correspond to X≤0,Y≤32.

f Y=−1 Y=0 Y=1 Y=3
X=−1 0.15 0.25 0.05 0.15
X=1 0.15 0.1 0.05 0.1

Therefore, we obtain

F(0,32)=∑x≤0∑y≤3/2f(x,y)=f(−1,−1)+f(−1,0)+f(−1,1)=0.15+0.25+0.05=0.45.
