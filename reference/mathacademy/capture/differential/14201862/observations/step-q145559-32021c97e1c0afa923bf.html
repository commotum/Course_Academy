EXPLANATION

If X and Y are discrete random variables with the joint probability mass function f(x,y), then the corresponding joint CDF is given by

F(x,y)=P(X≤x,Y≤y)=∑xi≤x∑yi≤yf(xi,yi).

By definition, we have

F(2,4)=P(X≤2,Y≤4).

We start by highlighting all cells in the table that correspond to X≤2,Y≤4.

f Y=2 Y=4 Y=6
X=1 0.1 0.25 0.25
X=2 0.05 0.15 0.2

Therefore, we obtain

F(2,4)=∑x≤2∑y≤4f(x,y)=f(1,2)+f(1,4)+f(2,2)+f(2,4)=0.1+0.25+0.05+0.15=0.55.
