The point a∈Rn is a critical point of the function f:Rn→R if f′(a)=0T. In such cases, we can classify a as follows:

  • if f″(a) is positive definite, then a is a local minimum

  • if f″(a) is negative definite, then a is a local maximum

  • if f″(a) is neither positive-definite nor negative-definite, then a is a saddle point

In this case, we have A=f″(a). Now, before we examine the statements, let's recall how to categorize quadratic forms.

Let Δi for i=1,2,…,n denote the leading principal minors of an n×n matrix A. Then, according to Sylvester's criterion, the quadratic form xTAx (as well as the matrix A) is

  • positive-definite if and only if Δi>0 for all i=1,2,…,n,

  • negative-definite if and only if, for all i=1,2,…,n, we have Δi<0 when i is odd, and Δi>0 when i is even.

With that in mind, let's examine each statement in turn.

  • Statement I is false. Indeed, a11=5, but det(A)=|5221|=1.

  • Statement II is true. Notice that Δ1=a11=5>0,Δ2=|5221|=1>0. So, by Sylvester's criterion, the matrix A is positive-definite.

  • Statement III is true. Since the matrix A is positive-definite, the critical point a is a local minimum of f.

Therefore, the correct answer is "II and III only."
