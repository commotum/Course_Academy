Given that ‖u‖=5 and u⋅v=−15, find the smallest possible value of ‖v‖.

a
15
b
1
c
3
d
5
e
10
Submit
Correct
EXPLANATION

Using the Cauchy-Schwarz inequality, we have

|u⋅v|≤‖u‖⋅‖v‖|−15|≤5⋅‖v‖15≤5⋅‖v‖.

Now, we multiply both sides of the inequality by 15:

15⋅15≤15⋅5⋅‖v‖3≤‖v‖

Therefore, the smallest possible value of ‖v‖ is 3.
