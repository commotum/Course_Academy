Suppose we have a dataset consisting of 4 datapoints with 2 features in the form of the 4×2 matrix X=[−0.270.39−0.99−1.23−0.13−0.281.391.12] where the data has been standardized (the mean of each feature is 0 and the standard deviation is 1). We are also given the SVD decomposition X=UΣVT where:

U=[0.0350.860.1320.491−0.657−0.314−0.2080.653−0.121−0.1960.9690.0920.743−0.351−0.0320.569]Σ=[2.389000.5420000]V=[0.707−0.7070.7070.707]

Which of the following matrices corresponds to the one-dimensional version of the data that preserves the most variance?

  1. [0.035−0.657−0.1210.743]⋅2.389
  2. [0.7070.707]
  3. [0.0350.860.1320.491]⋅2.389
a
I only
b

c

d

Correct
EXPLANATION

The one-dimensional version of the data that preserves the most variance is the projection onto the first principal component.

Recall that the principal components are the eigenvectors of the covariance matrix XTX.

Using the SVD and the fact that U is orthogonal (i.e., UTU=I), we get that

XTX=(UΣVT)T(UΣVT)=VΣTUTUΣVT=VΣTΣVT.

Now, since Σ is a diagonal matrix, and so is ΣTΣ, we know that the eigenvectors of XTX are the columns of V.

In particular, the first principal component is the eigenvector of XTX corresponding to the largest eigenvalue. And since Σ contains the corresponding singular values (square roots of the eigenvalues) in decreasing order, the first principal component is v1, the first column of V.

With that in mind, let's examine the given options.

  • Option I corresponds to the one-dimensional version of the data that preserves the most variance. Notice that it represents u1⋅σ1, where u1 is the first column of U and σ1 is the first singular value. But this equals X⋅v1:

X⋅v1=UΣVT⋅v1=UΣ⋅[10]=U⋅[σ1000]=u1⋅σ1

  • Option II represents v1, which is the first principal component. It represents a direction in feature space, not a version of the data. Notice that it is also dimensionally incorrect, since it is a 2×1 matrix instead of 4×1.

  • Option III uses the values of the first row of U multiplied by σ1. However, the projection corresponds to the first column of U. Thus, using the row vector is incorrect.

Therefore, the correct answer is "I only."
