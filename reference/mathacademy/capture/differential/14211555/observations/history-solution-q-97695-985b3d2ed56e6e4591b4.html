Let X represent the number of obstacles in a randomly selected game. From the problem statement, we know that X∼U{80,81,…,125}, and we wish to compute SD[X].

In general, if X∼U{a,a+1,…,b}, then the variance of X is

Var[X]=|S|2−112

where S={a,a+1,…,b}.

Now, we know that

|S|=b−a+1=125−80+1=46. So, for our random variable X∼U{80,81,…,125}, we have the following variance:

Var[X]=462−112=211512

Finally,

SD[X]=211512≈13.28.
