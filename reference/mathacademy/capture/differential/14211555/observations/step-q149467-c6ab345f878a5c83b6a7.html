In a math test, students have to answer a multiple-choice question, where the answers are labeled from 0 to 6. If Steph selects an answer at random, what is the expected value of her chosen answer?

a
4
b
3
c
2
d
3.5
e
3.25
Submit
Correct
EXPLANATION

Let X represent the number of the chosen answer. From the problem statement, we know that X∼U{0,1,…,6}, and we wish to compute E[X].

In general, if X∼U{a,a+1,…,b}, then X has the following expected value:

E[X]=a+b2

So, for our random variable X∼U{0,1,…,6}, we have the following expected value:

E[X]=0+62=3

Therefore, the expected value of the chosen answer is 3.
