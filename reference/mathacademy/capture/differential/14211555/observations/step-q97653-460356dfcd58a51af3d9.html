Ann chooses a card at random from a deck of cards labeled 28 through 65. What is the expected value of the chosen number?

a
48.5
b
47.5
c
47
d
46.5
e
46
Submit
Correct
EXPLANATION

Let X represent the value of the number chosen. From the problem statement, we know that X∼U{28,29,…,65}, and we wish to compute E[X].

In general, if X∼U{a,a+1,…,b}, then X has the following expected value:

E[X]=a+b2

So, for our random variable X∼U{28,29,…,65}, we have the following expected value:

E[X]=28+652=46.5

Therefore, the expected value of the chosen number is 46.5.
