In summer, the daily maximum temperature in a particular city (rounded to the nearest degree) varies between 25∘C and 36∘C, inclusive. Assuming that each maximum temperature value has the same probability of occurring on a given summer day, what is the expected value of the daily maximum temperature?

a
31.5∘C
b
30.5∘C
c
30∘C
d
29.5∘C
e
29∘C
Submit
Incorrect
EXPLANATION

Let X represent the daily maximum temperature (rounded to the nearest degree) on a randomly selected day. From the problem statement, we know that X∼U{25,26,…,36}, and we wish to compute E[X].

In general, if X∼U{a,a+1,…,b}, then X has the following expected value:

E[X]=a+b2

So, for our random variable X∼U{25,26,…,36}, we have the following expected value:

E[X]=25+362=30.5

Therefore, the expected value of the maximum temperature is 30.5∘C.
