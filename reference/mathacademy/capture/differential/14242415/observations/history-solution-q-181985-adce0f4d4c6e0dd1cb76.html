The Cartesian product A×B consists of all ordered pairs whose first coordinate belongs to A and whose second coordinate belongs to B.

A×B={(a,b):a∈A,b∈B}

In this case, the set S=[−1,0]×[−1,1] contains every point in R2 whose x-coordinate is any real number in the interval [−1,0] and whose y-coordinate is any real number in the interval [−1,1].

S={(x,y):x∈[−1,0],y∈[−1,1]}.

To visualize S, consider S0⊂S containing all points whose x-coordinate equals 0 and whose y-coordinate is any real number in the interval [−1,1].

S0={(0,y):y∈[−1,1]}

Now, consider a general Si⊂S containing all points whose x-coordinate equals some i∈[−1,0] and whose y-coordinate is any real number in the interval [−1,1].

Si={(i,y):y∈[−1,1]}

For each i∈[−1,0], Si is a vertical line segment from the point (i,−1) to the point (i,1).

Our Cartesian product S is the union of these subsets over I=[−1,0]:

S=⋃i∈ISi.
