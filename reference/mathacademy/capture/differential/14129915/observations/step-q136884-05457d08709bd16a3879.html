A discrete random variable X has the probability mass function f(x) shown in the table below. Find E[log2⁡(X)].

x 2 4 8
f(x) 18 12 38
a
94
b
138
c
238
d
258
e
98
Submit
Correct
EXPLANATION

For a discrete random variable X and a function r(x), the rule of the lazy statistician states that

E[r(X)]=∑x∈Sr(x)f(x).

In our case, we have

r(x)=log2⁡x.

Therefore, we obtain

E[log2⁡(X)]=∑x∈Slog2⁡(x)f(x)=log2⁡(2)⋅18+log2⁡(4)⋅12+log2⁡(8)⋅38=1⋅18+2⋅12+3⋅38=18+1+98=188=94.
