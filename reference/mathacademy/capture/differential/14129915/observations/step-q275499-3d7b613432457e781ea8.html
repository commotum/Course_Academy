EXPLANATION

For a continuous random variable X and a function r(x), the rule of the lazy statistician states that

E[r(X)]=∫−∞∞r(x)f(x)dx.

In this problem, the break point X is uniformly distributed over the interval [0,1], so the probability density function is

f(x)=1,0≤x≤1.

When the stick is broken at point X, it is divided into two pieces: one of length X and the other of length 1−X. The longer of the two pieces, Y, is therefore given by

Y=max(X,1−X).

Therefore, we define r(x)=max(x,1−x).

To evaluate the integral, we express r(x) as an explicit piecewise function. Observe that,

  • if 0≤x≤12, then x≤1−x, so the longer piece has length 1−x,

  • if 12<x≤1, then x>1−x, so the longer piece has length x.

Therefore,

r(x)={1−x,0≤x≤12,x,12<x≤1.
