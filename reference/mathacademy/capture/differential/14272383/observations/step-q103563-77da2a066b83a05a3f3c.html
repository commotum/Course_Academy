Which of the following statements are true?

  1. If 3+4<5, then 2+7<5.
  2. If 2+4<7, then 1+5<4.
  3. If 2+3<4, then 3+2<1.
a
II and III only
b
III only
c
II only
d
I and II only
e
I and III only
Submit
Correct
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent 3+4<5 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement II is false. The antecedent 2+4<7 is true, and the consequent 1+5<4 is false. So the promise is broken, and the statement is false.

  • Statement III is true. Again, the antecedent 2+3<4 is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

Therefore, the correct answer is "I and III only."
