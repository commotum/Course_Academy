Let L be the line in R3 that passes through the points (0,−1,2) and (1,2,0). Which of the following statements are true?

  1. L contains the zero-vector
  2. L is closed under vector addition
  3. L is closed under scalar multiplication
  4. L is a subspace of R3
a
I and III only
b
None of the statements are true
c
IV only
d
II and IV only
e
II only
Submit
Incorrect
EXPLANATION

Recall the following two facts about subspaces:

  • A set of vectors in a vector space is a subspace if it is closed under vector addition and scalar multiplication.

  • If a non-empty set is closed under scalar multiplication, then this set must contain the zero-vector (because 0⋅v=0 for any vector v). So, if a set does not contain the zero vector, then this set is not closed under scalar multiplication.

With that in mind, let's examine our statements.

  • Statement I is false.The direction vector of the line L is d=[120]−[0−12]=[13−2]. This means that the vector equation of the line is r=[0−12]+t[13−2] for t∈R, and the corresponding Cartesian equation is x=y+13=z−2−2. But this line does not pass through the origin since (0)≠(0)+13≠(0)−2−2.×

  • Statement II is false. Let's consider the vectors [0−12] and [120] from L (the position vectors of the given points). Then, [0−12]+[120]=[112]. However, the point (1,1,2) does not belong to L since (1)≠(1)+13≠(2)−2−2.×

  • Statement III is false. Since 0∉L, this set is not closed under scalar multiplication.

  • Statement IV is false. Since statements II and III are false, L is not a subspace of R3.

Therefore, the correct answer is "None of the statements are true."
