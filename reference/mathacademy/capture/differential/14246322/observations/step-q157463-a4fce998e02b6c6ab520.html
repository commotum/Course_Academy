Let Π be the plane with equation z=2x−y in R3. Which of the following statements are true?

  1. Π contains the zero-vector
  2. Π is closed under vector addition
  3. Π is closed under scalar multiplication
  4. Π is not a subspace of R3
a
II only
b
All the statements are true
c
I and III only
d
I, II, and III only
e
I only
Submit
Correct
EXPLANATION

Recall the following two facts about subspaces:

  • A set of vectors in a vector space is a subspace if it is closed under vector addition and scalar multiplication.

  • If a non-empty set is closed under scalar multiplication, then this set must contain the zero-vector (because 0⋅v=0 for any vector v). So, if a set does not contain the zero vector, then this set is not closed under scalar multiplication.

Notice that Π contains vectors of the form

[xyz]=[xy2x−y],x,y∈R.

With that in mind, let's examine our statements.

  • Statement I is true. The coordinates of the zero-vector satisfy the equation z=2x−y: z=2x−y(0)=2(0)−(0)0=0✓

  • Statement II is true. Let, for example, a=[a1a22a1−a2]∈Π and b=[b1b22b1−b2]∈Π. Then, a+b=[a1a22a1−a2]+[b1b22b1+b2]=[a1+b1a2+b2(2a1−a2)+(2b1−b2)]=[a1+b1a2+b22(a1+b1)−(a2+b2)], which satisfies the condition z=2x−y. Therefore, a+b∈Π.

  • Statement III is true. Let, for example, a=[a1a22a1−a2]∈Π and k∈R. Then, k⋅a=k⋅[a1a22a1−a2]=[ka1ka2k(2a1−a2)]=[ka1ka22(ka1)−ka2], which satisfies the condition z=2x−y. Therefore, k⋅a∈Π.

  • Statement IV is false. Since statements II and III are true, Π must be a subspace of R3.

Therefore, the correct answer is "I, II, and III only."
