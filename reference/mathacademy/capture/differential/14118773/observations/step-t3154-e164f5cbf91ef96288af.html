Given a system of linear equations, we have the following possibilities for the number of solutions:

  • The system has exactly one solution if and only if the respective coefficient matrix is non-singular (meaning that the determinant is not zero). Such systems are called consistent independent.

  • The system has infinitely many solutions if the second row in the standard echelon form contains only 's. These systems are called consistent dependent.

  • The system has no solution if the second row in the standard echelon form contains only 's on the left-hand side and a non-zero element on the right-hand side. These are called inconsistent systems.
