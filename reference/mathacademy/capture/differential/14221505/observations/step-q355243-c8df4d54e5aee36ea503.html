Recall that

  • maxx∈Sf(x) is the maximum output value, while

  • arg⁡maxx∈Sf(x) is an input in S where that maximum output occurs.

On the other hand,

  • minx∈Sf(x) is the minimum output value, while

  • arg⁡minx∈Sf(x) is an input in S where that minimum output occurs.

From the graph,

  • the highest point is at (2,4), so maxx∈Th(x)=4 and arg⁡maxx∈Th(x)=2, and

  • the lowest point is at (5,−2), so minx∈Th(x)=−2 and arg⁡minx∈Th(x)=5.
