The dimension of the null space of a matrix is the number of non-pivot columns in the matrix.

Also, all of the given matrices are in row echelon form.

With that in mind, let's consider each of the statements.

  • Statement I is false. The matrix B has 3 pivot columns and no non-pivot columns. So, dim(Null(B))=0.

  • Statement II is false. The matrix C has 2 pivot columns and 1 non-pivot column (namely, the 2nd column). So, dim(Null(C))=1.

  • Statement III is true. The matrix A has 2 pivot columns and no non-pivot columns. So, dim(Null(A))=0.

Therefore, the correct answer is "III only."
