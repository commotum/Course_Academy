Two continuous random variables X and Y with joint probability density function f(x,y) are independent if and only if

f(x,y)=fX(x)⋅fY(y)

for all possible values x and y, where fX(x) and fY(y) are the marginal probability density functions for X and Y, respectively.

Since our random variables are independent, we obtain

f(x,y)=fX(x)⋅fY(y)=32x⋅2y=3yx

where (x,y)∈[0,1]×[0,1]. Therefore, the full expression for f(x,y) is
