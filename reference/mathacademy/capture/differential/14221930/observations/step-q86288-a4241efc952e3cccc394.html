EXPLANATION

The area A can be approximated using the formula A≈(f(x0)+f(x1)+…+f(xn−1)⏞heights)⋅Δx⏟ width=(f(1)+f(4)+f(7))⋅Δx.

Since the interval [1,10] is divided into 3 equal subintervals, the width of each subinterval is Δx=10−13=3.

So, we now set up a table with the values of f(x) at the left endpoints:

x 1 4 7
f(x) 1 2 0

Finally, we obtain the following approximation for our area: A≈(1+2+0)⋅3=3⋅3=9.
