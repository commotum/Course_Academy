In this case, we have n=4 rectangles. Using the left Riemann sum, the area is approximated as

A≈f(0)Δx1+f(2)Δx2+f(5)Δx3+f(6)Δx4,

where each Δxi is calculated by considering the step between a particular x-value and the next one, i.e.,

Δxi=xi+1−xi.

We set up a value table that includes the Δx's.
