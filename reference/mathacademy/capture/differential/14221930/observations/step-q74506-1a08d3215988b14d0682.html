EXPLANATION

In this case, we have n=4 rectangles. Using the left Riemann sum, the area is approximated as A≈f(−3)Δx1+f(−1)Δx2+f(0)Δx3+f(3)Δx4, where each Δxi is calculated by considering the step between a particular x-value and the next one, i.e., Δxi=xi+1−xi.

We set up a value table that includes the Δx's.
