a
7.53

5.35

Correct
EXPLANATION

Let's sketch our situation.

The area A can be approximated using the formula

A≈(f(x0)+f(x1)+…+f(xn−1)⏞heights)⋅Δx⏟ width=(f(0.5)+f(1)+f(1.5)+f(2))⋅Δx.

So, we now set up a table with the values of f(x) at each point:

x 0.5 1 1.5 2
f(x) 1.25 2 2.25 2

Finally, we obtain the following approximation for our area: A≈(1.25+2+2.25+2)⋅0.5=7.5⋅0.5=3.75
