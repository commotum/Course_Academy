Which of the following statements are true for the sets A={x∈N∣−1≤x+1≤3} and B={x∈Z∣x2≤−2}?

  1. A⊆B
  2. A⊈B
  3. B⊆A
  4. A⊇B
a
II, III, and IV only
b
I and III only
c
I, III, and IV only
d
I and IV only
e
III and IV only
Submit
Incorrect
EXPLANATION

First, we must find the elements of the sets A and B.

  • The elements of the set A are all the natural numbers that satisfy the inequality −1≤x+1≤3, that is to say, −2≤x≤2. So, we have A={1,2}.

  • On the other hand, the elements of the set B are all integers that satisfy the inequality x2≤−2. So, we have B=∅.

Now, let's inspect the given statements.

  • A⊆B is false, while A⊈B is true. For example, 0∈A but 0∉B.

  • B⊆A is true. The empty set is a subset of every set.

  • A⊇B is equivalent to B⊆A, which is true.

Therefore, the correct answer is "II, III, and IV only."
