Which of the following statements are true for the sets A={x∈Z∣−1≤x+2≤3} and B={x∈Z∣x2<2}?

  1. A⊆B
  2. B⊆A
  3. B⊈A
a
II and III only
b
I and III only
c
II only
d
I only
e
III only

Correct
EXPLANATION

First, we must find the elements of the sets A and B.

  • The elements of the set A are all the integer numbers that satisfy the inequality −1≤x+2≤3, that is to say, −3≤x≤1. So, we have A={−3,−2,−1,0,1}.

  • On the other hand, the elements of the set B are all integers that satisfy the inequality x2<2. So, we have B={−1,0,1}.

Now, let's inspect the given statements.

  • A⊆B is false. For example, −3∈A but −3∉B.

  • B⊆A is true, while B⊈A is false. Indeed, every element in the set B is an element of the set A.

Therefore, the correct answer is "II only."
