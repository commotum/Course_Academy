Which of the following are subsets of Q0+ (the set of non-negative rational numbers)?

  1. Z
  2. Z+ (the set of positive integers)
  3. N
a
III only
b
II and III only
c
I and II only
d
II only
e
None
Submit
Incorrect
EXPLANATION

A is a subset of B if every element of A is an element of B.

With that in mind, let's inspect the given choices.

  • Z is not a subset of Q0+. For example, −1∈Z but −1∉Q0+.

  • Z+ is a subset of Q0+. Every positive integer is a positive rational number.

  • N a subset of Q0+. Every natural number is a positive rational number.

Therefore, the correct answer is "II and III only".
