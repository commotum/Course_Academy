Which of the following statements are true for the sets A={5,10,15,20,25,30,35,…} and B={5n∣n∈N,3≤n≤7}?

  1. B⊆A
  2. A⊆B
  3. A⊈B
  4. A⊇B
a
III and IV only
b
I, III, and IV only
c
II and IV only
d
I, II, and IV only
e
I, II, and III only
Submit
Correct
EXPLANATION

First, we must find the elements of the set B. Substituting the values n∈{3,4,5,6,7} into the formula 5n, we get the following elements:

n=3⇒5(3)=15n=4⇒5(4)=20n=5⇒5(5)=25n=6⇒5(6)=30n=7⇒5(7)=35

So, we have B={15,20,25,30,35}.

Now, let's inspect the given statements.

  • B⊆A is true. Every element in the set B is an element of the set A.

  • A⊆B is false, while A⊈B is true. For example, 5∈A but 5∉B.

  • A⊇B is equivalent to B⊆A, which is true.

Therefore, the correct answer is "I, III, and IV only".
