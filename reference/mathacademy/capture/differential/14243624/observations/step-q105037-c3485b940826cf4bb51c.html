Which statement is not true?

a
Z+⊆R
b
Z−⊆Z
c
N⊆R
d
R⊆Q
e
R⊆C
Submit
Correct
EXPLANATION

If A⊆B, then A is a subset of B, meaning that every element of A is an element of B.

Among the given choices, only R⊆Q is not true. This statement is not true because not every real number is a rational number. For example, we have 2∈R but 2∉Q.
