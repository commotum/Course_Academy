Which of the following statements are true for the sets A={x∈N:x<5} and B={x∈N:2x≥4}?

  1. A⊆B
  2. B⊆A
  3. ∅⊆B
  4. B⊇A
a
I, III, and IV only
b
III only
c
I and IV only
d
I and II only
e
II, III, and IV only
Submit
Correct
EXPLANATION

First, we must find the elements of the sets A and B.

  • The elements of the set A are all natural numbers less than 5. So, A={1,2,3,4}.

  • On the other hand, the elements of the set B are natural numbers which satisfy the inequality 2x≥4, that is to say x≥2. So, B={2,3,…}.

Now, let's inspect the given statements.

  • A⊆B is false. For example, 1∈A but 1∉B.

  • B⊆A is false. For example, 5∈B but 5∉A.

  • ∅⊆B is true. The null set ∅={} is a subset of every set.

  • B⊇A is equivalent to A⊆B, which is false.

Therefore, the correct answer is "III only."
