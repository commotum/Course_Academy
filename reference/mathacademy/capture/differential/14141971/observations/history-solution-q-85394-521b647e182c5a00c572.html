A Poisson random variable X with rate λ has the following probability mass function:

f(x)=λxe−λx!

Let X be the number of calls received in the telephone exchange. Since the average rate is 7 calls every 5 minutes, and events occur independently and at a constant average rate, the number of calls can be modeled as a Poisson random variable with rate λ=7, and we can write X∼Po(7).

So, X has the following probability mass function:

f(x)=7xe−7x!

To compute P(X≥5), we will use the complement:

P(X≥5)=1−P(X<5)

Computing the probability of the complement, we get

P(X<5)=P(X∈{0,1,2,3,4})=f(0)+f(1)+f(2)+f(3)+f(4)=70e−70!+71e−71!+72e−72!+73e−73!+74e−74!≈0.173

rounded to 3 decimal places.

P(X≥5)=1−P(X<5)≈1−0.173=0.827
