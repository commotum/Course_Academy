Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number obtained when spinning a roulette wheel that is biased towards landing on 0.
  2. The number obtained when picking a rational number between 0 and 1 at random.
  3. The IQ of a randomly selected student.
a
None
b
I only
c
I and III only
d
II only
e
II and III ony
Submit
Correct
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I cannot be modeled as a discrete uniform distribution. Each outcome is not equally likely, because there is a higher probability of getting 0.

  • Random variable II cannot be modeled as a discrete uniform distribution. This is because there are infinitely many rational numbers between 0 and 1, and so the support is not finite.

  • Random variable III cannot be modeled as a discrete uniform distribution. Each outcome is not equally likely, because there are a small number of students with very low and very high IQs.

Therefore, the correct answer is "None."
