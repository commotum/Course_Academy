Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The number of visitors to a museum in an hour.
  2. The number obtained when rolling a fair die.
  3. The amount of time, in minutes, between successive full charges in a smartphone.
a
III only
b
I and II only
c
I only
d
II only
e
II and III only
Submit
Correct
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I cannot be modeled as a discrete uniform distribution. This is because the number of visitors can be any positive integer. Moreover, each number of visitors is not equally likely.

  • Random variable II can be modeled as a discrete uniform distribution. This is because there are a finite number of integers as possible outcomes, between 1 and 6, and since the die is fair, each integer has an equal probability of being selected.

  • Random variable III cannot be modeled as a discrete uniform distribution. This is because the amount of time between events is a real number, so the support is not finite.

Therefore, the correct answer is "II only."
