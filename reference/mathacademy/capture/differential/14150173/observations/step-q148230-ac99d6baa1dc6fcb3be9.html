Which of the following random variables can be modeled as a discrete uniform distribution?

  1. The outcome after tossing a fair coin.
  2. The number obtained when picking a real number between 2 and 5 at random.
  3. The letter obtained when a letter from the word Mississippi is chosen at random.
a
None of the statements are true
b
I and III only
c
III only
d
II and III only
e
I only
Submit
Incorrect
EXPLANATION

We can use the discrete uniform distribution to model the outcome of a single event when the support S is finite, and each x∈S is equally likely.

With that in mind, let's consider each of the given random variables.

  • Random variable I can be modeled as a discrete uniform distribution. There are a finite number of possible outcomes after tossing a coin: Head and tail, and since the coin is fair, each outcome has an equal probability of being selected.

  • Random variable II cannot be modeled as a discrete uniform distribution. This is because there are infinitely many real numbers between 2 and 5, and so the support is not finite.

  • Random variable III cannot be modeled as a discrete uniform distribution. Each outcome is not equally likely, because so letters occur more often than others. For example, there is a lower probability of selecting the letter "M".

Therefore, the correct answer is "I only."
