Recall that:

  • A set is open if it does not contain any of its boundary points. In other words, an open set consists only of the interior points of the set.

  • A set is closed if it contains all of its boundary points. In other words, a closed set consists of all the interior and all the boundary points of the set.

Among the given sets, only [−2,2] and [3,9] are closed because:

  • The boundary points of [−2,2] are −2, and 2. Both of them lie in the set.

  • The boundary points of [3,9] are 3, and 9. Both of them lie in the set.

The other set is not closed because [−1,1)∪(3,4] has a boundary point 1, which does not lie in the set.

Therefore, the correct answer is "I and II only".
