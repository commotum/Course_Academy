Which of the following matrices are symmetric?

P=[01−11],Q=[0−1−12],R=[1231]

a
P and Q only
b
Q and R only
c
P only
d
R only
e
Q only
Submit
Incorrect
EXPLANATION

A square matrix A is symmetric if it is equal to its transpose: A=AT

Equivalently, aij=aji for all i,j. In other words, A is symmetric across its main diagonal.

With that in mind, let's examine each matrix in turn.

  • P is not a symmetric matrix. Since p12≠p21, we obtain P≠PT. P=[01−11]

  • Q is a symmetric matrix. Indeed, Q=QT.

  • R is not a symmetric matrix. Since r12≠r21, we obtain R≠RT. R=[1231]

Therefore, the correct answer is "Q only."
