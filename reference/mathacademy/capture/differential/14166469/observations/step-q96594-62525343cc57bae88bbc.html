Which of the following statements are true?

  1. The sum of two n×n diagonal matrices is always symmetric.
  2. If A is any n×n matrix, then A−1 is always symmetric (if it exists).
  3. If A is any matrix, then ATA is always symmetric.
a
II only
b
I only
c
II and III only
d
I and III only
e
I and II only

Correct
EXPLANATION

A square matrix A is symmetric if it is equal to its transpose: A=AT

Equivalently, aij=aji for all i,j. In other words, A is symmetric across its main diagonal.

With that in mind, let's examine our statements in turn.

  • Statement I is true. Indeed, for any diagonal matrices A and B, we have
    (A+B)T=AT+BT=A+B.

  • Statement II is false. As a counterexample, consider the non-singular matrix

    A=[0−110].

    However, A−1 is not symmetric: A−1=[01−10]

  • Statement III is true. Indeed, for any m×n matrix A, we have (ATA)T=AT(AT)T=ATA.

Therefore, the correct answer is "I and III only."
