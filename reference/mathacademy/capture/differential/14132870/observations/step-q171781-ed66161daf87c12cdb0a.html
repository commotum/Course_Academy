Consider the following predicates.

P(x): x|8. Q(x): x is even.

Which of the following is equivalent to the biconditional predicate P(x)⇔Q(x)?

  1. If x|8 then x is even, or if x is even then x|8.
  2. If x|8 then x is even, and if x is even then x|8.
  3. x|8 if and only if x is even.
a
I and II only
b
II only
c
I only
d
II and III only
e
III only
Submit
Correct
EXPLANATION

A biconditional expression P⇔Q≡(P⇒Q)∧(Q⇒P) can be read as shown below:

  • P if and only if Q

  • P is equivalent to Q

  • If P then Q, and if Q then P

So, A⇔B translates into the following sentences:

  • x|8 if and only if x is even.

  • x|8 is equivalent to x is even.

  • If x|8 then x is even, and if x is even then x|8.

Therefore, the correct answer is "II and III only."
