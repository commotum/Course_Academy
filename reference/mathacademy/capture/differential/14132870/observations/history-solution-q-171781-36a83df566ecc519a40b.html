A biconditional expression P⇔Q≡(P⇒Q)∧(Q⇒P) can be read as shown below:

  • P if and only if Q

  • P is equivalent to Q

  • If P then Q, and if Q then P

So, A⇔B translates into the following sentences:

  • x|8 if and only if x is even.

  • x|8 is equivalent to x is even.

  • If x|8 then x is even, and if x is even then x|8.

Therefore, the correct answer is "II and III only."
