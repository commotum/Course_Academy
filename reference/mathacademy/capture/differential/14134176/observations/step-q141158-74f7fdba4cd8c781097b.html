Let T be the set of all 2×2 real matrices A=(aij) such that a11a21+a12a22>0. Which of the following statements are true?

  1. The identity matrix I2 belongs to T.
  2. For every A∈T and α∈R, we have α⋅A∈T.
  3. The set is closed under scalar multiplication.
a
None of the statements are true
b
I and II only
c
I, II, and III
d
II and III only
e
I only
Submit
Incorrect
EXPLANATION

Let's verify the statements one at a time.

  • Statement I is false. The set T contains only matrices A=(aij) such that a11a21+a12a22>0. However, for the identity matrix I2=[1001], we have a11a21+a12a22=1⋅0+0⋅1=0≯0. So, I2∉T.

  • Statement II is false. For example, let α=0∈R and A=[a11a12a21a22]∈T. Then, α⋅A=0⋅A=[0000], where the sum of the products of columns' entries is 0⋅0+0⋅0=0≯0. Hence, 0⋅A∉T.

  • Statement III is false. Since statement II is false, the set is not closed under scalar multiplication.

Therefore, the correct answer is "None of the statements are true."
