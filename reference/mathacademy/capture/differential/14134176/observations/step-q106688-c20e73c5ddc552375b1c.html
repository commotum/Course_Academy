Let S be the set of all 2×2 matrices with real entries and determinant 1. Which of the following statements are true?

  1. The identity matrix [1001] belongs to S.
  2. For any A∈S, we can find the corresponding negative matrix −A∈S such that A+(−A)=O.
  3. There are matrices A,B,C∈S, such that (A+B)+C≠A+(B+C).
a
I, II, and III
b
II only
c
III only
d

e

Incorrect
EXPLANATION

Let's examine each statement in turn.

  • Statement I is true. Indeed, |1001|=1. Hence, [1001]∈S.

  • Statement II is true. Indeed, for any matrix A∈S, there is a corresponding negative 2×2 matrix −A such that A+(−A)=A−A=O. Notice that |−A|=|−1⋅A|=(−1)2⋅|A|=1⋅1=1, hence −A∈S.

  • Statement III is false. For any matrices A,B,C∈S, we have (A+B)+C=A+(B+C). since matrix addition is associative.

Therefore, the correct answer is "I and II only."
