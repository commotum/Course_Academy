Let F be the set of polynomials of the form ax+b, where a,b∈R. Which of the following statements are true?

  1. The zero-polynomial belongs to F.
  2. For the zero polynomial 0 and any p(x)∈F, we have p(x)+0=p(x).
  3. There are polynomials p(x),q(x)∈F such that p(x)+q(x)≠q(x)+p(x).

I and II only
b
III only
c
II and III only
d

Incorrect
EXPLANATION

Let's examine each statement in turn.

  • Statement I is true. Indeed, the zero-polynomial can be represented as 0=0⋅x+0. Hence, 0∈F.

  • Statement II is true. Indeed, for the zero-polynomial 0 and any p(x)∈F, we have p(x)+0=p(x) since 0 is the unique zero element in the set of all polynomials.

  • Statement III is false. For any polynomials p(x),q(x)∈F, we have that p(x)+q(x)=q(x)+p(x) since the addition of polynomials is commutative.

Therefore, the correct answer is "I and II only."
