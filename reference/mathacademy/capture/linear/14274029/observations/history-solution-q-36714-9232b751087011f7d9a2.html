In order for limx→2f(x) to exist, the left and right-sided limits must both exist and be equal.

  • Approaching from the left, we have x<2, so we use the expression f(x)=x2+x−1. We get limx→2−f(x)=limx→2−x2+x−1=(2)2+2−1=5.

  • Approaching from the right, we have x>2, so we use the expression f(x)=x2+bx+3. We get limx→2+f(x)=limx→2+x2+bx+3=(2)2+b⋅2+3=7+2b.

Finally, since the left and right-sided limits must be equal, we have limx→2−f(x)=limx→2+f(x)5=7+2b2b=−2b=−1.
