The residue of 52 modulo 5 is the integer 0≤r<5 such that

52≡r(mod5).

Method 1

To find the residue r, we need to write 52 as an integer multiple of 5, plus the residue r.

We note that 52≡2(mod5) because

52=10⋅5+2.

Therefore, the residue of 52 modulo 5 is 2.

Method 2

We can use the subtraction property:

52≡52−0(mod5)≡52−10⋅5(mod5)≡52−50(mod5)≡2(mod5)

Therefore, the residue of 52 modulo 5 is 2.
