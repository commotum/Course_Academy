Then, we count the number of circles. We see that there are 3 circles.

So the ratio of squares to circles is 3:3.

We can simplify this ratio by dividing both numbers by 3:

So, the complete statement is "The ratio of squares to circles is 1:1 because there is 1 square for every 1 circle."
