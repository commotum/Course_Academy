Which of the following numbers are surds?

144,25,74

a
74 only
b
74 and 144 only
c
144 and 25 only
d
144 only
e
25 only
Submit
Correct
EXPLANATION

A surd is a number containing a radical symbol 0 that cannot be written as a positive or negative whole number or fraction.

With that in mind, let's look at each number in turn.

  • 144 is NOT a surd. Since 144 is a perfect square, we can get rid of the square root symbol (x) and obtain a whole number: 144=122=12

  • 25 is NOT a surd. Since 25 is a perfect square, we can get rid of the square root symbol (x) and obtain a whole number: 25=52=5

  • 74 is a surd because 74 is not a perfect square. In fact 74=8.602 325...

Therefore, the correct answer is: 74 only.
