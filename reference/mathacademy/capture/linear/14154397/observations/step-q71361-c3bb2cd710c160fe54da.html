Which of the following numbers are surds?

53,503,1253

a
503 and 1253 only
b
1253 only
c
53 and 503 only
d
53 and 1253 only
e
503 only
Submit
Correct
EXPLANATION

A surd is a number containing a radical symbol 0 that cannot be written as a positive or negative whole number or fraction.

Surds can be square roots 0, cube roots 03, or higher roots such as 04, 05,…, etc.

With that in mind, let's look at each number in turn.

  • 53 is a surd because 5 is not a perfect cube. In fact 53=1.709975…

  • 503 is a surd because 50 is not a perfect cube. In fact 503=3.684031…

  • 1253 is NOT a surd. Since 125 is a perfect cube, we can get rid of the cube root symbol (03) and obtain a whole number. 1253=533=5

Therefore, the correct answer is: 53 and 503 only.
