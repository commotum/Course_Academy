Which of the following numbers are NOT surds?

49,28,64

a
64 only
b
49 and 64 only
c
49 only
d
49 and 28 only
e
28 and 64 only
Submit
Correct
EXPLANATION

A surd is a number containing a radical symbol 0 that cannot be written as a positive or negative whole number or fraction.

With that in mind, let's look at each number in turn.

  • 49 is NOT a surd. Since 49 is a perfect square, we can get rid of the square root symbol (x) and obtain a whole number: 49=72=7

  • 28 is a surd because 28 is not a perfect square. In fact 28=5.291502622...

  • 64 is NOT a surd. Since 64 is a perfect square, we can get rid of the square root symbol (x) and obtain a whole number: 64=82=8

Therefore, the correct answer is: 49 and 64 only.
