  3. If 22|72b then 22|b

EXPLANATION

For any integers a, b, and c,

c|ab and gcd(a,c)=1 ⟹ c|b.

With that in mind, let's examine each of the statements.

  • Statement I is false. As a counterexample, let b=19. Then, 192∣19⋅19 but 192∤19.

  • Statement II is true. First, note that gcd(12,35)=1. Therefore, we have 12|35b and gcd(12,35)=1, which implies 12|b.

  • Statement III is true. First, note that gcd(22,72)=1. Therefore, we have 22|72b and gcd(22,72)=1, which implies 22|b.

Therefore, the correct answer is "II and III only."
