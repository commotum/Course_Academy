EXPLANATION

For any integers a, b, and c,

c|ab and gcd(a,c)=1 ⟹ c|b.

With that in mind, let's examine each of the statements.

  • Statement I is true. First, note that gcd(32,10)=1. Therefore, we have 32|10b and gcd(32,10)=1, which implies 32|b.

  • Statement II is false. As a counterexample, let b=17. Then, 172∣17⋅17 but 172∤17.

  • Statement III is true. First, note that gcd(20,33)=1. Therefore, we have 20|33b and gcd(20,33)=1, which implies 20|b.

Therefore, the correct answer is "I and III only."
