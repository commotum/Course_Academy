EXPLANATION

First, we note that

  • x=−23 cannot be a solution since this would make the denominator on the left-hand side zero

  • x=0 cannot be a solution since this would make the denominator on the right-hand side zero

We can flip an equation involving two fractions as follows

ab=cd⟹ba=dc

The above technique works whenever a and c are both different from zero.

Therefore, we can flip the given equation as follows:

3x+22=−x4

Next, we write both fractions using the least common denominator 4, as follows:

6x+44=−x4

We can now solve this equation with the addition and the multiplication principles: 4⋅6x+44=4⋅(−x4)6x+4=−x6x+x=−4x=−47
