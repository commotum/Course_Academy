To visualize congruence modulo 2, let's write the numbers 0,1,2,3,… in a spiral around a circle so that each "layer" contains exactly 2 numbers.

In the diagram, each "spoke" of our wheel contains numbers that are congruent modulo 2.

Now, recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each case in turn.

  • Case I gives a true statement. Indeed, 2∣(6−0). There is no remainder: (6−0)÷2=6÷2=3

  • Case II gives a false statement because 2∤(6−1). Notice that 6−1=5, which is not divisible by 2.

  • Case III gives a true statement. Indeed, 2∣(6−2). There is no remainder: (6−2)÷2=4÷2=2

Therefore, the correct answer is "0 and 2 only."
