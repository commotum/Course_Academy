First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each statement in turn.

  • Statement I is true because 5∣(11−1). There is no remainder: (11−1)÷5=10÷5=2

  • Statement II is false because 7∤(27−15). Notice that 27−15=12, which is not divisible by 7.

  • Statement III is true because 4|(30−(−18)). There is no remainder: (30−(−18))÷4=48÷4=12

Therefore, the correct answer is "I and III only."
