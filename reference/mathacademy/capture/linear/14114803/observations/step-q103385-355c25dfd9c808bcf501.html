  1. 11≡3(mod3)
  2. 18≡16(mod4)
  3. 24≡19(mod5)

Incorrect
EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each statement in turn.

  • Case I gives a false statement because 3∤(11−3). Notice that 11−3=8, which is not divisible by 3.

  • Case II gives a false statement because 4∤(18−16). Notice that 18−16=2, which is not divisible by 4.

  • Case III gives a true statement. Indeed, 5∣(24−19). There is no remainder: (24−19)÷5=5÷5=1

Therefore, the correct answer is "III only."
