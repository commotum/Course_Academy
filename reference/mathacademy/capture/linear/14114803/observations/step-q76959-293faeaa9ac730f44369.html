EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each statement in turn.

  • Statement I is false because 3∤(−5−11). Notice that −5−11=−16, which is not divisible by 3.

  • Statement II is true because 7|(−7−0). There is no remainder: (−7−0)÷7=−7÷7=−7

  • Statement III is false because 9∤(6−25). Notice that 6−25=−19, which is not divisible by 9.

Therefore, the correct answer is "II only."
