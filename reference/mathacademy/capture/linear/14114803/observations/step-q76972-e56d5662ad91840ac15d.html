Given that 8≡23(modn), which of the following could be the value of n?

  1. n=3
  2. n=4
  3. n=5
a
I only
b
II and III only
c
I, II, and III
d
I and III only
e
I and II only
Submit
Correct
EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

We have a−b=8−23=−15.

With that in mind, let's analyze each statement in turn.

  • Note that 3∣(−15) because (−15)÷3=−5, and there is no remainder. Therefore, the statement is true when n=3.

  • Note that 4∤(−15). Therefore, the statement is false when n=4.

  • Note that 5∣(−15) because (−15)÷5=−3, and there is no remainder. Therefore, the statement is true when n=5.

Therefore, the correct answer is "I and III only."
