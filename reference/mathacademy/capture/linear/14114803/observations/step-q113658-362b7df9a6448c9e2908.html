Consider the following congruence. 11≡A(mod4) Which of the following values gives a true statement when inserted into the blank space?

  1. 1
  2. 3
  3. 7
a
1 and 7 only
b
1 only
c
3 only
d
3 and 7 only
e
7 only
Submit
Correct
EXPLANATION

To visualize congruence modulo 4, let's write the numbers 0,1,2,3,… in a spiral around a circle so that each "layer" contains exactly 4 numbers.

In the diagram, each "spoke" of our wheel contains numbers that are congruent modulo 4.

Now, recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each case in turn.

  • Case I gives a false statement because 4∤(11−1). Notice that 11−1=10, which is not divisible by 4.

  • Case II gives a true statement. Indeed, 4∣(11−3). There is no remainder: (11−3)÷4=8÷4=2

  • Case III gives a true statement. Indeed, 4∣(11−7). There is no remainder: (11−7)÷4=4÷4=1

Therefore, the correct answer is "3 and 7 only."
