  2. k−2
  3. 3

EXPLANATION

Let's look at each one in turn.

  1. h is a variable because it's a single letter by itself.
  2. k−2 is an algebraic expression, not a variable.
  3. 3 is a number, not a variable.
So, only choice I represents a variable.
