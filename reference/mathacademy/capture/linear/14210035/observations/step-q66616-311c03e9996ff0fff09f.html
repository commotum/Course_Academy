Given that the function f(x) has an inverse f−1(x), and the point (5,1) lies on the graph y=f(x), which point must lie on the graph of y=f−1(x)?

a
(−1,5)
b
(−1,−5)
c
(1,−5)
d
(1,5)
e
(−5,−1)
Submit
Correct
EXPLANATION

The function y=f−1(x) is a reflection of y=f(x) in the line y=x. Therefore, each point (a,b) on y=f(x) has a corresponding point (b,a) on y=f−1(x) (the x and y coordinates swap).

Since the point (5,1) lies on y=f(x), the point (1,5) lies on y=f−1(x).
