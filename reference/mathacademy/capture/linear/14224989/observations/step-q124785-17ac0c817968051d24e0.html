The diagram above shows the unit circle. Given that the y-coordinate of the point P is 23, use the Pythagorean identity to find cot⁡θ.

Correct
EXPLANATION

Any point (x,y) on the unit circle is related to the central angle θ as follows:

x=cos⁡θ,y=sin⁡θ

We're given that y=23 at the point P. Therefore, we have

sin⁡θ=23.

We can use the Pythagorean identity to find cos⁡θ:

sin2⁡θ+cos2⁡θ=1cos2⁡θ=1−sin2⁡θcos⁡θ=±1−sin2⁡θ

Substituting sin⁡θ=23 gives

cos⁡θ=±1−(23)2=±1−29=±79=±73.

We select the positive answer since cos⁡θ is positive in the first quadrant. So, cos⁡θ=73

Knowing that cot⁡θ=cos⁡θsin⁡θ, we have cot⁡θ=(73)(23)=72.

Finally, we rationalize the denominator. cot⁡θ=72=72⋅22=7⋅22=142
