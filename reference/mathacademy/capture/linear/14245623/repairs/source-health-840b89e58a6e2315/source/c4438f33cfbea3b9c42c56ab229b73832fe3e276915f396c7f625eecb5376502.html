The company wants to increase its output by implementing a new production model. The number of wooden tables an produced in the nth week since the implementation of the new model is given by the arithmetic sequence an+1=an+4,a1=12,n≥1 What is the explicit formula for the nth term of this arithmetic sequence?
an=
4n+8

Correct
Explanation

The explicit formula for the nth term of an arithmetic sequence is

an=a1+(n−1)d,n≥1,

so we need to determine the first term a1 and the common difference d.

We are given that the first term is a1=12, and we can use the recursive rule to compute the second term as follows:

a2=a1+4=12+4=16

Using the first and second terms, we can compute the common difference:

d=a2−a1=16−12=4

Now we substitute a1=12 and d=4 into the formula for the nth term: an=a1+(n−1)d=12+(n−1)(4)=12+4n−4=4n+8

Therefore, the formula for the nth term is

an=4n+8,n≥1.
