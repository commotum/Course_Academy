The constant term in the expression 4m+7n is
0
.
Submit
Correct
EXPLANATION

The expression has two terms:

4m,7n

Each of these terms contains a variable, so none are constant.

The constant term is missing. However, we can include it by adding zero to the expression. Rewriting the given expression as

4m+7n+0,

we see that the constant term is 0.
