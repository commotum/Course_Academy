To find the number of visitors this year, we apply a 25% increase to the previous year's figure.

Increasing by 25% means that we must apply a new percentage of

100%+25%=125%.

We begin by converting the percentage to a decimal:

125%=125100=1.25

Now, we multiply the original number of visitors by 1.25: 8,000×1.25=10,000

So, the library had 10,000 visitors this year.
