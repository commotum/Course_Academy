Consider the vector space M2(R) of all 2×2 matrices over R.

Which of the following statements are true?

  1. {[1000],[0001],[0100]} is a linearly independent set in M2(R)
  2. [230−4] can be expressed as a linear combination of {[1000],[0001],[0100]}
  3. {[1000],[0001],[0100]} is a basis of M2(R)
a
I and III only
b
I and II only
c
I, II, and III
d
I only
e
II only
Submit
Incorrect
EXPLANATION

Let's examine each of the statements in turn.

  • Statement I is true. Indeed, the equation x1⋅[1000]+x2⋅[0001]+x3⋅[0100]=[0000] is true if and only if x1=x2=x3=0. So, the set is linearly independent.

  • Statement II is true. Indeed, [230−4]=2⋅[1000]+(−4)⋅[0001]+3⋅[0100].

  • Statement III is false. For example, the matrix [1111] can't be written as a linear combination of {[1000],[0001],[0100]} since all these linear combinations result in matrices with the entry a21=0: a⋅[1000]+b⋅[0001]+c⋅[0100]=[ac0b]

Therefore, the correct answer is "I and II only."
