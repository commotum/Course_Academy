Recall that x=a is called a vertical asymptote of y=f(x) if f(x)→∞ or f(x)→−∞ as x→a+ or x→a−.

From the given graph, we see that as x approaches −2 from the left, the values of f(x) decrease, approaching −∞. Also, notice that as x approaches −2 from the right, the values of f(x) decrease, approaching −∞.

We also see that as x approaches 0 from the left, the values of f(x) decrease, approaching −∞. And, as x approaches 0 from the right, the values of f(x) decrease, approaching −∞.

So, we can write:

  • f(x)→−∞ as x→−2−

  • f(x)→−∞ as x→−2+

  • f(x)→−∞ as x→0−

  • f(x)→−∞ as x→0+

These give us the asymptotes x=−2 and x=0.
