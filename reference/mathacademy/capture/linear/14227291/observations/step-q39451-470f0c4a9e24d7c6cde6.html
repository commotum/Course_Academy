  1. As x→−2−, f(x)→∞
  2. As x→3−, f(x)→∞
  3. As x→3+, f(x)→−∞

Correct
EXPLANATION

The notation x→−2− means that x approaches −2 from the left. In the same way, the notation x→3− means that x approaches 3 from the left while x→3+ means that x approaches 3 from the right.

From the given graph, we see that:

  • As x approaches −2 from the left, the values of f(x) do not approach ∞. So, statement I is false.

  • As x approaches 3 from the left, the values of f(x) increase, approaching ∞. So, statement II is true.

  • As x approaches 3 from the right, the values of f(x) do not approach −∞. So, statement III is false.

Therefore, the correct answer is "II only".
