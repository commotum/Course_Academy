If 3log5⁡(x+2)=6, then x=

16
b
28

Correct
EXPLANATION

First, we rearrange our equation to isolate the logarithmic term:

3log5⁡(x+2)=6log5⁡(x+2)=63log5⁡(x+3)=2

To remove the logarithm, we exponentiate both sides of the equation. The base of the logarithm is 5, so we use this base for the exponentiation as well:

log5⁡(x+2)=25log5⁡(x+2)=52

Now, since exponentiation is the inverse function of the logarithm, we get 5log5⁡(x+2)=x+2.

Therefore, x+2=52x+2=25x=23.
