EXPLANATION

The explicit formula for the nth term of an arithmetic sequence is

an=a1+(n−1)d,n≥1,

so we need to determine the first term a1 and the common difference d.

We are given that the first term is a1=5, and we can use the recursive rule to compute the second term, as follows:

a2=a1−6=5−6=−1

Using the first and second terms, we can compute the common difference:

d=a2−a1=−1−5=−6

Now we substitute a1=5 and d=−6 into the formula for the nth term: an=a1+(n−1)d=5+(n−1)(−6)=5−6n+6=11−6n

Therefore, the formula for the nth term is

an=11−6n,n≥1.
