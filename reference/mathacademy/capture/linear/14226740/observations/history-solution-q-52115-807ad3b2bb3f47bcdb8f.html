We will isolate a variable in one of the equations and then substitute it into the other equation. It so happens that the first equation is already solved for a:

a=7

If we now substitute a=7 into 3a+6b=15, then we can find the value of b:

3a+6b=153(7)+6b=156b=−6b=−1

Therefore, the solution to the system of equations is a=7,b=−1. So,

a−b=7−(−1)=7+1=8.
