EXPLANATION

Recall the following:

  • a function f(x) is even if f(−x)=f(x)

  • a function f(x) is odd if f(−x)=−f(x)

Moreover, for any odd function f(x), the graph of y=f(x) has rotational symmetry of order 2 about the origin, so we have ∫−aaf(x)dx=0.

So, to determine which integrals evaluate to 0 due to symmetry, we have to determine which integrands are odd functions.

  • The function f(x)=cos⁡(3x) is not an odd function: f(−x)=cos⁡(3(−x))=cos⁡(−3x)=cos⁡(3x)≠−f(x)×

  • The function g(x)=sin⁡(2x) is an odd function, but integral II is not of the form ∫−aag(x)dx since the upper and lower limits are not opposites. Therefore, we cannot use symmetry to simplify the integral.

  • The function h(x)=2tan⁡x is an odd function: h(−x)=2tan⁡(−x)=−2tan⁡x=−h(x)✓ Therefore, by symmetry, we can conclude that ∫−112tan⁡xdx=0.

Hence, the correct answer is "III only."
