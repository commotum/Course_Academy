EXPLANATION

The function f(x) is continuous on [−1,1], so the intermediate value theorem guarantees that f(x)=k has a solution for each value of k between f(−1) and f(1).

Since f(−1)=−2 and f(1)=4, we must have k∈[−2,4].

Among the given options, only k=3 belongs to the interval [−2,4].
