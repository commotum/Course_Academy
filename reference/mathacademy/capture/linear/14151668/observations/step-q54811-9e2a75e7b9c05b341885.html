Which inequality corresponds to the highlighted region shown on the number line above?

a
 −1≤x≤4
b
−1>x>4
c
x<−1 or x>4
d
x≤−1 or x≥4
e
−1<x<4
Submit
Correct
EXPLANATION

The red segment contains all values between −1 and 4. In addition,

  • the closed circle at −1 implies that x can be equal to −1, while

  • the closed circle at 4 implies that x can be equal to 4.

Therefore, the highlighted region represents −1≤x≤4.
