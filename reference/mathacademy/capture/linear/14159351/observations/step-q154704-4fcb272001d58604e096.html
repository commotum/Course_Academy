EXPLANATION

Every inequality can be expressed as an interval. We use the following notations:

  • Parentheses (00) if the endpoints are not included.

  • Brackets [00] if the endpoints are included.

Our inequality contains only "less than" symbols. So, the endpoints −2 and 2 are not included.

−2<x<2

Therefore, we can express our inequality in interval notation as follows:

(−2,2)

More formally, we can also write

x∈(−2,2).
