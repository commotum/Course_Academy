EXPLANATION

Every interval can be expressed as an inequality. We use the following notations:

  • Parentheses (00) to indicate that the endpoints are not included.

  • Brackets [00] to indicate that the endpoints are included.

For the given interval

[−1,2)

we note the following:

  • The left endpoint −1 is included in the interval. Therefore, we use ≤.

  • The right endpoint 2 is not included in the interval. Therefore, we use <.

Therefore, the inequality that corresponds to the given interval is −1≤y<2.
