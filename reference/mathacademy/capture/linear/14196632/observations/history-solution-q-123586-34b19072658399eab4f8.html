The angles 0 and π2 are quadrantal angles. Let's draw out the quadrantal angles on the unit circle.

  • Let's first consider the angle 0. From the unit circle, we see that the angle 0 corresponds to the point (1,0). Since the cosine of the angle corresponds to the x-coordinate, we have cos⁡0=1. Therefore, using the fact that sec⁡θ=1cos⁡θ, we have sec⁡0=1cos⁡0=11=1.
  • Now, let's consider the angle π2. From the unit circle, we see that the angle π2 corresponds to the point (0,1). Since the sine of the angle corresponds to the y-coordinate, we have sin⁡(π2)=1. Therefore, using the fact that csc⁡θ=1sin⁡θ, we have

csc⁡(π2)=1sin⁡(π2)=11=1. Finally, we get sec⁡0+csc⁡(π2)=1+1=2.
