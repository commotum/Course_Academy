Because (x−4) is a factor of p(x), we know that (x−4) divides p(x) with no remainder. So, to begin factoring p(x), we can divide it by (x−4) using synthetic division:

which means that p(x)=(x−4)(x2−2x−8).

p(x)=(x−4)(x+2)(x−4)=(x+2)(x−4)2.

The factor (x−4) has an exponent of 2 in the factored form of p(x). So the root x=4 has multiplicity 2.
