Given the function f(x)=−x5, which of the following statements are true?

a
There is a local maximum at x=5
b
There is a local minimum at x=5
c
There is a local maximum at x=0
d
The function f(x) has no local extrema
e
There is a local minimum at x=0
Submit
Incorrect
EXPLANATION

First, we find the stationary points. Differentiating f(x) gives f′(x)=−5x4.

Solving f′(x)=0 gives −5x4=0⟹x=0.

So x=0 is the only stationary point of f(x). Next, to determine whether this point is local maximum or minimum, we use the first derivative test.

Let's choose the test points x=−1,1 and evaluate the first derivative at these points. f′(−1)=−5(−1)4=−5<0f′(1)=−5(1)4=−5<0

The first derivative does not change sign at x=0. Therefore, we conclude that x=0 is neither a minimum nor a maximum.

Hence, the first derivative test shows that the function has no local extrema.
