−11≡A(mod8) Which of the following values gives a true statement when inserted into the blank space?

  3. 11

EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each case in turn.

  • Case I gives a false statement because 8∤(−11−(−8)). Notice that −11−(−8)=−3, which is not divisible by 8.

  • Case II gives a true statement. Indeed, 8∣(−11−5). There is no remainder: (−11−5)÷8=−16÷8=−2

  • Case III gives a false statement because 8∤(−11−11). Notice that −11−11=−22, which is not divisible by 8.

Therefore, the correct answer is "5 only."
