Consider the following congruence.

−10≡A(mod7) Which of the following values gives a true statement when inserted into the blank space?

  1. −3
  2. −1
  3. 4
a
−1 only
b
−3 and 4 only
c
−3 and 1 only
d
4 only
e
−1 and 4 only
Submit
Correct
EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

With that in mind, let's analyze each case in turn.

  • Case I gives a true statement. Indeed, 7∣(−10−(−3)). There is no remainder: (−10−(−3))÷7=−7÷7=−1

  • Case II gives a false statement because 7∤(−10−(−1)). Notice that −10−(−1)=−9, which is not divisible by 7.

  • Case III gives a true statement. Indeed, 7∣(−10−4). There is no remainder: (−10−4)÷7=−14÷7=−2

Therefore, the correct answer is "−3 and 4 only."
