  3. n=7

EXPLANATION

First, we recall that

a≡b(modn)⟺n∣(a−b).

So, a and b are congruent modulo n if and only if (a−b) is divisible by n (there is no remainder).

We have a−b=−7−(−3)=−4.

With that in mind, let's analyze each statement in turn.

  • Note that 2∣(−4) because (−4)÷2=−2, and there is no remainder. Therefore, the statement is true when n=2.

  • Note that 3∤(−4). Therefore, the statement is false when n=3.

  • Note that 7∤(−4). Therefore, the statement is false when n=7.

Therefore, the correct answer is "I only."
