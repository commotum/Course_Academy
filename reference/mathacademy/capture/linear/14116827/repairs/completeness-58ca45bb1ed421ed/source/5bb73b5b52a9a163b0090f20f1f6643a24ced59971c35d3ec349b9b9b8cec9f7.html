Which of the following is congruent to 0 modulo 16?

a
68
b
72
c
46
d
50
e
64
Submit
Correct
EXPLANATION

First, recall that

a≡0(modn)⟺a=kn,

where k∈Z. In other words, when a is divided by n, there is no remainder. This means that any integer multiple of 16 is congruent to 0 modulo 16.

Therefore, since 16|64, we obtain

64≡4⋅16≡4⋅0≡0(mod16).

None of the other options are multiples of 16.
