What is the missing number in the following equality? 4×238=02

a
48
b
24
c
17
d
19
e
11

Correct
EXPLANATION

First, we write 4 as an improper fraction:

4=41

We also write 238 as an improper fraction:

238=(2×8)+38=198

So now, we need to solve the following multiplication problem:

41×198

Notice that the first fraction's numerator (4) and the second fraction's denominator (8) have a common factor of 4.

Therefore, we can simplify our problem by swapping the denominators first and then multiplying the resulting fractions:

41×198=48×191=12×19=1×192=192

Therefore, the missing number is 19.
