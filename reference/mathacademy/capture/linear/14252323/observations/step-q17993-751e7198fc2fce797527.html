The point W is shown in the picture above. Find the coordinates of the corresponding position vector.

a
OW→=⟨1,2⟩
b
OW→=⟨−2.5,1.5⟩
c
OW→=⟨2.5,−1.5⟩
d
OW→=⟨−1,−2⟩
e
OW→=⟨1.5,−2.5⟩
Submit
Correct
EXPLANATION

For a point with coordinates (ax,ay), the position vector is ⟨ax,ay⟩.

The point W has coordinates (1.5,−2.5), so the position vector is OW→=⟨1.5,−2.5⟩.
