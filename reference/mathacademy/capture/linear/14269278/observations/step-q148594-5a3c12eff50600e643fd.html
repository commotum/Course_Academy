 −1

 4

 −5

Correct
EXPLANATION

To find f−1(x), we start by replacing f(x) with y:

y=4(x+k)2

Now, interchanging x and y gives

x=4(y+k)2.

Then, we make y the subject of the equation, as follows:

x=4(y+k)2(y+k)2=4x(y+k)2=4x|y+k|=2xy+k=2xy=2x−k

Note that we used the fact that for y>−k, we have |y+k|=y+k.

Therefore, the inverse function is f−1(x)=2x−k.

Comparing our answer with the given expression, we conclude that k=5.
