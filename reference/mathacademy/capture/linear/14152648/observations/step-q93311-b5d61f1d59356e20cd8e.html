Correct
EXPLANATION

One of the points belonging to the graph is (1000,200). Let's write the ratio 1000:200 as a fraction:

1000200

We can simplify this fraction by dividing both the numerator and the denominator by 200:

1000÷200200÷200=51

So the ratio of red paint to yellow paint is 5:1.
