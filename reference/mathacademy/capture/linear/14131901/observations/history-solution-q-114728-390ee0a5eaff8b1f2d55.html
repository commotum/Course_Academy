Notice that the vertex of ∠SOT is point O, not point T. So ∠SOT is not a straight angle.

We can think of ∠SOT as:

  • a null angle, if we assume that it doesn't turn at all (diagram on the left), or

  • a full angle, if we assume that it makes one full turn (diagram on the right).

So, the answer is 'Null' or 'Full'.
