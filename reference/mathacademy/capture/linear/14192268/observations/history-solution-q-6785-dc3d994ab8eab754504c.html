The function above is defined for values between x=1 and x=4.

  • Since there is a closed circle at x=1, this point is included in the domain.

  • Since there is a closed circle at x=4, this point is also included in the domain.

Therefore, the domain of this function is

1≤x≤4.

Using interval notation, we can write this as

x∈[1,4].
