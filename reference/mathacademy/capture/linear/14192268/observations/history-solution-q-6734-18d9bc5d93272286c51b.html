The function f(x) above is defined for values between x=1 and x=4.

  • Since there is a closed circle at x=1, this point is included in the domain.

  • On the other hand, because there is an open circle at x=4, this point is not included in the domain.

Therefore, the domain of this function is

1≤x<4.

Using interval notation, we write this as

x∈[1,4).
