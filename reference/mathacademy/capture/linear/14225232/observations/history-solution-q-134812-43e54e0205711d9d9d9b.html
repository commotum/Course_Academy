The residual equals the difference between the actual value of the dependent variable and the value estimated using the linear regression model:

Residual=Actual−Estimated

The highlighted datapoint has coordinates (10,175). So, our actual value is y=175.

On the other hand, the point on the regression line that corresponds to x=10 has the y-coordinate 200. So, our estimated value is y^=200.

As a result,

Residual=Actual−Estimated=y−y^=175−200=−25.

Therefore, the residual is −25kg.
