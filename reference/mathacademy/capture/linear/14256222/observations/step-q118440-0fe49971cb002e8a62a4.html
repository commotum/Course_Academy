Which of the following equations could be used to describe the graph shown above?

a
y=sin⁡(−3x2)
b
y=sin⁡(−x)+32
c
y=sin⁡(−x)−32
d
y=sin⁡(32−x)
e
y=32sin⁡(−x)
Submit
Correct
EXPLANATION

To plot the given curve, we follow these steps:

  • Start with the graph of y=sin⁡x.

  • Then, reflect it across the y-axis.

  • Finally, stretch it parallel to the y-axis by a stretch factor of 32.

Therefore, the given curve is the graph of y=32sin⁡(−x).

Notice that, because the sine function is odd, the y-axis reflection has the same effect as the x-axis reflection, i.e., 32sin⁡(−x)=−32sin⁡x.

So the graph could also be viewed as y=−32sin⁡x. However, y=−32sin⁡x is not among the given options.
