To plot the given curve, we follow these steps:

  • Start with the graph of y=cos⁡x.

  • Now, stretch it parallel to the y-axis by a stretch factor of 2.

Therefore, the given curve is the graph of y=2cos⁡x.

Notice that, because the cosine function is even, it is symmetric about the y-axis, i.e.,

2cos⁡x=2cos⁡(−x)

So the graph could also be viewed as y=2cos⁡(−x).
