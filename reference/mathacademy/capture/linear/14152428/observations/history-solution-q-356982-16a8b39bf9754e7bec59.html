The value of x+y is the number located a distance |y| from x on the number line,

  • moving to the right if y is positive, and

  • moving to the left if y is negative.

In our situation:

  • We start at x=−5 on the number line.

  • Here, y=8, so the distance we move is |y|=8.

  • Because y is positive, we move 8 units to the right from −5.

This point corresponds to the number −5+8=3.
