Write the equations of the vertical and horizontal lines that pass through the point B.
The **equation** of the vertical line is
x=3
The **equation** of the horizontal line is
y=2
Submit
Correct
Explanation

The coordinates of B are (3,2).

  • Since the vertical line should pass through (3,2), the x-value for every point on the line is 3. Hence, the equation of that line is x=3.

  • Since the horizontal line should pass through (3,2), the y-value for every point on the line is 2. Hence, the equation of that line is y=2.
