Consider the equivalence relation ∼ on R, defined by x∼y if cos⁡x=cos⁡y. Which of the following are in the equivalence class [0]?

  1. 2π
  2. 3π
  3. π2
a
II only
b
I only
c
I and III only
d
III only
e
II and III only
Submit
Correct
EXPLANATION

The equivalence class [0] consists of the elements that are equivalent to 0 under the given equivalence relation. So, we have

[0]={x∈R|x∼0}={x∈R|cos⁡x=cos⁡0}={x∈R|cos⁡x=1}={…,−4π,−2π,0,2π,4π,…}.

We see that 2π is in [0], while 3π and π2 are not.

Therefore, the correct answer is "I only."
