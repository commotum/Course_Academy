An integer is odd if it can be written as 2a+1, where a is an integer.

Now, note the following regarding the expression 6p+10q+3:

  • All terms, apart from the constant term, have a common factor of 2.

  • The constant term can be written as 3=2+1.

Therefore, we complete our argument as follows:

The number n is odd since n=6p+10q+3=(6p+10q+2)+1=2(3p+5q+1⏟a)+1=2a+1, where a=3p+5q+1∈Z.
