EXPLANATION

Let's look at each statement in turn.

  • Statement I is false. As x approaches 0 from the right, the function value f(x) approaches y=1. Therefore, limx→0+f(x)=1.

  • Statement II is true. As x approaches 2 from the left, the function value f(x) approaches y=1, Therefore, limx→2−f(x)=1.

  • Statement III is false. As x approaches −1 from the right, the function value f(x) is undefined. Consequently, limx→−1+f(x)=DNE. Instead, as x approaches −1 from the left, the function value f(x) approaches y=1, and consequently limx→−1−f(x)=1. Therefore, limx→−1−f(x)≠limx→−1+f(x).

Therefore, only statement II is true.
