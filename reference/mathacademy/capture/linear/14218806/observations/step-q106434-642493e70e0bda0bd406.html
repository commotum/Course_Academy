Which of the following statements are true concerning the function y=f(x) whose graph is shown above?

  1. limx→−3+f(x)=0
  2. limx→−1+f(x)=DNE
  3. limx→−1−f(x)=limx→1+f(x)

I and II only

Correct
EXPLANATION

Let's look at each statement in turn.

  • Statement I is true. As x approaches −3 from the right, the function value f(x) approaches y=0, Therefore, limx→−3+f(x)=0.

  • Statement II is true. As x approaches −1 from the right, the function value f(x) is undefined, Therefore, limx→−1+f(x)=DNE.

  • Statement III is false. As x approaches −1 from the left, the function value f(x) approaches y=−2, and consequently limx→−1−f(x)=−2. Similarly, as x approaches 1 from the right, the function value f(x) approaches y=0, and consequently limx→1+f(x)=0. Therefore, limx→−1−f(x)≠limx→1+f(x).

Therefore, only statements I and II are true.
