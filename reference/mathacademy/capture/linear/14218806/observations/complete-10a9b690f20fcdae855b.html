  2. limx→1+f(x)=limx→2−f(x)
  3. limx→1−f(x)=limx→2+f(x)

b

Correct
EXPLANATION

First, let's compute the limits in question.

As x approaches −2 from the left, the function value f(x) approaches y=2, and consequently limx→−2−f(x)=2.

As x approaches −2 from the right, the function value f(x) approaches y=−2, and consequently limx→−2+f(x)=−2.

We cannot approach x=1 from the right because the function is not defined to the right of x=1. Consequently, limx→1+f(x)=DNE. Similarly, we cannot approach 2 from the left because the function is not defined to the left of x=2. Consequently, limx→2−f(x)=DNE.

As x approaches 1 from the left, the function value f(x) approaches y=1, and consequently limx→1−f(x)=1.

As x approaches 2 from the right, the function value f(x) approaches y=1, and consequently limx→2+f(x)=1.

Now, let's look at each statement in turn.

  • I. limx→−2−f(x)=limx→−2+f(x) becomes 2=−2, which is false.

  • II. limx→1+f(x)=limx→2−f(x) is false because neither one-sided limit exists.

  • III. limx→1−f(x)=limx→2+f(x) becomes 1=1, which is true.

Thus, only statement III is true.
