EXPLANATION

De Morgan's law for disjunctions states that

¬(A∨B)=¬A∧¬B.

So, the negation of "x is an integer or x is irrational" is

¬(x is an integer or x is irrational )≡¬(x is an integer∨x is irrational)≡¬(x is an integer)∧¬(x is irrational)≡x is not an integer∧x is not irrational ≡x is not an integer and x is not irrational.
