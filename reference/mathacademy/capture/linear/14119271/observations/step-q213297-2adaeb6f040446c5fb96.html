Given that 5a≡5b(mod15), which of the following statements must be true?

  1. a≡b(mod6)
  2. a≡b(mod3)
  3. 4a≡4b(mod12)
a
I and III only
b
II only
c
III only
d
II and III only
e
I only
Submit
Incorrect
EXPLANATION

The division properties of modular arithmetic state the following:

  • For k≠0, we have ka≡kb(modkn)⟺a≡b(modn).

  • For gcd(k,n)=1, we have ka≡kb(modn)⟺a≡b(modn).

With that in mind, let's consider each statement.

  • Statement I is false, while statement II is true. Applying the first property, we have the following: 5a≡5b(mod15)5⋅a≡5⋅b(mod5⋅3)5⋅a≡5⋅b(mod5⋅3)a≡b(mod3)
  • Statement III is true. By statement II and the first property, we have:
    a≡b(mod3)⟺4a≡4b(mod12)

Therefore, the correct answer is "II and III only ."
