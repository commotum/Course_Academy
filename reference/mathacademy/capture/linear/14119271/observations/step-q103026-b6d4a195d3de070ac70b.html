If ka≡kb(mod8) is equivalent to a≡b(mod8), which of the following could be the value of k?

  1. k=8
  2. k=−12
  3. k=−15
a
III only
b
I and II only
c
II only
d
I and III only
e
I only
Submit
Correct
EXPLANATION

The division property of modular arithmetic states that

ka≡kb(modn)⟺a≡b(modn)

provided that k and n are coprime. In other words, we require gcd(k,n)=1.

In this case, the modulus n=8. Let's consider each value of k in turn.

  • If k=8, then gcd(k,n)=gcd(8,8)=8≠1. Therefore, our equivalence is not valid for k=8.

  • If k=−12, then gcd(k,n)=gcd(−12,8)=4≠1. Therefore, our equivalence is not valid for k=−12.

  • If k=−15, then gcd(k,n)=gcd(−15,8)=1. Therefore, our equivalence is valid for k=−15.

Therefore, the correct answer is "III only."
