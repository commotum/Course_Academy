A binary relation R defined on a set A is transitive if, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R. In other words, if the pairs (x,y) and (y,z) belong to a transitive relation, then the pair (x,z) should also be in the relation.

It's sufficient to check all the "linked" pairs of the form (x,y) with x≠y and (y,z) with y≠z:

  • Consider the pair (2,4) whose second component is 4. It can be linked with the following pairs from R whose first component is 4:

    • Linking (2,4) with (4,2) requires that (2,2)∈R, and this pair is in R. ✓

    • Linking (2,4) with (4,8) requires that (2,8)∈R, and this pair is in R. ✓

  • Consider the pair (2,8) whose second component is 8. It can't be linked with any pair from R since none of them have a first component of 8.

  • Consider the pair (4,2) whose second component is 2. It can be linked with the following pairs from R whose first component is 2:

    • Linking (4,2) with (2,4) requires that (4,4)∈R, and this pair is in R. ✓

    • Linking (4,2) with (2,8) requires that (4,8)∈R, and this pair is in R. ✓

  • Consider the pair (4,8) whose second component is 8. It can't be linked with any pair from R since none of them have a first component of 8.

So, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R.

Therefore, the relation is transitive.
