Which of the above digraphs represents a transitive relation defined on the set A={p,q,r}?

a
II and III only
b
III only
c
II only
d
I and II only
e
I only
Submit
Correct
EXPLANATION

A binary relation R defined on a set A is transitive if, for all x,y,z∈A, we have (x,y)∈Rand(y,z)∈R⟹(x,z)∈R. In other words, if the pairs (x,y) and (y,z) belong to a transitive relation, then the pair (x,z) should also be in the relation.

It's sufficient to check all the "linked" pairs of the form (x,y) with x≠y and (y,z) with y≠z.

In terms of a digraph, if we have "linked" arrows x→y and y→z, then the arrow x→z must be in the digraph too.

With that in mind, let's examine our digraphs.

  • Digraph I does not represent a transitive relation. It has arrows q→r and r→p, but has no arrow q→p.

  • Digraph II represents a transitive relation. For any pair of arrows x→y and y→z, the arrow x→z also belongs to the digraph.

  • Digraph III does not represent a transitive relation. It has arrows p→q and q→r, but has no arrow p→r.

Therefore, the correct answer is "II only."
