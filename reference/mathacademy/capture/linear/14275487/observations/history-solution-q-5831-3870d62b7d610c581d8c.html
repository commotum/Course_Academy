Let's call A the event "we get the number 4 on the first toss" and B the event "we get the number 5 on the second toss." Then the required probability is P(A∩B).

Since die throws are independent events, we can use the multiplication law for independent events, which states that P(A∩B)=P(A)⋅P(B).

Let's find P(A) and P(B). There are 6 possible outcomes when we roll the die. So, we have P(A)=P(B)=16.

Therefore, substituting the above into the multiplication law for independent events, we get P(A∩B)=16⋅16=136.
