First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Let's now look at each statement in turn.

  • Statement I is true. A kite has two pairs of congruent sides that are adjacent to each other. A square fits the description because all the sides in a square are congruent.

  • Statement II is false. In a square, all the sides are congruent. However, in a rectangle, it's only necessary that two pairs of opposite sides are congruent to each other. Therefore, a rectangle is not always a square.

  • Statement III is false. In a trapezoid, only 1 pair of opposite sides are parallel to each other. However, in a rhombus, the 2 pairs of opposite sides are parallel to each other. Therefore, a rhombus is not a trapezoid.

In conclusion, only statement I is true.
