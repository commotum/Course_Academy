Which of the figures above is a rhombus?

a
P and Q only
b
Q only
c
Q and S only
d
R only
e
R and Q only
Submit
Correct
EXPLANATION

First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Remember that a rhombus is a parallelogram where all sides are congruent. The opposite angles of a rhombus are also congruent.

With that in mind, let's look at each shape in turn.

  • The shape P is a rectangle. The sides are not all congruent, so it is not a rhombus.

  • The shape Q is a kite. Since the sides are not all congruent, it is not a rhombus.

  • The shape R is a rhombus since all its sides are congruent and the opposite sides are parallel.

  • The shape S is an isosceles trapezoid. Since it has only one pair of congruent sides, it is not a rhombus.

Therefore, only shape R is a rhombus.
