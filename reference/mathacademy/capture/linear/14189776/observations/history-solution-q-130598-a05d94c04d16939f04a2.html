Recall that the graph of y=2−12x is a straight line, and two distinct points can determine any straight line.

So, given any two distinct values of x, we can find the corresponding y-values by substituting x into the formula y=2−12x. For example,

  • if x=0 then y=2−12(0)=2, which gives the point (0,2), and

  • if x=2 then y=2−12(2)=1, which gives the point (2,1).
