EXPLANATION

We can find the necessary function values using the graph.

From the graph, we note the following:

  • When x=−3, the function is undefined.

  • When x=3, we have y=−2. So, f(3)=−2.

Therefore, since f(−3) is undefined, the sum f(−3)+f(3) is undefined too.
