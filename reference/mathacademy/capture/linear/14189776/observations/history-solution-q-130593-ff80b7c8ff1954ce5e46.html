Recall that the graph of y=3x−3 is a straight line, and two distinct points can determine any straight line.

So, given any two distinct values of x, we can find the corresponding y-values by substituting x into the formula y=3x−3. For example,

  • if x=0 then y=3(0)−3=−3, which gives the point (0,−3), and

  • if x=1 then y=3(1)−3=0, which gives the point (1,0).
