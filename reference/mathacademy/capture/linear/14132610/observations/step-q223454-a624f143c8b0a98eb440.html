Which of the following numbers are divisible by 7?

  1. 434
  2. 785
  3. 587
a
I only
b
II only
c
I and II only
d
III only
e
II and III only
Submit
Correct
EXPLANATION

To check if a number is divisible by 7, double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by 7.

  • For the number 434, we have that 43−2(4)=43−8=35 which is divisible by 7. Therefore, 434 is divisible by 7.

  • For the number 785, we have that 78−2(5)=78−10=68 which is not divisible by 7. Therefore, 785 is not divisible by 7.

  • For the number 587, we have that 58−2(7)=58−14=44 which is not divisible by 7. Therefore, 587 is not divisible by 7.

Therefore, the correct answer is "I only."
