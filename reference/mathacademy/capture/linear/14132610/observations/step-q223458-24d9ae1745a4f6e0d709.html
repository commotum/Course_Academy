Which of the following numbers are divisible by 7?

  1. 276
  2. 647
  3. 805

Correct
EXPLANATION

To check if a number is divisible by 7, double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by 7.

  • For the number 276, we have that 27−2(6)=27−12=15 which is not divisible by 7. Therefore, 276 is not divisible by 7.

  • For the number 647, we have that 64−2(7)=64−14=50 which is not divisible by 7. Therefore, 647 is not divisible by 7.

  • For the number 805, we have that 80−2(5)=80−10=70 which is divisible by 7. Therefore, 805 is divisible by 7.

Therefore, the correct answer is "III only."
