  2. 352
  3. 217

EXPLANATION

To check if a number is divisible by 7, double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by 7.

  • For the number 448, we have that 44−2(8)=44−16=28 which is divisible by 7. Therefore, 448 is divisible by 7.

  • For the number 352, we have that 35−2(2)=35−4=31 which is not divisible by 7. Therefore, 352 is not divisible by 7.

  • For the number 217, we have that 21−2(7)=21−14=7 which is divisible by 7. Therefore, 217 is divisible by 7.

Therefore, the correct answer is "I and III only."
