  3. 423

EXPLANATION

To check if a number is divisible by 7, double the last digit, subtract the result from the remaining digits, and then check if the difference is divisible by 7.

  • For the number 476, we have that 47−2(6)=47−12=35 which is divisible by 7. Therefore, 476 is divisible by 7.

  • For the number 732, we have that 73−2(2)=73−4=69 which is not divisible by 7. Therefore, 732 is not divisible by 7.

  • For the number 423, we have that 42−2(3)=42−6=36 which is not divisible by 7. Therefore, 423 is not divisible by 7.

Therefore, the correct answer is "I only."
