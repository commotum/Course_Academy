Which of the following is equivalent to 3x≡1(mod14)?

a
x≡9(mod14)
b
x≡5(mod14)
c
x≡7(mod14)
d
x≡1(mod14)
e
x≡2(mod14)
Submit
Correct
EXPLANATION

The scalar multiplication properties of congruences state that for k∈Z, we have the following:

  • a≡b(modn)⟹ka≡kb(modn)

  • a≡b(modn)⟹ka≡kb(modkn)

The modulus equals 14 in all statements, which suggests we'll need to use the first property.

Notice that the coefficient of x is 3, and 5⋅3=15 is one larger than the modulus. Therefore, we can reduce the coefficient of x to unity as follows:

3x≡1(mod14)5⋅3x≡5⋅1(mod14)15x≡5(mod14)x+14x≡5(mod14)x+0x≡5(mod14)x≡5(mod14)
