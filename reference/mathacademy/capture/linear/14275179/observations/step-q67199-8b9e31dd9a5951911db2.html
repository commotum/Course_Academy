Express the following arithmetic series using sigma notation.

−12−7−2+3+8+…+28+33

a
∑n=110(5n−12)
b
∑n=110(5n−17)
c
∑n=110(12−5n)
d
∑n=09(5n−17)
e
∑n=133(−5n+17)

Correct
EXPLANATION

The first term a1=−12 and the common difference is:

d=a2−a1=−7−(−12)=5

Hence, the formula for the nth term is:

an=a1+(n−1)d=−12+(n−1)(5)=−12+5n−5=5n−17

We don't know the index of the last term, but we can find it using the formula for the nth term:

an=335n−17=335n=33+175n=50n=10

There are 10 terms in total, from n=1 to n=10. So, the sigma notation for the given sum is:

∑n=110(5n−17)
