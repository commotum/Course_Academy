Express the following arithmetic series using sigma notation.

1+53+73+…+373+13

a
∑n=119(53n+13)
b
∑n=119(23n+13)
c
∑n=119(53n+1)
d
∑n=119(23n+1)
e
∑n=119(23n+43)

Correct
EXPLANATION

The first term a1=1 and the common difference is:

d=a2−a1=53−1=23

Hence, the formula for the nth term is:

an=a1+(n−1)d=1+(n−1)(23)=1+23n−23=23n+13

We don't know the index of the last term, but we can find it using the formula for the nth term:

an=1323n+13=1323n=383n=19

There are 19 terms in total, from n=1 to n=19. So, the sigma notation for the given sum is:

∑n=119(23n+13)
