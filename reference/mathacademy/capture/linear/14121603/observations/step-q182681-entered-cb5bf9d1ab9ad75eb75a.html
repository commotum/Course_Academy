EXPLANATION

A variant of the principle of induction states the following: Let n0 be an integer. Suppose we have a sequence of mathematical statements P(n0),P(n0+1),P(n0+2),…, where

  • P(n0) is true, and

  • P(k)⇒P(k+1) for every natural number k≥n0.

Then, P(n) is true for every natural number n≥n0.

In this case, the general statement P(n) we're required to prove is the following: ∑i=3n(2i+3)=(n+6)(n−2)

We start by proving the so-called base case, P(3). To do this, we substitute n=3 into both the left-hand side and right-hand side and show that they're equal:

We proceed using induction on n.

Base Case: We first prove our statement is true for the base case n=3. For the left-hand side, we have ∑i=33(2i+3)=2(3)+3=9, and for the right-hand side, we have (3+6)(3−2)=9(1)=9. Thus, our statement is true for n=3.

Next, we state our inductive hypothesis. Here, we assume that the given statement is true for some n=k≥3.

Due to the base case, we already know that the statement is true for some value of k, namely k=3, so this assumption is valid.

Inductive Hypothesis: We assume that for some n=k≥3, we have ∑i=3k(2i+3)=(k+6)(k−2).

We must show that P(k)⇒P(k+1). Let's start by writing down P(k+1). This is the first part of the so-called inductive step, so let's write that, too.

Inductive Step: We're required to prove that ∑i=3k+1(2i+3)=(k+7)(k−1).(∗)

The idea is to rewrite the left-hand side of (∗) using the inductive hypothesis and apply algebraic techniques to show that this equals the right-hand side.

When proving sums of finite series using induction, the key to unlocking the proof is to write the last term on its own, as follows: ∑i=1k+1ai=(∑i=1kai)+ak+1

Let's apply this technique in this case:

We write ∑i=3k+1(2i+3)=(∑i=3k(2i+3))+2(k+1)+3. By the inductive hypothesis, we have (∑i=3k(2i+3))+2(k+1)+3=(k+6)(k−2)+(2k+5)=k2+4k−12+2k+5=k2+6k−7=(k+7)(k−1), as required.

Since we've shown that the left-hand side of (∗) equals the right-hand side, our proof is complete. So let's write down our conclusion.

Therefore, by the principle of induction, ∑i=3n(2i+3)=(n+6)(n−2) is true for all n≥3.
