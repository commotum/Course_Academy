First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Remember that a kite is a quadrilateral with two pairs of congruent sides that are adjacent to each other.

With that in mind, let's look at each shape in turn.

  • The shape P is a trapezoid. It doesn't have two pairs of congruent sides that are adjacent to each other, therefore, it is not a kite.

  • The shape Q is a rectangle. Since it doesn't have two pairs of congruent sides that are adjacent to each other, it is not a kite.

  • The shape R is a rhombus. Therefore, it has two pairs of congruent sides that are adjacent to each other, so it is a kite.

  • The shape S is a parallelogram. Any two adjacent sides are not congruent with each other, therefore, it is not a kite.

Therefore, only shape R is a kite.
