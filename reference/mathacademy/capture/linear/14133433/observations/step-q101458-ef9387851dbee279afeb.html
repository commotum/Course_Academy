First, we count the number of heptagons. We see that there are 4 heptagons.

Then, we count the number of squares. We see that there are 4 squares.

So the ratio of heptagons to squares is 4:4.

We can simplify this ratio by dividing both numbers by 4:

This means that 1:1 is equivalent to 4:4.

So, the complete statement is "The ratio of heptagons to squares is 1:1 because there is 1 heptagon for every 1 square."
