The table below defines the function f(x). Given that f(x) is an even function, find the value of a+b.

x −23 −15 −7 7 15 23
f(x) a+5 −2 b+1 4 −2 6
a
3
b

Submit
Correct
EXPLANATION

Since f(x) is an even function, we must have that f(−x)=f(x).

Using the fact that f(−23)=f(23), we obtain

f(−23)=f(23)a+5=6a=1.

Using the fact that f(−7)=f(7), we obtain

f(−7)=f(7)b+1=4b=3.

Finally, a+b=1+3=4.
