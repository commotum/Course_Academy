Remember that

  • a function is even if f(−x)=f(x) for all x, while

  • a function is odd if f(−x)=−f(x) for all x.

Computing f(−x) for the given function and comparing it to f(x), we have f(−x)=1(−x)2=1x2.

Since f(−x)=f(x), the function is even.

Lastly, we compute −f(x) and get −f(x)=−(1x2)=−1x2. Since f(−x)≠−f(x), the function is not odd.

Therefore, the function is only even.
