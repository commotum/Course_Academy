We need to isolate P, so we will treat the other variables E, Q, and C as constants. We can use the addition and multiplication principles to solve for P.

First, we add C to both sides:

E=PQ−CE+C=PQ−C+CE+C=PQ

Then, we divide by Q to get P alone:

E+C=PQE+CQ=PQQE+CQ=P

Thus, P=E+CQ.

Note: This result assumes that Q≠0.
