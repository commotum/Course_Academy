A partition of a set T is a collection of non-empty subsets of T where every element of T is contained in exactly one subset.

Of the given collections, only {{0,10},{2,4,6,8}} is a partition.

The rest of the collections are not partitions:

  • {∅,{0,2,4,6,8},{10}} is not a partition because the subset ∅ is empty.

  • {{0,2,4,6,8,10,12}} is not a partition because the element 12 does not appear in T.

  • {{0,10},{2},{4,8}} is not a partition because the element 6∈T does not appear in any subset.

  • {{0,10},{2,4,6,8,10}} is not a partition because the element 10 appears in two subsets.
