If Y={20,22,24,…,180}, which collection of subsets of Y is a partition of Y?

a
{{20,22,24,…,60},{62,64,66,…,120},{122,124,126,…,180}}
b
{{20,22,24,…,80},{66,68,70,…,180}}
c
 {{20,22,24,…,70},{140,142,144,…,180}}
d
{{2,4,6,…,180}}
e
 {{20,22,24,26},{27,28,29,…,180}}
Submit
Incorrect
EXPLANATION

A partition of a set Y is a collection of non-empty subsets of Y where every element of Y is contained in exactly one subset.

Of the given collections, only {{20,22,24,…,60},{62,64,66,…,120},{122,124,126,…,180}} is a partition.

The rest of the collections are not partitions:

  • {{20,22,24,…,70},{140,142,144,…,180}} is not a partition because some elements of Y, such as 72,74,…,138, do not appear in any subsets.

  • {{20,22,24,…,80},{66,68,70,…,180}} is not a partition because the elements 66,68,…,80 appear in both subsets.

  • {{2,4,6,…,180}} is not a partition because it contains many elements, such as 2,4,…,20, that do not appear in Y.

  • {{20,22,24,26},{27,28,29,…,180}} is not a partition because it contains many elements, such as 27 and 29, that do not appear in Y.
