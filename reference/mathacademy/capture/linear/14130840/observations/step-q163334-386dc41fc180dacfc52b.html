a
10mg
b
100mg
c
0.01mg

1000mg

0.1mg

EXPLANATION

A table showing the units of mass in metric units is given below.

Name Symbol Conversion
Kilogram kg 1kg=1000g
Gram g Base Unit
Milligram mg 1000mg=1g

So, 1g is equivalent to 1000mg.
