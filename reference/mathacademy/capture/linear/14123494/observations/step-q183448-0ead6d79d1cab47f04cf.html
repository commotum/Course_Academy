EXPLANATION

Let's recall the following grammatical constructions for the implication P⇒Q:

  • If P, then Q

  • P only if Q

  • Q if P

  • P implies Q

With that in mind, let's examine the given options.

  • Option I reads x2=4⏟Q(x)impliesx=2⏟P(x) which corresponds to Q(x)⇒P(x). ×

  • Option II reads ifx2=4⏟Q(x),thenx=2⏟P(x) which corresponds to Q(x)⇒P(x). ×

  • Option III reads x2=4⏟Q(x)only ifx=2⏟P(x) which corresponds to Q(x)⇒P(x). ×

  • Option IV reads x2=4⏟Q(x)ifx=2⏟P(x) which corresponds to P(x)⇒Q(x). ✓

Therefore, the correct answer is "IV only."
