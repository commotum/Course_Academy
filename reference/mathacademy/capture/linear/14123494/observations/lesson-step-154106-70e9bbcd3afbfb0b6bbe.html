is prime is not a multiple of

Which of the following expresses the conditional predicate

  1. is not a multiple of if is prime
  2. If is not a multiple of then is prime
  3. is prime implies is not a multiple of
  4. is not a multiple of only if is prime
EXPLANATION

Let's recall the following grammatical constructions for the implication

  • If then

  • only if

  • if

  • implies

With that in mind, let's examine the given options.

  • Option I reads which corresponds to

  • Option II reads which corresponds to

  • Option III reads which corresponds to

  • Option IV reads which corresponds to

Therefore, the correct answer is "I and III only."
