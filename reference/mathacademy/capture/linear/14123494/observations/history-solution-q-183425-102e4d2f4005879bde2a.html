Let's recall the following grammatical constructions for the implication P⇒Q:

  • If P, then Q

  • P only if Q

  • Q if P

  • P implies Q

Let's now compare these against the entries in our table:

  • "If B, then A" means B⇒A

  • "A only if B" means A⇒B

  • "B if A" means A⇒B

  • "B implies A" means B⇒A

The completed table is shown below.

Sentence Symbolic Form
If B, then A B⇒A
A only if B A⇒B
B if A A⇒B
B implies A B⇒A
