Consider the following set:

A={2,4,6}

Given the relation R on A defined by xRy⇔x∤y,

which of the following statements are true?

  1. 2R4
  2. 4R6
  3. 2R6
a
 II only
b
 I, II, and III
c
 II and III only
d
 I and II only
e
 I only
Submit
Correct
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A2

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x∤y. For this relation, note that

  • the symbols R and ∤ are interchangeable, and

  • the symbols R and ∣ are also interchangeable.

With that in mind, let's examine our statements in turn:

  • Statement I is false. Replacing R with the symbol ∤, we have 2∤4, which is false.

  • Statement II is true. Replacing R with the symbol ∤, we have 4∤6, which is true.

  • Statement III is true. Replacing R with the symbol ∣, we have 2∣6, which is true.

Therefore, the correct answer is "II and III only."
