Let B={−1,0,1}. Which set is equivalent to the following relation on B? R={(x,y)∈B2:|x|≠|y|}

a
{(−1,−1),(0,0),(1,1)}
b
{(0,−1),(0,1)}
c
{(−1,0),(0,−1),(0,1),(1,0)}
d
{(−1,0),(0,1)}
e
{(−1,0),(1,0)}
Submit
Incorrect
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A×A

In this case, R is the set of ordered pairs (x,y)∈B2 such that |x|≠|y|.

Let's check each element x∈B to see which elements y∈B it could be paired with to satisfy the conditions of our relation.

  • If x=−1, then the value y=0 satisfies |x|≠|y|. So, R contains the ordered pair (−1,0).

  • If x=0, then the values y=−1 and y=1 satisfy |x|≠|y|. So, R contains the ordered pairs (0,−1) and (0,1).

  • If x=1, then the value y=0 satisfies |x|≠|y|. So, R contains the ordered pair (1,0).

Therefore, we can describe our relation as the following set of ordered pairs:

R={(−1,0),(0,−1),(0,1),(1,0)}
