EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A2

In this case, R is the set of ordered pairs (x,y)∈A2 such that x≡y(mod3).

Let's check each element x∈A to see which elements y∈A it could be paired with to satisfy the relation.

  • If x=2, then the values y=2 and y=5 satisfy x≡y(mod3), since 3∣(2−2) and 3∣(2−5). So, R contains the ordered pairs (2,2),(2,5).

  • If x=5, then the values y=2 and y=5 satisfy x≡y(mod3), since 3∣(5−2) and 3∣(5−5). So, R contains the ordered pairs (5,2),(5,5).

Therefore, we can describe our relation as the following set of ordered pairs: R={(2,2),(2,5),(5,2),(5,5)}
