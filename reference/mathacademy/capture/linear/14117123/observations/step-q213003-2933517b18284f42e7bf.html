Consider the following set:

A={{0},{1,0}}

Which of the following ordered pairs is an element of the relation "is not a subset of" on A?

  1. ({0},{1,0})
  2. ({1,0},{0})
  3. ({1,0},{1,0})
a
I and II only
b
I only
c
II only
d
None of the ordered pairs are elements of the relation.
e
I, II, and III
Submit
Correct
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A2

In this case, R is the set of ordered pairs (x,y)∈A2 such that x⊈y.

With that in mind, let's examine our ordered pairs in turn.

  • The ordered pair ({0},{1,0}) is not an element of R since {0}⊆{1,0}.×

  • The ordered pair ({1,0},{0}) is an element of R since {1,0}⊈{0}.✓

  • The ordered pair ({1,0},{1,0}) is not an element of R since {1,0}⊆{1,0}.×

Therefore, the correct answer is "II only."
