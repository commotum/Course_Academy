EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A×A

In this case, R is the set of ordered pairs (x,y)∈B2 such that y=2x.

Let's check each element x∈B to see which elements y∈B it could be paired with to satisfy the conditions of our relation.

  • If x=0, then the value y=0 satisfies y=2x. So, R contains the ordered pair (0,0).

  • If x=1, then the value y=2 satisfies y=2x. So, R contains the ordered pair (1,2).

  • If x=2, then the value y=4 satisfies y=2x. So, R contains the ordered pair (2,4).

  • If x=3, then there is no value of y∈B that satisfies y=2x.

  • If x=4, then there is no value of y∈B that satisfies y=2x.

Therefore, we can describe our relation as the following set of ordered pairs:

R={(0,0),(1,2),(2,4)}
