Consider the following set:

A={{0},{0,1}}

Given the relation R on A defined by XRY⇔X⊃Y, which of the following statements are true?

  1. {0}R{0,1}
  2. {0,1}R{0,1}
  3. {0}R{0}
a
None of the statements are true.
b
II only
c
II and III only
d
III only
e
I, II, and III
Submit
Correct
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊂A2

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have XRY if and only if X⊃Y. For this relation, note that

  • the symbols R and ⊃ are interchangeable, and

  • the symbols R and ⊅ are also interchangeable.

With that in mind, let's examine our statements in turn.

  • Statement I is false. Replacing R with the symbol ⊃, we have {0}⊃{0,1}. This is equivalent to {0,1}⊂{0}, which is false.

  • Statement II is false. Replacing R with the symbol ⊃, we have {0,1}⊃{0,1}. This is equivalent to {0,1}⊂{0,1}, which is false.

  • Statement III is true. Replacing R with the symbol ⊅, we have {0}⊅{0}. This is equivalent to {0}⊄{0}, which is true.

Therefore, the correct answer is "III only."
