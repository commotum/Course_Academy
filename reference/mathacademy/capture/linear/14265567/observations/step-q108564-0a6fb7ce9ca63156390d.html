EXPLANATION

We start the first line from the point (0,0), since the lioness is starting from rest. Then, because the acceleration is 5m/s2, we draw a line with slope 5.

However, because the lioness is only accelerating for the first 4 seconds, we stop the line at t=4. At this time, the lioness' speed has increased by 5⋅4=20m/s. So, the first line segment goes from (0,0) to (4,20).

After t=4, the lioness has a deceleration of 4m/s2, so the slope of the second line segment is −4. The second line segment stops when the lioness' speed returns to 0. To figure out when this is, we need to find the equation for the second line segment.

Since the second line segment passes through the point (4,20) and has a slope of −4, we can use point-slope form to write the equation of the line:

v−v1=m(t−t1)v−20=−4(t−4)v−20=−4t+16v=−4t+36

We solve for t when the speed of the lioness is zero:

v=−4t+360=−4t+364t=36t=9
