First, we graph the function g(x)=2x−6.

Then, we find the lowest and highest y-values in the graph over the domain x∈[2,4].

  • The lowest y value is −2. This occurs at the point (2,−2).

  • The highest y value is 2. This occurs at the point (4,2).

The function covers all the y-values between −2 and 2, including the endpoints.

Therefore, the range is −2≤y≤2, which can also be written as

−2≤g(x)≤2.
