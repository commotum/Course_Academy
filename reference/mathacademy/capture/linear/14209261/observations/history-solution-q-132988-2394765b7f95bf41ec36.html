First, we recall the following definitions: * The global maximum of a function is the highest value that the function attains on its domain. There can only be (at most) one global maximum. * A global maximum point of a function is a point (x,y) where a function reaches a global maximum. There can be zero, one, or many global maximum points. For our function, the maximum value reached by the function is h(x)=5.
Therefore, the global maximum is hmax=5. The function reaches this value when x=2, so the global maximum point is (2,5).
