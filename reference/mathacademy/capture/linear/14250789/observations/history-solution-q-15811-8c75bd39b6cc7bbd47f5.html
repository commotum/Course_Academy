Remember that y=|x−h|+k is a vertical translation of the absolute value graph y=|x| by h units right and k units up.

The function y=|x+4|−1 has h=−4 and k=−1. Therefore, it is a translation of the absolute value graph y=|x| by 4 units left and 1 unit down.

Looking at the graph, we can see that the minimum value of y is −1. This occurs at the point (−4,−1).
