The minimum value of the function y=|x+3|+2 is y=
2
.

Correct
EXPLANATION

Remember that y=|x−h|+k is a vertical translation of the absolute value graph y=|x| by h units right and k units up.

The function y=|x+3|+2 has h=−3 and k=2. Therefore, it is a translation of the absolute value graph y=|x| by 3 units left and 2 units up.

Looking at the graph, we can see that the minimum value of y is 2.
