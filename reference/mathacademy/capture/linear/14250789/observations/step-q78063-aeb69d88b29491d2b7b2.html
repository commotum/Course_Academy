If y=|x+1|, what are the coordinates of the minimum point on the graph?

a
(−1,0)
b
(1,0)
c
(0,1)
d
(1,1)
e
(0,−1)
Submit
Correct
EXPLANATION

Remember that y=|x−a| is a horizontal translation of the absolute value graph y=|x| by a units right.

The function y=|x+1| has a=−1. Therefore, it is a horizontal translation of the absolute value graph y=|x| by 1 unit left.

Looking at the graph, we can see that the coordinates of the minimum point are (−1,0).
