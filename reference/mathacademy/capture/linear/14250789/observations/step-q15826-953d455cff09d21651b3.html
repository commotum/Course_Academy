If y=|x−5|, what are the coordinates of the minimum point on the graph?

a
(5,0)
b
(−5,0)
c
(0,0)
d
(0,−5)
e
(0,5)
Submit
Incorrect
EXPLANATION

Remember that y=|x−a| is a horizontal translation of the absolute value graph y=|x| by a units right.

The function y=|x−5| has a=5. Therefore, it is a horizontal translation of the absolute value graph y=|x| by 5 units right.

Looking at the graph, we can see that the coordinates of the minimum point are (5,0).
