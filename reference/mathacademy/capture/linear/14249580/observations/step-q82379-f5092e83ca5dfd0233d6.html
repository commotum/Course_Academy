EXPLANATION

Since the period is 4, if we add (or subtract) any multiple of 4 from the input, the output stays the same.

So, we can keep adding 4 to the input until we get to an input that we see in the graph:

f(−46)=f(−46+4)=f(−46+2⋅4)=⋯=f(−46+11⋅4)=f(−2)=1
