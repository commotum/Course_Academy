Unit rates can be used to solve many real-world problems in which we are given two quantities and wish to find what happens to one quantity when we vary the other.

For example, we might know the total cost of a specific number of items and be asked to find the cost for a different number of the same item.

To solve a problem using unit rates, the first step is to compute the unit rate by dividing the two given quantities. Then, we can use the unit rate to calculate the desired quantity.
