Express log6⁡8+log6⁡3+log6⁡2 as a single logarithm.

a
log6⁡13
b
log6⁡48
c
log18⁡48
d
log216⁡48
e
log18⁡13
Submit
Correct
EXPLANATION

First, let's recall the product rule for logarithms:

logn⁡a+logn⁡b=logn⁡(ab)

Using the product rule for logarithms, we can combine the first two terms as follows: log6⁡8+log6⁡3+log6⁡2=log6⁡(8⋅3)+log6⁡2=log6⁡24+log6⁡2

Using the product rule for logarithms once more, we obtain log6⁡24+log6⁡2=log6⁡(24⋅2)=log6⁡48.
