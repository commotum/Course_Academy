In order to graph the function, it's helpful to know the period. In order to determine the period, we first need to determine the scaling factor.

Notice that the function f(x)=tan⁡(x5) can be written as f(x)=tan⁡(15x). So, it takes the form y=tan⁡(Bx) with B=15.

The horizontal scaling factor is given by 1B=1(15)=5.

So, the period is

π⋅1B=π⋅5=5π.

Now that we know the period is 5π, we can draw the general shape of the tangent function, but stretch it so that it fills up the interval (−5π2,5π2).
