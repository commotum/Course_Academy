In order to find the value of B, we first need to find the period of the function.

From the graph, we can see that function makes a complete cycles on the interval (−π10,π10). So, the period is π5.

We know that for a function y=tan⁡(Bx), the horizontal scaling factor is 1B, and the period is multiplied by the scaling factor: period=π⋅1B

For our particular function, the period is π5, so we have

π5=π⋅1B15=1BB=5.
