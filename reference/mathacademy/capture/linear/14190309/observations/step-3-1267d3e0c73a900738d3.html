Explanation

Speed is a special unit rate applied to moving objects. It is defined as the distance traveled per unit of time:

speed=distancetime

To find the speed in meters per minute, we divide the number of meters, 960, by the number of minutes, 16. This gives,

96016=960÷816÷8=1202=120÷2=60.

Therefore, Mary's speed was 60 meters per minute.
