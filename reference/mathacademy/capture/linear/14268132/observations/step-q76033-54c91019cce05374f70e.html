a
(0,5)

Correct
EXPLANATION

The transformation y=−g(x) reflects the curve y=g(x) in the x-axis, as shown below.

Note that for the function y=−g(x):

  • Its minimum value is indicated by the y-coordinate of the point (−3,0), and this value is not included in the range.

  • Its maximum value is indicated by the y-coordinate of the point (−8,5), but this value is included in the range.

Therefore, the range of the function y=−g(x) is (0,5].
