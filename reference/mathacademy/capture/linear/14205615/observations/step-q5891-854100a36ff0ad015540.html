The table below defines the function f(x). Is the function even, odd, or neither?

x −99 −52 −8 8 52 99
f(x) 150 70 0 −11 −92 −180
a
Both even and odd
b
Neither even nor odd
c
It's not a function
d
Odd
e
Even
Submit
Correct
EXPLANATION

Recall that

  • a function is even if f(−x)=f(x) for all x in the domain of f

  • a function is odd if f(−x)=−f(x) for all x in the domain of f

First, we have

f(−99)=150≠f(99).

This means that f(−x)≠f(x) at least for some values of x in the domain of the function. So, the function is not even.

Next, we have

f(−99)=150≠−f(99).

This means that f(−x)≠−f(x) at least for some values of x in the domain of the function. So, the function is not odd.

Hence, the function is neither even nor odd.
