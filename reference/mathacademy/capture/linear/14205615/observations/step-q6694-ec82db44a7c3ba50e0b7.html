Is the function f(x)=−2x−5 even, odd, or neither?

a
Odd
b
Both even and odd
c
Neither even nor odd
d
Even
e
It's not a function
Submit
Correct
EXPLANATION

Recall that

  • a function is even if f(−x)=f(x) for all x

  • a function is odd if f(−x)=−f(x) for all x

Computing f(−x) for the given function and comparing it to f(x), we have f(−x)=−2(−x)−5=2x−5 Since f(−x)≠f(x), the function is not even.

Lastly, we compute −f(x) and get −f(x)=−(−2x−5)=2x+5 Since f(−x)≠−f(x), the function is not odd.

Therefore, the function is neither even nor odd.
