EXPLANATION

We convert the absolute value inequality into a compound inequality to remove the absolute value.

The inequality specifies every number 8−2z whose distance from zero is greater than 2. This corresponds to the following compound inequality:

8−2z<−2or8−2z>2

Now, we can solve each inequality using the usual methods. (Remember that whenever we multiply or divide by a negative number, we have to flip the inequality signs.)
