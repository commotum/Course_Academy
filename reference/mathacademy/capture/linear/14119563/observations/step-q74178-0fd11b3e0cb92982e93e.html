EXPLANATION

Using the triangle inequality, we have that

‖2u+v‖≤2‖u‖+‖v‖.

Simplifying and substituting in the given information, we get

‖2u+v‖≤2‖u‖+‖v‖14≤2⋅3+‖v‖14≤6+‖v‖8≤‖v‖.

Therefore, the smallest possible value of ‖v‖ is 8.
