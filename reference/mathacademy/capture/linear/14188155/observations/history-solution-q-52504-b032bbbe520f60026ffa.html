The square root of a squared quantity can be simplified using absolute value.

x2=|x|

In our case, we can simplify the given expression as follows: 9y2=3y⋅3y=(3y)2=|3y|=|3||y|=3|y|

We are told that y<0. To take the absolute value of any negative number we need to flip the sign, so we have |y|=−y. Therefore, our final answer is 3|y|=−3y.
