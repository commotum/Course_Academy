The square root of a squared quantity can be simplified using absolute value. x2=|x|

In our case, we can simplify the given expression as follows: 4f2g2h2=(2fgh)2=|2fgh|=|2|⋅|fgh|=2⋅|fgh|

We are told that f<0, g<0 and h>0. We know that the absolute value of any positive number is just itself, and to take the absolute value of any negative number we need to flip the sign. Therefore, our final answer is 2⋅|fgh|=2⋅|f|⋅|g|⋅|h|=2⋅(−f)⋅(−g)⋅(h)=2fgh.
