Negate the following statement:

Some rational numbers are not proper fractions.

a
All rational numbers are not proper fractions.
b
Some rational numbers are not proper fractions.

All rational numbers are proper fractions.

Some rational numbers are proper fractions.

None of the listed

Incorrect
EXPLANATION

The given statement can be re-phrased as follows:

There exists x∈Q such that x is not a proper fraction.

Introducing the existential quantifier, we get the following:

∃x∈Q,x is not a proper fraction.

Negating this, we obtain

¬(∃x∈Q,x is not a proper fraction)≡∀x∈Q,¬(x is not a proper fraction)≡∀x∈Q,x is a proper fraction

which reads

For all x∈Q, x is a proper fraction.

or simply

All rational numbers are proper fractions.
