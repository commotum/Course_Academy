Negate the following statement:

For all m∈N, 3m+1 is not odd.

a
There exists m∈N such that 3m+1 is odd.
b
For all m∈N, m is not odd.
c
There exists m∈N such that 3m+1 is not odd.
d
None of the listed.
e
For all m∈N, m is odd.
Submit
Correct
EXPLANATION

If we denote

P(m):3m+1 is odd,

our statement can be written as

∀m∈N,¬P(m).

Negating this, we obtain

¬(∀m∈N,¬P(m))≡∃m∈N,¬¬P(m)≡∃m∈N,P(m).

Finally, ∃m∈N,P(m) reads as follows:

There exists m∈N such that 3m+1 is odd.
