Negate the following statement:

There exists k∈Z such that 2k is not even.

a
For all k∈Z, 2k is even.
b
There exists k∈Z such that 2k is even.
c
For all k∈Z, 2k is not even.
d
None of the listed.
e
There exists k∈Z such that 2k is not even.
Submit
Correct
EXPLANATION

If we denote P(k):2k is even,

our statement can be written as ∃k∈Z,¬P(k).

Negating this, we obtain ¬(∃k∈Z,¬P(k))≡∀k∈Z,¬¬P(k)≡∀k∈Z,P(k).

Finally, ∀k∈Z,P(k) reads as follows:

For all k∈Z, 2k is even.
