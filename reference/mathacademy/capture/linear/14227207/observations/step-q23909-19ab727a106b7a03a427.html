Consider the equation x2+1=k. For which values of k does this equation have no real solutions?

a
k>1
b
k<0
c
k>−1
d
k≤1
e
k<1
Submit
Correct
EXPLANATION

Let's try and solve using the square root method:

x2+1=kx2=k−1x2=k−1|x|=k−1

The equation will have no real solutions if the expression under the square root is negative, which gives the following condition: k−1<0

We solve this inequality for k: k−1<0k<1

Therefore, any value of k that is less than 1 will give an equation with no real solutions.
