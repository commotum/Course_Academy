EXPLANATION

If a relation R is defined over A={a1,a2,…,am} and B={b1,b2,…bn} of cardinalities m and n, respectively, the adjacency matrix of R is a m×n-matrix (table), where the element rij at the intersection of the ith row and the jth column is given by rij={1,if aiRbj,0,otherwise.

The relation R is the set of ordered pairs (x,y)∈B2 with x∣y.

Let's consider each row in our table.

  • If x=2, then the values y=2,4,6 satisfy x∣y. So, R contains the ordered pairs (2,2), (2,4), and (2,6), and we write 1 in the intersection of the 1st row and the 1st column, in the intersection of the 1st row and the 2nd column, and in the intersection of the 1st row and the 3rd column in the adjacency matrix.

  • If x=4, then the value y=4 satisfies x∣y. So, R contains the ordered pair (4,4), and we write 1 in the intersection of the 2nd row and the 2nd column in the adjacency matrix.

  • If x=6, then the value y=6 satisfies x∣y. So, R contains the ordered pair (6,6), and we write 1 in the intersection of the 3rd row and the 3rd column in the adjacency matrix.

All the other cells in the matrix must be filled with zeros. Therefore, we have the following adjacency matrix:
