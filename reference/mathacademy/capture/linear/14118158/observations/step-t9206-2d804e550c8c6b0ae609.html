The Domain and Range of a Relation
?

Given a relation we have the following definitions:

  • The domain of is the set containing all elements from that appear as the first component of the ordered pairs in

  • The range of is the set containing all elements from that appear as the second component of the ordered pairs in

  • The codomain of is any superset of the range.
