EXPLANATION

Given a relation R⊆A×B,

  • the domain of R is the set containing all elements from A that appear as the first component of the ordered pairs in R, and

  • the range of R is the set containing all elements from B that appear as the second component of the ordered pairs in R.

With that in mind, we examine the given relation.

  • Notice that ln⁡(x−1) is defined only for x>1. So, the set of first components contains all real numbers greater than 1: {x∈R:x>1} Hence, the domain is {x∈R:x>1}.

  • Notice that ln⁡(x−1) is continuous on R, and has neither lower nor upper bounds. So, the set of second components contains all real numbers R. Hence, the range is R.
