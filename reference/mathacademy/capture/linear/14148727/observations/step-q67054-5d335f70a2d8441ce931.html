Which of the following is equivalent to the expression −2p+3q−5r?

a
5r+3q−2p
b
5r+3q+2p
c
−3q−5r+2p
d
3q−5r−2p
e
3q−5r+2p
Submit
Correct
EXPLANATION

The expression −2p+3q−5r has three terms: −2p, 3q, and −5r.

The order in which we combine the terms doesn't matter. Therefore, we can also write this expression as 3q−5r−2p.
