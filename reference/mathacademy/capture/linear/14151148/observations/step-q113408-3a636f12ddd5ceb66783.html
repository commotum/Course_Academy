EXPLANATION

  • Statement I is true. According to the picture, we have that both BC― and CE― have the same double hash marks, so BC―≅CE―.

  • Statement II is false. From the picture, the two segments DC― and CE― have different hash marks, so DC―≇CE―. Hence, DC≠CE.

  • Statement III is true. According to the picture, we have that BD― and AB― have the same hash marks, so BD―≅AB―. Hence, BD=AB=3cm.

Therefore, only statements I and III are true.
