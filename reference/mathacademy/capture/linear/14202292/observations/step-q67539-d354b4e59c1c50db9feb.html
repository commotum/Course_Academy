The function y=f(x) is defined on x∈(−52,3). Find limx→3f(x).

a
limx→3f(x)=0
b
limx→3f(x)=3
c
limx→3f(x)=12
d
limx→3f(x)=DNE
e
limx→3f(x)=−52
Submit
Correct
EXPLANATION

From the graph, we see that it is not possible to approach x=3 from the right. Therefore,

limx→3+f(x)=DNE.

When we approach x=3 from the left, we have

limx→3−f(x)=0.

Since limx→3−f(x)≠limx→3+f(x), we conclude that limx→3f(x)=DNE.
