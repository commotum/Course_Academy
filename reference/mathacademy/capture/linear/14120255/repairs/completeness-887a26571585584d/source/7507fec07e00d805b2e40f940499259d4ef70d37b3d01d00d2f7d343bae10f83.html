The directed graph of a relation defined on the set {α,β,γ} is given above. Which of the following ordered pairs belong to the relation?

  1. (β,γ)
  2. (γ,α)
  3. (α,β)
a
III only
b
II only
c
I only
d
I and III only
e
II and III only

Correct
EXPLANATION

A binary relation can be visualized using a directed graph (digraph), where

  • the nodes (vertices) of the graph are elements of the underlying set,

  • each pair (x,y) from the relation defines an arrow from node x to node y,

  • each pair (x,x) from the relation defines a loop from node x to itself.

With that in mind, let's examine the given ordered pairs.

  • The pair (β,γ) does not belong to the relation since the directed graph does not have an arrow that starts at the node β and ends at the node γ.

  • The pair (γ,α) does not belong to the relation since the directed graph does not have an arrow that starts at the node γ and ends at the node α.

  • The pair (α,β) belongs to the relation. Indeed, the directed graph has a an arrow that starts at the node α and ends at the node β.

Therefore, the correct answer is "III only."
