The ordered pairs belonging to our relation correspond to the arrows on the mapping diagram. Each arrow starts at the first component of the pair and ends at its second component.

Our diagram has the following arrows:

  • Arrows starting from w:

    • w→w and w→z, so the relation contains the pairs (w,w) and (w,z).

  • No arrows start from x.

  • Arrows starting from y:

    • y→x, so the relation contains the pair (y,x).

  • Arrows starting from z:

    • z→x, so the relation contains the pair (z,x).

Therefore, R contains the following ordered pairs:

R={(w,w),(w,z),(y,x),(z,x)}
