The ordered pairs belonging to our relation correspond to the arrows on the mapping diagram. Each arrow starts at the first component of the pair and ends at its second component.

We're given the following set: A={1,2,3,4}.

The relation R is the set of ordered pairs (x,y)∈A×A such that x<y.

  • If x=1, then the values y=2,3,4 satisfy x<y. So, R contains the ordered pairs (1,2),(1,3), and (1,4), and we should add the arrows 1→2,1→3, and 1→4 to the mapping diagram.

  • If x=2, then the values y=3,4 satisfy x<y. So, R contains the ordered pairs (2,3) and (2,4), and we should add the arrows 2→3 and 2→4 to the mapping diagram.

  • If x=3, then the value y=4 satisfies x<y. So, R contains the ordered pair (3,4), and we should add the arrow 3→4 to the mapping diagram.

  • If x=4 there are no values y∈A such that x<y. Therefore we do not add arrows starting from 4 to the mapping diagram.
