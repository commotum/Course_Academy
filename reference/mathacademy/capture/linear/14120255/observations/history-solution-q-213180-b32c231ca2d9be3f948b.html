A binary relation can be visualized using a plot (or graph), where

  • the first set is plotted along the horizontal axis,

  • the second set is plotted along the vertical axis, and

  • each pair (x,y) from the relation defines a point with coordinates (x,y) on the plot.

The relation R is the set of ordered pairs (x,y)∈A2 with x+y=4.

  • If x=1, then the value y=3 satisfies x+y=4. So, R contains the ordered pair (1,3), and we should plot this point on the graph.

  • If x=2, then the value y=2 satisfies x+y=4. So, R contains the ordered pair (2,2), and we should plot this point on the graph.

  • If x=3, then the value y=1 satisfies x+y=4. So, R contains the ordered pair (3,1), and we should plot this point on the graph.
