A binary relation can be visualized using a plot (or graph), where

  • the first set is plotted along the horizontal axis,

  • the second set is plotted along the vertical axis, and

  • each pair (x,y) from the relation defines a point with coordinates (x,y) on the plot.

The relation R is the set of ordered pairs (x,y)∈A×B with x≡y(mod2).

  • If x=3, then the values y=1,7 satisfy x≡y(mod2). So, R contains the ordered pairs (3,1) and (3,7), and we should plot these points on the graph.

  • If x=6, then the value y=4 satisfies x≡y(mod2). So, R contains the ordered pair (6,4), and we should plot this point on the graph.

  • If x=8, then the value y=4 satisfies x≡y(mod2). So, R contains the ordered pair (8,4), and we should plot this point on the graph.
