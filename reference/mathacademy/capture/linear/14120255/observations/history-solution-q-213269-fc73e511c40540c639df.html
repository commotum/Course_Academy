The ordered pairs belonging to our relation correspond to the arrows on the mapping diagram. Each arrow starts at the first component of the pair and ends at its second component.

We're given the following sets: A={7,8,9,10},B={0,1,2,3,4}.

The relation R is the set of ordered pairs (x,y)∈A×B with x≡y(mod3).

  • If x=7, then the value y=1 satisfies x≡y(mod3). So, R contains the ordered pair (7,1), and we should add the arrow 7→1 to the mapping diagram.

  • If x=8, then the value y=2 satisfies x≡y(mod3). So, R contains the ordered pair (8,2), and we should add the arrow 8→2 to the mapping diagram.

  • If x=9, then the values y=0,3 satisfy x≡y(mod3). So, R contains the ordered pairs (9,0) and (9,3), and we should add the arrows 9→0 and 9→3 to the mapping diagram.

  • If x=10, then the value y=1 satisfies x≡y(mod3). So, R contains the ordered pair (10,1), and we should add the arrow 10→1 to the mapping diagram.
