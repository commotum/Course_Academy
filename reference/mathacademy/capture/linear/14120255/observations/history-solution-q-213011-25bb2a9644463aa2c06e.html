The ordered pairs belonging to our relation correspond to the arrows on the mapping diagram. Each arrow starts at the first component of the pair and ends at its second component.

We're given the following sets: A={0.5,2,5},B={−1,0,1}.

The relation R is the set of ordered pairs (x,y)∈A×B with xy∈Z.

  • If x=0.5, then the values y=−1,0 satisfy xy∈Z. So, R contains the ordered pairs (0.5,−1) and (0.5,0), and we should add the arrows 0.5→−1 and 0.5→0 to the mapping diagram.

  • If x=2, then the values y=0,1 satisfy xy∈Z. So, R contains the ordered pairs (2,0) and (2,1), and we should add the arrows 2→0 and 2→1 to the mapping diagram.

  • If x=5, then the value y=0 satisfies xy∈Z. So, R contains the ordered pair (5,0), and we should add the arrow 5→0 to the mapping diagram.
