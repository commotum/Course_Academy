The function f(x) above is defined for values between x=−1 and x=5.

  • Since there is a closed circle at x=5, this point is included in the domain.

  • On the other hand, because there is an open circle at x=−1, this point is not included in the domain.

So, the function f(x) above is defined for values between x=−1 and x=5, including x=5 but not including x=−1.

Therefore, the domain is

x∈(−1,5].

Note that the function is defined at the point x=3, even though the function jumps at that point. The function value at x=3 is 1.
