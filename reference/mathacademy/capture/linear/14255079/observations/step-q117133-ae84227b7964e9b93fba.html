Which of the following could be the equation of the graph shown above?

a
y=cos⁡(3x4)
b
y=cos⁡x−34
c
y=cos⁡(x−34)
d
y=cos⁡(x+34)
e
y=−cos⁡(3x4)
Submit
Correct
EXPLANATION

Let's add the graph of y=cos⁡x to the plot.

To plot the given curve, we follow these steps:

  • Start with the graph of y=cos⁡x.

  • Then, shift it by 34 unit right.

Therefore, the given graph is y=cos⁡(x−34).
