First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Remember that a rectangle is a quadrilateral where all angles are right and has two pairs of parallel sides.

With that in mind, let's look at each shape in turn.

  • The shape P is an isosceles trapezoid. It has only one pair of parallel sides, not two, therefore, it is not a rectangle.

  • The shape Q is a parallelogram. It has no right angles, therefore, it is not a rectangle.

  • The shape R is a rhombus. Since it has no right angles, it is not a rectangle.

  • The shape S is a rectangle since all its angles are right.

Therefore, shape S is a rectangle. The shapes P, Q, and R are not rectangles.
