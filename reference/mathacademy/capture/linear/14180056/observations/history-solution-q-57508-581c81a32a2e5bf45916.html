If n is the number of toppings, and the pizzeria charges $3 per topping, then the cost for n toppings must be 3n.

However, there is also a fixed fee for the cheese pizza. This fee is $15. Consequently, the constant term of the expression should be 15.

Therefore, the expression that represents the total cost (in dollars) of a pizza with n toppings is:

3n+15
