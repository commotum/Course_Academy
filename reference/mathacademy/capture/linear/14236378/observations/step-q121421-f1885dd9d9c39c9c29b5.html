The point (−2,−1) lies on the curve y=f(x+1). Which of the following points must lie on y=−f(x)+5?

a
(−2,−6)
b
(−1,6)
c
(−1,3)
d
(1,2)
e
(−1,−3)
Submit
Correct
EXPLANATION

Method 1

We first find a point corresponding to (−2,−1) on y=f(x). Then, we find a corresponding point on y=−f(x)+5:

  • To plot the graph of y=f(x), we apply the following steps:

    • First, take the graph y=f(x+1).

    • Then, we shift the graph horizontally 1 unit to the right and get the graph of y=f(x). After this transformation, the point (−2,−1) will be mapped to the point (−2+1,−1)=(−1,−1).

  • Next, to plot the graph of y=−f(x)+5, we apply the following steps:

    • First, take the graph y=f(x).

    • Then, we reflect the result across the x-axis and get the graph of y=−f(x). After this transformation, the point (−1,−1) will be mapped to the point (−1,−(−1))=(−1,1).

    • Next, we shift the result vertically by 5 units up and obtain the graph of y=−f(x)+5. After this transformation, the point (−1,1) will be mapped to the point (−1,1+5)=(−1,6).

Method 2

Since the point (−2,−1) lies on the graph of y=f(x+1), we have that

f(−2+1)=−1⟹f(−1)=−1.

Now consider the graph of y=−f(x)+5. Substituting x=−1, we get

y=−f(−1)+5=−(−1)+5=6.

Therefore, the point (−1,6) must lie on y=−f(x)+5.
