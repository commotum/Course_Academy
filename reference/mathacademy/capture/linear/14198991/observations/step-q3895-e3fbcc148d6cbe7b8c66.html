  • Substituting 2 for x in the polynomial and evaluating, we get the following result: 24−13(2)2+36=16−13(4)+36=16−52+36=0 The polynomial is 0 when 2 is substituted for x. Therefore, 2 is a root.

  • Substituting −4 for x in the polynomial and evaluating, we get the following result: (−4)4−13(−4)2+36=256−13(16)+36=256−208+36=84 The polynomial does not equal 0 when −4 is substituted for x. Therefore, −4 is not a root.

Therefore, the values that are not roots are x=4 and x=−4, so the correct answer is "I and III only".
