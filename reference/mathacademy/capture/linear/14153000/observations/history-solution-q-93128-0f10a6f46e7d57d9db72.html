We're given a part and a whole, and we must find a percentage. So, we can use the following formula: percentage=part÷whole

In this case,

  • the part is the number of minutes George runs, which is 54, and

  • the whole is the total number of minutes George exercises, which is 120.

Substituting our numbers into the above formula, we get

percentage=54÷120=54120.

We can simplify this fraction as follows:

54120=54÷6120÷6=920

920=9×520×5=45100

45100=45%
