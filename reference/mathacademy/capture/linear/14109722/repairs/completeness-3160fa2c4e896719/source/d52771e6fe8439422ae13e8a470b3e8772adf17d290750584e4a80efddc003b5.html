Which of the following statements are true?

  1. If 7 is an even number, then 6 is an odd number.
  2. If 6 is an even number, then 7 is an even number.
  3. If 6 is an even number, then 7 is an odd number.
a
I, II, and III
b
I and III only
c
II only
d
III only
e
I only
Submit
Correct
EXPLANATION

An implication A⇒B is true unless A is true and B is false. In other words, the implication is true unless the "promise" is broken.

  • Statement I is true. The antecedent "7 is an even number" is false, so the promise does not apply. Regardless of the consequent, the promise is not broken, and the statement is true.

  • Statement II is false. The antecedent "6 is an even number" is true, and the consequent "7 is an even number" is false. So the promise is broken, and the statement is false.

  • Statement III is true. The antecedent "6 is an even number" is true, and the consequent "7 is an odd number" is true. So the promise is kept, and the statement is true.

Therefore, the correct answer is "I and III only."
