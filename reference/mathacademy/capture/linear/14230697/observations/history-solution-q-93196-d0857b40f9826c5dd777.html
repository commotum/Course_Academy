The solid is a heptagonal pyramid since it is a pyramid whose base is a heptagon.

Also, notice that:

  • The solid is not a heptagonal prism since it has only one heptagonal face.

  • The solid is not a hexagonal pyramid since it has no hexagonal face.

  • The solid is not a rectangular prism since not all of its faces are rectangles. Due to the same reasons, the solid is not a cube.
