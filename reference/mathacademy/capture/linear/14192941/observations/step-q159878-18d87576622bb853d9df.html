(−2,2)
b
(2,∞)

Correct
EXPLANATION

If we follow the graph from left to right, we can see that:

  • For x∈(−∞,−2) the graph falls

  • For x∈(−2,0) the graph is flat

  • For x∈(0,2) the graph rises

  • For x∈(2,∞) the graph falls

The function is strictly increasing on the intervals where it always rises: (0,2) only.
