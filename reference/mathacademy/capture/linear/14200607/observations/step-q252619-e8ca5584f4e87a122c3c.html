If the equation log1/4⁡64=−3 is equivalent to b−3=a, then a=
64
.
Submit
Correct
EXPLANATION

The logarithm of a with base b is defined as follows:

logb⁡a=x is equivalent to a=bx

If we compare log1/4⁡64=−3 with logb⁡a=x, we get a=64, b=14, and x=−3.

Therefore, the equation log1/4⁡64=−3 is equivalent to (14)−3=64. Consequently, a=64.
