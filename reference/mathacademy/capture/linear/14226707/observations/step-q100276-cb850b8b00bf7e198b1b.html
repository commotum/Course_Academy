What is the value of y if e5−y=74?

a
y=3−114ln⁡(7)
b
y=5−14ln⁡(2)
c
y=5−14ln⁡(7)
d
y=5+17ln⁡(4)
e
y=5+12ln⁡(7)
Submit
Correct
EXPLANATION

First, we find the natural logarithm (ln) of both sides of the equation:

e5−y=74ln⁡(e5−y)=ln⁡(74)

Now, we use the fact that ln⁡(ea)=a to simplify the left-hand side. This gives:

5−y=ln⁡(74)

Next, we write 74 as 71/4. So, we get:

5−y=ln⁡(71/4)

Finally, we rewrite the right-hand side using power law of logarithms and solve for y, as follows:

5−y=ln⁡(71/4)5−y=14ln⁡(7)−y=14ln⁡(7)−5y=5−14ln⁡(7)

Therefore, the solution is y=5−14ln⁡(7).
