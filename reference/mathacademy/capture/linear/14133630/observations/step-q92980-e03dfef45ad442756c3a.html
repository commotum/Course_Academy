If the ratio of rhombuses to triangles is 20, what is the missing number?

a
4
b
7
c
5
d
3
e
1

Incorrect
EXPLANATION

We count the number of rhombuses. We see that there are 2 rhombuses.

We count the number of triangles. We see that there are 3 triangles.

Hence, the ratio of rhombuses to triangles is 23.

So the missing number is 3.
