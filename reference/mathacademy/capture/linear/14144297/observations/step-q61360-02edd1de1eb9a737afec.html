EXPLANATION

We proceed as follows:

  • First, we split each whole into fourths.
  • Next, we create groups of 34.
  • Then, we count the groups.

So, if we divide 3 wholes into groups of 34, we get 4 groups in total.

Therefore, we conclude that

3÷34=4.

So, the missing number is 4.
