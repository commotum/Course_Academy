Determine the equation of the line that passes through the points (2,7) and (3,11).

y=4x+1
b
y=3x−3

Correct
EXPLANATION

We will write the equation of the line in the slope-intercept form y=mx+b. So, we need to work out the slope m and the y-intercept b.

First, we calculate the slope m using the given points:

m=y2−y1x2−x1=11−73−2=41=4

Substituting the slope m=4 into the slope-intercept formula y=mx+b, we reach

y=4x+b.

We now need to find the y-intercept b. We can find this by substituting the coordinates of a point on the line. Any point will do, so let's substitute (2,7): y=4x+b7=4(2)+b7=8+b7−8=b−1=b So the equation of the line is y=4x−1.
