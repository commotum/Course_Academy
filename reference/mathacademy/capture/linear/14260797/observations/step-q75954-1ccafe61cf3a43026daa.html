EXPLANATION

We note that x=0 cannot be a solution since division by 0 is undefined.

The equation has the denominators x2 and x. So first, we find the least common multiple (or LCM) of the denominators. We find that

LCM(x2,x)=x2.

So, we multiply both sides of the equation by x2, and simplify:

x−4x2−1x2=2xx2⋅(x−4x2−1x2)=x2⋅(2x)x2⋅(x−4x2)−x2⋅(1x2)=x2⋅(2x)x2⋅(x−4x2)−x2⋅(1x2)=x⋅x⋅(2x)(x−4)−1=2x

We now have a linear equation in x, and we can solve this using the addition and multiplication principles:

(x−4)−1=2xx−5=2xx=−5

Finally, we recall that we cannot allow x=0 as a solution. But since x=−5≠0, we conclude that the solution is x=−5.
