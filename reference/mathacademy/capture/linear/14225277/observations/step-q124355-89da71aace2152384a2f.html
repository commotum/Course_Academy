An angle θ in the coordinate plane (measured in the usual way) has a reference angle θR=π7. Which of the following cannot be θ?

a
8π7
b
13π7
c
6π7
d
π7
e
5π7
Submit
Correct
EXPLANATION

Let's remind ourselves of the relationship between θR and θ.

Using θR=π7, let's calculate all possible values of θ.

  • If θ lies in the first quadrant, then θ=θR=π7.

  • If θ lies in the second quadrant, then θ=π−θR=π−π7=6π7.

  • If θ lies in the third quadrant, then θ=π+θR=π+π7=8π7.

  • If θ lies in the fourth quadrant, then θ=2π−θR=2π−π7=13π7.

Therefore, θ cannot be equal to 5π7.
