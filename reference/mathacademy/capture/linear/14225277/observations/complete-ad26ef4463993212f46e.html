An angle θ in the coordinate plane (measured in the usual way) has a reference angle θR=20∘. Which of the following cannot be θ?

a
260∘
b
340∘
c
20∘
d
160∘
e
200∘
Submit
Correct
EXPLANATION

Let's remind ourselves of the relationship between θR and θ.

Using θR=20∘, let's calculate all possible values of θ.

  • If θ lies in the first quadrant, then θ=θR=20∘.

  • If θ lies in the second quadrant, then θ=180∘−θR=180∘−20∘=160∘.

  • If θ lies in the third quadrant, then θ=180∘+θR=180∘+20∘=200∘.

  • If θ lies in the fourth quadrant, then θ=360∘−θR=360∘−20∘=340∘.

Therefore, θ cannot be equal to 260∘.
