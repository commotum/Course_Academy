Which of the following statements are true for the polygons P, Q and R shown above?

  1. P≅Q
  2. Q≅R
  3. P≅R
a
III only
b
I only
c
I and III only
d
II and III only
e
I and II only
Submit
Correct
EXPLANATION

In general, congruent polygons have the same shape. In other words:

  • they have the same number of sides,

  • all corresponding sides are congruent, and

  • all corresponding interior angles are congruent.

With that in mind, let's compare the given polygons.

  • Statement I is false. Notice that the polygons P and Q have the same number of sides, but they don't seem to have the same shape. In particular, we notice they don't have corresponding congruent angles (P does not have right angles, while Q does).

  • Statement II is false. By the same reasoning as above, we can see that the polygons Q and R are not congruent.

  • Statement III is true. Since the polygons P and R have the same number of sides and all corresponding sides and angles are congruent, we conclude that P≅R.

Therefore, the correct answer is "III only."
