What is the missing digit in the following equality?

135×234=05

 22

 18

Correct
EXPLANATION

First, we write 135 as an improper fraction:

135=(1×5)+35=85

We also write 234 as an improper fraction:

234=(2×4)+34=114

Now, we can multiply the two numbers.

85×114

We can simplify this product by swapping the denominators:

85×114=84×115=2×115=225

Therefore, the missing number is 22.
