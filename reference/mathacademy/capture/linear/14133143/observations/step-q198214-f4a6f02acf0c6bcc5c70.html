EXPLANATION

First, we write 335 as an improper fraction: 335=(3×5)+35=185

We also write 213 as an improper fraction: 213=(2×3)+13=73

Now, we can multiply the two numbers. 185×73

We can simplify this product by swapping the denominators: 185×73=183×75=6×75=425

Finally, we write the resulting improper fraction as a mixed number: 425=8R2=825
