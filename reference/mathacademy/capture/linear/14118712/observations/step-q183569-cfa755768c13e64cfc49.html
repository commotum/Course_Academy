There is a real number such that, added to any natural number, gives a positive number.

Express the above in formal language.

a
∃x∈R,∀n∈N,xn>0
b
∀x∈R,∃n∈N,x+n>0
c
∀n∈N,∃x∈R,x+n>0
d
∃x∈R,∀n∈N,x+n>0
e
∃n∈N,∀x∈R,x+n>0
Submit
Correct
EXPLANATION

Notice that our sentence can be re-phrased as

There exists a real number x such that, added to any natural number, gives a positive number.

Now, "x added to any natural number gives a positive number" means that

For any natural number n, we have that x+n>0.

Therefore, we get the following statement:

There exists a real number x such that for any natural number n we have that x+n>0.

More formally, this reads as

∃x∈R,∀n∈N,x+n>0.
