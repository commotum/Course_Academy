EXPLANATION

To compute P(B′|A′), we need to ask, "what is the probability of B not occurring given that A has not occurred?"

Since we are assuming that A has not occurred, we only consider the elements outside A.

In total, the number of elements in the event A′ is

15+5=20.

Of these 20 elements, 5 lie outside B.

Since each outcome is equally likely, P(B′|A′) can be interpreted as the proportion of B′ that lies inside A′, relative to the size of A′. Therefore, we have

P(B′|A′)=520=14.
