We wish to compute the probability that a customer likes tulips given that they like roses. Therefore, we need to compute P(T|R).

To compute P(T|R), we need to ask, "what is the probability of T occurring given that R has occurred?"

Since we are assuming that R has occurred, we only consider the customers inside R.

In total, the number of customers in the set R is

80+118=198.

Of these 198 customers, 80 lie inside T.

Since each outcome is equally likely, P(T|R) can be interpreted as the proportion of T that lies inside R, relative to the size of R. Therefore, we have

P(T|R)=80198=4099.
