EXPLANATION

To remove the logarithm, we exponentiate both sides of the equation. The base of the logarithm is 3, so we use this base for the exponentiation as well:

log3⁡(x−5)=23log3⁡(x−5)=32

Now, since exponentiation is the inverse function of the logarithm, we get 3log3⁡(x−5)=x−5.

Therefore, x−5=32x−5=9x=14.
