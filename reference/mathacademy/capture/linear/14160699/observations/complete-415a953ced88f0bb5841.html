Question 1 ?
Aaron, Beatrice, and Chetna have each baked 2 cherry pies and 3 apple pies for the sale. In total, they baked
15
pies.

Correct
Explanation

We need to write and evaluate an expression representing the total number of pies.

Since each of them baked 2 cherry pies and 3 apple pies, the number of pies each person made is:

2⏟cherry pies+3⏟apple pies

Since each person made this number of pies, and there are 3 people, we must multiply the number of pies by 3. Therefore, the total number of pies is:

(2+3)⏟each person×3⏟people

To evaluate the expression, we follow the order of operations with parentheses.

First, we perform the operations inside the parentheses:

(2+3)×3=(2+3)×3=5×3.

Now, we multiply:

5×3=15
