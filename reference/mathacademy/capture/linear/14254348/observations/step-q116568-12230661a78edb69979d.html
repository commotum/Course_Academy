EXPLANATION

Let's recall some of the basic properties of y=tan⁡x:

  • The domain of the function is almost x∈(−∞,∞) except for the points where the function is undefined, namely x=±π2,±3π2,…

  • The range of the function is y∈(−∞,∞).

  • The period of the function is π.

  • There is no minimum or maximum value.

  • The zeros occur at x=0,±π,±2π,…

  • The graph has vertical asymptotes at the points not in the domain: x=±π2,±3π2,…. At each asymptote, the graph tends to ∞ from the left and −∞ from the right.
