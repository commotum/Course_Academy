EXPLANATION

Let's recall some of the basic properties of y=cot⁡x:

  • The domain is all real numbers except x=nπ for any integer n.

  • The range is all real numbers, so there is no minimum or maximum.

  • The period of the function is π.

  • Its zeros occur at x=π2+nπ for any integer n.

  • y→−∞ as x→π−, and y→∞ as x→0+.
