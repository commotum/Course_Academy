An athletics track is 1km long. What is this length in meters?

a
0.1m
b
0.001m
c
10m
d
100m
e
1000m
Submit
Incorrect
EXPLANATION

A table showing the units of length in metric units is given below.

Name Symbol Conversion
Kilometer km 1km=1000m
Meter m Base Unit
Centimeter cm 100cm=1m
Millimeter mm 1000mm=1m

So, 1km is equivalent to 1000m.
