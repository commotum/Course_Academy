A TV set is 1m wide. What is this width in centimeters?

a
10cm
b
0.1cm
c
0.01cm
d
100cm
e
1000cm
Submit
Correct
EXPLANATION

A table showing the metric units of length is given below.

Name Symbol Conversion
Kilometer km 1km=1000m
Meter m Base Unit
Centimeter cm 100cm=1m
Millimeter mm 1000mm=1m

So, 1m is equivalent to 100cm.
