The equation of this curve is y=
|x−7|

EXPLANATION

Remember that y=|x−a| is a horizontal translation of the absolute value graph y=|x| by a units right.

Notice that here, the graph is moved right by 7 units. This corresponds to a=7.

Therefore, the equation of the curve is y=|x−7|.
