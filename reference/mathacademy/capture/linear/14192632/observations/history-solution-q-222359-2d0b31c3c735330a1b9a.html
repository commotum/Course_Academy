Remember that y=|x−h|+k is a vertical translation of the absolute value graph y=|x| by h units right and k units up.

The function y=|x+1|+3 has h=−1 and k=3. Therefore, it is a translation of the absolute value graph y=|x| by 1 unit left and 3 units up.

Looking at the graph, we can see that the minimum value of y is 3.
