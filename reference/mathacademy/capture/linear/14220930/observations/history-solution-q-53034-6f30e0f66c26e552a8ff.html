First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Remember that a square is a quadrilateral where all angles are right and all sides are congruent.

With that in mind, let's look at each shape in turn.

  • The shape P is a rhombus. Its four sides are congruent, however, it has no right angle. Therefore, it is not a square.

  • The shape Q is a trapezoid. The sides are not all congruent, so it is not a square.

  • The shape R is a kite. Since the sides are not all congruent, it is not a square.

  • The shape S is an isosceles trapezoid. It has sides that are not congruent, therefore, it is not a square.

Therefore, none of the shapes is a square.
