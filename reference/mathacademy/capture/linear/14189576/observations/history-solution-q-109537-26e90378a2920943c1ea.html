We know that the line passes through the point (−3,−1), so we can use (x1,y1)=(−3,−1) in our point-slope formula. All that remains is to compute m, and we can do this using the given points:

m=y2−y1x2−x1=2−(−1)4−(−3)=2+14+3=37

Then, we substitute m=37 and the point (x1,y1)=(−3,−1) into the point-slope formula:

y−y1=m(x−x1)y−(−1)=37(x−(−3))y+1=37(x+3)
