Let's recall some of the basic properties of y=log2⁡x:

  • The domain is x>0, and the range is −∞<y<∞.

  • The graph has the vertical asymptote x=0.

  • The function is an increasing function.

  • The graph passes through the point (1,0).

  • For x>1, the graph is positive and grows very slowly as we increase x. We say that y→∞ (slowly) as x→∞.
