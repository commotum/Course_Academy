Which of the following is a horizontal asymptote of y=log6⁡x?

a
y=−6
b
There are no horizontal asymptotes.
c
y=6
d
y=0
e
y=1
Submit
Correct
EXPLANATION

Let's recall the graph of y=log6⁡x.

From the graph, we note that for x>1, the graph grows very slowly as we increase x.

We say that y→∞ (slowly) as x→∞.

Therefore, there are no horizontal asymptotes.
