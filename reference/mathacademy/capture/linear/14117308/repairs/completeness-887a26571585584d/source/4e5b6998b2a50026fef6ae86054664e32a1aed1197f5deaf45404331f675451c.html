Given the relation R on N defined by xRy⇔x>y, which of the following statements are true?

  1. 6R8
  2. 7R2
  3. 9R1
a
I, II, and III
b
I and II only
c
III only
d
II only
e
I only
Submit
Correct
EXPLANATION

A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A×A

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x>y. For this relation, note that

  • the symbols R and > are interchangeable, and

  • the symbols R and ≯ (or, equivalently, R and ≤) are also interchangeable.

With that in mind, let's examine our statements in turn:

  • Statement I is false. Replacing R with the symbol >, we have 6>8, which is false.

  • Statement II is true. Replacing R with the symbol >, we have 7>2, which is true.

  • Statement III is false. Replacing R with the symbol ≤, we have 9≤1, which is false.

Therefore, the correct answer is "II only."
