A relation R on a set A is a subset of the Cartesian product A×A=A2.

R⊆A×A

For a relation R on a set A, we also have the following notations:

  • aRb if and only if (a,b)∈R

  • aRb if and only if (a,b)∉R

In this case, R is the set of ordered pairs (x,y)∈Z×Z=Z2 such that 3|(x+y).

Therefore, we can write out R in set-builder notation as follows:

R={(x,y)∈Z2:3|(x+y)}
