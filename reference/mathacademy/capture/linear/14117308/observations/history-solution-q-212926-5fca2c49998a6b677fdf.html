A relation R on a set A is a subset of the Cartesian product A×A=A2. R⊆A×A

We also have the following notations:

  • xRy if and only if (x,y)∈R

  • xRy if and only if (x,y)∉R

In this case, we have xRy if and only if x∣y. For this relation, note that

  • the symbols R and ∣ are interchangeable, and

  • the symbols R and ∤ are also interchangeable.

With that in mind, let's examine our statements in turn:

  • Statement I is false. Replacing R with the symbol ∣, we have 6∣3, which is false.

  • Statement II is false. Replacing R with the symbol ∣, we have 5∣8, which is false.

  • Statement III is true. Replacing R with the symbol ∤, we have 7∤9, which is true.

Therefore, the correct answer is "III only."
