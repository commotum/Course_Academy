We are given the units kmmin, and we want to convert this into kmhour. To figure out what we need to multiply by, we can set up an equation to help us: kmmin⋅??=kmhour

We want to replace min with hour. To get rid of min, we can put min in the numerator so that it cancels out. To introduce hour, we can put hour in the denominator. kmmin⋅minhour=kmhour

So, our conversion formula is kmmin⋅minhour=kmhour.

Now that we have our conversion formula, we need to determine the correct numbers to use, and apply it.

  • The rate given in the problem statement is 2.5kmmin.
  • There are 60 minutes in one hour.

Applying our conversion formula, we have 2.5kmmin=2.5kmmin⋅60minhour=2.5⋅60(kmmin⋅minhour)=150kmhour.
