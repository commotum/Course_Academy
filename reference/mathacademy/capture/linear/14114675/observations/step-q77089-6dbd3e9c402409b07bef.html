EXPLANATION

Dividing −36 by 5 using integer division, we notice that

−8<−36÷5<−7.

The quotient q is the left-hand value. So q=−8.

Next, we find the remainder r by solving r=a−qn. This gives

r=−36−(−8)(5)=4.

Therefore, we can write −36=qn+r as follows:

−36=(−8)⏟q⋅5+4⏟r

Therefore, r=4.
