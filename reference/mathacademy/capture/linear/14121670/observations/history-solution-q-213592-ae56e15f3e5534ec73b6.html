First, recall the following definitions:

  • A binary relation R, defined on a set A, is symmetric if for all x,y∈A, we have (x,y)∈R⟹(y,x)∈R. In other words, if a pair (x,y) belongs to a symmetric relation, then the pair (y,x) should also be in the relation.

  • A binary relation R, defined on a set A, is antisymmetric if for all x,y∈A, we have (x,y)∈Rand(y,x)∈R⟹x=y. In other words, only one of the pairs, either (x,y) or (y,x), can be in an antisymmetric relation. Note that this condition allows pairs of the form (x,x).

The relation R is symmetric. Indeed, for any integers x and y, if x≡y(mod2), then y≡x(mod2).

Since for all x,y∈R, we have x≡y(mod2)⟹y≡x(mod2), the relation is symmetric.
