Which of the plots above represents a relation that is neither symmetric nor antisymmetric defined on the set A={a,b,c}?

a
I and III only
b
II only
c
I and II only
d
III only
e
I, II, and III

Correct
EXPLANATION

First, recall the following definitions:

  • A binary relation R, defined on a set A, is symmetric if for all x,y∈A, we have (x,y)∈R⟹(y,x)∈R. In terms of a plot, if a point (x,y) belongs to the plot, then (y,x), the point symmetric to (x,y) over the diagonal line y=x, should also be on the plot.

  • A binary relation R, defined on a set A, is antisymmetric if for all x,y∈A, we have (x,y)∈Rand(y,x)∈R⟹x=y. So, only one of the points, either (x,y) or (y,x), can be on the plot of an antisymmetric relation. Note that this condition allows points on the diagonal line y=x.

With that in mind, let's draw the diagonal line y=x and examine our plots.

  • Plot I represents an antisymmetric relation since the plot contains at most one point from each pair of the points symmetric over the line y=x.

  • Plot II represents neither a symmetric nor an antisymmetric relation. It's not symmetric since, for example, the pair (a,b) belongs to the plot while the point (b,a) does not. And it's not antisymmetric since it contains the pairs (a,c) and (c,a).

  • Plot III represents a symmetric relation since the plot is symmetric over the line y=x.

Therefore, the correct answer is "II only."
