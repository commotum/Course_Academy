Which of the plots above represent symmetric relations defined on the set A={0,2,4}?

a
I and II only
b
I and III only
c
II only
d
I only
e
III only
Submit
Incorrect
EXPLANATION

First, recall the following definitions:

  • A binary relation R, defined on a set A, is symmetric if for all x,y∈A, we have (x,y)∈R⟹(y,x)∈R. In terms of a plot, if a point (x,y) belongs to the plot, then (y,x), the point symmetric to (x,y) over the diagonal line y=x, should also be on the plot.

  • A binary relation R, defined on a set A, is antisymmetric if for all x,y∈A, we have (x,y)∈Rand(y,x)∈R⟹x=y. So, only one of the points, either (x,y) or (y,x), can be on the plot of an antisymmetric relation. Note that this condition allows points on the diagonal line y=x.

With that in mind, let's draw the diagonal line y=x and examine our plots.

  • Plot I represents a symmetric relation since the plot is symmetric over the line y=x.

  • Plot II represents an antisymmetric relation since the plot contains at most one point from each pair of the points symmetric over the line y=x.

  • Plot III represents neither a symmetric nor an antisymmetric relation. It's not symmetric since, for example, the pair (4,2) belongs to the plot while the point (2,4) does not. And it's not antisymmetric since it contains the pairs (0,4) and (4,0).

Therefore, the correct answer is "I only."
