Which of the above digraphs represents a symmetric relation defined on the set A={a,b,c}?

a
I only
b
II and III only
c
I and III only
d
III only
e
II only
Submit
Correct
EXPLANATION

First, recall the following definitions:

  • A binary relation R, defined on a set A, is symmetric if for all x,y∈A, we have (x,y)∈R⟹(y,x)∈R. In terms of a digraph, if we have an arrow x→y, then the arrow y→x must be in the digraph too.

  • A binary relation R, defined on a set A, is antisymmetric if for all x,y∈A, we have (x,y)∈Rand(y,x)∈R⟹x=y. So, only one of the arrows, either x→y or y→x, can be in the digraph of an antisymmetric relation. Note that this condition allows loops.

With that in mind, let's examine our digraphs.

  • Digraph I represents a symmetric relation since for every arrow x→y belonging to the graph, the corresponding inverse arrow y→x also belongs to the graph.

  • Digraph II represents an antisymmetric relation since for all possible x and y with x≠y, at most one of the arrows (either x→y or y→x, but not both) belongs to the digraph.

  • Digraph III represents a symmetric relation since for every arrow x→y belonging to the graph, the corresponding inverse arrow y→x also belongs to the graph.

Therefore, the correct answer is "I and III only."
