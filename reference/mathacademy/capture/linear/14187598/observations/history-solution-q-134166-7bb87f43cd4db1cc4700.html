Speed is a special unit rate applied to moving objects. It is defined as the distance traveled per unit of time:

speed=distancetime

To find the speed (in miles per hour), we divide the number of miles, 12, by the number of hours, 20. This gives,

1220=12÷220÷2=610=6÷10=0.6.

Therefore, the speed of starfish is 0.6 miles per hour.
