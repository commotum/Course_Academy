An arrow takes 3 seconds to travel 360 meters at a constant pace. How long does it take for the arrow to travel 660 meters?

a
6 seconds
b
5.5 seconds
c
4.5 seconds
d
6.5 seconds
e
5 seconds
Submit
Correct
EXPLANATION

Speed is a special unit rate applied to moving objects. It is defined as the distance traveled per unit of time:

speed=distancetime

To find the speed, in meters per second, we divide the number of meters, which is 360, by the number of seconds, 3. This gives,

3603=360÷3=120.

So, the speed of the arrow is 120 meters per second.

To find the time it takes the arrow to cover 660 meters, we divide the distance by 120. This gives

time=distancespeed=660120=660÷60120÷60=112=11÷2=5.5.

Therefore, it takes the arrow 5.5 seconds to travel 660 meters.
