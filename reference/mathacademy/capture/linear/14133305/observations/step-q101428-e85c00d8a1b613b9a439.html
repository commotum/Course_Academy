number of hexagons:number of pentagons

To find this ratio, we start by counting the number of occurrences of each shape:

  • First, we count the number of hexagons. There are 4 hexagons.

  • Next, we count the number of pentagons. There is 1 pentagon.

Therefore, the ratio of hexagons to pentagons is 4:1.

So, the missing numbers are 1 and 4.
