A study group contains 5 freshmen, 4 sophomores, and 3 juniors. What ratio describes the number of freshmen to the total number of students?
The required ratio is
5
:
12
Submit
Correct
EXPLANATION

We can express the ratio of the number of freshmen to the total number of students as follows:

number of freshmen:total number of students

We compute our ratio as follows:

  • First, we count the number of freshmen. There are 5 freshmen.

  • Next, we count the total number of students. There are 5+4+3=12 students.

Therefore, the ratio of freshmen to the total number of students is 5:12.
