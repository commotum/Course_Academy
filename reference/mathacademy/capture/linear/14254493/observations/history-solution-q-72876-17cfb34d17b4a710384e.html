Method 2

We know that y=sin⁡x has a minimum value of −1.

−1≤sin⁡x

Adding 3 from both sides of the above inequality gives:

−1+3≤sin⁡x+32≤sin⁡x+3

Therefore, the minimum value of sin⁡x+3 is 2.
