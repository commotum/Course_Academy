EXPLANATION

Method 1

To plot the given curve, we follow these steps:

  • Start with the graph of y=sin⁡x.

  • Then, shift it by 2 units down.

The resulting graph is shown below.

From the graph, we see that the minimum value is y=−3.

Method 2

We know that y=sin⁡x has a minimum value of −1.

−1≤sin⁡x

Subtracting 2 from both sides of the above inequality gives:

−1−2≤sin⁡x−2−3≤sin⁡x−2

Therefore, the minimum value of sin⁡x−2 is −3.
