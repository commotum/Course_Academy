Which of the following statements are true regarding the polynomial f(x)=x2+x−6?

  1. x=3 is a root of f(x)
  2. (x−3) is a factor of f(x)
  3. (x−3) divides f(x) with zero remainder
a
II and III only
b
I, II, and III
c
None of the statements are true
d
I and II only
e
I and III only

Correct
EXPLANATION

The factor theorem states that (x−r) is a factor of a polynomial p(x) if and only if the root x=r is also a root of p(x).

Here, we are considering (x−3). The root of this expression can be found by setting the expression equal to 0 and solving: x−3=0x=3

We now check each of the statements, in turn.

  • Statement I is false. Indeed, x=3 is not a root of f(x): f(3)=32+(3)−6=9+3−6=6≠0

  • Statement II is false. According to the factor theorem, since x=3 is not a root of f(x), then (x−3) is not a factor of f(x).

  • Statement III is false. Since (x−3) is not a factor of f(x), then it does not divide f(x) with zero remainder.

Therefore, the correct answer is "None of the statements are true."
