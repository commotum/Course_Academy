Which of the following statements are true regarding the polynomial f(x)=x3−3x+2?

  1. x=−12 is a root of f(x)
  2. (2x+1) is a factor of f(x)
  3. (2x+1) divides f(x) with zero remainder

Correct
EXPLANATION

The factor theorem states that (ax−b) is a factor of the polynomial p(x) if and only if the root x=ba is also root of p(x).

Here, we are considering (2x+1). The root of this expression can be found by setting the expression equal to 0 and solving: 2x+1=02x=−1x=−12

Let's now check each of the statements, in turn.

  • Statement I is false. Indeed, x=−12 is not a root of f(x):

f(−12)=(−12)3−3(−12)+2=−18+32+2=278≠0

  • Statement II is false. According to the factor theorem, since x=−12 is not a root of f(x), then (2x+1) is not a factor of f(x).

  • Statement III is false. Since (2x+1) is not a factor of f(x), then it does not divide f(x) with zero remainder.

Therefore, the correct answer is "None of the statements are true."
