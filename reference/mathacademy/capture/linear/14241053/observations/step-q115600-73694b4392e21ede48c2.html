Let b be directly proportional to g. Given that b=98 when g=−7, find the value of b when g=317.

EXPLANATION

Since b varies directly with g, we use the equation

b=kg.

We are told that b=98 when g=−7. We substitute this data into the equation to find k: 98=k⋅(−7)98(−7)=k−14=k

So, the direct variation equation is given by b=−14g.

Finally, substituting the value of g=317 into this equation gives b=−14⋅317=−2⋅31=−62.
