A function is invertible if and only if it's a one-to-one function. To determine which of the functions are one-to-one, we use the horizontal line test.

From the above, we see that:

  • For graphs I, III, and IV, any horizontal line will intersect the curve at most once, no matter where we draw the line. Therefore, graphs I, III, and IV show one-to-one functions. As a result, those functions are invertible.

  • For graph II, some horizontal lines intersect the curve more than once. So, this is not a one-to-one function. As a result, it is not invertible.
