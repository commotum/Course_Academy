A function is invertible on a particular interval if and only if it's a one-to-one function on that interval. To determine the intervals on which the function is invertible, we use the horizontal line test.

  • The given function is invertible on each of the intervals x∈(−4,−2) and x∈[−2,3]. Indeed, any horizontal line will intersect the curve at most once, no matter where we draw the line.
  • The given function is not invertible on the interval x∈[−3,3] because some lines will intersect the curve at more than one point.
