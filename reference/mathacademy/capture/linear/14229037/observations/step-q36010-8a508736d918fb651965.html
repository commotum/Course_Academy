EXPLANATION

The graph of the function f(x)=|x−2|+1 can be obtained in the following way:

  1. Take the curve y=|x|.

  2. Translate it by 2 units to the right, to get y=|x−2|.

  3. Finally, translate y=|x−2| by 1 unit up to get f(x)=|x−2|+1.

A function is invertible on a particular interval if and only if it's a one-to-one function on that interval. To determine the intervals on which the function is invertible, we use the horizontal line test.

  • The function f(x) is invertible on each of the intervals x∈(−∞,1] and x∈(2,4]. On these intervals, a horizontal line will intersect the curve at most once, no matter where we draw the line.
  • The function f(x) is not invertible on the interval x∈(1,∞). On this interval, some horizontal lines will intersect the curve more than once.

Therefore, the correct answer is "I and III only".
