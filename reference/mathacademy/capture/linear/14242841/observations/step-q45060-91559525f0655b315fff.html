What is the explicit formula for the nth term of the sequence f(n+1)=f(n)−7,f(1)=−1,n≥1?

a
f(n)=−7n+6,n≥1
b
f(n)=−7n−7,n≥1
c
f(n)=−7n+8,n≥1
d
f(n)=−7n−6,n≥1
e
f(n)=−7n−8,n≥1
Submit
Correct
EXPLANATION

The explicit formula for the nth term of an arithmetic sequence (in function notation) is

f(n)=f(1)+(n−1)d,n≥1,

so we need to determine the first term f(1) and the common difference d.

We are given that the first term is f(1)=−1, and we can use the recursive rule to compute the second term, as follows:

f(2)=f(1)−7=−1−7=−8

Using the first and second terms, we can compute the common difference:

d=f(2)−f(1)=−8−(−1)=−7

Now, we substitute f(1)=−1 and d=−7 into the formula for the nth term: f(n)=f(1)+(n−1)d=−1+(n−1)(−7)=−1−7n+7=−7n+6

Therefore, the formula for the nth term is

f(n)=−7n+6,n≥1.
