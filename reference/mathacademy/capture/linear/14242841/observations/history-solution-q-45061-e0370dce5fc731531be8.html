The explicit formula for the nth term of an arithmetic sequence (in function notation) is

f(n)=f(1)+(n−1)d,n≥1,

so we need to determine the first term f(1) and the common difference d.

We are given that the first term is f(1)=4, and we can use the recursive rule to compute the second term, as follows:

f(2)=f(1)+5=4+5=9

Using the first and second terms, we can compute the common difference:

d=f(2)−f(1)=9−4=5

Now, we substitute f(1)=4 and d=5 into the formula for the nth term: f(n)=f(1)+(n−1)d=4+(n−1)(5)=4+5n−5=5n−1

Therefore, the formula for the nth term is

f(n)=5n−1,n≥1.
