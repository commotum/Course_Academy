Which of the following statements are true regarding the function f:(0,∞)→R which is given by f(x)=ln⁡(x)?

  1. The range of f is (0,∞)
  2. ∀y∈R ∃x∈(0,∞) such that f(x)=y
  3. f maps (0,∞) into R
a
II only
b
II and III only
c
I and III only
d
III only
e
I only
Submit
Correct
EXPLANATION

First, we graph the function.

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. From the graph, there is no highest or lowest y value. The graph will cover any real value y. So the range of the function is all R..

  • Statement II is true. Since the range of the function is (−∞,∞), then for all y contained within (−∞,∞), there exists some x contained within R such that f(x)=y.

  • Statement III is false. Since the range of the function is (−∞,∞) the function is a surjection. Therefore, f is not an into function.

Therefore, the correct answer is "II only."
