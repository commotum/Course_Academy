Which of the following statements are true regarding the function f:R→(−∞,1) which is given by f(x)=1−2x?

  1. The range of f is (−∞,1)
  2. ∀y∈(−∞,1], ∃x∈R such that f(x)=y
  3. f is a function of R into (−∞,1)
a
I and II only
b
III only
c
II and III only
d
II only
e
I only
Submit
Incorrect
EXPLANATION

First, we graph the function.

Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is true. From the graph, the function takes all y-values lower than y=1, excluding y=1 itself. So the range of the function is indeed (−∞,1).

  • Statement II is false. Since the range of the function is (−∞,1), there can't be an x∈R whose image is 1∉(−∞,1).

  • Statement III is false. Since statement I is true, the function is a surjection. So, f is not a function of R into (−∞,1).

Therefore, the correct answer is "I only."
