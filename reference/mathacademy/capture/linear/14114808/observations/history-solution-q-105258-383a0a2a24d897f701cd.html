Recall that f:X→Y is an into function if it is not a surjection. In other words, there exists an element y in Y such that it has no preimage in X:

f:X→Y is an into function if ∃y∈Y such that ∀x∈X, we have f(x)≠y.

With that in mind, let's consider each statement in turn.

  • Statement I is false. The graph will cover all y-values greater than y=0, excluding y=0 itself. So the range of the function is (0,∞).

  • Statement II is false. Take, for example, y=−1. Since the range of the function is (0,∞), there can't be an x∈R whose image is −1.

  • Statement III is true. Since statement II is false, the function is not a surjection. So, f maps R into R.

Therefore, the correct answer is "III only."
