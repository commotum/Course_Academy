Which of the following equations has no solution?

  1. |5−x|=7
  2. 1−|5−x|=5
  3. |5−x|=−1
a
I only
b
III only
c
II only
d
II and III only
e
I and III only
Submit
Correct
EXPLANATION

An absolute value equation has no solution if, when the absolute value is isolated on the left side, the right-hand side is negative.

With that in mind, let's look at each equation in turn:

  • Equation I has a solution. The absolute value is already isolated on the left-hand side, and the right-hand side is non-negative.

  • Equation II has no solution. To see this, we first isolate the absolute value on the left-hand side as follows: 1−|5−x|=5−|5−x|=4|5−x|=−4 Since the right-hand side is negative, this equation has no solution.

  • Equation III has no solution. The absolute value is already isolated on the left-hand side, and the right-hand side is negative.

Therefore, the answer is "II and III only."
