The inequality x>12 corresponds to all numbers greater than 12. A number line for this inequality is shown below:

From the segment on the number line, we have the following:

  • The left endpoint 12 is not included in the interval.

  • There is no right endpoint - it continues forever. So, we write the interval with infinity as the right endpoint, not included.

Therefore, using interval notation, we represent x>12 as

x∈(12,∞).
