The inequality x<5 corresponds to all numbers less than 5. A number line for this interval is shown below:

From the segment on the number line, we have the following:

  • There is no left endpoint - it continues forever. So, we write the interval with negative infinity as the left endpoint, not included.

  • The right endpoint 5 is not included in the interval.

Therefore, using interval notation, we represent x<5 as x∈(−∞,5).
