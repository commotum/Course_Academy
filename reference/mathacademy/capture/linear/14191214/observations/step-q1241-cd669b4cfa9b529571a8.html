EXPLANATION

The inequality x<−7 corresponds to all numbers less than −7. A number line for this interval is shown below:

From the segment on the number line, we have the following:

  • There is no left endpoint - it continues forever. So, we write the interval with negative infinity as the left endpoint, not included.

  • The right endpoint −7 is not included in the interval.

Therefore, using interval notation, we represent x<−7 as

x∈(−∞,−7).
