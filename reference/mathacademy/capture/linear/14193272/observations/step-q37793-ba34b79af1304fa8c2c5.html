EXPLANATION

Let's examine each statement.

  • Statement I is false. As x increases on the right-hand side or decreases on the left-hand side of the graph, the function continues to increase without bound (as indicated by the two arrows). So, the function does not reach a global maximum value.

  • Statement II is false. The global minimum points are (−2,−1) and (2,−1). So the minimum value reached by the function is f(x)=−1. Therefore, the global minimum is −1.

  • Statement III is false. The function f(x) has global minimums at the points (−2,−1) and (2,−1), and a global minimum is a type of global extremum.

Therefore, the correct answer is "None of the statements are true."
