The graph y=f(x) is shown above. Which of the following statements are true?

  1. The global maximum of f(x) is 4.
  2. The global minimum of f(x) is 1.
  3. The function does not have any global extrema.
a
None of the statements are true.
b
II only
c
III only
d
I only
e
I and II only
Submit
Correct
EXPLANATION

Let's examine each statement.

  • Statement I is false. At first glance, it might seem that the point (1,4) corresponds to the global maximum, but since x=1 is not included in the domain (as indicated by the open circle), the function does not have a global maximum.

  • Statement II is true. The global minimum point is (5,1), and so the minimum value reached by the function is f(x)=1. Therefore, the global minimum is 1.

  • Statement III is false. The function f(x) has a global minimum at the point (5,1), and a global minimum is a type of global extremum.

Therefore, the correct answer is "II only."
