Let's construct our matrix:

  • The index 3 in J3(0) means that we have a 3×3 matrix.

  • The value 0 in J3(0) means that we have 0's on the main diagonal.

  • Also, we must have 1's on the superdiagonal (the diagonal above the main one).

Given that all the other entries must be zero, our Jordan block is

J3(0)=[010001000].
