We're given a part and a whole, and we must find a percentage. So, we can use the following formula: percentage=part÷whole

In this case,

  • the part is the number of students that failed the exam, which is 12, and

  • the whole is the total number of students, which is 40.

Substituting our numbers into the above formula, we get

percentage=12÷40=1240.

We can simplify this fraction as follows:

1240=12÷440÷4=310

To write this as a percentage, we create an equivalent fraction with 100 as the denominator:

310=3×1010×10=30100

Now we can write this fraction as a percentage:

30100=30%

Therefore, 30% of the students failed the exam.
