Recall that finite sets have the same cardinality if and only if they have the same number of elements.

With that in mind, let's examine our statements.

  • Statement I is true. Indeed, X is a finite set and |X|=4.

  • Statement II is false. Notice that Y={1,2,3,4} is a finite set and |Y|=4.

  • Statement III is true. Indeed, X and Y are finite sets and |X|=|Y|=4.

Therefore, the correct answer is "I and III only."

Your Answer:
III only
