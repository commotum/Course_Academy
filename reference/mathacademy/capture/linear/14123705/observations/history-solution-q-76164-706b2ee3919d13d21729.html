Given a relation R on a set A:

  • R is reflexive if and only if for all x∈A, xRx.

  • R is symmetric if and only if for all x,y∈A, if xRy, then yRx.

  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

With this in mind, let's consider each of the given relations.

  • Relation I is not an equivalence relation. For example, it is not reflexive because 0⋅0=0≯0.

  • Relation II is not an equivalence relation. For example, it is not symmetric because 2=2(1) but 1≠2(2).

  • Relation III is an equivalence relation:

    • It is reflexive because for all x∈R, we have x−x=0 is a rational number.

    • It is symmetric because for all x,y∈R, if x−y=r is a rational number, then y−x=−(x−y)=−r is also a rational number.

    • It is transitive because for all x,y,z∈R, if x−y=r and y−z=q, where r,q are rational numbers, then x−z=(x−y)+(y−z)=r+q is also a rational number.

Therefore, the correct answer is "III only".
