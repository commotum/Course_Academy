  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

With this in mind, let's consider each of the given relations.

  • Relation I is not an equivalence relation. For example, it is not reflexive because 22+22≰4.

  • Relation II is an equivalence relation since it's reflexive, symmetric, and transitive.

  • Relation III is not an equivalence relation. For example, it is not reflexive because 12⋅12∉N.
