Consider the relation R on the set A={α,β,γ} defined as R={(α,α),(β,β),(β,α),(α,β)}.

Which of the following statements are true?

  1. R is reflexive
  2. R is symmetric
  3. R is transitive
  4. R is an equivalence relation
a
II and III only
b
I only
c
III only
d
II and II only
e
I, II, III, and IV
Submit
Correct
EXPLANATION

Given a relation R on a set A:

  • R is reflexive if and only if for all x∈A, xRx.

  • R is symmetric if and only if for all x,y∈A, if xRy, then yRx.

  • R is transitive if and only if for all x,y,z∈A, if xRy and yRz, then xRz.

If R is reflexive, symmetric, and transitive, then R is an equivalence relation.

Let's consider each of the properties in turn.

  • The relation R is not reflexive because (γ,γ)∉R.

  • The relation R is symmetric because (y,x)∈R whenever (x,y)∈R. ✓

  • The relation R is transitive because for all x,y,z∈{α,β,γ}, if (x,y)∈R and (y,z)∈R, then (x,z)∈R. Recall that it's sufficient to check only the cases when both pairs have different components:

    • (α,β)∈R and (β,α)∈R, and also (α,α)∈R ✓

    • (β,α)∈R and (α,β)∈R, and also (β,β)∈R ✓

  • The relation is not an equivalence relation since it's not reflexive.

Therefore, the correct answer is "II and III only."
