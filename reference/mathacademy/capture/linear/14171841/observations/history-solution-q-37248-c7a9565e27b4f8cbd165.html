A rule is a function if and only if every input is mapped to precisely one output.

With that in mind, let's examine each statement:

  • Statement I is false, and statement II is true.

    x 12 9 7 3 6 9
    y 15 12 9 6 3 0

    Notice that the first row contains the value x=9 twice. The input value x=9 is assigned to more than one output value (12 and 0).

  • Statement III is false. The input x=15 is not mapped to anything.

Therefore, the correct answer is "II only."
