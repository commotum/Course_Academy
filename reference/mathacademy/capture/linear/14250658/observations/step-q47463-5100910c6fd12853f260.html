EXPLANATION

Let's analyze each statement one-by-one.

  • On the left of the graph, we see that as x gets more and more negative, the function f(x) levels off to the value of 2. We can express this as follows: f(x)→2asx→−∞ Therefore, statement I is true while statement III is false.

  • On the right of the graph, we see that as x gets larger and larger, the function f(x) levels off to the value of 1. We can express this as follows: f(x)→1asx→∞ Therefore, statement II is true.

As a result, the correct answer is "I and II only".
