On which of the following intervals is the function y=f(x) above continuous?

a
[−1,2]
b
[−10,0]
c
[−3,−1]
d
[1,3]
e
[0,5]
Submit
Correct
EXPLANATION

The function is continuous on the open intervals (−∞,−2), (−2,2) and (2,∞).

Additionally, the function is right-continuous at x=−2 and left-continuous at x=2. Hence, it is continuous on the closed interval [−2,2].

Therefore, we can say that the function is continuous on the intervals (−∞,−2), [−2,2] and (2,∞). It is also continuous on any subinterval of these intervals.

Among the answer choices, the correct one is the following:

[−1,2]

Notice that

  • [−3,−1] and [−10,0] contain the point of discontinuity x=−2, so the function is not continuous on these intervals.

  • [0,5] and [1,3] contain the point of discontinuity x=2, so the function is not continuous on these intervals.
