On which of the following intervals is the function y=f(x) above continuous? You may assume that all points of discontinuity of f(x) are shown in the diagram.

a
 (0,∞)
b
 (−2,4)
c
(−∞,6)
d
 (1,∞)
e
 (2,∞)
Submit
Correct
EXPLANATION

To determine the intervals of continuity of a function, we take the domain of the function and exclude any points of discontinuity.

The function is defined on the interval (−∞,∞). There is a discontinuity at x=2, so we need to exclude this point.

Therefore, the function is continuous on the intervals (−∞,2) and (2,∞). It is also continuous on any subinterval of these intervals.

Among the answer choices, the correct one is the following:

(2,∞)

Notice that:

  • The intervals (0,∞), (−2,4), (−∞,6), and (1,∞) contain the excluded point x=2, so the function is not continuous on any of these these intervals.
