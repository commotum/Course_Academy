The function is continuous on the open intervals (−3,0), (0,1) and (1,4).

Additionally, the function is right-continuous at x=−3 and left-continuous at x=0.

Therefore, we can say that the function is continuous on the intervals [−3,0], (0,1) and (1,4). It is also continuous on any subinterval of these intervals.

Among the answer choices, the correct one is the following:

[−2,−1]

Notice that

  • [1,2] and [1,3] contain the endpoint x=1, but the function is not right-continuous at this point.

  • [−1,1] contains the point of discontinuity x=0, so the function is not continuous on this interval.

  • [2,4] contains the endpoint x=4, but the function is not left-continuous at this point.
