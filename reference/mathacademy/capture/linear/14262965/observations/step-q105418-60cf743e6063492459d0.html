EXPLANATION

Let's examine each statement.

  • The function is not continuous on (−∞,−2]. Although the function is continuous on (−∞,−2), it is not left-continuous at x=−2.

  • The function is continuous on [−2,4]. It is continuous on (−2,4), and also right-continuous at x=−2 and left-continuous at x=4.

  • The function is not continuous on [4,∞). Although the function is continuous on (4,∞), it is not right-continuous at x=4.

Therefore, the correct answer is "II only."
