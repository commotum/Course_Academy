EXPLANATION

An indicator function maps elements from a set to the values 0 or 1, depending on whether the element belongs to a specified subset. The indicator function is designed to "indicate" whether an element is a member of a subset.

More specifically, consider a universal set X. Then, the indicator function of a set A⊆X is the function 1A(x)={1,if x∈A,0,if x∉A.

In the diagram above, only the elements b,c and e are mapped to 1. Therefore, the indicator function in the diagram above corresponds to the set A={b,c,e}.
