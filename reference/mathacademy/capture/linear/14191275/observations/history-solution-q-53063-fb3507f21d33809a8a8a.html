First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Let's now look at each statement in turn.

  • Statement I is true. A parallelogram is a rectangle when all the angles are right.

  • Statement II is false. A kite is always a quadrilateral because it has four sides.

  • Statement III is false. A trapezoid has only 1 pair of opposite sides that are parallel. However, in a square, 2 pairs of opposite sides are parallel, and so doesn't fit the definition of a trapezoid.

In conclusion, only statement I is true.
