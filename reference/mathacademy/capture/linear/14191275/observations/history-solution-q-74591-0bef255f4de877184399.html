First, recall the hierarchy diagram of quadrilaterals, where each shape below another is a specific type of the one above it.

Remember that a rhombus is a parallelogram where all sides are congruent.

With that in mind, let's look at each shape in turn.

  • The shape P is a rectangle. The sides are not all congruent, so it is not a rhombus.

  • The shape Q is a square. All its sides are congruent and the opposite sides are parallel, so it is a rhombus.

  • The shape R is a trapezoid. Since it has only one pair of parallel sides, it is not a rhombus.

  • The shape S is an isosceles trapezoid. Since it has only one pair of parallel sides, it is not a rhombus.

Therefore, shape Q is a rhombus. The shapes P, R, and S are not rhombuses.
