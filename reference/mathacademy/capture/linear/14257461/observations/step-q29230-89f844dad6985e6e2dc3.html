Which of the following statements are true regarding the function y=ln⁡x?

  1. It's an increasing function
  2. y→∞ as x→∞
  3. y→∞ as x→−∞
a
I and II only
b
I and III only
c
I only
d
All the statements
e
II only
Submit
Correct
EXPLANATION

Let's plot the graph of y=ln⁡x.

Let's go through each statement.

  • Statement I is true. From the graph, it's clear that the function is increasing.

  • Statement II is true. As x increases, y increases without bound.

  • Statement III is false. The function y=ln⁡x is not defined for x≤0.

In conclusion, only statements I and II are true.
