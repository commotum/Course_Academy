The figure above shows the graph of f(x). Evaluate limx→−2f(x).

a
limx→−2f(x)=DNE
b
limx→−2f(x)=∞
c
limx→2f(x)=−∞

Correct
EXPLANATION

As x approaches −2 from the right, the function value f(x) grows to infinity, and therefore

limx→−2+f(x)=∞.

However, as x approaches −2 from the left, the function value f(x) goes to −∞, and therefore

limx→−2−f(x)=−∞. Consequently, limx→−2f(x)=DNE.
