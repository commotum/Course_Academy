First, notice that the function is a product of 3 linear binomials, so this function is a cubic function. Moreover, it is a positive cubic because if we were to expand the parentheses, the coefficient of the x3 term would be positive:

15(x+1)(x+2)(x−5)=15⋅x⋅x⋅x+⋯=15x3+⋯

The equation is already in factored form. So by the zero-product rule, we deduce that the roots are x=−1, x=−2, and x=5.

We also find the y-intercept of the curve by plugging the value x=0 into the equation:

y=15(0+1)(0+2)(0−5)=(1)(2)(−5)5=−2.
