When a new app was first launched, it had 60 downloads. An exponential model estimates that at the end of each day after launch, the number of downloads increased by 120% of the number of downloads at the end of the previous day.

Which of the following equations best represents this model, where D is the estimated number of downloads t days after the app was launched, and t≤7?

aD(t)=60⋅(2.2)t
bD(t)=60⋅(1.2)t
cD(t)=60⋅(0.2)t
dD(t)=60⋅(12)t
eD(t)=60⋅(22)t
