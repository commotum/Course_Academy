  • The domain of the function is all real numbers except the points where the function is undefined: x=0,±π,±2π,…

  • The range of the function is y∈(−∞,−1]∪[1,+∞).

  • The period of the function is 2π.

  • It has no zeros and no global extrema.

  • The branches of the function alternate between positive and negative, with a positive branch for x∈(0,π).

  • The graph has vertical asymptotes at the points that are not in the domain: x=0,±π,±2π,…
