Which of the following is not the equation of an asymptote of the function y=csc⁡x?

a
x=5π
b
x=π5
c
x=0
d
x=50π
e
x=−3π
Submit
Correct
EXPLANATION

Let's recall the graph of y=csc⁡x.

Note that:

  • The domain of the function is all real numbers except the integer multiples of π, such as 0,±π,±2π,…

Therefore, the asymptotes of y=csc⁡x occur at x=nπ, where n is any integer.

So, of the given equations the only one that isn't an asymptote of the function is x=π5.
