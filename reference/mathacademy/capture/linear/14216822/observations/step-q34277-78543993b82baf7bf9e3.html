Given that the point A has coordinates (−54,−54), calculate the angle θ.

a
215∘
b
220∘
c
230∘
d
240∘
e
225∘

Correct
EXPLANATION

We can form a triangle by creating a vertical line from A to the x-axis. Let us call θ′ the acute angle that is formed with the x-axis such that θ′+180∘=θ

Using the tangent ratio, we have

tan⁡θ′=(54)(54)=1.

Finally, using the inverse tangent, we get

θ′=arctan⁡1=45∘.

Finally, using θ=θ′+180∘, we get θ=45∘+180∘=225∘.
