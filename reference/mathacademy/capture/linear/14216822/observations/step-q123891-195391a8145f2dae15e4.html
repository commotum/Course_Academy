Given that the point A has coordinates (−33,9), calculate the angle θ.

a
2π3
b
5π6
c
5π8
d
3π4
e
3π5
Submit
Correct
EXPLANATION

We can form a triangle by creating a vertical line from A to the x-axis. Let us call θ′ the acute angle that is supplementary to θ.

Using the tangent ratio, we have

tan⁡θ′=933=33=3.

Finally, using the inverse tangent, we get

θ′=arctan⁡3=π3. Since θ+θ′=π, then θ=π−θ′=π−π3=2π3.
