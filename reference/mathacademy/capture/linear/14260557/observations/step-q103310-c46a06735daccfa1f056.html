If tan⁡x=54, for some value of x, find the value of 24tan⁡(x−11π)−3.

a
2π+7
b
27
c
33
d
30+2π
e
27−2π
Submit
Correct
EXPLANATION

The period of y=tan⁡x is π. Therefore, for any integer n, we have

tan⁡x=tan⁡(x+nπ).

Substituting n=−11 into the above gives tan⁡x=tan⁡(x+(−11)⋅π)=tan⁡(x−11π).

Since tan⁡x=54, we get that tan⁡(x−11π)=54. Therefore 24tan⁡(x−11π)−3=24(54)−3=30−3=27.
