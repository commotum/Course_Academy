If log125⁡x=log5⁡xk, where k is an integer, then k=
3
.
Submit
Correct
EXPLANATION

We use the change of base formula: loga⁡X=logb⁡Xlogb⁡a

We want to change from base a=125 to base b=5. So, we have

log125⁡x=log5⁡xlog5⁡125.

Rewriting the expression in the denominator using exponents, we get

log5⁡xlog5⁡125=log5⁡xlog5⁡(53)=log5⁡x3.

Therefore, we conclude that

log125⁡x=log5⁡x3.

Hence, k=3.
