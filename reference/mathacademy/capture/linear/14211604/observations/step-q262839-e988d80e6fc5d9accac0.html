Let log⁡x=t. Express log1000⁡x via the variable t.
log1000⁡x=
t3​
Submit
Correct
EXPLANATION

We use the change of base formula: loga⁡X=logb⁡Xlogb⁡a

We want to change from base a=1000 to base b=10. So, we have log1000⁡x=log10⁡xlog10⁡(1000).

Rewriting the expression in the denominator using exponents, we get log10⁡xlog10⁡(1000)=log10⁡xlog10⁡(103)=log10⁡x3.

Therefore, since log⁡x=t, we conclude that log1000⁡x=log10⁡x3=t3.
