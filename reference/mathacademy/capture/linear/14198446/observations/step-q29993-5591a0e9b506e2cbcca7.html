a
−3x3/2+C

Correct
EXPLANATION

Remember that integration is the opposite of differentiation. So, if F′(x)=f(x), then integrating both sides of this equation gives

F′(x)=f(x)∫F′(x)dx=∫f(x)dxF(x)=∫f(x)dx.

Note that 1x3=x−3/2. So, we can use the power rule with n=−32 and get

F(x)=∫1x3dx=∫x−3/2dx=x−3/2+1(−32+1)+C=x−1/2(−12)+C=−2x−1/2+C.
