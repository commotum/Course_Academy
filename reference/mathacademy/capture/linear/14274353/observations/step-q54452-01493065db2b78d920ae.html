EXPLANATION

Let's sketch the graph of y=ln⁡(2x−1).

The function is not defined for x≤12. Therefore,

limx→1/2−ln⁡(2x−1)=DNE.

However, the function is defined for x>12. Moreover,

limx→1/2+ln⁡(2x−1)=−∞.

Since the left and right-sided limits are not equal, we have limx→1/2ln⁡(2x−1)=DNE.
