A cyclist has set up a 3-digit lock combination for their bicycle lock, where the digits are selected from the numbers 0-9. What is the probability that there are no repeated digits in the combination?

a
0.72
b
0.6
c
0.78
d
0.06
e
0.68
Submit
Correct
EXPLANATION

Let A denote the event described in the question. Then

P(A)=nN,

where N is the total number of 3-digit lock combinations that can be created from 10 digits (0,1,2,…,9), and n is the number of combinations that have no repeated digits.

First, we compute N. We want to count how many 3-digit lock combinations can be formed from a set of 10 digits with repetition. This is equal to the number of permutations of 3 items chosen from a set of 10 with repetition, which is N=103=1000.

Now, we compute n. To create a 3-digit combination from the 10 digits where no digits are repeated, we choose 3 of the 10 possible digits. Since the order of the digits matters, we use permutations:

n=10P3=10!7!=720

Finally, we have

P(A)=nN=0.72.
