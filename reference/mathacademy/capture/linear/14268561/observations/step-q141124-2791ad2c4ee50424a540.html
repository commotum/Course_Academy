EXPLANATION

Notice that the logarithms share the same base.

First, we apply the power rule to the first term to make the coefficient in front of each logarithm the same:

2log6⁡(3x)−log6⁡(2x2+1)=log6⁡3log6⁡(9x2)−log6⁡(2x2+1)=log6⁡3

Next, we combine the logarithms on the left-hand side using the quotient rule:

log6⁡(9x22x2+1)=log6⁡3

Now, we solve the equation for x using the usual methods.

9x22x2+1=3(2x2+1)⋅9x22x2+1=(2x2+1)⋅3(2x2+1)⋅9x22x2+1=(2x2+1)⋅39x2=6x2+33x2=3x2=1

So, x=−1 or x=1.

Let's now check for extraneous solutions by substituting back into the original equation:

  • Substituting x=−1 back into the original equation, we get 2log6⁡(3⋅(−1))−log6⁡(2(−1)2+1)=?log6⁡32log6⁡(−3)−log6⁡(3)≠log6⁡3× because log6⁡(−3) is undefined. Therefore, x=−1 is not a valid solution.

Therefore, the correct answer is "x=1 only".
