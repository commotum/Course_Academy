  2. [3]6

EXPLANATION

Let's now consider each of the given equivalence classes.

  • 7∈[−5]6 because 7≡−5(mod6) ✓

  • 7∉[3]6 because 7≢3(mod6) ×

  • 7∈[1]6 because 7≡1(mod6) ✓

Therefore, the correct answer is "I and III only".
