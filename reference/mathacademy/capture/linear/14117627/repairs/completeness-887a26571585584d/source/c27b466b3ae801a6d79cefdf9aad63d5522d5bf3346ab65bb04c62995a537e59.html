EXPLANATION

We have −4∈[a]10 if −4≡a(mod10).

Let's now consider each of the given equivalence classes.

  • −4∉[4]10 because −4≢4(mod10) ×

  • −4∈[−14]10 because −4≡−14(mod10) ✓

  • −4∈[6]10 because −4≡6(mod10) ✓

Therefore, the correct answer is "II and III only".
