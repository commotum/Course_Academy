  2. [13]8

EXPLANATION

We have 5∈[a]8 if 5≡a(mod8).

Let's now consider each of the given equivalence classes.

  • 5∈[−3]8 because 5≡−3(mod8) ✓

  • 5∈[13]8 because 5≡13(mod8) ✓

  • 5∉[6]8 because 5≢6(mod8) ×

Therefore, the correct answer is "I and II only".
