EXPLANATION

Recall that the residue classes modulo n have the following properties:

  • There are exactly n distinct residue classes modulo n

  • Two distinct residue classes have an empty intersection: [a]n∩[b]n=∅ if a≢b(modn)

  • Residue classes modulo n form a partition of the set of all integers: Z=[0]n∪[1]n∪⋯∪[n−1]n

  • The integers modulo n is defined as the set containing all distinct residue classes modulo n: Zn={[0]n,[1]n,…,[n−1]n}

With that in mind, let's now consider each of the given statements.

  • Statement I is false. There are exactly 6 distinct residue classes modulo 6.

  • Statement II is false. Since 5≢1(mod 3), we have that [5]3∩[1]3=∅.

  • Statement III is true. First, notice the following: [3]2=[1+2⋅1]2=[1]2[6]2=[0+2⋅3]2=[0]2 As a result, we get [3]2∪[6]2=[1]2∪[0]2=[0]2∪[1]2=Z

Therefore, the correct answer is "III only".
