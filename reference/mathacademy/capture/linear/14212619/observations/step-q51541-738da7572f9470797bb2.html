Given that P(x) is a polynomial of degree 4, which of the following statements are always true?

  1. x4P(x) is a polynomial
  2. x4⋅P(x) is a polynomial of degree 8
  3. x4+P(x) is a polynomial of degree 4
a
III only
b
I only
c
II only
d
I and III only
e
II and III only
Submit
Correct
EXPLANATION

Let's look at each statement in turn.

  • Statement I is false. For example, suppose P=x4+2. Then x4P(x)=x4x4+2, which is not a polynomial.

  • Statement II is true. The highest-degree term in P must contain x4. Therefore, the highest-degree term in x4⋅P(x) must contain x4⋅x4=x4+4=x8, meaning that x4⋅P(x) has degree 8.

  • Statement III is false. For example, suppose P=−x4. Then x4+P(x)=x4−x4=0, which is not a polynomial of degree 4.

In conclusion, only statement II is true.
