What is 4250g expressed in kg?

a
425kg
b
42.5kg
c
42500kg
d
4.25kg
e
0.425kg

Correct
EXPLANATION

We start by recalling the conversion table for mass units.

Name Symbol Conversion
Kilogram kg 1kg=1000g
Gram g Base Unit
Milligram mg 1000mg=1g

There are 1000g per kg, which we can write as follows:

1000gkg

However, since we're converting from a smaller unit of mass (g) to a larger one (kg), we need to multiply 4250g by the reciprocal of the above:

kg1000g

This is our conversion factor.

Now, multiplying 4250g by our conversion factor, we get

4250g=4250g⋅kg1000g=4250g⋅kg1000g=4250⋅kg1000=42501000kg=4.25kg

Therefore, 4250g is equivalent to 4.25kg.
