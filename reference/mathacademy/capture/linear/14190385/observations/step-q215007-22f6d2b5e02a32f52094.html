EXPLANATION

We start by recalling the conversion table for mass units.

Name Symbol Conversion
Kilogram kg 1kg=1000g
Gram g Base Unit
Milligram mg 1000mg=1g

There are 1000mg per g, which we can write as follows: 1000mgg

This is our conversion factor.

Now, multiplying 4g by our conversion factor, we get 4g=4g⋅1000mgg=4g⋅1000mgg=4⋅1000mg=4000mg.

Therefore, 4g is equivalent to 4000mg.
