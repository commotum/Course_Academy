What is 1.2g expressed in mg?

a
12mg
b
1200mg
c
120mg
d
12000mg
e
0.12mg
Submit
Correct
EXPLANATION

We start by recalling the conversion table for mass units.

Name Symbol Conversion
Kilogram kg 1kg=1000g
Gram g Base Unit
Milligram mg 1000mg=1g

There are 1000mg per g, which we can write as follows:

1000mgg

This is our conversion factor.

Now, multiplying 1.2g by our conversion factor, we get

1.2g=1.2g⋅1000mgg=1.2g⋅1000mgg=1.2⋅1000mg=1200mg.

Therefore, 1.2g is equivalent to 1200mg.
