If the quadratic equation kx2+4x+2=0 has one distinct real solution, then k=
2
.

Correct
EXPLANATION

The equation has one distinct real solution if its discriminant is zero. So, we need to find the values of k so that the discriminant is zero.

First, we calculate the discriminant. We have a=k, b=4, and c=2, so the discriminant is as follows: D=b2−4ac=(4)2−4(k)(2)=16−8k

Now, we find the values of k such that the discriminant is zero: D=016−8k=08k=16k=168k=2

Therefore, the given equation will have one distinct real solution if k=2.
