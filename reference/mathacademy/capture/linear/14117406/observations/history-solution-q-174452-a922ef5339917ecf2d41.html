The union of a family of indexed sets is the set containing all elements belonging to at least one set in the indexed family:

⋃i∈IAi={x∈U:x∈Aifor at least one Ai,i∈I} where U is a universal set.

Let's now write down a few instances of our indexed sets:

  • if i=1, we have S1=[0,2]

  • if i=2, we have S2=[0,32]

  • if i=3, we have S3=[0,43]

and so on.

Notice that as i increases,

  • the left endpoint of the intervals is 0 for all the sets,

  • the right endpoint of the intervals approaches 1 but never reaches it.

Moreover, all the intervals are contained in S1.

Therefore,

⋃i∈ISi=S1=[0,2].
