EXPLANATION

We'll work out the indefinite integral first and then proceed with the definite integral.

First, we note that a denominator of the integrand can be factored as x2−1=(x−1)(x+1).

So the integrand can be converted into a sum of partial fractions, 1x2−1=1(x−1)(x+1)=A(x+1)+B(x−1),

which gives 1=A(x−1)+B(x+1).

Plugging in x=1, we can eliminate A and solve for B: 1=A(1−1)+B(1+1)1=2BB=12

On the other hand, plugging in x=−1, we can eliminate B and solve for A: 1=A(−1−1)+B(−1+1)1=−2AA=−12

Therefore,

1x2−1=−12(x+1)+12(x−1).

Now, we integrate, and we get

∫1x2−1dx=∫(−12(x+1)+12(x−1))dx=12∫1x−1dx−12∫1x+1dx=12ln⁡|x−1|−12ln⁡|x+1|+C.

We can simplify the result using the laws of logarithms, as follows:

∫dxx2−1dx=12ln⁡|x−1|−12ln⁡|x+1|+C=12ln⁡|x−1x+1|+C

Finally, the definite integral is

∫231x2−1dx=12ln⁡|x−1x+1||23=12(ln⁡(12)−ln⁡(13))=12ln⁡(12⋅31)=12ln⁡(32).
