The Cartesian product A×B consists of all ordered pairs whose first coordinate belongs to A and whose second coordinate belongs to B.

A×B={(a,b):a∈A,b∈B}

In this case, the set S=R×R contains every point in R2 whose x-coordinate is any real number and whose y-coordinate is any real number.

S={(x,y):x∈R,y∈R}.

To visualize S, consider S0⊂S containing all points whose x-coordinate equals 0 and whose y-coordinate is any real number.

S0={(0,y):y∈R}

Si={(i,y):y∈R}
