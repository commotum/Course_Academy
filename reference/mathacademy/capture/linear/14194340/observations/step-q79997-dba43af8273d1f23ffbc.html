Incorrect
EXPLANATION

First, we find the smallest and largest y-values in the graph.

  • There is no smallest y-value.

  • The largest y-value is 1. This occurs when x→−∞. However, note that this point is not included in the graph.

The function covers all the y-values between −∞ and 1, but not including 1.

Therefore, the range is −∞<y<1, which can also be written as −∞<f(x)<1.
