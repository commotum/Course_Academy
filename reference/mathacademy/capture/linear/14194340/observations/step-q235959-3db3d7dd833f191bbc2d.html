EXPLANATION

We find the ranges of the individual pieces, and then calculate their union:

  • The range of the branch defined on x∈[−3,0) is [0,2)

  • The range of the branch defined on x∈[0,3] is [−3,−1]

Therefore, the range of f(x) is [−3,−1]∪[0,2).

Note: From the graph, we see that the value y=2 is NOT a valid output of the function y=f(x). Therefore, we use parentheses (…) instead of brackets […] at this endpoint.
