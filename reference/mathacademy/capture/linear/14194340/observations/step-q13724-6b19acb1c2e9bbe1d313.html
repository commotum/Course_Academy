Consider the linear function f(x)=x2, where −2<x≤5. What is its range?

a
−2<f(x)<3
b
−1≤f(x)≤52
c
−1<f(x)≤52
d
−1<f(x)<52
e
−2<f(x)≤3
Submit
Correct
EXPLANATION

First, we graph the function.

Then, we find the smallest and largest y-values in the graph.

  • The smallest y-value is −1. This occurs at the point (−2,−1). However, note that this point is not included in the graph.

  • The largest y-value is 52. This occurs at the point (5,52).

The function covers all the y-values between −1 and 52, including 52 but not including −1.

Therefore, the range is −1<y≤52, which can also be written as −1<f(x)≤52.
