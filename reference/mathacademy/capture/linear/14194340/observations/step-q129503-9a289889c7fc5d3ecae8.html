Correct
EXPLANATION

We find the ranges of the individual pieces, and then calculate their union:

  • The range of the branch defined on x∈[−3,1] is [−2,1]

  • The range of the branch defined on x∈(1,3) is (−3,1)

Therefore, the range of f(x) is [−2,1]∪(−3,1)=(−3,1].

Note: From the graph, we see that the value y=−3 is NOT a valid output of the function y=f(x). Therefore, we use parentheses (…) instead of brackets […] at this endpoint.
