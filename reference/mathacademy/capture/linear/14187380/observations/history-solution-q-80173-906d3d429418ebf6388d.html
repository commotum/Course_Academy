First, notice that we can factor out a (−3) from each of the terms:

6−3x−3x2=−3(x2+x−2)

Now, we just need to factor the polynomial x2+x−2 in parentheses.

We start by listing the factor pairs of the constant term (−2). The constant term is negative, so that means one of the factors is negative and the other is positive:

1×(−2)(−1)×2

Now, we find which factor pair adds up to the coefficient of the linear term (1):

1+(−2)=−1×(−1)+(2)=1✓

Using the factor pair identified above, we write the linear term as x=−x+2x and then factor:

−3(x2+x−2)=−3(x2−x+2x−2)=−3((x2−x)+(2x−2))=−3(x(x−1)+2(x−1))=−3(x+2)(x−1)
