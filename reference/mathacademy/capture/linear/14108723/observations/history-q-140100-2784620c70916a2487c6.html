5.Identifying True Statements Using the Rank-Nullity Theorem?

Let T:R5→R5 be a linear transformation whose standard matrix is T, and let {v1,v2,v3,v4} be a set of linearly independent vectors in R5. Consider the following statement:

If Im(T)=Span{v1,v2,v3,v4}, then __________.

Which of the following can be placed into the blank space to make a true statement?

  1. rank(T)=4
  2. nullity(T)=4
  3. T is a bijection
