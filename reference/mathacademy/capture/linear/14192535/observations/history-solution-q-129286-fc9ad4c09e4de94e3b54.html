The function is defined for values less than −2, and for values between −2 and 3.

  • Since there is a closed circle at x=−2, this point is included in the domain.

  • Since there is an open circle at x=3, this point is excluded from the domain.

Therefore, the domain is x∈(−∞,3).

Note that the function is defined at the point x=−2, even though the function jumps at that point. The function value at x=−2 is 1.
