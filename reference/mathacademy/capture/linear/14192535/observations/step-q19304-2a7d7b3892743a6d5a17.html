EXPLANATION

We will graph each branch separately.

  • On the interval (−∞,1], we have a line with slope 2 and y-intercept 1. So the graph is the line y=2x+1 that ends at (1,3), including this point.

  • On the interval (1,∞), we have a line with a slope of −2 that passes through the point (1,0). We can find the equation of this line using point-slope form: y−0=−2(x−1)⟹y=2−2x So the graph is the line y=2−2x that starts at (1,0), excluding this point.

Therefore, the function is defined as follows:

f(x)={2x+1,x≤12−2x,x>1
