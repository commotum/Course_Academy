EXPLANATION

We note that n=0 cannot be a solution since division by 0 is undefined.

The equation has the denominators 2n, n2, and 3n. So first, we find the least common multiple (or LCM) of the denominators. We find that

LCM(2n,n2,3n)=6n2.

So, we multiply both sides of the equation by 6n2, and simplify:

32n−1−nn2=73n6n2⋅(32n−1−nn2)=6n2⋅(73n)6n2⋅(32n)−6n2⋅(1−nn2)=6n2⋅(73n)3n⋅2n⋅(32n)−6⋅n2⋅(1−nn2)=2n⋅3n⋅(73n)3n⋅2n⋅(32n)−6⋅n2⋅(1−nn2)=2n⋅3n⋅(73n)3n⋅(3)−6⋅(1−n)=2n⋅(7)9n−6(1−n)=14n

We now have a linear equation in n, and we can solve this using the addition and multiplication principles:

9n−6(1−n)=14n15n−6=14nn=6

Finally, we recall that we cannot allow n=0 as a solution. But since n=6≠0, we conclude that the solution is n=6.
