First, we fill the table. Given a value of x we can find the corresponding y by substituting x into the formula y=2x+2. Therefore, we obtain

  • if x=0 then y=2(0)+2=2,

  • if x=1 then y=2(1)+2=4,

  • if x=2 then y=2(2)+2=6, and

  • if x=3 then y=2(3)+2=8.
