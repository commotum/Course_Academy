Which of the given points lie on the line y=−5x+6?

a
A and C only
b
C only
c
B only

A and B only

Correct
EXPLANATION

The plotted points correspond to the xy-pairs A(0,5),B(1,2) and C(2,−4).

To check whether a point lies on the line, we substitute the coordinates of the point into the equation and determine whether the resulting statement is true.

  • Substituting the point A(0,5) results in a false statement: y=−5x+6(5)=−5(0)+65=6× Therefore, the point A does not lie on the line.

  • Substituting the point B(1,2) results in a false statement: y=−5x+6(2)=−5(1)+62=1× Therefore, the point B does not lie on the line.

  • Substituting the point C(2,−4) results in a true statement: y=−5x+6(−4)=−5(2)+6−4=−4✓ Therefore, the point C does lie on the line.

Finally, only point C lies on the line.
