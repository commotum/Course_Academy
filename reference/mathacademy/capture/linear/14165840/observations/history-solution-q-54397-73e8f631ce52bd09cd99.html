First, we fill the table. Given a value of x, we can find the corresponding y by substituting x into the formula y=x−2. Therefore,

  • if x=0 then y=(0)−2=−2,

  • if x=1 then y=(1)−2=−1,

  • if x=2 then y=(2)−2=0, and

  • if x=3 then y=(3)−2=1.
