Consider the equation (2x+2)2−1=k. For which values of k does this equation have no real solutions?

a
k>0
b
k<1
c
k<−2
d
k<−1
e
k>−2
Submit
Correct
EXPLANATION

Let's try and solve using the square root method: (2x+2)2−1=k(2x+2)2=k+1(2x+2)2=k+1|2x+2|=k+1

The equation will have no real solutions if the expression under the square root is negative, which gives the following condition: k+1<0

We solve this inequality for k: k+1<0k<−1

Therefore, any value of a that is less than −1 will give an equation with no real solutions.
