EXPLANATION

The logarithm of a with base b is defined as follows:

a=bx is equivalent to logb⁡a=x

If we compare 30=1 with a=bx, we get a=1,b=3 and x=0.

Therefore, the equation 30=1 is equivalent to log3⁡1=0.

Note that logn⁡1=0 for any n>0,n≠1.
