Which of the following statements are true regarding the polynomial f(x)=x2+2x−3?

  1. x=−3 is a root of f(x)
  2. (x+3) is a factor of f(x)
  3. (x+3) divides f(x) with zero remainder
a
I only
b
III only
c
I, II, and III
d
I and II only
e
None of the statements are true

Correct
EXPLANATION

The factor theorem states that (x−r) is a factor of a polynomial p(x) if and only if the root x=r is also a root of p(x).

Here, we are considering (x+3). The root of this expression can be found by setting the expression equal to 0 and solving: x+3=0x=−3

We now check each of the statements, in turn.

  • Statement I is true. Indeed, x=−3 is a root of f(x): f(−3)=(−3)2+2(−3)−3=9−6−3=0

  • Statement II is true. According to the factor theorem, since x=−3 is a root of f(x), then (x+3) is a factor of f(x).

  • Statement III is true. If (x+3) is a factor of f(x), then (x+3) divides f(x) with zero remainder.

Therefore, the correct answer is "I, II, and III."
