Which of the following subspaces must be orthogonal to Col(A) for every matrix A?

  1. Col(AT)
  2. Null(AT)
  3. Null(A)
a
II only
b
I and III only
c
II and III only
d
III only
e
I only
Submit
Incorrect
EXPLANATION

Recall that Col(A) consists of all linear combinations of the columns of A, that is, the rows of AT.

If a vector is orthogonal to every linear combination of the rows of AT, it must be orthogonal to each row of AT. But notice that when pre-multiplying a vector by AT, we actually multiply each row of AT by that vector. So, Col(A) must be orthogonal to the left null space of A, which is Null(AT).

Therefore, the correct answer is "II only."
