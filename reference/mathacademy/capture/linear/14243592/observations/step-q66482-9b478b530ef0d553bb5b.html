EXPLANATION

The graph of the function f(x)=x2+2 can be obtained in the following way:

  1. Take the curve y=x2.

  2. Translate it by 2 units up to get f(x)=x2+2.

    A function is invertible on a particular interval if and only if it's a one-to-one function on that interval. To determine the intervals on which the function is invertible, we use the horizontal line test.

  3. The function f(x) is not invertible on the interval x∈(−2,2). On this interval, some horizontal lines will intersect the curve more than once.

  4. The function f(x) is invertible on the intervals x∈[0,∞) and x∈(−∞,0]. On these intervals, any horizontal line will intersect the curve at most once, no matter where we draw the line.

Therefore, the correct answer is "II and III only".
