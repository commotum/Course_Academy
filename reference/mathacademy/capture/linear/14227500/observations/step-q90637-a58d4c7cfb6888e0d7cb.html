  2. f(x) attains a local minimum at x=3
  3. f(x) attains a global maximum at x=1

EXPLANATION

Let's examine each of the given statements in turn.

  • Statement I is true. Indeed, the function has a global maximum at x=4. The global maximum is the highest point on the graph and our function does not have points where its value is greater than f(4).

  • Statement II is true. The function has a local minimum at x=3. For example, in the interval (2.5,3.5), the smallest value of the function is attained at x=3, as shown below.

    We can write this mathematically as f(x)≥f(3) for all x∈(2.5,3.5).

  • Statement III is false. The function does not have a global maximum at x=1. The global maximum is the highest point on the graph, but our function has points where its value is greatest than f(1). For example, f(4)>f(1).

Therefore, the correct answer is "I and II only."
