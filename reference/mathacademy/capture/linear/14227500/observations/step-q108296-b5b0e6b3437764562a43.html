  2. f(x) attains a global minimum at x=1
  3. f(x) attains a local maximum at x=3

EXPLANATION

Let's examine each of the given statements in turn.

  • Statement I is true. The function has a local minimum at x=−2. For example, in the interval (−2.5,−1.5), the smallest value of the function is attained at x=−2, as shown below.

    We can write this mathematically as f(x)≥f(−2) for all x∈(−2.5,−1.5).

  • Statement II is true. Indeed, the function has a global minimum at x=1. The global minimum is the lowest point on the graph and our function does not have points where its value is smaller than f(1).

  • Statement III is true. The function has a local maximum at x=3. For example, in the interval (2.5,3.5), the greatest value of the function is attained at x=3, as shown below.

    We can write this mathematically as f(x)≤f(3) for all x∈(2.5,3.5).

Therefore, the correct answer is "I, II, and III."
