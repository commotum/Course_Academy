The graph of the function y=f(x) is shown above. Which of the points shown are the local maxima of the function?

a
A and E only
b
The function does not have local maxima
c
B and D only
d
D and E only
e
A, C, and E only
Submit
Correct
EXPLANATION

Consider the point B. We can take an open interval of x-values such that B will be the highest point on the graph in this interval. Hence, B is a local maximum.

A similar interval exists for the point D, too. Hence, D is also a local maximum.
