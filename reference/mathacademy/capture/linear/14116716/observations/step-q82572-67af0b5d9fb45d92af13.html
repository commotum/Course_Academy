For the function f:(0,∞)→R defined by f(x)=x−2, which of the following statements are true?

  1. The function is an injection
  2. The function is a surjection
  3. The function is a bijection
a
II only
b
I only
c
I and II only
d
II and III only
e
III only
Submit
Correct
EXPLANATION

Recall that a function f:X→Y is

  • an injection if ∀x1,x2∈X, whenever f(x1)=f(x2), we have x1=x2,

  • a surjection if ∀y∈Y, ∃x∈X such that f(x)=y,

  • a bijection if it is both a surjection and an injection.

With this in mind, let's check each statement.

  • Statement I is true. Any horizontal line (like the one depicted below) crosses the graph of f(x) at most once.

  • Statement II is false. There is no value x for which f(x)=−2∈R.

  • Statement III is false because the function is not a surjection.

Therefore, the correct answer is "I only."
