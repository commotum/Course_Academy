The graph above shows the function y=csc⁡(4x5+C), where C is a constant. Given that −π<C<π, what is the value of C?

a
−4π5
b
−7π10
c
−7π8
d
−3π10
e
−5π8
Submit
Correct
EXPLANATION

The parameter C represents a horizontal shift of the function.

First, we rewrite the function by factoring the horizontal stretch factor, as follows: y=csc⁡(4x5+C)=csc⁡(45(x+5C4))

From the graph, we see that the graph of cosecant has been shifted by 7π8 units to the right. Therefore 5C4=−7π8⟹C=−7π10.
