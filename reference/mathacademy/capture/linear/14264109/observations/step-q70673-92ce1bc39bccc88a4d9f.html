Which of the following statements are true regarding the function y=cot⁡x? Assume n is an integer.

  1. The domain of the function is (−∞,+∞).
  2. cot⁡(x)=cot⁡(x−π)
  3. The function has a vertical asymptote at x=−5π.
a
None
b
I and II only
c
I only
d
I and III only
e
II and III only
Submit
Correct
EXPLANATION

Let's plot the graph of y=cot⁡x.

Now, let's go through each statement.

  • Statement I is false. The domain of the function is all the real numbers except for the points x=nπ.

  • Statement II is true. Since the period of cot⁡x is π, we have cot⁡(x+nπ)=cot⁡x for any integer n. Thus, for n=−1, we get cot⁡(x)=cot⁡(x−π).

  • Statement III is true. The lines x=nπ are the vertical asymptotes of the function. Thus, x=−5π is a vertical asymptote.
