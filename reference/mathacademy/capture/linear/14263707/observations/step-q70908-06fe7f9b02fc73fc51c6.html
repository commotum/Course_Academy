Which of the following equations have no real solution?

  1. 2x−3=1
  2. 4x+1=−6
  3. 2x−1=12
a
III only
b
I and II only
c
I only
d
I and III only
e
II only
Submit
Correct
EXPLANATION

Remember that a square root is always positive or zero. So, a radical equation has no real solution if it states that a square root is equal to a negative number.

Of the given equations, only II states that a square root is equal to a negative number. Therefore, equation II has no real solution.

So, the correct answer is "II only".
