EXPLANATION

First, let's compute the limits in question.

We see from the graph that as x approaches 3 from the left, the function f(x) approaches ∞. So, the left-hand limit is

limx→3−f(x)=∞.

Likewise, as x approaches 3 from the right, the function f(x) again approaches ∞. So, the right-hand limit is

limx→3+f(x)=∞.

Consequently,

limx→3f(x)=∞.

Now, let's examine each statement in turn.

  • Statement I is true.

  • Statement II is true.

  • Statement III is false.
