First, remember that for x>0, the graph of y=x3 increases very rapidly as we increase x. We say that y→∞ as x→∞. The only graphs that exhibit this increasing property are II and IV.

Now, we need to choose between graphs II and IV. To do this, let's evaluate y=x3 at some value of x, say x=−1. Substituting x=−1 into the function, we get

y=(−1)3=−1,

so the correct graph must pass through the point (−1,−1). Only graph IV satisfies this criterion.

Therefore, graph IV corresponds to the graph of y=x3.
