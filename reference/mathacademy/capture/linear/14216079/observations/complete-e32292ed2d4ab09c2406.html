EXPLANATION

First, notice that graph III resembles a straight line. So, we disregard this option.

Now, remember that for x>0, the graph of y=−x3 decreases very rapidly as we increase x. We say that y→−∞ as x→∞. The only graphs that exhibit this decreasing property are I and II.

Now, we need to choose between graphs I and II. To do this, let's evaluate y=−x3 at some value of x, say x=0. Substituting x=0 into the function, we get y=−(0)3=0, so the correct graph must pass through the point (0,0). Only graph II satisfies this criterion.

Therefore, graph II corresponds to the graph of y=−x3.
