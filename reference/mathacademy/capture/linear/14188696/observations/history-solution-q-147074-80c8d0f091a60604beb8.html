We start with the ratio 4:9 and write it as a fraction:

49

In this fraction, the numerator represents the number of heads, and the denominator represents the total number of tosses.

We can make a numerator of 16 by multiplying the numerator and denominator by 4:

4×49×4=1636

Therefore, the coin was tossed 36 times in total. So, the number of tails is

36−16=20.
