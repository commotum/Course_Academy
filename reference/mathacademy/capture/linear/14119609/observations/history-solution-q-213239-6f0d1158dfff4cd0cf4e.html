The additive inverse of −50 modulo 13 is the integer 0≤x<13 such that

x+(−50)≡0(mod13).

First, we note that −50≡2(mod13): −50≡(−4)⋅13+2(mod13)≡(−4)⋅0+2(mod13)≡2(mod13)

Also, note that −2+2≡0, so x≡−2(mod13). To write this in the required form, we use the following sequence of congruences:

x≡−2(mod13)≡0−2(mod13)≡13−2(mod13)≡11(mod13)

Therefore, the additive inverse of the element −50 modulo 13 is 11.

Note: In general, the additive inverse of a modulo n is simply the residue of −a modulo n, i.e. −amodn.
