The additive inverse of 7 modulo 28 is the integer 0≤x<28 such that

x+7≡0(mod28).

Notice that −7+7≡0, so x≡−7(mod28). To write this in the required form, we use the following sequence of congruences:

x≡−7(mod28)≡0−7(mod28)≡28−7(mod28)≡21(mod28)

Therefore, the additive inverse of the element 7 modulo 28 is 21.

We can verify this result as follows: 7+21≡28≡0✓(mod28)

Note: The additive inverse of a modulo n is simply the residue of −a modulo n, i.e. −amodn.
