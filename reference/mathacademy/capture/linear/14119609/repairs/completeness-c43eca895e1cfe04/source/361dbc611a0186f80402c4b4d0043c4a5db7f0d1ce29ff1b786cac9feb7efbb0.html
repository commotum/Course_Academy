Expressed as a nonnegative integer smaller than 16, the additive inverse of 28 modulo 16 is
4
.
Submit
Correct
EXPLANATION

The additive inverse of 28 modulo 16 is the integer 0≤x<16 such that

x+28≡0(mod16).

First, we note that 28≡12(mod16): 28≡1⋅16+12(mod16)≡1⋅0+12(mod16)≡12(mod16)

Also, note that −12+12≡0, so x≡−12(mod16). To write this in the required form, we use the following sequence of congruences:

x≡−12(mod16)≡0−12(mod16)≡16−12(mod16)≡4(mod16)

Therefore, the additive inverse of the element 28 modulo 16 is 4.

We can verify this result as follows: 28+4≡32≡2⋅16≡0✓(mod16)

Note: In general, the additive inverse of a modulo n is simply the residue of −a modulo n, i.e. −amodn.
