Which of the following statements are true regarding the function f:[−2,4]→[−3,9] which is given by f(x)=2x+1?

  1. f(−2)=f(4)
  2. ∀x1,x2∈[−2,4], if f(x1)=f(x2), we have x1=x2
  3. f is an injection
a
I only
b
III only
c
II and III only
d
II only
e
I and II only
Submit
Incorrect
EXPLANATION

First, we graph the function.

A function f:X→Y is an injection (also known as one-to-one) if every element in X is mapped to a distinct element in Y:

f:X→Y is an injection if ∀x1,x2∈X, if f(x1)=f(x2), we have x1=x2.

With that in mind, let's consider each statement in turn.

  • Statement I is false. We have f(2)=2(−2)+1=−3 and f(4)=2⋅4+1=9.

  • Statement II is true. As we can see from the graph, it passes the horizontal line test, meaning that there are no two distinct elements within [−2,4] that map to the same element in [−3,9]. So, for all x1 and x2 contained within the domain [−2,4], if f(x1) and f(x2) are equal, then we must have x1=x2.

  • Statement III is true. Indeed, since statement II is true, f is an injection.

Therefore, the correct answer is "II and III only."
