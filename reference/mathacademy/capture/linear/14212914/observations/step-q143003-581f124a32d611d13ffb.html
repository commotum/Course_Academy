In figure ABCD shown above, which of the following are equal to the vector BO→?

  1. BA→+AD→−OD→
  2. OD→−OC→
  3. OC→+CB→
a
II and III only
b
I and III only
c
I only
d
I and II only
e
II only
Submit
Correct
EXPLANATION
  • For the 1st expression, we have: BA→+AD→−OD→=(BA→+AD→)+DO→=BD→+DO→=BO→✓

  • For the 2nd expression, we have: OD→−OC→=OD→+CO→=CD→≠BO→×

  • For the 3rd expression, we have: OC→+CB→=OB→≠BO→×

Therefore, the correct answer is "I only".
