EXPLANATION

The multiplicative inverse of 3 modulo 5, denoted 3−1, is the number x such that

3⋅x≡1(mod5).

Note that since gcd(3,5)=1, an inverse element exists and is unique up to congruence modulo 5.

Since the modulus n=5 is small, we can find the inverse x by computing exponents of 3 (modulo 5) until we get a result of 1:

32≡3⋅3≡9≡5+4≡4(mod5)33≡3⋅4≡12≡2⋅5+2≡2(mod5)34≡3⋅2≡6≡5+1≡1(mod5)

So, 3⋅2≡1(mod5). Therefore, the multiplicative inverse of 3 modulo 5 is 2.
