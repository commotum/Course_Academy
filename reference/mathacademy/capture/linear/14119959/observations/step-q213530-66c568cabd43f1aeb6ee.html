EXPLANATION

First of all, notice that gcd(55,258)=1. So, the multiplicative inverse of 55 modulo 258 exists.

The multiplicative inverse of 55 modulo 258 is the number x such that

55⋅x≡1(mod258).

To find the value of x, we will use the extended Euclidean algorithm. First, we apply the forward reduction:

258=55⋅4+38↙↙55=38⋅1+17↙↙38=17⋅2+4↙↙17=4⋅4+1

Solving for the rightmost terms in the equations above, we get

38=258−55⋅417=55−384=38−17⋅21=17−4⋅4.

Then, we back-substitute:

1=17−4⋅4=17−(38−17⋅2)⋅4=17⋅9−38⋅4=(55−38)⋅9−38⋅4=55⋅9−38⋅13=55⋅9−(258−55⋅4)⋅13=55⋅61+258⋅(−13)

55⋅61+258⋅(−13)≡1(mod258)55⋅61≡1(mod258)

So, we have 55⋅61≡1(mod258), which means that 55−1mod258=61.
