Which of the following integers has a multiplicative inverse modulo 36?

  1. 5
  2. 13
  3. 24
a
I and II only
b
III only
c
I only
d
II only
e
II and III only
Submit
Correct
EXPLANATION

An integer a has a multiplicative inverse modulo n if and only if a and n are coprime, i.e., gcd(a,n)=1.

With this in mind, let's examine the given options.

  • 5 has a multiplicative inverse modulo 36 since gcd(5,36)=1.✓

  • 13 has a multiplicative inverse modulo 36 since gcd(13,36)=1.✓

  • 24 does not have a multiplicative inverse modulo 36 since gcd(24,36)=12≠1.×

Therefore, the correct answer is "I and II only."
