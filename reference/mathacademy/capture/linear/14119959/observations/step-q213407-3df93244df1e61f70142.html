Which of the following integers has a multiplicative inverse modulo 27?

  1. 11
  2. 16
  3. 23
a
II and III only
b
I, II, and III
c
I only
d
I and II only
e
I and III only

Correct
EXPLANATION

An integer a has a multiplicative inverse modulo n if and only if a and n are coprime, i.e., gcd(a,n)=1.

With this in mind, let's examine the given options.

  • 11 has a multiplicative inverse modulo 27 since gcd(11,27)=1.✓

  • 16 has a multiplicative inverse modulo 27 since gcd(16,27)=1.✓

  • 23 has a multiplicative inverse modulo 27 since gcd(23,27)=1.✓

Therefore, the correct answer is "I, II, and III."
