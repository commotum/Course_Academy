A set is a collection of elements listed between two braces (curly brackets). However, note that the null set (the set that does not contain any elements) can be written as either {} or ∅.

  • f,g,h is not a set. The letters f, g, and h are not listed between two braces.

All the other choices are sets.

  • {f,{h}} is a set. The elements are f, and {h}, and they are listed between the two outermost braces.

  • {∅,{f,g}} is a set. The elements are ∅, and {f,g}, and are listed between the two outermost braces.

  • {} is a set. It is the null set.

  • {1,f,2,g} is a set. The elements are 1, f, 2, and g, and they are listed between two braces.
