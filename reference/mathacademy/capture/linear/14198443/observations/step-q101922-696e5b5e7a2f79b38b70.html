If x,y, and z are elements of B, but v and w are not, then which of the following is true?

a
x,y,z∉B and v,w∈B
b
x,y∈B and z,v,w∉B
c
x,y,z∉B
d
v,w∈B
e
x,y,z∈B and v,w∉B
Submit
Correct
EXPLANATION

If a is an element of S, we write a∈S. Otherwise, if a is not an element of S, we write a∉S.

  • Since x,y, and z are elements of B, we write x,y,z∈B.

  • Since v and w are not elements of B, we write v,w∉B.

All together, we have the following statement:

x,y,z∈B and v,w∉B
