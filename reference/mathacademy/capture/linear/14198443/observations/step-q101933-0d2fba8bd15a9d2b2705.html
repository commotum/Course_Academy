 25,27,29∈B and 34,50∉B

EXPLANATION

If a is an element of S, we write a∈S. Otherwise, if a is not an element of S, we write a∉S.

  • Since 25,27, and 29 are elements of B, we write 25,27,29∈B.

  • Since 34 and 50 are not elements of B, we write 34,50∉B.

All together, we have the following statement:

25,27,29∈B and 34,50∉B
