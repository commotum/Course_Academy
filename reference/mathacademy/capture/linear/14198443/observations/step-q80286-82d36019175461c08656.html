If π,e and 2 are elements of Y, but 0 and 1 are not, then which of the following is true?

a
 π,e,2∉Y and 0,1∈Y
b
1,π,2∉Y
c
 0∈Y and π,2∉Y
d
 π,e,2∈Y and 0,1∉Y
e
 0,1,π,e∈Y
Submit
Correct
EXPLANATION

If a is an element of S, we write a∈S. Otherwise, if a is not an element of S, we write a∉S.

  • Since π,e and 2 are elements of Y, we write π,e,2∈Y.

  • Since 0 and 1 are not elements of Y, we write 0,1∉Y.

All together, we have the following statement:

π,e,2∈Y and 0,1∉Y
