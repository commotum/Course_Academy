Let f(x)=1−x3 and let A denote the required area. The general formula for the trapezoidal rule states that

A≈12[f(a)+2(f(x1)+f(x2)+…+f(xn−1))+f(b)]Δx,

where n is the number of trapezoids and Δx=b−an is the step size.

Here, we have the following values:

  • The number of trapezoids is n=2.

  • The corresponding interval is [−2,0], so we have a=−2 and b=0.

  • The step size is given by Δx=b−an=0−(−2)2=1.

Using the above values, the general formula becomes A≈12[f(−2)+2f(−1)+f(0)]⋅1.

To identify the function values, we now set up a table with the values of x and f(x):

x −2 −1 0
f(x) 9 2 1

Finally, we obtain the following approximation for our area: A≈12[9+2(2)+1]⋅1=7

Because the function is concave up over the interval [−2,0], the trapezoids lie over the function, and therefore approximation is an overestimate of the correct area.
