The acceleration a at time t of a particle P moving in the xy-plane is given by a(t)=⟨4t+4,6t−21⟩,t>0. Given that the particle has velocity v=⟨42,−18⟩ when t=4, calculate the times at which the particle is stationary.

a
t=12
b
t=1,6
c
No stationary points
d
t=1
e
t=6
Submit
Correct
EXPLANATION

The particle is stationary when its velocity is zero. So first, we need to compute the velocity of the particle.

To compute the velocity vector, we need to integrate the acceleration vector:

v(t)=∫a(t)dt=∫⟨4t+4,6t−21⟩dt=⟨∫(4t+4)dt,∫(6t−21)dt⟩=⟨2t2+4t+C1,3t2−21t+C2⟩

Now, we can solve for the constants of integration using the fact that v(1)=⟨42,−18⟩. Substituting t=4, we get

v(4)=⟨2(4)2+4(4)+C1,3(4)2−21(4)+C2⟩⟨42,−18⟩=⟨48+C1,−36+C2⟩,

so we must have C1=−6 and C2=18. Therefore, the velocity is given by

v(t)=⟨2t2+4t−6,3t2−21t+18⟩.

To find the times at which the particle is stationary, we solve for the times at which the velocity is zero:

v(t)=0⟨2t2+4t−6,3t2−21t+18⟩=⟨0,0⟩

So we need 2t2+4t−6=2(t−1)(t+3)=0⇒t=−3,1,3t2−21t+18=3(t−1)(t−6)=0⇒t=1,6.

The only solution that satisfies both equations is t=1, so this is the only value of t when the particle is stationary.
