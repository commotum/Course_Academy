We know how to use the first derivative test to find the local extrema of a continuous function. But how do we find the global extrema of a continuous function on a closed interval

We apply the candidates test, which consists of the following three steps.

Step 1: Find all of the critical points. The critical points are our "candidates."

  • If the function is defined on a closed interval then we must remember to include the endpoints as well.

  • If the function is defined on an open interval then we do not include the endpoints.

Step 2: Determine the value of the function at each of the critical points.

Step 3: Compare all the values of found in step The greatest of these values is the global maximum value, and the least is the global minimum value.
