Recall that a random variable is a variable whose value is determined by the outcome of a trial or experiment. A random variable can take on one of many values from a set called the range or support of

A continuous random variable is a random variable whose set of possible values is given by an interval of real numbers.

For example, the height of a randomly selected person could be modeled as a continuous random variable because its possible values form an interval of real numbers. For modeling purposes, we usually assume that the height of a randomly selected person could be any number in the real interval although we could also restrict this to a finite interval if we wanted.

On the other hand, the result of rolling a -sided die is not a continuous random variable because its possible values are which does not correspond to an interval of real numbers.

Physical quantities, such as mass, length, area, volume, time, fluid concentration, etc, are usually modeled as continuous variables.
