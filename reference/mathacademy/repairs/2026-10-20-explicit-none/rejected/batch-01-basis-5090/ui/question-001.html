Which of the following are first-order ordinary differential equations?

Select all that apply.

Answer: 3y″+2xy′=x2y
Answer: 5x2y+3y5y′=4x
Answer: y2+y′+7x3=ey
Answer: None of the above
CorrectPreview only
Solution:

Answer: 3y″+2xy′=x2y · correct value:

false

Equation I contains y'', so its highest derivative is second order.

Answer: 5x2y+3y5y′=4x · correct value:

true

Equation II contains y' and no higher derivative. The factor y^5 does not change the differential order.

Answer: y2+y′+7x3=ey · correct value:

true

Equation III contains y' and no higher derivative. The square root does not change the differential order.

Answer: None of the above · correct value:

false

Equations II and III are first-order ordinary differential equations.

A differential equation is of first-order if the largest derivative term in the equation is y′.

Keeping this in mind, let's check each given equation.

  • Equation 3y″+2xy′=x2y is not a first-order differential equation. The highest derivative in this equation is y″, so this is a second-order differential equation.

  • Equation 5x2y+3y5y′=4x is a first-order differential equation. The highest derivative in this equation is y′.

  • Equation y2+y′+7x3=ey is also a first-order differential equation. The highest derivative in this equation is y′.

Therefore, the correct answer is 5x2y+3y5y′=4x; y2+y′+7x3=ey only.
