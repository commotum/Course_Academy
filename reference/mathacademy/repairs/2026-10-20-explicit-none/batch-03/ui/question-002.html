Consider the vectors shown above. Given that the inner product in the vector space R3 is defined as

⟨x,y⟩=x1y1+2x2y2+x3y3,

which of the following statements are true?

Select all that apply.

Answer: v1⊥v3 with respect to the given inner product
Answer: v2⊥v3 with respect to the given inner product
Answer: S=v1,v2,v3 is an orthogonal set with respect to the given inner product
Answer: None of the above

true

Answer: v2⊥v3 with respect to the given inner product · correct value:

false

Answer: S=v1,v2,v3 is an orthogonal set with respect to the given inner product · correct value:

false

Answer: None of the above · correct value:

false

Recall that a set of vectors in an inner product space is orthogonal if all vectors in the set are mutually orthogonal with respect to the given inner product.

With that in mind, let's examine our statements in turn.

  • Statement “v1⊥v3 with respect to the given inner product” is true. Indeed, we have

⟨v1,v3⟩=(−1)(1)+2(1)(2)+(1)(−3)=(−1)+4−3=0,

which means that v1⊥v3 with respect to the given inner product.

  • Statement “v1⊥v3 with respect to the given inner product” is false since

⟨v2,v3⟩=(2)(1)+2(−1)(2)+(2)(−3)=2−4−6=−8≠0,

which means that v2⊥̸v3 with respect to the given inner product.

  • Statement “S=v1,v2,v3 is an orthogonal set with respect to the given inner product” is false. Since v2⊥̸v3, the set S is not orthogonal.

Therefore, the correct answer is “v1⊥v3 with respect to the given inner product” only.
