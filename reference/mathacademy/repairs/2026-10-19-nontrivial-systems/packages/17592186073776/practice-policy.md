# Eligible linear systems

Identical equations and equations differing only by a sign are excluded.
This applies to default sampling and explicit parameters for learner output.

Easy: standard form, multiplier magnitude 2, coefficients <=5, constants <=12.
Moderate: standard form, multiplier magnitude 2..4, coefficients <=10, constants <=30;
exclude every instance fitting easy. Hard: rearrange both zero-RHS equations;
nonunit multiplier 2..4, with the existing signed coefficient bounds.
All three outcomes are selected before instance sampling at every level.
These are authored bands; captured source practice questions have no ratings.
