A function is invertible if and only if it's a one-to-one function. To determine which of the functions are one-to-one, we use the horizontal line test.

From the above, we see that:

  • For graphs I, III, any horizontal line will intersect the curve at most once, no matter where we draw the line. Therefore, these graphs show one-to-one functions. As a result, these functions are invertible.

  • For graphs II, IV, some horizontal lines intersect the curve more than once. These are not one-to-one functions. As a result, they are not invertible.
