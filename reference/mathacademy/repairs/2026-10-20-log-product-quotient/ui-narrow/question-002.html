Review topic

Express ln⁡(5)+ln⁡(x)−ln⁡(z) as a single logarithm. Assume x>0 and z>0.

Choose an answer
CorrectPreview only
Solution:

Answer · correct value:

ln⁡(5⋅xz)

Using the product rule for logarithms, combine the first two terms:

ln⁡(5)+ln⁡(x)−ln⁡(z)=ln⁡(5⋅x)−ln⁡(z).

Now use the quotient rule to combine the remaining difference:

ln⁡(5⋅x)−ln⁡(z)=ln⁡(5⋅xz).
