Suppose we want to rewrite log3⁡(4)−log3⁡(6) as a single logarithm. We can do this using the quotient rule.

The quotient rule is very similar to the product rule, except that this time we're dealing with the difference of two logarithms rather than the sum.

The quotient rule states that two logarithms which share a common base n satisfy

logn⁡(a)−logn⁡(b)=logn⁡(ab).

So, we can use this rule to rewrite log3⁡(4)−log3⁡(6) as

log3(4)−log3(6)=log3(46)=log3(23).

The quotient rule works exactly the same for the natural and common logarithms.
