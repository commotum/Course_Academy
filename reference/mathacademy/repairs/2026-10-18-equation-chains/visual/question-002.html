Consider the recurrence relation

an+1=11an−10an−1,a1=5,a2=95,n∈N,n≥2.

Suppose we wish to prove the following statement using strong induction:

an=10n−5,∀n∈N

A proof template is outlined below. Fill in the missing statements.

Base Cases: We first prove that our statement is true for the base cases n=1 and n=2.

a1=101−5a2=103−5

Inductive Hypothesis: We assume that an=10n−5 is true for all n≤k. In particular, we have the following:

ak=10k−1ak−1=10k−1

Inductive Step: We're required to prove that

ak+1=10k−1

Conclusion: Therefore, an=10n−5 for all n∈N.

Solution:

To prove a statement using strong induction, we use the following framework:

  • Step 1: Base Case

  • Step 2: Inductive Hypothesis

  • Step 3: Inductive Step

  • Step 4: Conclusion

In this case, the general statement P(n) we're required to prove is the following:

an=10n−5

We start by proving the base cases. Since the first application of the recurrence formula an+1=11an−10an−1 does not apply until a3, we must check the base cases P(1) and P(2).

Base Cases: We first prove our statement is true for the base cases n=1 and n=2.

a1=101−5a2=102−5

Proving that the base cases are true is usually straightforward. We simply calculate the right-hand side and show that it equals the left-hand side in both cases.

Next, we write down our (strong) inductive hypothesis, which is to assume that P(n) is true for all n≤k, where k≥2.

Inductive Hypothesis: We assume that an=10n−5 is true for all n≤k for k≥2. In particular, we have the following:

ak=10k−5ak−1=10k−1−5

Then, we move onto the inductive step: We must show that P(1),P(2),…,P(k)⇒P(k+1). We start by writing down P(k+1).

Inductive Step: We're required to prove that

ak+1=10k+1−5.

The inductive step is where most of the work lies. The idea is to rewrite the left-hand side of this equation using the recurrence relation and inductive hypothesis to show that this equals the right-hand side.

Once we've shown that P(1),P(2),…,P(k)⇒P(k+1), the proof is complete, and we state our conclusion.

Conclusion: Therefore, an=10n−5 for all n∈N.
